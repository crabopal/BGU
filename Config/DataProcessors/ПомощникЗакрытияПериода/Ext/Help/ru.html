Помощник закрытия периода

Рабочее место Помощник закрытия периода является сервисным инструментом и предназначен для оказания помощи бухгалтеру при выполнении регламентных операций по закрытию учетного периода.

Основное назначение Помощника – сформировать список регламентных операций, которые необходимо выполнить в конце месяца или года, а также указать последовательность их выполнения.

Также в форме Помощника слева от каждой регламентной операции отображаются индикаторы проверки, которые отражается отражают информация информацию о состоянии регламентных операций:

  • Проверка пройдена. Никаких действий не требуется.
  • Предупреждение. Документы введены частично, либо заполнены не полностью.
  • Проверка не пройдена. Не введены документы по данному разделу учета.

Кроме того Помощник содержит вспомогательные инструменты для получения дополнительной информации и ввода соответствующих регламентных документов.

Работа с "Помощником закрытия периода"

Для вызова Помощника закрытия периода можно использовать команду Помощник закрытия периода меню функций раздела Учет и отчетность.

В шапке формы следует указать Месяц и Год, для которых необходимо выполнить закрытие периода, а также выбрать Организацию.

Список операций содержит список регламентных операций за указанный в шапке период, которые необходимо проанализировать и в случае необходимости выполнить.

Список регламентных операций показан в той последовательности, в которой эти операции необходимо выполнять.

Элемент списка операций может быть либо конкретной регламентной операцией, либо группой операций.

Группа операций объединяет зависимые друг от друга операции, относящиеся к одному виду учета.

После нажатия гиперссылки с нужной регламентной операцией в правой колонке появится дополнительная информация о данной операции.

Для заполнения списка данными о состоянии регламентных операций следует нажать на кнопку Обновить все командной панели формы.

Дальнейшие действия определяются состоянием, в котором находится та или иная регламентная операция:

  • Проверка не пройдена. Не введены документы по данному разделу учета – для ввода документа следует использовать гиперссылку Ввести документ в строке операции или гиперссылку Открыть список документов и нажать кнопку Создать. После заполнения документа его следует провести;
  • Предупреждение. Документы введены частично, либо заполнены не полностью – для данного состояния доступны гиперссылки Ввести документ и Открыть список документов;
  • Проверка пройдена. Никаких действий не требуется – для этого состояния доступна только гиперссылка Открыть список документов.
