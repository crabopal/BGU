Сервис "Сверка данных учета НДС"

Сервис Сверка данных учета НДС предназначен для выполнения сверки данных учета НДС с контрагентами.

Для вызова формы Сверка данных учета НДС можно использовать команду Сверка данных учета НДС меню функций раздела Налоги.

Работа с сервисом состоит в отправке поставщикам по электронной почте запросов на получение реестров счетов фактур, получении о них запрошенных реестров и последующей сверкой полученных реестров с данными учета организации.

Предварительно, до использования сервиса, его необходимо настроить.

Настройка сервиса заключается в выборе учетной записи электронной почты на закладке Настройки.

Закладка "Запросы поставщикам"

На закладке Запросы поставщикам можно запросить у поставщиков реестры счетов-фактур для проведения сверки.

При этом список поставщиков будет автоматически заполнен контрагентами, которые выставляли в отчетном периоде счета-фактуры.

У каждого контрагента будет указано состояние запроса реестров:

  • Не запрошен;
  • Запрошен;
  • Ожидает загрузки;
  • Устарел;
  • Готов к сверке.

У поставщиков можно задать адреса электронной почты, а затем автоматически разослать им запросы о сверке с помощью кнопки Запросить реестры.

Закладка "Ответы поставщиков"

На закладке Ответы поставщиков содержится информация о реестрах, поступивших от поставщиков. Эта информация автоматически поступает из электронной почты.

Чтобы загрузить реестры поставщиков для сверки следует выбрать необходимые реестры, а затем использовать кнопку Загрузить.

Закладка "Сверка"

Отчет о соответствии счетов-фактур организации данным счетов-фактур поставщиков за выбранный отчетный период формируется на закладке Сверка после использования кнопки Сверить.

Закладка "Запросы покупателей"

Загрузка запросов покупателей на сверку выполняется на закладку Запросы покупателей.

После нажатия на кнопку Ответить программа автоматически сформирует реестры счетов-фактур по отмеченным запросам и отправит их покупателям по электронной почте.
