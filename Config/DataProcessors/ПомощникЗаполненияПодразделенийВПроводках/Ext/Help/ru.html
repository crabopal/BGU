Помощник заполнения подразделений в проводках

Помощник предназначен для исправления последствий ошибки 00-00157184:

При обновлении на релизы 2.0.56.36, 2.0.56.38, 2.0.56.40 настройки следующих счетов сбрасывались в состояние по умолчанию:

101.12, 101.22, 101.26, 101.32, 101.36, 104.12, 104.22, 104.26, 104.32, 104.36, 108.53, 205.21, 205.30, 205.31, 205.40, 205.41, 205.50, 205.51, 206.40, 206.41, 206.42, 206.50, 206.51, 02, 02.1, 02.2, 21, 21.20, 21.22, 21.26, 21.30, 21.32, 21.36, 25.53, 25.53, 40.

Необходимо проверить и восстановить настройки счетов вручную.
После этого нужно запустить эту обработку, получить список документов с недозаполненными проводками, и перепровести документы.

В релизе 2.0.57.7 изменена группировка счетов по признаку учета по подразделениям. При обновлении конфигурации у счетов каждой группы устанавливается одинаковый признак. В результате у некоторых счетов может быть установлен признак учета по подразделениям. Обработка позволяет выявить эти счета и документы по ним с незаполненными подразделениями в проводках.

При открытии список счетов заполняется счетами:
- входящими в группы учета по подразделениям, у которых установлен признак учета по подразделениям и есть остатки с пустым подразделением;
- счетами из ошибки 00-00157184, не входящими в группы учета по подразделениям: 205.21, 205.30, 205.31, 205.40, 205.41, 205.50, 205.51, 206.40, 206.41, 206.42, 206.50, 206.51, 02, 02.1, 02.2, 25.53, 40.


По кнопке Найти недозаполнненные документы выполняется поиск документов, у которых не заполнены реквизиты по установленным признакам учета. Проводки проверяются по признакам Учет по подразделениям и Валютный. Список документов сортируется по дате и номеру документа.

По кнопке Перепровести выполняется последовательное перепроведение документов (переформировываются только проводки). У перепроведенных документов флажок в списке документов сбрасывается. Если при перепроведении возникают ошибки, то перепроведение останавливается на проблемном документе.
Ошибки могут быть:
- проводки документа отредактированы вручную;
- при перепроведении количество проводок или суммы в них изменяются;
- возникла другая ошибка, например недостаточно остатков для списания.

В этом случае документ необходимо отработать вручную. Перепровести, исправив возникшие ошибки, или вручную заполнить подразделение в проводках. После этого в списке документов снять флажок у этого документа и нажать Перепровести, проведение продолжится дальше.

Для просмотра проводок документа без его открытия можно нажать кнопку Д-т/К-т формы обработки.
