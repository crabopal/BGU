Форма "Зависимости от других отчетов"

Некоторые форматы выгрузки имеют требования, что некоторые отчеты могут выгружаться только совместно с другими отчетами. В случае наличия подобных требований и невозможности решения их в автоматическом режиме открывается эта форма. В которой для  каждого нерешенного требования нужно выбрать отчет, который будет выгружаться совместно с отмеченным для выгрузки отчетом.

Пример

Примером подобных требований может случить взаимосвязь отчетов "Ф. 0503730, Баланс государственного (муниципального) учреждения" и "Ф. 0503730, Справка по забалансовым счетам" при выгрузке в ФНС. Если один из этих отчетов отмечен для выгрузки тогда система попробует найти второй отчет и если найдет только один, то система сама выберет его, но если найдено будет более одного отчета, то будет открыта эта форма, в которой нужно выбрать какой из найденных отчетов следует использовать для выгрузки.

Таблица требований выгружаемых отчетов

В эту таблицу выводятся требования выбранных для выгрузки отчетов. При этом у одного отчета может быть несколько требований, в том числе и с одинаковыми видами требуемых отчетов. Полное описание требования выводится под таблицей вариантов. При выделении строки этой таблицы в таблице вариантов выводятся возможные варианты решений.


Возможные варианты решений

Тут выводятся переключатели соответствующие возможным вариантам решений. Для каждого требования тут нужно выбрать подходящий вариант.

Продолжение выгрузки

Для продолжения выгрузки нужно выбрать вариант для каждого требования выгружаемых отчетов. Пока это не сделано кнопка Продолжить не доступна.
В случае если одно из требований не имеет вариантов, продолжение выгрузки невозможно. В этом случае стоит отменить выгрузку и создать требуемый отчет, или снять отметку выгрузки с отчета который предъявил невыполнимое требование, и повторно выгрузить отчеты.
