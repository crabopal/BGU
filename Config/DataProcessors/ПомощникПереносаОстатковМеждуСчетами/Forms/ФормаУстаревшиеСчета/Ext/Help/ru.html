Перенос остатков по устаревшим счетам

Помощник предназначен для переноса остатков с устаревших счетов на новые счета.

В поле На дату указывается дата, на которую будет выполяться поиск устаревших счетов и остатков по ним.
В поле Организация указывается организация, по которой будет выполняться поиск остатков. Если поле не заполнено, поиск будет осуществляться по всем организациям.
В поле Счет (устаревший) указывается счет, по которому будет выполняться поиск остатков. Если поле не заполнено, поиск будет осуществляться по всем счетам.

По кнопке Заполнить выполняется поиск остатков на указанную дату. Новый счет определяется автоматически - актуальный счет с тем же кодом, что у устаревшего счета. Новый счет можно изменить вручную.
По кнопке Перенести остатки создаются документы Операция (бухгалтерская) с проводками по переносу остатков. Документы создаются в разрезе организаций, КФО, счета (устаревшего), с ограничением в 1000 проводок на каждый документ. Документы отмечаются комментарием «Перенос остатков с устаревших счетов».

На вкладке Документы отображаются документы Операция (бухгалтерская), которые были созданы после нажатия кнопки Перенести остатки.
