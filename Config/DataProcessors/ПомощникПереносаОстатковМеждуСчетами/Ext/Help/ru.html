Обработка "Помощник переноса остатков между счетами"

Универсальная обработка Помощник переноса остатков между счетами, далее – Помощник, предназначена для переноса остатков по счету на определенную дату на другой счет или другую аналитику. Помощник можно использовать для переноса остатков как по балансовым счетам, так и по забалансовым.

Внимание! Помощник предназначен для переноса остатков со счетов, действующих на дату переноса остатков. Для переноса остатков с устаревших счетов следует использовать Помощник переноса остатков с устаревших счетов.

В заголовочной части Помощника следует:

  • указать дату переноса остатков (Дата переноса);
  • выбрать учреждение, по которому переносятся остатки (Организация),
  • указать первичный документ – основание операции, его дату и номер;
  • в поле Содержание ввести текст основания переноса данных, например: "Переход на приказ № ХХн".

Форма Помощника состоит из двух частей:

  • Источник остатков (откуда переносим) – группа реквизитов для настройки отбора при получении остатков и самих остатков, сформированных по установленному отбору.
  • Приемник остатков (куда переносим) – группа реквизитов для настройки корреспондирующей стороны проводки при переносе остатков со счетов-источников.

Группа "Источник остатков (откуда переносим)"

Группа реквизитов состоит из двух частей: фильтра для настройки отбора остатков и таблицы остатков.

В общей части следует указать счет, с которого переносятся остатки (Счет), а также КФО, КПС, КОСГУ, аналитику счета, по которым требуется отобрать остатки для переноса.

Таблица, расположенная ниже, содержит остатки, сформированные по установленному отбору. Таблица заполняется по кнопке Заполнить остатки в командной панели. В таблице остатков разрешено только изменять порядок строк и удалять строки. Редактировать данные строк нельзя.

Если требуется перенести остатки не в полной сумме, следует скопировать строку в приемник (кнопка Еще - Скопировать строку в приемник в командной панели таблицы Источника остатков) и внести изменения в полученную таким образом строку в таблице Приемника остатков.

Строки таблицы остатков, для которых в таблице-приемнике задана детализация, выделяются синим цветом шрифта. Если общая сумма или количество в таблице-приемнике не равно сумме строки таблицы остатков, соответствующая ячейка строки остатков выделяется желтым цветом фона.

Примечание. Если в таблице остатков суммы остатков положительные, то это дебетовые остатки, если отрицательные - кредитовые. Это правило не зависит от вида счета (активный, пассивный).

Группа "Приемник остатков (куда переносим)"

Группа реквизитов состоит из двух частей: общих реквизитов корреспондирующей стороны проводок и таблицы детализации.

В общей части следует указать счет и его аналитику, куда следует перенести остатки со счетов-источников, для которых не указаны данные в таблице детализации.

Таблица детализации позволяет детализировать корреспондирующую сторону проводок для конкретных счетов-источников. Т.е. данные, введенные в таблицу детализации, относятся к текущей строке таблицы остатков. Строка таблицы остатков, у которой введены детальные строки в таблице детализации, выделяются синим цветом шрифта.

Таблица детализации необязательна для заполнения. Если для счета-источника не указаны данные в таблице детализации, то остатки будут перенесены на счет, указанный в общей части.

Как в общей части, так и в таблице детализации можно не заполнять аналитику счета. В этом случае, при формировании проводок программа автоматически заполнит субконто счета-приемника аналогичными субконто счета-источника, с которого переносятся остатки.

Правила формирования проводок Помощником

В общем случае, остатки переносятся прямыми проводками (не сторно!). Из этого следует, что если остатки в таблице остатков положительные, то списываться они будут с кредита счета-источника, независимо от вида счета (активный, пассивный), в дебет счета-приемника.

Для переноса остатков в межотчетный период в корреспонденции со счетом 401 30 следует установить флаги Переносить через транзитный счет и Отразить в межотчетном периоде и указать счет 401.30 и вид межотчетного периода "Изменение валюты баланса".

Для счетов-источников, для которых не указаны данные в таблице детализации группы приемника, остатки будут перенесены на счет, указанный в общей части.

Если для счета-источника указаны данные в таблице детализации, то его остатки будут перенесены на счета, указанные в таблице детализации.

Если у счета-приемника не указана аналитика (либо в общей части приемника, либо в таблице детализации), то программа будет пытаться заполнить субконто счета-приемника данными аналогичной аналитики счета-источника.

Например, если переносится остаток со счета 205.31, у которого есть субконто Контрагенты и Договоры, на счет 205.74, который имеет такие же субконто, то если для счета-приемника 205.74 не указать аналитику, она будет заполнена из аналитики счета-источника (205.31). При этом порядок следования субконто на счетах источника и приемника не имеет значения.

Правила указания оборотных КЭК:

  • Если перенос остатков выполняется по счетам, у которых КЭК оборотный, то он будет автоматически рассчитан и подставлен в проводку программой, если он не указан для счета-приемника в общей части группы приемника или в таблице детализации.
  • Если КЭК напрямую указан в общей части группы приемника или таблице детализации, то именно он будет подставлен для счета-приемника. Для счета-источника он будет рассчитан.
  • Если включен флажок Указанный в приемнике оборотный КЭК использовать по дебету и по кредиту, то КЭК, указанный для счета-приемника, будет использоваться и для счета-источника. Это позволит реализовать проводки, отражающие внутренние обороты, в которых и по дебету, и по кредиту используется один и тот же КЭК. Например, Д-т 104.28.410, К-т 104.38.410.
  • Этот флажок действует только для оборотных КЭК!

По кнопке Перенести остатки формируется документ Операция (Бухгалтерская).

Если в Помощнике установлены флаги Переносить через транзитный счет и Отразить в межотчетном периоде и указан транзитный счет, в документе Операция (Бухгалтерская) будет указан вид межотчетного периода "Изменение валюты баланса" и сформированы бухгалтерские записи по переносу остатков по счетам в корреспонденции со счетом 401.30.

Важно. При повторном нажатии кнопки Перенести остатки формируется новый документ Операция (Бухгалтерская).
Правки надо вносить в сформированный ранее документ Операция (Бухгалтерская) или удалить ошибочный документ после повторного ввода.
