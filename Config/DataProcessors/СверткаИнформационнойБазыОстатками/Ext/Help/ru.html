Обработка "Помощник свертки информационной базы (Вводом остатков)"

С помощью данной обработки можно выполнить свертку информационной базы.

Для выполнения свертки потребуется указать дату свертки, выбрать организации, для которых будет выполнена свертка, а также выбрать режим выполнения свертки.

В результате свертки информационной базы будут сформированы входящие остатки, а документы, до даты свертки включительно, будут помечены на удаление.

Внимание!
Операция свертки информационной базы является необратимой. Перед сверткой необходимо создать копию информационной базы.

Пометка на удаление

Документы до даты свертки помечаются на удаление, кроме документов следующих видов:

  • Регистрация обязательств и сведений по договорам (очищаются только проводки).
  • Регистрация сведений об имуществе.
  • Регламентированный бухгалтерский отчет.

Ввод остатков и движений

Остатки и движения по основным средствам вводятся документами:

  • Ввод начальных остатков ОС, НМА, НПА (счета 101, 102, 103, 105, 108, 21, 25, 26).
  • Ввод начальных остатков по разделу учета Ввод остатков ОС на забалансовых счетах (01, 02, 22) (счета 01, 02, 22).

Остатки и движения по материальным запасам вводятся документами:

  • Ввод начальных остатков по имуществу казны (МЗ) (счет 108.56).
  • Ввод начальных остатков материалов (а также счет 08) (счета 105, 02, 07, 08, 09, 12, 13, 22, 23).
  • Ввод начальных остатков по разделу учета Ввод остатков по счету 106.хП (счета 106.2П, 106.3П, 106.4П, Н15) .
  • Ввод начальных остатков по разделу учета Ввод остатков бланков строгой отчетности (счета 03).

Остатки НДС (входящему и исходящему) вводятся документом:

  • Ввод начальных остатков по разделу учета Ввод остатков НДС (счета 210.10).

Остатки по остальным счетам бухгалтерского учета вводятся документом:

  • Ввод начальных остатков по разделу учета Ввод остатков по прочим счетам бух. учета.

Цены номенклатуры вводятся документом:

  • Установка цен номенклатуры.

Документом "Корректировка регистров" вводятся остатки по регистрам:

  • Безналичные денежные средства.
  • Входящий НДС к распределению.
  • Денежные документы.
  • Журнал учета компенсации родительской платы.
  • Наличие драгоценных материалов в ломе и отходах.
  • Наличные денежные средства.
  • Параметры амортизации прав пользования ОС, НМА, НПА.
  • Параметры списания доходов будущих периодов.
  • Расчеты с учащимися.
  • Расчеты с учащимися по дополнительным услугам.
  • Сведения об учащихся.
  • Учет компенсации родительской платы.

Документом "Корректировка регистров" переносятся движения регистров:

  • Плановые даты оплаты (образование).
  • Плановые поступления родительской платы.
  • Сведения о прочих услугах для учащихся.

Данные следующих неподчиненных регистров сведений сворачиваются на втором этапе свертки:

  • История изменения ставки для компенсации родительской платы.
  • Настройка способов отражения зарплаты в бух. учете.
  • Настройка статей финансирования (зарплата).
  • Настройки заполнения отчетов статистики по драг. материалам.
  • Параметры начислений за прочие услуги учащимся.
  • Паспорта транспортных средств.
  • Плательщики по услугам образования.
  • Протоколы отправленных отчетов.
  • Регистрация земельных участков.
  • Регистрация транспортных средств.
  • Сведения кадастрового учета.
  • Состояние объектов учета реестра имущества.
  • Состояния отправленных отчетов.
  • Ставки налога на имущество.
  • Ставки налога на прибыль для всех организаций.
  • Численность довольствующихся.
