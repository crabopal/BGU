Способы свертки информационной базы

Свертка информационной базы проводится, чтобы достигнуть 4 цели:

1. Уменьшить объем базы данных;
2. Увеличить скорость работы программы:
    – в пользовательском режиме;
    – при обновлении (изменении) конфигурации;
    – при проведении тестирования;
    – при исправлении информационной базы;
3. Удалить неактуальные элементы справочников;
4. Устранить ошибки ведения учета.

При свертке данных по старому способу, с использованием документов Корректировка регистров, достигаются только первые 3 цели. При этом, четвертая цель – исправление и устранение ошибок в учете – трудоемка, так как отредактировать данные в документах Корректировка регистров затруднительно.

Для достижения 4 цели реализован новый подход свертки базы – с использованием документов ввода начальных остатков. При выполнении свертки таким способом происходит формирование документов ввода остатков по регистрам на дату свертки и установка пометки на удаление на неиспользуемые документы и движения по регистрам сведений, регистрам накопления и регистрам бухгалтерии до даты свертки включительно.
см. справку Свертка информационной базы (Вводом остатков).

При ранее используемом подходе свертки базы способы свертки для каждого регистра сведений, регистра накопления, регистра бухгалтерии и документа настраивались вручную выбором одного из вариантов «Свернуть», «Перенести», «Очистить», «Не сворачивать». В отличие от прежнего подхода, при свертке базы по-новому:
     – способы свертки регистров пользователем больше не настраиваются;
     – способ свертки «Не сворачивать» - не применяется.
см. справку Свертка информационной базы (Корректировками регистров).

В результате свертки базы по новому способу все данные по регистрам, необходимые для сохранения движения, автоматически переносятся в документы ввода остатков, при этом ненужные движения будут удалены.

Новая обработка свертки выполняется в фоновом режиме и позволяет наблюдать за состоянием свертки в реальном времени.
