Помощник ввода начальных остатков

Для вызова "Помощника ввода начальных остатков" можно использовать команду "Помощник ввода начальных остатков" панели навигации раздела "Настройка и администрирование".

В окне формы на отдельных закладках расположены таблицы Основные счета плана счетов и Забалансовые счета плана счетов.

Каждая строка и той, и другой таблицы содержит код счета, наименование счета, а также поля для хранения начальных остатков по дебету и кредиту счета – Сальдо Дт (нач.) и Сальдо Кт (нач.).

В шапке формы Помощника появляются выделенные красным цветом актуальные подсказки, а также синие гиперссылки, помогающие выполнить ряд действий, предшествующих вводу остатков.

Важно
Предварительно, до ввода остатков, потребуется выбрать организацию, для которой необходимо вводить остатки, указать для нее параметры учетной политики и выбрать дату ввода остатков.

Примечание. Первая подсказка в шапке формы: "К вводу остатков не готов. Не указана организация".

Выбор организации

Наименование организации следует указать в реквизите Организация, выбрав его из справочника Организации.

Примечание. Если карточка организации отсутствует в справочнике "Организации", то ее необходимо создать с помощью кнопки "Создать" командной панели формы списка, после чего ввести в нее минимальный набор реквизитов – "Наименование", "ОКПО" и "ИНН".
После нажатия на кнопку "Записать и закрыть" карточку следует выбрать из формы списка с помощью кнопки "Выбрать" или двойного щелчка левой кнопки мыши.

Примечание. После того, как организация выбрана, в шапке формы появляется вторая подсказка: К вводу остатков не готов. Не установлена дата ввода начальных остатков.

Выбор даты ввода начальных остатков

Диалог для установки даты ввода начальных остатков вызывается с помощью гиперссылки Дата ввода начальных остатков.

Важно
Дату ввода начальных остатков необходимо задавать на один день ранее даты начала ведения учета.

Если датой начала ведения учета является 1 января какого-либо года, то в качестве даты ввода начальных остатков следует выбрать 31 декабря предыдущего года.

Для сохранения даты, введенной в поле диалога "Дата ввода начальных остатков", и закрытия диалога следует нажать на кнопку "Установить".

После закрытия диалога в форме окна помощника будет представлена информация о заданной дате ввода остатков и появится гиперссылка, позволяющая изменить указанную дату.

Выбор параметров учетной политики

Если параметры учетной политики организации были заданы ранее, то в шапке фломы Помощника будет видна гиперссылка Учетная политика: Задана, позволяющая, если это необходимо, открыть диалог Учетная политика организации и отредактировать необходимые реквизиты.

Если параметры учетной политики организации не заданы, то в шапке формы Помощника появится подсказка – Учетная политика: Не задана (необходимо заполнить), позволяющая открыть диалог Учетная политика организации и задать необходимые реквизиты.

После того, как параметры учетной политики определены, можно приступать к вводу остатков.

Ввод начальных остатков

Для ввода начальных остатков следует выбрать счет, остатки по которому следует ввести, в таблице "Основные счета плана счетов" или "Забалансовые счета плана счетов", а затем нажать на кнопку "Ввести остатки по счету".

В результате откроется документ, предназначенный для ввода остатков в разделе учета, которому принадлежит выбранный счет.

Дальнейшие действия по вводу остатков ничем не отличается от действий по вводу остатков с использованием соответствующего документа.

Проверка правильности ввода начальных остатков

Для проверки правильности ввода остатков можно использовать отчет "Оборотно - сальдовая ведомость".

Открыть отчет "Оборотно - сальдовая ведомость" можно с помощью команды "Оборотно - сальдовая ведомость" панели действий раздела "Учет и отчетность".
