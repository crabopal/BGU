Помощник ввода начальных остатков

Помощник ввода начальных остатков предназначен для ввода начальных остатков на счетах бухгалтерского учета в начале работы с программой.

Для вызова Помощника ввода начальных остатков можно использовать команду Помощник ввода начальных остатков меню функций раздела Администрирование.

В окне формы на отдельных закладках расположены таблицы Основные счета и Забалансовые счета плана счетов. Каждая строка и той, и другой таблицы содержит код счета, наименование счета, а также поля для хранения начальных остатков по дебету и кредиту счета – Сальдо Дт (нач.) и Сальдо Кт (нач.).

На закладках Ввод остатков ОС, НМА, НПА и Ввод остатков по другим разделам учета находятся списки документов, которые будут созданных в процессе ввода остатков.

В шапке формы Помощника появляются выделенные цветом актуальные подсказки, а также гиперссылки, помогающие выполнить ряд действий, предшествующих вводу остатков.

Внимание!
Предварительно, до ввода остатков, потребуется выбрать организацию, для которой необходимо вводить остатки, указать для нее параметры учетной политики и выбрать дату ввода остатков.

Выбор организации

Наименование организации следует указать в реквизите Организация, выбрав его из справочника Организации.

Если карточка организации отсутствует в справочнике Организации, то ее необходимо создать с помощью кнопки Создать командной панели формы списка, после чего ввести в нее минимальный набор реквизитов – Наименование, ОКПО и ИНН.

После нажатия кнопки Записать и закрыть карточку следует выбрать из формы списка с помощью кнопки Выбрать или двойного щелчка левой кнопки мыши.

Выбор даты ввода начальных остатков

Диалог для установки даты ввода начальных остатков вызывается с помощью гиперссылки Дата ввода остатков.

Важно!
Дату ввода начальных остатков необходимо задавать на один день ранее даты начала ведения учета. Если датой начала ведения учета является 1 января какого-либо года, то в качестве даты ввода начальных остатков следует выбрать 31 декабря предыдущего года.

Для сохранения даты, введенной в поле диалога Установка даты ввода начальных остатков, и закрытия диалога следует нажать кнопку Установить.

Выбор параметров учетной политики

Если параметры учетной политики организации были заданы ранее, то в правом окне формы помощника будет видна гиперссылка Учетная политика: Задана, позволяющая, если это необходимо, открыть диалог Учетная политика организации и отредактировать необходимые реквизиты.

Если параметры учетной политики организации не заданы, то в шапке формы помощника:

  • появится подсказка Не готов к вводу остатков;
  • появится гиперссылка Учетная политика: Не задана, позволяющая открыть диалог Учетная политика организации и задать необходимые реквизиты.

После того как параметры учетной политики определены, можно приступать к вводу остатков.

Ввод начальных остатков

Для ввода начальных остатков следует выбрать счет, остатки по которому следует ввести, в таблице Основные счета или Забалансовые счета плана счетов, а затем нажать кнопку Ввести остатки по счету.

В результате откроется документ, предназначенный для ввода остатков в разделе учета, которому принадлежит выбранный счет.

Проверка правильности ввода начальных остатков

Для проверки правильности ввода остатков можно использовать отчет Оборотно-сальдовая ведомость.

Открыть отчет Оборотно-сальдовая ведомость можно с помощью команды Оборотно-сальдовая ведомость меню функций раздела Главное.
