Помощник "Управление номерами инвентарных объектов"

Помощник Управление номерами инвентарных объектов предназначен для переноса данных из устаревших индивидуальных характеристик справочника Основные средства, НМА, НПА в справочник Инвентарные номера ОС.

Для вызова помощника можно использовать команду Управление номерами инвентарных объектов меню функций раздела ОС, НМА, НПА.

В шапке формы Управление номерами инвентарных объектов предусмотрен отбор по реквизитам Организация и Основное средство.

Если флажок В том числе перенесенные установлен, то таблица будет заполнена также основными средствами, у которых есть инвентарные номера и у которых заполнена хотя бы одна индивидуальная характеристика. Используется для контроля над переносом данных.

После использования кнопки Заполнить таблица заполняется основными средствами, у которых имеются данные хотя бы в одной из индивидуальных характеристик:

  • Реестровый номер,
  • Заводской номер,
  • Номер паспорта,
  • Дата выпуска.

Для запуска механизма переноса следует нажать на кнопку Перенести.

Далее помощник формирует для каждого объекта табличной части инвентарный номер и переносит соответствующие данные.

Примечание. Закладка Индивидуальные характеристики в справочнике Основные средства, НМА, НПА используется только для ввода пользовательских индивидуальных характеристик. Ввод таких реквизитов объекта ОС как Реестровый номер, Заводской номер, Номер паспорта и Дата выпуска выполняется в справочнике Инвентарные номера ОС, НМА, НПА и возможен только для объектов ОС, для которых инвентарные номера созданы.

Внимание!
Заполнение реквизитов Реестровый номер, Заводской номер, Номер паспорта и Дата выпуска для объектов ОС, НМА и НПА, у которых инвентарные номера отсутствуют, не предусмотрено!
