Обмен данными с казначейскими системами и учреждениями банка

Форма Обмен данными с казначейскими системами и учреждениями банка предназначена для экспорта и импорта платежных файлов.

Для вызова формы Обмен данными с казначейскими системами и учреждениями банка можно использовать команду Задания обмена (банк, казначейство) меню функций раздела Денежные средства.

На закладке Экспорт формы находится список документов вида Задание на экспорт. Документ данного вида используется для выгрузки расчетно-платежных документов в платежный файл с последующей его отправкой адресату.

Загрузка документов из входящих платежных файлов выполняется с помощью документов Задания на импорт, список которых расположен на закладке формы Импорт.
