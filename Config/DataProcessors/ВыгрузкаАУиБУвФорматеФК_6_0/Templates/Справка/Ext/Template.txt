&lt;p&gt;&lt;span style='font-size: 16pt; font-weight: bold;'&gt;Выгрузка в формате ФК. Версия формата:&amp;quot;19.0&amp;quot;&lt;/span&gt;&lt;/p&gt;
&lt;p&gt;
&lt;p&gt;&lt;span style='font-size: 16pt;'&gt;Доступные способы отправки:&lt;/span&gt;&lt;/p&gt;

&lt;/ol&gt;
&lt;p&gt; &lt;/p&gt;
&lt;p&gt;&lt;span style='font-size: 16pt;'&gt;Настройки формата обмена:&lt;/span&gt;&lt;/p&gt;
&lt;ol&gt;
&lt;li&gt;&lt;span style=' font-weight: bold;'&gt;Архивировать отчеты &lt;/span&gt;&lt;br&gt;
При необходимости каждый файл может быть сохранен в отдельный архив формата ZIP, для архивирования отчетов следует установить значение «Да» &lt;br&gt;&lt;/li&gt;

&lt;li&gt;&lt;span style=' font-weight: bold;'&gt;Вид источника отчетности&lt;/span&gt;&lt;br&gt;
Может принимать одно из значений: «3» - для ГАБС, ГВБФ; «4», «5» - для ФО.&lt;br&gt;&lt;/li&gt;

&lt;li&gt;&lt;span style=' font-weight: bold;'&gt;Тип субъекта &lt;/span&gt;&lt;br&gt;
Используется при формировании имени файла, параметра файла «ИСТ» (и кода субъекта при выгрузке в ПУиО ГИИС ЭБ): &lt;br&gt;
«03» - Формирование ГРБС/ГАДБ/ГАИФ сводной отчетности; &lt;br&gt;
«04» - Формирование отчетности АУ/БУ; &lt;br&gt;
«05» - Формирование уполномоченной организацией сводной отчетности АУ/БУ, сводной отчетности АУ/БУ по филиалам; &lt;br&gt;
«07» - Формирование ГВБФ отчетности; &lt;br&gt;
«09» - Формирование ФО консолидированной отчетности субъектов РФ, МО; &lt;br&gt;
В имени архивного файла устанавливается код: &lt;br&gt;
«G» – файл сформирован ГАБС (типы «03,04,05»); &lt;br&gt;
«F» – файл сформирован ФО (тип «09»); &lt;br&gt;
«S» – файл сформирован ГВБФ (тип «07»).&lt;br&gt;&lt;/li&gt;

&lt;li&gt;&lt;span style=' font-weight: bold;'&gt;Код субъекта в ПУиО ГИИС ЭБ&lt;/span&gt;&lt;br&gt;
Если при выгрузке в поле файла «ИСТ» («РОД» при реорганизации) вместо главы по БК требуется указать 21-значный код субъекта отчетности ПУиО ЭБ, соответствующий значению реквизита «Код субъекта отчетности» записи по субъекту отчетности системы ПУиО ГИИС ЭБ,
состоящий из кода главы, типа субъекта, кода по Сводному реестру, ОКТМО бюджета финансирования. &lt;br&gt;
При выгрузке отчетов с указанием кода главы, а также для сводной отчетности ГРБС заполнять настройку не следует.&lt;br&gt;&lt;/li&gt;

&lt;li&gt;&lt;span style=' font-weight: bold;'&gt;Реорганизация. Вид отчетности &lt;/span&gt;&lt;br&gt;
Определяет, является ли отчетность реорганизационной: &lt;br&gt;
- Не реорганизационная; &lt;br&gt;
«1» - Передаточная (разделительная); &lt;br&gt;
«2» - Ликвидационная; &lt;br&gt;&lt;/li&gt;

&lt;li&gt;&lt;span style=' font-weight: bold;'&gt;Реорганизация. Правопреемник &lt;/span&gt;&lt;br&gt;
Определяет, является ли отчетность реорганизационной: &lt;br&gt;
«0» - Правопреемника нет; &lt;br&gt;
«1» - Правопреемник - другой ГРБС &lt;br&gt;
если правопреемником является другой ГРБС, заполняется реквизит файла выгрузки «ИСТ» &lt;br&gt;
«2» - Правопреемник - другой бюджет; &lt;br&gt;
если правопреемником является другой бюджет, заполняется реквизит файла ОКТМОР. &lt;br&gt;&lt;/li&gt;

&lt;li&gt;&lt;span style=' font-weight: bold;'&gt;Реорганизация. Код правопреемника &lt;/span&gt;&lt;br&gt;
Используется в реорганизационной отчетности. Может принимать следующие значения, в зависимости от значения реквизита Реорганизация. Правопреемник: &lt;br&gt;
для (1) Правопреемника - другого ГРБС  может быть указан: &lt;br&gt;
 - код главы министерства ведомства, которому перешли функции реорганизуемого; &lt;br&gt;
 - или 21-значный код субъекта отчетности ПУиО ЭБ, соответствующий значению реквизита «Код субъекта отчетности» записи по субъекту отчетности. &lt;br&gt;
для (2) Правопреемника - другого бюджета указывается код по Общероссийскому классификатору территорий муниципального образования, к которому перешли функции реорганизуемого.&lt;br&gt;&lt;/li&gt;

&lt;/ol&gt;
