Управление фискальным устройством

Форма "Управление фискальным устройством"

Форму Управление фискальным устройством можно открыть с помощью команды Управление фискальным устройством меню функций раздела Денежные средства.

Форма Управление фискальным устройством содержит кнопки:

  • Открыть кассовую смену – команда фискальному регистратору для открытия кассовой смены.
  • Закрыть кассовую смену – команда фискальному регистратору для закрытия кассовой смены и распечатки отчета о состоянии счетчиков ККТ с гашением на устройстве.


Группа Отчеты содержит кнопки:

  • Отчет о текущем состоянии расчетов – команда для формирования отчета, в котором отражена дата первого не переданного фискального документа и общее количество не переданных фискальных документов. Такой отчет может быть сформирован, как для самопроверки, так и по требованию налогового инспектора.
  • Отчет без гашения – команда фискальному регистратору для формирования отчетного документа по содержимому сменных денежных и операционных счетчиков ККМ без обнуления счетчиков ККМ и без записи в фискальную память ККМ ежесменной итоговой информации.


Группа Дополнительные режимы:

Закрытие кассовой смены без Z-отчета – флажок, предназначенный для закрытия смены в программе, когда она уже закрыта в оборудовании.

Группа Внесение /выемка денежных средств

Режим ввода: Документ/Сумма – переключатель режима ввода внесенных и изъятых из фискального устройсва денежных средств.

Кнопки Внесение денежных средств и Выемка денежных средств, предназначены для изменения значений внутреннего счетчика наличных денежных средств в подключенном оборудовании ККТ с передачей данных.

Нажатие на кнопку Внесение денежных средств в режиме ввода Документ открывает форму списка документов Расходные кассовые ордера.

Нажатие на кнопку Выемка денежных средств в режиме ввода Документ открывает форму списка документов Отчеты по кассовым сменам.
