Технологический анализ

Технологический анализ представляет собой инструмент для автоматического контроля текущего состояния учета и корректности данных.

Внимание!
Технологический анализ является внутренним средством контроля ведения учета в программе. Проверки технологического анализа разработаны согласно применяемой в программе методике ведения учета и используемой структуры данных. Результаты технологического анализа не могут являться основанием для выявления нарушений норм законодательства Российской Федерации, равно как и являться доказательством их отсутствия.


Обработка Технологический анализ раздела Учет и отчетность позволяет:

  • получить информацию о последних результатах выполнения проверок состояния учета
  • получить подробную расшифровку по каждой выявленной проблеме
  • распечатать результаты технологического анализа или сохранить в файл
  • вручную запустить проверки технологического анализа
  • получить информацию о дате и времени выполнения проверок
  • посмотреть описание проверок

Настройка параметров формы

В шапке отчета имеется возможность настроить отбор по реквизитам Организация и Важность. При этом список текущих проблем будет отфильтрован с учетом настроенного отбора.

  • Организация – выбирается из справочника Организации.
  • Важность – можно выбрать одно или комбинацию из значений: Информация, Предупреждение, Ошибка.


В левой части формы расположен список всех проверок технологического анализа, сгруппированный по группам проверок. Если по проверке были выявлены ошибки, то имя проверки в списке будет выделено жирным шрифтом, и в скобках будет указано количество найденных ошибок.

При отметке одной или нескольких проверок в списке проблем будут показаны только проблемы по отмеченным проверкам

При выделении одной из проверок под списком проверок будет выведена информация о последней дате проведения этой проверки и описание предмета проверки.

В правой части формы расположен перечень обнаруженных проблем, сгруппированный по проверкам и группам проверок. Для проверок, выполняющихся за определенный период, справа от имени проверки указан период, за который она была выполнена в последний раз.

Результаты технологического анализа могут быть распечатаны по кнопке Печать, при этом печать будет осуществлена с учетом отборов в форме технологического анализа.

Расшифровка результатов анализа

Для расшифровки проблемы следует нажать на текст проблемы двойным щелчком мыши или клавишу Enter. При наличии нескольких вариантов расшифровки будет вызвано выпадающее меню со списком вариантов.

Для каждой выявленной проблемы предусмотрена индивидуальная расшифровка:

  • переход к объекту (списку объектов) (справочник, документ, счет ЕПСБУ), содержащему ошибку
  • формирование стандартного отчета с предустановленными отборами
  • переход к таблице с расшифровкой сравниваемых показателей
  • открытие набора записей регистра сведений

Ручной запуск выполения проверок

Для интерактивного запуска выполнения проверок необходимо выполнить команду Еще - Выполнить проверку. Перед запуском проверок будет предложено выбрать период, за который необходимо выполнить проверку. 

Примечание. Рекомендуется выполнять проверки за период с начала года, так как многие проверки имеют смысл только при таком периоде.

При ручном запуске будут выполнены только проверки, отмеченные в списке проверок в левой части формы.
