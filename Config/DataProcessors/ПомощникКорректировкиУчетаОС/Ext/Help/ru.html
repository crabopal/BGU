Помощник корректировки учета ОС, НМА, НПА


Помощник предназначен для выявления некорректных данных учета ОС, НМА, НПА и предложения вариантов их исправления.

Помощник необходимо выполнять:
    - после переноса данных из БГУ1 или других программ;
    - при изменении структуры данных и наличии в описании изменений версии рекомендаций проверить корректность данных.

Помощник рекомендуется выполнять:
    - в конце года перед формированием отчетности;
    - перед сверткой информационной базы.

В помощнике предусмотрены проверки:
    - Ссылочная целостность
    - Устаревшие документы (Ввод остатков)
    - Устаревшие документы (Приказ 173н)
    - Ввод остатков (101,102,103,108,21,25,26)
    - Ввод остатков (01, 02, 22)
    - Инвентарные номера
    - События
    - Периоды регистров сведений
    - Остатки по счетам ЕПСБУ
    - Регистры учета НФА
    - Налоговая база налога на имущество
    - Учетные данные
    - Необходимость Открыть карточки
    - Необходимость Закрыть карточки
    - Номера инвентарных объектов
    - Код по ОКОФ
    - Тип НФА
