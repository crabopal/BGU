Помощник "Перенос правообладаний и обременений"


Помощник предназначен для упрощения переноса сведений о правообладаниях и обременениях из устаревшей табличной части "Правообладание (обременение)" справочника "Основные средства, НМА, НПА" в табличную часть "Правообладания" этого же справочника для правообладаний, и в табличную часть "Обременения" справочника "Инвентарные номера ОС" для обременений, для формирования инвентарных карточек объектов НФА по Приказу Минфина России от 15.04.2021 № 61н в ред. от 07.11.2022 № 157н.

По кнопке "Заполнить" в список ОС попадают объекты НФА, у которых есть данные в табличной части "Правообладание (обременение)".

Необходимо распределить все данные с закладки "Правообладание (обременение)" на закладки "Правообладания" и "Обременения" с помощью кнопок "Правообладание (Ctrl + 1)" и "Обременение (Ctrl + 2)". Запись также можно удалить по кнопке "Удалить".
Можно распределить строки автоматически по кнопке "Распределить все ... ". В этом случае по кнопке открывается форма, которая содержит список всех видов прав и обременений, указанных в ОС. Для каждого вида можно указать, в какую таблицу переносить строку с этим видом – "Правообладание" или "Обременение". Если оставить флажок "Вручную", то строки с этим видом автоматически перенесены не будут.

Таблица "Правообладание" содержит те же колонки, что и таблица "Правообладание (обременение)", поэтому дозаполнения не требует.

На закладке "Обременения" колонок больше, поэтому после переноса строк на закладку "Обременения" данные строк необходимо дозаполнить, кроме того указать, в какие инвентарные номера эти данные будут записаны.

По кнопке "Перенести" выполняется перенос данных. Переносятся данные только тех ОС, у которых установлен флажок. Если при установленном флажке строка отмечена красным цветом, значит, по ОС есть ошибки, данные по нему перенесены не будут. Ошибкой считается:
- если не все данные распределены, т. е. закладка "Правообладание (обременение)" не пустая;
- если на закладке "Обременения" есть строки, но у ОС нет инвентарных номеров. 
Такие данные переносить некуда, поэтому необходимо очистить закладку "Обременения".
