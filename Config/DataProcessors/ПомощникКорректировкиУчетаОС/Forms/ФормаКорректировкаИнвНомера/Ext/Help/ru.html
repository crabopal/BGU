Корректировка инвентарного номера в регистрах

В рамках одного объекта основных средств, НМА, НПА в регистрах учета одновременно не должно быть записей с заполненным и незаполненным инвентарным номером. Так же не должно быть инвентарных номеров, принадлежащих другим объектам НФА.
По кнопке Заполнить выполняется поиск основных средств, НМА, НПА, у которых заполненность инвентарных номеров в регистрах учета различается, либо присутствуют чужие инвентарные номера.

Если для объектов с индивидуальным учетом есть инвентарный номер, то он автоматически подставляется в колонку Инвентарный номер табличной части и устанавливается флажок.

Расшифровка с данными регистров показывается по объекту ОС, НМА, НПА выделенной строки таблицы. Если установлен флажок Показывать расшифровку в этом окне, то расшифровка показывается под таблицей объектов, иначе открывается в отдельном окне.

В расшифровке по клику на имени записи регистра можно открыть форму списка регистра, при клике по записи в этой форме можно попасть в документ регистратор. Это удобно для редактирования документа.

По кнопке Корректировать выполняется подстановка инвентарного номера (в том числе пустого), указанного в колонке Инвентарный номер, для строк, в которых установлен флажок.

Если при изменении инвентарного номера в записи получается запись, которая по составу измерений уже есть в наборе записей, то в случае, когда флажок Удалить дублирующие записи установлен, редактируемая запись будет удалена, а в противном случае набор записей не будет записан, об этом будет выдано сообщение.


Редактируются только данные в регистрах, документы не редактируются.
