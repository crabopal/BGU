Выгрузка данных в "Бюджет муниципального образования, ред. 1.3"

Обработка предназначена для выгрузки данных о бухгалтерских операциях за период из базы данных БГУ 2.0 в базу данных БМО 1.3 финансового органа, организующего исполнение бюджета.

При нажатии на кнопку Отправить обработка выполняет подключение к WEB-сервису финансового органа.

Настройки подключения к WEB-сервису указываются в реквизитах: Адрес сервиса, Пользователь и Пароль.

Внимание!
Настройки подключения (Адрес, Пользователь, Пароль) к WEB-сервису должны быть получены от фининсового органа, организующего исполнение бюджета.

При подключении к WEB-сервису финансового органа проверяется наличие выбранного на форме учреждения в базе данных конфигурации "Бюджет муниципального образования, редакция 1.3".

Далее, через WEB-сервис получаются настройки, заданные финансовым органом, и по этим настройкам выбираются данные о бухгалтерских операциях за период (задается на форме).

Эти данные передаются на WEB-сервер финансового органа.

Сервер возвращает протокол обработки данных, который отображается на форме.

Также возможно сохранение данных в xml-файл. Для этого нужно нажать на кнопку Сохранить данные в файл. В этом случае выбираются данные о бухгалтерских операциях за период (задается на форме) и сохраняются в выбранный файл. Подключение к WEB-сервису финансового органа при сохранении в файл не выполняется. Файл передается сотрудникам финансового органа любым доступным способом.
