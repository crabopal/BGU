Заполнение данных о существующих регистрациях плательщиков

Таблица Регистрации (в левой части формы) содержит список учащихся, договоров и соответствующих им документов регистрации плательщиков.
Таблица Данные плательщиков (в правой части формы) по реквизитному составу соответствует табличной части документов Регистрация плательщиков по договору (образование) и позволяет задать для каждой строки данные регистрации плательщиков.

Заполнение таблиц выполняется по данным введенных документов Приказы (образование), с помощью команды Заполнение - Заполнить по приказам.
Отбор документов Приказ (образование) выполняется по организации, указанной в поле Организация.
После выбора документов в таблице Регистрации заполняются колонки Учащиеся и Договоры. Колонка Регистрация плательщиков заполняется по данным регистра Плательщики по договору (образование) - по состоянию на дату, указанную в поле На дату.
При выделении строки в таблице Регистрации, в таблице Данные плательщиков отображаются зарегистрированные плательщики. Таблица Данные плательщиков может быть пустой, если регистрация плательщиков не выполнялась.

Установка новых данных плательщиков

Новые данные плательщиков в таблице Данные плательщиков могут быть заданы как вручную для каждой строки таблицы Регистрации, так и с помощью команд установки значений:

  • Изменить заданный порядок выписки сч.фактур – устанавливает для всех существующих плательщиков выбранный порядок выписки счетов-фактур (На плательщика или Сводно). Новые строки таблицы Данные плательщиков не создаются. Значения устанавливаются только по существующим строкам плательщиков.
  • Контрагент по учащемуся (100% оплаты, СФ сводно) – очищает все существующие данные в таблице Данные плательщиков и по каждой строке таблицы Регистрации добавляет новые данные плательщиков – Контрагент учащегося, 100% оплаты, порядок выписки счета-фактуры Сводно.
  • Контрагент по учащемуся (100% оплаты, СФ на плательщика) – очищает все существующие данные в таблице Данные плательщиков и по каждой строке таблицы Регистрации добавляет новые данные плательщиков – Контрагент учащегося, 100% оплаты, порядок выписки счета-фактуры На плательщика.
  • Единый контрагент для всех учащихся (100% оплаты, СФ на плательщика) – предлагает выбрать контрагента, который будет установлен в качестве плательщика. После этого очищает все существующие данные в таблице Данные плательщиков и по каждой строке таблицы Регистрации добавляет новые данные плательщиков – выбранный контрагент, 100% оплаты, порядок выписки счета-фактуры На плательщика.

Формирование документов регистрации плательщиков

После заполнения новых данных плательщиков выполняется формирование документов регистрации.
Может быть выбран один из двух способов формирования документов:

  • Изменять существующие – вносить изменения в существующие документы Регистрация плательщиков (образование). Если при этом последние изменения были внесены документами ввода остатков, корректировкой регистров, или раннее документов по строке не было, для строки создается новый документ Регистрация плательщиков (образование).
  • Создавать новые – всегда создавать новые документы Регистрация плательщиков (образование).

Формирование документов выполняется только по отмеченным строкам таблицы Регистрации.
Новые документы Регистрация плательщиков (образование) вводятся датой, указанной в поле На дату.
