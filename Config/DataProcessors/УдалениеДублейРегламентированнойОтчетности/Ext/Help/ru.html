Обработка "Удаление дублей регламентированной отчетности"

Обработка позволяет удалить дублирующиеся элементы подсистемы бухгалтерской регламентированной отчетности.

Дубли могут возникать при обмене данными с помощью универсальных средств обмена, либо при некорректном сопоставлении элементов при загрузке комплектов отчетности.

Обработка выполняет следующие виды операций с дублирующимися элементами:

  • поиск, объединение и удаление дублей элементов регламентированной отчетности;
  • поиск групп раскрытия с дублирующимися аналитиками с последующей очисткой;
  • очистка служебных регистров, хранящих временные настройки;

Порядок работы с обработкой

Внимание! Обработка выполняет замену значений в объектах информационной базы универсальным образом. Рекомендуется перед использованием обработки сделать архивную копию информационной базы. После удаления дублей и загрузки комплектов следует убедиться в том, что регламентированные отчеты работают корректно.

Перед выполнением любых действий с помощью обработки необходимо сделать резервную копию.


Команды для исправления ошибок подсистемы регламентированной отчетности расположены в подменю Способы исправления ошибок.

1. Поиск, объединение и удаление дублей элементов регламентированной отчетности:

  • 1.1. Нажать кнопку Найти дубли элементов:
    • Производится поиск дублирующих элементов по кодам элемента, с учетом иерархии.
    • В таблицу заменяемых значений добавляются найденные дублирующиеся элементы (с группировкой по видам справочников/планов видов характеристик).
    • Устанавливаются флажки для всех элементов для проведения объединения. При необходимости можно снять флажки с тех элементов, замена которых не требуется.
    • Для ускорения объединения элементов рекомендуется завершить работу пользователей в базе данных и установить флаг Заблокировать всю работу в программе и ускорить объединение.
  • 1.2. Нажать кнопку "Выполнить объединение":
    • Производится замена дублирующихся элементов во всех местах использования, объединение элементов и удаление элемента-дубля;
    • Если после проведения замены в таблице заменяемых значений остались элементы, нужно нажать кнопку "Выполнить объединение" повторно. Такая ситуация может возникать при наличии перекрестных ссылок (например, при удалении группы и элементов справочника одновременно).

2. Поиск групп раскрытия с дублирующимися аналитиками с последующей очисткой:

  • 2.1. Нажать кнопку Проверить группы раскрытия:
    • Производится поиск одинаковых видов аналитик в каждой группе раскрытия.
    • Если такие группы раскрытия найдены, выводится список проблемных групп.
    •
  • 2.2. Нажать кнопку Очистить ошибочные группы раскрытия:
    • Поскольку нельзя автоматически определить, какую из аналитик группы раскрытия нужно использовать, а какую - удалить, нужно очистить такие группы раскрытия (при загрузке комплекта отчетности аналитика групп автоматически восстанавливается).
    • После очистки групп раскрытия работа с отчетами, у которых группы раскрытия были очищены невозможна до восстановления состава групп раскрытия (с помощью обновления комплекта отчетности).

3. Очистка служебных регистров, хранящих временные настройки:

  • 3.1. Нажать кнопку Очистить сохраненные настройки:
    • Выполняется полная очистка регистра "Хранилище параметрической настройки".
    • Выполняется очистка регистра "Аналитика показателей" с отбором по значениям "Пустая ссылка" для измерения "Экземпляр отчета".

Перейти к обновлению комплекта отчетности:

  • После выполнения описанных действий необходимо обновить комплект отчетности, поскольку при обновлении комплекта отчетности происходит восстановление актуальных параметров.
  • Необходимо обновить все комплекты отчетности, над отчетами которых производились действия. Например, если были удалены дубли видов отчетов "ф. 0503127" и "ф. 0503737", следует обновить комплекты "staterep191" и "staterep33".
  • Если выполнялась только очистка служебных регистров, то обновление комплектов отчетности не требуется, достаточно только пересчета вычисляемых показателей в отчетах с проблемами автоматического расчета показателей.
  • Обновление можно сделать стандартным способом или по кнопке Перейти к обновлению комплекта отчетности.
