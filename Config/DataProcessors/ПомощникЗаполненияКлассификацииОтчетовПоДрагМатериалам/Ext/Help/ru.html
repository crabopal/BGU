Помощник заполнения классификации статистических отчетов по драг. материалам для объектов НФА

Помощник заполнения классификации статистических отчетов по драг. материалам для объектов НФА предназначен для заполнения и проверки корректности классификации объектов НФА по принятым в формах статистической отчетности по драгоценным материалам видам, содержащих драгоценные материалы объектов. 

Вызов "Помощник заполнения классификации статистических отчетов по драг. материалам для объектов НФА"

Для вызова Помощника можно использовать команду Помощник заполнения классификации объектов НФА формы списка регистра сведений Настройки заполнения отчетов статистики по драг. материалам. Форму списка этого регистра сведений можно открыть с помощью команды Настройки заполнения отчетов статистики по драг. материалам из группы команд Учет драгоценных металлов и драгоценных камней в разделах Материальные запасы, Основные средства, НМА, НПА и Имущество казны.  

В начале работы с помощником следует заполнить реквизиты:

  • Отчетный период – установить период, за который требуется заполнить классификацию объектов. В список объетов попадут все обхекты, по которым были остатки или обороты в регистре учета драгоценных материалов за этот период;
  • Список Организации – добавить строки и выбрать значения из справочника Организации;
  • Выбрать объекты:
    • с незаполненной классификацией; - в список объектов НФА будут отобраны значения, у которых не установлена классификация в регистре сведений Настройки заполнения отчетов статистики по драг. материалам отчетов вида, указанного в реквизите для отчета на конец отчетного периода.
    • с заполненной классификацией. - в список объектов НФА будут отобраны значения, у которых установлена классификация в регистре сведений Настройки заполнения отчетов статистики по драг. материалам отчетов вида, указанного в реквизите для отчета на конец отчетного периода. Данный режим предназначен для контроля заполнения классификации отчетов.          
  • Список Коды ОКОФ для отбора объектов НФА - выбрать коды ОКОФ, которые ограничат список объектов НФА. При выборе группы кодов в список объектов НФА будут включены все объекты с кодами входящими в выбранную группу.
  • Список Счета учета для отбора объектов НФА - выбрать счета учета, которые ограничат список объектов НФА. При выборе группы счетов в список объектов НФА будут включены все объекты со счетами учета входящими в выбранную группу.

 

Для заполнения списка объектов НФА следует нажать кнопку Заполнить на командной панели списка объектов НФА.

После заполнения списка объектов НФА следует заполнить обязательные реквизиты в группе Классификации отчета для списка объектов НФА:

  • Дата начала действия – период записей регистра сведений Настройки заполнения отчетов статистики по драг. материалам, которые планируется создать;
  • Отчет - отчет, для которого задается классификация;
  • Тип номенклатуры в отчете - значения из классификации отчета.

 

Для назначения всем объектам НФА из списка следует нажать кнопку Назначить классификацию отчета.
