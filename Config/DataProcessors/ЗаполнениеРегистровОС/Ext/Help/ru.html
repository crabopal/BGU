Обработка предназначена для исправления ошибок в данных регистров ОС, которые есть в базе по причине того, что она свернута, либо из-за переноса некорректных данных из БГУ1.

Заполняет регистры накопления и сведений по данным регистра бухгалтерии:
     - Амортизация, обесценение объектов ОС, НМА, НПА
     - Стоимость объектов ОС, НМА, НПА
     - Стоимость объектов ОС, НМА, НПА (по контрагентам)
     - Учетные данные объекта ОС, НМА, НПА

Заполнение и исправление выполняется по выбранной Организации.

Свести суммы в проводках и регистрах


По кнопке Свести исправляет расхождения сумм регистра бухгалтерии и описанных выше регистров. Данные анализируются по состоянию на даты, указанные в списке На даты. В результате будут созданы документы Корректировка регистров.
В лучшем случае расхождений быть не должно. Если в результате сведения созданы документы, следует проанализировать записи этих документов и причину по которой возникли расхождения.
Рекомендуется выполнить сведение на все даты, предлагаемые по умолчанию.
