Помощник группового изменения учетных параметров детей

Помощник группового изменения учетных параметров детей предназначен для изменения параметров учета у списка детей и позволяет изменить следующие параметры:

  • Группа детского учреждения;
  • Ставка оплаты;
  • Льгота.

Также с помощью Помощника можно оформить как выбытие детей из группы по услуге детского учреждения, так и из учреждения в целом.

Для вызова Помощника группового изменения учетных параметров детей следует использовать команду Помощник изменения параметров в меню Еще формы списка справочника Дети.

Выбор режима работы


При запуске Помощника откроется диалоговое окно, в котором предлагается выбрать один из режимов работы:

  • Изменение параметров по основной образовательной программе;
  • Изменение параметров по дополнительным образовательным программам;
  • Выбытие детей из дошкольного учреждения.

Если режим был выбран ошибочно или произошел случайный отказ от выбора режима работы помощника, то для возврата к выбору режима можно перейти с помощью команды Выбор режима работы в меню Еще формы помощника.

Реквизиты, общие для всех режимов работы


Реквизиты, общие для всех режимов работы, расположены в шапке формы:

  • Организация – организация, по которой будет выполнен отбор детей при заполнении табличной части обработки. Выбирается из справочника Организации.
  • Группа детского учреждения – группа по услуге детского учреждения, по которой будет производиться отбор детей при заполнении табличной части обработки. Выбирается из справочника Группы детского учреждения.

Заполнить табличную часть помощника можно автоматически с помощью кнопки Заполнить на (дату) или с использованием подбора – кнопка Подбор.

Предварительно необходимо установить дату, на которую в ходе заполнения будут отобраны дети и их учетные параметры.

Режимы работы "Изменение параметров по основной образовательной программе" и "Изменение параметров по дополнительным образовательным программам"


Наборы инструментов и реквизитов помощника для этих двух режимов работы идентичны.

В группе реквизитов Новые параметры можно выбрать значения учетных параметров, которые будут присвоены детям в результате работы помощника.

  • Группа детского учреждения – группа по услуге детского учреждения. Выбирается из справочника Группы детского учреждения.
  • Ставка оплаты – ставка оплаты за услуги детского учреждения. Выбирается из справочника Ставки оплаты.
  • Льгота – льгота, на величину которой уменьшается начисление платы за услуги детского учреждения. Выбирается из справочника Льготы.
  • Дата начала действия – в реквизите необходимо указать значение даты, начиная с которой вступают в силу новые учетные параметры детей.
  • Актуальность – флажок, установка которого определяет статус актуальности учетных параметров детей.

Важно
Если флажок Актуальность не установлен, то результатом работы помощника будет являться исключение детей из текущей группы по услуге детского учреждения. Выбывшие дети в дальнейшем не будут принимать участие в расчетах по родительской плате с отбором по той группе детского учреждения, из которой оформлено выбытие.

Далее следует заполнить табличную часть помощника.

Режим работы "Выбытие детей из дошкольного учреждения"


Режим предназначен для оформления выбытия детей из детского учреждения.

Для работы помощника необходимо заполнить реквизит:

Дата выбытия – дата, начиная с которой дети будут считаться выбывшими из детского учреждения и перестанут попадать в любые расчеты по родительской плате.

Далее следует заполнить табличную часть помощника.

Запуск помощника для выполнения изменений


После заполнения табличной части и выбора новых значений параметров можно запустить помощник для выполнение с помощью кнопки Выполнить в шапке формы.

В случае корректного завершения работы помощника на экран будет выведено сообщение об успешной записи новых параметров детей.
