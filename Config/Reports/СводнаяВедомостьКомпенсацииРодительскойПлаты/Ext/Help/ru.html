Отчет "Ведомость по расчету компенсации родительской платы (список)"

Отчет Ведомость по расчету компенсации родительской платы (список) предназначен для оперативного контроля над начислениями компенсаций.

Открыть форму отчета можно с помощью гиперссылки Ведомость по расчету компенсации родительской платы (список) в форме Отчеты раздела "Платное обучение", для вызова которой можно использовать команду Отчеты по платным образовательным услугам меню функций раздела Платное обучение.

Настройка отчета

Для выбора варианта формирования отчета можно использовать кнопку Варианты отчета командной панели формы.

Предусмотрены следующие варианты формирования отчета:

  • Ведомость по расчету компенсации родительской платы (список).
  • Ведомость по расчету компенсации родительской платы по КФО и КПС (список).

В отчете предусмотрен отбор по периоду, детскому учреждению, группе детского учреждения, ребенку, проценту компенсации, исполнителю и КФО.

Для доступа к расширенным вариантам отбора и группировки следует нажать кнопку командной панели Настройки.

Формирование отчета

Для формирования отчета можно нажать на кнопку Сформировать.

Сформированный отчет открывается в виде табличного документа, который затем может быть выведен на печать.
