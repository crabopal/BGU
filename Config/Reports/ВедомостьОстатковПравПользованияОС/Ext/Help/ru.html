Отчет "Ведомость остатков прав пользования ОС, НПА"

В отчете Ведомость остатков прав пользования ОС, НПА для каждого объекта прав пользования приводятся сведения о договоре, по которому данных объект был получен, дате начала и окончания начисления амортизации, оставшемся и фактическом сроках полезного использования, балансовой стоимости и начисленной амортизации, а также остаточной стоимости.

Для вызова отчета можно использовать гиперссылку Ведомость остатков прав пользования ОС, НПА формы Отчеты раздела "Основные средства, НМА, НПА".

Настройка отчета

В шапке отчета можно настроить отбор по следующим реквизитам:

  • Дата отчета – дата, на которую будет сформирован отчет;
  • Счет (в группе) – счет учета объектов права пользования. Выбирается из фрагмента плана счетов ЕПСБУ, ограниченного субсчетами счета 111.40;
  • Организация – учреждение, для которого необходимо сформировать отчет. Выбирается из справочника Организации;
  • Контрагент – арендодатель, по которому необходимо сформировать отчет. Выбирается из справочника Контрагенты.
  • Договор – договор с арендодателем, по которому будет сформирован отчет. Выбирается из справочника Договоры и иные основания возникновения обязательств.
  • Объект права пользования – наименование объекта права пользования. Выбирается из справочника Основные средства, НМА, НПА.

Примечание. При необходимости выполнить расширенную настройку следует использовать кнопку Вид: Расширенный формы Настройки отчета "Ведомость остатков прав пользования ОС, НПА", которая вызывается с помощью кнопки Настройки командной панели формы отчета.

Заполнение отчета

Колонки со сроком пользования заполняются:

  • Срок пользования (полный) – количество месяцев между датой начала и датой окончания амортизации;
  • Срок пользования (оставшийся) – количество месяцев между датой отчета и датой окончания амортизации;
  • Срок пользования (фактический) – количество месяцев между датой начала амортизации и датой отчета.
