Отчет "Расчет среднегодовой стоимости имущества"

Отчет предназначен для расчета среднегодовой стоимости имущества (основных средств), которые числятся на балансе учреждения.

Для вызова данного отчета можно использовать гиперссылку Расчет среднегодовой стоимости имущества формы Отчеты раздела "Основные средства, НМА, НПА".

Настройка отчета

В шапке отчета можно настроить отбор по следующим реквизитам:

  • Расчет на дату – дата на которую будет выполнен расчет;
  • Организация – учреждение, для которого необходимо сформировать отчет. Выбирается из справочника Организации;
  • КПС – классификационный признак счета. Выбирается из списка КПС;
  • КФО – код финансового обеспечения. Выбирается из списка КФО.

Примечание. При необходимости выполнить расширенную настройку следует использовать кнопку Вид: Расширенный формы Настройки отчета «Расчет среднегодовой стоимости имущества», которая вызывается с помощью кнопки Настройки командной панели формы отчета.
