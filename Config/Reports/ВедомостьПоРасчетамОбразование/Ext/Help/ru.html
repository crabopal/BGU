Отчет "Ведомость по расчетам (образование)"

Отчет Ведомость по расчетам (образование) предназначен для получения информации по расчетам с учащимися – о выполненных начислениях и полученной оплате.

Внимание! Данные об оплате за образовательные услуги попадут в отчет только после распределения полученной оплаты по учащимся, выполненного с помощью документа Распределение оплаты (образование).

Открытие формы отчета

Открыть форму отчета можно с помощью гиперссылки Ведомость по расчетам за образование в форме Отчеты раздела «Платное обучение», для вызова которой можно использовать команду Отчеты по платным образовательным услугам меню функций раздела Платное обучение.

Выбор варианта отчета

В программе предусмотрены два варианта ведомости – Сводная и Подробная.

Меню для выбора варианта отчета вызывается с помощью кнопки Варианты отчета.

Быстрая настройка отчета

Быстрая настройка отчета позволяет задать Период, настроить отбор данных по Учащемуся и Плательщику. Быстрая настройка для варианта отчета Подробный содержит дополнительный реквизит Выводить первичные документы.

Ведомость по расчетам образования (сводная)

Сводный отчет представляет собой список учащихся с данными о начислениях, полученной оплате, а также о суммах начального и конечного остатка.

Ведомость по расчетам образования (подробная)

В подробном отчете в список учащихся с данными о начислениях и оплате выводится также информация о договорах на получение образовательных услуг, а также о валюте взаиморасчетов по каждому договору. После установки флага Выводить первичные документы в Быстрых настройках отчета и нажатия на кнопку Сформировать в Ведомости будет также представлена информация о первичных документах.

Примечание. Если установлен флаг Учет расчетов и обязательств ведется в иностранных валютах в разделе Общие настройки формы Настройка параметров учета, то отчет формируется и в валюте взаиморасчетов (ставки оплаты) и в валюте регламентированного учета.
