Отчет "Остатки и обороты товаров в торговых точках"

Отчет Остатки и обороты товаров в торговых точках предназначен для формирования сведений об остатках и оборотах количества товаров из справочника Номенклатура за период по каждому месту хранения (торговой точке) из справочника Центры материальной ответственности.

Сведения для отчета могут быть получены только для тех центров материальной ответственности, что указаны в качестве места хранения для Кассы ККМ и для которых настроен и ведется контроль остатков товаров в торговых точках.

Для вызова отчета можно использовать команду Остатки и обороты товаров в торговых точках, которую можно вызвать с помощью команды Отчеты по денежным средствам меню функций раздела Денежные средства или подменю Отчеты в форме журнала Чеки ККМ группы Розничные продажи раздела Денежные средства.

Настройка отчета

Период – период, за который будет сформирован отчет;
Организация – учреждение, для которого необходимо сформировать отчет. Выбирается из справочника Организации;
МОЛ/Место хранения – материально-ответственное лицо. Выбирается из справочника Центры материальной ответственности.
Макет оформления – выбранный параметр влияет на внешний вид отчета.

Примечание. При необходимости выполнить расширенную настройку следует использовать кнопку Вид: Расширенный формы Настройки отчета "Остатки и обороты товаров в торговых точках", которая вызывается с помощью кнопки Настройки командной панели формы отчета.

Для формирования отчета следует нажать на кнопку Сформировать.

Расшифровка отчета

Для того, чтобы увидеть каким документом было выполнено движение, повлиявшие на остатки или обороты товаров в розничных торговых точках можно сформировать расшифровку отчета.
Чтобы получить отчет – расшифровку по документу-регистратору, необходимо выполнить следующую последовательность действий:

  • Выбрать ячейку отчета;
  • нажать правую кнопку мыши и выбрать команду Расшифровать... в открывшемся контекстном меню;
  • в открывшемся окне выбрать поле Регистратор и нажать кнопку Выбрать.
