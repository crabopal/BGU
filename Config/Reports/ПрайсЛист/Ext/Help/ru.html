Отчет "Прайс-лист"

Отчет Прайс-лист предназначен для формирования актуального перечня товаров, услуг, работ из справочника Прейскурант с текущими ценами на дату отчета по группам товаров.

Для вызова отчета можно использовать команду Прайс-лист, которую можно вызвать с помощью команды Отчеты по денежным средствам меню функций раздела Денежные средства или подменю Отчеты в форме журнала Чеки ККМ группы Розничные продажи раздела Денежные средства.

Настройка отчета

Организация – учреждение, для которого необходимо сформировать отчет. Выбирается из справочника Организации;
Дата отчета – дата, на которую будет сформирован отчет;
Подразделение – подразделение, по которому необходимо сформировать отчет. Выбирается из справочника Подразделения;
Тип цены – тип цены, по которой необходимо сформировать отчет. Выбирается из справочника Типы цен номенклатуры;
Макет оформления – выбранный параметр влияет на внешний вид отчета.

Примечание. При необходимости выполнить расширенную настройку следует использовать кнопку Вид: Расширенный формы Настройки отчета "Прайс-лист", которая вызывается с помощью кнопки Настройки командной панели формы отчета.

Для формирования отчета следует нажать на кнопку Сформировать.
