Сводные данные об исполнении бюджета ГРБС, РБС

Отчет Сводные данные об исполнении бюджета ГРБС, РБС является управленческим и формируется по данным регистров бухгалтерского учета.

Отчет предназначен для получения информации о полученных и переданных бюджетных данных и остатках нераспределенных бюджетных данных – ассигнований, ЛБО и ПОФ.

Для вызова отчета можно использовать гиперссылку Сводные данные об исполнении бюджета ГРБС, РБС формы Отчеты раздела Планирование и санкционирование, которая открывается с помощью команды Отчеты по планированию и санкционированию меню функций раздела Планирование и санкционирование.

Примечание. Также в программе предусмотрено формирование вариантов отчета Переданные бюджетные данные (по КБК) и Переданные бюджетные данные (по организациям). Для вызова данных вариантов отчета можно использовать одноименные команды в форме Отчеты раздела «Планирование и санкционирование» раздела Планирование и санкционирование.

Настройка отчета
  • Период – период, за который будет сформирован отчет;
  • Плановый период – переключатель, который может принимать значения Текущий год, Очередной год или Второй год, следующий за текущим;
  • ГРБС, РБС или финансовый орган, от которого поступает финансирование – выбирается из справочника Контрагенты;
  • Организация – выбирается из справочника Организации;
  • Лицевой счет – выбирается из справочника Лицевые счета после выбора значения для реквизита Организация.

Важно!
В процессе формирования отчета выполняется запрос к бухгалтерским итогам. При этом отбираются только данные по КФО = 1 (бюджет).

Детальную настройку и отбор можно задать на панели настройки, которая открывается при нажатии кнопки Настройки командной панели формы отчета.

Для формирования отчета следует нажать на кнопку Сформировать командной панели формы.
