Отчет "Поступление продуктов питания по поставщикам"

Отчет предназначен для получения информации о поступлении продуктов питания в разрезе поставщиков.

По каждому поставщику отчет формирует отдельную карточку.

Открыть форму отчета можно с помощью гиперссылки Поступление продуктов по поставщикам в форме Отчеты раздела «Услуги, работы, производство», для вызова которой можно использовать команду Отчеты по работам, услугам, производству меню функций раздела Услуги, работы, производство.

Настройка отчета

В форме отчета необходимо заполнить реквизиты:

  • Организация – наименование организации, по данным которой необходимо сформировать отчет. Выбирается из справочника Организации;
  • Период отчета – интервал дат, в котором операции расхода должны отображаться в отчете.

Для продолжения настройки параметров отчета следует с помощью кнопки Настройки командной панели формы отчета открыть форму настроек.
