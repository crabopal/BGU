Отчет "Анализ начислений родительской платы"

Отчет позволяет проанализировать начисления родительской платы в разрезе детей, типов начислений, договоров, ставок и т.д.

Открыть форму отчета можно с помощью гиперссылки Анализ начислений родительской платы в форме Отчеты раздела «Платное обучение», для вызова которой можно использовать команду Отчеты по платным образовательным услугам меню функций раздела Платное обучение.

Настройка отчета

В шапке формы отчета предусмотрены следующие настройки.

Период – период, за который будет сформирован отчет.

Возможна настройка отбора по следующим реквизитам:

  • Исполнитель (подпись) – выбирается из справочника Сотрудники;
  • Организация – выбирается из справочника Организации;
  • Группа ДДУ – выбирается из справочника Группы детского учреждения;
  • Ребенок – выбирается из справочника Дети;
  • Контрагент – плательщик за услуги детского учреждения. Выбирается из справочника Контрагенты;
  • Договор – договор на оказание образовательных услуг. Выбирается из справочника Договоры и иные основания возникновения обязательств;
  • Ставка оплаты – выбирается из справочника Ставки оплаты;
  • Льгота – выбирается из справочника Льготы учащихся и воспитанников;
  • Документ – документ вида Начисление платы за услуги дошкольного учреждения или вида Расчет платы за услуги дошкольного учреждения.

Для доступа к расширенным вариантам отбора и группировки следует нажать кнопку командной панели Настройки.

Для формирования отчета можно нажать кнопку Сформировать.

Сформированный отчет открывается в виде табличного документа, который затем может быть выведен на печать.
