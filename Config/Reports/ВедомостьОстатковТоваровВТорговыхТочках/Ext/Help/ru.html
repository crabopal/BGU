Отчет "Остатки товаров в торговых точках"

Отчет Остатки товаров в торговых точках предназначен для формирования сведений об остатках количества товаров из справочника Номенклатура на дату по каждому месту хранения (торговой точке) из справочника Центры материальной ответственности.

Сведения для отчета могут быть получены только для тех центров материальной ответственности, что указаны в качестве места хранения для Кассы ККМ и для которых настроен и ведется контроль остатков товаров в торговых точках.

Для вызова отчета можно использовать команду Остатки товаров в торговых точках, которую можно вызвать с помощью команды Отчеты по денежным средствам меню функций раздела Денежные средства или подменю Отчеты в форме журнала Чеки ККМ группы Розничные продажи раздела Денежные средства.

Настройка отчета

Организация – учреждение, для которого необходимо сформировать отчет. Выбирается из справочника Организации;
Дата отчета – дата, на которую будет сформирован отчет;
МОЛ/Место хранения – материально-ответственное лицо. Выбирается из справочника Центры материальной ответственности;
Выделять отрицательные – при включении флага отрицательные значение остатков товаров будут выделяться красным шрифтом;
Макет оформления – выбранный параметр влияет на внешний вид отчета.

Примечание. При необходимости выполнить расширенную настройку следует использовать кнопку Вид: Расширенный формы Настройки отчета "Остатки товаров в торговых точках", которая вызывается с помощью кнопки Настройки командной панели формы отчета.

Для формирования отчета следует нажать на кнопку Сформировать.
