Отчет "Карточка работы"

Отчет Карточка работы предназначен для получения информации о финансовом результате выполнения работы, а также о структуре расходов, произведенных при ее выполнении.

По каждому этапу работ в отчете отражается финансовый результат от реализации работы по счету 401.10, доходы по счету 401.40 и расходы по счету 109.60.

Открыть форму отчета можно с помощью
гиперссылки Карточка работы в форме Отчеты раздела «Услуги, работы, производство», для вызова которой можно использовать команду Отчеты по работам, услугам, производству меню функций раздела Услуги, работы, производство.

Настройка отчета

В форме отчета необходимо заполнить реквизиты:

  • Организация – наименование организации;
  • Период – интервал дат, за который должны отображаться операции;
  • Исполнитель – исполнитель работ, выбирается из справочника Сотрудники;
  • Этап – этап работ. Выбирается из справочника Этапы сдачи работ.

Для продолжения настройки параметров отчета следует с помощью кнопки Настройки командной панели формы отчета открыть форму настроек.
