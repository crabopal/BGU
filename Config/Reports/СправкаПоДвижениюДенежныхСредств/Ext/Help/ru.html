Отчет "Справка по операциям с денежными средствами"

Отчет Справка по операциям с денежными средствами предназначен для получения информации о движении по лицевому счету, открытому в органе казначейства или в кредитной организации.

В отчете представлена информация за выбранный период о движении денежных средств на счетах 201.00 в разрезе КПС и КЭК операции, а также дополнительной аналитики, установленной на счетах, отражающих исполнение плана ФХД.

Для вызова отчета можно использовать команду Справка по движению наличных денежных средств формы Отчеты раздела "Денежные средства", которую можно открыть с помощью команды Отчеты по денежным средствам меню функций раздела Денежные средства.

Отчет "Контроль оборотов балансовых и забалансовых счетов"

Вариант отчета Контроль оборотов балансовых и забалансовых счетов позволяет проконтролировать обороты балансовых счетов группы 201.00 и забалансовых счетов 17 и 18.

В случае появления отклонения в оборотах в отчете будет представлена информация о документах, явившихся причиной данного отклонения.

Для вызова варианта отчета Контроль оборотов балансовых и забалансовых счетов можно нажать на кнопку Варианты отчета командной панели отчета Справка по операциям с денежными средствами и использовать команду Контроль оборотов балансовых и забалансовых счетов в выпадающем меню.

Также для вызова варианта отчета можно использовать команду Контроль оборотов балансовых и забалансовых счетов формы Отчеты раздела "Денежные средства", которую можно открыть с помощью команды Отчеты по денежным средствам меню функций раздела Денежные средства.
