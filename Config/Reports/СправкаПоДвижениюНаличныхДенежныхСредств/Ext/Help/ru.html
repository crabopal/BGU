Отчет "Справка по движению наличных денежных средств"

Отчет Справка по движению наличных денежных средств предназначен для получения информации о начальном и конечном остатках наличных денежных средств в кассе, о суммах поступления или выбытия по каждой операции в разрезе КПС и КЭК в заданном периоде.

Для вызова отчета можно использовать команду Справка по движению наличных денежных средств формы Отчеты раздела "Денежные средства", которую можно открыть с помощью команды Отчеты по денежным средствам меню функций раздела Денежные средства.

Для формирования отчета следует выбрать значения реквизитов Период, Организация и нажать на кнопку Сформировать.

Отчет "Контроль оборотов балансовых и забалансовых счетов (касса)"

Вариант отчета Контроль оборотов балансовых и забалансовых счетов (касса) позволяет проконтролировать обороты между балансовым счетом 201.34 и забалансовым счетом НД, а также выявить отклонения, если они имели место.

Для вызова варианта отчета Контроль оборотов балансовых и забалансовых счетов (касса) можно нажать на кнопку Варианты отчета командной панели отчета Справка по движению наличных денежных средств и использовать команду Контроль оборотов балансовых и забалансовых счетов (касса) в выпадающем меню.

Также для вызова варианта отчета можно использовать команду Контроль оборотов балансовых и забалансовых счетов (касса) формы Отчеты раздела "Денежные средства", которую можно открыть с помощью команды Отчеты по денежным средствам меню функций раздела Денежные средства.
