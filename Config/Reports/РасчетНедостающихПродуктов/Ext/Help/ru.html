Отчет "Расчет недостающих продуктов"

Отчет позволяет сформировать Справку-расчет о количестве недостающих продуктов в двух режимах – для конкретного документа меню - требование или в целом, на заданную дату.

Формирование отчета для документа "Меню – требование"

Для получения информации о недостающих продуктах по текущему документу Меню - требование следует сформировать отчет Справка-расчет о количестве недостающих продуктах с помощью кнопки Вывести остатки командной панели на закладке Списание продуктов.

Примечание. При формировании отчета программа учитывает остатки продуктов питания, а также потребность в продуктах для всех категорий питающихся, заданных в документе "Меню - требование".

Формирование отчета на заданную дату

Открыть форму отчета можно с помощью гиперссылки Расчет недостающих продуктов в форме Отчеты раздела «Услуги, работы, производство», для вызова которой можно использовать команду Отчеты по работам, услугам, производству меню функций раздела Услуги, работы, производство.

Настройка отчета

Перед формированием отчета необходимо заполнить реквизиты На дату, Организация, Мол/Место хранения и Подразделение.

Для формирования отчета следует нажать на кнопку Сформировать командной панели формы отчета.

Примечание. При формировании отчета программа учитывает остатки продуктов питания, актуальные приемы пищи и варианты меню, а также количество питающихся.
