Отчет "Накопительная ведомость по расходу продуктов питания (ф. 0504038)"

Отчет Накопительная ведомость по расходу продуктов питания (ф. 0504038) позволяет получать информацию о расходовании продуктов питания со счетов 105.22 и 105.32 в разрезе номенклатуры по датам.

Открыть форму отчета можно с помощью гиперссылки Накопительная ведомость по расходу продуктов питания в форме Отчеты раздела «Услуги, работы, производство», для вызова которой можно использовать команду Отчеты по работам, услугам, производству меню функций раздела Услуги, работы, производство.

Настройка отчета

В форме отчета необходимо заполнить реквизиты:

  • Организация – наименование организации, по данным которой необходимо сформировать отчет. Выбирается из справочника Организации;
  • Период отчета – интервал дат, в котором операции поступления должны отображаться в отчете;
  • КФО – код финансового обеспечения. Выбирается в списке КФО;
  • ЦМО – центр материальной ответственности. Выбирается из справочника Центры материальной ответственности.

Для продолжения настройки параметров отчета следует с помощью кнопки Настройки командной панели формы отчета открыть форму настроек.
