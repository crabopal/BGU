Карточка учета ЛБО (бюджетных ассигнований)

Отчет предназначен для получения карточки учета лимитов бюджетных обязательств (полученных или переданных) по форме № 0504062

Карточка учета лимитов бюджетных обязательств (бюджетных ассигнований) (ф. 0504062) применяется финансовыми органами для учета принятых и переданных лимитов бюджетных обязательств текущего года.

Данные формируются нарастающим итогом с начала года на основании Уведомлений о лимитах бюджетных обязательств (бюджетных ассигнований) (ф. 0504822) главного распорядителя, распорядителя бюджетных средств по кодам бюджетной классификации Российской Федерации.

Учет полученных и переданных лимитов бюджетных обязательств (бюджетных ассигнований) ведется обособленно на отдельных Карточках.

Сформированный отчет открывается в виде табличного документа, который затем может быть выведен на печать.

Для вызова формы отчета можно использовать команду Карточка учета ЛБО (ассигнований) формы Отчеты раздела «Планирование и санкционирование», которую можно открыть с помощью команды Отчеты по планированию и санкционированию меню функций раздела Планирование и санкционирование.

Настройка отчета

  • Период – период, за который будет сформирован отчет. Выбирается с помощью указания даты начала и даты окончания периода;
  • Счет – счет учета ЛБО. Выбирается из фрагмента Плана счетов ЕПСБУ, ограниченного субсчетами счета 501.00 и 503.00.
  • Организация – выбирается из справочника Организации.

Детальную настройку и отбор можно задать на панели настройки, которая открывается при нажатии кнопки Настройки командной панели формы отчета.

Возможна настройка отбора по следующим реквизитам:

  • Организация;
  • КПС;
  • КЭК.

Группа Реквизиты печатной формы позволяет указать значения реквизитов, которые будут напечатаны в отчете:

  • Организация – выбирается из справочника Организации;
  • Подразделение – выбирается из справочника Подразделения.

Ответственные лица, а именно, Главный бухгалтер, Начальник отдела и Исполнитель выбираются из справочника Сотрудники.

Примечание. Справочник Сотрудники доступен только после выбора организации в группе Реквизиты печатной формы.

Для формирования отчета следует нажать на кнопку Сформировать отчет командной панели формы.
