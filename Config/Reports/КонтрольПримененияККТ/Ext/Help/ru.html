Отчет "Контроль применения ККТ"

Отчет Контроль применения ККТ позволяет сформировать список документов, для которых чек на ККТ не был напечатан. Также в отчет выводятся документы, на сновании которых был создан и распечатан Исправительный чек ККМ, но на ККТ исправленный чек из первоначального документа не напечатан. Отчет доступен для профиля Главный бухгалтер.

Формирование отчета

Отчет Контроль применения ККТ можно открыть помощью команды Отчеты по денежным средствам – Управление ККТ меню функций раздела Денежные средства.

Настройка отчета

Период – период, за который будет сформирован отчет.

Организация – учреждение, для которого необходимо сформировать отчет. Выбирается из справочника Организации.

Для формирования отчета следует нажать на кнопку Сформировать.
