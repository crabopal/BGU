Отчет "Расчеты с банком по счету 201.23"

Отчет Расчеты с банком по счету 201.23 предназначен для формирования сведений о расчетах с банком-эквайером за период с группировкой по дням по следующим показателям:

  • Задолженность банка на начало дня;
  • Оплата от покупателей (задолженность банка);
  • Уменьшение задолженности банка (в том числе Поступление от банка, Комиссия банка, Возврат покупателям, Всего);
  • Задолженность банка на конец дня.

Для вызова отчета Расчеты с банком по счету 201.23 можно использовать команду Расчеты с банком по счету 201.23 в форме Отчеты раздела "Денежные средства" (раздел Денежные средства, команда Отчеты по денежным средствам).

Настройка отчета
  • Период – период, за который будет сформирован отчет;
  • Организация – выбирается из справочника Организации.

Возможна настройка дополнительного отбора по реквизиту Лицевой счет.

Для формирования отчета следует нажать на кнопку Сформировать.
