Отчет "Табель учета посещаемости детей"

Отчет Табель учета посещаемости детей позволяет сформировать и вывести на печать бланк табеля учета посещаемости детей за месяц для дальнейшего заполнения вручную.

Открытие формы отчета

Открыть форму отчета можно с помощью гиперссылки Табель учета посещаемости детей в форме Отчеты раздела «Платное обучение», для вызова которой можно использовать команду Отчеты по платным образовательным услугам меню функций раздела Платное обучение.

Выбор варианта отчета

В программе предусмотрены несколько вариантов отчета. Меню для выбора варианта вызывается с помощью кнопки Варианты отчета.

Отчет поставляется в трех вариантах:

  • сводно по группе – выводятся данные списочного состава детей с отбором по группе по услуге детского учреждения и колонки, в которых можно вручную указать количество дней оплачиваемых и неоплачиваемых пропусков посещений;
  • сводно по организации – выводятся данные списочного состава детей в целом по детскому учреждению и колонки, в которых можно вручную указать количество дней оплачиваемых и неоплачиваемых пропусков посещений;
  • ф. 0504608 (по дням) – формируется печатная форма 0504608 «Табель учета посещаемости детей» согласно приказа Министерства финансов Российской Федерации от 30.03.2015 №52н. Печатная форма заполняется списочным составом группы по услуге детского учреждения и ячейками, соответствующими дням месяца формирования отчета. Ячейки дней месяца формируются с учетом праздничных и выходных дней, заданных в графике работы группы по услуге детского учреждения, либо по данным Производственного календаря Российской Федерации, если график работы группы по услуге не установлен.
