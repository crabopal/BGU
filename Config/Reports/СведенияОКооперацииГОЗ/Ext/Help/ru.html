Отчет "Сведения о кооперации по гособоронзаказу"

Отчет предназначен для получения перечня контрактов с заказчиками и исполнителями, заключенных в рамках кооперации по гособоронзаказу.

Для вызова формы отчета можно использовать команду Сведения о кооперации по гособоронзаказу в форме Отчеты раздела "Планирование и санкционирование" (команда Отчеты по планированию и санкционированию меню функций раздела Планирование и санкционирование).

Настройка отчета

В форме отчета можно настроить отбор по реквизитам:

  • Организация – организация, по которой необходимо сформировать отчет.
  • Государственный оборонный заказ – государственный контракт по государственному оборонному заказу.
  • Контракт с заказчиком по кооперации – договор с заказчиком по кооперации, в рамках исполнения которого были заключены договора с исполнителями.

Детальная настройка отчета

Для детальной настройки отчета следует с помощью кнопки Настройки вызвать форму Настройки отчета "Сведения о кооперации по гособоронзаказу".

Детальная настройка позволяет настроить вывод в отчет дополнительных колонок, задать дополнительный отбор и изменить настройку группировки.

Формирование отчета

Для формирования отчета можно нажать кнопку Сформировать. Сформированный отчет открывается в виде табличного документа, который затем может быть выведен на печать.
