Сводные данные об исполнении плана ФХД

Отчет Сводные данные об исполнении плана ФХД является управленческим и формируется по счетам бухгалтерского учета санкционирования и кассовых доходов и расходов.

Отчет предназначен для получения информации о плановых (сметных) назначениях по поступлениям и выбытиям, об их исполнении, о принятии обязательств за счет плановых (сметных) назначений и об их исполнении.

Для вызова отчета можно использовать гиперссылку Сводные данные об исполнении плана ФХД формы Отчеты раздела "Планирование и санкционирование", которая открывается с помощью команды Отчеты по планированию и санкционированию меню функций раздела Планирование и санкционирование.

Примечание. Также в программе предусмотрено формирование варианта отчета Сводные данные об исполнении плана ФХД и остатки средств на счетах. Для вызова данных вариантов отчета можно использовать одноименные команды в форме Отчеты раздела "Планирование и санкционирование" раздела Планирование и санкционирование.

Настройка отчета

Период – период, за который будет сформирован отчет;

Плановый период – переключатель, который может принимать значения:

  • Текущий год – отчет формируется по данным счетов 500.10;
  • Очередной год – отчет формируется по данным счетов 500.20;
  • Второй год за текущим – отчет формируется по данным счетов 500.30;
  • Второй год за очередным – отчет формируется по данным счетов 500.40;
  • Иные очередные годы – отчет формируется по данным счетов 500.90;

Организация – выбирается из справочника Организации;

КФО – выбирается из предопределенного списка кодов финансового обеспечения;

Учитывать некассовые операции – переключатель, который может принимать значения:

  • Не учитывать – в отчете не учитываются некассовые операции;
  • По балансовым счетам – в отчете учитываются некассовые операции по балансовым счетам при расчете исполнения доходов и расходов;
  • По забалансовым счетам НКО – в отчете учитываются некассовые операции по забалансовым счетам НКО.ХХ при расчете исполнения доходов и расходов.

Важно!
В процессе формирования отчета выполняется запрос к бухгалтерским итогам. При этом установлен отбор по коду финансового обеспечения не равному 1 (бюджет).

Детальную настройку и отбор можно задать на панели настройки, которая открывается при нажатии кнопки Настройки командной панели формы отчета.

Для формирования отчета следует нажать на кнопку Сформировать командной панели формы.
