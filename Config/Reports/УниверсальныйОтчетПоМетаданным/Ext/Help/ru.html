Отчет "Универсальный отчет (по регистрам, документам, справочникам)"

Отчет Универсальный отчет (по регистрам, документам, справочникам) позволяет отображать данные документов, справочников, их табличных частей, регистров накопления и регистров сведений и их виртуальных таблиц.

Для вызова формы отчета можно использовать команду Универсальный отчет (по регистрам, документам, справочникам) панели действий раздела Учет и отчетность.

Реквизит Тип данных может принимать значение:

  • Документ;
  • Справочник;
  • Регистр накопления;
  • Регистр сведений;
  • Регистр бухгалтерии.

После выбора значения реквизита Тип данных в поле Имя объекта становится доступен для выбора список объектов выбранного типа данных.

Если реквизит Тип данных имеет значение Документ или Справочник, то в поле Имя таблицы будет автоматически подставлено наименование первой табличной части.

Если табличные части отсутствуют, то поле Имя таблицы также будет отсутствовать. Отчет при этом будет формироваться непосредственно по справочнику.

В качестве значения реквизита Имя объекта можно выбрать любой регистр накопления, существующий в программе.

Если в поле Имя объекта выбрать оборотный регистр накопления, то в поле Имя таблицы будет автоматически подставлено значение Обороты. В результате отчет будет формироваться по виртуальной таблице Обороты.

Если в поле Имя объекта выбрать регистр накопления остатков, то в поле Имя таблицы будет автоматически подставлено значение Остатки и обороты. В результате отчет будет формироваться по виртуальной таблице Остатки и обороты.

Для периодических регистров накопления в поле Имя таблицы можно выбрать Срез последних (выставляется по умолчанию) или Срез первых".

Для регистров накопления и сведений помимо выбора виртуальных таблиц, можно также выбрать непосредственно таблицу регистра. Для этого необходимо в реквизите Имя таблицы указать пустое поле.

При выборе типа данных, имени объекта и имени таблицы выполняется начальная настройка отчета. Начальная настройка может быть скорректирована на закладках Панели настроек, которую можно открыть с помощью кнопки Настройка.

На закладке Основные можно указать выбранные поля, настроить группировку и отбор.

На закладке Дополнительные можно настроить сортировку данных отчета и задать параметры его оформления.
