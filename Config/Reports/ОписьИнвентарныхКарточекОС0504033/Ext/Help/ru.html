Отчет "Опись инвентарных карточек НФА"

Отчет позволяет сформировать Опись инвентарных карточек по учету нефинансовых активов по форме 0504033.

Опись инвентарных карточек по учету нефинансовых активов (форма 0504033) применяется для регистрации открываемых Инвентарных карточек (ф. ф. 0504031, 0504032).

Для вызова данного отчета можно использовать гиперссылку Опись инвентарных карточек НФА формы Отчеты раздела "Основные средства, НМА, НПА".

Настройка отчета

В форме отчета необходимо указать:

  • Период, за который требуется сформировать отчет;
  • Организацию, для которой необходимо получить опись;
  • Подразделение организации.
