Табель учета посещаемости учащихся

Отчет Табель учета посещаемости учащихся позволяет сформировать и вывести на печать бланк табеля учета посещаемости учащихся за месяц для дальнейшего заполнения вручную.

Открытие формы отчета

Открыть форму отчета можно с помощью гиперссылки Табель учета посещаемости учащихся в форме Отчеты раздела «Платное обучение», для вызова которой можно использовать команду Отчеты по платным образовательным услугам меню функций раздела Платное обучение.

Выбор варианта отчета

В программе предусмотрены несколько вариантов отчета. Меню для выбора варианта вызывается с помощью кнопки Варианты отчета.

Отчет поставляется в двух основных вариантах:

  • по дням – заполняется списочным составом учащихся, а также ячейками, соответствующими дням месяца формирования отчета по данным Производственного календаря Российской Федерации с учетом праздничных и выходных дней;
  • сводно – в отчет выводится списочный состав учащихся и колонки, в которых можно вручную ввести количество дней оплачиваемых и неоплачиваемых пропусков занятий учащимися.

Для каждого из двух основных вариантов доступны следующие подчиненные варианты:

  • по группе – выводятся данные списочного состава учащихся с отбором по группе учебного заведения;
  • по организации – выводятся данные списочного состава учащихся в целом по образовательной организации;
  • по факультету – выводятся данные списочного состава учащихся с отбором по факультету.
