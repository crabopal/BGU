Отчет "Учащиеся по плательщику"

Отчет Учащиеся по плательщику предназначен для вывода актуальной информации по плательщикам за услуги образования на текущую или на указанную дату.

Пример. Учащийся Петров Антон Федорович был зачислен в образовательное учреждение. В карточке учащегося в качестве плательщика было указано ООО "Астра" и установлена дата начала действия сведений о плательщике за услуги образования - 01.09.2011. В феврале 2012 года плательщик поменялся, и в карточке учащегося с 01.02.2012 установлен в качестве плательщика его отец, Петров Федор Максимович.
В данной ситуации в отчете Учащиеся по плательщику, сформированном на дату 01.01.2012, будет выведена информация: Действует с 01.09.2011, ООО Астра, Петров Антон Федорович. При этом в отчете, сформированном на дату 01.03.2012, будет выведена информация:
Действует с 01.02.2012, Петров Федор Максимович, Петров Антон Федорович.

Открытие формы отчета

Открыть форму отчета можно с помощью гиперссылки Учащиеся по плательщику в форме Отчеты раздела «Платное обучение», для вызова которой можно использовать команду Отчеты по платным образовательным услугам меню функций раздела Платное обучение.

Выбор варианта отчета

В программе предусмотрены два варианта отчета – Плательщик по учащемуся и Учащиеся по плательщику.

Меню для выбора варианта отчета вызывается с помощью кнопки Варианты отчета.

Плательщик по учащемуся

В варианте отчета Плательщик по учащемуся выводится список учащихся с указанием сведений по плательщику на заданную (либо текущую) дату, а также выводится дата, с которой действуют эти сведения.

Быстрая настройка отчета

Быстрая настройка для данного варианта отчета позволяет настроить отбор данных по учащемуся.

Учащиеся по плательщику

В варианте отчета Учащиеся по плательщику выводится информация по учащимся, сгруппированная по плательщику с указанием даты действия сведений о плательщике по каждому учащемуся.

Быстрая настройка отчета

Быстрая настройка для данного варианта отчета позволяет настроить отбор по плательщику и договору с плательщиком.
