Отчет "Ведомость по плательщикам за услуги образования"

Отчет Ведомость по плательщикам за услуги образования предназначен для вывода сведений о плательщиках за услуги образования с указанием периода действия данных сведений.

Открытие формы отчета

Открыть форму отчета можно с помощью гиперссылки Ведомость по плательщикам в форме Отчеты раздела «Платное обучение», для вызова которой можно использовать команду Отчеты по платным образовательным услугам меню функций раздела Платное обучение.

Быстрая настройка отчета

Быстрая настройка отчета позволяет настроить отбор по Учащемуся, Контрагенту и Договору контрагента.

Для формирования отчета можно использовать кнопку Сформировать.

По умолчанию формируется вариант отчета Ведомость по плательщикам. Данный вариант отчета предусматривает вывод данных по учащимся с указанием сведений по всем плательщикам, которые действовали ранее и которые действуют в настоящее время.

Пример. Учащийся Петров Антон Федорович был зачислен в образовательное учреждение. В карточке учащегося в качестве плательщика было указано ООО "Астра" и установлена дата начала действия сведений о плательщике за услуги образования - 01.09.2011. В феврале 2012 года плательщик поменялся. В карточке учащегося с 01.02.2012 установлен в качестве плательщика его отец, Петров Федор Максимович.
В данной ситуации в отчете будет выведена информация:
Петров Антон Федорович
01.09.2011 31.01.2012 ООО Астра
01.02.2012 Действует сейчас Петров Федор Максимович.
