Отчет по кадровым данным по родительской плате

Отчет по кадровым данным по родительской плате предназначен для получения разнообразной информации, имеющей отношение к процессу начисления родительской платы в дошкольном образовательном учреждении.

Открытие формы отчета

Открыть форму отчета можно с помощью гиперссылки Отчет по кадровым по родительской плате в форме Отчеты раздела «Платное обучение», для вызова которой можно использовать команду Отчеты по платным образовательным услугам меню функций раздела Платное обучение.

Быстрая настройка отчета

Быстрая настройка для данного варианта отчета позволяет настроить отбор реквизитам:

  • Организация;
  • Группа детского учреждения;
  • Ставка оплаты;
  • Льгота.

Форма Настройки отчета «Отчет по кадровым данным по родительской плате», вызываемая с помощью кнопки Настройки, позволяет настроить разнообразные отборы и группировки, используя, в том числе дополнительные реквизиты и сведения.
