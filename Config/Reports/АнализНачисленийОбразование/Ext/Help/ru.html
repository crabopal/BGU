Отчет "Анализ начислений (образование)"

Отчет Анализ начислений (образование) предназначен для анализа и проверки правильности начислений за образовательные услуги. Отчет формируется на основании данных о Плановых и Фактических начислениях.

Под Плановыми начислениями в данном случае понимаются суммы, которые необходимо начислить плательщикам согласно документам вида Приказ (образование), предусматривающим оплату за услуги. Под Фактическими начислениями понимаются суммы начисления, которые уже начислены документами вида Начисление за услуги образования.

Открытие формы отчета

Открыть форму отчета можно с помощью гиперссылки Анализ начислений по услугам образования в форме Отчеты раздела «Платное обучение», для вызова которой можно использовать команду Отчеты по платным образовательным услугам меню функций раздела Платное обучение.

Быстрая настройка отчета

Быстрая настройка отчета позволяет задать Период, настроить отбор данных по Факультету, Учащемуся и Контрагенту.

Детальная настройка отчета

Для детальной настройки отчета следует с помощью кнопки Настройка вызвать форму Настройка отчета "Анализ начислений (образование)". Детальная настройка позволяет настроить вывод в отчет дополнительных колонок, задать дополнительный отбор и изменить настройку группировки.

Часть настроек выполняется с использованием флагов:

  • Только фактические начисления – после установки флага в отчет будут выводиться данные только по фактически выполненным начислениям;
  • Только различия в начислениях – после установки флага в отчет будут выводиться данные только по различиям в фактических и плановых начислениях;
  • Выделять серым корректные начисления – после установки флага цвет текста корректных начислений будет серым.

По окончании детальной настройки следует с помощью кнопки Завершить редактирование закрыть форму Настройка отчета "Анализ начислений (образование)".

Для формирования отчета можно использовать кнопку Сформировать.

Примечание. Данные в отчете разбиты по периодам начислений – по месяцам.

Строки отчета выделяются текстом разного цвета.

Черный цвет текста. Черный текст означает, что фактические начисления отличаются от плановых. В этом случае необходимо проанализировать ситуацию, внести корректировки, актуализировать данные с помощью кнопки Актуализировать начисления и сформировать отчет заново.

Синий цвет текста. Синий цвет текста означает, что начисления требуют актуализации данных. Это возможно, например, при проведении документов Приказ (образование) "задним числом". Актуализировать данные необходимо с помощью кнопки Актуализировать начисления. После сообщения программы о том, что начисления актуализированы, необходимо снова сформировать отчет.

Серый цвет текста. Серый цвет текста означает правильность, а также идентичность плановых и фактических начислений.
