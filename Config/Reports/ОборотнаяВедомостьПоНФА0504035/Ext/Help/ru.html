Отчет "Оборотная ведомость по нефинансовым активам"

Отчет предназначен для формирования Оборотной ведомости по нефинансовым активам по форме 0504035.

Отчет отражает наличие и движение НФА за выбранный период на счетах группы счетов 101 Основные средства, 102 Нематериальные активы, 103 Непроизведенные активы, 104 Амортизация, 105 Материальные запасы, 108 Нефинансовые активы имущества казны, 111.60 Права пользования нематериальными активами.

Оборотные ведомости по нефинансовым активам применяется для обобщения данных по наличию и стоимости нефинансовых активов и сверки записей, выполненных по счетам аналитического учета с данными счетов учета ОС, НПА, НМА и материалов Главной книги (ф. 0504072).

Оборотная ведомость составляется ежемесячно по всем объектам учета в количественном и стоимостном выражении.

При этом третий лист может быть использован в качестве вкладного листа.

Кроме того, оборотная ведомость применяется для ведения аналитического учета по счетам амортизации основных средств и нематериальных активов, отражения начисленных сумм амортизации и списания их с учета.

В оборотной ведомости отражается входящее сальдо по каждому объекту НФА, подсчитываются обороты и выводятся остатки на конец месяца.

Организация вправе составлять оборотную ведомость ежеквартально.

Программа позволяет сформировать три варианта отчета:

  • Оборотная ведомость по нефинансовым активам;
  • Оборотная ведомость по нефинансовым активам (группировка по счетам);
  • Оборотная ведомость по нефинансовым активам (произвольный отчет).

Настройка отчета

В шапке отчета можно настроить отбор по следующим реквизитам:

  • Период – период, за который будет сформирован отчет;
  • Счет – счет учета объектов ОС, НМА, НПА или МЗ. Выбирается из фрагмента плана счетов ЕПСБУ, ограниченного счетами 101.00, 102.00, 103.00, 104.00, 105.00, 108.00 и 111.60;
  • Организация – учреждение, для которого необходимо сформировать отчет. Выбирается из справочника Организации;
  • Подразделение – подразделение, выбирается из справочника Подразделения.

Также предусмотрена возможность настройки следующих параметров формирования отчета:

  • Выводить титульный лист – при включении флажка выводится титульный лист;
  • Дата заполнения – дата заполнения отчета;
  • Исполнитель – сотрудник, данные которого подставляются в графу Исполнитель в подвале отчета.

Примечание. При необходимости выполнить расширенную настройку следует использовать кнопку Вид: Расширенный формы Настройки отчета "Оборотная ведомость по нефинансовым активам", которая вызывается с помощью кнопки Настройки командной панели формы отчета.
