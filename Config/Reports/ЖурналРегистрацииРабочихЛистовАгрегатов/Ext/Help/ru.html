Журнал регистрации рабочих листов агрегатов

Журнал регистрации рабочих листов агрегатов предназначен для формирования заполненного журнала регистрации рабочих листов агрегатов.

Отчет позволяет подписать заполненный электронный журнал усиленной квалифицированной электронной подписью и сохранить в архив электронных документов.

Для вызова отчета Журнал регистрации рабочих листов агрегатов можно использовать гиперссылку Журнал регистрации рабочих листов агрегатов в форме Журнал учетных листов агрегатов (раздел ГСМ, команда Журнал учетных листов агрегатов).

Настройка и заполнение отчета

Для формирования отчета следует указать период и организацию, после чего нажать на кнопку Сформировать.

Отчет имеет следующие дополнительные параметры формирования:

  • Подразделение – при заполнении отчет заполняется только рабочими листами с указанным подразделением;
  • Ответственный – при заполнении в сформированном отчете заполнена должность и фамилия, имя, отчество ответственного;
  • Дата заполнения – для вывода даты заполнения в сформированном отчете.

Отчет заполняется по сведениям документов путевых листов из Журнала рабочих листов агрегатов. Тип, марка и модель агрегата заполняются по данным основного средства. Графа Примечание заполняется по данным реквизита Комментарий документов рабочих листов агрегатов.

Для подписания отчета электронной подписью следует нажать кнопку Регистр учета - Подписать ЭП и сохранить.
