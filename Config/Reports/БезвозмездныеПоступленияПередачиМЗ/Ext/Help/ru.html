Отчет "Безвозмездные поступления (выбытия) МЗ"

Отчет Безвозмездные поступления (выбытия) МЗ позволяет сформировать четыре варианта отчета:

  • Безвозмездные поступления МЗ (по датам);
  • Безвозмездные поступления МЗ (по месяцам и контрагентам);
  • Безвозмездные выбытия МЗ (по датам);
  • Безвозмездные выбытия МЗ (по месяцам и контрагентам).

Вариант отчета Безвозмездные поступления МЗ (по датам) содержат информацию о материальных запасах и объектах имущества казны, полученных по централизованным поставкам, внутриведомственному перемещению, а также безвозмездно, сгруппированную по дате поступления.

Вариант отчета Безвозмездные поступления МЗ (по месяцам и контрагентам) содержат информацию о материальных запасах и объектах имущества казны, полученных по централизованным поставкам, внутриведомственному перемещению, а также безвозмездно, сгруппированную по месяцам и контрагентам.

Вариант отчета Безвозмездные выбытия МЗ (по датам) содержат информацию о переданных безвозмездно материальных запасах и объектах имущества казны, сгруппированную по дате поступления.

Вариант отчета Безвозмездные поступления МЗ (по месяцам и контрагентам) содержат информацию о переданных безвозмездно материальных запасах и объектах имущества казны, сгруппированную по месяцам и контрагентам.

Для вызова нужного варианта отчета можно использовать соответствующую гиперссылку Безвозмездные поступления (выбытия) МЗ формы Отчеты раздела "Материальные запасы".

Примечание. Если открыт какой-либо вариант отчета Безвозмездные поступления (выбытия) МЗ, то следует нажать на кнопку командной панели Варианты отчета и выбрать в списке необходимый вариант отчета.

Настройка отчета

В шапке отчета можно настроить отбор по следующим реквизитам:

  • Период – период, за который будет сформирован отчет;
  • Организация – учреждение, для которого необходимо сформировать отчет. Выбирается из справочника Организации;
  • Контрагент – выбирается из справочника Контрагенты;
  • Счет кор. – выбирается из фрагмента Плана счетов ЕПСБУ.

Примечание. При необходимости выполнить расширенную настройку следует использовать кнопку Вид: Расширенный формы Настройки отчета "Безвозмездные поступления (выбытия) МЗ", которая вызывается с помощью кнопки Настройки командной панели формы отчета.
