Отчет по кадровым данным учащихся

Отчет по кадровым данным учащихся предназначен для получения разнообразной информации, имеющей отношение к процессу обучения учащихся в образовательной организации.

Открытие формы отчета

Открыть форму отчета можно с помощью гиперссылки Отчет по кадровым данным учащихся в форме Отчеты раздела «Платное обучение», для вызова которой можно использовать команду Отчеты по платным образовательным услугам меню функций раздела Платное обучение.

Быстрая настройка отчета

Быстрая настройка для данного варианта отчета позволяет настроить отбор реквизитам:

  • Факультет;
  • Курс;
  • Специальность;
  • Группа;
  • Учащийся;
  • Контрагент (плательщик);
  • Договор на обучение;
  • Состояние учащегося;
  • Ставка оплаты;
  • Льгота;
  • Приказ.

Форма Настройки отчета «Отчет по кадровым данным учащихся», вызываемая с помощью кнопки Настройки, позволяет настроить разнообразные отборы и группировки, используя, в том числе дополнительные реквизиты и сведения.
