Отчет "Оборотная ведомость по расчетам с контрагентами"

Отчет Оборотная ведомость по расчетам с контрагентами предназначен для получения информации об общих взаиморасчетах с контрагентами. В отчете отражаются расчеты по счетам 205, 206, 207.00, 209.00, 210.00 и 302.

Для вызова формы отчета Оборотная ведомость по расчетам с контрагентами можно использовать команду Оборотная ведомость по расчетам с контрагентами в форме Отчеты раздела "Планирование и санкционирование" (команда Отчеты по планированию и санкционированию меню функций раздела Планирование и санкционирование).

Настройка отчета

Для вызова панели настроек следует использовать кнопку Настройки командной панели формы.

  • Период – период, за который будет сформирован отчет.
  • Счет – выбирается из фрагмента Плана счетов ЕПСБУ, ограниченного счетами 205.00, 206.00, 207.00, 209.00, 210.00 и 302.00.
  • Организация – выбирается из справочника Организации.
  • Контрагент – выбирается из справочника Контрагенты.
  • КФО – выбирается из списка КФО.
  • КПС – выбирается из списка КПС.
