Отчет "Ведомость начисленной и выплаченной компенсации"


Отчет Ведомость начисленной и выплаченной компенсации предназначен для получения информации о суммах начисленной и выплаченной компенсации родительской платы за период времени.

Открыть форму отчета можно с помощью гиперссылки Ведомость начисленной и выплаченной компенсации в форме Отчеты раздела "Платное обучение", для вызова которой можно использовать команду Отчеты по платным образовательным услугам меню функций раздела Платное обучение.

Настройка отчета


Для выбора варианта формирования отчета можно использовать кнопку Варианты отчета командной панели формы.

Предусмотрены следующие варианты формирования отчета:

  • Ведомость начисленной и выплаченной компенсации (сводно).
  • Ведомость начисленной и выплаченной компенсации (детально, список).
  • Ведомость начисленной и выплаченной компенсации (детально, ставка).
  • Ведомость начисленной и выплаченной компенсации по КФО и КПС (сводно).
  • Ведомость начисленной и выплаченной компенсации по КФО и КПС (детально, список).
  • Ведомость начисленной и выплаченной компенсации по КФО и КПС (детально, ставка).


В сводных отчетах доступен отбор по Периоду, Детскому учреждению и Проценту компенсации.

В детальных отчетах доступен отбор по Периоду, Детскому учреждению, Проценту компенсации, Ребенку и Плательщику родительской платы.

Формирование отчета
Для формирования отчета можно нажать кнопку Сформировать. Сформированный отчет открывается в виде табличного документа, который затем может быть выведен на печать.
