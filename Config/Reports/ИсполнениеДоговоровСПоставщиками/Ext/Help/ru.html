Отчет "Исполнение договоров с поставщиками"

Настройки, включенные в состав отчета Исполнение договоров с поставщиками, позволяют сформировать отчеты:

  • Анализ состояния расчетов по договорам;
  • Поступление товаров, работ, услуг по договорам.

Отчет "Анализ состояния расчетов по договорам"

Отчет Анализ состояния расчетов по договорам предназначен для анализа состояния расчетов с поставщиками по договорам приобретения товаров, работ, услуг.

Отчет позволяет получить информацию о сальдо расчетов с поставщиками на начало и конец периода, а также об исполнении обязательств по договору со стороны поставщиков и со стороны учреждения в течение периода.

Для вызова формы отчета Анализ состояния расчетов по договорам можно использовать команду Анализ состояния расчетов по договорам в форме Отчеты раздела "Планирование и санкционирование" (команда Отчеты по планированию и санкционированию меню функций раздела Планирование и санкционирование).

Настройка отчета

Для вызова панели настроек следует использовать кнопку Настройки командной панели формы.

  • Период – период, за который будет сформирован отчет.
  • Организация – выбирается из справочника Организации.
  • Контрагент – выбирается из справочника Контрагенты.

Отчет "Поступление товаров, работ, услуг по договорам"

Отчет Поступление товаров, работ, услуг по договорам предназначен для получения информации об обязательствах поставщиков по договорам, о запланированных поступлениях по плану финансирования и о фактических поступлениях.

Для вызова формы отчета Поступление товаров, работ, услуг по договорам можно использовать команду Поступление товаров, работ, услуг по договорам в форме Отчеты раздела "Планирование и санкционирование" (команда Отчеты по планированию и санкционированию меню функций раздела Планирование и санкционирование).

Настройка отчета

Для вызова панели настроек следует использовать кнопку Настройки командной панели формы.

  • Период – период, за который будет сформирован отчет.
  • Организация – выбирается из справочника Организации.
  • Контрагент – выбирается из справочника Контрагенты.
