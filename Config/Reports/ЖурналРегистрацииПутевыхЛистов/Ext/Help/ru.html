Журнал регистрации путевых листов

Журнал регистрации путевых листов предназначен для формирования заполненного журнала регистрации путевых листов.

Отчет позволяет подписать заполненный электронный журнал усиленной квалифицированной электронной подписью и сохранить в архив электронных документов согласно приказу Минтранса России от 11.09.2020 № 368 «Об утверждении обязательных реквизитов и порядка заполнения путевых листов».

Для вызова отчета Журнал регистрации путевых листов можно использовать гиперссылку Журнал регистрации путевых листов в форме Журнал путевых листов (раздел ГСМ, команда Журнал путевых листов).

Настройка и заполнение отчета

Для формирования отчета следует указать период и организацию, после чего нажать на кнопку Сформировать.

Отчет имеет следующие дополнительные параметры формирования:

  • Подразделение – при заполнении отчет заполняется только путевыми листами с указанным подразделением;
  • Ответственный – при заполнении в сформированном отчете заполнена должность и фамилия, имя, отчество ответственного;
  • Дата заполнения – для вывода даты заполнения в сформированном отчете.

Отчет заполняется по сведениям документов путевых листов из Журнала путевых листов. Тип, марка и модель транспортного средства заполняются по данным основного средства. Графа Примечание заполняется по данным реквизита Комментарий документов путевых листов.

Для подписания отчета электронной подписью следует нажать кнопку Регистр учета - Подписать ЭП и сохранить.
