Отчет "Исполннение контрактов по гособоронзаказу (по КБК)"

Отчет позволяет контролировать ход кассового исполнения контракта по государственному оборонному заказу.

Для вызова формы отчета можно использовать команду Исполннение контрактов по гособоронзаказу (по КБК) в форме Отчеты раздела "Планирование и санкционирование"(команда Отчеты по планированию и санкционированию меню функций раздела Планирование и санкционирование).

Настройка отчета

В форме отчета можно настроить отбор по реквизитам:

  • Период – период, за который будет сформирован отчет.
  • Организация – организация, по которой необходимо сформировать отчет.
  • Классификатор статей калькуляции – выбирается из справочника Дополнительные бюджетные классификаторы;
  • Лицевой счет – отдельный счет организации.
  • Договор с заказчиком – договор с заказчиком по кооперации, в рамках исполнения которого были заключены договора с исполнителями.

Детальная настройка отчета

Для детальной настройки отчета следует с помощью кнопки Настройки вызвать форму Настройки отчета "Исполннение контрактов по гособоронзаказу".

Детальная настройка позволяет настроить вывод в отчет дополнительных колонок, задать дополнительный отбор и изменить настройку группировки.

Формирование отчета

Для формирования отчета можно нажать кнопку Сформировать.

Сформированный отчет открывается в виде табличного документа, который затем может быть выведен на печать.

Кнопка Варианты отчета командной панели формы предназначена для выбора варианта отчета:

  • Исполнение контрактов по гособоронзаказу (по КБК):
  • Исполнение контрактов по гособоронзаказу.

Основной вариант отчета – Исполнение контрактов по гособоронзаказу (по КБК).

Заполнение граф данного варианта отчета происходит следующим образом:

  • Договор заказчиком, лицевой счет, КПС, КЭК;
  • Смета (поступления) – оборот между дебетом счета 507.10 и кредитом счета 504.11.
  • Смета (расходы), План – оборот между дебетом счета 504.12 и кредитом счета 506.10.
  • Кассовое поступление – оборот по дебету счета 17 минус оборот по кредиту счета 17.
  • Кассовые расходы, исполнено – Оборот по кредиту счета 18 минус оборот по дебету счета 18.
  • Исполнение плана, % – отношение графы Исполнено к графе План.
  • Остаток – План минус Исполнено.

Исполнение контрактов по гособоронзаказу – является облегченным, управленческим вариантом отчета.

При формировании данного варианта отчета заполняются графы Договор с заказчиком, Государственный оборонный заказ, План, Исполнено, Исполнение плана % и Остаток.
