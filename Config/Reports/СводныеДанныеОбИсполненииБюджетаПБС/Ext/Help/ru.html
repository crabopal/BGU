Сводные данные об исполнении бюджета ПБС

Отчет Сводные данные об исполнении бюджета ПБС является управленческим и формируется по счетам бухгалтерского учета санкционирования и кассовых расходов: 503.03, 501.03, 502.01, 502.02, 304.04, 304.05, 201.21, 17, 18, ПОФ.С.

Данный отчет предназначен для получения информации о полученных бюджетных данных – ассигнованиях, ЛБО, ПОФ, принятых за счет них обязательствах, произведенных кассовых расходах и остатках бюджетных данных для принятия обязательств.

Для вызова отчета можно использовать гиперссылку Сводные данные об исполнении бюджета ПБС формы Отчеты раздела "Планирование и санкционирование", которая открывается с помощью команды Отчеты по планированию и санкционированию меню функций раздела Планирование и санкционирование.

Примечание. Также в программе предусмотрено формирование вариантов отчета Кассовое исполнение государственных (муниципальных программ), Сводные данные о финансировании на банковские счета ПБС, Сводные данные об исполнении обязательств ПБС и Структура кассовых расходов ПБС. Для вызова данных вариантов отчета можно использовать одноименные команды в форме Отчеты раздела «Планирование и санкционирование» раздела Планирование и санкционирование.

Настройка отчета

Период – период, за который будет сформирован отчет;

Плановый период – переключатель, который может принимать значения:

  • Текущий год – отчет формируется по данным счетов 500.10;
  • Очередной год – отчет формируется по данным счетов 500.20;
  • Второй год, следующий за текущим – отчет формируется по данным счетов 500.30;
  • Второй год за очередным – отчет формируется по данным счетов 500.40;
  • Иные очередные годы – отчет формируется по данным счетов 500.90;

Организация – выбирается из справочника Организации;

Лицевой счет – выбирается из справочника Лицевые счета после выбора значения для реквизита Организация;

Раздел лицевого счета – выбирается из справочника Разделы лицевых счетов.

Порядок заполнения отчета
  • Графа "полученные ассигнования" – сумма оборота по кредиту счета 503.Х3;
  • Графа "детализация ассигнований" – сумма оборота по дебету счета 503.Х3 при условии, что счет кредита 503.Х3;
  • Графа "ассигнования" – графа "полученные ассигнования" минус графа "детализация ассигнований";
  • Графа "полученные ЛБО" – сумма оборота по кредиту счета 501.Х3 при условии, что счет кредита не 502.Х7;
  • Графа "детализация ЛБО" – сумма оборота по дебету счета 501.Х3 при условии, что счет кредита 501.Х3;
  • Графа "ЛБО" – графа "полученные ЛБО" минус графа "детализация ЛБО";
  • Графа "получено ПОФ" – сумма оборота по дебету счета ПОФ.С;
  • Графа "бюджетные назначения" – графа "ЛБО", если в ней есть данные, иначе графа "ассигнования". По каждой классификации;
  • Графа "принято бюджетных обязательств" – сумма оборота по кредиту счета 502.Х1;
  • Графа "принято обязательств" – равно графе "принято бюджетных обязательств";
  • Графа "принято бюджетных обязательств за счет ассигнований" – сумма оборота по кредиту счета 502.Х1 при условии, что счет дебета 503.Х3;
  • Графа "принято бюджетных обязательств за счет ЛБО" – графа "принято обязательств" минус графа "принято бюджетных обязательств за счет ассигнований";
  • Графа "принято бюджетных обязательств (с применением конкурентных способов)" – сумма оборота по кредиту счета 502.Х1 при условии, что счет дебета 502.Х7;
  • Графа "принимаемые обязательства" – сумма оборота по кредиту счета 502.Х7 минус сумма оборота по дебету счета 502.Х7;
  • Графа "принято денежных обязательств" – сумма оборота по кредиту счета 502.Х2;
  • Графа "кассовые выбытия" – сумма оборотов по кредиту счета 304.05 и счетов 18.01, 18.07;
  • Графа "восстановлено расходов" – сумма оборотов по дебету счета 304.05 и счетов 18.01, 18.07;
  • Графа "кассовое исполнение" – графа "кассовые выбытия" минус графа "восстановлено расходов";
  • Графа "остаток бюджетных назначений для принятия обязательств" – графа "бюджетные назначения" минус графа "принято бюджетных обязательств" минус графа "принимаемые обязательства";
  • Графа "неисполнено назначений" – графа "бюджетные назначения" минус графа "принято бюджетных обязательств" минус графа "кассовое исполнение";
  • Графа "остаток ПОФ" – графа "получено ПОФ" минус графа "принято бюджетных обязательств" минус графа "кассовое исполнение";
  • Графа "неисполнено бюджетных обязательств" – графа "принято обязательств" минус графа "кассовое исполнение";
  • Графа "неисполнено денежных обязательств" – графа "принято денежных обязательств" минус графа "кассовое исполнение".

Важно!
В процессе формирования отчета выполняется запрос к бухгалтерским итогам. При этом отбираются только данные по КФО = 1 (бюджет).

Детальную настройку и отбор можно задать на панели настройки, которая открывается при нажатии кнопки Настройки командной панели формы отчета.

Для формирования отчета следует нажать на кнопку Сформировать командной панели формы.
