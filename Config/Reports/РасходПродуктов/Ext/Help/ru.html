Отчет "Расход продуктов"

Отчет Расход продуктов предназначен для получения информации о расходе по каждому из продуктов питания в разрезе категорий довольствующихся за период.

Данные в отчете представлены в количественном и стоимостном выражении.

Также предусмотрен вариант отчета Расход продуктов (по периодам), позволяющий получить информацию о расходе продуктов питания в разрезе периодов по категориям довольствующихся.

Данные в отчете представлены в количественном и стоимостном выражении.

Открыть форму отчета можно с помощью гиперссылки Расход продуктов в форме Отчеты раздела «Услуги, работы, производство», для вызова которой можно использовать команду Отчеты по работам, услугам, меню функций раздела Услуги, работы, производство.

Настройка отчета

В форме отчета необходимо заполнить реквизиты:

  • Организация – наименование организации, по данным которой необходимо сформировать отчет. Выбирается из справочника Организации;
  • Период – интервал дат, в котором операции расхода должны отображаться в отчете.

Для выбора варианта отчета следует использовать кнопку командной панели формы отчета.

Для продолжения настройки параметров отчета следует с помощью кнопки Настройки командной панели формы отчета открыть форму настроек.
