Отчет о стоимости питания

Отчет предназначен для получения информации о плановой и фактической стоимости питания категорий довольствующихся за период формирования отчета.

Открыть форму отчета можно с помощью гиперссылки Отчет о стоимости питания в форме Отчеты раздела «Услуги, работы, производство», для вызова которой можно использовать команду Отчеты по работам, услугам, производству меню функций раздела Услуги, работы, производство.

Настройка отчета

В форме отчета необходимо заполнить реквизиты:

  • Организация – наименование организации, по данным которой необходимо сформировать отчет. Выбирается из справочника Организации;
  • Период – интервал дат, в котором операции должны отображаться в отчете.

Предусмотрено два варианта отчета:

  • Отчет о стоимости питания (таблица);
  • Отчет о стоимости питания (список).

Вариант Отчет о стоимости питания (таблица) предназначен для получения информации о фактической стоимости питания по датам за период.

Вариант Отчет о стоимости питания (список) позволяет получить информацию о плановой и фактической стоимости питания по категориям довольствующихся за период.

Для выбора варианта отчета используется соответствующая команда меню, которое открывается кнопкой Варианты отчета командной панели.

Для продолжения настройки параметров отчета следует с помощью кнопки Настройки командной панели формы отчета открыть форму настроек.
