Отчет "Список/Кросс-таблица"

Отчет предназначен для получения списков и кросс-таблиц.

Кросс-таблица представляет собой отчет с группировкой данных в строках и в колонках. Отчет может быть построен для любого регистра накопления, присутствующего в программе.

Благодаря этой возможности, отчет может быть использован в том числе для регистров накопления, которые изначально в программе отсутствовали.

Для вызова формы отчета можно использовать команду Список/Кросс - таблица формы Отчеты раздела «Стандартные отчеты», которую можно открыть с помощью команды Стандартные отчеты, меню функций, например, раздела Учет и отчетность.

Настройка отчета

В качестве значения реквизита Имя объекта можно выбрать любой регистр накопления, существующий в программе.

Если выбрать оборотный регистр накопления, то в поле Имя таблицы будет автоматически подставлено значение Обороты. В результате отчет будет формироваться по виртуальной таблице Обороты.

Если выбрать регистр накопления остатков, то в поле Имя таблицы будет автоматически подставлено значение Остатки и обороты. В результате отчет будет формироваться по виртуальной таблице Остатки и обороты.

Помимо выбора виртуальных таблиц, можно также выбрать непосредственно таблицу регистра. Для этого необходимо в реквизите Имя таблицы указать пустое поле.

При выборе имени объекта и имени таблицы выполняется начальная настройка отчета. Начальная настройка может быть скорректирована на закладках Панели настроек, которую можно открыть с помощью кнопки Настройка.

На закладке Основные можно указать выбранные поля, настроить группировку.

На закладке Дополнительные можно настроить отбор и сортировку данных отчета.

На закладке Оформление можно задать оформление отчета.
