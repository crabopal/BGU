Отчет "Ведомость амортизации"

Отчет Ведомость амортизации содержит подробную информацию о начисленной амортизации в разрезе инвентарных объектов, счетов учета и других параметров.

Для каждого объекта ОС, НМА и НПА, прав пользования НМА с определенным сроком полезного использования в отчете приводятся сведения о дате принятия к учету, коде ОКОФ, амортизационной группе, сроке полезного использования и месячной норме амортизации (если они заданы), балансовой стоимости на конец периода, амортизации на начало и конец периода, амортизации начисленной и списанной за период, а также об остаточной стоимости на конец периода.

Для вызова отчета можно использовать гиперссылку Ведомость амортизации формы Отчеты раздела "Основные средства, НМА, НПА".

Настройка отчета

В шапке отчета можно настроить отбор по следующим реквизитам:

  • Период – период, за который будет сформирован отчет;
  • Организация – учреждение, для которого необходимо сформировать отчет. Выбирается из справочника Организации;
  • Основное средство – выбирается из справочника Основные средства;
  • Счет учета – выбирается из фрагмента Плана счетов ЕПСБУ, ограниченного счетами 101.00, 102.00, 103.00 и 111.60.

Примечание. При необходимости выполнить расширенную настройку следует использовать кнопку Вид: Расширенный формы Настройки отчета "Ведомость амортизации", которая вызывается с помощью кнопки Настройки командной панели формы отчета.
