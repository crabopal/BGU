Отчет "Продажи"

Отчет Продажи предназначен для формирования сведений о количестве и сумме реализованных в розницу за период товарах, услугах, работах из справочника Прейскурант в разрезе контрагентов – покупателей.
Для вызова отчета можно использовать команду Продажи, которую можно вызвать с помощью команды Отчеты по денежным средствам меню функций раздела Денежные средства или подменю Отчеты в форме журнала Чеки ККМ группы Розничные продажи раздела Денежные средства.

Настройка отчета

Период – период, за который будет сформирован отчет;
Организация – учреждение, для которого необходимо сформировать отчет. Выбирается из справочника Организации;
Контрагент – контрагент, которому продали товар. Выбирается из справочника Контрагенты;
Подразделение – подразделение, по которому необходимо сформировать отчет. Выбирается из справочника Подразделения;
Номенклатура – номенклатура товара, по которой необходимо сформировать отчет. Выбирается из справочника Типы цен номенклатуры;
Макет оформления – выбранный параметр влияет на внешний вид отчета.

Примечание. При необходимости выполнить расширенную настройку следует использовать кнопку Вид: Расширенный формы Настройки отчета "Продажи", которая вызывается с помощью кнопки Настройки командной панели формы отчета.

Для формирования отчета следует нажать на кнопку Сформировать.
