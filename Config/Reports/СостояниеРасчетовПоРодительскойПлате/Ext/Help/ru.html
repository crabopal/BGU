Отчет "Состояние расчетов по родительской плате"

Отчет Состояние расчетов по родительской плате позволяет сформировать список детей, зачисленных в группы детских учреждений на заданную дату.  

Открыть форму отчета можно с помощью гиперссылки Состояние расчетов по родительской плате в форме Отчеты раздела «Платное обучение», для вызова которой можно использовать команду Отчеты по платным образовательным услугам меню функций раздела Платное обучение.

Настройка отчета 

В шапке формы отчета предусмотрены следующие настройки.

Дата отчета – дата, по состоянию на которую будет сформирован отчет.

Возможна настройка отбора по следующим реквизитам: 

  • Основная образовательная программа – выбирается из списка, Да или Нет, для вывода сведений по группам основной или дополнительный образовательной деятельности; 
  • Организация – выбирается из справочника Организации;
  • Группа – выбирается из справочника Группы детского учреждения;
  • Ребенок – выбирается из справочника Дети.

Для доступа к расширенным вариантам отбора и группировки следует нажать кнопку командной панели Настройки. 

Формирование отчета

Для формирования отчета можно нажать на кнопку Сформировать. 

Сформированный отчет открывается в виде табличного документа, который затем может быть выведен на печать. 

Выводится информация о зачисленных в группы детях и сальдо по данных бухгалтерских регистров на указанную дату.
