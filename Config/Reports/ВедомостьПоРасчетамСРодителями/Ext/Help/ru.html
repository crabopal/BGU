Отчет "Ведомость расчетов по родительской плате"

Отчет Ведомость расчетов по родительской плате предназначен для формирования ведомости по расчетам с родителями за содержание детей в детских учреждениях по форме, разработанной на основе ф. № 327.

Открыть форму отчета можно с помощью гиперссылки Ведомость расчетов по родительской плате в форме Отчеты раздела «Платное обучение», для вызова которой можно использовать команду Отчеты по платным образовательным услугам меню функций раздела Платное обучение.

Выбор варианта отчета

В программе предусмотрены четыре варианта ведомости расчетов по родительской плате – без оформления, по группе, сводно и списком.

Меню для выбора варианта отчета вызывается с помощью кнопки Варианты отчета.

Настройка отчета

В шапке формы отчета предусмотрены следующие настройки.

Период – период, за который будет сформирован отчет.

Возможна настройка отбора по следующим реквизитам:

  • Исполнитель (подпись) – выбирается из справочника Сотрудники;
  • Вид образовательной программы – выбирается из списка, Основная или Дополнительная;
  • Организация – выбирается из справочника Организации;
  • Группа – выбирается из справочника Группы детского учреждения;

Примечание. Реквизит Группа доступен только в отчете Ведомость расчетов по родительской плате (по группе). В отчете Ведомость расчетов по родительской плате (списком) реквизит Группа отсутствует.
  • Ребенок – выбирается из справочника Дети;
  • Договор – выбирается из справочника Договоры и иные основания возникновения обязательств;
  • Родитель – плательщик за услуги детского учреждения. Выбирается из справочника Контрагенты;
  • Направление деятельности – выбирается из справочника Направления деятельности;
  • КПС – выбирается из справочника КПС;
  • КФО – выбирается из списка;
  • Воспитатель – выбирается из справочника Сотрудники.

Для доступа к расширенным вариантам отбора и группировки следует нажать кнопку командной панели Настройки.

Формирование отчета

Для формирования отчета можно нажать на кнопку Сформировать.

Сформированный отчет открывается в виде табличного документа, который затем может быть выведен на печать.

В зависимости от варианта группировки в отчете приводятся данные по одному или нескольким учреждениям, с отбором по одному ребенку или по всем детям.

Выводится информация о сальдо по лицевому счету на начало и конец выбранного периода, а также о суммах, начисленных за дни посещения и об оплаченных суммах.

Примечание. При переводе ребенка из одной группы в другую без оформления нового договора в отчете Ведомость расчетов по родительской плате ребенок отображается в той группе, в которую зачислен последним.
Так же, если ребенок оформлен в несколько групп дополнительного образования по одному договору, в отчете Ведомость расчетов по родительской плате ребенок будет отображен в той группе, в которую принят позже.
Это связано с тем, что состояние расчетов определяется по данным бухгалтерских счетов 205.00, расчеты в разрезе групп не ведутся.
