Отчет "Накопительная ведомость по приходу продуктов питания (ф. 0504037)"

Отчет Накопительная ведомость по приходу продуктов питания (ф. 0504037) позволяет получать информацию о поступлении продуктов питания на счета 105.22 и 105.32 по датам в разрезе поставщиков и в разрезе номенклатуры.

Отчет состоит из двух частей:

  • информации об операциях поступления продуктов питания в разрезе поставщиков;
  • информации об операциях поступления продуктов питания в разрезе номенклатуры.

Открыть форму отчета можно с помощью гиперссылки Накопительная ведомость по приходу продуктов питания в форме Отчеты раздела «Услуги, работы, производство», для вызова которой можно использовать команду Отчеты по работам, услугам, производству меню функций раздела Услуги, работы, производство.

Настройка отчета

В форме отчета необходимо заполнить реквизиты:

  • Организация – наименование организации, по данным которой необходимо сформировать отчет. Выбирается из справочника Организации;
  • Период – интервал дат, в котором операции поступления должны отображаться в отчете.

Для продолжения настройки параметров отчета следует с помощью кнопки Настройка командной панели формы отчета открыть форму настроек.

Группа Реквизиты печатной формы:

  • Организация – наименование организации для отображения в шапке отчета. Значение реквизита выбирается из справочника Организации. Выбранное значение не влияет на отбор данных отчета;
  • Подразделение – наименование подразделения для отображения в шапке отчета. Значение реквизита выбирается из справочника Подразделения. Выбранное значение не влияет на отбор данных отчета;
  • Составил (МОЛ) – сотрудник, данные которого подставляются в графу Составил в подвале отчета. Выбирается из справочника Сотрудники;
  • Проверил – сотрудник, данные которого подставляются в графу Проверил в подвале отчета. Выбирается из справочника Сотрудники.

Группа реквизитов Прочие:

  • Формировать приход только от поставщиков – при установке флага в отчете будет отображены данные по приходу продуктов питания только от поставщиков;

Примечание. Операции, в которых продукты появились на счете 105 в результате внутренних причин (например, оприходования излишков по результатам инвентаризации, перемещения от одного МОЛ к другому, ввода остатков и т.п.) в отчет не попадут.
  • Учитывать внутренние обороты – при установке флага в отчете будут отражены операции, в которых продукты появились на счете 105 в результате внутренних причин.

Отбор записей в отчет возможен по полям Организация, ИФО, КПС, КФО, Контрагент, Номенклатура, Счет контрагента, Счет номенклатуры, Период и ЦМО.
