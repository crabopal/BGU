Отчет "Реестр платежных документов"

Отчет Реестр платежных документов предназначен для формирования списка платежных документов, направленных или полученных из казначейства, банка за любой период.

Для вызова отчета можно использовать команду Реестр платежных документов формы Отчеты раздела "Денежные средства", которую можно открыть с помощью команды Отчеты по денежным средствам меню функций раздела Денежные средства.
