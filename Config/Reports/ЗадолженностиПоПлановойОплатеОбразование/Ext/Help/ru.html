Отчет "Задолженность по плановой оплате (образование)"

Отчет предназначен для контроля поступления оплаты по графику, заданному документом Плановые поступления оплаты (образование). Анализ данного отчета позволяет проконтролировать сумму поступивших денежных средств, ожидаемую дату оплаты, а также оплачиваемый период и т. д.

Открытие формы отчета

Открыть форму отчета можно с помощью гиперссылки Задолженность по плановой оплате в форме Отчеты раздела «Платное обучение», для вызова которой можно использовать команду Отчеты по платным образовательным услугам меню функций раздела Платное обучение.

Быстрая настройка отчета
Быстрая настройка отчета позволяет задать Период, настроить отбор данных по Факультету и Учащемуся. Снятие флага Не выводить учащихся без плановых сведений позволит вывести в отчет данные об учащихся, по которым начислена оплата, но не были зарегистрированы плановые поступления.

Для формирования отчета можно использовать кнопку Сформировать.

При формировании отчета программа анализирует введенные документы Плановые поступления оплаты (образование) и поступившую оплату, зарегистрированную документом Распределение оплаты (образование). Сведения в отчете указываются в виде нарастающего итога для выбранного периода и детальных сведений за указанный период.

Примечание. Если в настройках отчета указан период, то выполняется анализ плановых поступлений и оплаты за заданный период. В случае если период не указан, то отчет формируется за весь период времени, за который найдена информация по плановым поступлениям и оплате.
