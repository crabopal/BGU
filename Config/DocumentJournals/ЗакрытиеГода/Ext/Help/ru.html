Журнал "Документы закрытия года"

Журнал Документы закрытия года можно открыть с помощью команды Документы закрытия года меню функций раздела Учет и отчетность.

В журнале предусмотрен отбор по организации и типу документа.

Для создания нового документа следует нажать на кнопку Создать командной панели формы журнала и выбрать необходимый документ в списке:

  • Закрытие балансовых счетов в конце года;
  • Закрытие забалансовых счетов поступлений и выбытий денежных средств;
  • Закрытие счетов санкционирования завершаемого финансового года;
  • Перенос показателей по санкционированию;
  • Формирование остатков по КОСГУ 000;
  • Формирование остатков по счетам расчетов;
  • Формирование остатков по журналам операций.
