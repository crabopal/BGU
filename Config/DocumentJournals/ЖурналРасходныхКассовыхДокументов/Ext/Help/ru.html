Отчет "Журнал регистрации кассовых ордеров"

Отчет Журнал регистрации кассовых ордеров позволяет сформировать и напечатать журнал регистрации приходных и расходных кассовых документов по унифицированной форме № КО-3.

Для вызова отчета можно использовать команду Журнал регистрации кассовых ордеров формы Касса организации раздела Денежные средства.

Журнал регистрации кассовых ордеров формируется отдельно для денежной и фондовой кассы.

Для вывода титульного листа журнала регистрации необходимо установить флаг Вывести титульный лист.

Для формирования отчета следует нажать на кнопку Сформировать.
