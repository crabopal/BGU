Журнал неоплаченных путевок

Для работы с документами, предназначенными для оформления операций с неоплаченными путевками, удобно использовать Журнал неоплаченных путевок.

Открыть Журнал неоплаченных путевок можно с помощью команды Журнал неоплаченных путевок меню функций раздела Денежные средства.

Для отбора по организации и типу документа необходимо указать значения реквизитов:

  • Организация – выбирается из справочника Организации;
  • Тип документа – выбирается из списка.

В журнале отображаются документы типа Поступление неоплаченных путевок, Перемещение неоплаченных путевок и Выбытие неоплаченных путевок.

Для создания нового документа по движению неоплаченных путевок можно использовать кнопку Создать командной панели формы списка.
