Прочитать файлы выписки, выгруженные из ЕБП или повторно обработать файл истории запросов из ЕБП


В данной форме можно загрузить файлы Выписки, выгруженные из ЕБП, а также, при необходимости, повторно обработать документы из файла запросов документов из ЕБП, выгруженного из истории запросов.

В шапке выбрать Организацию и Лицевой счет по которым планируется загрузка файлов.

По кнопке 1.Выбрать файлы - выбрать файлы zip-архивов, выписок, выгруженных из ЕБП, или zip-архив из истории запросов.

По кнопке 2.Обработать файлы - выбранные файлы будут обработаны. 

Особенности загрузки Выписок из ЕБП:

Выписка за одну и туже дату может быть сформирована несколько раз и состав может отличаться (исправляются ошибки, допущенные при обработке документов ЕБП)
При повторной загрузке выписки:
- если ГУИД новой выписки совпадает с идентификатором ранее обработанной - выписка не загрузится
- если ГУИД другой - загрузится следующим образом:
  - будет создана новая выписка
  - в новую выписку будут подтянуты ранее загруженные документы - РСКП, поступления на л/с. Причем ранее загруженные документы перезаписываться не будут, все останется как было после первичной загрузки
  - будут созданы (или переведены в конечный статус) документы, которых в предыдущей выписке не было

Внимание! Документы могут быть исключены из выписки. 
Следует вручную сравнить две выписки самостоятельно найти исключенные документы и решить, что сними делать.
