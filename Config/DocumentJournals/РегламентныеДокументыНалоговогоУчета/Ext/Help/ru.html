Журнал "Регламентные документы налогового учета"

Журнал регламентных документов налогового учета можно открыть с помощью команды Регламентные документы меню функций раздела Налоги.

В журнале предусмотрен отбор по организации и типу документа.

Для создания нового документа следует нажать на кнопку Создать командной панели формы журнала и выбрать необходимый документ в списке:

  • Расчет базы по налогу на прибыль;
  • Расчет налога на прибыль;
  • Закрытие счетов налогового учета.
