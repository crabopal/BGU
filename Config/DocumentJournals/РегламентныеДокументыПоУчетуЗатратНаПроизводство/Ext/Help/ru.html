Журнал Регламентные документы по учету затрат на производство предназначен для работы с документами:

  • Инвентаризация незавершенного производства;
  • Закрытие счетов производственных затрат;
  • Регистрация базы распределения общих затрат;
  • Списание затрат по услугам.

Журнал Регламентные документы по учету затрат на производство можно открыть с помощью команды Регламентные документы (затраты) меню функций раздела Услуги, работы, производство.

В списке предусмотрен отбор по организации и типу документа.

Для создания нового документа можно нажать кнопку Создать командной панели формы и выбрать необходимый тип документа в списке.
