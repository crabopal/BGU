Журнал путевых листов

Журнал путевых листов предназначен для работы со всеми видами путевых листов.

Открыть Журнал путевых листов можно с помощью команды Журнал путевых листов меню функций раздела ГСМ.

Для отбора по организации и виду документа необходимо выбрать значения реквизитов:

Организация – выбирается из справочника Организации;
Тип документа – выбирается из списка и может принимать значения:

  • Путевой лист автобуса (форма № 6);
  • Путевой лист автобуса необщего пользования (форма № 6 спец);
  • Путевой лист грузового автомобиля (форма № 4-П);
  • Путевой лист грузового автомобиля (форма № 4-С);
  • Путевой лист легкового автомобиля (форма № 3);
  • Путевой лист специального автомобиля (форма № 3 спец);
  • Путевой лист строительной машины (форма № ЭСМ-2);
  • Путевой лист трактора (форма № 412-АПК).

Для создания нового путевого листа можно нажать кнопку Создать командной панели формы Журнал путевых листов и выбрать нужный тип документа в форме Выбор типа документа.

Примечание. Для упрощения заполнения путевых листов можно использовать Настройку заполнения документов учета ГСМ. При этом появится возможность автоматически заполнять в общем случае основные реквизиты путевого листа, список водителей, список прицепов, марку и код горючего, быстро заполнять адреса из списка адресов, часто посещаемых транспортным средством.

Например, если для транспортного средства в настройках определен список водителей, то при нажатии на кнопку выпадающего списка появляется возможность быстрого выбора водителя.

Для вызова Настройки заполнения документов учета ГСМ можно использовать команду Настройка заполнения документов учета ГСМ раздела Специализированные подсистемы формы Настройка параметров учета раздела Администрирование.
