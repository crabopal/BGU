При обновлении конфигурации в типовые операции по движению НФА по счетам 101.00, 102.00, 103.00, 105.00, 106.00, 107.00, 108.00 были добавлены реквизиты "Виды движения НФА". Значения данных реквизитов используются при заполнении отчетных форм 0503168/0503768.

В некоторых типовых операциях значение добавленных реквизитов были установлены автоматически в документ и в проводки документа. Во всех остальных случаях следует воспользоваться обработкой "Установка видов движений НФА" для заполнения добавленных реквизитов. Сделать это можно в любое время, в том числе по частям, а не сразу по всем документам.
