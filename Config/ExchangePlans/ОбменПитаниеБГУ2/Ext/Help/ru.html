План обмена "Плановое питание, ред. 2" предназначен для синхронизации данных между информационной базой с конфигурацией из линейки "Плановое питание" (1С:Дошкольное питание, 1С:Школьное питание, 1С:Медицина. Диетическое питание, 1С:Комбинат планового питания, 1С:Плановое питание КОРП) и информационной базой "Бухгалтерия государственного учреждения" редакции 2.0.
