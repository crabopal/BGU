Форма узла обмена "Обмен Питание БГУ2" содержит настройки данного узла обмена для отправки и получения данных:
  • Отбор по организациям - с последующей командой "Выбрать организации" и отметкой нужных записей, участвующих в передаче из БГУ в Питание - фильтр для передачи данных
  • Отбор по контрагентам - с последующей командой "Выбрать контрагентов" и отметкой нужных записей (поставщиков продуктов питания) - фильтр для передачи данных из БГУ в Питание. Данный фильтр необходим при передаче договоров из БГУ в Питание. Если отбор по контрагентам не установлен, договора (из БГУ в Питание) переноситься не будут, т.к. это приведет к передаче всех договоров, большая часть из которых не имеет отношения к Питанию.
  • Правила получения данных: Проводить документы при получении - флажок устанавливают для попытки проведения документов по учету продуктов немедленно по их записи в инфобазу БГУ. По умолчанию флажок не установлен, т.е. рекомендуется, чтобы бухгалтер до проведения в бухучете документов, поступивших от пищеблока, проверял их и при необходимости дозаполнял их данными, неизвестными Кладовщику.
  • Установить дату запрета получения данных - этой командой можно установить дату запрета изменений для документов, получаемых от пищеблока. Такой запрет предохраняет от случайной перезаписи документов прошлых периодов.
 
На служебной закладке формы ("Служебная информация") отображаются номера пакетов принятого и переданного, код узла. Для включения закладки используйте Еще - Настройка формы.
