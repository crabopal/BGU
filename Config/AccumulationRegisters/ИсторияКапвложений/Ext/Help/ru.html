Регистр накопления "История капвложений"

Регистр предназначен для хранения истории карточек капвложений и данных карточек капвложений первого применения:

При начале учета карточек капвложений по остаткам на счетах 106.хх формируются карточки первого применения. Данные этих карточек сохраняются в регистре накопления История капвложений.
При свертке базы любым способом история карточек капвложений будет сохранена в этом регистре автоматически.

  • при свертке способом В документы ввода начальных остатков история карточек будет сохранена документом Ввод истории капвложений.
  • при свертке способом Корректировка регистров данные в регистр будут занесены документом Корректировка регистров.
