Работа со списком

Список полей приказов можно открыть с помощью команды Поля приказов (образование) меню функций раздела Платное обучение.

Создание нового элемента

Для создания нового поля можно нажать на кнопку Создать командной панели формы списка Поля приказов (образование).

Будет добавлено новое поле приказа, в котором необходимо указать реквизиты:

Наименование – наименование поля приказа.

Тип значения – тип значения поля. Выбирается из списка:

  • Вид начисления учащимся за прочие услуги;
  • Группа учащихся;
  • Значения полей приказов;
  • Курсы обучения;
  • Льгота учащегося (воспитанника);
  • Состояния учащихся;
  • Специальность;
  • Ставка оплаты;
  • График оплаты.

Пример. Обучение в учебном заведении ведется по нескольким специальностям, наименования которых требуется отобразить в приказах. Для этого следует создать новое поле приказа с наименованием Специальность и выбрать Значения полей приказов в качестве значения для реквизита Тип значения. После этого с помощью команды Значения полей приказов панели навигации формы Специальность следует открыть форму Значения полей приказов и ввести в табличную часть наименования специальностей – Робототехника, Моделирование и прикладная математика, Квантовая электроника и т.д.
