Настройка отбора по договорам

Форма "Настройка отбора по договорам с контрагентами"

Форма Настройка отбора по договорам с контрагентами предназначена для выбора одного или нескольких договоров для установки отбора в документах, в частности:

  • Списание доходов будущих периодов;
  • Начисление амортизации прав пользования ОС, НПА;
  • Прекращение прав пользования ОС, НПА.

С помощью кнопки Заполнить таблица заполняется списком договоров, по которым есть остатки на соответствующих счетах учета 401.40, 111.40.

Далее следует отметить в списке один или несколько договоров, по которым в документе нужно установить отбор.

Установить или снять все флажки сразу можно, используя кнопки командной панели Установить флажки и Снять флажки.

Для поиска в списке договоров по реквизитам можно использовать кнопки командной панели Найти ... и Отменить поиск.

После нажатия на кнопку Установить отбор в документе будет установлен отбор по договорам, отмеченным флажками.

Кнопка Очистить отбор позволяет очистить отбор по договорам и заполнить далее документ без отбора по договорам.
