Единый справочник "Нормативы расходов подотчетных лиц"

Единый справочник Нормативы расходов подотчетных лиц – это единое рабочее место для просмотра и редактирования нормативов всех видов по командировочным расходам и нормативов по компенсации проезда к месту отпуска (Крайний Север).

В едином справочнике Нормативы расходов подотчетных лиц хранятся сведения о нормативном размере расходов на оплату суточных, проезда и проживания при направлении работников учреждения в командировки по территории Российской Федерации и на территории иностранных государств, которые установлены локальным актом учреждения, а также сведения о нормативах компенсации оплаты стоимости проезда к месту использования отпуска и обратно, установленных законодательством Российской Федерации для лиц, работающих в районах Крайнего Севера и приравненных к ним местностях, и членов их семей.

Работа со списком

Единый справочник Нормативы расходов подотчетных лиц можно открыть с помощью команды Нормативы расходов подотчетных лиц меню функций раздела Денежные средства, подраздела Расчеты с подотчетными лицами.

В едином справочнике Нормативы расходов подотчетных лиц предусмотрен отбор по реквизиту Организация.

Для разных видов нормативов командировочных расходов предусмотрены отдельные закладки единого справочника Нормативы расходов подотчетных лиц:

  • для норматива на оплату суточных – закладка Суточные;
  • для норматива на оплату проезда – закладка Проезд;
  • для норматива на оплату проживания – закладка Проживание.

Важно. Сведения об утвержденных в учреждении нормативах суточных, проезда и проживания следует внести в единый справочник Нормативы расходов подотчетных лиц до оформления документов Решение о командировании, Решение о компенсации (Крайний Север).

Справочник "Норматив суточных"

Справочник Норматив суточных предназначен для хранения сведений о нормативном размере расходов на оплату суточных с учетом поправок, установленных локальным актом учреждения.

Справочник Норматив суточных разделен на отдельные закладки:

  • закладка Командировки – для заполнения сведений об основных нормативах суточных;
  • закладка Дополнительные условия – для установки поправок к основным нормативам суточных;
  • закладка Надбавки в загранкомандировках – для установки набавки суточных в загранкомандировках.

Создание нового элемента

На закладках Командировки, Дополнительные условия, Надбавки в загранкомандировках для ввода нового элемента справочника Норматив суточных, в том числе Дополнительного условия (поправки к нормативу суточных) и Набавки суточных в загранкомандировках можно нажать кнопку Создать.

Закладка "Командировки"

На закладке Командировки вводятся действующие Нормативы суточных, установленные в соответствии со статьей 168 ТК РФ, заполняются реквизиты:

  • Действует с – дата начала применения норматива суточных. По умолчанию – текущая дата;
  • Организация – по умолчанию поле заполнено текущей организацией. Поле обязательно для заполнения;
  • Страна – страна, при командировании на территорию которой действует норматив суточных (выбирается из справочника Страны мира). По умолчанию – "любая страна";
  • Территория – территория с отдельным нормативом суточных (выбирается из справочника Территории с отдельным нормативами). По умолчанию – "вся территория";

Примечание. Поле Территория заполняется для конкретной страны - после заполнения поля Страна.
  • Вид договора – вид договора с работником, для которого действует норматив суточных. Выбирается из списка, доступны варианты: Трудовой договор, Контракт госслужащего, Договор муниципального служащего, Контракт военнослужащего, Военнослужащий по призыву. По умолчанию – "любой вид договора";
  • КФО – код вида финансового обеспечения, за счет которого выплачиваются суточные. Если поле не заполнено, нормативное значение суточных применяется для любого КФО;
  • Сумма – нормативное значение расходов на оплату суточных, установленное локальным актом учреждения;
  • Валюта – валюта, в которой выплачиваются суточные.

Флаг Оплачиваются однодневный командировки – если установлен, то однодневные командировки тоже оплачиваются.

Для сохранения созданного норматива суточных следует нажать на кнопку Записать и закрыть или Записать.

Закладка "Дополнительные условия"

На закладке Дополнительные условия справочника Норматив суточных вводятся дополнительные условия (поправки к нормативу суточных), при которых нормативное значение суточных, указанное на закладке Командировки, корректируется.

Заполняются реквизиты:

  • Дополнительное условие – описание дополнительного условия, при котором нормативное значение суточных, указанное на закладке Командировки, корректируется (например: ежедневное возвращение к месту проживания, оплата за счет принимающей стороны и т.д.);
  • Процент изменения – значение (в процентах), на которое при выбранном дополнительном условии должен быть увеличен стандартный размер суточных, указанный на закладке Командировки и принимаемый за 100%.

Например,

  • если Процент изменения равен 25, то суточные должны быть выплачены в размере 125%;
  • если Процент изменения равен 150, то суточные должны быть выплачены в размере 250%;
  • если Процент изменения равен 700, то суточные должны быть выплачены в размере 800%.

Для сохранения созданного Дополнительного условия (поправки к нормативу суточных) следует нажать на кнопку Записать и закрыть или Записать.

Примечание. Данные, заранее внесенные в справочник Нормативы суточных с учетом дополнительного условия, автоматически отражаются в документе Решение о командировании:
– в графе Норматив (суточные) закладки Место и сроки и корректировке не подлежат;
– в графе Норматив закладки Суточные и могут быть скорректированы вручную.

Закладка "Надбавки в загранкомандировках"

На закладке Надбавки в загранкомандировках справочника Норматив суточных вводятся размеры надбавок к суточным в иностранной валюте, выплачиваемых отдельным категориям работников, военнослужащих в период пребывания в служебных командировках на территориях иностранных государств. Например, для работника с особым статусом «руководитель правительственной делегации» надбавка к суточным составляет 50% (Приложение № 2 к постановлению Правительства РФ от 26.12. 2005 № 812).

Заполняются реквизиты:

  • Особый статус – особый статус, при котором работнику выплачивается надбавка к суточным (выбирается из справочника Особые статусы командированных);
  • Размер надбавки, % – значение надбавки к суточным (в процентах).

Для сохранения Надбавки суточных в загранкомандировках следует нажать на кнопку Записать и закрыть или Записать.

Справочник "Норматив проезда"

Справочник Норматив проезда предназначен для хранения сведений о нормативном размере расходов на оплату проезда к месту командирования и обратно, а также для лиц, работающих в районах Крайнего Севера и приравненных к ним областях - о нормативном размере расходов на оплату проезда к месту отдыха и обратно, установленных локальным актом учреждения.

Справочник Норматив проезда разделен на отдельные закладки:

  • закладка Командировки – для заполнения сведений о нормативе проезда к месту командирования;
  • закладка Отпуск (Крайний Север) – для заполнения сведений о нормативе проезда к месту отдыха и обратно для лиц, работающих в районах Крайнего Севера и приравненных к ним областях.

Создание нового элемента

На закладках Командировки, Отпуск (Крайний Север) для ввода нового норматива проезда к месту командирования и обратно, к месту отдыха и обратно можно нажать кнопку Создать.

Закладка "Командировки"

На закладке Командировки справочника Норматив проезда вводятся сведения о нормативном размере расходов на оплату проезда к месту командирования и обратно.

Заполняются реквизиты:

  • Действует с – дата начала применения норматива проезда. По умолчанию – текущая дата;
  • Организация – по умолчанию поле заполнено текущей организацией. Поле обязательно для заполнения;
  • Вид транспорта – вид транспорта, для которого действует норматив проезда. Выбирается из списка, доступны варианты: Воздушный, Железнодорожный, Морской, Автомобильный, Речной, Служебный, Личный, Иной. Поле обязательно для заполнения;
  • Вид договора – вид договора с работником, для которого действует норматив проезда. Выбирается из списка, доступны варианты: Трудовой договор, Контракт госслужащего, Договор муниципального служащего, Контракт военнослужащего, Военнослужащий по призыву. По умолчанию – "любой вид договора";
  • Особый статус – особый статус работника, для которого действует норматив проезда (выбирается из справочника Особые статусы командированных). Если поле не заполнено, норматив проезда действует для любого особого статуса;
  • Категория – нормативная категория проезда для указанного Вида транспорта. Выбирается из справочника Виды проезда.

Для контракта госслужащего можно уточнить:

  • Категорию должности – категория должности госслужащего. Выбирается из списка, доступны варианты: Руководители, Помощники (советники), Специалисты, Обеспечивающие специалисты. По умолчанию – "любая категория должности";
  • Группу должности – группа должности госслужащего. Выбирается из списка, доступны варианты: Высшие, Главные, Ведущие, Старшие, Младшие. По умолчанию – "любая группа должности".

Для сохранения созданного норматива проезда к месту командирования и обратно следует нажать на кнопку Записать и закрыть или Записать.

Справочник "Норматив проживания"

Справочник Норматив проживания предназначен для хранения сведений о нормативном размере расходов на оплату проживания (или категории проживания) в месте командирования, установленном локальным актом учреждения.

Создание нового элемента

Для ввода нового элемента справочника Норматив проживания можно нажать кнопку Создать командной панели на закладке Командировки.

Закладка "Командировки"

На закладке Командировки вводятся действующие Нормативы проживания, установленные локальным актом учреждения, заполняются реквизиты:

  • Действует с – дата начала применения норматива суточных. По умолчанию – текущая дата;
  • Организация – по умолчанию поле заполнено текущей организацией. Поле обязательно для заполнения;
  • Условие проживания – условие проживания в месте командирования, для которого применяется норматив проживания (выбирается из справочника Условия проживания командированных). Поле обязательно для заполнения;
  • Страна – страна, при командировании на территорию которой действует норматив суточных (выбирается из справочника Страны мира). По умолчанию – "любая страна";
  • Территория – территория с отдельным нормативом суточных (выбирается из справочника Территории с отдельным нормативами). По умолчанию – "вся территория";

Примечание. Поле Территория заполняется для конкретной страны – после заполнения поля Страна.
  • Вид договора – вид договора с работником, для которого действует норматив суточных. Выбирается из списка, доступны варианты: Трудовой договор, Контракт госслужащего, Договор муниципального служащего, Контракт военнослужащего, Военнослужащий по призыву. По умолчанию – "любой вид договора";
  • Особый статус – особый статус работника, для которого действует норматив проезда (выбирается из справочника Особые статусы командированных). Если поле не заполнено, норматив проезда действует для любого особого статуса.

Вид норматива – может принимать значения:

  • Стоимость – применяется для установления норматива по стоимости проживания в сутки при выбранном Условии проживания;
  • Категория – применяется для установления норматива проживания по категории проживания при выбранном Условии проживания.

Вид норматива (Стоимость):

  • Сумма – нормативное значение расходов на оплату проживания в сутки, установленное локальным актом учреждения;
  • Валюта – валюта, в которой оплачиваются расходы на проживание.

Вид норматива (Категория):

  • Категория – нормативная категория проживания для выбранного Условия проживания, установленная локальным актом учреждения.

Для сохранения созданного норматива проживания следует нажать на кнопку Записать и закрыть или Записать.
