Настройка отбора по договорам

Форма предназначена для выбора одного или нескольких договоров для установки отбора в документах, в частности:

  • Списание доходов будущих периодов;
  • Начисление амортизации прав пользования ОС, НПА;
  • Прекращение прав пользования ОС, НПА;

По кнопке Заполнить таблица заполняется списком договоров, по которым есть остатки на соответствующих счетах учета 401.40, 111.40.

Затем следует отметить в списке один или несколько договоров, по которым нужно установить отбор в документе. Снять или установить все флажки сразу можно, используя кнопки командной панели Установить флажки и Снять флажки. Для поиска договоров в списке по реквизитам можно использовать кнопки командной панели Найти ... и Отменить поиск.

По кнопке Установить отбор в документе будет установлен отбор по договорам, отмеченным флажками. По кнопке Очистить отбор в документе будет очищен отбор по договорам, и заполнение документа будет производиться без отбора по договорам.
