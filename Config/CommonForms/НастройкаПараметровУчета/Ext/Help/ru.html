Настройка параметров учета

Перед началом работы необходимо настроить параметры учета. Форма для настройки параметров учета вызывается с помощью команды Настройка параметров учета меню функций раздела Администрирование.

Все настройки сгруппированы в нескольких разделах формы. Для перехода между разделами используются гиперссылки в левой части формы Настройка параметров учета.

Раздел "Общие настройки"

Основная организация. Наименование организации, которое будет подставляться в новые документы и справочники. Эта настройка имеет значение только для пользователей, у которых не задана организация по умолчанию и ее можно изменить в любое время.

Примечание. При создании документа или справочника можно поменять организацию, подставленную по умолчанию, на другую. Для изменения текущей организации в текущем сеансе можно использовать форму Текущая организация на Начальной странице.

Валюта регламентированного учета. Не изменяется пользователем. В качестве валюты регламентированного учета выбран российский рубль.

Учет расчетов и обязательств в иностранных валютах. Влияет на возможность выбора в документах иностранных валют. Если не разрешено использование иностранных валют, то в интерфейсе отсутствует справочник Валюты и в документах и отчетах нет возможности выбора валюты.

Внимание!
Не рекомендуется отключать учет расчетов и обязательств в иностранных валютах, когда в системе уже есть документы, в которых выбрана валюта, отличная от валюты регламентированного учета. Это может привести к невозможности исправления валюты в документах, просмотра отчетов в валютных суммах и неверного проведения уже созданных в системе документов в иностранных валютах.

Учет по ИФО. Влияет на возможность использования источников финансового обеспечения – дополнительной аналитики в документах и бухгалтерских проводках. Если флажок установлен, то указание источника финансового обеспечения обязательно.

Использование учета по ИФО позволяет дополнительно детализировать учет на уровне источников финансового обеспечения в рамках одной организации. Источники финансового обеспечения являются балансовыми разделителями учета наравне со справочником Организации.

Внимание!
Решение о необходимости в использовании учета по ИФО должно быть принято до начала ведения учета. Если в системе были созданы документы, то изменение режима использования учета по ИФО может потребовать ввода дополнительной информации и перепроведения всех документов, формирующих бухгалтерские проводки.

Учет по подразделениям. Влияет на возможность использования подразделений организации в качестве дополнительной аналитики в бухгалтерских проводках. Включение опции позволяет настроить использование учета по подразделениям в плане счетов.

Формирование проводок обособленно от документа. Влияет на режим формирования бухгалтерской операции документа – одновременно с проведением документа или обособленно, с использованием специализированной формы. Данную настройку можно изменить в любое время.

Примечание. При выключении режима формирования проводок обособленно от документа необходимо перепровести документы, которые были проведены, но бухгалтерские проводки для которых не сформированы.

Раздел "Ведение учета"

Группа Контроль операций на соответствие РПС.
Флажок Контролировать операции на соответствие рабочему плану счетов. Влияет на возможность контроля соответствия реквизитов проводок рабочему плану счетов при проведении документов.

Группа Контроль расходов.
Флажок Контролировать расходы. Влияет на возможность контроля за непревышением расходов по обязательствам и денежным обязательствам, лимитам бюджетных обязательств, бюджетным ассигнованиям, предельным объемам финансирования, статьям плана финансово-хозяйственной деятельности. Включение опции позволяет настроить параметры контроля и действия, которые будут выполняться программой по результатам контроля.

Группа Контроль исполнения договоров.
Флажок Вести и контролировать исполнение графиков по договорам с контрагентами. Влияет на возможность ведения и контроля исполнения графиков платежей, плановых графиков закупок и реализации по договорам с поставщиками (кредиторами) и покупателями (дебиторами), на возможность контроля просроченной задолженности.

В группе реквитов Использовать дополнительную аналитику в графиках платежей можно настроить детализацию графиков платежей по аналитическим разрезам: Доп. классификация, Код мероприятия, Код цели, установив флажки с покупателями (дебиторами) и с поставщиками (кредиторами).

Внимание!
В базовой версии программы «1С:Бухгалтерия государственного учреждения 8», редакция 2 возможность ведения и контроля исполнения договоров недоступна!

Группа Развернутое сальдо по активно-пассивным счетам.
Настроить развернутое сальдо – гиперссылка для вызова списка, в котором следует задать порядок формирования развернутого сальдо по активно-пассивным счетам в регламентированных регистрах Главная книга, Журнал операций в соответствии с порядком формирования развернутого сальдо в регламентированных бухгалтерских отчетах. Эту настройку можно будет далее загрузить в стандартный отчет Оборотно-сальдовая ведомость.

Группа Учет авансов по документам оплаты.
Настроить учет выданных поставщикам авансов по документам оплаты – гиперссылка для вызова формы для настройки учета на счетах плана счетов авансов, выданных поставщикам, по документам оплаты.

Применяемые структуры РПС.
Таблица, позволяющая настроить структуры используемых рабочих планов счетов для всех учреждений любых типов — автономных, бюджетных и казенных.

Группа Внутренний электронный документооборот.

Подсистема внутреннего электронного документооборота недоступна в КОРП версии.

Группа реквизитов Формирование бухгалтерской справки:

  • Не включать данные по забалансовым счетам в бухгалтерскую справку. Влияет на формирование бухгалтерской справки ф. 0504833. В справку не будут включаться проводки по забалансовым счетам. Данную настройку можно изменить в любое время.
  • Выводить только бухгалтерские счета в справке. Влияет на формирование бухгалтерской справки ф. 0504833. В справку будут включаться только бухгалтерские счета. Данную настройку можно изменить в любое время.
  • Не выводить итоговую сумму в бухгалтерской справке. Влияет на формирование бухгалтерской справки ф. 0504833. В справку не будет выводиться общий итог по всем проводкам. Данную настройку можно изменить в любое время.

Гиперссылка Настроить вывод итогов по балансовым и забалансовым проводкам ф. 0504833 открывает группу Настройки вывода итогов:

  • Выводить общий итог по балансовым и забалансовым счетам в бухгалтерской справке. Имеет смысл, только если выводится итоговая сумма в бухгалтерской справке. Выводится одна итоговая сумма, включающая и балансовые, и забалансовые счета. Данную настройку можно изменить в любое время.
  • Выводить раздельно итоги по балансовым и забалансовым счетам в бухгалтерской справке. Имеет смысл, только если выводится итоговая сумма в бухгалтерской справке. Выводится отдельно итог по балансовым счетам, отдельно – по забалансовым. Данную настройку можно изменить в любое время.

Раздел "Денежные средства"

Группа Фондовая касса:

  • Вести количественный учет денежных документов. При включенной опции в приходных и расходных кассовых ордерах необходимо указывать количество денежных документов.

Внимание!
Если в системе уже введены документы по учету денежных документов, то после включения опции потребуется ввести недостающую информацию в документы и перепровести их.
  • Фондовая кассовая книга ведется отдельно от денежной. Влияет на порядок заполнения отчетов кассира. После включения опции для отчетов кассира по фондовой кассе будет использоваться отдельный вид документа – Отчет кассира (фондовый).

Внимание!
Если в системе уже введены кассовые документы, то изменение опции может привести к невозможности изменения уже созданных отчетов кассира.

  • Параметры договора эквайринга;
  • Настройки ККТ и эквайринга для рабочих мест.

Группа Настройки формирования чеков ККТ (54-ФЗ):

  • Флажок Использовать настройки платежного агента. Влияет на возможность исполнения организацией функций платежного агента.
  • Флажок Отправлять электронные чеки ККТ по расписанию. Влияет на возможность настройки отправки по расписанию чеков ККТ с помощью электронной почты и SMS непосредственно из программы, не прибегая к услугам оператора фискальных данных.

Раздел "Обмен данными и интеграция"

Группа Интеграция с «1С:Зарплата и кадры государственного учреждения», редакция 3.0

Для автоматического формирования документов Отражение зарплаты в учете и Начисление резервов по отпускам в процессе их импорта из конфигурации «1С:Зарплата и кадры государственного учреждения», редакция 3.0 необходимо выполнить настройку статей финансирования и способов отражения заработной платы в учете.

  • Настроить статьи финансирования – команда для вызова справочника Статьи финансирования с целью настройки всех начислений, которые применяются в учреждении.
  • Настроить способы отражения в учете – команда для вызова справочника Способы отражения зарплаты в бухгалтерском учете с целью создания настроек, которые необходимы для формирования проводок по заработной плате в программе "1С:Бухгалтерия государственного учреждения 8", редакция 2.0.

Группа Интеграция с информационными системами учета и начисления платежей:

Интеграция с ИС РНИП или ИС УНП. Флажок влияет на возможность взаимодействия с ИС РНИП или ИС УНП.

Внимание!
При отключении интеграции с системой учета начислений и платежей (фактов оплаты) становится недоступен просмотр созданных в данной подсистеме документов.

Интеграция с ГИС ГМП. Флажок влияет на возможность взаимодействия с ГИС ГМП.

Внимание!
При отключении интеграции с государственной информационной системой о государственных и муниципальных платежах становится недоступен просмотр созданных в данной подсистеме документов.
  • Взаимодействие с ГИС ГМП через базу главного администратора доходов. После выбора опции документы начислений передаются в базу главного администратора начислений (ГАН). Документы полученных платежей загружаются их базы ГАН;
  • Передавать в ГИС ГМП начисления подведомственных. После выбора опции в ГИС ГМП будут передаваться начисления подведомственных администраторов начислений, загруженных в данную информационную базу по планам обмена.
  • Взаимодействие с ГИС ГМП Администраторов запросов. После выбора опции для участников с ролью администратора запросов появляется возможность взаимодействия с ГИС ГМП в формате 2.0 (и выше), в т.ч. создание запросов начислений/платежей, просмотр ранее отправленных запросов и результатов ответа от сервиса.

В подгруппе Настройка подписи сообщений можно выбрать, где будет выполняться подпись – на клиенте или на сервере.

  • Подписывать сообщения на сервере – настройка применяется если используется клиент – серверная база. Если флажок установлен подпись xml сообщений будет выполняться на сервере. Если же флажок не установлен, то подпись будет выполняться на клиенте.
  • Обращаться к TSA серверу на сервере – настройка применяется для взаимодействия с ГИС ГМП по форматам 1.16. Если флажок установлен, обращение к TSA серверу выполняется с сервера, если не установлен, то с клиента.

Группа Интеграция с системой учета имущества:

Интеграция с системой учета имущества. После установки флажка становится доступна подсистема Реестр имущества. После выбора опции Настройки подсистемы Реестр имущества находятся на поддержке настройки подсистемы для обмена данными с автоматизированной системой учета федерального имущества (АСУФИ) будут обновляться при обновлении конфигурации.

Группа Интеграция с 1С:Документооборот:

Настройка интеграции – команда для вызова формы Интеграция с 1С:Документооборотом, которая предназначена для организации работы с входящими, внутренними и исходящими документами, использования процессов, задач и других возможностей решения 1С:Документооборот.

Группа Интеграция с 1С:Вещевое довольствие 8. Предназначена для настройки аналитики и правил загрузки документов движения имущества из программы "1С:Вещевое довольствие":

  • Операции учета вещевого довольствия – команда для вызова справочника Операции учета вещевого довольствия;
  • Статьи аналитики вещевого довольствия – команда для вызова справочника Статьи аналитики вещевого довольствия.

Группа Электронный документооборот с контрагентами: Обмен электронными документами (акты выполненных услуг, накладные ТОРГ-12, счета-фактуры, счета на оплату).

Настройка обмена электронными документами. Включение опции позволяет настроить обмен электронными документами, такими как акты выполненных услуг, накладные ТОРГ-12, счет-фактуры, счета на оплату.

Настройка интеграции с сервисом 1С:Номенклатура. Включение опции используется для интеграции с сервисом 1С:Номенклатура и позволяет:

  • загружать и обновлять карточки номенклатуры и категорий номенклатуры из облачного каталога сервиса;
  • заполнять данные справочников Номенклатура и Основные средства, НМА, НПА по загруженным сведениям о товарах и услугах;
  • связывать номенклатуру сервиса и элементы справочников Номенклатура и Основные средства, НМА, НПА для автоматического сопоставления при получении электронных документов, содержащих идентификаторы номенклатуры сервиса.

Внимание!
Перед началом использования сервиса 1С:Номенклатура необходимо быть зарегистрированным на Портале "1С:ИТС" и подключить пакет карточек в личном кабинете пользователя.

Группа Интеграция с 1С:Свод отчетов 8:

  • Интеграция с 1С:Свод отчетов 8. Флажок влияет на возможность экспортировать в "1С:Свод отчетов" регламентированные бухгалтерские отчеты через web-сервис, импортировать протоколы проверки и обработки отправленных отчетов, получать информацию о статусе отправленных отчетов, а также загружать опубликованные комплекты регламентированной бухгалтерской отчетности.
  • Выгружать данные автозаполнения отчетов в формате Свод отчетов 2.0. Флажок влияет на возможность выгрузки сохраненных данных автозаполнения отчета, если они существуют, в формате "Свод отчетов 2.0".

Группа Обмен данными с офлайн оборудованием. Флажок Использовать обмен с офлайн оборудованием.

В результате включения опции в разделе Денежные средства появится команда для вызова формы Обмен с офлайн оборудованием. Данная форма предназначена для экспорта сведений о товарах, услугах, работах и ценах в офлайн-ККМ, а также для импорта из офлайн-ККМ данных о продажах в виде документа Отчет по кассовой смене.

Группа Интеграция с ВетИС (Меркурий). Используется для интеграции с государственной информационной системой в области ветеринарии ВетИС (Меркурий). Настройки интеграции с ВетИС (Меркурий) – гиперссылка для вызова формы Настройки интеграции с ВетИС.

Раздел "Специализированные подсистемы"

Группа Учет продуктов питания.

Флажок Учет продуктов питания. Влияет на возможность ведения учета продуктов питания. После установки флажка в меню функций раздела Услуги, работы, производство отображаются справочники и документы подсистемы Учет питания.

Внимание!
При отключении ведения учета продуктов питания подсистема Учет питания становится недоступна. При этом ранее введенные документы по учету питания можно будет просмотреть только в журнале операций.

Группа Учет расчетов за содержание детей в ДДУ.

Флажок Учет расчетов с родителями за содержание детей в ДДУ. Влияет на возможность ведения учета расчетов с родителями за содержание детей в детских дошкольных учреждениях. После установки флажка в меню функций раздела Платное обучение отображаются команды для вызова справочников и документов подсистемы Родительская плата.

Внимание!
При отключении ведения учета расчетов с родителями за содержание детей в детских дошкольных учреждениях подсистема Родительская плата становится недоступна. При этом ранее введенные документы по учету расчетов с родителями можно будет просмотреть только в журнале операций.

Группа Учет расчетов по образовательным услугам.

Флажок Учет расчетов по образовательным услугам. Влияет на возможность ведения учета расчетов по образовательным услугам. После установки флажка в меню функций раздела Платное обучение отображаются команды для вызова справочников и документов подсистемы Образовательные услуги.

Внимание!
При отключении ведения учета образовательных услуг подсистема Образовательные услуги становится недоступна. При этом ранее введенные документы данной подсистемы можно будет просмотреть только в журнале операций.

Группа Учет горюче-смазочных материалов.

Флажок Учет горюче-смазочных материалов.Влияет на возможность ведения учета горюче-смазочных материалов. При включении опции в панели разделов появляется раздел ГСМ.

  • Настройка округления результата расчета нормативного расхода ГСМ – гиперссылка для вызова формы Настройки округления результата расчета нормативного расхода ГСМ.
  • Настройка заполнения документов учета ГСМ – гиперссылка для вызова формы Настройки заполнения документов учета ГСМ. Данная форма позволяет создать для каждого транспортного средства шаблоны заполнения путевых листов, содержащие часто используемые реквизиты.
  • Настройка отражения затрат на ГСМ – гиперссылка для вызова формы Настройка отражения затрат на ГСМ, предназначенной для настойки отражения затрат на ГСМ на счетах бухгалтерского учета.

Группа Учет имущества казны.

Флажок Учет имущества казны. Влияет на возможность ввода документов учета имущества казны. При включении опции на панели разделов появляется раздел Имущество казны, в учетной политике появляются настройки особенностей учета имущества казны для каждой организации.

Внимание!
При отключении опции подсистема Имущество казны становится недоступна. При этом документы данной подсистемы, введенные ранее, можно просмотреть только в журнале операций.

Группа Учет государственных контрактов.

Флажок Учет государственных контрактов (договоров, соглашений). Влияет на возможность ведения перечня заключенных контрактов (договоров, соглашений) и расчетов по ним. После установки флажка в разделе Планирование и санкционирование произойдут необходимые изменения.

Флажок Учет расчетов по контрактам при банковском или казначейском сопровождении. Влияет на возможность открытия отдельных лицевых счетов (разделов лицевых счетов) для расчетов по исполнению государственных контрактов (договоров, соглашений), в том числе заключенных в целях выполнения государственного оборонного заказузаказа и получения информации о структуре кооперации и кассовом исполнении данных контрактов (договоров, соглашений).

Группа Учет кредитов, займов, долговых обязательств.

Флажок Учет кредитов, займов, долговых обязательств. Влияет на возможность ведения учета расчетов по кредитам, займам (ссудам) и долговым обязательствам.

Группа Учет прослеживаемых товаров.

Флажок Вести учет прослеживаемых товаров. Влияет на возможность ведения учета прослеживаемых товаров в соответсвии с Федеральным законом 09.11.2020 № 371-ФЗ.
