Справочник "Юридические лица"

Справочник Юридические лица предназначен для хранения списка сторонних юридических лиц.

Работа со списком

Список юридических лиц можно открыть с помощью команды Юридические лица меню функций раздела Справочники.

Создание нового элемента

Для ввода нового элемента справочника можно использовать кнопку Создать командной панели формы списка Юридические лица.

Другой способ создания карточки Юридического лица предусматривает ввод нового элемента в справочник Контрагенты, у которого реквизит Вид контрагента будет иметь значение Юридическое лицо.

После ввода и записи значений реквизита Официальное наименование, а также иных реквизитов в карточке контрагента, в справочнике Юридические лица появится карточка юридического лица, в которой реквизит Официальное наименование и другие реквизиты будут заполнены.

С другой стороны, если карточка юридического лица в справочнике Юридические лица содержит заполненные реквизиты, то после выбора в справочнике Контрагенты значения Наименование из справочника Юридические лица значения заполненных реквизитов будут скопированы в соответствующие поля карточки контрагента.

Заполнение реквизитов элемента справочника


В поле Наименование указывается рабочее наименование юридического лица, для отображения в списках.

Официальное название юридического лица указывается в поле Официальное наименование.

В поле Страна регистрации указывается страна, в которой зарегистрировано юридическое лицо. Выбирается из справочника Страны мира.

Если юридическое лицо зарегистрировано в иностранном государстве, то для заполнения станут доступны реквизиты Наименование латиницей и Налоговый номер.

Так же в справочнике заполняются регистрационные коды:

  • Глава по БК – код главы по перечню прямых получателей.
  • Бюджет – наименование бюджета.
  • Код по РПБС – код по реестру получателей бюджетных средств.
  • Распорядитель (вышестоящее учреждение) – распорядитель (главный распорядитель) юридического лица, выбирается из справочника Контрагенты.
  • ИНН – идентификационный номер налогоплательщика. Заполняется в соответствии с порядком, утвержденным приказом МНС РФ от 03.03.2004 № БГ-3-09/178.
  • КПП – код причины постановки на учет. Заполняется в соответствии с порядком, утвержденным приказом МНС РФ от 03.03.2004 № БГ-3-09/178.
  • ОГРН – основной государственный регистрационный номер, присвоенный юридическому лицу в едином государственном реестре.
  • Дата регистрации – дата регистрации юридического лица в едином государственном реестре.
  • Код ОКПО – код организации по ОКПО.
