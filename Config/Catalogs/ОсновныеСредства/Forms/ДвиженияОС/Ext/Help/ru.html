Данные регистров по ОС, НМА, НПА


Форма показывает движения по выбранному ОС по всем регистрам. Это удобно для анализа данных и выявления причин различных проблем. В отчете предусмотрена возможность маскирования персональных данных, удобно в случае передачи данных для анализа на сторону.

По всем регистрам выводятся записи регистров. Исключение составляет регистр бухгалтерии Журнал проводок (ЕПСБУ) - по нему выводятся остатки. Остатки выводятся на дату, указанную в поле Остатки на дату.
Чтобы вывести замаскированные данные, необходимо установить флажок Замаскировать персональные данные и переформировать отчет по кнопке Сформировать.
Маскируются данные типов:
  • Справочник Центры материальной ответственности
  • Справочник Подразделения
  • Справочник Контрагенты
При маскировании не выводятся данные регистров сведений Сведения кадастрового учета и Паспорта транспортных средств.
