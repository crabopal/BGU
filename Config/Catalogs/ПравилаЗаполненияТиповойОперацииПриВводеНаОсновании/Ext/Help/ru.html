Тумблер "Отключена/Используется" позволяет отключить правила, которые не нужно использовать.
Например, поставляемые правила нельзя удалить. Их можно только отключить.

Основание - тип документа или справочника, на основании которого вводится новый документ. Ограничен типами, на основании которых можно вводить документы;
Вводимый документ - тип вводимого документа. Ограничен типами, которые вводятся на основании выбранного типа основания.

Фильтр по реквизитам документа-основания - значения реквизитов основания, при которых будет использоваться данное правило.

Типовая операция основания - если выбрана, то правило будет использоваться только при вводе на основании документов с указанной типовой операцией.

Фильтр по дополнительным реквизитам операции - значения дополнительных реквизитов операции, при которых будет использоваться данное правило.

Типовая операция - типовая операция, которая будет подставлена в новый документ.

Таблица Реквизиты операции - значения дополнительных реквизитов операции. Можно указать следующие правила заполнения:
  • Реквизит документа - реквизит документа-основания, из которого берется значение.
  • Значение реквизита - конкретное значение, которое будет установлено.
  • Реквизит операции основания - дополнительный реквизит операции документа основания, из которого берется значение.

    • Если в строке реквизита типовой операции заполнены несколько колонок, то будет использоваться первое заполненное значение в следующей последовательности:
    • Реквизит документа,
    • Реквизит операции,
    • Значение реквизита.

    Если правило заполнения дополнительного реквизита операции не задано, то реквизит заполняется как при выборе типовой операции в документе. Будет заполнено значение по-умолчанию, если оно задано в настройках типовой операции или было установлено обработкой "Установка типовых операций и значений реквизитов операций по умолчанию".
