Справочник "Варианты меню"

Справочник применяется для ведения списка вариантов меню, используемых в организации.

Это могут быть варианты меню для разных диетических столов, групп питающихся и т.д. Классификация меню в справочнике произвольная.

Вариант меню представляет собой пронумерованный набор типовых меню, которые не повторяются в пределах некоторого цикла питания.

Цикл питания две недели, например, означает, что в пределах двух недель меню повторяться не будет. Повторение меню начнется с третьей недели, то есть с началом нового цикла

Работа со списком

Справочник Варианты меню можно открыть с помощью команды Варианты меню меню функций раздела Услуги, работы, производство.

Создание нового элемента

Для добавления в справочник нового элемента можно нажать на кнопку Создать командной панели формы Варианты меню.

Заполнение реквизитов элемента справочника

  • Наименование – произвольное наименование варианта меню в виде текста;
  • Текущий порядок – целое число, определяющее номер типового дневного меню в цикле питания. Может принимать значения в диапазоне от 1 до числа, равного максимальному количеству дневных меню, предусмотренных для данного варианта меню.

Заполнение реквизитов табличной части

В табличную часть Типовые меню для каждого дневного меню вводятся данные о приемах пищи, блюдах и т.п.

  • Прием пищи – выбирается из списка Приемы пищи;

Чтобы выбор реквизита Прием пищи был возможен, справочник Приемы пищи необходимо заполнить до ввода данных в справочник Варианты меню.
  • Блюдо – готовое блюдо, входящее в меню. Выбирается из справочника Номенклатура;

Для выбора доступны только те элементы номенклатуры, у которых реквизит Тип номенклатуры имеет значение Готовое блюдо.
  • Спецификация – вариант рецепта для выбранного готового блюда. Выбирается из справочника Спецификации номенклатуры;

Примечание. Для каждого блюда в программе может храниться несколько вариантов рецепта.
  • Выход – вес готового блюда. Задается в единице измерения, указанной в карточке готового блюда в справочнике Номенклатура.

После заполнения табличной части Типовые меню для текущего номера дневного меню, заданного в реквизите Текущий порядок, введенные данные необходимо сохранить с помощью кнопки Записать объект командной панели формы элемента.

Затем необходимо с помощью кнопки Добавить выбрать новое значение реквизита Текущий порядок и заполнить табличную часть для нового значения реквизита, и т.д. до тех пор, пока не будут введены все дневные меню для данного варианта меню.
