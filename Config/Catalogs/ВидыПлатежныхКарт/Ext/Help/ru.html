Справочник "Виды платежных карт"

Справочник Виды платежных карт предназначен для хранения перечня видов платежных карт, принимаемых к оплате по договорам эквайринга.

Работа со списком

Список Виды платежных карт можно открыть с помощью команды Виды платежных карт раздела Денежные средства формы Настройка параметров учета раздела Администрирование.

Создание нового элемента

Для ввода вида платежной карты можно нажать кнопку Создать командной панели формы списка Виды платежных карт.

Заполнение реквизитов справочника

В форме Вид платежной карты необходимо заполнить реквизиты:

  • Код – код элемента справочника, присваивается автоматически;
  • Наименование – наименование вида платежной карты.


Если эквайер взимает одинаковую комиссию для всех видов обслуживаемых платежных карт, то в справочник необходимо добавить только один элемент с наименованием Все платежные карты.
