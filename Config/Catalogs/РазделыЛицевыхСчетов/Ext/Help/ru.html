Справочник "Разделы лицевых счетов"

На одном лицевом счете возможно ведение учета по нескольким разделам – источникам средств.

Например, на лицевом счете получателя средств Федерального бюджета учет можно вести по разделам:

  • средства бюджета;
  • средства дополнительного бюджетного финансирования;
  • средства от приносящей доход деятельности.

Перечень разделов хранится в справочнике Разделы лицевых счетов, который является подчиненным справочнику Лицевые счета.

Для вызова справочника Разделы лицевых счетов можно использовать команду Разделы лицевых счетов панели навигации элемента справочника Лицевые счета.

Для ввода нового раздела лицевого счета можно использовать копку Создать командной панели табличной части.

Для каждого раздела лицевого счета следует указать реквизиты:

Источник средств – выбирается из справочника Источники (виды) средств для исполнения обязательств. Значение реквизита будет указываться в платежных документах (заявках на кассовый расход и т.п.), представляемых в органы казначейства.

В таблице Допустимые КФО указываются значения КФО, операции по которым отражаются в разделе лицевого счета. Для добавления КФО в таблицу можно использовать кнопку Добавить.


Код раздела – устанавливается автоматически по источнику средств.

Важно!
Не следует без особой необходимости изменять значение кода раздела, установленное автоматически.

Группа реквизитов Казначейское сопровождение (Аналитический код и Государственный контракт) становится доступна для заполнения по разделам, открытым на лицевом счете с признаком ведения казначейского сопровождения в разрезе разделов лицевого счета (флажок Ведется по государственным контрактам в разрезе разделов лицевого счета). Для одного лицевого счета доступно создание нескольких разделов с уникальными аналитическими кодами по числу исполняемых контрактов.
