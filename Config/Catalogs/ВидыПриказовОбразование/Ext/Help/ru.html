Справочник "Виды приказов (образование)"

Для регистрации событий, например, зачисления учащихся, перевода их на следующий курс или в другую группу, для назначения льготы по оплате и т.д. образовательное учреждение использует приказы различного вида. Состав информации в каждом приказе определяется его видом. Каждый вид приказа в программе состоит из определенного набора полей, отражающих его суть.

Пример. В набор полей приказа Назначение и изменение льготы по оплате логично добавить поле Льгота. Если приказ касается перевода учащегося из одной группы в другую, то добавление в поля приказа двух полей Группа является обоснованным.

Справочник Виды приказов (образование) предназначен для создания и хранения списка видов приказов, а также добавления и настройки полей для ввода информации в приказе каждого вида.

Работа со списком

Список видов приказов можно открыть с помощью команды Виды приказов (образование) меню функций раздела Платное обучение.

Создание нового элемента

Для создания нового приказа можно нажать на кнопку Создать командной панели формы списка Виды приказов (образование).

Наименование – наименование вида приказа в виде произвольного текста, по возможности отражающее суть вида приказа: Зачисление на обучение, Перевод в другую группу, Назначение льготы по оплате и т.д.

Закладка "Настройки полей"

В табличной части закладки выполняется добавление полей для ввода данных, а также настройка правил работы с полями. Для добавления нового поля можно использовать кнопку Добавить командной панели табличной части.

  • Поле – выбирается из списка Поля приказов (образование), который содержит значения Группа, Курс, Ставка оплаты и Льгота. При необходимости выбрать значение, отсутствующее в списке, например, Факультет, его необходимо предварительно добавить в список Поля приказов, а затем выбрать;
  • Заполнять – установка флага означат, что заполнение поля возможно, но не обязательно. После установки флага Заполнять доступен реквизит Заполнение обязательно;
  • Заполнение обязательно – после установки флага поле становится обязательным для заполнения;
  • Показывать пред. значение – после установки флага в приказе будет справочно отображаться предыдущее значение поля.

Пример. Учащемуся назначен новый процент льготы по оплате за обучение. Настраивая поля приказа об изменении льготы, для поля Льгота можно установить флаги – Заполнять, Заполнение обязательно и Показывать предыдущее значение. Таким образом, в приказе об изменении льготы будет необходимо указать новый процент льготы, при этом справочно будет доступна информации о предыдущем значении льготы.

Закладка "Проведение документа"

Некоторые приказы могут приводить к изменению состояния учащегося – зачислению, предоставлению академического отпуска и т.д. Для регистрации изменения состояния учащегося следует установить флаг у реквизита Установить состояние учащегося, а затем выбрать необходимое состояние из справочника Состояния учащихся.
