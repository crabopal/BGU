Справочник "Виды обязательств"

Справочник Виды обязательств предназначен для хранения информации о видах обязательсв по средствам, полученным во временное распоряжение.

Справочник используется для ведения аналитического учета на счете 304.01 "Расчеты по средствам, полученным во временное распоряжение".

Работа со списком

Справочник Виды обязательств можно открыть с помощью команды Виды обязательств меню функций раздела Планирование и санкционирование или раздела Учет и отчетность.

Создание нового элемента

Для создания новой карточки вида обязательств можно нажать кнопку Создать командной панели формы списка Виды обязательств.
