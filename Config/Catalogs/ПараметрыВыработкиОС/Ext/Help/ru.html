Справочник "Параметры выработки ОС"

Справочник Параметры выработки ОС предназначен для хранения списка натуральных показателей, пропорционально объему которых может начисляться амортизация основных средств.

Применяется при регистрации выработки с помощью документа Выработка ОС для объектов ОС с методом начисления амортизации "Пропорционально объему продукции".

Карточка Параметр выработки ОС содержит реквизиты:

  • Наименование – наименование параметра выработки.
  • Единица измерения – единица измерения параметра выработки.
