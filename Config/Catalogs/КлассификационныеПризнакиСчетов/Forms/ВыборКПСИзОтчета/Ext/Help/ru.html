Выбор кода БК из справочника КПС

Для универсального регламентированного отчета может быть настроена возможность выбора кода БК из справочника КПС. В этом случае в форме документа «Универсальный регламентированный отчет» появляется кнопка Выбор из КПС .

Выбор производится в следующем порядке.

Если для бланка отчета задана настройка выбора из КПС, данный режим считается основным, при открытии формы отчета кнопка Выбор из КПС  отображается нажатой. Для бланка отчета, в котором доступен режим выбора из КПС, для возможности выбора каждого элемента кода БК вручную требуется отключить режим Выбор из КПС (кнопка должна быть не нажатой).

Список КПС заполняется с отбором по виду КПС, доступному для выбранной строки отчета и дате действия (соответствующей дате окончания периода отчета). В форме выбора кода БК из справочника КПС следует выбрать нужный элемент, нажав двойным щелчком левой клавишей мыши в списке доступных кодов КПС.

В области предварительно выбранных значений отображаются элементы БК, полученные из выбранного КПС. При необходимости элементы БК могут быть изменены в форме выбора.  Перенос предварительно выбранных значений в строку отчета выполняется нажатием кнопки Выбрать.
