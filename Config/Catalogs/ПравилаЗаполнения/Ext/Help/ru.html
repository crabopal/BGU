Справочник "Правила заполнения"

Назначение справочника

Справочник "Правила заполнения" предназначен для хранения настроек заполнения видов отчетов справочника "Виды отчетов". Настройки заполнения могут создаваться и редактироваться в пользовательском режиме.

Настройка использования

Для одного вида отчета может быть определено несколько правил заполнения. Для определения правила заполнения, используемого "по умолчанию", предназначены команды подменю "Настройка использования":

  • "Основное" - правило заполнения используется "по умолчанию" для заполнения вида отчета. В данном случае, исходя из его настроек, формируются команды подменю "Заполнить" в форме документа "Универсальный регламентированный отчет";
  • "Дополнительное" - правило заполнения "по умолчанию" не используется для заполнения вида отчета. Заполнить отчет данным правилом можно в случае, если в меню "Заполнить" выбрать команду "Настройка заполнения". В открывшейся форме необходимо включить видимость у реквизита "Правило заполнения".

Структура правила заполнения

Фактически Правила заполнения представляют собой справочник, подчиненный справочнику "Виды отчетов".

Область заполнения

Неотъемлемой частью Правила заполнения является понятие "Область заполнения". Область заполнения - объект метаданных. Она реализует расчет групп показателей отчетной формы на основании данных бухгалтерского учета. Область заполнения может соответствовать одной или нескольким группам показателей отчета. Одно Правило заполнения может иметь несколько Областей заполнения. Области заполнения представляют собой справочник, подчиненный справочнику "Правила заполнения".

Область заполнения содержит два основных элемента: Источник данных и Схема заполнения.

Источник данных области заполнения

Источник данных объединяет в себе все запросы к информационной базе с установленными отборами, предоставляя данные, необходимые для заполнения всех показателей отчетной формы, соответствующих данной области заполнения. Состав источника данных области заполнения определяется запросами к информационной базе.

Схема заполнения

Схема заполнения представляет собой таблицу, каждая строка которой соответствует конкретному показателю отчетной формы. При этом одному показателю отчетной формы может соответствовать несколько строк в схеме заполнения. Схема заполнения предназначена для определения аналитических разрезов группировки данных и задания формул для вычисления значения показателя и его аналитики на основании данных источника.

Подробную информацию о редактировании правил заполнения можно узнать в статье на диске ИТС "Создание правила заполнения отчетной формы".
