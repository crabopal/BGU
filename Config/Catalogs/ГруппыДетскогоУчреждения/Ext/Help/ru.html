Справочник "Группы детского учреждения"

Справочник Группы детского учреждения предназначен для ведения списка групп детского учреждения по видам оказываемых услуг.

Ребенок может быть одновременно включен в несколько групп детского учреждения, каждая из которых соответствует определенному набору услуг. Для детского сада это может быть, например, основная возрастная группа (Младшая, Средняя или Подготовительная), группа по времени дополнительного пребывания (Продленного дня, Ночная), группа по дополнительным занятиям (Музыкальная, Спортивная) и т.д.

Для каждого вида группы, другими словами, для каждого элемента справочника, следует ввести список детей, которые включены в данную группу. Для каждого ребенка в списке необходимо, в свою очередь, указать ставку оплаты и правило расчета суммы начисления за данную услугу. Если ребенок имеет льготы по оплате, то необходимо также выбрать льготу.

Информация из справочника Группы детского учреждения используется для группового заполнения документов по родительской плате, а также при формировании Табеля учета посещаемости детей.

Работа со списком

Справочник Группы детского учреждения можно открыть с помощью команды Группы детского учреждения меню функций раздела Платное обучение.

Организация – детское учреждение. По умолчанию в справочнике отражается информация по детям учреждения, заданного в сеансе работы как Текущая организация. Для ввода и просмотра информации по другому учреждению, например, в случае использования программы в централизованной бухгалтерии, следует выбрать нужное учреждение из справочника Организации.

Создание нового элемента

Для создания нового элемента справочника можно нажать на кнопку Создать командной панели формы списка Группы детского учреждения.

Заполнение реквизитов карточки группы

  • Организация – учреждение, воспитанником которого является ребенок. Автоматически подставляется значение, указанное в реквизите Организация формы списка справочника Группы детского учреждения. При необходимости можно выбрать иное наименование учреждения в справочнике Организации;
  • Наименование – наименование;
  • Группа справочника – выбирается при наличии групп в справочнике Группы детского учреждения;
  • График работы – можно выбрать из справочника Графики работы, но можно и не указывать. Если график работы не указан, то при расчете родительской платы будет использоваться производственный календарь Российской Федерации;
  • Воспитатель – выбирается из справочника Сотрудники;
  • Номенклатура – наименование гос. услуги. Выбирается из фрагмента справочника Номенклатура, ограниченного услугами. Данные справочника Номенклатура используются для автоматизации процесса выписки квитанций на оплату услуг детского дошкольного учреждения;
  • Направление деятельности – выбирается из справочника Направления деятельности.

Далее для каждого вида Группы детского учреждения следует ввести список детей, которые включены в данную группу.

Заполнение состава группы

Чтобы открыть список Состав групп детского учреждения, следует предварительно открыть карточку Группы, а затем использовать одну из команд: Состав групп основной общеобразовательной программы или Состав групп дополнительных общеобразовательных программ панели навигации формы карточки Группы детского учреждения.

Пример
Предположим, Средняя группа детского сада оказывает ребенку услуги по уходу и содержанию. В этом случае для данного ребенка эта группа является основной и для включения его в группу необходимо использовать команду Состав групп основной общеобразовательной программы.
Если же ребенка приводят в Среднюю группу только на занятия рисованием, то эта группа не является для ребенка основной. Для включения его в группу в этом случае следует использовать команду Состав групп дополнительных общеобразовательных программ.

Для создания нового элемента справочника можно нажать на кнопку Создать командной панели формы списка Состав групп.

Для ввода нескольких элементов удобно использовать режим Подбор, для вызова которого следует использовать кнопку Заполнить подбором.

  • Ребенок – ребенок, который включен в состав данной группы. Выбирается из справочника Дети;
  • Группа детского учреждения – наименование группы, которой подчинен данный список Состав групп. Значение реквизита заполнено и совпадает со значением реквизита Наименование карточки группы;
  • Ставка оплаты – ставка и правило расчета начисления оплаты за услуги. Выбирается из справочника Ставки оплаты;
  • Льгота – наименование льготы, которая может быть задана для льготных категорий граждан. Выбирается из справочника Льготы учащихся и воспитанников;
  • Договор – договор на оказание образовательных услуг. Выбирается из справочника Договоры и иные основания возникновения обязательств;
  • Запись действует с: – дата начала действия веденных данных.

После нажатия на кнопку Записать и закрыть в состав группы будет включен один ребенок. Кроме того в карточке ребенка в справочнике Дети на закладке Сведения о ребенке появится соответствующая запись.

При этом в справочнике Группы детского учреждения число в колонке Количество посещающих группу детей в строке с наименованием данной группы увеличится на единицу.
