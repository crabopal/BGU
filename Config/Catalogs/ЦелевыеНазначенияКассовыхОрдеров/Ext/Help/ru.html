Целевые назначения кассовых ордеров

Справочник Целевые назначения кассовых ордеров предназначен для хранения наименований часто используемых целевых назначений движения наличных денежных средств:

  • Возмещение ущерба,
  • Депоненты,
  • Доходы от реализации активов,
  • Заработная плата,
  • Возврат неиспользованных денежных средств,
  • Оплата обучения,
  • Подотчет,
  • Приобретение МЗ,
  • Прочие работы, услуги,
  • Увеличение стоимости материальных запасов,

и т.д.

Работа со списком

Список Целевые назначения кассовых ордеров можно открыть с помощью команды Целевые назначения кассовых ордеров раздела Денежные средства.

Создание нового элемента

Для ввода целевого назначения кассовых ордеров можно нажать кнопку Создать командной панели формы списка Целевые назначения кассовых ордеров.
