Справочник "Приемы пищи"

Справочник предназначен для ведения списка приемов пищи.

Список приемов пищи может включать элементы Первый завтрак, Второй завтрак, Обед, Полдник и т.д.

Работа со списком

Форму списка Приемы пищи можно открыть с помощью команды Приемы пищи меню функций раздела Услуги, работы, производство.

Создание нового элемента

Для добавления в справочник нового элемента можно нажать на кнопку Создать командной панели формы списка Приемы пищи.
