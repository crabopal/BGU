Справочник "Карточки капвложений"

Справочник Карточки капвложений предназначен для ведения и хранения сведений по карточкам капитальных вложений в объекты нефинансовых активов: основных средств, нематериальных и непроизведенных активов с целью формирования Карточек учета капитальных вложений (ф. 0509211), утв. приказом Минфина России от 15.04.2021 г. № 61н.

Каждый элемент справочника содержит реквизиты карточки капвложения в НФА: номер, объект вложений, организацию, в которой заведена карточка и т.п..

Данные капитальных вложений, относящиеся к карточке, получаются из данных бухгалтерских проводок по счетам 106.хх, к которым карточка была привязана и которые сформированы учетными документами.


Работа со списком

Справочник Карточки капвложений можно открыть с помощью команды Карточки капвложений меню функций раздела ОС, НМА, НПА.

Создание нового элемента

Для добавления в справочник элемента капвложения в НФА можно нажать кнопку Создать командной панели формы Карточки капвложений.

Примечание. Чтобы создать элемент капвложения в НФА в определенной группе, необходимо предварительно ее открыть.

Чтобы добавить в справочник группу капвложений в НФА, необходимо нажать кнопку Создать группу командной панели формы Карточки капвложений.

Заполнение реквизитов карточки капвложений

Вид капвложений – определяет вид карточки или вид капвложений. Выбирается из выпадающего списка:

  • Поступление возмездное;
  • Поступление безвозмездное;
  • Модернизация реконструкция;
  • Централизованное снабжение;
  • Изготовление для собственных нужд;
  • Первое применение;
  • Прочие капвложения.

Комментарий – произвольный текстовый комментарий к карточке капвложения в НФА.

Группа карточек – группа капвложений в НФА, в которую входит данное капвложение.

Наименование – наименование карточки капвложений в НФА. Формируется автоматически из наименования объекта капвложений и вида карточки. Можно изменить вручную.

Дата начала вложений – дата, с которой начались вложения, относящиеся к карточке. Реквизит виден только для карточки с видом капвложений Первое применение, т.к. карточки первого применения формируются по остаткам на счетах 106.хх при первом применении функционала карточек капвложений – по состоянию на 01.01.2023, но дата открытия карточки, для карточек первого применения, должна соответствовать реальной дате начала формирования капвложений. Для карточек других видов дата открытия карточки соответствует дате первого вложения в карточку и не требует заполнения, поэтому в форме не видна.

Примечание. Карточки капвложений в НФА первого применения формируются документом Ввод истории карточек капвложений с видом операции Ввод карточек капвложений по остаткам (первое применение). В таблице объектов документа есть реквизит Дата, который и определяет дату начала вложений. Реквизит можно заполнить в документе и при его проведении соответствующий реквизит карточки будет заполен.

Закрыта – флажок, который определяет состояние карточки (закрыта, открыта).

Дата закрытия карточки – реквизит доступен только когда установлен флажок Закрыта. Карточка закрывается датой прекращения признания в учете капитальных вложений в объекты нефинансовых активов, но не ранее даты государственной регистрации права собственности на объекты нефинансовых активов, на которые в соответствии с законодательством Российской Федерации требуется такая регистрация.

Объект вложений – объект НФА, для которого формируются капитальные вложения и открывается карточка капвложений. Заполняется автоматически при создании новой карточки капвложений, если карточка создается из учетного документа и в нем указан объект капвложений - НФА из справочника Основные средства, НМА, НПА, которое является значением субконто «Основные средства» счета 106.хх.

Печать карточки капвложений

По кнопке Карточка капвложений (ф. 0509211) командной панели формы карточки капвложений формируется Карточка капвложений (ф. 0509211).

Печатную форму карточки также можно сформировать из справочника Карточки капвложений и с закладки Карточки капвложений карточки основного средства.
