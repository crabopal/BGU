Справочник Денежные документы

Справочник предназначен для хранения информации о конкретных денежных документах.

Для вызова справочника можно использовать команду Денежные документы меню функций раздела Денежные средства.

В справочник вводится информация о наименовании денежного документа, единице измерения и номинале денежного документа.

При создании нового элемента справочника следует заполнить реквизиты:

  • Вид документа – выбирается из справочника Виды денежных документов;
  • Единица измерения – единица измерения денежных документов. Значение Штука, выбирается из справочника Классификатор единиц измерения;
  • Номинальная стоимость – стоимость денежного документа в рублях.
