Справочник "Виды денежных документов"

Справочник используется для ведения аналитического учета по счетам, для которых установлено ведение аналитического учета в разрезе видов денежных документов.

Справочник в комплекте поставки заполнен предопределенными наименованиями наиболее часто используемых видов денежных документов:

  • Вексельные марки;
  • Марки государственной пошлины;
  • Оплаченные авиабилеты;
  • Оплаченные железнодорожные билеты;
  • Оплаченные путевки в дома отдыха, санатории, турбазы;
  • Почтовые марки;
  • Путевки неоплаченные;
  • Талоны на бензин;
  • Талоны на масла;
  • Талоны на питание.

При необходимости справочник можно дополнить другими использующимися в учреждении видами документов, например, видом Ценные бумаги.

Работа со списком

Список Виды денежных документов можно открыть с помощью команды Виды денежных документов меню функций раздела Денежные средства.

Создание нового элемента

Для ввода элемента справочника можно нажать кнопку Создать командной панели формы списка Виды денежных документов.
