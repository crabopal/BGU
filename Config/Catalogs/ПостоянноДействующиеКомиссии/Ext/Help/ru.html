Справочник "Комиссии"

Для хранения информации о списке постоянно действующих и временных комиссий предназначен справочник Комиссии. Например, информации о членах комиссии по инвентаризации, комиссии по поступлению и выбытию активов и др.

Информация из справочника Комиссии используется для автозаполнения сведений о комиссиях в документах по списанию и восстановлению кредиторской и дебиторской задолженности, по отражению принятия к бухгалтерскому учету и списании с учета имущества, при составлении инвентаризационных описей (сличительных ведомостей) и т. п.

Работа со списком

Справочник Комиссии можно открыть с помощью команды Комиссии меню функций раздела Справочники – Организационная структура или раздела Инвентаризация – Прочие объекты (61н).

Создание нового элемента

Для добавления в справочник новой комиссии учреждения можно в командной панели формы Комиссии нажать правую кнопку мыши и выбрать кнопку Создать.

Заполнение реквизитов элемента справочника

Наименование – наименование комиссии, которое используется для идентификации при выборе в документах программы.

Временная – флажок следует установить, если в учреждении создается временная комиссия.

Группа реквизитов Приказ о создании комиссии – заполняется наименование, номер и дата приказа о создании комиссии, которые выводятся в печатных формах учетных документов (реквизиты Номер приказа и Дата приказа).

В группе реквизитов Настройки регламента голосования следует установить настройки регламента голосования:

  • Кворум, минимальный % присутствующих – минимальное количество присутствующих членов комиссии, при котором собрание комиссии считается состоявшимся;
  • Минимальный % голосов "за" присутствующих – определяет минимальное количество голосов, необходимое для одобрения резолюции комиссии;
  • С учетом голоса председателя – при установке флажка при равенстве голосов 50/50, голос председателя комиссии будет решающим.

В табличной части Состав комиссии с помощью кнопки Добавить из справочника Сотрудники следует выбрать членов комиссии, с помощью флажка Председатель следует установить председателя комиссии. Также в табличной части в графе Номер рабочей комиссии для каждого члена комиссии можно ввести номер рабочей комиссии.
