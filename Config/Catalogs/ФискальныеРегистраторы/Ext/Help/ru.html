Справочник "Кассы ККМ (фискальные регистраторы)"

Справочник Кассы ККМ (фискальные регистраторы) предназначен для хранения данных об используемых контрольно-кассовых машинах..

Работа со списком

Список Кассы ККМ (фискальные регистраторы) можно открыть с помощью команды Кассы ККМ (фискальные регистраторы) группы Управление ККТ в меню функций раздела Денежные средства.

Создание нового элемента

Для ввода элемента справочника можно нажать кнопку Создать командной панели формы списка Фискальные регистраторы.

Заполнение реквизитов элемента справочника


Организация – наименование организации. Заполняется автоматически.

Подразделение – наименование подразделения. Выбирается из справочника Подразделения.

Примечание. Реквизит Подразделение указывается при необходимости заполнения реквизита Подразделение в документе Чек ККМ, а также для выгрузки данных о номенклатуре в офлайн-ККМ только по этому подразделению, если в номенклатуре прейскуранта заполнен реквизит Подразделение.

Наименование – наименование фискального регистратора.

Закладка "Основные параметры"


Группа реквизитов Подключаемое оборудование:

Использовать без подключения к системе – флаг устанавливается в случае, если оборудование работает автономно, без подключения к программе «1C:Бухгалтерия государственного учреждения 8».

Подключаемое оборудование – фискальный регистратор, подключенный к программе «1C:Бухгалтерия государственного учреждения 8». Выбирается из списка Подключаемое оборудование.

Настройка распределения выручки по секциям – выбирается из справочника Настройка распределения выручки по секциям фискального регистратора.

Группа реквизитов Формирование расчетных документов без применения ККТ:

Использовать для печати расчетных документов без применения ККТ – при установленном флажке у учреждений, которые в силу закона не применяют ККТ, появляется возможность формировать бланки расчетных документов с единой нумерацией.
Режим печати – выбирается один из вариантов:


  • На обычном принтере – при данном режиме печати бланк и копия бланка выводятся параллельно;
  • На принтере чеков – при данном режиме печати бланк и копия бланка выводятся последовательно.

Журнал учета расчетных документов без применения ККТ – по гиперссылке открывается форма для формирования отчета Журнал учета расчетных документов без применения ККТ. По кнопке Сформировать отчет можно отдельно вывести на печать титульный лист и листы журнала учета расчетных документов со списком выданных покупателям расчетных документов в хронологическом порядке.

Примечание. Группа реквизитов Формирование расчетных документов без применения ККТ становится доступна, если в группе реквизитов Подключаемое оборудование установлен флажок Использовать без подключения к системе.

Группа реквизитов Передача данных покупателям:

Электронные чеки (Email) передаются программой "1С" – при снятом флажке электронный чек будет отправлен по электронной почте ОФД (рекомендуется);
Электронные чеки (SMS) передаются программой "1С" – при снятом флажке электронный чек в sms будет отправлен ОФД (рекомендуется);
Не печатать фискальный чек при отправке электронного – при установленном флажке фискальный чек на бумажной кассовой ленте не будет напечатан в случае, если были введены контактные данные (адрес электронной почты или номер телефона) для отправки электронного чека.

Примечание. Группа реквизитов Передача данных покупателям становится доступна, если в реквизите Подключаемое оборудование выбрана онлайн-касса.


Группа реквизитов Сведения о ККТ:

Серийный номер – заводской номер оборудования.
Наименование места расчета – наименование точки продаж.
Адрес места расчета – адрес точки продаж.

Закладка "Настройки заполнения документов"

На закладке Настройки заполнения документов заполняются сведения, необходимые для автоматического заполнения реквизитов документов с выбранной кассой ККМ.

Основная система налогообложения – основная система налогообложения для заполнения реквизита Касса ККМ в документах с командой Напечатать чек.

В группе Заполнение кассира в чеке ККМ в кассовых документах задаются наименования реквизитов документа, которые будут переданы в качестве кассира в ККТ. Доступные значения для выбора – Кассир и Ответственный. Основное значение – Кассир.

Если флажок Не проверять ИНН кассира установлен, то перед печатью чека не будет выполняться проверка на обязательное наличие ИНН кассира.

В группе Заполнение списка номенклатуры значения реквизитов Тип цены, Сумма включает НДС предназначены для заполнения новых документов вида Чек ККМ значениями по умолчанию.

Реквизиты Номенклатура платежа и Признак способа расчета платежа определяют значение номенклатуры и признак способа оплаты при заполнении кассовых чеков в документе Чеки ККМ для реестра платежей. У указанного значения номенклатуры реквизит Признак предмета расчета должен иметь значение Платеж выплата.

Реквизит Признак способа расчета для документа-основания номенклатуры чека ККМ задает признак способа расчета для чеков кассы ККМ по умолчанию, если в карточке договора с контрагентом не задан Признак способа расчета.

Группа реквизитов Заполнение сведений о покупателе:

Настройка Флажок "Розничный покупатель" в документах "Чек ККМ" и "Чек ККМ на возврат" по умолчанию выключен используется в том случае, если документы Чек ККМ и Чек ККМ на возврат чаще оформляются не на розничного покупателя и по умолчанию новый документ розничных продаж должен иметь снятый флажок Розничный покупатель.

Если требуется, чтобы в документах Чек ККМ и Чек ККМ на возврат была возможность заполнять и сохранять сведения о контрагенте и договоре при установленном флажке Розничный покупатель, то следует установить флажок Заполнять контрагента и договор в документах "Чек ККМ" при включенном флажке "Розничный покупатель".

Реквизиты Контрагент для розничных продаж, Договор для розничных продаж предназначены для автоматического заполнения реквизитов Контрагент и Договор при записи новых документов Чек ККМ и Чек ККМ на возврат с установленным флажком Розничный покупатель.

Если установлен флажок Заполнять ФИО ребенка в чеках ККМ по реестру платежей для поступления родительской платы, то в документе Чеки ККМ для реестра платежей в кассовых чеках для родительской платы в номенклатуре чека к наименованию услуг для большей информативности будут добавлены фамилия и инициалы ребенка.

Если установлен флажок Заполнять ФИО плательщика в чеках ККМ по реестру платежей для поступления родительской платы, то в документе Чеки ККМ для реестра платежей в кассовых чеках для родительской платы в номенклатуре чека к наименованию услуг для большей информативности будут добавлены фамилия и инициалы плательщика.

Если установлен флажок Формировать чеки по каждому платежу в документе "Чеки ККМ для реестра платежей", то в документе Чеки ККМ для реестра платежей для каждой оплаты одного контрагента по каждому договору будет свой кассовый чек. Без включения этой опции по всем оплатам контрагента из документа-основания будет сформирован один кассовый чек.

Закладка "Параметры учета и контроля"

Группа реквизитов Контроль остатков товаров при розничных продажах:

Вести контроль остатков товаров на складе торговой точки – при установленном флажке ведется контроль остатков товаров в розничной торговой точке, который предполагает:

  • показ остатков в форме подбора номенклатуры прейскуранта;
  • проверку и уведомление в случае недостаточных остатков товаров на складе торговой точки при проведении документов Чек ККМ.

Внимание!
По умолчанию контроль остатков товаров в торговой точке не осуществляется. Для того чтобы вести контроль остатков товаров на складе в торговой точке, кроме установки флажка необходимо ввести документ Ввод остатков товаров на складе торговой точки.

МОЛ/Место хранения товаров – указывается центр материальной ответственности, для которого контролируются остатки товаров в торговой точке. Выбирается из справочника Центры материальной ответственности.

Примечание. Если при поступлении или выбытии товаров в торговой точке указывать в документах Поступление МЗ, Акт о приемке материалов и Требование-накладная (Материальные запасы) МОЛ/Место хранения из настроек кассы ККМ, то становится доступна установка флажков Оформить поступление товаров на склад торговой точки или Оформить выбытие товаров со склада торговой точки.

Розничная реализация маркированных товаров – установка флажка влияет на возможность ввода кода маркировки для печати кассового чека при реализации маркированной продукции.

В группе реквизитов Отражение розничных продаж в учете для учета подразделений в документах Приходный кассовый ордер и Эквайринговая операция при их формировании из документа Отчет по кассовой смене следует установить флажок Учет по подразделениям.

Для сохранения настройки следует нажать на кнопку Записать и закрыть.
