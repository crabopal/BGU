Справочник "Учащиеся"

Справочник Учащиеся предназначен для ведения списка учащихся образовательного учреждения. Списки учащихся ведутся раздельно по каждой организации (учреждению), бухгалтерский учет которых ведется в информационной базе. Кроме того в рамках одной организации можно вести списки учащихся раздельно по факультетам.

Работа со списком

Список учащихся можно открыть с помощью команды Учащиеся навигациименю функций раздела Платное обучение.

В форме списка Учащиеся предусмотрены отборы по реквизитам:

  • Организация – выбирается из справочника Организации;
  • Факультет – выбирается из справочника Подразделения;
  • Актуальность – выбирается из списка и может принимать значения: Все, Актуальные или Архивные.

Отнесение карточки учащегося к категории Актуальных или Архивных достаточно произвольно и выполняется на основании правил, принятых в учреждении. К Актуальным, например, можно отнести все карточки учащихся, которые обучаются в учреждении на текущий момент. Карточки учащихся, которые находятся в академическом отпуске, отчислены или закончили обучение, в этом случае можно будет отнести к категории Архивные.

Внимание! Перенос карточки учащегося в категорию Архивные не влияет на состояние учащегося и не затрагивает начисления за услуги образования. Данный механизм используется только для настройки быстрого отбора в форме списка учащихся.

Для отнесения карточек к той или иной категории следует выделить в списке Учащиеся одну или несколько карточек, вызвать правой кнопкой мыши контекстное меню и выбрать в нем пункт Поместить в/извлечь из архива. В результате выделенные Актуальные карточки учащихся станут Архивными, а Архивные переместятся в категорию Актуальных.

Пример. Учащемуся Иванову А. И. предоставлен академический отпуск. Для перевода его карточки из Актуальных в категорию Архивных выделяем в списке Учащихся строку со значением Иванов А. И. реквизита ФИО, нажимаем на правую кнопку мыши и выбираем в контекстном меню пункт Поместить в/извлечь из архива. В последующем при просмотре списка учащихся с установленным отбором Актуальные карточка учащегося Иванова А. И. в списке будет отсутствовать.

Программа запоминает последние настройки быстрых отборов формы списка Учащиеся и восстанавливает их при следующем открытии формы.

Вывод в список текущих данных, установленных приказами

По умолчанию список Учащиеся содержит две колонки – Табельный номер и ФИО. При установленном отборе по Факультету программа позволяет вывести в список также другие текущие данные учащихся, установленные приказами, – о группах, факультетах, курсах, состояниях учащихся и т.д.

Для вывода в список необходимых дополнительных данных следует установить отбор по факультету и выбрать в меню Еще командной панели формы списка пункт Изменить форму. В Настройке формы следует перейти в окно Элементы формы, последовательно раскрыть группы Страницы, Список со значениями, Список по факультету и установить курсор на реквизите Ссылка. После этого необходимо нажать на кнопку Добавить поля командной панели и выбрать с помощью флагов необходимые поля в открывшейся форме. После сохранения настроек в форме списка Учащиеся появятся колонки с выбранными полями.

Внимание! Настройка вывода в список текущих данных, установленных приказами, возможна только при установленном отборе по факультету. Выполненная настройка автоматически сохраняется и применяется в последующем к списку Учащихся при его открытии.

Создание новой карточки учащегося

Внимание! Аналитический учет расчетов с учащимися ведется в программе в разрезе контрагентов. Каждой карточке учащегося соответствует карточка контрагента.

Некоторые реквизиты карточки Учащегося и карточки Контрагента являются общими для карточек обеих видов. Это касается реквизитов, используемых для хранения личных данных, информации о гражданстве, документе, удостоверяющем личность и т.д. Изменение значения любого из этих реквизитов в карточке Учащегося автоматически приводит к изменению значения данного реквизита в карточке соответствующего Контрагента, и наоборот.

Новую карточку учащегося можно создать двумя способами.

Первый способ

При работе со списком учащихся для создания новой карточки можно использовать кнопку Создать командной панели формы списка.

Второй способ

Предусматривает создание новой карточки учащегося на основании созданной ранее карточки Контрагента. Список контрагентов можно открыть с помощью команды Контрагенты меню функций раздела Справочники.
После выделения курсором необходимого контрагента следует использовать кнопку Создать на основании командной панели формы и выбрать в списке команду Учащийся.

Пример. Учащийся Иванов П. И. поступил в образовательное учреждение на факультет Радиотехника. В системе были созданы карточка контрагента Иванов Петр Ильич, а затем, на ее основании карточка учащегося Иванов Петр Ильич. По окончании первого семестра Иванов П. И. был по собственному желанию отчислен с факультета Радиотехника и зачислен на факультет Прикладная математика. При этом для него на основании карточки контрагента Иванов Петр Ильич была создана новая карточка учащегося.

Пример. Учащийся Федоров В. И. был зачислен на факультет Графика и одновременно на факультет Скульптура. В системе была создана карточка контрагента Федоров Владимир Ильич, на основании которой далее были созданы две карточки учащегося – по одной карточке для каждого факультета.

Также программа позволяет несколько иным способом установить связь между карточками Учащегося и Контрагента. При этом новая карточка учащегося создается в форме списка учащихся, а связь между карточками будет установлена после выбора значения для поля Контрагент в карточке Учащегося.

Пример. Лаборант Смирнов Т. К. является сотрудником образовательного учреждения. Через некоторое время после начала работы он сдал экзамены и был зачислен учащимся в образовательное учреждение, в котором он работал. В данной ситуации можно создать новую карточку учащегося и выбрать для поля Контрагент значение Смирнов Тимофей Константинович, уже присутствующее в списке контрагентов.

Заполнение основных реквизитов карточки учащегося
  • Организация – выбирается из справочника Организации;
  • Учащийся (ФИО) – фамилия, имя и отчество, указываются полностью.

Примечание. Реквизиты Организация и Учащийся (ФИО) будут заполнены автоматически, если карточка Учащегося создана на основании карточки Контрагент, или если в карточке Учащегося в реквизите Контрагент будет указан контрагент.

Предположим для учащегося, данные которого необходимо ввести, соответствующий Контрагент в справочнике Контрагенты отсутствует. В этом случае создание соответствующего Контрагента выполняется в процессе работы с карточкой Учащегося.

Внимание! Для записи карточки учащегося, а также для продолжения ввода данных следует на данном этапе записать карточку Учащегося с помощью кнопки Записать командной панели формы.

В результате будут выполнены следующие действия:

  • Карточка Учащегося будет записана и доступна в списке Учащиеся;
  • Будет создана, записана и доступна в списке Контрагенты карточка Контрагента, соответствующая карточке Учащегося;
  • Станут доступны для заполнения реквизиты группы Сведения о плательщике за услуги образования.

Плательщиком за образовательные услуги является "Учащийся"

По умолчанию предполагается, что плательщиком за услуги образования, полученные учащимся, является сам учащийся. Для создания договора с плательщиком в данной ситуации следует использовать гиперссылку Создать договор обучения в форме карточки Учащегося.

В результате откроется форма нового договора, в котором будет указан контрагент, в реквизите Вид обязательства будет указано значение Договор на оплату за обучение, а в реквизите Наименование будет сформировано наименование договора – Договор на оплату за обучение + ФИО учащегося.

Пример. Учащийся Петров М. С. поступил в образовательное учреждение, при этом в договоре указано, что плательщиком является сам учащийся. Для автоматического создания нового договора на обучение необходимо в карточке учащегося нажать на кнопку Записать или использовать сочетание клавиш Ctrl+S, а затем выполнить команду Создать договор обучения.
Автоматически созданный договор будет оформлен с заполненным контрагентом Петров Михаил Семенович, с видом обязательства Договор на оплату за обучение, а также с наименованием Договор на оплату за обучение Петров Михаил Семенович.

Плательщиком за образовательные услуги является иной "Контрагент"

Плательщиком за услуги образования, помимо учащегося, может быть также иное физическое или юридическое лицо, которое необходимо указать в реквизите Контрагент в группе реквизитов Сведения о плательщике за услуги образования. Договор с контрагентом на оплату обучения выбирается в реквизите Договор из справочника Договоры и иные основания возникновения обязательств.

Действует с – в данном реквизите указывается дата, начиная с которой сведения о плательщике начинают применяться. Начиная с этой даты начисления за образовательные услуги, оказанные учащемуся, будут производиться на заданного плательщика по выбранному договору с соблюдением указанного порядка оформления счета-фактуры.

Пример. Учащийся Петров А. П. поступил в образовательное учреждение. При этом в сведениях о плательщике в его карточке с 01.09.2012 указан плательщик ООО "Астра", а с 15.09 2012 – указан плательщик ООО "Веста".
В данной ситуации при начислении за услуги образования, оказанные в сентябре 2012 г. учащемуся Петрову А.П., будут сформированы две строки. В одной строке будет рассчитана сумма начислений с 01.09.2012 по 14.09.2012 по плательщику ООО "Астра" по договору с ним, в другой строке – сумма начислений с 15.09.2012 по 30.09.2012 по плательщику ООО "Веста" и соответствующему договору.

Порядок выписки СФ – порядок выписки счета фактуры. Может принимать значения:

  • Сводно. Значение Сводно выбирается для плательщиков физических лиц, которые не нуждаются в счете фактуре. Это позволяет оформить сводный счет фактуру по нескольким учащимся на одного контрагента. Для удобства выбора контрагента его можно указать как служебного контрагента Поставщик услуг в реквизите Контрагент для сводного счета фактуры за услуги образования в разделе Услуги, работы, производство формы Настройка параметров учета;
  • На плательщика. Значение На плательщика выбирается, если необходимо формировать счет-фактуру с указанием конкретного плательщика.

Смена фамилии, имени или отчества

При смене Фамилии, Имени или Отчества учащегося необходимо отредактировать реквизит Наименование его карточки.

При записи карточки после редактирования Наименования программа откроет диалог с вариантами ответа:

  • Исправлена ошибка. При выборе этого варианта реквизиты ФИО в Истории ФИО будут исправлены автоматически. При этом дата исправления ошибки не будет зарегистрирована.
  • Изменилось имя. В случае если выбран вариант Изменилось имя, то в Историю ФИО будет добавлена запись с указанием даты изменения и новых реквизитов ФИО.
  • Отмена.

Просмотреть историю можно по гиперссылке История ФИО.

Пример.
Учащаяся Иванова И. О. вышла замуж за Петрова В. Н. Для того чтобы поменять фамилию Иванова на фамилию Петрова, необходимо открыть карточку учащейся Ивановой И. О. и отредактировать поле Наименование. При сохранении карточки следует выбрать вариант Изменилось имя.

Дополнительные возможности

На основании карточки Учащегося можно создать документ Приказ (образование).
