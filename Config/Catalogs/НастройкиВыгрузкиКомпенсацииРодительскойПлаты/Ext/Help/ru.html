Справочник "Настройки выгрузки перечислений физическим лицам"

Справочник Настройки выгрузки перечислений физическим лицам предназначен для хранения настроек, используемых при экспорте реестров перечислений физическим лицам в банк в формате "Сбербанк Онлайн".

В данном справочнике хранятся, например, настройки выгрузки компенсации части родительской платы.

Работа со списком

Список настроек можно открыть с помощью команды Настройки выгрузки перечислений физическим лицам меню функций раздела Платное обучение. В форме списка предусмотрен отбор по организации.

Создание нового элемента

Для создания элемента справочника можно использовать кнопку Создать командной панели формы списка Настройки выгрузки перечислений физическим лицам.

Заполнение реквизитов элемента справочника

  • Наименование – наименование настройки, которое позволяет идентифицировать ее в списке настроек.
  • Организация – организация, выполняющая обмен с банком реестрами перечислений физическим лицам. Выбирается из справочника Организации.
  • Использовать сокращенное наименование организации – после установки флажка в формируемый файл реестра перечислений физическим лицам будет выгружаться сокращенное наименование организации в том виде, в котором оно указано в карточке организации.
  • Банк – банк, с которым заключен договор на перечисление физическим лицам и в который выгружаются реестры. Выбирается из справочника Кредитные организации.
  • Расчетный счет – номер расчетного счета организации в банке, с которого происходит перечисление физическим лицам.
  • Дата договора – дата договора с банком на перечисление физическим лицам.
  • Номер договора – номер договора с банком на перечисление физическим лицам. Согласно требованиям формата обмена реквизит является обязательным для заполнения.
  • Отделение банка – номер отделения банка, которое занимается перечислением физическим лицам.
  • Филиал отделения банка – номер филиала отделения банка, выполняющего перечисление физическим лицам.

№ реестра – справочно показывается номер последнего выгруженного реестра перечислений физическим лицам.
