Справочник "Дети"

Справочник Дети предназначен для хранения сведений о детях, как о воспитанниках детского учреждения, включая информацию о дате приема в учреждение и дате выбытия, группе обучения, плательщике и т.д.

Работа со списком

Справочник Дети можно открыть с помощью команды Дети меню функций раздела Платное обучение.

В форме списка предусмотрен отбор по реквизитам:

Организация – детское учреждение. По умолчанию в справочнике отражается информация по детям учреждения, которое задано в сеансе работы как Текущая организация.

Для ввода и просмотра информации по другому учреждению, например, в случае использования программы в централизованной бухгалтерии, следует выбрать нужное учреждение в справочнике Организации.

Если значение для реквизита Организация не задано, то в списке появится колонка Организация, кроме того в списке будут представлены данные по детям во всех учреждениях.

Группа детского учреждения – выбирается из справочника Группы детского учреждения.

На дату – дата, на которую следует отобрать данные.

Показывать в списке – настройка отбора, которая будет применена на дату, указанную в реквизите На дату. Может принимать значения:

  • Числящихся на указанную дату;
  • Всех, в том числе непринятых и выбывших;
  • Выбывших на указанную дату.

Создание новой группы
Справочник многоуровневый, и это позволяет объединять детей в произвольные группы. Для создания новой группы можно нажать на кнопку Создать группу командной панели формы списка Дети.

При вводе новой группы программа предлагает указать ее наименование.

Например, для детей, выбывших из детского учреждения, можно создать группу Выбывшие.

Важно!
Для изменения параметров учета у группы детей следует использовать Помощник группового изменения учетных параметров детей.

Для вызова Помощника следует использовать команду Помощник изменения параметров в меню Еще формы списка.

К параметрам, которые доступны для изменения, относятся:

  • Группа детского учреждения;
  • Ставка оплаты;
  • Льгота.

Также с помощью Помощника можно оформить как выбытие детей из группы по услуге детского учреждения, так и из учреждения в целом.

Создание нового элемента

Для создания нового элемента, другими словами, карточки ребенка, можно нажать на кнопку Создать командной панели формы списка Дети.

Заполнение реквизитов карточки ребенка

Организация – детское учреждение, воспитанником которого является ребенок. Автоматически подставляется значение, указанное в реквизите Организация формы списка справочника Дети. При необходимости можно выбрать иное наименование учреждения в справочнике Организации.

Ребенок (ФИО) – фамилия, имя и отчество ребенка. Значение реквизита Ребенок (ФИО), а также некоторых других реквизитов в карточке ребенка в справочнике Дети совпадают со значениями реквизитов, указанными в карточке ребенка в справочнике Контрагенты.

На момент заполнения справочника Дети карточка ребенка может, как присутствовать, так и отсутствовать в справочнике Контрагенты.

Если карточка ребенка в справочнике Контрагенты присутствует, то следует с помощью гиперссылки Нажмите для выбора, если данные ребенка уже есть в спр. Контрагенты открыть справочник Контрагенты и выбрать ребенка.

В результате заполненные значения реквизитов будут скопированы из карточки ребенка в справочнике Контрагенты в карточку ребенка в справочнике Дети.

Примечание. Данное действие выполняется однократно. После сделанного выбора гиперссылка будет недоступна.

Если карточка ребенка в справочнике Контрагенты отсутствует, то следует заполнить реквизиты карточки Организация и Ребенок (ФИО), а затем записать данные с помощью кнопки Записать. В результате в справочнике Контрагенты будет автоматически создана карточка ребенка.

Последующее заполнение реквизитов в карточке ребенка в справочнике Дети, например, Дата рождения, ИНН, СНИЛС и других приведет к автоматическому заполнению идентичных реквизитов карточки ребенка в справочнике Контрагенты. Обратное также верно.

В реквизит Дата приема вводится дата приема нового ребенка в учреждение. Дата выбытия заполняется при выбытии ребенка из учреждения с целью исключения выбывшего ребенка из расчета начисления родительской платы.

Группа "Параметры родительской платы за присмотр и уход"
  • Группа детского учреждения – наименование группы, которая является для ребенка основной. Выбирается из справочника Группы детского учреждения;
  • Ставка оплаты – ставка и правило расчета начисления оплаты за услуги. Выбирается из справочника Ставки оплаты;
  • Льгота – наименование льготы, которая может быть задана для льготных категорий граждан. Выбирается из справочника Льготы учащихся и воспитанников;
  • Договор – договор на содержание ребенка в детском учреждении. Если договор уже присутствует в информационной базе, то его можно выбрать из фрагмента справочника Договоры и иные основания возникновения обязательств. В случае отсутствия договора для его создания можно использовать гиперссылку Создать договор.

Параметры родительской платы за оказание основной услуги, включающей присмотр и уход за детьми, вводятся в реквизиты группы Параметры родительской платы за присмотр и уход:

Примечание. Оплата по указанному договору будет учитываться при расчете компенсации родительской платы за просмотр и уход за детьми.
  • Параметры действуют с: – дата начала действия указанных параметров родительской платы.

Группа "Дополнительные образовательные услуги"

Помимо основной услуги, включающей присмотр и уход, ребенку могут быть оказаны дополнительные образовательные услуги, предусматривающие дополнительные занятия – рисование, музыка, физкультура и т.д.

Для ввода информации о дополнительных образовательных услугах следует использовать гиперссылку Ребенок не посещает ни одной группы по дополнительным услугам.

После щелчка по гиперссылке откроется список Состав групп дополнительных образовательных программ. Для включения ребенка в группу по дополнительным услугам можно использовать кнопку Создать командной панели табличной части.

В созданной карточке Состав групп дополнительных образовательных программ следует заполнить реквизиты:

  • Группа детского учреждения – выбирается из справочника Группы детского учреждения;
  • Ставка оплаты – ставка и правило расчета начисления оплаты за услуги. Выбирается из справочника Ставки оплаты;
  • Льгота – наименование льготы, которая может быть задана для льготных категорий граждан. Выбирается из справочника Льготы учащихся и воспитанников;
  • Договор – договор на оказание дополнительных образовательных услуг. Для создания договора можно использовать гиперссылку Создать договор;

Примечание. Оплата по договору на оказание дополнительных образовательных услуг не будет учитываться при расчете компенсации родительской платы.
  • Действует с – дата начала действия указанных сведений.

Важно
Если ребенку оказывается несколько дополнительных образовательных услуг, то для каждой услуги аналогичным образом необходимо оформить свою карточку. Информация обо всех дополнительных образовательных услугах ребенку будет отражена к тексте гиперссылки.

Группа "Компенсация родительской платы"
  • Плательщик родительской платы – выбирается из справочника Контрагенты;
  • Счет плательщика – выбирается из справочника Банковские и казначейские счета;
  • Действует с: – дата начала действия указанных параметров компенсации родительской платы.

В программе предусмотрено использование нескольких ставок компенсации родительской платы по разным КФО и КПС.

Для ввода нескольких ставок компенсации в справочнике Дети предусмотрена таблица Настройки компенсации.

По каждой строке таблицы вводится срок действия и выбирается настройка из справочника Настройки расчетов по родительской плате, в состав которой входит формула расчета компенсации, а также КФО и КПС для отражения компенсации в учете.

Таблица Настройки компенсации

Для добавления новой строки в таблицу можно использовать кнопку Добавить.

Настройка компенсации – необходимую настройку можно выбрать из справочника Настройки расчетов по родительской плате или ничего не выбирать. В последнем случае в поле появится бледная надпись настройка из документа.

Процент – процент компенсации. Если поле Настройка компенсации не заполнено, то в поле Процент следует обязательно указать процент компенсации. И наоборот, если поле Настройка компенсации заполнено, то в поле Процент появляется бледная надпись не используется, и его заполнять не следует.

Дата начала и Дата окончания – дата начала и, соответственно, окончания срока действия ставки компенсации.

Группа "Личные данные"

В группе Личные данные следует заполнить реквизиты ИНН, Пол, СНИЛС, Дата рождения, № полиса ОМС и Место рождения.

Группа "Адреса, телефоны"

В реквизитах группы Адреса, телефоны отражается информация, указанная ранее в карточке ребенка в справочнике Контрагенты. В поля закладки можно ввести новую информацию, а также отредактировать существующую. После записи карточки ребенка сделанные изменения будут отражены в его карточке в справочнике Контрагенты.

Группа "Дополнительные данные"

Группа Дополнительные данные содержит поля Выдать кому и Получить от кого, в которые следует ввести наименование контрагента соответственно в дательном и родительном падежах.

Данные значения будут использоваться для автоматического заполнения полей Выдать кому, Принято от кого в расходных и приходных кассовых ордерах

После ввода в карточку необходимых сведений о ребенке следует их сохранить, нажав кнопку Записать и закрыть.
