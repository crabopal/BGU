Справочник "Прочие услуги (образование)"

Справочник Прочие услуги (образование) предназначен для ведения перечня дополнительных образовательных услуг (образовательных курсов, кружков и пр.) и прочих услуг (общежитие и т.п.), оказываемых организацией учащимся.

Работа со списком

Список прочих услуг можно открыть с помощью команды Прочие услуги в группе Образовательные услуги в меню функций раздела Платное обучение.

Создание нового элемента

Для создания нового элемента можно нажать кнопку Создать командной панели формы списка Прочие услуги.

Заполнение реквизитов элемента справочника

Наименование – наименование прочих услуг, оказываемых организацией учащимся;

Вид начисления – определяет характер начислений за услуги:

  • По долгосрочным договорам – по договорам, относящимся к долгосрочным согласно Стандарту "Долгосрочные договоры";
  • По краткосрочным договорам – по договорам, не относящимся к долгосрочным;
  • Разовое начисление – флажок, устанавливается для вида начисления, имеющего разовый характер.

Группа реквизитов Параметры начислений для автоподстановки в документы:

  • Номенклатура – прочая услуга. Выбирается из справочника Номенклатура.
  • Учитывать НДС и Ставка НДС – реквизиты, определяющие способ учета НДС для данной услуги.

Группа реквизитов Расчет стоимости услуг:

  • Ставка оплаты – ставка оплаты устанавливается для услуг, оказываемых по краткосрочным договорам. Выбирается из справочника Ставки оплаты, определяет стоимость услуг за месяц.
  • График оплаты – график оплаты устанавливается для услуг, оказываемых по долгосрочным договорам. Выбирается из справочника Графики оплаты, определяет стоимость услуг за весь срок действия договора.
  • Действует с: – дата, начиная с которой применяется указанная ставка или график оплаты.
