Справочник "Программы целевых статей КРБ"

Справочник «Программы целевых статей КРБ» предназначен для хранения перечня программ целевых статей классификации расходов бюджета.

Изначально справочник «Программы целевых статей КРБ» содержит перечень программ целевых статей классификации расходов федерального бюджета.

Список программ можно ограничить перечнем, относящимся к определенной целевой статье.

Необходимые коды и наименования позиций классификатора, утвержденные законом (решением) о бюджете, из которого финансируется учреждение, следует ввести в справочник самостоятельно.

В элементе справочника «Программы целевых статей КРБ» указываются соответствующая целевая статья, код (разряды 4—5 соответствующей целевой статьи) и наименование программы.

В реквизите «Начало действия» указывается дата, начиная с которой должен применяться этот код.

  • Код программы (Строка)
  • Код (Строка)
  • Наименование (Строка)
  • Дата начала действия (Дата)
  • Дата окончания действия (Дата)
  • Окончание действия (Дата)
  • Целевая статья (Целевые статьи КРБ)
  • Бюджет (Бюджеты)
