Справочник "Налоги и платежи организации"

В справочнике Налоги и платежи организации содержится список налогов, сборов и иных платежей в бюджет и их получателей. Справочник используется для ведения аналитического учета по счету 303.00 «Расчеты по платежам в бюджеты». Информация справочника используется также при оформлении платежных документов на перечисление налогов, сборов и иных платежей в бюджет.

Работа со списком

Справочник Налоги и платежи организации можно открыть с помощью команды Налоги и платежи организации меню функций раздела Справочники.

Создание нового элемента

Для создания нового элемента можно нажать кнопку Создать командной панели формы списка Налоги и платежи организации.

Заполнение реквизитов элемента справочника

При вводе нового элемента справочника необходимо заполнить реквизиты:

  • Вид налога или платежа – выбирается из справочника Виды налогов и платежей. После выбора автоматически заполняются реквизиты: Очередность платежа, Статус составителя (101), Текст назначения платежа.
  • Группа Реквизиты для постановки в платежно-расчетные документы заполняются реквизиты: Регистрационный номер, Код ОКТМО (105), Показатель основания (106), Показатель периода (107), Показатель типа платежа (110), Текст назначения платежа, ИНН плательщика, КПП плательщика.
  • Группа Получатель платежа (администратор поступлений) заполняются реквизиты: Контрагент, Счет контрагента, Наименование.
