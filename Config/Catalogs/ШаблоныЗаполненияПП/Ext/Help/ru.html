Шаблоны текста "Назначение платежа"

Справочник Шаблоны текста "Назначение платежа" предназначен для создания и хранения шаблонов текста, которые используются для автоматизированного заполнения поля Назначение платежа в расчетно-платежных документах.
Создание шаблонов текста для поля Назначение платежа возможно для следующих документов:

  • Платежное поручение;
  • Заявка на кассовый расход;
  • Заявка на кассовый расход (сокращенная);
  • Инкассовое поручение;
  • Платежное требование;
  • Аккредитив;
  • Объявление на взнос наличными;
  • Сводная заявка на кассовый расход.

Работа со списком шаблонов текста

Справочник можно открыть с помощью команды Шаблоны текста "Назначение платежа" меню функций раздела Денежные средства.

Создание нового шаблона текста

Для создания нового шаблона текста можно нажать на кнопку Создать командной панели списка Шаблоны текста "Назначение платежа".
