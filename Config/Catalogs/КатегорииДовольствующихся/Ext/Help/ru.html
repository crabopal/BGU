Справочник "Категории довольствующихся"

Справочник предназначен для ведения списка категорий питающихся.

Работа со списком элементов справочника

Справочник Категории довольствующихся можно открыть с помощью команды Категории довольствующихся меню функций раздела Услуги, работы, производство.

Добавление элементов справочника

Для добавления в справочник нового элемента можно нажать на кнопку Создать командной панели формы Категории довольствующихся.

Заполнение реквизитов элемента справочника

  • Наименование – произвольное наименование категории питающихся в виде текста;
  • Персонал или Довольствующиеся – переключатель, положение которого зависит от того, относится ли данная категория к персоналу или нет;
  • Вариант меню – выбирается из справочника Варианты меню.

Заполнение реквизитов на закладке "Приемы пищи/источники средств"

Табличная часть "Приемы пищи"

После выбора значения реквизита Вариант меню табличная часть Приемы пищи будет заполнена в соответствии с выбранным вариантом.

Исп – использовать прием пищи. Флаг устанавливается для приема пищи, который категория питающихся будет посещать согласно выбранному варианту меню.

Табличная часть "Источники средств"

В табличной части следует указать источники средств для приобретения продуктов, которые могут быть списаны на обеспечение питания заданной категории питающихся.

Для одной категории можно задать несколько источников средств. Это будет означать, что для обеспечения питания категории в соответствии с выбранным вариантом меню продукты могут быть списаны с любого из этих источников.

  • ИФО – источник финансового обеспечения. Выбирается в справочнике ИФО;

Необходимость в заполнении реквизита ИФО появляется только в случае установки флага Использовать учет по ИФО в форме Настройка параметров учета.
  • КФО – код финансового обеспечения. Выбирается в справочнике КФО;
  • Счет затрат – выбирается из фрагмента Плана счетов (ЕПСБУ);
  • КЭК – код экономической классификации. Выбирается из справочника "КЭК".
  • Субконто 1, Субконто 2 и Субконто 3 – разрезы аналитического учета. Возможность выбора субконто зависит от наличия и количества разрезов аналитического учета у выбранного Счета затрат.

Заполнение реквизитов на закладке "Плановая стоимость/количество питающихся"

Табличная часть "Плановая стоимость"

Табличная часть позволяет задать плановую стоимость питания для одного питающегося на один день и указать дату, начиная с которой заданная плановая стоимость будет применяться.

Информация о плановой стоимости питания используется только для формирования отчетов и не влияет на ведение учета.

Для ввода данных следует с помощью кнопки Создать новый элемент списка командной панели табличной части "Плановая стоимость" вызвать форму элемента Плановая стоимость дня (создание).

Далее необходимо заполнить реквизиты:

  • Действует с – дата, начиная с которой для категории питающихся будет применяться значение плановой стоимости;
  • Стоимость 1 дня – плановая стоимость питания для одного питающегося на один день.

Табличная часть "Количество довольствующихся"

Табличная часть позволяет указать предполагаемую численность питающихся в данной категории и указать дату, начиная с которой указанная численность будет применяться.

Для ввода данных следует с помощью кнопки Создать новый элемент списка командной панели табличной части Количество довольствующихся вызвать форму элемента Численность довольствующихся (создание).

Далее необходимо заполнить реквизиты:

  • Действует с – дата, начиная с которой для категории питающихся будет применяться значение количества питающихся;
  • Количество довольстующихся – количество питающихся по данной категории.

Информация о количестве довольствующихся используется для автоматического заполнения в документе Меню-требование.
