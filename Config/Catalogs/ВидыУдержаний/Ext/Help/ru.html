Справочник "Виды удержаний"

Справочник Виды удержаний предназначен для хранения информации о видах удержаний при расчетах по оплате труда.

Справочник используется для ведения аналитического учета на счете 304.03 "Расчеты по удержаниям из выплат по оплате труда".

Работа со списком

Справочник Виды удержаний можно открыть с помощью команды Виды удержаний меню функций раздела Учет и отчетность.

Создание нового элемента

Для создания новой карточки лицевого счета можно нажать кнопку Создать командной панели формы списка Виды удержаний.
