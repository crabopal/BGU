Справочник "Виды операций отражения зарплаты в учете"

Справочник Виды операций отражения зарплаты в учете используется только для указания вида операции при заполнении документа Отражение зарплаты в учете.

Справочник поставляется заполненным и содержит предопределенные элементы. При необходимости элементы справочника можно отредактировать, а также добавить новые.

Работа со списком

Список Виды операций отражения зарплаты в учете можно открыть с помощью команды Виды операций отражения зарплаты в учете меню функций раздела Учет и отчетность.

Создание нового элемента

Для ввода в справочник нового элемента можно нажать на кнопку Создать командной панели формы списка Виды операций отражения зарплаты в учете.

Заполнение реквизитов элемента справочника
  • Наименование – наименование хозяйственной операции;
  • Код – краткое наименование хозяйственной операции, без пробелов;
  • Не использовать – после установки флага вид операции будет отсутствовать при выборе вида операции в выпадающем списке в документе Отражение зарплаты в учете.

Совет. Рекомендуем в начале работы с программой изучить перечень и настройки хозяйственных операций и при необходимости отключить неиспользуемые.

Табличные части Доступные счета и Доступные КЭК позволяют настроить для каждого вида Счета расходов и КЭК, которые можно будет использовать с этим видом операции.

Если флаги Все счета и Все КЭК сняты, то доступными будут только те значения, которые указаны в соответствующих табличных частях. При этом если флаг Все счета снят, а табличная часть не содержит значений, то для этого вида операции ввод Счета расходов будет недоступен.

Это имеет место, например, у видов операций Удержание НДФЛ из сумм по оплате труда, денежного довольствия, компенсаций и прочих выплат и Начисление пособий и др. выплат за счет средств государственного социального страхования.
