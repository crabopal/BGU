Справочник "Маршруты автобусов"

Справочник Маршруты автобусов предназначен для хранения перечня маршрутов. Используется для заполнения путевых листов.

Для вызова справочника можно использовать команду Маршруты автобусов меню функций раздела ГСМ.


Заполнение реквизитов элемента справочника
  • Наименование маршрута – название маршрута;
  • Номер маршрута, Наименование прямого маршрута и Наименование обратного маршрута – реквизиты, в которые вводится соответствующая информация о маршруте автобуса;
  • Группа – группа маршрутов, например, Городские маршруты.
