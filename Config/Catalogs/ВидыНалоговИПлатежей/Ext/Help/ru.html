Справочник "Виды налогов и платежей"

В справочнике Виды налогов и платежей содержится список налогов, сборов и иных платежей в бюджет.

Справочник используется для ведения аналитического учета по счету 303.00 "Расчеты по платежам в бюджеты".

Информация справочника используется также при оформлении платежных документов на перечисление налогов, сборов и иных платежей в бюджет.

Справочник Виды налогов и платежей в комплекте поставки программы заполнен отдельными видами налогов, взносов и сборов.

Работа со списком

Справочник Виды налогов и платежей можно открыть с помощью команды Виды налогов и платежей меню функций раздела Справочники.

Создание нового элемента

Для создания нового элемента можно нажать на кнопку Создать командной панели формы списка Виды налогов и платежей.

Заполнение реквизитов элемента справочника

При вводе нового элемента справочника необходимо заполнить реквизиты:

  • Наименование – наименование вида налога, сбора, страхового взноса или иного платежа в бюджет;
  • Счет учета – субсчет счета 303.00, который будет использован для формирования проводок при начислении и перечислении платежей. Выбирается из фрагмента Плана счетов ЕПСБУ, ограниченного субсчетами счета 303.00.

В группе реквизитов Код бюджетной классификацииследует заполнить:

  • Администратор поступлений – код администратора поступлений. Выбирается из справочника Главы по БК;
  • КБК дохода – код бюджетной классификации налога (сбора) по классификации доходов бюджетов Российской Федерации. Выбирается из справочника Классификация доходов бюджета.

Внимание!
В 14-17 разрядах кода доходов налогоплательщик должен самостоятельно указать код программы доходов, первый знак которого отражает вид платежа: налог (1), пени и проценты (2), штрафы (3). В типовой конфигурации в справочнике Классификация доходов бюджетов разряды 14-17 заполнены нулями. При перечислении налога или сбора следует самостоятельно отредактировать разряды 14-17 в соответствующем реквизите платежного документа (ПД). Также можно ввести в справочник отдельные элементы для пеней, процентов, штрафов.

В группе Реквизиты для подстановки в платежно-расчетные документы следует указать:

  • Очередность платежа,
  • Статус составителя (101) – выбирается из списка,
  • Текст назначения платежа.
