Справочник "Направления деятельности"

Справочник предназначен для ведения списка направлений, в рамках которых учреждение ведет свою деятельность. При соответствующей настройке Плана счетов Направления деятельности можно использовать в качестве аналитических разрезов при ведении учета на счетах:

  • 109.хх "Затраты на изготовление готовой продукции, выполнение работ, услуг";
  • 401.10 "Доходы текущего финансового года";
  • 401.20 "Расходы текущего финансового года".

Примечание. Настройка аналитического учета Плана счетов описана в главе 2 Формирование рабочего плана счетов, разделе Единый план счетов бухгалтерского учета, подразделе Свойства счетов, фрагменте Аналитический учет.

Также справочник используется для разделения по направлениям деятельности расчетов с контрагентами. Разделение расчетов по направлениям деятельности выполняется с помощью указания реквизита Направление деятельности в договоре с контрагентом в справочнике Договоры и иные основания возникновения обязательств.

В результате каждый договор с контрагентом относится к определенному направлению деятельности.

Работа со списком

Справочник Направления деятельности можно открыть с помощью команды Направления деятельности меню функций раздела Услуги, работы производство.

Создание нового элемента

Для создания нового элемента можно нажать на кнопку Создать командной панели формы списка Направления деятельности.

Заполнение реквизитов элемента справочника

Наименование – наименование вида деятельности.

Если учреждение оказывает детям только обязательные образовательные услуги, то справочник Направления деятельности должен в обязательном порядке содержать, по крайней мере, один элемент, например, Основной вид деятельности - Плата за содержание ребенка (присмотр и уход).

Если учреждение оказывает детям наряду с обязательными также дополнительные образовательные услуги, то справочник Направления деятельности должен в обязательном порядке содержать, по крайней мере, два элемента, например:

  • Основной вид деятельности - Плата за содержание ребенка (присмотр и уход);
  • Иностранный язык – Плата за дополнительные образовательные услуги.

Это необходимо для того, чтобы выделить Плату за содержание ребенка (присмотр и уход), поскольку в соответствии с законодательством компенсация предоставляется родителям только на эту, обязательную часть платы за образовательные услуги. По остальным, дополнительным видам услуг, компенсация родительской планы не предоставляется. В дальнейшем, при расчете компенсации родительской платы в документе Компенсация родительской платы следует выбирать группу с направлением деятельности, по которому учитываются только расчеты за содержание ребенка, а именно, присмотр и уход за ребенком в соответствующем образовательном учреждении.

Вид взаиморасчетов – укрупненный разрез учета. Позволяет получить данные о расчетах и результатах финансовой деятельности учреждения в разрезе видов взаиморасчетов, а в рамках каждого вида взаиморасчетов – в разрезе направлений деятельности. Выбирается из списка предопределенных значений.

Примечание. Все расчеты с учащимися рекомендуется вести в рамках вида взаиморасчетов Расчеты по платному обучению. То есть в договорах, заключенных со студентами, следует указывать направления деятельности, у которых выбран вид взаиморасчетов Расчеты по платному обучению.
Все расчеты по родительской плате необходимо вести в рамках вида взаиморасчетов Расчеты по родительской плате. Иначе говоря, в договорах, заключенных по различным видам родительской платы, следует указывать направления деятельности только с видом взаиморасчетов Расчеты по родительской плате.
