Справочник "Подразделения"

Справочник предназначен для ведения списка подразделений учреждения.

Справочник используется для выписки первичных документов, а также для ведения аналитического учета по счетам и объектам учета, для которых в настройке параметров учета установлено ведение аналитического учета по подразделениям.

Работа со списком

Список Подразделения можно открыть с помощью команды Подразделения меню функций раздела Справочники.

В форме списка предусмотрен отбор по Организации.

Справочник Подразделения является многоуровневым и позволяет объединять подразделения в произвольные группы.

Создание нового элемента

Для ввода нового элемента можно нажать на кнопку Создать командной панели списка Подразделения.

В форме элемента следует заполнить реквизиты Организация и Наименование.

Обособленное подразделение – после установки флажка становятся доступны для заполнения реквизиты на закладках Основные сведения и Адрес, телефон.

Важно!
Флажок Обособленное подразделение доступен только для элемента, который создан в корне справочника и таким образом не входит в какую-либо группу.

Закладка "Основные сведения"

Наименование для первичных документов – наименование обособленного подразделения для первичных документов.

Налоговый орган – выбирается из справочника Регистрации в налоговом органе.

Примечание. После заполнения поля Налоговый орган реквизиты КПП и Код налогового органа заполняются автоматически.

Обособленная нумерация документов – установка флажка позволяет реализовать в обособленном подразделении обособленную нумерацию документов с префиксом, указанном в поле Префикс.

В группе Ответственные лица следует указать данные ответственных лиц – Руководитель, Главный бухгалтер, Кассир и Руководитель ПФС.
