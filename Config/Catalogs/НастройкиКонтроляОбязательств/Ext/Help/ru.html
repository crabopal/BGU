Справочник "Настройки контроля обязательств"

Справочник Настройки контроля обязательств содержит настройки, которые используются при контроле принятия обязательств и формировании платежно-расчетных документов.

Для каждой организации, которая существует в информационной базе, в справочнике имеется своя настройка.

Для вызова формы списка справочника Настройки контроля обязательств можно использовать гиперссылку Настроить параметры контроля, которая становится доступна после установки флажка Контролировать расходы в группе Контроль расходов раздела Ведение учета формы Настройка параметров учета раздела Администрирование.

В форме списка предусмотрен отбор по организации.

Для поиска настройки для нужной организации также можно использовать форму поиска, которая вызывается с помощью кнопки Найти командной панели табличной части.

После того, как необходимая настройка найдена, ее следует открыть.

Форма Настройка контроля обязательств каждой организации позволяет настроить аналитические разрезы, по которым будет производиться контроль, а также вариант поведения системы при обнаружении несоответствия документа показателям санкционирования:

  • предупреждение о несоответствии и запись документа;
  • предупреждение о несоответствии и отказ от записи документа.

Предусмотрены следующие варианты контроля:

  • Контроль платежно-расчетных документов;
  • Контроль принятия денежных обязательств;
  • Контроль принятия обязательств.

Вариант Контроль платежно-расчетных документов позволяет настроить контроль:

  • непревышения суммы платежного документа над суммой принятого денежного обязательства;
  • непревышения суммы платежного документа над суммой принятого обязательства;
  • непревышения суммы платежного документа над суммой лимитов бюджетных обязательств и/или бюджетных ассигнований;
  • непревышения суммы платежного документа над суммой предельных объемов финансирования;
  • непревышения суммы платежного документа над суммой статьи плана финансово-хозяйственной деятельности.

Вариант Контроль принятия денежных обязательств позволяет настроить контроль непревышения суммы принятого денежного обязательства над суммой принятого обязательства.

Вариант Контроль принятия обязательств позволяет настроить контроль:

  • непревышения суммы принимаемого обязательства над суммой лимитов бюджетных обязательств и/или бюджетных ассигнований;
  • непревышения суммы принимаемого обязательства над суммой статьи плана финансово-хозяйственной деятельности.

Контроль обязательств настраивается с помощью флажков, установленных у соответствующих вариантов.

Щелчок по варианту, который отмечен флажком, открывает форму, позволяющую указать аналитические разрезы счетов, которые будут использоваться при контроле.

Кнопка Загрузить настройку по умолчанию предназначена для замены текущей настройки на настройку по умолчанию, в которой задан контроль показателей санкционирования по всем доступным аналитическим разрезам.
