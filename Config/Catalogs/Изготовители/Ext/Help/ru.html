Справочник "Изготовители"

Справочник Изготовители предназначен для хранения информации о производителях ОС и НМА:

  • Наименование.
  • Официальное наименование.
  • Код ОКПО.
  • Адрес.

Для вызова справочника Изготовители можно использовать команду Изготовители меню функций раздела ОС, НМА. НПА.
