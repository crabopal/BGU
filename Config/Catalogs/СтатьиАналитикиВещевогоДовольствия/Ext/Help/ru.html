Справочник "Статьи аналитики вещевого довольствия"


Справочник Статьи аналитики вещевого довольствия содержит статьи аналитики и используется для обмена данными с программой "1С:Вещевое довольствие 8", редакция 2.

Каждый элемент содержит сведения о комбинации значений КФО, КПС и ИФО, по которым может учитываться имущество на счете 105.00. Для каждой организации, участвующей в обмене, создается свой набор статей аналитики.

Статьи аналитики выгружаются в "1С:Вещевое довольствие 8", ред. 2 и используются при ведении учета вещевого имущества.

В последующем, при загрузке в "1С:Бухгалтерию государственного учреждения 8" данных из "1С:Вещевое довольствие 8", ред. 2 и автоматическом заполнении бухгалтерских документов по учету материальных запасов информация из статей аналитики используется для заполнения значений КФО, КПС и ИФО.

Создание нового элемента

Для ввода статьи аналитики вещевого довольствия можно нажать на кнопку Создать командной панели формы списка Статьи аналитики вещевого довольствия.

Заполнение реквизитов справочника


В форме Статья аналитики вещевого довольствия необходимо заполнить реквизиты:

  • Наименование – наименование статьи аналитики;
  • Организация
    • – выбирается из справочника Организации;
  • КФО – код финансового обеспечения. Выбирается из списка;
  • КПС – классификационный признак счета. Выбирается из справочника КПС;
  • ИФО – источник финансового обеспечения. Выбирается из справочника ИФО.
