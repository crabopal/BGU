Справочник "Группы учащихся"

Справочник Группы учащихся предназначен для ведения списка групп учащихся на Факультете. Элементы справочника Группы учащихся, являются дополнительными объектами группировки и используются в отборах учащихся в документах и отчетах.

Работа со списком

Справочник Группы учащихся можно открыть с помощью команды Группы учащихся меню функций раздела Платное обучение. В справочнике предусмотрен отбор по факультету.

Создание нового элемента

Для создания нового элемента можно нажать на кнопку Создать командной панели формы списка Группы учащихся.

В созданном элементе справочника Группы учащихся необходимо заполнить реквизит Наименование и выбрать Факультет.

Примечание. Создать новую группу в справочнике Группы учащихся можно также непосредственно при работе с документом Приказ (образование).
