Справочник "Бланки строгой отчетности"

К бланкам строгой отчетности относятся трудовые книжки, дипломы, свидетельства о рождении, паспорта и т.д.

Для ведения списка видов бланков строгой отчетности (БСО) в программе предназначен справочник Бланки строгой отчетности.

Также данный справочник используется для ведения учета в качестве субконто на забалансовом счете 03 Бланки строгой отчетности.

Работа со списком элементов справочника

Справочник Бланки строгой отчетности можно открыть с помощью команды Бланки строгой отчетности меню функций раздела Материальные запасы.

Создание нового элемента справочника

Для добавления в справочник нового вида БСО можно нажать на кнопку Создать командной панели формы Бланки строгой отчетности.

Заполнение реквизитов элемента справочника
  • Наименование – наименование вида бланка строгой отчетности;
  • Длина номера – число символов, равное длине номера данного вида БСО;

Примечание. Длина номера используется в документах по оформлению движений БСО. В соответствии с длиной номера формируется маска для ввода номера, наличие которой позволяет уменьшить количество ошибок при вводе номера.
  • Единица измерения - единица измерения бланков строгой отчетности. Выбирается из справочника Классификатор единиц измерения.
