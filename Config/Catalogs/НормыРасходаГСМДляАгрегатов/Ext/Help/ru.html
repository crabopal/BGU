Справочник "Нормы для расчета расхода ГСМ для агрегатов"

Справочник Нормы для расчета расхода ГСМ для агрегатов предназначен для хранения перечня норм расхода ГСМ для двигателей, которые входят в состав специального оборудования, силовых, тепловых и иных агрегатов. Параметры норм расхода используются для расчета нормативного расхода ГСМ.

Структура справочника разработана в соответствии со следующими вариантами расчета нормативного расхода:

  • по продолжительности времени работы;
  • по объему работы;
  • по показаниям счетчика агрегата.

Для вызова справочника можно использовать команду Нормы для расчета расхода ГСМ для агрегатов меню функций раздела ГСМ.

Заполнение реквизитов элемента справочника


Наименование – наименование нормы расхода ГСМ.

Вид нормы – выбирается из списка:

  • Базовая норма расхода ГСМ;
  • Норма расхода смазочных материалов и спец. жидкостей (ед. / на 100 ед. топлива).


Если Вид нормы имеет значение Базовая норма расхода ГСМ, то доступны для заполнения реквизиты:

Вид ГСМ (горючее) – выбирается из справочника Виды ГСМ.
Значение расхода горючего – указывается количество ГСМ, расходуемое за контрольный период времени, либо необходимое для выполнения контрольного объема работы или для получения контрольных показаний счетчика.
Единица измерения – выбирается из справочника Классификатор единиц измерения.

Основной параметр расчета выбирается из списка:

  • Продолжительность работы (в часах);
  • Объем работы;
  • Показания счетчика (в количестве единиц).

Значение основного параметра расчета – в зависимости от выбранного Основного параметра расхода указывается значение, соответствующее расходу ГСМ по норме:

  • контрольный период (в часах);
  • контрольный объем работы (в единицах измерения);
  • контрольные показания счетчика (в единицах измерения).

Единица измерения – единица измерения основного параметра расчета. Выбирается из справочника Классификатор единиц измерения.

Сезонная норма – флажок, который следует установить в случае, если норма расхода ГСМ является сезонной. После установки флажка становятся доступны реквизиты, описывающие период действия сезона:

  • Месяц начала сезона – порядковое число, месяц начала действия сезонных норм расхода ГСМ;
  • Число месяца начала сезона – порядковое число, день в месяце начала действия сезонных норм расхода;
  • Месяц окончания сезона – порядковое число, месяц окончания действия сезонных норм;
  • Число месяца окончания сезона – порядковое число, день в месяце окончания действия сезонных норм расхода ГСМ.

Если Вид нормы имеет значение Норма расхода смазочных материалов и спец. жидкостей (ед. / на 100 ед. топлива), то доступны для заполнения реквизиты:

  • Вид смазочного материала – выбирается из справочника Виды ГСМ;
  • для вида горючего топлива – выбирается из справочника Виды ГСМ;
  • Значение расхода – указывается количество ГСМ, расходуемое на 100 единиц топлива;
  • Единица измерения – выбирается из справочника Классификатор единиц измерения;
  • Сезонная норма – флажок, который следует установить в случае, если норма расхода ГСМ является сезонной. В случае установки флажка потребуется настройка периода действия сезонной нормы, описанная выше.

В группе реквизитов Основание применения указывается первичный документ – основание применения нормы расхода ГСМ.
