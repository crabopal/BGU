Справочник "Государственные контракты (договоры, соглашения)"

Справочник Государственные контракты предназначен для хранения сведений о государственных контрактах (договоров, соглашений), заключенных с открытием отдельных разделов лицевых счетов по каждому контракту в соответствии с Приказом Казначейства России от 09.01.2020 №1н..

Работа со списком

Список государственных контрактов можно открыть с помощью команды Государственные контракты меню функций раздела Планирование и санкционирование.

Создание нового элемента

Для добавления нового государственного контракта можно нажать кнопку Создать командной панели формы списка Государственные контракты.

Заполнение реквизитов элемента справочника

Идентификатор – идентификатор государственного контракта.
Предмет контракта – краткое наименование контракта, предмет поставки.

Переключатель Отдельные счета открываются: может находиться в положении:

  • В уполномоченном банке;
  • В органе казначейства.

Уполномоченный банк – банк, выбранный головным исполнителем, в котором все участники кооперации открывают отдельные счета. Выбирается из справочника Кредитные организации.

Казначейство – казначейство, назначенное головным исполнителем, в котором все участники кооперации открывают отдельные счета. Выбирается из справочника Казначейства.

Примечание. При создании отдельных счетов по государственному оборонному заказу наименование уполномоченного банка или, соответственно, казначейства, будет подставляться автоматически, по умолчанию.

Головной исполнитель – головной исполнитель поставок продукции по государственному оборонному заказу. Выбирается из справочника Контрагенты.
