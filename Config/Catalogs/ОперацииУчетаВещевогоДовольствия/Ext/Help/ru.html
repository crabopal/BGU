Справочник "Операции учета вещевого довольствия"


Справочник Операции учета вещевого довольствия содержит различные варианты учета вещевого довольствия и используется при загрузке данных из конфигурации «1С:Вещевое довольствие 8», ред. 2.

Заполнение справочника Операции учета вещевого довольствия производится в программе «1С:Бухгалтерия государственного учреждения» ред.2.

В дальнейшем при выполнении первой синхронизации элементы справочника будут автоматически перенесены в программу «1С:Вещевое довольствие 8» в справочник Варианты бухгалтерского учета операций.

Справочник Операции учета вещевого довольствия можно открыть с помощью команды Операции учета вещевого довольствия в группе Интеграция с 1С:Вещевое довольствие 8 в разделе Обмен данными и интеграция формы Настройка параметров учета раздела Администрирование.

Первоначальное заполнение справочника


Организация – выбирается из справочника Организации.

Первоначальное заполнение справочника выполняется автоматически.

Для заполнения справочника операциями учета вещевого довольствия следует нажать на кнопку Загрузить по умолчанию для организации командной панели формы справочника.

Каждый элемент справочника содержит сведения о типе загружаемого документа, типовой операции и значениях реквизитов документа и типовой операции.

Идентификация вида хозяйственной операции производится по значению реквизита Вид операции.

Список видов хозяйственных операций одинаков в программах «1С:Вещевое довольствие 8» и «1С:Бухгалтерия государственного учреждения 8».

Важно!
Добавление пользователем новых хозяйственных операций в справочник Операции учета вещевого довольствия или удаление существующих не предусмотрено.

Примечание. Так как настройки операций учета вещевого имущества в учреждениях различаются, то список операций учета вещевого довольствия следует формировать и настраивать для каждой организации, которая участвует в обмене.

Проверка и заполнение некоторых реквизитов элементов справочника


Каждый элемент справочника описывает вид документа, который создается для указанного вида операции, и некоторые реквизиты документа, которые
отсутствуют в программе «1С:Вещевое довольствие 8», но должны быть заполнены в программе «1С:Бухгалтерия государственного учреждения 8» ред. 2.

Шапка элемента справочника содержит заполненные реквизиты:

  • Наименование – наименование операции учета вещевого довольствия;
  • Организация – наименование организации;
  • Вид операции – наименование хозяйственной операции;
  • Вид документа – вид документа, который будет создан в программе 1С:Бухгалтерия государственного учреждения 8» ред. 2 в результате переноса данных, относящихся к соответствующей хозяйственной операции;
  • Типовая операция – наименование типовой операции.

В группе Настройка переноса документа установлен один из признаков:

  • Один документ – означает, что операция подлежит переносу и что в процессе синхронизации будет создан один документ;
  • Последовательность документов – означает, что при синхронизации в программе «1С:Бухгалтерия государственного учреждения 8» ред. 2 будет создано несколько документов;
  • Не переносится – означает, что документы для данной операции в процессе обмена создаваться не будут.

Форма операции содержит закладки Реквизиты документа, Реквизиты операции и Параметры обмена.

Общие правила заполнения реквизитов на данных закладках:

  • Значения следует указать для тех реквизитов, у которых после загрузки в справочник операций вещевого довольствия значения отсутствуют;
  • Если значения реквизитов указаны, то следует проверить эти значения и в случае необходимости скорректировать;
  • При необходимости переноса каких-либо иных реквизитов можно добавить их и указать для них значения.

Закладка "Реквизиты документа"


Содержит данные для заполнения реквизитов документа. Здесь могут быть указаны особые значения реквизитов документа.

Имя реквизита выбирается из списка в поле Представление реквизита. Список реквизитов определяется выбранным видом документа. Имя реквизита - это внутреннее имя реквизита.

Представление реквизита заполняется автоматически и содержит пользовательское представление, заданное для выбранного реквизита.

Значение реквизита выбирается или заполняется пользователем. При этом способ выбора или ввода зависит от типа значений реквизита.

Пример
Вид документа – Поступление МЗ (М-4). Необходимо указать способ зачета аванса для данного документа. Нажимаем на кнопку Добавить, открываем в поле Представление реквизита список и выбираем в списке значение – Зачет аванса (СпособЗачетаАнанса). Далее в поле Значение реквизита выбираем из списка необходимое значение – Автоматически, По документу или Не зачитывать.

Закладка "Реквизиты операции"


Содержит данные для заполнения дополнительных реквизитов операции. Также здесь могут быть указаны особые значения реквизитов операции.

Имя реквизита выбирается из списка, который определяется выбранной типовой операцией. Имя реквизита - это имя для формулы текущего реквизита.

Представление реквизита заполняется автоматически и содержит пользовательское представление, заданное для выбранного реквизита.

Значение реквизита выбирается или заполняется пользователем. При этом способ выбора или ввода зависит от типа значений реквизита.

Пример
Вид документа – Поступление МЗ (М-4), Типовая операция – Поступление по договорам купли–продажи, договорам поставки, другим аналогичным договорам. Необходимо указать способ принятия денежного обязательства. Нажимаем на кнопку Добавить, открываем в поле Представление реквизита список и выбираем в списке значение – Принять денежное обязательство (ПринятьДенежноеОбязательство). Далее в поле Значение реквизита выбираем из списка необходимое значение – Да или Нет.

Закладка "Параметры обмена"


Содержит правила особого заполнения реквизитов ИФО, КФО и КПС.

ИФО, КФО и КПС передаются из программы «1С:Вещевое довольствие 8», редакция 2 в виде элемента справочника Статьи аналитики с каждой строкой исходного документа.

В программе «1С:Бухгалтерия государственного учреждения 8», редакция 2 эти реквизиты могут располагаться в шапке документа или среди реквизитов типовой операции.

На закладке Параметры обмена указывается реквизит, который будет заполнен переданным значением.

Данные исходного документа содержит имя параметра, в котором передаются данные из программы «1С:Вещевое довольствие 8», ред. 2.

Принимающий реквизит содержит имя реквизита документа программы «1С:Бухгалтерия государственного учреждения 8», редакция 2 или дополнительного реквизита типовой операции, в который будет загружено переданное значение.

Пример
В программе «1С:Бухгалтерия государственного учреждения 8», редакция 2 реквизит ИФО всегда расположен в шапке документа, а КФО может быть дополнительным реквизитом типовой операции. Данная ситуация имеет место, например, в документе вида Поступление МЗ (М-4). В данном случае для реквизита ИФО, расположенного в поле Данные исходного документа, в поле Принимающий реквизит указан реквизит Документ.ИФО. А для реквизита КФО, расположенного в следующей строке в поле Данные исходного документа, в поле Принимающий реквизит указано значение ДополнительныйРеквизит.КФО.
