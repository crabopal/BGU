Справочник "Параметры договора и операций эквайринга"

Справочник Параметры договора и операций эквайринга предназначен для хранения данных о договоре эквайринга, эквайере, тарифах услуг эквайера по видам платежных карт, списка эквайринговых терминалов, обслуживаемых согласно договору эквайринга, а также параметров, определяющих порядок бухгалтерского и налогового учета операций эквайринга. Данная информация используется для заполнения реквизитов документа Эквайринговая операция.

Работа со списком

Список Параметры договора и операций эквайринга можно открыть с помощью команды Параметры договора и операций эквайринга раздела Денежные средства формы Настройка параметров учета раздела Администрирование.

Создание нового элемента

Для ввода элемента справочника можно нажать кнопку Создать командной панели формы списка Параметры договора и операций эквайринга.

Заполнение реквизитов элемента справочника
  • Эквайер – наименование эквайера. Выбирается из справочника Контрагенты;
  • Договор эквайринга – наименование договора с эквайером. Выбирается из справочника Договоры и иные основания возникновения обязательств;
  • Наименование – наименование договора с эквайером в произвольной форме;
  • Организация – наименование организации, которая будет принимать оплату платежными картами. Выбирается из справочника Организации;
  • Лицевой счет – лицевой счет организации, на который будут поступать денежные средства в результате операций эквайринга. Выбирается в справочнике Лицевые счета;
  • Источник средств – выбирается из списка.

Закладка "Тарифы"

На закладке Тарифы указываются тарифы договора эквайринга.

Для добавления тарифа можно использовать кнопку Добавить командной панели.


  • Вид платежной карты – выбирается из справочника Виды платежных карт;
  • % комиссии (торговой уступки) – процент комиссии, оговоренный эквайером;
  • Основной вид – флаг, установка которого позволяет автоматически заполнять реквизиты Вид платежной карты и % комиссии банка при создании нового документа Эквайринговая операция.

Закладка "Терминалы"

На закладке Терминалы следует указать терминалы, которые обслуживаются согласно данному договору эквайринга.

Для добавления терминала можно использовать кнопку Добавить командной панели.

Эквайринговый терминал – выбирается из справочника Эквайринговые терминалы.

Закладка "Параметры платежей"

Использовать для отражения оплат платежными картами – установка флажка позволяет задать заполнение документа Эквайринговая операция сводными данными по оплате в неавтоматизированной торговой точке (НТТ).

Группа Реквизиты платежей:

  • Подразделение – выбирается из справочника Подразделения.

Важно!
Реквизит Подразделение доступен для заполнения только при включенном учете по подразделениям в разделе Администрирование – Общие настройки (флажок Учет по подразделениям, гиперссылка Настроить учет по подразделениям для плана счетов).
  • КФО – код финансового обеспечения. Выбирается из списка;
  • КПС – классификационный признак счета назначения платежа. Выбирается из справочника КПС;
  • КЭК – код экономической классификации назначения платежа;
  • Ставка НДС – ставка налога на добавленную стоимость. Выбирается из списка.

Группа Дополнительная классификация заполняется, если на счетах 205.00, 209.00, 401.10 ведется дополнительный аналитический учет:

  • Код цели – выбирается из справочника Виды целевых средств.
  • Код мероприятия – выбирается из справочника Мероприятия.
  • Доп. классификация – выбирается из справочника Дополнительные бюджетные классификаторы.

Группа Настройки заполнения первичного документа:

Заполнять первичный документ при оплате – установка флажка позволяет настроить автоматическое заполнение реквизитов Вид, № и Дата группы Первичный документ документа Эквайринговая операция, после чего будет выполнено его автоматическое проведение. Если флажок отсутствует, то после факта оплаты и формирования слип чека потребуется вручную ввести указанные реквизиты слип чека в документ Эквайринговая операция, а затем вручную провести его.

Закладка "Комиссия банка"

Переключатель Комиссия за услуги банка-эквайера, может принимать значения:

  • Удерживается при проведении платежа;
  • Оплачивается после поступления денежных средств на счет учреждения.

Группа Учет комиссии в расходах организации.

В состав группы Бухгалтерский учет входят реквизиты:

  • Счет затрат;
  • КПС;
  • Субконто затрат 1;
  • Субконто затрат 2;
  • Субконто затрат 3.

При начале выбора реквизита Счет учета затрат в появившемся окне План счетов – рабочие счета в списке счетов слева следует выбрать счет расходов на комиссию эквайера, а затем в правом списке двойным щелчком мыши выбрать КПС для этого счета, согласно рабочему плану счетов. После выбора КПС реквизиты Счет учета затрат и КПС учета затрат элемента справочника будут заполнены автоматически.

Тип и наименования реквизитов Субконто затрат 1, Субконто затрат 2 и Субконто затрат 3 определяются выбранным значением реквизита Счет затрат.

Заполнение реквизитов группы Налоговый учет производится при условии оплаты приносящей доход деятельности и ведения учреждением налогового учета по налогу на прибыль.

В состав группы Налоговый учет входят реквизиты:

  • Счет затрат (НУ);
  • Субконто затрат 1 (НУ);
  • Субконто затрат 2 (НУ);
  • Субконто затрат 3 (НУ).

Тип и наименования реквизитов Субконто затрат 1 (НУ), Субконто затрат 2 (НУ) и Субконто затрат 3 (НУ) определяются при выборе реквизита Счет затрат (НУ).

Группа Дополнительная классификация заполняется аналогично закладке Параметры платежей, если на счетах 109.00, 401.20 ведется дополнительный аналитический учет.

При необходимости выбора варианта учета обязательств следует открыть группу Учет обязательств:

Переключатель Обязательства на текущий финансовый год может принимать значения:

  • Принимаются при проведении платежа (документом Эквайринговая операция);
  • Принимаются предварительно (документом Регистрация обязательств и сведений по договорам).
