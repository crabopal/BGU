Работа со списком

Список Прейскурант можно открыть с помощью команды Прейскурант группы Розничные продажи в меню функций раздела Денежные средства.

Создание нового элемента

Для ввода нового элемента справочника можно нажать на кнопку Создать командной панели формы списка Прейскурант. Для быстрого создания нескольких элементов справочника Прейскурант можно использовать Помощник создания номенклатуры прейскуранта и цен.

Заполнение реквизитов элемента справочника
  • Организация – заполняется автоматически значением Текущая организация.
  • Наименование – условное наименование номенклатуры розничных продаж.
  • Номенклатура – номенклатура розничной продажи. Выбирается из справочника Номенклатура.
  • Снята с продажи – флажок, используется при необходимости исключить номенклатуру из формы выбора при заполнении списка номенклатуры документа Чек ККМ.
  • Артикул – заполняется при наличии артикула и необходимости его указания.
  • Штрихкод – заполняется вручную или с помощью кнопки Новый штрихкод, расположенной справа от поля ввода, а также при помощи обработки присвоения штрихкодов для группы товаров.

В полях Наименование для чека ККМ, Признак предмета расчета и Ставка НДС отражаются значения для выбранного элемента справочника Номенклатура.

  • Количество по умолчанию – значение для заполнения поля Количество в строке табличной части в документах розничных продаж Чек ККМ.
  • Статья аналитики оплаты – элемент справочника Статьи аналитики оплаты чеков ККМ, соответствующий бюджетной классификации учета доходов от розничных продаж.

В реквизитах КФО, КПС и КЭК отражаются значения для выбранного элемента в поле Статья аналитики оплаты.

Группа Доп. классификация содержит реквизиты дополнительной бюджетной классификации, а именно, Код цели, Код мероприятия и Доп. классификация, которые заполняются при необходимости.
Параметры договора платежного агента – выбирается из справочника Параметры договора платежного агента. Заполняется при необходимости.

Примечание. Реквизит Параметры платежного агента становится доступен после установки флажка Использовать настройки платежного агента в группе Настройки формирования чека ККТ (54-ФЗ) раздела Денежные средства формы Настройка параметров учета раздела Администрирование.

Список цен в таблице Цены номенклатуры соответствует ценам, установленным документом Установка цен номенклатуры.

Для сохранения данных следует нажать кнопку Записать и закрыть.
