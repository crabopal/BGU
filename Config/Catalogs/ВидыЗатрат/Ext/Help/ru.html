Справочник "Виды затрат"

Содержит список видов затрат, которые используются в учете для детализации расходов.
Справочник применяется для ведения аналитического учета на расходных счетах как в бухгалтерском (106.00, 109.00), так и в налоговом учете (Н20, Н25, Н26).

Работа со списком

Справочник Виды затрат можно открыть с помощью команды Виды затрат меню функций раздела Материальные запасы.

Создание нового элемента

Для создания нового элемента можно нажать на кнопку Создать командной панели формы списка Виды затрат.

Заполнение реквизитов вида затрат

Наименование – осмысленное наименование вида затрат. Вводится в виде произвольного текста.

Реквизиты бухгалтерского учета

КЭК – код экономической классификации, выбирается из справочника КЭК, из списка КЭК счета затрат 109.60. Позволяет идентифицировать вид затрат в бюджетной классификации.

Примечание. В справочнике Виды затрат не применяются КЭК группы 3ХХ, поскольку эти КЭК не используются на счетах 109.ХХ. В видах затрат, применяемых на счетах 106.ХХ при поступлении НФА, следует применять элементы справочника Виды затрат с незаполненным КЭК (и не указывать в них КЭК 3ХХ). Виды затрат с пустым КЭК будут доступны для выбора с учетом отборов.

Реквизиты налогового учета

Реквизиты налогового учета в целях налогового учета по налогу на прибыль организаций классифицируют вид затрат в рамках деятельности, приносящей доход. Ведение в программе налогового учета по налогооблагаемой деятельности реализовано для КФО = 2.

При заполнении реквизитов налогового учета следует исходить из позиционирования вида затрат в рамках деятельности, приносящей доход.

Важно
Не следует создавать виды затрат отдельно для бухгалтерского и налогового учета. Рекомендуем по возможности использовать один вид затрат как в бухгалтерском, так и в налоговом учете. При заполнении налоговых реквизитов в процессе создания нового вида затрат следует исходить из поведения этой затраты в налоговом учете при отражении операций в рамках деятельности, приносящей доход, то есть для КФО = 2.

Если деятельность, приносящая доход, в учреждении не ведется, то значения налоговых реквизитов, установленные по умолчанию, можно оставить без изменения, так как на бухгалтерский учет значения налоговых реквизитов не влияют.

Реквизит Вид деятельности в налоговом учете, к которому относится вид затрат, определяет систему налогообложения, к которой относится вид затрат в рамках деятельности, приносящей доход. Может принимать одно из трех значений:

  • По деятельности с основной системой налогообложения (общая или упрощенная);
  • По отдельным видам деятельности с особым порядком налогообложения. При выборе данного значения вид затрат будет относиться к специальным режимам налогообложения – ЕСХН и т.д.;
  • По разным видам деятельности (распределяются пропорционально доходам по ст. 272 НК РФ). При выборе данного значения сумма затрат, собранная по текущему виду затрат, будет отнесена к расходам, уменьшающим прибыль только в части, относящейся к основной системе налогообложения. Распределение производится пропорционально доходу, полученному в рамках деятельности с общей системой налогообложения, к общей сумме доходов по налогооблагаемой деятельности.

Вид расхода в НУ – определяет вид затраты с позиции налогового учета. Значения выбираются из списка видов расходов, которые с точки зрения налогового учета имеют определенную специфику.
