Справочник "Реквизиты лицевых счетов"

Справочник Реквизиты лицевых счетов предназначен для хранения платежных реквизитов лицевого счета (раздела лицевого счета) и является подчиненным справочнику Лицевые счета.

Для вызова справочника Реквизиты лицевых счетов можно использовать команду Реквизиты лицевых счетов панели навигации элемента справочника Лицевые счета.

Для ввода нового раздела лицевого счета можно использовать копку Создать командной панели табличной части.

Заполнение элемента справочника

Банк/ Казначейство – выбирается из справочника Кредитные организации или из справочника Казначейства.

Счет казначейства – выбирается из справочника Банковские и казначейские счета.

В группе Филиал банка при необходимости можно указать наименование и местонахождение филиала банка.

Данные реквизиты будут в дальнейшем использованы при заполнении поля Плательщик.

Группа Банк для расчетов

Банк-корреспондент – выбирается из справочника Кредитные организации. Заполняется в случае непрямых расчетов.

Группа Реквизиты корреспондента («плательщик» или «получатель») в платежных документах.

Заполнение реквизитов ИНН, КПП и Наименование производится автоматически, копированием соответствующих значений из карточки Организации.

По умолчанию данные значения не редактируются. При необходимости отредактировать значение реквизита Наименование следует установить флажок Редактировать реквизиты корреспондента.

В группе Дополнительные параметры находятся флажки для настройки дополнительных параметров платежных документов:

  • Указывать сумму без копеек, если она в целых рублях.
  • Указывать в дате документа месяц прописью.
  • Всегда указывать КПП в платежных документах.
