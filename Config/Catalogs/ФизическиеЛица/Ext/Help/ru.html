Справочник "Физические лица"

Справочник Физические лица предназначен для хранения информации о физических лицах.

Работа со списком

Список физических лиц можно открыть с помощью команды Физические лица меню функций раздела Справочники.

Создание нового элемента

Для ввода нового справочника можно использовать кнопку Создать командной панели формы списка Физические лица.

Другой способ создания карточки физического лица предусматривает ввод нового элемента в справочник Контрагенты, у которого реквизит Вид контрагента будет иметь значение Физ. лицо.

Последующее заполнение реквизитов на карточке физического лица в справочнике Физические лица, например, Дата рождения, ИНН, СНИЛС и других, приведет к автоматическому заполнению идентичных реквизитов карточки физического лица в справочнике Контрагенты. Обратное также верно.

При смене фамилии, имени или отчества физического лица необходимо отредактировать реквизит ФИО его карточки.

При записи карточки после редактирования наименования программа откроет диалог с вариантами ответа:

  • Исправлена ошибка. При выборе этого варианта реквизиты ФИО в Истории изменений имени физического лица будут исправлены автоматически. При этом дата исправления ошибки не будет зарегистрирована.
  • Изменилось имя. В случае выбора этого варианта в Историю изменений имени физического лица будет добавлена запись с указанием даты изменения и новых реквизитов ФИО.
  • Отмена.

Просмотреть историю ФИО можно по гиперссылке История изменений имени физического лица.

Аналогично, с помощью соответствующих гиперссылок, можно просмотреть историю изменений сведений о гражданстве и историю документа, удостоверяющего личность.
