Справочник "Банковские карты"

Справочник Банковские карты предназначен для хранения информации о банковских картах, выданных организации в соответствии с правилами обеспечения организаций наличными денежными средствами.

Работа со списком

Список Банковские карты можно открыть с помощью команды Банковские карты меню функций раздела Денежные средства.

Создание нового элемента

Для ввода элемента справочника можно нажать кнопку Создать командной панели формы списка Банковские карты.

Заполнение реквизитов элемента справочника

В форме Банковские карты необходимо заполнить реквизиты:

  • Организация – заполняется автоматически наименованием текущей организации. При необходимости данное значение можно изменить, выбрав другую организацию в справочнике Организации.
  • Номер – номер банковской карты.
  • Сотрудник – сотрудник, которому выдана банковская карта. Выбирается из справочника Сотрудники.
  • Наименование – наименование банковской карты.
