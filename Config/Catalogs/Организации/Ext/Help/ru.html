Справочник "Организации"

Справочник Организации предназначен для хранения списка учреждений (филиалов, структурных подразделений, выделенных на самостоятельный баланс), по которым в программе следует вести обособленный учет с получением отдельного баланса.

Этот справочник используется для ведения обособленного учета в разрезе учреждений, для вывода в документах и отчетах информации об учреждениях, а также для получения аналитических отчетов по учреждению.

Справочник Организации является разделителем учета. Любая операция, документ в программе вводятся от имени конкретного учреждения.

Работа со списком

Справочник Организации можно открыть с помощью команды Организации меню функций раздела Справочники.

Создание нового элемента

Для создания новой организации можно нажать на кнопку Создать новый элемент командной панели формы списка Организации.

Справочник одноуровневый. При вводе нового элемента программа предлагает заполнить в режиме диалога реквизиты, в которых будут храниться сведения об организации.

При вводе в справочник новой карточки организации ей автоматически присваивается внутренний учетный код.

Форма "Основное"

Данная форма содержит основные сведения об организации:

  • Наименование в программе – рабочее наименование, которое отображается в списке организаций, в списках документов и справочников, в полях формы.
  • Код – служебный реквизит, уникальный в информационной базе. Не рекомендуется редактировать.
  • Наименование полное – официальное наименование организации в соответствии с учредительными документами. Используется при печати документов, обмене с банковскими и казначейскими органами.
  • Наименование сокращенное – сокращенное наименование организации в соответствии с учредительными документами.
  • Использовать в платежных документах сокращенное наименование – признак использования сокращенного наименования при печати и экспорте платежных документов.
  • Наименование латиницей – наименование организации латинскими буквами. Используется при экспорте и печати заявлений на проведение операций с иностранной валютой.
  • Головная организация – указывается для обособленных подразделений, ведущих учет в одной информационной базе с головным учреждением.
  • Префикс – префикс, который включается в номер документа. В случае ведения учета по нескольким организациям, позволяет нумеровать документы по каждой организации по отдельности.

Внимание!
Если в одной информационной базе ведется учет по нескольким организациям, то указание префикса является обязательным для всех организаций в информационной базе. В отсутствие префиксов номера, присвоенные документам одной организации, не смогут использоваться для документов другой организации.

Для обособленного учета операций по переданным полномочиям рекомендуется использовать разделитель учета «Организация» - ввести в справочник Организации элемент для каждого органа исполнительной власти, передавшего полномочия, далее – орган, передавший полномочия.

Примечание. Для каждого органа, передавшего полномочия (элемента справочника Организации) следует ввести свою учетную политику.

Для нового элемента справочника Организации следует заполнить следующие реквиты:

  • Учет переданных полномочий – флажок устанавливается, для созданного элемента справочника, предназначенного для учета операций по переданным полномочиям. В результате установки флажка появляется реквизит Получатель полномочий, в котором следует указать учреждение, которому переданы полномочия по совершению операций.
  • Префикс – предназначен для настройки порядка нумерации документов для учреждения, получившего полномочия. Если префикс учреждения и органа, передавшего полномочия, одинаковые - нумерация единая. Если для органа, передавшего полномочия. установить другой префикс - нумерация будет раздельная.
  • Учетный номер – код по реестру получателей бюджетных средств или учетный номер, присвоенный органом казначейства.
  • ОКПО – код по ОКПО.
  • ИНН – идентификационный номер налогоплательщика.
  • КПП – код причины постановки на учет.
  • ОГРН – государственный регистрационный номер.
  • Дата регистрации – дата регистрации организации.

Внимание!
При оформлении документов по органу, передавшему полномочия, используются списки подразделений, сотрудников, ответственных лиц учреждения, указанного в реквизите Получатель полномочий.
При оформлении операций движения денежных средств по переданным полномочиям допустимо использовать Лицевые счета как органа, передавшего полномочия (лицевые счета по переданным полномочиям), так и отдельные лицевые счета.
По органу, передавшему полномочия, не ведется отдельная кассовая книга, все операции с наличными денежными средствами отражаются в кассовой книге учреждения, указанного в реквизите Получатель полномочий.

Группа реквизитов Учредитель:

Бюджет – бюджет, из которого учреждение получает финансовое обеспечение. Выбирается из справочника Бюджеты.
Субъект Российской Федерации – выбирается из справочника Субъекты РФ.

Подгруппа реквизитов Орган, осуществляющий полномочия учредителя:

Код главы – код главного распорядителя средств. Выбирается из справочника Главы по БК.
ОКПО – ОКПО учредителя.
Распорядитель – распорядитель бюджетных средств (если есть), в ведении которого находится учреждение. Выбирается из справочника Контрагенты. Получатель бюджетных средств, например, указывает в данном реквизите вышестоящего распорядителя.

Группа реквизитов Налоговый орган предназначена для хранения информации о налоговом органе, в который сдается отчетность. Включает следующую информацию о налоговом органе:

Код – код налогового органа.
Наименование – краткое наименование налогового органа, отображаемое в списках и полях формы.
ОКТМО (ОКАТО) налогового органа.

Если организация является крупнейшим налогоплательщиком, то следует установить флажок Организация является крупнейшим налогоплательщиком и в реквизите Код налогового органа – получателя отчетности указать код ИФНС – получателя отчетности по крупнейшим налогоплательщикам.

Код, Наименование, ОКТМО (ОКАТО) заполняются автоматически на основании информации, указанной в карточке регистрации в налоговом органе.

Группа реквизитов Ответственные лица содержит информацию об ответственных лицах учреждения, в том числе о датах назначения их на должности, а также изображение оттиска печати учреждения.

Группа реквизитов Адреса, телефоны содержит данные:

Юридический адрес – юридический адрес организации. Выбирается из адресного классификатора или вводится вручную.
Фактический адрес – фактический адрес организации. Выбирается из адресного классификатора или вводится вручную.
Почтовый адрес – почтовый адрес организации. Выбирается из адресного классификатора или вводится вручную.
Адрес за пределами РФ – фактический адрес организации. Заполняется только для зарубежных организаций. Выбирается из адресного классификатора или вводится вручную.
Международный адрес – вводится международный формат адреса.
Email – адрес электронной почты организации.
Факс – номер факса организации. Вводится с помощью специального окна или вручную. Может содержать несколько номеров.
Телефон – номер телефона организации. Вводится с помощью специального окна или вручную. Может содержать несколько номеров.
Другое – любая дополнительная контактная информация.

В группе реквизитов Пенсионный фонд следует указать:

Регистрационный номер – регистрационный номер в ПФР.
Код территориального органа – код территориального органа ПФР.
Территориальный орган – краткое наименование территориального органа ПФР.

В группе реквизитов Фонд социального страхования следует указать:

Регистрационный номер в ФСС – регистрационный номер страхователя их «Извещения о регистрации в качестве страхователя».
Код подчиненности – код подчиненности из «Извещения о регистрации в качестве страхователя».
Территориальный орган – наименование территориального органа ФСС.

В группе реквизитов Коды статистики следует указать:

ОКОНХ – отрасль народного хозяйства к которой относится организация в соответствии с общероссийским классификатором "Отрасли народного хозяйства".
ОКОПФ – организационно-правовая форма по ОКОПФ. Выбирается из справочника ОКОПФ.
ОКФС – форма собственности по ОКФС.
ОКВЭД ред. 1 – код основного вида деятельности по ОКВЭД по Общероссийскому классификатору видов экономической деятельности ОК 029-2007 (КДЕС Ред. 1.1).

Примечание. С 2017 года в отчетности в ФНС и Росстат используется код ОКВЭД ред. 2, поэтому код ОКВЭД ред. 1 с 2017 года можно не заполнять.

ОКВЭД ред. 2 – указывается код по Общероссийскому классификатору видов экономической деятельности ОК 029-2014 (КДЕС Ред. 2).
Код территориального органа Росстата – заполняется при предоставлении отчетности в Роста. Необходим для формирования отчетов в электронном виде.

Группа реквизитов Дополнительно содержит реквизиты:

УИС ЭД (УФЭБС) – уникальный идентификатор составителя электронного документа. Используется при осуществлении безналичных расчетов через расчетную сеть Банка России.

Также в основной форме карточки учреждения с помощью кнопки Ещё - Лимиты остатка кассы задается сумма лимита остатка денежных средств в кассе учреждения. При возникновении превышения лимита остатка наличных денег, сумма превышения выводится в форме документа Отчет кассира.

Форма "Учетная политика организации"

Для просмотра и редактирования учетной политики организации необходимо использовать команду Учетная политика на панели навигации формы элемента справочника Организации.

Форма "Лицевые счета организации"

Открыть форму списка справочника Лицевые счета организации для просмотра и редактирования можно с помощью команды Лицевые счета на панели навигации формы элемента справочника Организации.

Форма "Мероприятия по информатизации"

Открыть форму списка справочника Мероприятия по информатизации для просмотра и редактирования можно с помощью команды Мероприятия по информатизации на панели навигации формы элемента справочника Организации.
