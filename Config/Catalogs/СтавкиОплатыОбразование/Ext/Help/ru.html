Справочник "Ставки оплаты"

Справочник Ставки оплаты предназначен для ведения списка ставок по краткосрочным договорам образования для оплаты образовательных услуг, а также услуг других видов, оказываемых учреждением на периодической основе. Ставка оплаты представляет собой тариф или правило, по которому будет рассчитываться сумма начисления.

Внимание!
По долгосрочным договорам на оказание образовательных услуг для указания срока оплаты, суммы и периода обучения, за который производится оплата, следует вводить данные в справочник Графики оплаты.

Работа со списком

Список ставок оплат можно открыть с помощью команды Ставки оплаты меню функций раздела Платное обучение.

Создание нового элемента

Для создания нового элемента можно нажать на кнопку Создать командной панели формы списка Ставки оплаты.

Внимание! Ставки оплаты доступны для всех учреждений, для которых в информационной базе предусмотрено ведение учета.

Заполнение реквизитов элемента справочника

Наименование – текстовое наименование ставки оплаты. Например, Обучение на факультете электронной техники, Семестр (фиксированный) и т.д.

Состояние – выбирается из списка:

  • Подготовлено – применяется, если ставку оплаты по какой-либо причине еще нельзя использовать. Например, ставка оплаты разработана, но еще не утверждена;
  • Действует – применяется для действующей ставки. Ставка с состоянием Действует доступна для выбора в документах и может быть использована при назначении потребителям оплаты за услуги;
  • Закрыто – применяется для ставки, которую отменили или период действия которой закончился. Ставка со значением Закрыто недоступна для выбора в документах и не может быть использована при назначении потребителям оплаты за услуги.

По умолчанию, при создании новой карточки ставки для реквизита Состояние задается значение Действует.

Действует с: и по: – период действия ставки оплаты. Может быть задан как диапазон, ограниченный датой начала и датой окончания. Выбранный период накладывает ограничения на применение ставки оплаты. Ставку оплаты можно назначить приказом, только если дата начала действия приказа находится внутри периода действия ставки.

Пример. Если даты начала и окончания периода в реквизите Возможно к выбору не указаны, то Ставка оплаты доступна для выбора в документах в любом периоде. Если в реквизите Возможно к выбору указана дата начала периода, а дата окончания периода не задана, то Ставка оплаты доступна для выбора в документах начиная с указанной даты.

При необходимости ввода дополнительной информации по строке можно использовать реквизит Описание.

Валюта – валюта ставки оплаты, в которой для учащегося будут производиться начисления за услуги образования.

Внимание! Реквизит доступен для заполнения только при установленном флаге Учет расчетов и обязательств ведется в иностранных валютах в разделе Общие настройки формы Настройка параметров учета.

При создании новой Ставки оплаты необходимо выбрать вариант расчета итоговой суммы оплаты. Система предоставляет два ключевых варианта начисления:
Вычисляемый и Фиксированный.

Фиксированная ставка за период – снятый флажок означает, что выбран Вычисляемый вариант.

Вычисляемый вариант применяется, если сумма начисления определяется хотя бы одним из параметров:

  • Ставка за месяц – фиксированная ставка, не зависит от фактического количества посещений;
  • Переменная ставка за месяц – при расчете суммы учитывается количество фактических посещений за месяц;
  • Ставка за день (за посещение) - устанавливается плата за один день (одно посещение).

Значение каждого параметра вводится в соответствующий реквизит на закладкев группе Порядок начисления. Программа позволяет одновременно задать для Ставки оплаты от одного до трех параметров. При расчете суммы начисления значения всех параметров будут учтены.
Формула расчета суммы оплаты в общем случае по всем заданным параметрам выглядит следующим образом:

Результат = (Ставка за месяц + Переменная ставка за месяц * Дней посещения / Количество рабочих дней + Ставка за день * Дней посещения)

Фиксированный режим расчета ставки включается установкой флага Фиксированная ставка за период, после чего становятся доступны реквизит Сумма, а также табличная часть Порядок начисления.

Сумма – сумма оплаты за семестр, учебный год и т.д., установленная в договоре на обучение.

После ввода значения в поле Сумма следует нажать на кнопку Распределить по периодам командной панели табличной части Порядок начисления. В появившемся диалоге Заполнение по периодам следует выбрать месяц в реквизите Месяц начала начисления и указать количество месяцев в реквизите Количество периодов.

После нажатия на кнопку ОК в форме диалога будет выполнено автоматическое распределение общей суммы оплаты на количество месяцев для определения суммы начисления помесячно. В последнем месяце учитывается погрешность при делении с помощью добавления разницы к сумме. Результат распределения общей суммы оплаты будет представлен в табличной части Порядок начисления.

Пример. Учащийся обучается в образовательном учреждении по договору, в котором установлена сумма оплаты за обучение 81 000 руб. за очередной семестр (6 месяцев). В этом случае после установки флага Фиксированная ставка за период в реквизите Сумма следует указать общую сумму обучения за семестр 81 000 руб. В диалоге Заполнение по периодам следует выбрать месяц начала начисления и ввести число "6" в поле Количество периодов. После нажатия на кнопку ОК для каждого Периода начисления (месяца) будет показана сумма оплаты за обучение, которая в данном случае составляет 13 500 руб.
