Справочник "Скидки (наценки, ограничения)"

Справочник Скидки (наценки, ограничения) предназначен для хранения сведений о скидках (льготах) для отдельных категорий розничных покупателей, а также о наценках.

Работа со списком

Список Скидки (наценки, ограничения) можно открыть с помощью команды Скидки (наценки, ограничения) меню функций раздела Денежные средства.

Создание нового элемента

Для ввода нового элемента справочника можно нажать на кнопку Создать командной панели формы списка Скидки (наценки, ограничения).

Заполнение реквизитов элемента справочника

В форме Скидка (наценка, ограничение) необходимо заполнить реквизиты:

  • Наименование – условное наименование скидки (наценки).
  • Статус действия – при создании нового элемента имеет по умолчанию значение Действует.

Примечание. При необходимости отменить скидку следует выбрать значение Отменена.
  • Способ предоставления – возможные значения Сумма или Процент.
  • Значение – числовое значение величины скидки.

Примечание. При назначении наценки процент в поле Значение должен быть со знаком минус.

Дата начала действия и Дата окончания действия - значения реквизитов заполняются для скидок, активных в определенный период времени.

Получатели – перечень получателей – элементов справочника Контрагенты (в группе).

Округлять сумму скидки – настройка округления результата расчета скидки со способом предоставления Процент.
