Справочник "Льготы учащихся и воспитанников"

Справочник Льготы учащихся и воспитанников предназначен для ведения списка льгот, которые устанавливаются для льготных категорий граждан. Размер льготы (скидки по оплате) указывается в процентах.

Работа со списком

Список льгот можно открыть с помощью команды Льготы учащихся и воспитанников меню функций раздела Платное обучение.

Создание нового элемента

Для создания нового элемента можно нажать на кнопку Создать командной панели формы списка Льготы учащихся и воспитанников.

Заполнение реквизитов элемента справочника

  • Наименование – наименование льготы;
  • Процент льготы – указать числом процент льготы.

При необходимости в поле Описание вводится описание льготы в виде произвольного текста.
