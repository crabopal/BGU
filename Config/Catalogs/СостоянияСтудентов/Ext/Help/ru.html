Справочник "Состояния учащихся"

В каждый момент времени учащийся может находиться в одном из состояний, например, Зачислен, Академический отпуск, Отчислен и т.д.

Для хранения информации о возможных состояниях учащихся, а также для установления связи между состоянием и необходимостью выполнять начисление оплаты предназначен справочник Состояния учащихся.

Работа со списком

Список состояний учащихся можно открыть с помощью команды Состояния учащихся навигациименю функций раздела Платное обучение.

Создание нового элемента

Для создания нового элемента можно нажать на кнопку Создать командной панели формы списка Состояния учащихся.

Заполнение реквизитов элемента справочника

  • Наименование – наименование состояния учащихся;
  • Действует начисление – если флаг Действует начисление установлен, то при выборе в Приказе (образование) данного состояния для учащегося будет производиться начисление за образовательные услуги. При снятом флаге начисление за образовательные услуги выполняться не будет.

Пример. Учащийся написал заявление об уходе в академический отпуск. В программе создается новое состояние Академический отпуск, при этом флаг Действует начисление для этого состояния не устанавливается. В последующем при проведении документа Приказ (образование) вида Академический отпуск учащийся будет переведен в новое состояние Академический отпуск, для которого начисление оплаты за образовательные услуги выполняться не будет.

При снятом флаге Действует начисление доступен реквизит Начислять в день приказа.

Начислять в день приказа – при установленном флаге Начислять в день приказа начисление оплаты за обучение производится по день приказа о прекращении обучения включительно.

Пример. Принято решение об отчислении учащегося из образовательного учреждения. В программе создается новое состояние Отчислен, в карточке которого устанавливается флаг Начислять в день приказа. При проведении приказа для учащегося в состоянии Отчислен начисление за образовательные услуги будет выполняться по дату приказа включительно.
