Справочник "Эквайринговые терминалы"

Справочник Эквайринговые терминалы предназначен для хранения данных об используемых эквайринговых терминалах и устройствах печати слип-чеков.

Работа со списком

Список Эквайринговые терминалы можно открыть с помощью команды Эквайринговые терминалы раздела Денежные средства формы Настройка параметров учета раздела Администрирование.

Создание нового элемента

Для ввода элемента справочника можно нажать кнопку Создать командной панели формы списка Эквайринговые терминалы.


Заполнение реквизитов элемента справочника


Наименование – наименование терминала.

Использовать эквайринговый терминал без подключения к системе – флаг устанавливается в случае, если терминал работает автономно, без подключения к программе «1C:Бухгалтерия государственного учреждения 8».

Подключаемое оборудование (терминал) – терминал, подключенный к программе «1C:Бухгалтерия государственного учреждения 8». Выбирается из списка Подключаемое оборудование.

Использовать отдельное устройство для печати слип-чеков – флаг устанавливается в случае, если для печати слип-чеков используется не терминал, а фискальный регистратор.

Подключаемое оборудование (фискальный регистратор) – фискальный регистратор, который будет использоваться для печати слип-чеков. Выбирается из списка Подключаемое оборудование.
