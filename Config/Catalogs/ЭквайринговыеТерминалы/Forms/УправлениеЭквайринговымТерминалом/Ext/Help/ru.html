Управление эквайринговым терминалом

Форма Управление эквайринговым терминалом предназначена для выполнения сверки итогов с банком-эквайером.

Для вызова формы Управление эквайринговым терминалом можно использовать команду Управление эквайринговым терминалом в группе Эквайринг в меню функций раздела Денежные средства.

Сверка итогов с банком-эквайером

Для сверки итогов с банком-эквайером в случае использования подключаемого оборудования следует использовать кнопку Выполнить сверку итогов с банком.

Если на рабочем месте подключено несколько эквайринговых терминалов, то в процессе сверки итогов потребуется выбрать терминал, для которого должна быть выполнена сверка.

По окончании сверки будет напечатан документ-отчет сверки итогов с банком-эквайером на терминале или на фискальном регистраторе.

Отмена оплаты платежной картой

Для отмены оплаты платежной картой используется команда Отменить оплату панели навигации документа Эквайринговая операция.

Примечание. Отмена оплаты по карте может быть проведена только в течение открытой смены, до проведения сверки итогов.

В результате выполнения команды будут напечатаны слип-чек для операции отмены платежа на терминале или на фискальном регистраторе, а также документ Чек ККМ на возврат.

Напечатать последний слип-чек

При необходимости напечатать слип-чек последней банковской операции следует нажать кнопку Напечатать последний слип-чек в группе Дополнительные операции.
