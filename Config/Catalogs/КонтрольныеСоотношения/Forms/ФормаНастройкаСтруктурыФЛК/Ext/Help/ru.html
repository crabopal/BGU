Настройка структуры таблицы

Предназначена для редактирования колонок таблицы проверок контрольного соотношения.

При открытии формы настройки в левом окне будут заполнены доступные элементы колонок.В правом окне отображаются уже установленные колонки.

Для добавления элементов из левой части дерева в правую часть таблицы:

  • кликнуть два раза левой кнопкой мыши
  • нажать на левую кнопку мыши и перетащить в правое окно

 

Для реквизитов аналитики, таких как «Код», «Наименование» можно указать интервал символов проверки. В структуре таблицы выберите строку с реквизитом и в нижнем правом углу установите интервал при необходимости.
