Документ "Расчет платы по долгосрочным договорам (образование)"

Документ Расчет платы по долгосрочным договорам (образование) предназначен для использования в качестве основания для выписки квитанций на оплату по долгосрочным договорам по образовательным услугам.

Формирование квитанций по данным документа предполагается в случае, когда учреждение формирует квитанции на оплату до выполнения начислений за период по долгосрочным договорам.

Заполнение документа выполняется по данным регистра сведений Порядок оплаты (образование), при этом сумма выполненной оплаты за период определяется по данным регистра Расчеты с учащимися.

Документ не формирует движений по регистрам.

Работа со списком документов

Список документов Расчет платы по долгосрочным договорам (образование) можно открыть с помощью команды Расчет платы по долгосрочным договорам (образование) меню функций раздела Платное обучение.

В форме списка предусмотрен отбор по реквизитам Организация и Факультет.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Расчет платы по долгосрочным договорам (образование).

Заполнение реквизитов шапки документа

По каждой услуге, которая будет оказана учащимся следует ввести отдельный документ Расчет платы по долгосрочным договорам (образование).

Период платежей – указывается период, за который предполагается формировать квитанции на оплату;

Способ заполнения – в зависимости от выбранного способа заполнения порядок получения плановых данных отличается:

  • Для способа заполнения по оплачиваемому периоду отбор выполняется по данным графиков платежей с оплачиваемым периодом, полностью входящим в период, выбранный в документе.
  • Для способа заполнения по дате оплаты отбор выполняется по данным графиков платежей с датой оплаты, входящей в период, выбранный в документе.

Факультет – выбирается из справочника Подразделения. При заполнении учащихся выполняется отбор по факультету;

Номенклатура – выбирается из справочника Номенклатура, наименование образовательной услуги, используется при формировании назначения платежа.

Заполнение реквизитов табличной части

Заполнение табличной части документа выполняется с помощью команды Заполнить - Учащимися по отбору.

При использовании команды Добавить отбор выполняется аналогичным способом, по учащимся содержащим данные в регистре Сведения об учащихся.

Автоматически заполняются следующие реквизиты табличной части:

  • Учащийся – учащийся факультета.
  • Группа Плательщик включает реквизиты Контрагент и Договор контрагента, которые указаны в карточке учащегося.
  • Период – период, за который формируется квитанция на оплату.
  • Дата оплаты – запланированная дата оплаты, указанная в графике оплаты.
  • Сумма по договору – сумма начислений по графику оплаты.
  • Оплачено – сумма оплаты за периода по данным регистра Расчеты с учащимися.
  • Сумма к оплате – сумма к оплате по графику оплаты, за вычетом уже оплаченных сумм.
