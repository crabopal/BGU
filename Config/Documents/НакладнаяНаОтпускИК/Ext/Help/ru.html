Документ "Накладная на отпуск материалов на сторону (имущество казны)"

Документ Накладная на отпуск материалов на сторону (имущество казны) предназначен для отражения в учете операций по передаче и перемещению материальных запасов, входящих в состав имущества казны.

Документ позволяет оформить следующие операции:

  • Передача на сторону;
  • Передача по договору аренды;
  • Передача по договору безвозмездного пользования;
  • Реализация.

После заполнения и записи документа можно сформировать печатные формы Накладная на отпуск материальных ценностей на сторону (ф. 0510458), Акт о приеме-передаче объектов нефинансовых активов (ф. 0510448).

Также после заполнения реквизитов бухгалтерской операции и проведения документа можно сформировать Справку о содержании драг. материалов и бухгалтерскую справку по ф. 0504833.

Примечание. При проведении документа Накладная на отпуск материалов на сторону (Имущество казны) в программе будет отражено исполнение графика передачи или перемещения материальных запасов по договору с контрагентом, если по данному договору ведется график реализации.

Работа со списком документов

Список документов вида Накладная на отпуск материалов на сторону (имущество казны) можно открыть с помощью команды Накладная на отпуск (имущество казны) меню функций раздела Имущество казны.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Накладная на отпуск материалов на сторону (имущество казны).

Заполнение реквизитов шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

  • Контрагент – выбирается из справочника Контрагенты.
  • Договор – выбирается из справочника Договоры и иные основания возникновения обязательств, подчиненного справочнику Контрагенты.
  • Контроль – гиперссылка для вызова формы Контроль исполнения договоров с информацией об общем объеме запланированных (неисполненных) обязательств по договору, а также о сумме просроченных обязательств по договору (в т.ч. более 30 и более 90 дней просрочки).

Примечание. Гиперссылка Контроль доступна в Накладных на отпуск материалов на сторону (Имущество казны) по договорам, в которых задано ведение графиков исполнения.
  • Перевозчик – выбирается из справочника Контрагенты;
  • КФО – код финансового обеспечения, равен "1" (бюджетная деятельность);
  • КПС – классификационный признак счета учета материалов в составе имущества казны. Выбирается из справочника КПС.

Закладка "Материалы"

Информация о материальных запасах вводится в табличную часть.

Номенклатура – наименование материала, выбирается из справочника Номенклатура.

Для выбора материальных запасов удобно использовать форму подбора, которая открывается с помощью кнопки Подобрать командной панели табличной части.

После выбора материалов с использованием формы подбора в строках табличной части также будут заполнены реквизиты:

  • Единица измерения – единица измерения Значение совпадает со значением реквизита Ед. измерения элемента номенклатуры;
  • Количество – количество в учетных единицах.
  • Примечание – дополнительная информация в виде текста. Вводится при необходимости.

При выборе в шапке документа вида передачи Реализация для заполнения станут доступны реквизиты:

  • Цена – цена единицы номенклатуры.
  • Сумма – значение суммы вычисляется автоматически.
  • Ставка НДС – ставка налога на добавленную стоимость. Значение выбирается из выпадающего меню.
  • Сумма НДС – значение суммы налога на добавленную стоимость. Рассчитывается автоматически.
  • Всего – итоговая сумма по строке. Рассчитывается автоматически.

Закладка "Драгоценные материалы"

Табличная часть Материальные запасы, расположенная в левой части закладки, содержит список всех материальных запасов, которые были указаны на закладке Материалы.

Для заполнения табличной части Содержание драгоценных материалов, расположенной справа, следует нажать на кнопку Заполнить.

В результате в табличной части Содержание драгоценных материалов, расположенной справа, появится одна или несколько строк с информацией о драгоценных материалах, которые содержатся в материальных запасах.

Закладка "Бухгалтерская операция"

Типовая операция – выбирается из списка Типовые операции.

Для вида передачи Передача на сторону доступны типовые операции:

  • Безвозмездная передача (401.20);
  • Внутриведомственное перемещение (304.04).

Для вида передачи Передача по договору аренды доступна типовая операция Передача по договору возмездного пользования (25.56).

Для вида передачи Передача по договору безвозмездного пользования доступна типовая операция Передача по договору безвозмездного пользования (26.56).

Для вида передачи Реализация доступна типовая операция Реализация материальных запасов (401.10.172).

Доступность для выбора той или иной типовой операции зависит от выбранных значений для реквизитов документа.

Регистрация документа

Регистрация документа Накладная на отпуск материалов на сторону (Имущество казны) производится в журнале Документы по учету имущества казны.

Дополнительные возможности

На основании документа Накладная на отпуск материалов на сторону (Имущество казны) можно ввести документы Акт о приемке материалов, Исходящее извещение, Сторно.

Для вида передачи Реализация можно ввести документ Счет-фактура выданный, используя гиперссылку Ввести счет-фактуру в левом нижнем углу формы документа.
