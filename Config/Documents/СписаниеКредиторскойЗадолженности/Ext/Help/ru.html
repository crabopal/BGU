Документ "Списание кредиторской задолженности"

Документ Списание кредиторской задолженности предназначен для отражения в бухгалтерском и налоговом учете операций:

  • списания кредиторской задолженности без последующего наблюдения с балансовых счетов учета 205.00, 207.00, 208.00, 209.00, 301.00, 302.00, 303.00, 304.02, 304.03, 304.06;
  • списания кредиторской задолженности с последующим наблюдением с балансовых счетов учета 205.00, 208.00, 209.00, 301.00, 302.00, 303.00, 304.02, 304.03, 304.06 на забалансовый счет 20 "Задолженность, невостребованная кредиторами";
  • прекращение наблюдения задолженности с ее списанием с забалансового счета 20 "Задолженность, невостребованная кредиторами".

После заполнения и проведения документа по кнопке Печать можно сформировать Решение о списании задолженности, невостребованной кредиторами (форма по ОКУД 0510437).

Также можно распечатать Лист голосования и бухгалтерскую справку по ф. 0504833.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Списание кредиторской задолженности.

Заполнение шапки документа

Вид операции – выбирается из списка и может принимать значения:

  • Списать без последующего наблюдения;
  • Списать с последующим наблюдением;
  • Прекратить наблюдение задолженности.

Счет учета – счет учета кредиторской задолженности, невостребованной кредиторами. Выбирается из фрагмента плана счетов ЕПСБУ.

Подразделение – подразделение для отбора остатков задолженности. Отбор применяется в случае, если учет на счетах учета задолженности ведется в разрезе подразделений. Выбирается из справочника Подразделения.

Вид документа физ. лиц – индентификаторы контрагентов - физических лиц, которые формируются по выбранному виду документа либо в автоматическом режиме.

Закладка "Кредиторская задолженность"

На закладке вводится список контрагентов (кредиторов), при этом для каждого контрагента автоматически формируется и фиксируется в документе идентификатор контрагента по форматам ГИС ГМП 2.Х.

По кнопке Заполнить в командной панели таблицы Задолженность в документе заполняется информация об имеющейся задолженности выбранных контрагентов (кредиторов) по остаткам на счетах бухгалтерского учета. Сумму задолженности к списанию, при необходимости, можно скорректировать (в колонке Списать).

Реквизиты Резолюция комиссии и Срок наблюдения заполняются в зависимости от выбранного вида операции.

Закладка "Комиссия"

На закладке в реквизите Комиссия из справочника Комиссии (раздел Справочники – Организационная структура) следует выбирать одну из постоянно действующих комиссий учреждения. После выбора комиссии состав комиссии фиксируется и заполнится автоматически, при этом в таблице необходимо отметить отсутствующих членов комиссии и указать причину их отсутствия.

В справочнике Комиссии предусмотрены настройки регламента голосования:

  • Кворум, минимальный % присутствующих – минимальное количество присутствующих членов комиссии, при котором собрание комиссии считается состоявшимся;
  • Минимальный % голосов "за" присутствующих – определяет минимальное количество голосов, необходимое для одобрения резолюции комиссии.

После записи документа на закладке Кредиторская задолженность становится доступной возможность зарегистрировать результаты голосования членов комиссии. В группе Голосование в поле Сотрудник выбирается один из присутствующих членов комиссии, при этом в таблице Задолженность становятся доступными дополнительные колонки:

  • Резолюция комиссии – формулировка резолюции комиссии по строке документа (задолженности);
  • Решение – решение За или Против выбранного члена комиссии по строке документа (задолженности).

Сохранить результаты голосования выбранного члена комиссии можно по кнопке Сохранить результаты в группе Голосование.

Закладка "Бухгалтерская операция"

Типовая операция выбирается в зависимости от вида операции, установленного в шапке документа:

  • Списание кредиторской задолженности без последующего наблюдения – отражаются бухгалтерские записи по списанию кредиторской задолженности с балансовых счетов учета Дт 205.00, 207.00, 208.00, 209.00, 301.00, 302.00, 303.00, 304.0х Кт 401.10.173. В налоговом учете (по налогу на прибыль) отражается включение в налоговую базу внереализационных доходов Дт НПВ Кт Н91.01 (п.18 ст.250 НК РФ).
  • Списание кредиторской задолженности с последующим наблюдением – отражаются бухгалтерские записи по списанию кредиторской задолженности с балансовых счетов учета Дт 205.00, 208.00, 209.00, 301.00, 302.00, 303.00, 304.0х Кт 401.10.173 с одновременным отнесением задолженности на забалансовый счет 20 "Задолженность, невостребованная кредиторами".
  • Прекращение наблюдения задолженности (окончание срока исковой давности) – отражаются бухгалтерские записи по списанию кредиторской задолженности с забалансового счета 20 "Задолженность, невостребованная кредиторами". В налоговом учете (по налогу на прибыль) отражается включение в налоговую базу внереализационных доходов Дт НПВ Кт Н91.01 (п.18 ст.250 НК РФ).

Внимание!
Бухгалтерские записи формируются только по строкам документа, по которым резолюция комиссии была одобрена в результате голосования.
