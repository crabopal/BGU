Документ "Операция (бухгалтерская)"

Документ Операция (бухгалтерская) предназначен для ввода бухгалтерских операций вручную.

Документ можно заполнять полностью вручную или с использованием типовой операции.

Текущий режим заполнения определяется флажком Использовать типовые операции.

После заполнения реквизитов и проведения документа можно сформировать бухгалтерскую справку по ф.0504833.

Работа со списком документов

Список документов вида Операция (бухгалтерская) можно открыть с помощью команды Операции (бухгалтерские) меню функций раздела Учет и отчетность.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Операции (бухгалтерские).

Заполнение с использованием типовой операции

Для заполнения с использованием типовой операции необходимо включить флажок Использовать типовые операции.

После этого появляется поле для выбора типовой операции и кнопка Заполнить по типовой операции.

Типовая операция – выбирается из списка:

  • Зачет аванса выданного (по документу поступления).
  • Зачет аванса полученного.
  • Зачет аванса полученного (по документу реализации).
  • Исполнение по доходам (поступлениям).
  • Корректировка остатков расходов, не учитываемых при налогообложении (НУ).
  • Начисление доходов в сумме субсидии.
  • Начисление процентов, пеней, штрафов к получению.
  • Начисление процентов, пеней, штрафов к уплате.
  • Оприходование МПЗ по фактической стоимости при приобретении.
  • Оприходование МПЗ по фактической стоимости при приобретении (Имущество казны).
  • Принятие денежного обязательства текущего года.
  • Зачет аванса выданного.

После выбора типовой операции и заполнения всех обязательных дополнительных реквизитов к ней, необходимо нажать кнопку командной панели табличной части Заполнить по типовой операции.

Примечание. При заполнении на основании типовой операции все имеющиеся проводки очищаются.

Допускается редактирование заполненных проводок, удаление их и добавление новых.

Заполнение операции вручную

Реквизиты Счет дебета и Счет кредита выбираются из рабочего плана счетов.

Реквизиты КПС дебета, КПС кредита, КЭК дебета и КЭК кредита заполняются по выбранному рабочему счету.

При необходимости, пользователь может изменить эти реквизиты.

Примечание. Если в Настройке параметров учета установлен флаг Контролировать операции на соответствие рабочему плану счетов и если выбранный КПС не соответствует рабочему плану счетов, то операция не запишется.

Доступность реквизитов операции

Доступность некоторых реквизитов проводки зависит от настройки соответствующего счета в Плане счетов и настройки параметров учета.

  • Подразделение – становится видимым только при установленном флажке Учет по подразделениям на странице Общие настройки формы Настройка параметров учета раздела Администрирование. Реквизит доступен только для счетов с включенным признаком учета Учет по подразделениям в форме Настройка учета по подразделениям.
  • КПС – доступен только для счетов с включенным признаком учета Учет по КПС в карточке счета.
  • КЭК – доступен только для счетов с включенным признаком учета Учет по КПС в карточке счета.
  • Количество – доступен только для счетов с включенным признаком учета Количественный учет в карточке счета.
  • Валюта и Валютная сумма – становятся видимыми только при установленном флажке Учет расчетов и обязательств в иностранных валютах на странице Общие настройки формы Настройка параметров учета раздела Администрирование. Доступен только для счетов с включенным признаком учета Валютный учет в карточке счета.
  • ИФО – доступен при установленном флажке Учет по ИФО на странице Общие настройки формы Настройка параметров учета раздела Администрирование. Данный реквизит влияет на все проводки операции.

Дополнительные возможности

На основании документа Операция (бухгалтерская) можно ввести документы Регистрация исполнения договоров и Сторно.
