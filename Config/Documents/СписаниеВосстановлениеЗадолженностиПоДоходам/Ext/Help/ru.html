Документ "Списание, восстановление задолженности по доходам"

Документ Списание, восстановление задолженности по доходам предназначен для отражения в бухгалтерском учете операций:

  • списания сомнительной задолженности с балансовых счетов учета задолженности по доходам 205.00, 207.00, 209.00, 210.05 на забалансовый счет 04 "Сомнительная задолженность";
  • восстановления сомнительной задолженности со счета 04 на счета 205.00, 207.00, 209.00, 210.05;
  • списания безнадежной к взысканию задолженности с балансовых счетов учета задолженности по доходам 205.00, 207.00, 209.00, 210.05 или с забалансового счета 04.

После заполнения и проведения документа по кнопке Печать можно сформировать Решение о признании (восстановлении) сомнительной задолженности по доходам (форма по ОКУД 0510445) и Акт о признании безнадежной к взысканию задолженности по доходам (форма по ОКУД 0510436).

Также можно распечатать Лист голосования и бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида Списание, восстановление задолженности по доходам можно открыть с помощью команды Списание, восстановление задолженности по доходам меню функций раздела Учет и отчетность.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Списание, восстановление задолженности по доходам.

Заполнение шапки документа

Вид операции – выбирается из списка и может принимать значения:

  • Списание сомнительной задолженности (205.00, 207.00, 209.00, 210.05);
  • Восстановление сомнительной задолженности (04);
  • Списание безнадежной к взысканию задолженности (205.00, 207.00, 209.00, 210.05, 04).

Подразделение – подразделение для отбора остатков задолженности. Отбор применяется в случае, если учет на счетах учета задолженности ведется в разрезе подразделений. Выбирается из справочника Подразделения.

Вид документа физ. лиц – индентификаторы контрагентов - физических лиц, которые формируются по выбранному виду документа либо в автоматическом режиме.

Закладка "Задолженность по доходам"

На закладке вводится список контрагентов (дебиторов), при этом для каждого контрагента автоматически формируется и фиксируется в документе идентификатор контрагента по форматам ГИС ГМП 2.Х.
По кнопке Заполнить в командной панели таблицы Задолженность в документе заполняется информация об имеющейся задолженности выбранных контрагентов (дебиторов) по остаткам на счетах бухгалтерского учета, а также счет списания задолженности. Сумму задолженности к списанию, при необходимости, можно скорректировать (в колонке Списать).

Закладка "Комиссия"

На закладке в реквизите Комиссия из справочника Комиссии (раздел Справочники – Организационная структура) следует выбирать одну из постоянно действующих комиссий учреждения. После выбора комиссии состав комиссии фиксируется и заполнится автоматически, при этом в таблице необходимо отметить отсутствующих членов комиссии и указать причину их отсутствия.

В справочнике Комиссии предусмотрены настройки регламента голосования:

  • Кворум, минимальный % присутствующих – минимальное количество присутствующих членов комиссии, при котором собрание комиссии считается состоявшимся;
  • Минимальный % голосов "за" присутствующих – определяет минимальное количество голосов, необходимое для одобрения резолюции комиссии.

После записи документа на закладке Задолженность по доходам становится доступной возможность зарегистрировать результаты голосования членов комиссии. В группе Голосование в поле Сотрудник выбирается один из присутствующих членов комиссии, при этом в таблице Задолженность становятся доступными дополнительные колонки:

  • Резолюция комиссии – формулировка резолюции комиссии по строке документа (задолженности);
  • Решение – решение За или Против выбранного члена комиссии по строке документа (задолженности).

Сохранить результаты голосования выбранного члена комиссии можно по кнопке Сохранить результаты в группе Голосование.

Закладка "Бухгалтерская операция"

Типовая операция выбирается в зависимости от вида операции, установленного в шапке документа:

  • Признание сомнительной задолженности по доходам (205.00, 207.00, 209.00, 210.05) – отражаются бухгалтерские записи по списанию сомнительной задолженности с балансовых счетов учета Дт 401.10.173 Кт 205.00, 207.00, 209.00, 210.05 и формированию резерва по сомнительной задолженности на забалансовом счете 04 "Сомнительная задолженность".
  • Восстановление сомнительной задолженности по доходам (04) – отражаются бухгалтерские записи по восстановлению задолженности на балансовых счетах учета Дт 205.00, 207.00, 209.00, 210.05 Кт 401.10.173 с одновременным списанием задолженности с забалансового счета 04 "Сомнительная задолженность".
  • Списание безнадежной к взысканию задолженности (205.00, 207.00, 209.00, 210.05, 04) – отражаются бухгалтерские записи по списанию безнадежной к взысканию задолженности с балансовых счетов учета Дт 401.10.173 Кт 205.00, 207.00, 209.00, 210.05 или с забалансового учета 04 "Сомнительная задолженность". В налоговом учете (по налогу на прибыль) отражается включение в налоговую базу внереализационных расходов Дт Н91.02 Кт НПВ (пп.2 п.2 ст.265 НК РФ).

Внимание!
Бухгалтерские записи формируются только по строкам документа, по которым резолюция комиссии была одобрена в результате голосования.
