Поступление МЗ (М-4)

Документ предназначен для оформления поступления материальных запасов и возвратной тары на склад.

Документ формирует печатную форму приходного ордера М-4 (форма по ОКУД 0315003) и бухгалтерской справки 0504833.

Оформление поступления материалов на склад

Документ "Поступление МЗ (М4)" предназначен для учета материальных запасов, поступивших в организацию.

На основании заполненного и проведенного документа можно распечатать "Приходный ордер М-4" (форма по ОКУД 0315003) и бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов "Поступление МЗ (М4)" можно открыть с помощью команды " Поступление МЗ (М4)" панели навигации раздела "Материальные запасы".

Для ввода нового документа можно нажать на кнопку "Создать" командной панели списка "Поступление МЗ (М4)".

Заполнение документа

В первую очередь необходимо заполнить реквизиты "Организация" и "Дата".

  • "Контрагент" – выбирается из справочника "Контрагенты".
  • "Договор" – выбирается из справочника "Договоры и иные основания возникновения обязательств", подчиненного справочнику "Контрагенты".
  • "МОЛ/Место хранения" – выбирается из справочника "Центры материальной ответственности".

Необходимость в заполнении реквизита "Подразделение (кор.) " появляется только в случае установки флага "Использовать учет по подразделениям" в форме "Настройка параметров учета".

Заполнение реквизитов на закладке "Материальные запасы"

"Сумма включает НДС" – наличие или отсутствие флага у реквизита определяет порядок отражения НДС в документе, который должен соответствовать порядку отражения НДС в полученном первичном документе.

Информация о поступивших материальных запасах вводится в табличную часть на закладке "Материальные запасы":

  • "Номенклатура" – наименование материала, выбирается из справочника "Номенклатура";

Примечание. Если информация о материалах уже присутствует в справочнике, то для выбора позиций номенклатуры удобно использовать форму подбора, которая открывается с помощью кнопки "Подбор" командной панели табличной части.

  • "Уч. ед" – учетная единица. Значение совпадает со значением реквизита "Ед. измерения" элемента номенклатуры;
  • "Ед. изм" – единица измерения;
  • "К-во мест" – количество приходуемых единиц материалов (кг, упаковок, банок, пачек, мешков и т.д.);
  • "К-во в 1 месте" – количество МЗ в учетной единице измерения в 1 месте (количество товара в упаковке в учетных единицах измерения). По умолчанию предлагается 1.000;
  • "К-во в уч. ед." – рассчитывается автоматически как произведение значений реквизитов "К-во мест" и "К-во в 1 месте". Может быть указано вручную;
  • "Сумма" – стоимость указанного количества материалов. Если флаг «Сумма включает НДС» установлен, то стоимость следует указывать с НДС, в противном случае – без НДС;
  • "Ставка НДС" - ставка налога на добавленную стоимость;
  • "Сумма НДС" - сумма налога на добавленную стоимость по строке;
  • "Всего" – сумма по строке с учетом налога на добавленную стоимость.

Заполнение реквизитов на закладке "Возвратная тара"

  • "Номенклатура" – возвратная тара, выбирается из справочника "Номенклатура";

Примечание. Если информация о возвратной таре уже присутствует в справочнике, то для выбора позиций номенклатуры удобно использовать форму подбора, которая открывается с помощью кнопки "Подбор" командной панели табличной части.

  • "Количество" – количество возвратной тары по строке;
  • "Сумма" – стоимость возвратной тары по строке.

Заполнение реквизитов на закладке "Дополнительные данные"

На закладке "Дополнительные данные" вводится информация о первичном документе поставщика:

  • "Вид документа" – значение реквизита выбирается из справочника "Виды первичных документов";
  • "Номер" – номер первичного документа;
  • "Дата" – дата первичного документа;
  • "Грузоотправитель" – выбирается из справочника "Контрагенты";
  • "Грузополучатель" – выбирается из справочника "Контрагенты";
  • "Доверенность" – выбирается из списка "Доверенности".

Отражение документа в бухгалтерском учете

Отражение документа в бухгалтерском учете происходит только после ввода данных о бухгалтерской операции и проведения документа.

Если режим "Формирование проводок обособленно от документа" в форме "Настройка параметров учета" выключен, то перед проведением документа необходимо ввести данные на закладке "Бухгалтерская операция".

Выбор типовой операции

Заполнение реквизитов на закладке "Бухгалтерская операция"

"Типовая операция" – выбирается из списка "Типовые операции".

Для документа предусмотрены следующие типовые операции:

  • безвозмездное поступление (внутриведомственное) (304.04);
  • безвозмездное поступление прочее (401.10);
  • поступление МЗ, ранее учтенных как НФА в пути (107);

Примечание. При оформлении поступления МЗ, ранее учтенных как НФА в пути, можно вводить документ на основании "Поступления МЗ (в пути)". При этом заполнение всех реквизитов документа, включая данные по типовой операции, выполняется автоматически.

  • поступление от подотчетных лиц (208);
  • поступление по договорам купли-продажи, договорам поставки, другим аналогичным договорам (302).

После выбора типовой операции для оформления поступления "Вложений в МЗ (счет 106.2П и 106.3П) " необходимо заполнить реквизиты группы "Вложения в МЗ":

  • "Учесть как вложения (сч. 0 106 00) " – установить флаг;
  • "Счет вложений" – выбрать счет вложений;
  • "Вид затрат" – выбрать вид затрат из справочника "Виды затрат".

Регистрация документа

Регистрация документов "Поступление МЗ (М4)" производится в журнале "Документы по учету материальных ценностей".

Дополнительные возможности

На основании документа "Поступление МЗ (М4)" можно ввести документы "Акт приемки материалов (М7)", "Сторно" и "Счет-фактура полученный".
