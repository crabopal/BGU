Документ "Начисление компенсации учащимся"

Документ Начисление компенсации учащимся предназначен для отражения в учете начисления компенсаций учащимся.

Из документа можно распечатать Бухгалтерскую справку (ф. 0504833) и Ведомость начисленной компенсации учащимся.

Работа со списком документов

Список документов Начисление компенсации учащимся можно открыть с помощью команды Начисление компенсации учащимся меню функций раздела Платное обучение.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Начисление компенсации учащимся.

Заполнение реквизитов шапки документа

Период начисления – период, за который начисляется компенсация.

Факультет – наименование (номер) класса (отделения, учебного подразделения и т.п.), путем выбора из справочника Подразделения.

Основание – указывается нормативный акт или другой документ, согласно которому будет выплачиваться компенсация. Выбирается из справочника Договоры и иные основания возникновения обязательств. Также основание можно указать в табличной части для каждого учащегося. Если в табличной части не заполнено основание (договор), основание будет взято из шапки документа.

Примечание. Если для всех учащихся начисление компенсации осуществляется по одному основанию (договору), такое основание следует создать в справочнике Договоры и иные основания возникновения обязательств с видом договора Иное основание обязательства без указания контрагента.


Аналитика затрат в каждой строке – флажок устанавливается, если компенсация начисляется по разным основаниям, для указания КФО, КПС и КЭК в табличной части.

Закладка "Компенсация"

Для автоматического заполнения табличной части следует нажать кнопку Заполнить и выбрать в меню команду Учащиеся по отбору. Откроется форма Настройка параметров отбора учащихся, которая настроена по умолчанию на отбор учащихся по факультету, указанному в шапке документа, и по сумме компенсации, назначенной учащемуся в этом периоде приказом о начислении компенсации. При необходимости можно добавить отбор по другим параметрам – значению ставок компенсации, перечню учащихся, группам справочника Учащиеся и т.д.

Помимо настроек отбора в форме, при заполнении документа всегда действует следующее условие отбора: учащийся должен быть зачислен документом Приказ (образование) в учреждение по факультету, выбранному в документе по состоянию на период начисления компенсации.

По окончании настройки отбора после нажатия на кнопку Выполнить отбор и заполнить документ табличная часть на закладке будет заполнена данными:

  • Учащийся – получатель компенсации, заданный с помощью приказа (образование). Для школьников, как правило, получателем компенсации является родитель или законный представитель ребенка. При необходимости в табличной части можно изменить получателя компенсации, путем выбора из справочника Контрагенты.
  • Договор – указывается нормативный акт или другой документ, согласно которому будет выплачиваться компенсация, по умолчанию берется из реквизита Основание шапки документа.
  • Период начисления – дата начала и окончания расчета компенсации по строке таблицы.
  • Ставка компенсации за период – сумма компенсации для начисления за весь период расчета.
  • Ставка компенсации за день – сумма компенсации за один день посещения учреждения.
  • Количество дней – количество дней посещения учреждения в периоде. При заполнении по списку учащихся расчет дней выполняется по заданному графику работы учреждения. Может быть отредактировано вручную.
  • Сумма – сумма компенсации. Рассчитывается по формуле: Ставка компенсации за период + Ставка компенсации за день ? Количество дней и может быть отредактирована вручную. При ручном редактировании значения поля Сумма, значения полей Ставка компенсации за период и Ставка компенсации за день очищаются.

Закладка "Аналитика затрат"

Закладка заполняется, если в шапке документа для начисления компенсации указан общий договор по всем учащимся.

Закладка "Бухгалтерская операция"

Типовая операция имеет одно значение: Начисление компенсации учащимся. Для данной типовой операции следует указать реквизиты:

  • Счет затрат – 401.20.
  • Принять денежное обязательство – флажок следует установить для формирования проводок по принятию денежного обязательства.
  • Раздел лицевого счета – выбирается из справочника Разделы лицевых счетов (требуется для формирования проводок по денежным обязательствам).

Дополнительные возможности

На основании документа Начисление компенсации учащимся вводится документ Ведомость в банк для дальнейшего перевода денежных средств физическим лицам на банковские счета или Платежная ведомость для выплаты через кассу.

Также на основании документа можно ввести документ Сторно.
