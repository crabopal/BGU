Документ "Начисление доходов будущих периодов (образование)"

Документ Начисление доходов будущих периодов (образование) предназначен для начисления в бухгалтерском учете сумм доходов от оказания образовательных услуг по долгосрочным договорам, которые относятся к будущим отчетным периодам.

После заполнения реквизитов бухгалтерской операции и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида Начисление доходов будущих периодов (образование) можно открыть с помощью команды Начисление доходов будущих периодов (образование) меню функций раздела Платное обучение - Долгосрочные договоры.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Начисление доходов будущих периодов (образование).

Заполнение реквизитов шапки документа

Начисление – выбирается позиция переключателя:

  • за услуги образования – для отражения предстоящих доходов по долгосрочным договорам платного обучения;
  • за прочие услуги – для отражения предстоящих доходов по долгосрочным договорам по прочим услугам, оказываемым учащимся. При выборе данной позиции следует заполнить параметры начисления и расчеты стоимости услуг по долгосрочным договорам с учацимися из справочника Виды начислений учащимся за прочие услуги.

Факультет – наименование факультета. Выбирается из справочника Подразделения;
Номенклатура – наименование образовательной услуги. Выбирается из фрагмента справочника Номенклатура, ограниченного перечнем услуг;
КФО, КПС, Счет, КЭК – полный счет доходов будущих периодов (401.40).

НДС не учитывается – гиперссылка для вызова формы Цены в документе, которая содержит группы Валюта документа и НДС в документе.

Группа Валюта документа позволяют задать для документа значения реквизитов Валюта, Курс и Кратность на определенную дату.

Группа НДС в документе содержит флажки:

  • Учитывать НДС – после установки флажка в табличной части документа будут доступны колонки Ставка НДС и Сумма НДС.
  • Включен в сумму – установка или снятие флажка определяет способ отображения НДС в документе.

Закладка "Начисления"

Для добавления строк в табличную часть закладки вручную можно использовать кнопку Добавить командной панели.

Для автоматического заполнения данными табличной части следует нажать на кнопку Заполнить и выбрать в меню команду Учащимися по отбору. Откроется форма Настройка параметров отбора учащихся, которая настроена по умолчанию на отбор учащихся по факультету, указанному в шапке документа, и которая может быть при необходимости дополнена отбором по другим реквизитам – Группа, Курс, Состояние учащегося и т.д. По окончании настройки отбора после нажатия на кнопку Выполнить отбор и заполнить документ табличная часть на закладке будет заполнена данными.

  • Количество – количество услуг, работ.
  • Ед. изм. – единица измерения услуг, работ.
  • Цена – стоимость за единицу услуги, работы.

Пример
Если при заключении договора обучения на 18 месяцев в поле Количество указывается 18, в поле Ед. изм. выбирается единица измерения мес. (месяц), то в поле Цена указывается стоимость (ставка) обучения за месяц. Колонки Количество, Ед.изм. и Цена заполнять необязательно, достаточно заполнить итоговую сумму начисления в колонке Сумма.
  • Сумма – суммарная стоимость услуг, работ по строке. Рассчитывается автоматически, может быть скорректирована вручную.

Примечание. При корректировке вручную значения в поле Сумма автоматически выполняется пересчет значения в поле Цена.
  • Ставка НДС – ставка НДС. Выбирается из списка.
  • Сумма НДС – сумма НДС. Рассчитывается автоматически.
  • Всего – итоговая сумма по строке. Рассчитывается автоматически.
  • Расчеты – счет расчетов по доходам. Заполняется автоматически на основании выбранного значения КЭК, выбирается из списка счетов 205.00.

Закладка "Порядок учета доходов"

Признание доходов – определяет порядок списания со счетов учета доходов будущих периодов (401.40) на счета учета доходов текущего периода (401.10), выбирается из списка и может принимать значения:

  • По месяцам - расчет суммы списания производится равномерно по месяцам. Сумма списания (сумма доходов текущего периода) рассчитывается как остаток по счету 401.40 «Доходы будущих периодов», не списанный на данный момент, деленный на количество месяцев, оставшихся до окончания периода списания. Если период начала (окончания) приходится не на первый (последний) день месяца, то текущий месяц учитывается в той доле, которая приходится на него в периоде списания. При этом расчет доли месяца производится пропорционально количеству дней, которые в месяце учитываются, к количеству календарных дней в этом же месяце.
  • По календарным дням - расчет суммы списания производится равномерно по календарным дням. Рассчитывается сумма списания (сумма доходов текущего периода), приходящаяся на один день, как остаток по счету 401.40 «Доходы будущих периодов», не списанный на данный момент, деленный на количество дней, оставшихся до окончания списания. Для расчета суммы списания (суммы доходов текущего периода) эта сумма умножается на количество дней в текущем месяце. В последнем месяце полностью списывается остаток, и таким образом учитываются погрешности округления в расчетах других периодов.
  • По графику - расчет суммы списания производится в соответствии с установленным договором планом-графиком реализации услуг (работ). Для договоров платного обучения план-график реализации определяется на основе указанных периодов обучения (колонка Период обучения на закладке Общий (особый) порядок оплаты), таким образом, доходы от реализации услуг (работ) будут отражаться на счетах учета доходов текущего периода на дату окончания соответствующего периода обучения.
  • В особом порядке - сумма списания в текущем месяце не рассчитывается автоматически, ее нужно указать вручную в документе начисления доходов текущего периода.

Начало списания, Окончание списания (при признании доходов "По месяцам" или "По календарным дням") – период, в течение которого доходы будущих периодов будут относиться на финансовый результат текущего периода.

Отражение в доходах текущего периода – указываются счет и аналитика бухгалтерского учета доходов текущего периода, а также порядок отражения доходов в налоговом учете (налог на прибыль, УСН).

Примечание. Для ежемесячного начисления доходов текущего периода по графику (в реквизите Признание доходов установлено значение По графику) порядок оплаты на закладках Общий / Особый порядок оплаты также должен быть указан с детализацией помесячно, при этом для нескольких строк может быть указана одинаковая дата оплаты. Например, Оплатить до 31.12.2020 для всех шести строк первого полугодия с 01.01.2021 по 30.06.2021 (семестра), при этом в каждой строке должна быть указана сумма доходов за соответствующий месяц обучения. Доходы текущего периода признаются на дату окончания соответствующего периода обучения документами Начисление за услуги образования и Начисление учащимся за прочие услуги.

Закладка "Общий порядок оплаты"

На данной закладке вводится общий (стандартный) порядок оплаты для всех начислений на закладке Начисления, за исключением отдельных начислений с особым порядком оплаты (см. закладку Особый порядок оплаты).

График оплаты указан – следует выбрать вариант ввода графика оплаты:

  • В абсолютных величинах (суммы платежей) – указываются суммы платежей. Итоговая сумма платежей по графику оплаты должна быть равна сумме по каждому из начислений, указанных на закладке Начисления.
  • В относительных величинах (процентах, долях) – график оплаты указывается в процентах (долях) от сумм начислений. Например, 50% аванс и 50% по факту оказания услуг.

Для добавления строк в табличную часть закладки следует использовать кнопку Добавить командной панели.

  • Оплатить до – следует указать планируемую (крайнюю) дату оплаты, после которой платеж будет считаться просроченным.
  • Сумма (%, доля) – указывается сумма (процент от суммы начисления) к уплате за соответствующий Период обучения.
  • Примечание – произвольное примечание, например, "1 семестр", "2 семестр" и т.п.

Закладка "Особый порядок оплаты"

На данной закладке вводится особый порядок оплаты для отдельных начислений, для которых неприменим общий (стандартный) порядок оплаты. Например, в случае предоставления скидок, льгот или особого графика оплаты образовательных услуг для некоторых договоров (учащихся).

В левой части формы следует выбрать строку начисления и установить флажок Особый порядок оплаты для выбранного начисления. Особый порядок оплаты для выбранного начисления вводится в правой части формы по тем же правилам, что на закладке Общий порядок оплаты.

Закладка "Бухгалтерская операция"

Типовая операция – выбирается из списка Типовые операции.

Ввод входящих остатков в межотчетном периоде (401.30)

Для данной типовой операции необходимо заполнить реквизиты:

Группа Финансовый результат прошлых отчетных периодов

  • Счет учета – по умолчанию счет 401.30 "Финансовый результат прошлых отчетных периодов".
  • КПС – КПС для счета 401.30.

Примечание. Входящие остатки по долгосрочным договорам платного обучения при первом применении стандарта "Долгосрочные договоры" по состоянию на 1 января 2020 года вводятся документами от 31.12.2019 с установленным флажком Отразить в межотчетном периоде.

При проведении документа по каждому начислению (каждой строке табличной части Начисления) формируются бухгалтерские записи:

  • Дт 0 205 ХХ 56Х – Кт 0 401 30 000 – расчеты с дебиторами по доходам от реализации за весь срок действия долгосрочного договора;
  • Дт 0 401 30 000 – Кт 0 401 4Х 1ХХ – доходы будущих периодов за весь срок действия долгосрочного договора.

Начисление доходов будущих периодов (205.00 - 401.40)

При проведении документа по каждому начислению (каждой строке табличной части Начисления) формируются бухгалтерские записи Дт 0 205 ХХ 56Х – Кт 0 401 4Х 1ХХ – расчеты с дебиторами и доходы будущих периодов на сумму доходов от реализации за весь срок действия долгосрочного договора.

Дополнительные возможности
