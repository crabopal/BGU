Документ "Ввод начальных остатков по денежным документам"

Документ Ввод начальных остатков по денежным документам предназначен для ввода данных о количестве и стоимости остатков денежных документов в начале эксплуатации программы и автоматического формирования проводок.

Ввести количественные остатки денежных документов в разрезе единиц денежных документов можно только при установленном флаге Вести количественный учет денежных документов в разделе Денежные средства формы Настройка параметров учета.

После заполнения и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833 (кнопка Печать).

Создание нового документа

Для ввода начальных остатков денежных документов необходимо с помощью команды Помощник ввода начальных остатков меню функций раздела Администрирование открыть форму Помощник ввода начальных остатков.

Далее следует установить курсор на строку с номером счета 201.35 «Денежные документы» на закладке Основные счета и нажать на кнопку командной панели Ввести остатки по счету.

Откроется форма документа Ввод начальных остатков по денежным документам.

Заполнение реквизитов шапки документа
  • Дата – дата ввода начальных остатков;

Примечание. При вводе начальных остатков в качестве значения реквизита Дата должна быть установлена дата, предшествующая дате начала учета.
  • Организация – наименование организации;
  • Счет кассы – полный счет 201.35, на который будут зачислены остатки денежных документов. Реквизит составной, содержит значения КПС, Счет (значение 201.35), КФО и КЭК. Необходимый набор значений выбирается из Рабочего плана счетов для счета 201.35.

Заполнение реквизитов табличной части

Данные по остаткам денежных документов вводятся в табличную часть.

Для ввода новой строки можно нажать на кнопку Добавить командной панели табличной части.

  • Вид денежного документа – выбирается из справочника Виды денежных документов;

Примечание. Если необходимый элемент отсутствует в справочнике Виды денежных документов, то его необходимо создать с помощью, например, кнопки Создать командной панели формы списка. Наименование вида денежного документа указывается в реквизите Наименование созданного элемента справочника.
  • Денежный документ – денежный документ, по которому должно пройти зачисление остатка. Выбирается из справочника Денежные документы;

Примечание. Если необходимый элемент отсутствует в справочнике Денежные документы, то его необходимо создать с помощью, например, кнопки Создать командной панели формы списка. Наименование денежного документа указывается в реквизите Наименование созданного элемента справочника.
  • Количество – количество денежных документов;

Примечание. Реквизит доступен только при установленном флаге Вести количественный учет денежных документов в разделе Денежные средства формы Настройка параметров учета.
  • Сумма – балансовая стоимость денежных документов.

Заполнение реквизитов "Бухгалтерская операция"

Типовая операция – не выбирается, имеет по умолчанию значение Ввод начальных остатков по денежным документам.

Регистрация документа

Регистрация документа Ввод начальных остатков по денежным документам производится в списке Ввод начальных остатков.
