Список "Ввод начальных остатков"

Для ввода остатков по различным разделам учета в программе используются документы:

  • Ввод остатков ОС и НМА;
  • Ввод остатков по НПА;
  • Ввод остатков по имуществу казны;
  • Ввод остатков ОС на забалансовых счетах;
  • Ввод остатков денежных средств;
  • Ввод остатков материалов;
  • Ввод остатков по счету 106хП;
  • Ввод остатков по денежным документам;
  • Ввод остатков бланков строгой отчетности;
  • Ввод остатков НДС;
  • Ввод остатков по учащимся;
  • Ввод остатков по родительской плате;
  • Ввод остатков по прочим счетам бухгалтерского учета.

Работа со списком документов

Все документы для ввода начальных остатков по всем разделам учета находятся в списке "Ввод начальных остатков", который можно открыть с помощью команды "Ввод начальных остатков" панели навигации раздела "Настройка и администрирование".

В форме списка "Ввод начальных остатков" предусмотрены отборы по реквизитам:

  • Организация – выбирается из справочника "Организации";
  • Раздел учета – выбирается из списка;
  • Счет проводки – выбирается из Плана счетов ЕПСБУ.

Создание нового документа

Для ввода нового документа по вводу остатков можно нажать на кнопку "Создать" командной панели списка "Ввод начальных остатков", а затем выбрать вид необходимого документа в форме выбора "Ввод начальных остатков (создание)".

Второй, более удобный способ создания нового документа по вводу остатков, предполагает, что предварительно, до нажатия на кнопку "Создать", будет выбран из списка раздел учета и указан в качестве значения реквизита "Раздел учета".

В этом случае после нажатия на кнопку "Создать" откроется не форма выбора "Ввод начальных остатков (создание)" как в предыдущем случае, а форма документа для ввода остатков по заданному разделу учета.

Предположим, нам необходимо ввести начальные остатки наличных денежных средств. В результате выбора для реквизита "Раздел учета" значения "Ввод остатков денежных средств" и нажатия на кнопку "Создать" на экране появляется форма документа "Ввод начальных остатков денежных средств".

Третий, также удобный и, кроме того, наглядный способ ввода начальных остатков, предполагает использование "Помощника для ввода начальных остатков".

Проверка правильности ввода начальных остатков

Для проверки правильности ввода остатков можно использовать отчет "Оборотно - сальдовая ведомость".

Открыть отчет "Оборотно - сальдовая ведомость" можно с помощью команды "Оборотно - сальдовая ведомость" панели действий раздела "Учет и отчетность".
