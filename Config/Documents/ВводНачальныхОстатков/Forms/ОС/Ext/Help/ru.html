Проведение документа

Регистрация документа

(устарел) Документ "Ввод начальных остатков по ОС и НМА"

Документ "Ввод начальных остатков по ОС и НМА" предназначен для ввода начальных остатков, а также всех сведений об объектах основных средств и нематериальных активов (НМА), необходимых для дальнейшего ведения учета.

Документ служит для отражения операций по вводу остатков основных средств (нематериальных активов) по счетам 101 "Основные средства" (102 "Нематериальные активы"), 104 "Амортизация", а также для заполнения реквизитов справочника "Основные средства" и регистров сведений информацией об объектах ОС (НМА).

Примечание. В документ следует вносить лишь актуальные сведения об основных средствах.

Данные следует указывать только для тех основных средств, которые на момент ввода остатков уже приняты к учету, но еще не списаны.

После заполнения и записи документа можно сформировать печатную форму "Ведомость введенных данных по ОС и НМА".

После проведения документа можно сформировать бухгалтерскую справку по ф. 0504833 (кнопка "Печать").

Работа со списком документов

Документы вида "Ввод начальных остатков по ОС и НМА" находятся в списке "Ввод начальных остатков", который можно открыть с помощью команды "Ввод начальных остатков" панели навигации раздела "Настройка и администрирование".

Создание нового документа

Для ввода нового документа следует выбрать для реквизита "Раздел учета" списка "Ввод начальных остатков" значение "Ввод остатков ОС и НМА", а затем нажать на кнопку "Создать".

Откроется форма документа "Ввод начальных остатков по ОС и НМА".

Заполнение реквизитов шапки документа
  • Дата – дата ввода начальных остатков;

Примечание. При вводе начальных остатков в качестве значения реквизита "Дата" должна быть установлена дата, предшествующая дате начала учета.
  • Организация – наименование организации;
  • Вид НФА – выбирается из списка. Может принимать значения "Основные средства" или "Нематериальные активы";
  • КФО – код финансового обеспечения. Выбирается из списка;
  • Счет – полный счет учета ОС (НМА). Выбирается из плана счетов ЕПСБУ, ограниченного субсчетами счета 101 (для выбранного ранее "Вида НФА" — "Основные средства") или субсчетами счета 102 (для выбранного ранее "Вида НФА" — "Нематериальные активы").

Реквизиты группы Режим ввода остатков в новом документе по умолчанию имеют следующие значения:

  • Бух. учет – значение Да;
  • Налоговый учет – значение Нет.

При наличии необходимости в изменении значений, заданных по умолчанию, следует с помощью щелчка мыши по гиперссылке Да или Нет вызвать диалог Режим ввода остатков.

Далее следует установить или снять в диалоге флаги Ввод остатков по бухгалтерскому учету и Ввод остатков по налоговому учету.

Видимость и, следовательно, доступность для редактирования колонок табличной части документа зависит от настройки, выполненной в диалоге Режим ввода остатков.

Например, при установленных значениях Да для реквизита Бух. учет и Нет для реквизита Налоговый учет, в табличной части будут доступны только колонки с данными по бухгалтерскому учету – Балансовая стоимость, Сумма амортизации и т.д.

После установки для реквизита Налоговый учет значения Да в табличной части станут также доступны колонки с данными по налоговому учету – Балансовая стоимость (НУ), Сумма амортизации (НУ) и т.д.

В некоторых случаях, например, при изменении системы налогообложения, у организации появляется потребность во вводе остатков только по налоговому учету, поскольку в результате ведения бухгалтерского учета данные по бухгалтерскому учету уже находятся в информационной базе.

В этом случае в новом документе Ввод остатков по ОС и НМА в диалоге Режим ввода остатков следует снять флаг Ввод остатков по бухгалтерскому учету и установить флаг Ввод остатков по налоговому учету.

После подтверждения выполненной настройки и закрытия диалога с помощью кнопки ОК следует нажать на кнопку Заполнить по данным бух. учета табличной части.

В результате табличная часть документа для целей налогового учета будет заполнена на основании данных бухгалтерского учета.

Далее введенные данные по налоговому учету можно при необходимости откорректировать и привести таким образом в соответствие реальным данным налогового учета.

Заполнение реквизитов табличной части

Данные по объектам ОС и НМА вводятся в табличную часть документа.

Для ввода данных по объектам ОС и НМА в программе предусмотрено два режима: "Редактирование в диалоге" и "Редактирование в строке".

Для перехода от одного режима к другому используется кнопка "Редактирование в диалоге" командной панели табличной части формы документа.

Количество реквизитов, которые можно ввести в режимах "Редактирование в строке" и "Редактирование в диалоге" отличаются.
Ввод данных в табличную часть документа "Ввод остатков ОС и НМА" всегда начинается с режима "Редактирование в строке", который позволяет быстро ввести минимально необходимое количество основных реквизитов.
Для продолжения редактирования и ввода всех остальных реквизитов следует использовать режим "Редактирование в диалоге".

Режим "Редактирование в строке"

Примечание. Для ввода данных в режиме "Редактирование в строке" кнопка "Редактирование в диалоге" командной панели табличной части должна быть отжата.

Для ввода новой строки можно нажать на кнопку "Добавить" командной панели табличной части.

  • Основное средство – объект ОС или НМА. Выбирается из справочника "Основные средства";

Примечание. Если карточка объекта ОС или НМА отсутствует в справочнике "Основные средства", то ее необходимо создать с помощью, например, кнопки "Создать" командной панели формы списка. В новом элементе справочника следует в реквизите "Наименование" указать наименование нужного объекта ОС или НМА и сохранить сделанные изменения с помощью кнопки "Записать и закрыть" формы элемента. После это новый элемент можно выбрать при заполнении документа.
  • Гр. уч. – признак ведения группового учета, отображается справочно;

Примечание. Установка флага "Групповой учет" в строке выполняется при редактировании строки в диалоге.
  • Инв. № – инвентарный номер объекта ОС или НМА, если он имеется у объекта;

Примечание. Возможность задания списка инвентарных номеров для объектов ОС становится доступна в режиме "Редактирование в диалоге" после установки флага "Группой учет".
  • Количество – количество объектов ОС или НМА;
  • Балансовая стоимость – суммарная балансовая стоимость объекта ОС или НМА;
  • МОЛ - Место хранения – центр материальной ответственности. Выбирается из справочника "Центры материальной ответственности";

Примечание. Если карточка центра материальной ответственности отсутствует в справочнике "Центры материальной ответственности", то ее необходимо создать с помощью, например, кнопки "Создать" командной панели формы списка. Затем в новом элементе следует заполнить реквизиты "Сотрудник" и "Места хранения" выбором элементов из справочников "Сотрудники" и, соответственно, "Места хранения". При отсутствии необходимых элементов в указанных справочниках их следует ввести.

При наличии в организации нескольких МОЛ с совпадающими фамилиями и инициалами рекомендуется при создании элемента справочника "Сотрудники" наряду с реквизитом "Наименование", в который полностью вводятся фамилия, имя и отчество сотрудника, заполнить также реквизит "ИНН". Значение "ИНН" позволяет однозначно идентифицировать сотрудника и избежать путаницы.

Примечание. Остальные реквизиты элемента справочника "Сотрудники" следует заполнить позднее, в процессе ведения учета.
  • Сумма амортизации – сумма амортизации объекта ОС или НМА, начисленная на дату ввода остатков.

Режим "Редактирование в диалоге"

Чтобы редактирование в диалоге строки табличной части стало возможно, поле "Основное средство" строки должно быть заполнено.

Примечание. Для перехода в режим "Редактирование в диалоге" необходимо нажать кнопку "Редактирование в диалоге" командной панели табличной части.

Для вызова диалога для редактирования строки следует сделать двойной щелчок левой кнопки мыши по строке или установить курсор на строку и нажать клавишу "Enter".

Диалог "Ввод начальных остатков ОС – строка (номер строки)" имеет закладки:

  • Общие сведения;
  • События;
  • Амортизация.

Заполнение реквизитов шапки диалога
  • Организация – справочно отображается название организации;
  • Основное средство – отображается наименование основного средства. Карточка основного средства может быть открыта и отредактирована;
  • Групповой учет – при необходимости ведения группового учета ОС следует установить флаг. Для НМА ведение группового учета не предусмотрено;
  • Инв. номер – инвентарный номер объекта ОС или НМА.

Заполнение реквизитов на закладке "Общие сведения"

Значения реквизитов "Счет учета", "Вид НФА" и "Вид имущества" выводятся на закладке справочно, для информации.

  • Код по ОКОФ – код по "Общероссийскому классификатору основных фондов". Выбирается из справочника "Общероссийский классификатор основных фондов";
  • Амортизационная группа – выбирается из списка, если для выбранного значения реквизита "Код по ОКОФ" предусмотрено несколько допустимых значений реквизита "Амортизационная группа";

Примечание. В случае если для значения реквизита "Код по ОКОФ" предусмотрена только одна амортизационная группа, то после его выбора значения реквизита "Амортизационная группа", а также реквизита "Срок полезного использования" на закладке "Амортизация" заполняются автоматически. Рассчитанное значение реквизита "Срок полезного использования" может быть отредактировано вручную.

Примечание. Для десятой амортизационной группы (свыше 30 лет) срок полезного использования задается вручную.

Первоначальная стоимость (БУ) и/или Первоначальная стоимость (НУ) – суммарная первоначальная стоимость объекта ОС или НМА по соответствующему виду учета.

Группа реквизитов Балансовая стоимость на момент ввода остатков:

  • Сумма (БУ) и/или Сумма (НУ) – суммарная балансовая стоимость объекта ОС или НМА по соответствующему виду учета;
  • Количество – количество объектов ОС или НМА;

Примечание. Для ОС, по которым ведется индивидуальный учет или вводится инвентарный номер, указывается значение, равное "1".
Для ОС стоимостью менее 3000 рублей, для которых задано ведение группового учета, можно ввести любое целое значение.
  • Ставка налога на имущество – указывается для объектов ОС, которые подлежат обложению налогом на имущество.

Реквизиты группы "Амортизация":

  • Счет амортизации – полный счет учета амортизации, в котором "КПС" отображается справочно и соответствует "КПС", указанному в шапке документа. "Счет амортизации" и "КЭК" в составе полного счета учета амортизации заполнены автоматически, но могут быть отредактированы;
  • Сумма амортизации (БУ) и/или Сумма амортизации (НУ) – начисленная сумма амортизации на дату ввода остатков по соответствующему виду учета.

Заполнение реквизитов на закладке "События"

Реквизиты группы "Местонахождение":

  • МОЛ-Место хранения – место хранения объекта ОС (НМА), а также лицо, ответственное за сохранность объекта. Выбирается из справочника "Центры материальной ответственности".

Состояние ОС – текущее состояние объекта. Выбирается из списка:

  • Принято к учету;

После выбора значения "Принято к учету" для реквизита "Состояние ОС" доступны для заполнения только реквизиты группы "Принятие к учету".
  • Введено в эксплуатацию.

После выбора значения "Введено в эксплуатацию" для реквизита "Состояние ОС" становятся доступны для заполнения наряду с реквизитами группы "Принятие к учету" также реквизиты группы "Ввод в эксплуатацию".

Реквизиты группы "Принятие к учету":

  • Дата – дата принятия объекта ОС (НМА) к учету;
  • Название документа – наименование документа, которым объект ОС (НМА) был принят к учету;
  • Номер документа – номер документа, которым объект ОС (НМА) был принят к учету.

Реквизиты группы "Ввод в эксплуатацию":

  • Одновременно с принятием к учету – если принятие к учету объекта ОС и ввод его в эксплуатацию происходят одновременно, то необходимо установить флаг.

Примечание. После установки флага "Одновременно с принятием к учету" значения реквизитов "Дата", "Название документа" и "Номер" группы "Принятие к учету" автоматически копируются в реквизиты "Дата", "Название документа" и "Номер" группы "Ввод в эксплуатацию".
При этом реквизиты группы "Ввод в эксплуатацию" становятся недоступны для редактирования.
В тоже время они синхронно изменяются в случае редактирования соответствующих реквизитов группы "Принятие к учету".

Заполнение реквизитов на закладке "Амортизация"

Реквизиты группы "Параметры амортизации".

Порядок погашения стоимости – порядок погашения стоимости объекта ОС (НМА). Может принимать значения:

  • стоимость не погашается;
  • начисление амортизации.

Примечание. При выборе значения "Начисление амортизации" для реквизита "Порядок погашения стоимости" становятся доступны для заполнения реквизит "Начислять амортизацию", а также реквизиты группы "Счет затрат".

Срок полезного использования – срок полезного использования объекта ОС (НМА) "в месяцах". В скобках справочно выводится рассчитанное значение срока полезного использования "в годах".

Начислять амортизацию – флаг, который устанавливается при необходимости начислять амортизацию.

Реквизиты группы Расчет амортизации.

Автозаполнение – после установки флага происходит расчет значений и автоматическое заполнение реквизитов Остаточная стоимость, Оставшийся срок использования и Дата записи. При этом значения данных реквизитов недоступны для редактирования.

Если рассчитанные данные необходимо скорректировать, то флаг Автозаполнение следует снять, после чего значения указанных реквизитов можно изменить.

Примечание. Наличие дополнительных реквизитов для заполнения и их состав определяются настройкой аналитических разрезов учета в Плане счетов у счета затрат, выбранного в реквизите "Счет".

После ввода всех необходимых данных окно диалога закрывается с помощью кнопки "ОК" или сочетания клавиш "Ctrl-Enter".

Реквизиты группы "Счет затрат":

  • Счет – выбирается из фрагмента Плана счетов ЕПСБУ;
  • КЭК – код экономической классификации. Задается автоматически в зависимости от выбранного значения реквизита "Счет";
  • КПС – классификационный признак счета. Выбирается из справочника "Классификационные признаки счета".

Заполнение реквизитов на закладке "Капитальный ремонт"

Закладка Капитальный ремонт предназначена для ввода данных по истории капитального ремонта основных средств, выполненного ранее даты ввода начальных остатков.

После установки флага Автоматически устанавливать отбор по основному средству, выбранному в таблице Основные средства будет выполнен отбор по основному средству, на котором в данный момент в таблице Основные средства установлен курсор.

Данные, которые далее будут введены в табличной части на закладке Капитальный ремонт будут относиться именно к отобранному основному средству.

Примечание. Данные по истории модернизации и переоценки ОС вводятся на закладках Модернизация и Переоценка аналогичным образом.

Заполнение реквизитов на закладке "Бухгалтерская операция"

Типовая операция – не выбирается, имеет по умолчанию значение "Ввод начальных остатков ОС и НМА".

Проведение документа

Остатки по балансовым счетам вводятся в корреспонденции со счетом 000 "Вспомогательный". Остатки по счету 401.30 "Финансовый результат прошлых отчетных периодов" вводятся либо с помощью проводок, сформированных вручную, либо с помощью других документов.

При проведении документа формируются следующие проводки:

  • Дт "Счет учета" - Кт 000 "Вспомогательный счет" на сумму, равную значению реквизита "Балансовая стоимость";
  • Дт 000 "Вспомогательный счет" - Кт "Счет амортизации" на сумму, равную значению реквизита "Сумма амортизации".

При проведении документа кроме проводок по балансовым счетам производится также запись информации в справочник "Основные средства" - записывается информация об организации, виде НФА, виде имущества и первоначальной стоимости объекта ОС.

При проведении документа выполняются записи в следующие регистры.

В регистр сведений "Состояние и местонахождение ОС" записываются: "Учреждение", "Основное средство", "Инвентарный номер", "ЦМО" и "Состояние ОС".

В регистр сведений "События ОС" записываются: "Учреждение", "Основное средство", "Инвентарный номер", событие, дата события, вид и номер документа. Вводятся данные по тем событиям, информация о которых заполнена в строке. При этом на каждое событие формируется своя запись.

В регистр сведений "Расчет амортизации ОС" записываются: "Основное средство", "Срок полезного использования", "Остаточная стоимость для вычисления амортизации" и "Оставшийся срок использования для вычисления амортизации".

В регистр сведений "История амортизации" записываются: "Основное средство", "Инвентарный номер" и "Сумма амортизации".

В регистр сведений Капитальный ремонт ОС записываются: Основное средство, Инвентарный номер, Сумма, Номер документа о кап.ремонте.

В регистр сведений Модернизация ОС записываются: Основное средство, Инвентарный номер, Сумма модернизации, Срок полезного использования после модернизации, Номер документа о модернизации.

В регистр сведений Переоценка НФА записываются: НФА, Балансовая стоимость после переоценки, Амортизация после переоценки, Приказ о переоценке.

При установленном флаге Ввод остатков по налоговому учету документ формирует бухгалтерские проводки:

  • Дт Н01(Н04) Кт 000 на сумму (НУ);
  • Дт 000 Кт Н02(Н05) на сумму амортизации (НУ).

При установленном флаге Ввод остатков по налоговому учету производится запись в следующие регистры:

  • в регистр сведений Начисление амортизации ОС (налоговый учет) записываются: Основное средство, Начислять амортизацию;
  • в регистр сведений Параметры амортизации ОС (налоговый учет) записываются: Основное средство, Срок полезного использования;
  • в регистр сведений Первоначальные сведения ОС (налоговый учет) записываются: Основное средство, Первоначальная стоимость (НУ), Метод начисления амортизации (НУ);
  • в регистр сведений Специальный коэффициент для амортизации ОС (налоговый учет) записываются: Основное средство, Специальный коэффициент.

Регистрация документа

Регистрация документа "Ввод начальных остатков по ОС и НМА" производится в списке "Ввод начальных остатков".
