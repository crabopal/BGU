Проведение документа

Документ "Ввод начальных остатков по счету 106.хП"

На счетах 106.хП группы счетов 106.00 "Вложения в нефинансовые активы" плана счетов ЕПСБУ ведется учет в разрезе партий.

Это обуславливает необходимость во вводе начальных остатков на счетах 106.хП по каждой партии поступивших, но еще не принятых к учету материальных запасов.

Для ввода остатков по счетам 106.хП в разрезе партий в программе предназначен документ Ввод начальных остатков по счету 106.хП.

Примечание. Для остатков по каждой партии материальных запасов следует вводить свой документ.

После заполнения и записи документа можно сформировать печатную форму Ведомость введенных данных по счету 106.хП.

После проведения документа можно сформировать бухгалтерскую справку по ф. 0504833 (кнопка Печать).

Создание нового документа

Для ввода начальных остатков по счету 106.хП необходимо с помощью команды Помощник ввода начальных остатков меню функций раздела Администрирование открыть форму Помощник ввода начальных остатков.
Далее следует установить курсор на строку с номером счета 106.2П или 106.3П на закладке Основные счета и нажать на кнопку командной панели Ввести остатки по счету.

Заполнение реквизитов шапки документа

Дата – дата ввода начальных остатков;

Примечание. При вводе начальных остатков в качестве значения реквизита Дата должна быть установлена дата, предшествующая дате начала учета.

КФО – код финансового обеспечения. Выбирается из списка;
Организация – наименование организации.

В группе реквизитов Первичный документ партии материалов указываются:

  • Вид – вид документа. Выбирается из справочника Виды первичных документов;
  • Дата – дата первичного документа;
  • Номер– номер первичного документа.

Реквизиты группы "Режим ввода остатков"

Реквизиты группы Режим ввода остатков в новом документе по умолчанию имеют следующие значения:

  • Бух. учет – значение Да;
  • Налоговый учет – значение Нет.

При наличии необходимости в изменении значений, заданных по умолчанию, следует с помощью щелчка мыши по гиперссылке Да или Нет вызвать диалог Режим ввода остатков.

Далее следует установить или снять в диалоге флаги Ввод остатков по бухгалтерскому учету и Ввод остатков по налоговому учету.

Видимость и, следовательно, доступность для редактирования колонок табличной части документа зависит от настройки, выполненной в диалоге Режим ввода остатков.

Например, при установленных значениях Да для реквизита Бух. учет и Нет для реквизита Налоговый учет, в табличной части будут доступны только колонки с данными по бухгалтерскому учету.

После установки для реквизита Налоговый учет значения Да в табличной части станут также доступны колонки с данными по налоговому учету.

В некоторых случаях, например, при изменении системы налогообложения, у организации появляется потребность во вводе остатков только по налоговому учету, поскольку в результате ведения бухгалтерского учета данные по бухгалтерскому учету уже находятся в информационной базе.

В этом случае в новом документе Ввод начальных остатков по счету 106.хП в диалоге Режим ввода остатков следует снять флаг Ввод остатков по бухгалтерскому учету и установить флаг Ввод остатков по налоговому учету.

После подтверждения выполненной настройки и закрытия диалога с помощью кнопки ОК следует нажать на кнопку Заполнить по данным бух. учета командной панели
табличной части.

В результате табличная часть документа для целей налогового учета будет заполнена на основании данных бухгалтерского учета.

Далее введенные данные по налоговому учету можно при необходимости откорректировать и привести таким образом в соответствие реальным данным налогового учета.

Заполнение реквизитов табличной части "Материалы"

В таблицу Материалы вводится информация о номенклатуре, ее количестве и счете учета.

Для ввода новой строки можно нажать на кнопку Добавить командной панели табличной части.

  • Номенклатура – наименование МЗ. Выбирается из справочника Номенклатура;

Примечание. Если карточка номенклатуры отсутствует в справочнике Номенклатура, то ее необходимо создать с помощью, например, кнопки Создать командной панели формы списка. В новом элементе справочника следует в реквизите Наименование указать наименование номенклатуры, а в реквизите Ед. измерения выбрать единицу измерения. Сохранить сделанные изменения можно с помощью кнопки Записать и закрыть формы элемента. После это новый элемент можно выбрать при заполнении документа.

Примечание. Остальные реквизиты элемента справочника Номенклатура можно заполнить позднее, в процессе ведения учета.
  • Ед. изм. – справочно выводится значение реквизита Ед. измерения из карточки номенклатуры;
  • Количество – количество МЗ в партии;
  • (Дт), Счет (Дт), КЭК (Дт) – полный счет учета МЗ. Выбирается из плана счетов ЕПСБУ, ограниченного субсчетами счета 106.хП.

Заполнение реквизитов табличной части "Затраты"

В таблицу Затраты вводятся данные по суммам затрат в разрезе видов затрат.

Данные по видам затрат вводятся для позиции номенклатуры (строка таблицы), являющейся текущей в таблице Материалы.

Для ввода новой строки можно нажать на кнопку Добавить командной панели табличной части.

  • Вид затрат – Выбирается из справочника Виды затрат;
  • Сумма– балансовая стоимость партии МЗ.

Заполнение реквизитов "Бухгалтерская операция"

Типовая операция – не выбирается, имеет по умолчанию значение Ввод начальных остатков по счету 106хП.

Проведение документа

При проведении документа формируются следующие проводки:

Дт 106.хП Кт 000 "Вспомогательный счет" на сумму, равную значению реквизита Сумма.

При установленном флаге Ввод остатков по Налоговому учету формируется бухгалтерская проводка: Дт Н15 на сумму затрат (НУ).
