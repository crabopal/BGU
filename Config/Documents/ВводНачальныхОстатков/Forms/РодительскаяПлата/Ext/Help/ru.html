Документ "Ввод начальных остатков по родительской плате"

Документ Ввод начальных остатков по родительской плате предназначен для ввода сумм задолженности или переплаты родителей за содержание детей в начале эксплуатации программы, а также для автоматического формирования проводок по счету 205.31.

Примечание. Для получения возможности ведения учета расчетов по родительской необходимо установить флаг Учет расчетов с родителями за содержание детей в ДДУ в разделе Специализированные подсистемы формы Настройка параметров учета.

После заполнения и записи документа можно сформировать печатную форму Ведомость начальных остатков по родительской плате.
После заполнения и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Создание нового документа

Для ввода начальных остатков по родительской плате необходимо с помощью команды Помощник ввода начальных остатков меню функций раздела Администрирование открыть форму Помощник ввода начальных остатков.

Далее можно установить курсор на строку с номером счета 205.31 "Расчеты по доходам от оказания платных услуг (работ)" на закладке Основные счета и нажать на кнопку Ввести остатки по счету. Откроется форма Выберите один раздел учета, в которой следует выбрать Ввод остатков по ролительской плате.

Заполнение реквизитов шапки документа

Дата – дата ввода начальных остатков;

Примечание. При вводе начальных остатков в качестве значения реквизита Дата должна быть установлена дата, предшествующая дате начала учета.

Организация – наименование организации;
Принять детей в группу – после установки флажка становится доступна группа реквизитов Прием ребенка в группу в табличной части на закладке Родительская плата.
Группа детского учреждения – выбирается из справочника Группы детского учреждения.

Примечание. Заполнение реквизита Группы детского учреждения позволит использовать режим автозаполнения табличной части.

В группе Счет следует заполнить реквизиты:

  • КПС – классификационный признак счета, по которому учитываются доходы от поступления родительской платы. Выбирается из справочника КПС;
  • КФО – код финансового обеспечения. Выбирается из списка;
  • Счет – счет расчетов за услуги, оказанные детским учреждением, 205.31. Выбирается из фрагмента плана счетов ЕПСБУ.

Далее следует установить переключатель в нужное положение: Родительская плата или Доп. образовательные услуги.

Заполнение реквизитов на закладке "Родительская плата"

На закладке Родительская плата следует ввести список детей, по которым есть задолженность или переплата.

Примечание. Для заполнения списка группы по услуге в документ также можно ввести информацию о детях, по которым нет сальдо расчетов.

Если группа, выбранная в реквизите Группа детского учреждения, содержит список детей, то после нажатия на кнопку Заполнить – Списком детей табличная часть закладки будет заполнена списком детей, включенных в эту группу. Для каждого ребенка будет указана ставка оплаты.

Если для ребенка в справочнике Договоры и иные основания возникновения обязательств есть договор по виду услуг, указанному в документе Ввод начальных остатков по родительской плате, информация о нем будет отражена в графе Договор закладки Родительская плата.

Суммы задолженности или переплаты следует ввести в соответствующие поля.

В случае если группа, выбранная в реквизите Группа детского учреждения, не содержит список детей, то следует заполнить строки табличной части документа вручную, последовательно выбирая из справочника Дети детей из одной группы.

Примечание. Для выбора детей из справочника Дети удобно использовать форму подбора, для вызова которой следует нажать на кнопку Подобрать.

Для добавления в табличную часть по одной строке можно использовать кнопку Добавить.

Примечание. Дату выбытия необходимо ввести в случае, если на момент ввода остатков ребенок выбыл из группы, но по нему осталась сумма задолженности или переплаты.
  • Льгота – льгота по оплате за услуги. Если имеет место, то выбирается из справочника Льготы учащихся и воспитанников.

Заполненный документ следует сохранить, например, с помощью кнопки Записать объект.

Ребенок – выбирается из справочника Дети;
Номер лицевого счета – номер лицевого счета ребенка в справочнике Дети. Заполняется автоматически после заполнения реквизита Ребенок;
Договор – договор, соответствующий значению реквизита Группа детского учреждения, указанному в шапке документа. Автоматически подставляется договор, указанный на закладке Договоры справочника Дети и соответствующий указанной группе детского учреждения;
Задолженность – сумма задолженности по ребенку. Следует ввести остаток по дебету счета 205.31 (205.89);
Переплата – сумма переплаты по ребенку. Следует ввести остаток по кредиту счета 205.31 (205.89).
Ставка оплаты – ставку и правило расчета месячной суммы оплаты за услугу. Выбирается из справочника Ставки оплаты;
Дата приема – дата приема ребенка в группу.
Ставка оплаты – ставка и правило расчета месячной суммы оплаты за услугу. Выбирается из справочника Ставки оплаты.
Дата приема – дата приема ребенка в группу.
Льгота – льгота по оплате за услуги. Если имеет место, то выбирается из справочника Льготы учащихся и воспитанников.

Заполненный документ следует сохранить, например с помощью кнопки Записать.

Печать документа

Для проверки правильности введенных данных рекомендуется с помощью кнопки Печать сформировать Ведомость начальных остатков. Данная ведомость содержит список детей, ставки оплаты и введенные остатки. Для удобства работы Ведомость можно распечатать.

Заполнение реквизитов на закладке "Бухгалтерская операция"

Реквизит Типовая операция имеет по умолчанию значение Ввод начальных остатков по родительской плате.

Проведение документа

При проведении документа формируются проводки:

  • Дт 205.31 – Кт 000 "Вспомогательный счет" на сумму, равную значению реквизита Задолженность в строке документа;
  • Дт 000 "Вспомогательный счет" – Кт 205.31 на сумму, равную значению реквизита Переплата в строке документа.
