Документ "Ввод начальных остатков по имуществу казны (МЗ)"

Документ Ввод начальных остатков по имуществу казны (МЗ) служит для отражения в учете операций по вводу остатков материальных запасов по счету 108.56 «Материальные запасы в составе имущества казны».

Примечание. Для получения возможности ведения учета имущества казны необходимо установить флажок Вести учет имущества казны в разделе Специализированные подсистемы формы Настройка параметров учета раздела Администрирование.

После проведения документа можно сформировать бухгалтерскую справку по ф. 0504833 (кнопка Печать).

Создание нового документа

Для ввода начальных остатков материальных запасов в составе имущества казны необходимо с помощью команды Помощник ввода начальных остатков меню функций раздела Администрирование открыть форму Помощник ввода начальных остатков.

Далее следует установить курсор на строку с номером счета 108.56 Материальные запасы, составляющие казну на закладке Основные счета, и нажать на кнопку командной панели Ввести остатки по счету.

Откроется форма документа Ввод начальных остатков по имуществу казны (МЗ).

Заполнение реквизитов шапки документа
  • Дата– дата ввода начальных остатков;

Примечание. При вводе начальных остатков в качестве значения реквизита Дата должна быть установлена дата, предшествующая дате начала учета.
  • Организация – наименование организации. Выбирается из справочника Организации;
  • Счет – полный счет учета материальных запасов в составе имущества казны в соответствии с Планом счетов ЕПСБУ. Реквизит составной, содержит значения КПС, Счет (значение 108.56), КФО и КЭК. Необходимый набор значений выбирается из Рабочего плана счетов для счета 108.56.

Закладка "Материальные запасы"

Для ввода новой строки можно нажать на кнопку Добавить командной панели табличной части.

  • Номенклатура – соответствующая номенклатурная позиция. Выбирается из справочника Номенклатура;

Примечание. Если карточка номенклатуры отсутствует в справочнике Номенклатура, то ее необходимо создать с помощью, например, кнопки Создать командной панели формы списка. В новом элементе справочника следует в реквизите Наименование указать наименование номенклатуры, а в реквизите Ед. измерения выбрать единицу измерения. Реквизит Тип номенклатуры у нового элемента по умолчанию имеет значение Прочее МЗ. При необходимости это значение можно изменить. Сохранить сделанные изменения можно с помощью кнопки Записать и закрыть формы элемента. После этого новый элемент можно выбрать при заполнении документа.

Примечание. Остальные реквизиты элемента справочника Номенклатура можно заполнить позднее.
  • Ед. изм. – справочно выводится значение реквизита Ед. измерения из карточки номенклатуры;
  • Количество мест - указать количество приходуемых единиц (упаковок, банок, пачек, мешков и т.д.);
  • Коэффициент - указать количество МЗ в учетной единице измерения в 1 месте. По умолчанию предлагается 1.000.
  • Кол-во – общее количество МЗ по строке. Рассчитывается автоматически как произведение значений двух предыдущих граф (Кол-во = Количество мест х Коэффициент) или может быть указано вручную.
  • Сумма- указать балансовую стоимость указанного количества МЗ;
  • Подразделение -– выбирается из справочника Подразделения.

Бухгалтерская операция

Типовая операция– не выбирается, имеет по умолчанию значение Ввод начальных остатков по имуществу казны.

Проведение документа

При проведении документа формируются следующие проводки:

Дт 108.56 – Кт 000 (Вспомогательный счет) на сумму, равную значению реквизита "Балансовая стоимость".

Для проверки правильности ввода данных можно сформировать и напечатать бухгалтерскую справку по ф. 0504833 по проводкам документа.
