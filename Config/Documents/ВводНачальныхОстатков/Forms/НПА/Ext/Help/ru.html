Регистрация документа

(устарел) Документ "Ввод начальных остатков по НПА"

Документ "Ввод начальных остатков по НПА" предназначен для ввода в начале работы с программой входящих остатков по балансовой стоимости НПА.

В документ вносятся лишь актуальные сведения о НПА.

Данные указываются только для тех НПА, которые на момент ввода остатков уже приняты к учету, но еще не списаны.

После заполнения и записи документа можно сформировать печатную форму "Ведомость введенных данных по НПА".

После проведения документа можно сформировать бухгалтерскую справку по ф. 0504833 (кнопка "Печать").

Работа со списком документов

Документы вида "Ввод начальных остатков по НПА" находятся в списке "Ввод начальных остатков", который можно открыть с помощью команды "Ввод начальных остатков" панели навигации раздела "Настройка и администрирование".

Создание нового документа

Для ввода нового документа следует выбрать для реквизита "Раздел учета" списка "Ввод начальных остатков" значение "Ввод остатков по НПА", а затем нажать на кнопку "Создать".

Откроется форма документа "Ввод начальных остатков по НПА".

Заполнение реквизитов шапки документа
  • Дата – дата ввода начальных остатков;

Примечание. При вводе начальных остатков в качестве значения реквизита "Дата" должна быть установлена дата, предшествующая дате начала учета.
  • Организация – наименование организации;
  • КФО – код финансового обеспечения. Выбирается из списка;
  • Счет – полный счет учета ОС (НМА). Выбирается из плана счетов ЕПСБУ, ограниченного субсчетами счета 103.00 "Непроизведенные активы".

Заполнение реквизитов табличной части

Данные по объектам НПА вводятся в табличную часть документа.

Для ввода новой строки можно нажать на кнопку "Добавить" командной панели табличной части.

  • НПА – объект НПА. Выбирается из справочника "Основные средства";

Примечание. Если карточка объекта НПА отсутствует в справочнике "Основные средства", то ее необходимо создать с помощью, например, кнопки "Создать" командной панели формы списка. В новом элементе справочника следует в реквизите "Наименование" указать наименование нужного объекта НПА и сохранить сделанные изменения с помощью кнопки "Записать и закрыть" формы элемента. После это новый элемент можно выбрать при заполнении документа.

Примечание. Часть реквизитов элемента справочника "Основные средства" будет заполнена при вводе его остатков, остальные реквизиты можно заполнить позднее.
  • Инв. № – инвентарный номер объекта НПА;
  • Балансовая стоимость – балансовая стоимость объекта НПА с учетом капитальных вложений;
  • Первоначальная стоимость – первоначальная стоимость объекта НПА на дату вода в эксплуатацию;
  • МОЛ - Место хранения – центр материальной ответственности. Выбирается из справочника "Центры материальной ответственности";

Примечание. Если карточка центра материальной ответственности отсутствует в справочнике "Центры материальной ответственности", то ее необходимо создать с помощью, например, кнопки "Создать" командной панели формы списка.
Затем в новом элементе следует заполнить реквизиты "Сотрудник" и "Места хранения" выбором элементов из справочников "Сотрудники" и, соответственно, "Места хранения".
При отсутствии необходимых элементов в указанных справочниках их следует ввести.

При наличии в организации нескольких МОЛ с совпадающими фамилиями и инициалами рекомендуется при создании элемента справочника "Сотрудники" наряду с реквизитом "Наименование", в который полностью вводятся фамилия, имя и отчество сотрудника, заполнить также реквизит "ИНН". Значение "ИНН" позволяет однозначно идентифицировать сотрудника и избежать путаницы.

Примечание. Остальные реквизиты элемента справочника "Сотрудники" следует заполнить позднее, в процессе ведения учета.
  • Состояние НПА – состояние объекта НПА. Выбирается из списка и может принимать значения "Принято к учету" или "Введено в эксплуатацию".

Группа реквизитов "Принятие к учету":

  • Дата – дата принятия к учету объекта НМА;
  • Название документа – наименование документа по принятию к учету объекта НМА;
  • № документа – номер документа по принятию к учету объекта НМА.

Заполнение реквизитов "Бухгалтерская операция"

Типовая операция – не выбирается, имеет по умолчанию значение "Ввод начальных остатков по НПА".

Проведение документа

Остатки по балансовым счетам вводятся в корреспонденции со счетом 000 "Вспомогательный".

При проведении документа формируются следующие проводки:

Дт "Счет учета" Кт 000 "Вспомогательный счет" на сумму, равную значению реквизита "Балансовая стоимость".

Регистрация документа

Регистрация документа "Ввод начальных остатков по НПА" производится в списке "Ввод начальных остатков".
