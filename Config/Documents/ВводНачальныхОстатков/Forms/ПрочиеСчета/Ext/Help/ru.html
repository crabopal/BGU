Документ "Ввод начальных остатков по прочим счетам бух. учета"

Документ Ввод начальных остатков по прочим счетам бух. учета предназначен для ввода остатков вручную в начале работы с программой по тем счетам учета, для которых не предусмотрены специализированные документы по вводу остатков.

Режим ручного ввода отличается максимальной гибкостью, он позволяет указать любое содержание операции и ввести любые проводки.

Также документом Ввод остатков по прочим счетам бух.учета либо документом Операция (бухгалтерская) вводятся начальные остатки прочих непризнанных расходов, за исключением остатков по расходам на приобретение материальных запасов на складе и остатков по расходам на приобретение ОС (НМА) при применении УСН.

Каждая операция содержит одну или несколько проводок, отражающих хозяйственную операцию в бухгалтерском учете в натуральном и денежном выражении.

После заполнения и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833 (кнопка Печать).

Создание нового документа

Для ввода начальных остатков по прочим счетам учета необходимо с помощью команды Помощник ввода начальных остатков меню функций раздела Администрирование открыть форму Помощник ввода начальных остатков.

Далее можно установить курсор на строку с номером нужного счета на закладке Основные счета или Забалансовые счета, и нажать на кнопку командной панели Ввести остатки по счету. Откроется форма Ввод начальных остатков по прочим счетам бухгалтерского учета.

Откроется форма документа Ввод начальных остатков по прочим счетам бух. учета.

Заполнение реквизитов шапки документа
  • Дата – дата ввода начальных остатков;

Примечание. При вводе начальных остатков в качестве значения реквизита Дата должна быть установлена дата, предшествующая дате начала учета.
  • Организация – наименование организации. Выбирается из справочника Организации.

Данные операции по вводу остатков вручную вводятся в табличную часть документа.

Заполнение реквизитов табличной части
  • КФО – выбирается из списка;

Примечание. Остатки по дебету или кредиту балансового счета вводятся в корреспонденции со Вспомогательным счетом 000 соответственно по кредиту или дебету.
  • Счет – счет учета остатков. Выбирается из рабочего плана счетов. В зависимости от аналитики выбранного счета и наличия у счета признака ведения количественного учета может появиться потребность в заполнении реквизитов Субконто 1, Субконто 2, Субконто 3 и Количество;
  • Сумма– сумма проводки;
  • № Ж/О– номер журнала операций. Выбирается автоматически;
  • Первичный документ – вид первичного документа. Выбирается из справочника Первичные документы;
  • Дата– дата первичного документа;
  • Номер – номер первичного документа;
  • Содержание операции – дополнительная текстовая информация, кратко характеризующая конкретную проводку;
  • (Дт) Характеристика движения – дополнительная аналитическая информация, характеризующая движение по дебету счета. Выбирается из списка Выбор типа данных;
  • (Кт) Характеристика движения – дополнительная аналитическая информация, характеризующая движение по кредиту счета. Выбирается из списка Выбор типа данных.

С целью проверки правильности сформированных проводок после проведения документа можно сформировать и напечатать бухгалтерскую справку по ф.0504833.

Регистрация документа

Регистрация документа Ввод начальных остатков по прочим счетам бух. учета производится в списке Ввод начальных остатков.
