Документ "Ввод начальных остатков ОС на забалансовых счетах"

Документ Ввод начальных остатков ОС на забалансовых счетах предназначен для ввода в начале работы с программой входящих остатков:

  • объектов ОС, полученных в безвозмездное пользование или в аренду;
  • объектов ОС на хранении;
  • объектов ОС, признанных не активами;
  • по объектам основных средств, полученных по централизованному снабжению.

После проведения документа можно сформировать бухгалтерскую справку по ф. 0504833 (кнопка Печать).

Создание нового документа

Для ввода начальных остатков ОС на забалансовых счетах необходимо с помощью команды Помощник ввода начальных остатков меню функций раздела Администрирование открыть форму Помощник ввода начальных остатков.
Далее следует установить курсор на строку с номером счета 01.хх, 02.11, 02.3, 02.31 или 22.1 на закладке Забалансовые счета и нажать на кнопку командной панели Ввести остатки по счету.

Заполнение реквизитов шапки документа

Дата – дата ввода начальных остатков, предшествует дате начала учета.
Организация – наименование организации.
Вид учета – выбирается из списка, может принимать значения:

  • Собственные и в оперативном управлении,
  • Основные средства в пользовании,
  • На ответственном хранении.

Счет – выбирается из фрагмента плана счетов, обусловленного значением реквизита Вид учета.
КФО – код финансового обеспечения. Выбирается из списка.
Контрагент – выбирается из справочника Контрагенты.

Закладка "Основные средства"

Данные по объектам ОС вводятся в табличную часть документа.
Для ввода новой строки можно нажать кнопку Добавить командной панели табличной части.

  • Основное средство – объект ОС. Выбирается из справочника Основные средства, НМА, НПА. Если карточка объекта ОС отсутствует в справочнике Основные средства, НМА, НПА, то ее необходимо создать – с помощью кнопки Создать командной панели формы списка. В новом элементе справочника следует в реквизите Наименование указать наименование нужного объекта ОС и сохранить сделанные изменения с помощью кнопки Записать и закрыть формы элемента. После этого новый элемент можно выбрать при заполнении документа.
  • Гр. уч. – признак ведения группового учета, отображается справочно.
  • Инв. № – инвентарный номер объекта ОС, если он имеется у объекта.
  • Количество – количество объектов ОС.
  • Сумма – суммарная балансовая стоимость объектов ОС.
  • МОЛ/Место хранения – центр материальной ответственности. Выбирается из справочника Центры материальной ответственности. Если карточка центра материальной ответственности отсутствует в справочнике Центры материальной ответственности, то ее необходимо создать – с помощью кнопки Создать командной панели формы списка. Затем в новом элементе следует заполнить реквизиты Сотрудник и Места хранения выбором элементов из справочников Сотрудники и, соответственно, Места хранения. При отсутствии необходимых элементов в указанных справочниках их следует ввести.

При наличии в организации нескольких МОЛ с совпадающими фамилиями и инициалами рекомендуется при создании элемента справочника Сотрудники наряду с реквизитом Наименование, в который полностью вводятся фамилия, имя и отчество сотрудника, заполнить также реквизит ИНН. Значение ИНН позволяет однозначно идентифицировать сотрудника и избежать путаницы. Остальные реквизиты элемента справочника Сотрудники следует заполнить позднее, в процессе ведения учета.

Бухгалтерская операция

Реквизит Типовая операция имеет по умолчанию значение Ввод начальных остатков ОС на забалансовых счетах.

Проведение документа

При проведении документа в зависимости от выбранных значений реквизитов Вид учета НФА и Забалансовый счет учета формируются проводки:

  • по дебету забалансового счета 22.1 "Основные средства, полученные по централизованному снабжению";
  • по дебету забалансового счета 01.ХХ "Имущество, полученное в пользование";
  • по дебету забалансового счета 02.ХХ "ОС на хранении";
  • по дебету забалансового счета 02.3 "ОС, не признанные активом".

Кроме того, формируются движения по регистрам:

  • Стоимость объектов ОС, НМА, НПА (по контрагентам),
  • Учетные данные объекта ОС, НМА, НПА.
