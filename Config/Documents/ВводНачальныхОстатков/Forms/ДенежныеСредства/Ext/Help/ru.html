Документ "Ввод начальных остатков наличных денежных средств"

Документ Ввод начальных остатков наличных денежных средств предназначен для формирования проводок по вводу начальных остатков на счет 201.34 Касса в разрезе КПС и КЭК в начале работы с программой.

Примечание. По каждой организации (балансу), виду деятельности вводится отдельный документ.

После заполнения и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833 (кнопка Печать).

Создание нового документа

Для ввода начальных остатков наличных денежных средств необходимо с помощью команды Помощник ввода начальных остатков меню функций раздела Администрирование открыть форму Помощник ввода начальных остатков.

Далее следует установить курсор на строку с номером счета 201.34 на закладке Основные счета, и нажать на кнопку командной панели Ввести остатки по счету.

Откроется форма документа Ввод начальных остатков наличных денежных средств.

Заполнение реквизитов шапки документа
  • Дата– дата ввода начальных остатков;

Примечание. При вводе начальных остатков в качестве значения реквизита "Дата" должна быть установлена дата, предшествующая дате начала учета.
  • Организация – наименование организации;
  • Счет кассы – полный счет 201.34 (субсчет), включая КПС и КФО. Если к счету 201.34 открыты пользовательские субсчета, следует указать конечный субсчет счета 201.34. Необходимый набор значений выбирается из Рабочего плана счетов для счета 201.34 (субсчет);
  • Сумма – общая сумма документа. Заполняется с помощью кнопки Скорректировать сумму после того, как все суммы в табличной части на закладке Наличные денежные средства будут указаны.

Закладка "Наличные денежные средства"

Данные по остаткам денежных средств в разрезе КПС и КЭК вводятся в табличную часть документа.

Для ввода новой строки можно нажать на кнопку Добавить командной панели табличной части.

  • Назначение остатка по КПС – выбирается из справочника КПС;
  • Назначение остатка по КЭК – выбирается из справочника КЭК;
  • Сумма – сумма денежных средств.

Заполнение реквизитов "Бухгалтерская операция"

Типовая операция – не выбирается, имеет по умолчанию значение Ввод начальных остатков денежных средств.

Проведение документа

При проведении документа формируются следующие проводки:

  • Дт 201.34 Кт 000 Вспомогательный счет на сумму, равную значению реквизита Сумма в шапке документа или, другими словами, на общую сумму документа;
  • Дт НД (Забалансовый счет) на сумму каждой строки табличной части, другими словами по каждому назначению остатка по КПС и КЭК.

Регистрация документа

Регистрация документа Ввод начальных остатков наличных денежных средств производится в списке Ввод начальных остатков.
