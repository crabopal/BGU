Регистрация документа

Документ "Ввод начальных остатков ОС на забалансовых счетах"

Документ Ввод начальных остатков ОС на забалансовых счетах предназначен для ввода в начале работы с программой входящих остатков:

  • объектов ОС, полученных в безвозмездное пользование или в аренду;
  • объектов ОС, принятых на ответственное хранение;
  • по объектам основных средств, полученных по централизованному набжению.

После заполнения и записи документа можно сформировать печатную форму Ведомость введенных данных по ОС в оперативном учете.

После проведения документа можно сформировать бухгалтерскую справку по ф. 0504833 (кнопка Печать).

Создание нового документа

Для ввода начальных остатков ОС на забалансовых счетах необходимо с помощью команды Помощник ввода начальных остатков меню функций раздела Администрирование открыть форму Помощник ввода начальных остатков.

Далее следует установить курсор на строку с номером счета 01.хх, 02.1 или 22.1 на закладке Забалансовые счета, и нажать на кнопку командной панели Ввести остатки по счету.

Откроется форма документа Ввод начальных остатков по ОС на забалансовых счетах.

Заполнение реквизитов шапки документа

Дата – дата ввода начальных остатков.

Примечание. При вводе начальных остатков в качестве значения реквизита Дата должна быть установлена дата, предшествующая дате начала учета.

Организация – наименование организации.

Вид учета НФА – выбирается из списка, может принимать значения:

  • Собственные и в оперативном управлении;
  • Основные средства в пользовании;
  • На ответственном хранении.

КФО – код финансового обеспечения. Выбирается из списка.
Забалансовый счет учета – выбирается из фрагмента Плана счетов, обусловленного значением реквизита Вид учета НФА.

Закладка "Основные средства"

Данные по объектам ОС вводятся в табличную часть документа.

Для ввода данных по объектам ОС в программе предусмотрено два режима: Редактирование в диалоге и Редактирование в строке. Для перехода от одного режима к другому используется кнопка Редактирование в диалоге командной панели табличной части формы документа.

Количество реквизитов, которые можно ввести в режимах Редактирование в строке и Редактирование в диалоге, отличается.

Ввод данных в табличную часть документа Ввод начальных остатков ОС на забалансовых счетах всегда начинается с режима Редактирование в строке, который позволяет быстро ввести минимально необходимое количество основных реквизитов.

Для продолжения редактирования и ввода всех остальных реквизитов следует использовать режим Редактирование в диалоге.

Режим "Редактирование в строке"
  • Основное средство – объект ОС. Выбирается из справочника Основные средства;

Примечание. Если карточка объекта ОС или НМА отсутствует в справочнике Основные средства, то ее необходимо создать с помощью, например, кнопки Создать командной панели формы списка. В новом элементе справочника следует в реквизите Наименование указать наименование нужного объекта ОС или НМА и сохранить сделанные изменения с помощью кнопки Записать и закрыть формы элемента. После это новый элемент можно выбрать при заполнении документа.
  • Гр. уч. – признак ведения группового учета, отображается справочно. Установка флажка Групповой учет в строке выполняется, если это необходимо, при редактировании в диалоге.
  • Инв. № – инвентарный номер объекта ОС или НМА, если он имеется у объекта. Возможность задания списка инвентарных номеров для объектов ОС становится доступна в режиме Редактирование в диалоге после установки флажка Групповой учет.
  • Количество – количество объектов ОС.
  • Балансовая стоимость – суммарная балансовая стоимость объекта ОС.
  • МОЛ/Место хранения – центр материальной ответственности. Выбирается из справочника Центры материальной ответственности.

Примечание. Если карточка центра материальной ответственности отсутствует в справочнике Центры материальной ответственности, то ее необходимо создать с помощью, например, кнопки Создать командной панели формы списка. Затем в новом элементе следует заполнить реквизиты Сотрудник и Места хранения выбором элементов из справочников Сотрудники и, соответственно, Места хранения. При отсутствии необходимых элементов в указанных справочниках их следует ввести.

Важно!
При наличии в организации нескольких МОЛ с совпадающими фамилиями и инициалами рекомендуется при создании элемента справочника Сотрудники наряду с реквизитом Наименование, в который полностью вводятся фамилия, имя и отчество сотрудника, заполнить также реквизит ИНН. Значение ИНН позволяет однозначно идентифицировать сотрудника и избежать путаницы.

Примечание. Остальные реквизиты элемента справочника Сотрудники следует заполнить позднее, в процессе ведения учета.

Режим "Редактирование в диалоге"

Внимание!
Чтобы редактирование в диалоге строки табличной части стало возможно, поле Основное средство строки должно быть заполнено.

Для перехода в режим Редактирование в диалоге необходимо нажать кнопку Редактирование в диалоге на командной панели табличной части, далее дважды щелкнуть левой кнопкой мыши по строке или выделить строку и нажать клавишу Enter.

Диалог Ввод начальных остатков ОС – строка (номер строки) имеет закладки:

  • Общие сведения,
  • События.

Заполнение реквизитов шапки диалога
  • Организация – справочно отображается название организации.
  • Основное средство – отображается наименование основного средства. Карточка основного средства может быть открыта и отредактирована.
  • Групповой учет – при необходимости ведения группового учета ОС следует установить флажок.
  • Инв. номер – инвентарный номер объекта ОС.

Закладка "Общие сведения"

Счет учета – отображается справочно.
Первоначальная стоимость (БУ) – первоначальная стоимость объекта ОС в бухгалтерском учете.
Сумма (БУ) – суммарная балансовая стоимость объектов ОС. Можно внести изменения.
Количество – количество объектов ОС.

Значения реквизитов Первоначальная стоимость (БУ), Сумма (БУ) и Количество можно отредактировать.

Закладка "События"

Группа Местонахождение:
МОЛ - Место хранения – центр материальной ответственности.
Подразделение – подразделение, в котором находится объект ОС.
Состояние ОС – выбирается из списка.

Группа Принятие к учету
Дата, Название документа и Номер – реквизиты первичного документа, которым зарегистрировано принятие объекта ОС к учету.
Номер инвентарной карточки – номер инвентарной карточки объекта ОС.

Группа Ввод в эксплуатацию.
Одновременно с принятием к учету – если флажок снят, то потребуется заполнить реквизиты первичного документа по вводу объекта ОС в эксплуатацию: Дата, Название документа и Номер.

Закладка "Капитальный ремонт"

На данной закладке заполняется история капительного ремонта основных средств, выполненного до даты ввода начальных остатков.
З
аполнение реквизитов аналогично описанному заполнению на закладке Кап. ремонт документа Ввод начальных остатков ОС, НМА, НПА.

Заполнение реквизитов на закладке "Бухгалтерская операция"

Типовая операция – не выбирается, имеет по умолчанию значение "Ввод начальных остатков по ОС на забалансовых счетах".

Проведение документа

При проведении документа в зависимости от выбранных значений реквизитов Вид учета НФА и Забалансовый счет учета формируются проводки:

  • по дебету забалансового счета 22.1 Основные средства, полученные по централизованному снабжению;
  • по дебету забалансового счета 01.ХХ Имущество, полученное в пользование;
  • по дебету забалансового счета 01.1 ОС, принятые на ответственное хранение.

Кроме того, формируются движения по регистрам сведений:

  • Состояние и местонахождение ОС;
  • Регистр События ОС.

Регистрация документа

Регистрация документа "Ввод начальных остатков по ОС на забалансовых счетах" производится в списке "Ввод начальных остатков".
