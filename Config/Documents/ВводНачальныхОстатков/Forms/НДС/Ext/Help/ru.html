Документ "Ввод начальных остатков НДС"

Документ Ввод начальных остатков НДС предназначен для ввода начальных остатков как входящего НДС, принимаемого к вычету, так и исходящего НДС, подлежащего перечислению в бюджет.

Примечание. Документ Ввод начальных остатков НДС вводится в межотчетный период, перед началом работы с программой.

Важно
Остатки по входящему и исходящему НДС следует вводить в отдельных документах.

При вводе остатков по НДС вводятся данные по счетам-фактурам и замещающим их документам, по которым на дату ввода входящих остатков не завершены расчеты.

После заполнения и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833 (кнопка Печать).

Создание нового документа

Для ввода начальных остатков по НДС необходимо с помощью команды Помощник ввода начальных остатков меню функций раздела Администрирование открыть форму Помощник ввода начальных остатков.

Далее можно установить курсор на строку с номером счета 201.10 "Расчеты по налоговым вычетам по НДС" на закладке Основные счета и нажать на кнопку командной панели Ввести остатки по счету.

Откроется форма документа Ввод начальных остатков НДС.

Заполнение реквизитов шапки документа

Дата – дата ввода начальных остатков;

Примечание. При вводе начальных остатков в качестве значения реквизита Дата должна быть установлена дата, предшествующая дате начала учета.

Организация – наименование организации. Выбирается из справочника Организации;
Вид документа – вид первичного документа. Значение по умолчанию Бухгалтерская справка 0504833, но может быть отредактировано пользователем непосредственно в данном поле.

Вид НДС – переключатель, может принимать значения:

  • Входящий – для ввода остатков по входящему НДС, принимаемого к вычету;
  • Исходящий – для ввода остатков по исходящему НДС, подлежащему перечислению в бюджет, по которым расчеты на дату ввода остатков не закрыты.

Примечание. От значения реквизита Вид НДС зависит состав реквизитов табличной части документа. При изменении значения реквизита Вид НДС очищаются колонки Причина налогообложения и Счет расчетов в табличной части документа.

Заполнение реквизитов табличной части для входящего НДС

Для ввода новой строки можно нажать на кнопку Добавить командной панели табличной части.

Номер счета-фактуры, Дата счета-фактуры – указать номер и дату счета-фактуры, который был получен организацией от поставщика.

Контрагент – поставщик товаров, работ (услуг). Выбирается из справочника Контрагенты;

Примечание. Если карточка контрагента отсутствует в справочнике Контрагенты, то ее необходимо создать с помощью, например, кнопки Создать командной панели формы списка. В новом элементе справочника следует в реквизите Наименование указать наименование контрагента, а в реквизите ИНН указать его ИНН. Сохранить сделанные изменения можно с помощью кнопки Записать и закрыть формы элемента. После это новый элемент можно выбрать при заполнении документа.

Значение ИНН позволяет однозначно идентифицировать контрагента и избежать путаницы в учете.

Примечание. Остальные реквизиты элемента справочника Контрагенты можно заполнить позднее, в процессе ведения учета.

Договор – договор с указанным контрагентом. Выбирается из справочника Договоры и иные основания возникновения обязательств, подчиненного справочнику Контрагенты.

Причина налогообложения – выбирается из списка:

  • Аванс полученный;
  • Внутреннее потребление;
  • Возврат НФА поставщику;
  • Налоговый агент – аренда, покупка ФИ (п. 3. ст. 161);
  • Налоговый агент – покупка у нерезидента (п. 2. ст. 161);
  • Реализация;
  • Реализация по ставке 0%;
  • Налоговый агент – реализация конфиската, клад (п.4, ст.161);
  • СМР хозяйственным способом;
  • Аванс выданный;
  • Возврат от покупателя;
  • Таможенные платежи;
  • Покупка;
  • СМР подрядным способом;
  • Аванс полученный (лом, шкуры, п.8, ст.161);
  • Реализация лома, шкур (п.8, ст.161).

Вид ценности – выбирается из списка:

  • ОС и НМА;
  • Материалы;
  • Услуги;
  • Аванс;
  • Прочее.

Ставка НДС – выбирается из списка.
Сумма без НДС – вводится числом;
НДС – рассчитывается автоматически;
КФО – выбирается из списка;
Счет вычета (Кт) – полный счет расчетов по НДС 201.Р1 по приобретенным материальным ценностям, работам и услугам. Выбирается из фрагмента Плана счетов ЕПСБУ;
Счет расчетов – счет расчетов 302.ХХ с поставщиком материальных ценностей, работ (услуг). Выбирается из фрагмента плана счетов ЕПСБУ.
Объект налогообложения – документ, подтверждающий факт поступления товарно-материальных ценностей, работ, услуг. Конкретный документ-основание выбирается из соответствующего списка после выбора типа документа.

Способ выставления – способ выставления счета-фактуры. Выбирается из списка:

  • Бумажный;
  • Электронный.

Документ корректировки – Корректировочный счет-фактура полученный или Исправительный счет-фактура полученный. Выбирается из соответствующего списка после указания вида документа.
Место регистрации – место регистрации счета-фактуры. Выбирается из двух вариантов: Книга продаж или Доп. лист.

Заполнение реквизитов табличной части для исходящего НДС

Для ввода новой строки можно нажать на кнопку Добавить командной панели табличной части.

Номер счета-фактуры, Дата счета-фактуры – указать номер и дату исходящего счета-фактуры, по которому еще остались расчеты;
Контрагент – покупатель товаров, работ (услуг).

Примечание. Все реквизиты табличной части за исключением реквизитов Счет расчетов, Счет дебета и Документ корректировки заполняются аналогично тому, как описано выше в разделе "Заполнение реквизитов табличной части для входящего НДС".

Счет расчетов – полный счет расчетов 205.ХХ с покупателем материальных ценностей, работ (услуг). Выбирается из фрагмента рабочего плана счетов;
Счет дебета – дебет счета 401.ХХ и его аналитика для начисления НДС. Выбирается из фрагмента Плана счетов.
Документ корректировки – Корректировочный счет-фактура выданный или Исправительный счет-фактура выданный. Выбирается из соответствующего списка после указания вида документа.

Заполнение реквизитов "Бухгалтерская операция"

Типовая операция – не выбирается.

Примечание. Для значения Входящий реквизита Вид НДС реквизит Типовая операция имеет значение Ввод начальных остатков входящего НДС.
Для значения Исходящий реквизита Вид НДС у реквизита Типовая операция значение отсутствует.

Проведение документа

Если реквизит Вид НДС в шапке документа имеет значение Входящий, то при проведении документа по каждой строке табличной части будут сформированы проводки вида Дт 210.Р1 "Расчеты по НДС по приобретенным материальным ценностям, работам, услугам" – Кт 000 "Вспомогательный", а также записи в регистрах накопления, необходимые для дальнейшего учета НДС.

Также по каждой строке можно сформировать документы вида Счет-фактура полученный. Для этого следует нажать кнопку Создать. Увидеть список созданных счетов-фактур можно в табличной части НДС в колонке Счет-фактура или по гиперссылке Список документов, которая находится в левом нижнем углу формы документа в группе Созданные счета-фактуры.

Счет-фактуры, созданные на основании документа Ввод начальных остатков НДС будут не доступны для проведения, так как движения по регистрам формируются документом ввода остатков. При желании сформированные счета-фактуры можно отредактировать вручную, в т.ч. дозаполнить табличную часть.

Если реквизит Вид НДС в шапке документа имеет значение Исходящий, то при проведении документа проводки по балансовым счетам не формируются. При этом выполняются только движения по регистрам накопления, необходимые для дальнейшего учета НДС.

Также по каждой строке можно сформировать документы вида Счет-фактура выданный. Для этого следует нажать кнопку Создать. Увидеть список созданных счетов-фактур можно в табличной части НДС в колонке Счет-фактура или по гиперссылке Список документов, которая находится в левом нижнем углу формы документа в группе Созданные счета-фактуры.

Примечание. При попытке проведения документа Ввод начальных остатков НДС программа выполняет проверку на предмет существования в информационной базе документов Счет-фактура полученный или Счет-фактура выданный с таким же набором реквизитов, как те, которые она пытается создать. При обнаружении в информационной базе хотя бы одного такого документа будет сформировано сообщение, при этом создание новых счетов-фактур по всем строкам будет отменено.
