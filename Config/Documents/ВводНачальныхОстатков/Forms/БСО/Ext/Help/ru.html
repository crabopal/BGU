Документ "Ввод начальных остатков по БСО"

Документ Ввод начальных остатков по БСО предназначен для ввода данных об остатках бланков строгой отчетности в начале эксплуатации программы и автоматического формирования проводок.

Примечание. Согласно инструкции по применению ЕПСБУ бланки принимаются к забалансовому учету по условной оценке 1 руб. за один бланк.

После заполнения и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833 (кнопка Печать).

Создание нового документа

Для ввода начальных остатков БСО необходимо с помощью команды Помощник ввода начальных остатков меню функций раздела Администрирование открыть форму Помощник ввода начальных остатков.

Далее следует установить курсор на строку с номером счета 03.1 «Бланки строгой отчетности (в усл. ед.)» на закладке Забалансовые счета и нажать на кнопку командной панели Ввести остатки по счету.

Откроется форма документа Ввод начальных остатков по БСО.

Заполнение реквизитов шапки документа
  • Дата – дата ввода начальных остатков;

Примечание. При вводе начальных остатков в качестве значения реквизита Дата должна быть установлена дата, предшествующая дате начала учета.
  • Организация – наименование организации;
  • МОЛ - Место хранения – центр материальной ответственности. Выбирается из справочника Центры материальной ответственности;
  • Счет – справочно выводится счет учета бланков строгой отчетности 03.1, на который будут зачислены остатки БСО. Карточка счета доступна для просмотра;
  • КФО – код финансового обеспечения. Выбирается из списка.

Заполнение реквизитов табличной части "БСО"

Данные по остаткам бланков строгой отчетности вводятся в табличную часть.

Для ввода новой строки можно нажать на кнопку Добавить командной панели табличной части.

  • БСО – наименование бланка строгой отчетности. Выбирается из справочника Бланки строгой отчетности;

Примечание. Если карточка БСО отсутствует в справочнике Бланки строгой отчетности, то ее необходимо создать с помощью, например, кнопки Создать командной панели формы списка. В новом элементе справочника следует в реквизите Наименование указать наименование бланка строгой отчетности, а в реквизите Ед. измерения выбрать единицу измерения. В реквизите Длина номера необходимо ввести число, соответствующее количеству знаков в номере данного БСО.
Сохранить сделанные изменения можно с помощью кнопки Записать и закрыть формы элемента. После это новый элемент можно выбрать при заполнении документа.
  • Ед. изм. – единица измерения бланков строгой отчетности. Заполняется автоматически на основании значения реквизита Единица, заданного для данного вида БСО;
  • Серия – серия бланков строгой отчетности. Выбирается из справочника Серии бланков строгой отчетности;
  • Начальный номер – начальный номер указанной серии БСО. Количество знаков в номере соответствует значению реквизита Длина номера бланка строгой отчетности;

Примечание. Реквизит Начальный номер обязательно должен быть заполнен. При этом если указано только значение реквизита Начальный номер, а значение реквизита Конечный номер не указано, то это означает, что речь идет об одном бланке.
  • Конечный номер – конечный номер указанной серии БСО. Количество знаков в номере соответствует значению реквизита Длина номера бланка строгой отчетности;
  • Количество – количество БСО указанной серии. Рассчитывается автоматически на основании значений реквизитов Начальный номер и Конечный номер.

Заполнение реквизитов "Бухгалтерской операции"

Реквизит Типовая операция имеет по умолчанию значение Ввод начальных остатков БСО.

Проведение документа

При проведении документа по каждой строке формируется проводка по дебету забалансового счета 03.1 Бланки строгой отчетности (в усл. ед.).

Регистрация документа

Регистрация документа Ввод начальных остатков по БСО производится в списке Ввод начальных остатков.
