Документ "Ввод начальных остатков по учащимся"

Документ Ввод начальных остатков по учащимся предназначен для ввода начальных остатков по договорам платного обучения учащихся, по договорам оказания прочих (дополнительных) услуг, а также для первоначального ввода списка учащихся и плательщиков за их обучение, распределения учащихся по группам и факультетам.

Примечание. Для включения возможности ведения учета расчетов по образовательным услугам необходимо установить флаг Учет расчетов по образовательным услугам в разделе Специализированные подсистемы - Учет расчетов по образовательным услугам формы Настройка параметров учета.

После заполнения и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833 (кнопка Печать).

Создание нового документа

Для ввода начальных остатков по учащимся необходимо с помощью команды Помощник ввода начальных остатков меню функций раздела Администрирование открыть форму Помощник ввода начальных остатков.

Далее можно установить курсор на строку с номером счета 205.31 "Расчеты с плательщиками доходов от оказания платных работ, услуг" на закладке Основные счета и нажать на кнопку командной панели Ввести остатки по счету. Откроется форма Выберите один раздел учета, в которой следует выбрать Ввод остатков по учащимся. Откроется форма документа Ввод начальных остатков по учащимся.

Работа со списком документов

Список документов Ввод начальных остатков по учащимся с возможностью отбора по факультету, курсу обучения, группе учащихся доступен на закладке Ввод остатков по учащимся в форме Помощник ввода начальных остатков.

Заполнение реквизитов шапки документа
  • Дата – дата ввода начальных остатков;

Примечание. При вводе начальных остатков в качестве значения реквизита Дата должна быть установлена дата, предшествующая дате начала учета.
  • Организация – наименование организации;
  • Первичный документ – вид первичного документа. Значение по умолчанию Бухгалтерская справка, но может быть отредактировано пользователем непосредственно в данном поле;
  • Начисление - выбирается из вариантов:
    • за услуги образования - начисления по основным образовательным программам. Учащиеся распределяются по факультетам, курсам обучения и группам учащихся, учитываются состояния учащихся.
    • за прочие услуги - начисления по дополнительным образовательным услугам (образовательным курсам, кружкам и пр.) и прочим услугам (общежитие и т.п.). Начисления за прочие услуги формируются по видам прочих услуг в течение указанного периода начисления.
  • Вид начислений - выбирается из вариантов:
    • По долгосрочным договорам - по договорам, относящимся к долгосрочным согласно Стандарту "Долгосрочные договоры";
    • По краткосрочным договорам - по договорам, не относящимся к долгосрочным.
  • Факультет – выбирается из справочника Подразделения;
  • Зачислить в группу – установите флажок, чтобы отразить зачисление учащихся в выбранную группу учащихся и курс обучения (недоступно при начислении за прочие услуги):
    • Группа учащихся – выбирается из справочника Группы учащихся; 
    • Курс обучения – выбирается из справочника Курсы обучения.
  • КФО – выбирается из списка, по умолчанию заполняется значением КФО 2 "Приносящая доход деятельность (собственные доходы учреждения)". 

Закладка "Учащиеся"

В табличную часть на закладке Учащиеся вводятся данные по остаткам задолженности и переплаты учащихся.

Для ввода новой строки можно нажать на кнопку Добавить командной панели табличной части.

  • Учащийся – выбирается из справочника Учащиеся.

Примечание. При снятом флажке Зачислить в группу добавление учащихся в табличную часть производится из списка Учащихся с отбором по факультету, заданному в реквизите Факультет. При установленном флажке добавление учащихся в табличную часть выполняется из полного списка Учащихся, без отбора. 

Примечание. Если карточка учащегося отсутствует в справочнике Учащиеся, то ее необходимо создать с помощью, например, кнопки Создать командной панели формы списка. Для создания карточки учащегося с возможностью добавления ее в табличную часть необходимо, чтобы флажок Зачислить в группу в шапке документа был установлен. Затем в новом элементе следует заполнить реквизиты Наименование, а также ИНН. Значение ИНН позволяет однозначно идентифицировать учащегося и избежать путаницы в учете. Остальные реквизиты элементов справочника Учащиеся следует заполнить позднее, в процессе ведения учета.

Группа реквизитов Плательщик, договор:

  • Контрагент – плательщик за образовательные услуги. Выбирается из справочника Контрагенты;

Примечание. Если карточка контрагента отсутствует в справочнике Контрагенты, то ее необходимо создать с помощью, например, кнопки Создать командной панели формы списка. В новом элементе справочника следует в реквизите Наименование указать наименование контрагента, а в реквизите ИНН указать его ИНН. Значение ИНН позволяет однозначно идентифицировать контрагента и избежать путаницы в учете. Остальные реквизиты элемента справочника Контрагенты можно заполнить позднее, в процессе ведения учета. Сохранить сделанные изменения можно с помощью кнопки Записать и закрыть формы элемента. После этого новый элемент можно выбрать при заполнении документа. 

  • Договор – договор на оплату услуг с указанным контрагентом. Выбирается из справочника Договоры и иные основания возникновения обязательств, подчиненного справочнику Контрагенты;

В группе реквизитов Расчеты выбирается счет расчетов по доходам 205.хх, КПС и дополнительная аналитика расчетов. Порядок выписки счета-фактуры - автоматически устанавливается значение На плательщика.

Для начислений за прочие услуги указываются:

  • Начисление за услугу – вид прочих услуг, выбирается из справочника прочих услуг;
  • Период начисления – выбираются даты начала и окончания периода начисления;

Для начислений по краткосрочным договорам указываются:

  • Ставка оплаты – ставка оплаты за услуги образования, выбирается из справочника ставок оплаты (недоступно при начислении за прочие услуги);
  • Льгота – выбирается из справочника льгот учащихся и воспитанников;
  • Задолженность - сумма задолженности плательщика за обучение учащегося, если она имеет место;
  • Переплата - сумма переплаты плательщика за обучение учащегося, если она имеет место.

Для начислений по долгосрочным договорам указываются:

  • Остатки до конца срока действия договора:
    • Не оплачено (205.00) – остаток расчетов с дебиторами по доходам от реализации за оставшийся срок действия долгосрочного договора (см. пункт 11 Стандарта "Долгосрочные договоры");
    • Не исполнено (401.40) - остаток предстоящих доходов за оставшийся срок действия долгосрочного договора.
  • Задолженность, Переплата – вычисляются автоматически как разница между показателями Не оплачено и Не исполнено за оставшийся срок действия долгосрочного договора.
  • Признание доходов - параметры признания доходов текущего периода (по месяцам / по календарным дням / по графику / в особом порядке).
  • Отражение доходов в учете - счета и аналитики учета доходов текущего периода в бухгалтерском учете, параметры отражения доходов в налоговом учете.

Закладка "Порядок оплаты"

На закладке Порядок оплаты вводится порядок оплаты услуг по долгосрочным договорам (Стандарт "Долгосрочные договоры").

В левой части формы следует выделить строку с учащимся. Порядок оплаты для выбранного учащегося вводится в правой части формы:

  • Оплачено - флаг следует установить в строках с оплаченными периодами обучения;
  • Оплатить до – планируемая (крайняя) дата оплаты, после которой платеж будет считаться просроченным; 
  • Сумма в валюте – указывается сумма оплаты (стоимость услуг за указанный период) в валюте расчетов;
  • Период обучения - период оказания образовательных услуг (месяц, семестр и т.п.), следует указать дату начала и окончания периода;
  • Примечание – произвольное примечание, например, "1 семестр", "2 семестр" и т.п.

Достаточно ввести порядок оплаты за оставшийся срок действия договора. Можно ввести порядок оплаты за весь срок действия договора.

График оплаты услуг на закладке Порядок оплаты может быть сохранен в качестве шаблона (элемента справочника Графики оплаты) по кнопке Сохранить и загружен из шаблона по кнопке Загрузить.

Расчет итоговых данных и заполнение показателей Не оплачено и Не исполнено за оставшийся срок действия долгосрочного договора на закладке Учащиеся выполняется по кнопке Рассчитать командной панели списка учащихся.

Закладка "В целом по плательщикам"

На закладке В целом по плательщикам с помощью кнопки Обновить командной панели табличной части можно сформировать для справки таблицу со сводными данными по плательщикам.

Таблица содержит колонки Контрагент, Договор, Задолженность и Переплата и формируется на основании данных таблицы на закладке Учащиеся.

Закладка "Бухгалтерская операция"

Типовая операция – выбирается из списка Типовые операции.

Ввод начальных остатков по учащимся (по долгосрочным договорам)

Группа реквизитов Доходы будущих периодов:

  • Счет – по умолчанию счет 401.40 "Доходы будущих периодов".
  • Номенклатура – наименование образовательной услуги. Выбирается из фрагмента справочника Номенклатура, ограниченного перечнем услуг.

При проведении документа по каждому учащемуся (каждой строке табличной части Учащиеся) формируются бухгалтерские записи:

  • Дт 0 205 ХХ 000 – Кт 0 000 00 000 – расчеты с дебиторами по доходам от реализации за оставшийся срок действия долгосрочного договора; 
  • Дт 0 000 00 000 – Кт 0 401 4Х 1ХХ – доходы будущих периодов за оставшийся срок действия долгосрочного договора;
  • Кт 0 АП 1ХХ – формируется при установленном флаге Отразить переплату на забалансовом счете расчетов по авансам полученным (АП) на сумму переплаты (колонка Переплата таблицы Учащиеся).

Ввод начальных остатков по учащимся (по краткосрочным договорам)

При проведении документа по каждому учащемуся (каждой строке табличной части Учащиеся) формируются бухгалтерские записи:

  • Дт 0 205 ХХ 000 – Кт 0 000 00 000 – на сумму задолженности по договору (колонка Задолженность таблицы Учащиеся); 
  • Дт 0 000 00 000 – Кт 0 205 ХХ 000 – на сумму переплаты по договору (колонка Переплата таблицы Учащиеся);
  • Кт 0 АП 1ХХ – формируется при установленном флаге Отразить переплату на забалансовом счете расчетов по авансам полученным (АП) на сумму переплаты (колонка Переплата таблицы Учащиеся).
