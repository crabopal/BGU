Проведение документа

Документ "Ввод начальных остатков материалов (а также счет 08)"

Документ Ввод начальных остатков материалов (а также счет 08) предназначен для ввода данных по остаткам материальных запасов как на балансовых, так и на забалансовых счетах, и автоматического формирования проводок в начале эксплуатации программы.

Также документом Ввод начальных остатков материалов (а также счет 08) с установленным режимом ввода Налоговый учет вводятся начальные остатки по расходам на приобретение материальных запасов на складе по счетам У10.Сх "Материалы к списанию …", У41.Сх "Товары к списанию …".

После заполнения и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833 (кнопка Печать).

Создание нового документа

Для ввода начальных остатков материальных запасов необходимо с помощью команды Помощник ввода начальных остатков меню функций раздела Администрирование открыть форму Помощник ввода начальных остатков.

Далее следует установить курсор на строку с номером счета учета материальных запасов на закладке Основные счета или Забалансовые счета, и нажать на кнопку командной панели Ввести остатки по счету.

Откроется форма документа Ввод начальных остатков материалов (а также счет 08).

Заполнение реквизитов шапки документа

Дата – дата ввода начальных остатков;

Примечание. При вводе начальных остатков в качестве значения реквизита Дата должна быть установлена дата, предшествующая дате начала учета.

Организация – наименование организации.

Группа счетов – балансовый счет (105) или забалансовый счет (02.2, 02.4, 07, 08, 09, 12, 13.2, 22.2, 23), по которому вводятся остатки. Выбирается из списка:

  • 105.00 Материальные запасы, счет;
  • 105.00 Материальные запасы, счет - группа (товары в рознице, наценка);
  • 02.2 МЗ на хранении;
  • 02.4 МЗ, не признанные активом;
  • 07 Награды, призы, кубки и ценные подарки, сувениры;
  • 08 Путевки неоплаченные;
  • 09 Запасные части к транспортным средствам, выданные взамен изношенных;
  • 12 Спецоборудование для выполнения научно-исследовательских работ по договорам с заказчиками;
  • 13.2 Экспериментальные устройства (МЗ);
  • 22.2 МЗ, полученные по централизованному снабжению;
  • 23 Периодические издания для пользования;
  • 25 Имущество, переданное в возмездное пользование (аренду);
  • 26 Имущество, переданное в безвозмездное пользование;
  • 27 Материальные ценности, выданные в личное пользование работникам (сотрудникам).

Примечание. Состав реквизитов табличной части зависит от значения реквизита Счет, указанного в шапке документа. Например, при выбранном значении 02.2 или 22.2, 25, 26, 27 в табличной части появится реквизит Контрагент. Данный реквизит используется для указания контрагента, который передал организации материальные запасы.

Реквизиты группы "Режим ввода остатков"

Реквизиты группы Режим ввода остатков в новом документе по умолчанию имеют следующие значения:

  • Бух. учет – значение Да;
  • Налоговый учет – значение Нет.

При наличии необходимости в изменении значений, заданных по умолчанию, следует с помощью щелчка мыши по гиперссылке Да или Нет вызвать диалог Режим ввода остатков.

Далее следует установить или снять в диалоге флаги Ввод остатков по бухгалтерскому учету и Ввод остатков по налоговому учету.

Видимость и, следовательно, доступность для редактирования колонок табличной части документа зависит от настройки, выполненной в диалоге Режим ввода остатков.

Например, при установленных значениях Да для реквизита Бух. учет и Нет для реквизита Налоговый учет, в табличной части будут доступны только колонки с данными по бухгалтерскому учету.

После установки для реквизита Налоговый учет значения Да в табличной части станут также доступны колонки с данными по налоговому учету.

В некоторых случаях, например, при изменении системы налогообложения, у организации появляется потребность во вводе остатков только по налоговому учету, поскольку в результате ведения бухгалтерского учета данные по бухгалтерскому учету уже находятся в информационной базе.

В этом случае в новом документе Ввод начальных остатков материалов (а также счет 08) в диалоге Режим ввода остатков следует снять флаг Ввод остатков по бухгалтерскому учету и установить флаг Ввод остатков по налоговому учету.

После подтверждения выполненной настройки и закрытия диалога с помощью кнопки ОК следует нажать на кнопку Заполнить по данным бух. учета командной панели табличной части.

В результате табличная часть документа для целей налогового учета будет заполнена на основании данных бухгалтерского учета.

Далее введенные данные по налоговому учету можно при необходимости откорректировать и привести таким образом в соответствие реальным данным налогового учета.

Заполнение реквизитов табличной части

Данные по начальным остаткам МЗ вводятся в табличную часть документа.

В общем случае в состав табличной части входят следующие реквизиты:

  • КФО - код вида финансового обеспечения, в рамках которого вводится остаток. Выбирается из списка;
  • Счет - полный счет учета МЗ;

Примечание. Если в реквизите Счет в шапке документа указан счет-группа 105, то значение реквизита Счет в табличной части будет выбираться из соответствующего фрагмента Плана счетов.
Если в реквизите Счет в шапке документа указан конкретный счет, то данный счет будет автоматически подставлен в реквизит Счет табличной части после добавления новой строки.
  • Номенклатура – соответствующая номенклатурная позиция. Выбирается из справочника Номенклатура;

Примечание. Если карточка номенклатуры отсутствует в справочнике Номенклатура, то ее необходимо создать с помощью, например, кнопки Создать командной панели формы списка. В новом элементе справочника следует в реквизите Наименование указать наименование номенклатуры, а в реквизите Ед. измерения выбрать единицу измерения. Реквизит Тип номенклатуры у нового элемента по умолчанию имеет значение Прочее МЗ. При необходимости это значение можно изменить. Сохранить сделанные изменения можно с помощью кнопки Записать и закрыть формы элемента. После этого новый элемент можно выбрать при заполнении документа.

Примечание. Остальные реквизиты элемента справочника Номенклатура можно заполнить позднее.
  • Ед. изм. – справочно выводится значение реквизита Ед. измерения из карточки номенклатуры;
  • МОЛ/Место хранения – центр материальной ответственности. Выбирается из справочника Центры материальной ответственности. Если карточка центра материальной ответственности отсутствует в справочнике Центры материальной ответственности, то ее необходимо создать.

Примечание. Если карточка центра материальной ответственности отсутствует в справочнике Центры материальной ответственности, то ее необходимо создать с помощью, например, кнопки Создать командной панели формы списка. Затем в новом элементе следует заполнить реквизиты Сотрудник и Места хранения выбором элементов из справочников Сотрудники и, соответственно, Места хранения. При отсутствии необходимых элементов в указанных справочниках их следует ввести.

При наличии в организации нескольких МОЛ с совпадающими фамилиями и инициалами рекомендуется при создании элемента справочника Сотрудники наряду с реквизитом Наименование, в который полностью вводятся фамилия, имя и отчество сотрудника, заполнить также реквизит ИНН. Значение ИНН позволяет однозначно идентифицировать сотрудника и избежать путаницы.

Примечание. Остальные реквизиты элемента справочника Сотрудники можно заполнить позднее, в процессе ведения учета.
  • Мест – количество приходуемых мест (упаковок, банок, пачек, мешков и т.д.);
  • Коэфф. – количество в учетной единице измерения в 1 месте. По умолчанию предлагается значение 1.000;
  • Количество в учетных единицах - рассчитывается автоматически как произведение значений двух предыдущих граф (Количество в учетных единицах = Количество мест Х Количество в 1 месте) или может быть указано вручную;
  • Сумма - балансовая стоимость указанного количества МЗ.

Заполнение реквизитов на закладке "Бухгалтерская операция"

Типовая операция – не выбирается, имеет по умолчанию значение Ввод начальных остатков материалов (а также счет 08).

Проведение документа

При проведении документа формируются следующие проводки:

  • при учете остатков МЗ на балансовых счетах – Дт 105.хх – Кт 000 "Вспомогательный счет" на сумму, равную значению реквизита Сумма;
  • при учете остатков МЗ на забалансовых счетах – Дт "Забалансовый счет".

При установленном флаге Ввод остатков по налоговому учету формируются бухгалтерские проводки:
Дт Н10 (Н41.01 или Н43, определяется автоматически исходя из счета учета номенклатуры) на сумму (НУ).
