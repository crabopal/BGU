Документ "Групповая корректировка долгосрочных договоров (образование)"

Документ Групповая корректировка долгосрочных договоров (образование) предназначен для групповой корректировки долгосрочных договоров об образовании, в том числе, при ежегодной индексации стоимости образования (увеличении стоимости образовательных услуг с учетом уровня инфляции, п.3 статьи 54 ФЗ "Об образовании" от 29.12.2012 № 273-ФЗ), в связи с переводом на онлайн- и дистанционное обучение с уменьшением стоимости по договору и в других случаях.

После заполнения реквизитов бухгалтерской операции и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида Групповая корректировка долгосрочных договоров (образование) можно открыть с помощью команды Групповая корректировка долгосрочных договоров (образование), размещенной в группе Образовательные услуги – Долгосрочные договоры меню функций раздела Платное обучение.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Групповая корректировка долгосрочных договоров (образование).

Заполнение реквизитов шапки документа

Факультет – наименование факультета. Выбирается из справочника Подразделения.

Номенклатура – наименование образовательной услуги. Выбирается из фрагмента справочника Номенклатура, ограниченного перечнем услуг.

Примечание. Группа реквизитов Увеличение (уменьшение) стоимости образовательных услуг используется для автоматического пересчета порядка (графика) оплаты по договору за незавершенные периоды обучения, либо за произвольный указанный период. С помощью опции Изменить суммы на процент (индексация) можно увеличить (уменьшить) стоимость обучения за указанные периоды на относительную величину (в процентах), с помощью опции Распределить сумму по периодам - на абсолютную величину (в валюте). Если дата начала (окончания) периода пересчета не совпадает с началом (окончанием) периода обучения (семестра, месяца и пр.), расчет производится пропорционально количеству календарных дней, вошедших в период пересчета.
Примеры:
1) При предоставлении скидки на обучение на следующий календарный год можно ввести сумму скидки (с минусом) в поле Распределить сумму по периодам, а в полях За периоды с/по указать период предоставления скидки.
2) При ежегодной индексации стоимости обучения в поле Изменить суммы на процент (индексация) следует ввести процент индексации, например, 5%, а в поле За периоды с указать дату начала периода индексации стоимости обучения, например, с 01.09.2021 (дату окончания указывать в данном случае необязательно, поскольку пересчет выполняется до конца срока действия договора).

Закладка "Доходы будущих периодов"

Для автоматического заполнения данными табличной части следует нажать на кнопку Заполнить и выбрать в меню команду Учащимися по отбору. Откроется форма Настройка параметров отбора учащихся, которая настроена по умолчанию на отбор учащихся по факультету, указанному в шапке документа, и которая может быть при необходимости дополнена отбором по другим реквизитам – Группа, Курс, Состояние учащегося и т.д. По окончании настройки отбора после нажатия на кнопку Выполнить отбор и заполнить документ табличная часть на закладке будет заполнена данными.

Табличная часть на закладке Доходы будущих периодов заполняется списком учащихся с учетом установленых отборов на основании данных оформленных приказов по контингенту учащихся (документы Приказ (образование) в разделе Платное обучение – Образовательные услуги) и остатков на счете учета предстоящих доходов по долгосрочным договорам с учащимися (401.40 "Доходы будущих периодов"):

  • Учащийся – заполняется из справочника Учащиеся.
  • Плательщик – заполняется из справочника Контрагенты.
  • Договор – заполняется из справочника Договоры и иные основания возникновения обязательств.
  • Остаток – заполняется остаток предстоящих доходов по договору с учащимся на счете учета 401.40 "Доходы будущих периодов".
  • Изменить (+ / -) – следует ввести суммы корректировки предстоящих доходов за оставшийся срок договора.
  • После изменения – автоматически рассчитываются суммы предстоящих доходов за оставшийся срок договора с учетом произведенных корректировок.
  • Счет учета – автоматически заполняется счет учета доходов будущих периодов (401.40), включая КФО, КПС и КЭК.
  • Расчеты – автоматически заполняется счет расчетов (205.ХХ) в зависимости от значения КЭК доходов. При необходимости, значения можно изменить.
  • Порядок оплаты – заполняется автоматически. Показывает, какой порядок оплаты ("Общий" или "Особый") применяется для учащегося (договора обучения) в рамках данного документа.

Закладка "Порядок учета доходов"

Закладка доступна при выборе в шапке документа вида операции Корректировка доходов будущих периодов и установке флажка Порядок учета доходов.
Закладка заполняется аналогично закладке Порядок учета доходов документа Начисление доходов будущих периодов (образование).

Закладки "Общий порядок оплаты" и "Особый порядок оплаты"

Табличные части Общий порядок оплаты и Особый порядок оплаты заполняются актуальными данными о порядке оплаты образовательных услуг по каждому учащемуся (договору обучения). В качестве общего (стандартного) порядка оплаты (закладка Общий порядок оплаты) выбирается наиболее часто используемый порядок оплаты среди всех учащихся (договоров обучения), попавших в выборку при заполнении документа. Порядок оплаты по остальным учащимся (договорам обучения) заполняется и редактируется на закладке Особый порядок оплаты.

Примечание. Общий (стандартный) порядок оплаты предназначен для удобства ввода и корректировки условий долгосрочных договоров для большинства учащихся, для которых действуют общие (стандартные, одинаковые) условия оплаты. Общий порядок оплаты применяется сразу для всех учащихся (договоров обучения) на закладке Доходы будущих периодов, за исключением отдельных учащихся (договоров обучения) с особым порядком оплаты. Особый порядок оплаты используется для отдельных учащихся с особыми условиями по стоимости обучения и его оплате, например, в случае предоставления скидок, льгот.

Первоначально строки табличной части заполняются автоматически актуальными данными по договору с учащимся. Строки, заполненные автоматически, не подлежат удалению или корректировке. Для того, чтобы изменить сумму оплаты по такой строке следует указать соответствующую сумму изменения с плюсом или минусом в колонке Сумма. Для добавления новых строк следует использовать кнопку Добавить командной панели, либо ввести новые строки копированием существующих.

Например, для переноса даты оплаты по договору с учащимся на месяц вперед, следует в строке с первоначальной датой оплаты (колонка Оплатить до) в колонке Сумма указать сумму корректировки с минусом. Затем следует добавить копированием новую строку, установить в ней новую дату оплаты и в колонке Сумма указать ту же сумму корректировки с плюсом. После произведенных корректировок, показатели в колонке После изменения будут пересчитаны автоматически.

  • Оплатить до – планируемая (крайняя) дата оплаты, после которой платеж будет считаться просроченным.
  • До изменения – первоначальная сумма.
  • Сумма – указывается сумма корректировки с плюсом или с минусом.
  • После изменения – автоматически рассчитывается сумма с учетом произведенных корректировок.
  • Валюта – валюта расчетов.
  • Период обучения – период оказания образовательных услуг (месяц, семестр и т.п.), следует указать дату начала и окончания периода.
  • Примечание – произвольное примечание, например, "1 семестр", "2 семестр" и т.п.

Итоговая сумма корректировки порядка оплаты (итог по колонке Сумма) должна соответствовать сумме корректировки доходов будущих периодов (колонка Изменить (+ / -) на закладке Доходы будущих периодов) по каждому учащемуся (договору обучения).

Закладка "Бухгалтерская операция"

Типовая операция – выбирается из списка Типовые операции.
При выборе типовой операции Корректировка доходов будущих периодов (205.00) при проведении документа формируются следующие бухгалтерские записи:

  • при корректировке в сторону увеличения: Дт 0 205 30 56Х - Кт 0 401 40 13Х – увеличение предстоящих доходов.
  • при корректировке в сторону уменьшения: Дт 0 401 40 13Х – Кт 0 205 30 66Х – уменьшение предстоящих доходов.
