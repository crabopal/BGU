Документ "Чеки ККМ для реестра покупателей"

В некоторых случаях в учреждении требуется массово распечатать группу кассовых чеков. Такая необходимость появляется:

  • при поступлении безналичных платежей по реестру;
  • при оформлении оплаты по реестру платежей при оплате электронными средствами платежа;
  • при передаче сотрудникам товаров, работ, услуг в кредит;
  • при оплате по реестру платежей в счет удержания из заработной платы сотрудников стоимости приобретенных у организации товаров, работ, услуг;
  • при зачете авансов, предоплат для группы контрагентов.

Работа со списком документов

Список документов вида Чеки ККМ для реестра платежей можно открыть с помощью команды Чеки ККМ для реестра платежей группы Управление ККТ в меню функций раздела Денежные средства.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Чеки ККМ для реестра платежей. Также Чеки ККМ для реестра платежей можно ввести на основании документа Кассовое поступление.

Заполнение реквизитов шапки документа

Вид операции – выбирается из списка:

  • поступление платежей по реестру;
  • удержание из заработной платы за приобретенные товары, работы, услуги;
  • зачет авансов и предоплат для группы контрагентов;
  • передача сотрудникам товаров, работ, услуг в кредит.

Состав реквизитов шапки документа для заполнения зависит от выбранного в шапке документа вида операции.

Документ-основание – документ вида Кассовое поступление. Выбирается из списка документов Кассовое поступление.
Касса ККМ – выбирается из справочника Кассы ККМ (фискальные регистраторы).
Система налогообложения – подставляется автоматически исходя из настроек Кассы ККМ и системы налогообложения, закрепленной в учетной политике организации.
Поступление родительской платы – при поступлении родительской платы следует установить флажок.
При увольнении по сведениям о реализации – флажок, следует установить в случае необходимости печати кассовых чеков на удержания для списка увольняемых сотрудников до момента поступления документа Отражение зарплаты в учете.
Направлять покупателю электронные чеки – флажок, следует установить для отправки покупателям электронных чеков.

Заполнение табличных частей на закладках

Видимость закладок документа для заполнения зависит от выбранного в шапке документа вида операции.

Для вида операции Поступление платежей по реестру для заполнения доступны закладки Платежи контрагентов и Расшифровка платежей контрагентов.

Для вида операции Удержание из заработной платы за приобретенные товары, работы, услуги для заполнения доступны закладки Сведения о реализации, Сведения об удержании из зарплаты и Удержания из заработной платы сотрудников. При установке в шапке документа флажка При увольнении по сведениям о реализации для заполнения становится доступна закладка Контрагенты-сотрудники и убирается закладка Сведения об удержании из зарплаты.

Для вида операции Зачет авансов и предоплат для группы контрагентов для заполнения доступны закладки Сведения о реализации и Расчеты с контрагентами.

Для вида операции Передача сотрудникам товаров, работ, услуг в кредит для заполнения доступны закладки Сведения о реализации и Передача контрагентам.

Дополнительные возможности

На основании документа Чеки ККМ для реестра платежей можно ввести документ Исправительный чек ККМ и группу документов Эквайринговая операция с типовой операцией Оплата ЭСП по реестру (205.00, 209.00) с помощью обработки, которая вызывается командой Эквайринговые операции для оплаты ЭСП.

Примечание. Документ Исправительный чек ККМ с видом операции Исправление чека ККМ позволяет сторнировать некорректный чек ККМ документа-основания и напечатать чек-сторно. Далее необходимо вернуться к документу-основанию, внести в него необходимые исправления, а затем провести и напечатать корректный чек.

Более подробно с особенностями работы с документом Чеки ККМ для реестра платежей можно ознакомиться в статье «1С:Бухгалтерия государственного учреждения 8, редакция 2. Формирование кассового чека при осуществлении денежных расчетов», опубликованной на ИТС (Бухгалтерия государственного учреждения, редакция 2 – Методика ведения учета – Интеграция с кассовым оборудованием).
