Документ "Внутреннее перемещение ОС, НМА, НПА (имущество казны)"

Документ Внутреннее перемещение ОС, НМА, НПА (Имущества казны) предназначен для оформления и учета операций по перемещению объектов ОС, НМА и НПА, включенных в состав имущества казны внутри учреждения.
Документ позволяет оформить следующие операции:

  • перемещение ОС, НМА, НПА, включенных в состав имущества казны от одного материально ответственного лица другому (если на счетах 108.00 ведется учет по ЦМО);
  • перемещение ОС, НМА, НПА, включенных в состав имущества казны от одного подразделения другому (если на счетах 108.00 ведется учет по подразделениям);
  • перемещение ОС, НМА, НПА, включенных в состав имущества казны с одного счета на другой. Например, передача имущества в концессию;
  • перемещение капитальных вложений имущества казны.

На основании заполненного и проведенного документа можно сформировать Накладную на внутреннее перемещение объектов нефинансовых активов (ф. 0510450) и бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов Внутреннее перемещение ОС, НМА, НПА (Имущества казны) можно открыть с помощью команды Внутренние перемещения ОС, НМА, НПА (Имущества казны) меню функций раздела Имущество казны.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Внутренние перемещения ОС,НМА, НПА (Имущества казны).

Заполнение реквизитов шапки документа

Реквизит Вид операции может принимать значения:

  • Перемещение ОС, НМА, НПА между ЦМО;
  • Перемещение ОС, НМА, НПА между счетами;
  • Перемещение капитальных вложений.

Общие реквизиты шапки документа для любого Вида операции:
В группе Основание необходимо заполнить реквизиты:

  • Вид документа – вид документа-основания. Выбирается из справочника Виды первичных документов.
  • Дата и Номер – дата и номер документа-основания.

Реквизиты шапки документа для вида операции Перемещение ОС, НМА, НПА между ЦМО:
В группе Отправитель необходимо заполнить реквизиты:

  • МОЛ/Место хранения – центр материальной ответственности отправителя. Выбирается из справочника Центры материальной ответственности.
  • Подразделение – подразделение отправителя. Выбирается из справочника Подразделения.

Реквизит Подразделение доступен для заполнения только при включенном учете по подразделениям на счете 108.00 в разделе Администрирование – Общие настройки – флажок Учет по подразделениям, гиперссылка Настроить учет по подразделениям для плана счетов.

Аналогичные реквизиты следует заполнить в группе Получатель.

Закладка "Основные средства"

Данные о перемещаемых основных средствах, нематериальных активах, непроизведенных активах, составляющих имущество казны вводятся в табличную часть.
Реквизиты табличной части для вида операции Перемещение ОС, НМА, НПА между ЦМО:

  • Основное средство – выбирается из справочника Основные средства, НМА, НПА. Для выбора объектов ОС, НМА, НПА, включенных в имущество казны удобно использовать форму подбора, которая открывается с помощью кнопки Подобрать командной панели табличной части.

Список формы подбора будет содержать объекты ОС, НМА, НПА у которых значение реквизита Вид НФА в карточке объекта позволяет применить к ним Вид операции, указанный в шапке документа.

После выбора объектов ОС, НМА, НПА, составляющих имущество казны с использованием формы подбора в строках табличной части будут заполнены реквизиты:

  • Гр. уч. – признак группового учета для выбранного объекта ОС. Для объектов ОС, по которым задано ведение группового учета, автоматически устанавливается флажок.
  • Счет учета – субсчет счета, на котором ведется учет объекта ОС, НМА, НПА, составляющего казну.
  • Инв. номер – инвентарный номер объекта ОС, НМА, НПА, составляющего казну.

Примечание. Реквизит Инв. номер в обязательном порядке используется при учете объектов ОС, НМА, НПА, составляющих казну стоимостью более 10 000 руб., за исключением объектов библиотечного фонда. Для объектов стоимостью до 10 000 руб. программа позволяет использовать инвентарные номера по желанию.
  • КФО – код вида финансового обеспечения.
  • КПС – классификационный признак счета.
  • Количество – количество объектов ОС, НМА, НПА, составляющих имущество казны. Для одиночных объектов ОС, НМА, НПА, составляющих имущество казны имеющих инвентарный номер, значение реквизита автоматически устанавливается равным 1. Реквизит доступен для заполнения для объектов ОС, составляющих имущество казны у которых не предусмотрены инвентарные номера.
  • Цена – балансовая стоимость объекта ОС, НМА, НПА, составляющих имущество казны.
  • Сумма – балансовая стоимость объектов ОС, НМА, НПА, составляющих имущество казны по строке.

Реквизиты Цена и Сумма недоступны для редактирования. Значения реквизитов рассчитываются автоматически с помощью кнопки Рассчитать командной панели табличной части.

Если на аналитических счетах счета 108.00 включено субконто Центры материальной ответственности и местонахождение объекта ОС, НМА, НПА, составляющих имущество казны не совпадает с местонахождением, указанным в реквизите МОЛ/Место хранения, то реквизиты Цена и Сумма для такого объекта заполнены не будут.

При изменении значений реквизитов шапки заполненного документа необходимо перезаполнить табличную часть, т. к. данные в ней могут не соответствовать новым значениям реквизитов шапки документа. При невыполнении данного требования попытка проведения документа может оказаться невозможна.

  • Примечание – дополнительная информация в виде текста. Вводится при необходимости.

Реквизиты табличной части для вида операции Перемещение ОС, НМА, НПА между счетами:

  • Основное средство – выбирается из справочника Основные средства, НМА, НПА. Для выбора объектов ОС, НМА, НПА, включенных в имущество казны удобно использовать форму подбора, которая открывается с помощью кнопки Подобрать командной панели табличной части.

Список формы подбора будет содержать объекты ОС, НМА, НПА у которых значение реквизита Вид НФА в карточке объекта позволяет применить к ним Вид операции, указанный в шапке документа.

После выбора объектов ОС, НМА, НПА, составляющих имущество казны с использованием формы подбора в строках табличной части будут заполнены реквизиты:

  • Счет учета (текущий) – субсчет счета, на котором на текущую дату ведется учет объекта ОС, НМА, НПА, составляющего казну.
  • Счет учета (новый) – следует вручную перевыбрать субсчет счета, на который необходимо переместить объект ОС, НМА, НПА, составляющего казну.

Закладка "Бухгалтерская операция"

Значение реквизита Типовая операция зависит от вида операции, указанного в шапке документа.

Если реквизит Вид операции имеет значение Перемещение ОС, НМА, НПА между ЦМО, то типовая операция имеет значение Внутреннее перемещение.

Если Вид операции имеет значение Перемещение ОС, НМА, НПА между счетами, то используется типовая операция Внутреннее перемещение между счетами (концессия 108.9Х - 108.5Х).

Если Вид операции имеет значение Перемещение капитальных вложений, то используется типовая операция Внутреннее перемещение капитальных вложений.

Заполнение дополнительных реквизитов для типовых операций не требуется.

Дополнительные возможности

На основании документа Внутреннее перемещение ОС, НМА, НПА (Имущества казны) можно ввести документ Сторно.
