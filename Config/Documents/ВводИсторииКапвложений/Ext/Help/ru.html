Документ "Ввод истории капвложений"

Документ Ввод истории капвложений предназначен для формирования и сохранения истории операций карточек капвложений в специальном регистре накопления "История капвложений".

Документ используется в трех случаях:

1. Формирование карточек капвложений первого применения при начале использования функционала карточек капвложений и сохранения данных остатков на счетах 106.хх.
2. Сохранения истории операций карточек капвложений перед сверткой базы, в случае ее проведения.
3. Ввод истории карточек капвложений вручную.

Работа со списком документов

Список документов вида Ввод истории капвложений можно открыть с помощью команды Истории карточек капвложений меню функций раздела ОС, НМА, НПА.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Истории карточек капвложений.

Формирование карточек первого применения

Согласно п.87 Методических указаний по формированию Карточки учета капитальных вложений (ф. 0509211 (Приложение №5 к приказу Минфина России от 15.04.2021 г. № 61н) при первом применении карточек капвложений по состоянию на 01.01.2023, карточки формируются по остаткам на счетах капитальных вложений.

Для формирования карточек первого применения следует выбрать вид операции Ввод карточек капвложений по остаткам (первое применение).

В форме документа, при этом, будут видны две таблицы:

  • таблица Объекты вложений, содержащая объекты, по которым есть остатки капвложений на счетах 106.хх.
  • таблица История операций, содержащая остатки на счетах 106.хх по соответствующему объекту.

Порядок заполнения

Для формирования карточек первого применения по остаткам на 01.01.2023 в документе следует указать дату 31.12.2022 г.

1. По кнопке Заполнить по остаткам документ будет заполнен остатками на счетах 106.хх по данным бухгалтерского учета на конец дня даты, указанной в документе.

После заполнения документа по кнопке Заполнить по остаткам:

  • колонка Карточка капвложений таблицы История капвложений будет пуста у тех объектов, у которых в справочнике Карточки капвложений еще нет карточки капвложений первого применения. Для объектов, у которых такая карточка уже есть, будет подставлена она, т.к. у объекта не может быть больше одной карточки капвложений первого применения.
  • колонка Дата в таблице Объекты вложений будет пуста. В эту колонку можно ввести дату начала формирования капвложений в объект, если она известна.

2. Затем следует нажать на кнопку Сформировать/заполнить карточки капвложений первого применения.

При этом будут сформированы карточки первого применения, для объектов, у которых их еще нет.

Если заполнена дата в колонке Дата таблицы Объекты вложений, то в карточке первого применения (созданы элементы справочника Карточки капвложений), для объектов, у которых их еще нет.

Если заполнена дата в колонке Дата таблицы Объекты вложений, то в карточке первого применения соответствующего объекта будет заполнен реквизит Дата начала вложений.

Примечание. Чтобы дата начала вложений была заполнена в карточке капвложений первого применения автоматически, дата в колонке Дата таблицы Объекты вложений должна быть заполнена до нажатия на кнопку Сформировать/заполнить карточки капвложений первого применения.
Если забыли ввести дату и нажали на кнопку, то дату можно ввести и после. Но после ввода даты следует снова нажать на кнопку Сформировать/заполнить карточки капвложений первого применения. При этом новые карточки созданы не будут, а в уже существующих будут заполнены даты начала вложений.

3. Провести документ.

Сохранения истории операций карточек капвложений перед сверткой базы

Порядок заполнения

Для сохранения истории карточек капвложений используется вид операции Ввод истории карточек капвложений.

Внимание! Вводить вручную документ при свертке базы не нужно, т.к. обработка свертки введет его автоматически.

В форме документа, при этом, будут видны три таблицы:

  • таблица Объекты вложений, содержащая объекты капитальных вложений.
  • таблица Карточки объекта, содержащая карточки объектов вложений (у одного объекта может быть несколько карточек). В таблице видны карточки текущего объекта в таблице Объекты вложений.
  • таблица История операций карточки, содержащая операции карточки по счетам 106.хх. В таблице видны операции текущей карточки в таблице Карточки объекта.

Ввод истории карточек капвложений вручную

Порядок заполнения

Для ввода истории карточек капвложений вручную следует выбрать вид операции Ввод истории карточек капвложений.

В этом случае, таблицы документа следует заполнять вручную в последовательности:

1. Сначала вводится объект вложений в таблицу Объекты вложений;
2. Затем для объекта вводятся карточки в таблицу Карточки объекта;
3. Затем для каждой карточки заполняется история операций в таблице История операций карточки.
