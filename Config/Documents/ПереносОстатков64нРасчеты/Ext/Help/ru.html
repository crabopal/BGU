Документ «Переход на применение приказа 64н (Расчеты)»

Документ предназначен для переноса остатков на начало 2018 года и оборотов по счетам расчетов с 01.01.2018 г. по дату перехода на применение приказа 64н от 31.03.2018 г.

Документ содержит три операции:

  • Перенос остатков. Предназначена для переноса остатков по счетам расчетов на начало 2018 г. Дату переноса остатков при этой операции, следует устанавливать 31.12.2017 г.
  • Перенос оборотов. Предназначена для переноса оборотов по счетам расчетов за период с 01.01.2018 по дату начала применения приказа 64н.

    Примечание
    При этой операции не будут отработаны обороты Дт 205.21, Кт 401.10.120. эти обороты отрабатываются следующей операцией.
  • Сторнирование начислений арендодателя (Дт 205.21, Кт 401.10.120). Предназначена для сторнирования оборотов Дт 205.21, Кт 401.10.120 за период с 01.01.2018 по дату начала применения приказа 64н.

    Примечание
    Проводки арендодателя по начислению за аренду только сторнируются, т.к. предполагается, что аренда со стороны арендодателя будет оформлена в соответствии с федеральным стандартом «Аренда» с начала года.
    Т.е. с начала года следует оформить документ «Начисление доходов будущих периодов» с каждым арендатором на всю оставшуюся на начало 2018 года сумму арендного договора.
    Документ сформирует проводку Д-т 205.21, К-т 401.40.121 на всю сумму договора.
    Далее, на дату начала применения приказа 64н ввести по каждому арендатору операцию на сумму сторнированных документом оборотов Д-т 401.40.121, К-т 401.10.121.

Под переносом оборотов понимается:

Сторнирование оборотов по старым счетам со старыми КЭК и формирование оборотов по новым счетам и новым КЭК.

Например:

Была операция

Д-т 205.31, К-т 401.10.130 – в этой операции устарел КЭК 130, и он будет заменен на КЭК 131. Счет, в данном случае не изменяется.

Документ сформирует следующие проводки:

- Д-т 205.31, К-т 401.10.130  СТОРНО старой операции.

- Д-т 205.31, К-т 401.10.131  новая операция с новым КЭК.

Все корректирующие проводки будут сформированы на дату документа «Переход на применение приказа 64н (Расчеты)».

Правила переноса остатков и оборотов

Правила переноса остатков и оборотов приведены в таблице на форме документа.

Таблица содержит колонки со следующим смыслом:

Для операции «Перенос остатков»

Колонка со Счета содержит счет-источник с которого будут переноситься остатки на счет, указанный в колонке на Счет. Если счет-приемник (колонка на Счет) содержит тот же счет, то остатки переноситься не будут.

Если в колонке по КФО указан конкретный КФО, то указанный в строке перенос будет выполнен только в рамках этого КФО.

Другие колонки для данной операции не используются.

Для операции «Перенос оборотов»

Колонка со Счета содержит счет-источник, корреспонденция которого будет переноситься. Т.е. будут переноситься корреспонденции, с указанным счетом. При этом счет-источник (со Счета) будет заменяться на счет-приемник (на Счет), если он меняется, а КЭК-источник (с КЭК) корреспондирующего счета будет заменяться на КЭК-приемник (на КЭК).

Если в колонке по КФО указан конкретный КФО, то перенос оборотов по текущему правилу будет выполнен только в рамках этого КФО.

Перенос документом оборотов выполняется за период, указанный в реквизитах Перенос оборотов за период с… по…. Наличие этих реквизитов дает возможность выполнять перенос по частям. Каждую часть переносить за короткий промежуток времени, например, за один день. Это может быть востребовано при большом объеме базы, когда единовременный перенос за весь период с 01.01.2018 по дату перехода на применение 64н, может оказаться очень длительным.

По кнопке Настроить открывается форма редактирования макета с настройками. Настройка применяется для всех документов "Переход на применение приказа 64н (Расчеты)". Если есть проведеные документы, то после изменения настроек их необходимо перепровести. При изменении настроек так же необходимо внести соответствующие изменения в настройки документа Переход на применение приказа 64н (КЭК).
