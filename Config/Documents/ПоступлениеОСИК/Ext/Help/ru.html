Документ "Поступление ОС, НМА, НПА (имущество казны)"

Документ Поступление ОС, НМА, НПА (имущество казны) используется для оформления поступления НФА, включенных в состав имущества казны, в т. ч. оборудования, от сторонних организаций.

Документ позволяет оформить следующие операции:

  • безвозмездное поступление ОС, НМА, НПА (внутриведомственное);
  • безвозмездное поступление ОС, НМА, НПА прочее (401.10);
  • поступление вложений в НФА при реорганизации (304.06);
  • поступление ОС, НМА от подотчетных лиц;
  • поступление ОС, НМА, НПА по договорам купли-продажи, договорам поставки, другим аналогичным договорам.

При оформлении поступления оборудования после заполнения и записи документа можно сформировать печатную форму Приходный ордер на приемку материальных ценностей (нефинансовых активов) (форма по ОКУД 0504207) и бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида Поступление ОС, НМА, НПА (имущество казны) можно открыть с помощью команды Поступление ОС, НМА, НПА (имущество казны) меню функций раздела Имущество казны.

Создание нового документа

Для ввода нового документа следует нажать кнопку Создать командной панели списка Поступление ОС, НМА, НПА (имущество казны).

Заполнение реквизитов документа

Заполнение реквизитов документа Поступление ОС, НМА, НПА (имущество казны) выполняется аналогично заполнению реквизитов документа Поступление ОС, НМА, НПА.

Дополнительные возможности

На основании документа Поступление ОС, НМА, НПА (имущество казны) можно ввести документы Счет-фактура полученный и Сторно.
