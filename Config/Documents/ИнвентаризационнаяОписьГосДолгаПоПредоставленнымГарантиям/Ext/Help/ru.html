Документ "Инвентаризационная опись состояния государственного (муниципального) долга по предоставленным гарантиям (ф. 0510474)"

Документ Инвентаризационная опись состояния государственного (муниципального) долга по предоставленным гарантиям (ф. 0510474) применяется для отражения результатов проведения инвентаризации состояния государственного (муниципального) долга по предоставленным гарантиям.

Документ поддерживает инвентаризацию на следующих счетах учета:

  • 301.31 "Расчеты с бюджетами бюджетной системы Российской Федерации по государственным (муниципальным) гарантиям";
  • 301.33 "Расчеты с иными кредиторами по государственному (муниципальному) долгу по государственным (муниципальным) гарантиям".

Документ Инвентаризационная опись состояния государственного (муниципального) долга по предоставленным гарантиям (ф. 0510474) формируется ответственным исполнителем бухгалтерской службы на основании документа Решение о проведении инвентаризации (ф. 0510439) по месту проведения инвентаризации, а также по виду задолженности: "внутренний долг"; "внешний долг", указанному в шапке документа Инвентаризационная опись состояния государственного (муниципального) долга по предоставленным гарантиям (ф. 0510474).

После заполнения и записи документа можно сформировать печатную форму Инвентаризационной описи состояния государственного (муниципального) долга по предоставленным гарантиям (ф. 0510474).

Заполнение реквизитов шапки и подвала документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Подразделение – подразделение выбирается из справочника Подразделения. Реквизит доступен, если включена настройка Учет по подразделениям (Раздел Главное - Настройки параметров учета - Общие настройки). Если реквизит заполнен и на счете учета долговых обязательств включен учет по подразделениям, Раздел 1 будет заполнен остатками в выбранном подразделении. Если реквизит не заполнен, Раздел 1 будет заполнен без отбора по Подразделению.

ИФО – выбирается из справочника Источники финансового обеспечения. Реквизит доступен для выбора, если включена настройка Учет по ИФО (Раздел Главное - Настройки параметров учета - Общие настройки). Ели реквизит не заполнен, Раздел 1 будет заполнен без отбора по ИФО.

Для начала работы с документом необходимо предварительно в шапке документа указать Вид задолженности путем выбора предопределенных значений: "внутренний долг" или "внешний долг". Для отбора остатков в рублях используется значение "внутренний долг", для отбора остатков в иностранной валюте используется значение "внешний долг".

Также в шапке следует указать Решение о проведении инвентаризации (ф. 0510439), в открывшемся окне Выбор данных из Решения с учетом изменений необходимо отметить строки, по которым следует заполнить документ описи и нажать на кнопку Выбрать строки. После этого будет автоматически заполнена закладка Комиссия составом инвентаризационной комиссии, а также реквизиты в шапке документа Инвентаризационная опись состояния государственного (муниципального) долга по предоставленным гарантиям (ф. 0510474), в группе реквизитов Сведения об инвентаризации из Решения:

  • По состоянию на – дата, по состоянию на которую проводится инвентаризация, в формате "ДД.ММ.ГГГГ";
  • Номер комиссии – номер инвентаризационной комиссии/рабочей комиссии в составе инвентаризационной;
  • Список счетов – список счетов, отобранных из документа Решение о проведении инвентаризации (ф. 0510439);
  • Период проведения с/по – даты начала и окончания инвентаризации в формате "ДД.ММ.ГГГГ";
  • Место проведения – адрес или место проведения инвентаризации.

Примечание. Редактирование вышеперечисленных реквизитов в документе описи не предусмотрено, так как они зафиксированы документом Решении о проведении инвентаризации (ф. 0510439), выбранном в шапке документа.

Ответственное лицо – ответственное лицо, осуществляющее взаимодействие с бухгалтерской службой в части передачи документов, необходимых для отражения в бухгалтерском учете состояния государственного (муниципального) долга по предоставленным гарантиям, которым формируется и подписывается простой ЭП расписка, являющаяся неотъемлемым приложением к Инвентаризационной описи состояния государственного (муниципального) долга по предоставленным гарантиям (ф. 0510474).

В подвале документа Инвентаризационная опись состояния государственного (муниципального) долга по предоставленным гарантиям (ф. 0510474) в соответствующих реквизитах следует заполнить ответственного исполнителя бухгалтерской службы и ответственного исполнителя инвентаризационной комиссии.

До начала проведения инвентаризации ответственным лицом, осуществляющим взаимодействие с бухгалтерской службой в части передачи документов, необходимых для отражения в бухгалтерском учете состояния государственного (муниципального) долга по предоставленным гарантиям, формируется и подписывается простой ЭП расписка, являющаяся неотъемлемым приложением к Инвентаризационной описи состояния государственного (муниципального) долга по предоставленным гарантиям (ф. 0510474), что к началу проведения инвентаризации все документы по обязательствам государственного (муниципального) долга по предоставленным гарантиям переданы в бухгалтерскую службу для отражения в бухгалтерском учете.

Документ Расписка инвентаризации формируется нажатием на гиперссылку:

  • Создать расписку, если документ Инвентаризационная опись состояния государственного (муниципального) долга по предоставленным гарантиям (ф. 0510474) предварительно записан;
  • Создать расписку (документ будет записан), если документ не записан, при этом перед открытием окна представления формы документа Расписка инвентаризации документ будет записан автоматически.

При нажатии на гиперссылку откроется окно созданного документа Расписка инвентаризации, который следует сохранить и провести.

Заполнение расписки ответственным лицом, осуществляющим взаимодействие с бухгалтерской службой в части передачи документов, необходимых для отражения в бухгалтерском учете состояния государственного (муниципального) долга по предоставленным гарантиям является обязательным условием для продолжения заполнения описи, поэтому только после проведения документа Расписка инвентаризации становится возможным заполнение закладок Раздел 1, Раздел 2 и Раздел 3 документа Инвентаризационная опись состояния государственного (муниципального) долга по предоставленным гарантиям (ф. 0510474).

Заполнение закладки "Раздел 1"

Раздел 1 "Сведения о состоянии государственного (муниципального) долга по предоставленным гарантиям по данным бухгалтерского учета" заполняется ответственным исполнителем бухгалтерской службы на закладке Раздел 1 по кнопке Заполнить по данным учета. Документ описи будет заполнен остатками по счетам 301.31, 301.33 с учетом отбора, указанного на закладке Отбор из решения. Остатки определяются на конец предыдущего дня от даты, по состоянию на которую проводится инвентаризация, указанной в шапке документа в реквизите По состоянию на.

Например, если инвентаризация проводится перед составлением годовой отчетности за 2025 финансовый год, то реквизит По состоянию на будет заполнен датой 01.01.2026, а остатки по счетам 301.00 будут взяты на конец дня 31.12.2025.

В результате автозаполнения в табличной части закладки Раздел 1 будут заполнены реквизиты:

  • N – порядковый номер строки;
  • Код подраздела – код подраздела соответствующей группы кредиторов;
  • Группа держателей гарантии – элемент справочника Контрагенты вида "Учетная группа". заполняется, если аналитический учет на счете 301.ХХ ведется по группам держателей гарантий (в карточке Контрагента указан Вид контрагента "Учетная группа");
  • Код строки – порядковый номер строки текущего подраздела по группе кредиторов. Используется для вывода в печатной форме;
  • Договор – служебное поле, заполняемое соответствующим элементом справочника Договоры и иные основания возникновения обязательств, в разрезе которого существует остаток задолженности. Не заполняется, если заполнена Группа держателей гарантии;
  • Государственная (муниципальная) гарантия (Номер, Дата) – соответствующие значения реквизитов №, От элемента справочника Договоры и иные основания возникновения обязательств. Не заполняется, если заполнена Группа держателей гарантии;
  • Срок действия – срок действия гарантии. При автоматическом заполнении Срок действия заполняется в зависимости от выбранной настройки Для классификации дебиторской и кредиторской задолженности в упрощенном режиме используется дата исполнения: (Настройка параметров учета – Ведение учета). Соответственно значением Окончание на закладке Свойства или значением Срок исполнения (погашения). Не заполняется, если заполнена Группа держателей гарантии;
  • Бенефициар – элемент справочника Контрагенты. Заполняется значением субконто Контрагенты остатков по счету 301.ХХ. Не заполняется, если заполнена Группа держателей гарантии;
  • Принципал – элемент справочника Контрагенты. Заполняется значением реквизита Контрагент элемента справочника Договоры и иные основания возникновения обязательств, по которому отражены остатки на счете 301.ХХ. Не заполняется, если заполнена Группа держателей гарантии;
  • КФО, Счет, КПС – заполняется по остаткам на счете 301.ХХ;
  • Код срока гарантии – заполняется соответствующим значением кода срока гарантии. При автоматическом заполнении срок гарантии определяется по значению указанному в реквизите Срок действия и началу действия договора. Начало действия договора задается в реквизите Срок действия с карточки договора (при оформлении документа Регистрация обязательств и сведений по договорам). Если Срок действия с в карточке договора не заполнен, датой начала действия договора считается дата договора указанная в реквизите от:. Не заполняется, если заполнена Группа держателей гарантии;
  • Валюта – элемент справочника Валюты. Валюта остатка на счете 301.ХХ;
  • Сумма задолженности, вал. – при автоматическом заполнении определяется по остаткам на счете 301.ХХ со значением субконто "Виды расчетов по займам (кредитам)" равным значению "Основной долг" и "Проценты";
  • Сумма задолженности, руб. – при автоматическом заполнении определяется по остаткам на счете 301.ХХ со значением субконто "Виды расчетов по займам (кредитам)" равным значению "Основной долг" и "Проценты".

Ручное редактирование табличной части раздела 1 не предусмотрено.

Команда Расшифровать открывает отчет Анализ задолженности с отбором, соответствующим реквизитам текущей строки раздела 1.

Раздел 1 подписывается ответственным исполнителем бухгалтерской службы простой ЭП.

Заполнение закладки "Раздел 2"

Раздел 2 "Сведения о состоянии государственного долга по предоставленным гарантиям по данным инвентаризационной комиссии" заполняется ответственным исполнителем инвентаризационной комиссии. На закладке Раздел 2 по кнопке Заполнить (Заполнить по данным раздела 1 (без сумм)/(включая суммы)) таблица может быть заполнена автоматически по данным Раздела 1.

В результате автозаполнения командой Заполнить по данным раздела 1 (без сумм) в табличной части закладки Раздел 2 по данным соответствующих одноименных реквизитов табличной части закладки Раздел 1 будут заполнены реквизиты: Код подраздела, Группа держателей гарантии, Код строки, Договор, Государственная (муниципальная) гарантия (Номер, Дата), Срок действия, Бенефициар, Принципал, КФО, Счет, КПС, Код срока гарантии, Валюта.

При выборе команды Заполнить по данным раздела 1 (включая суммы) в табличной части закладки Раздел 2 по данным соответствующих одноименных реквизитов табличной части закладки Раздел 1 будут заполнены реквизиты: Код подраздела, Группа держателей гарантии, Код строки, Договор, Государственная (муниципальная) гарантия (Номер, Дата), Срок действия, Бенефициар, Принципал, КФО, Счет, КПС, Код срока гарантии, Валюта, Сумма задолженности, вал., Сумма задолженности, руб..

При инвентаризации обязательств в разрезе держателей гарантии (в текущей строке реквизит Группа держателей гарантии не заполнен), реквизиты Код подраздела, Группа держателей гарантии, Код строки, Договор, Государственная (муниципальная) гарантия (Номер, Дата), Срок действия, Бенефициар, Принципал, КФО, Счет, КПС, Код срока гарантии, Валюта заполненные по данным Раздела 1 корректировке не подлежат.

Предусмотрено ручное заполнение суммовых показателей табличной части Раздела 2:

  • Сумма задолженности, вал. – сумма задолженности в валюте. Доступен для редактирования, если выбран вид задолженности "внешний долг".
  • Сумма задолженнотси, руб. – сумма задолженности в рублях (рублевом эквиваленте).

При инвентаризации долговых обязательств по группам держателей гарантий (заполнен реквизит Группа держателей гарантии в строке табличной части), все данные раздела 2 по соответствтующей группе держателей гарантии заполняются вручную. Новые строки табличной части добавляются командой Добавить или Скопировать. Удалить строку можно командой Удалить или клавишей Del.

Код строки нумеруется автоматически по соответствующей группе держателей гарантии.

Если по данным бухгалтерского учета сформировалось несколько разделов по разным группам держателей гарантий, при добавлении строки в Раздел 2 будет предложено выбрать соответствующую группу держателей гарантии.

При инвентаризации долговых обязательств в разрезе держателей гарантии, добавление строк в Раздел 2 не предусмотрено.

Команда Расшифровать открывает отчет Анализ задолженности с отбором, соответствующим реквизитам текущей строки Раздела 2.

Заполнение закладки "Раздел 3"

Раздел 3 "Заключение инвентаризационной комиссии" заполняется ответственным исполнителем инвентаризационной комиссии на закладке Раздел 3 по кнопке Заполнить по данным разделов 1 и 2.

В результате автозаполнения в табличной части закладки Раздел 3 будут заполнены реквизиты: N, Код подраздела, Группа держателей гарантии, Код строки, Договор, Государственная (муниципальная) гарантия (Номер, Дата), Срок действия, Бенефициар, Принципал, КФО, Счет, КПС, Код срока гарантии, Валюта, Отклонение, вал., Отклонение, руб..

Если по итогам инвентаризации есть отклонения, то заключение комиссии можно написать произвольным текстом в реквизите Заключение комиссии, либо выбрать из справочника Заключения комиссии по инвентаризационным описям.

В случае если по итогам инвентаризации отклонения не установлены, то заключение инвентаризационной комиссии будет заполнено значением "Отклонения не выявлены, данные инвентаризационной комиссии соответствуют учетным данным", а в остальных графах проставлены нули.

Закладка "Комиссия"

Состав комиссии определен в документе Решение о проведении инвентаризации и изменению не подлежит. Заполняется автоматически при выборе Решения о проведении инвентаризации в соответствующем реквизите.
