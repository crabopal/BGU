Документ "Уведомление об исчисленных суммах налога"

Документ Уведомление об исчисленных суммах налогов предназначен для подготовки и отправки в ФНС уведомления по форме КНД 1110355 (Приказ ФНС России от 02.11.2022 № ЕД-7-8/1047@).

Документ Уведомление об исчисленных суммах налогов можно ввести на основании документов:

  • Начисление имущественных налогов;
  • Отражение зарплаты в учете;
  • Сведения об удержанном НДФЛ.

При вводе на основании документ Уведомление об исчисленных суммах налогов заполняется автоматически. При заполнении на основании документа Отражение зарплаты в учете уведомление заполняется только в части страховых взносов.

После проведения документа можно сформировать печатную форму уведомления Форма по КНД 1110355, а так же машиночитаемый бланк со штрихкодом PDF417.

Группа команд Проверка содержит команды Проверить контрольные соотношения, Проверить выгрузку, Проверить в интернете.

Команда Отправить предназначена для отправки отчета в контролирующий орган (если подключен сервис 1С-Отчетность). Команда Выгрузить формирует файл выгрузки для отправки в ФНС через стороннее ПО.

Внимание! Не допускается дублирование строк в документе по совокупности значений КПП, Код по ОКТМО, КБК, Отчетный период.

Работа со списком документов

Список документов вида Уведомление об исчисленных суммах налогов можно открыть с помощью команды Уведомление меню функций раздела Налоги в группе Единый налоговый счет.

Так же список Уведомлений отображается в едином рабочем месте окна 1С-Отчетности на закладке Уведомления.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Уведомления об исчисленных суммах налогов.

Из единого рабочего места 1С-Отчетности команда Создать на закладке Уведомления. При создании из единого рабочего места 1С-Отчетности, после нажатия кнопки Создать и выборе вида уведомления Уведомление об исчисленных суммах налогов, открывается вспомогательное окно Выбор редакции формы. Команда Создать открывает форму документа, с возможностью автоматического заполнения. Команда Форма ручного заполнения открывает форму регламентированного отчета для ручного заполнения.

Так же новый документ можно ввести на основании следующих документов: Начисление имущественных налогов, Отражение зарплаты в учете, Сведения об удержанном НДФЛ.

Работа с документом

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Реквизиты табличной части:

Налог – группа реквизитов Вид налога, платежа, Налоги и платежи организации.

Вид налога, платежа – выбирается из справочника Виды налогов и платежей. При выборе значения автоматически заполняется значение КБК налога.

Налоги и платежи организации – выбирается из справочника Налоги и платежи организаций. При выборе значения автоматически заполняется значение Код по ОКТМО.

КПП – КПП, указанный в соответствующей налоговой декларации (расчете). Можно заполнить вручную или выбором из справочника Регистрации в налоговом органе. При добавлении новой строки заполняется значением КПП Организации.

КБК – код бюджетной классификации.

Отчетный период – отчетный (налоговый) период.

Сумма – сумма налога, авансовых платежей по налогу, сбора, страховых взносов, подлежащая уплате (перечислению).

Для заполнения табличной части можно воспользоваться командой Подбор.

Команда Подбор открывает форму подбора начислений по документам Начисление имущественных налогов, Отражение зарплаты в учете, Сведения об удержанном НДФЛ.

По команде Перенести в документ подобранные начисления добавляются в табличную часть документа. Если в документе уже есть начисления с такими же значениями КПП, Код по ОКТМО, КБК, Отчетный период, подобранные начисления заменят значения в документе.
