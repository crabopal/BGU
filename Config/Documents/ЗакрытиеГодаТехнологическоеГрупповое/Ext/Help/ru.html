Проведение документа

Документ "Формирование остатков по КОСГУ 000"

В программе учет в разрезе кодов классификации операций сектора государственного управления (КЭК) ведется по каждому счету с помощью аналитических счетов.

В соответствии с инструкцией по бухгалтерскому учету субсчета по кодам классификации операций сектора государственного управления, предназначенные для отражения увеличения (уменьшения), поступления (выбытия), фактически являются накопительными регистрами в пределах года, на начало года остатков по ним не должно быть.

Документ Формирование остатков по КОСГУ 000 предназначен для закрытия остатков по всем счетам рабочего плана счетов учреждения (рабочим счетам), кроме счетов 109.00, 210.02, 210.04, 304.04, 304.05, 304.06, 304.84, 304.94, 304.86, 304.96, 401.00, 402.10, 501.00, 502.00, 503.00, 504.00, 506.00, 507.00, 508.00, 205.00, 206.00, 208.00, 209.00, 210.03, 210.05, 210.06, 210.10, 302.00, 303.00, 304.02, 304.03.

Документ Формирование остатков по КОСГУ 000 вводится в последний день года.

После заполнения реквизитов и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Документы вида Формирование остатков по КОСГУ 000 находятся в журнале Документы закрытия года. Журнал Документы закрытия года можно открыть с помощью команды Документы закрытия года меню функций раздела Учет и отчетность.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели журнала Документы закрытия года и выбрать в списке тип документа Формирование остатков по КОСГУ 000.

Заполнение реквизитов документа

Дата документа заполняется автоматически значением рабочей (текущей) даты. Для закрытия года следует указать – последний день финансового года (31 декабря);
Организация – учреждение, для которого производится закрытие счетов. Выбирается из справочника Организации.
Финансовый год – окончившийся финансовый год.

Типовая операция – имеет значение Закрытие оборотных КЭК по счетам.

Проведение документа

При проведении документа бухгалтерские записи по завершению счетов формируются в корреспонденции со служебным счетом "Вспомогательный" 000.

В результате проведения сворачиваются остатки по рабочим счетам по КЭК (например, 310 и 410, 330 и 430 и т.д.) и формируются остатки по КЭК 000.

Для каждой сформированной проводки устанавливается тип межотчетного периода Технологические операции.
