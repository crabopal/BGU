Документ "Распределение оплаты (образование)"

Документ Распределение оплаты (образование) предназначен для отражения в регистре накопления Расчеты с учащимися информации о плате, полученной организацией за образовательные услуги по каждому учащемуся.

При поступлении от плательщика оплаты одной суммой за несколько учащихся документ позволяет равномерно распределить по ним данную сумму.

Примечание. Данные регистра Расчеты с учащимися используется при формировании отчета Ведомость по расчетам за образование.

Работа со списком документов

Список документов Распределение оплаты (образование) можно открыть с помощью команды Распределение оплаты (образование) в форме Все функции, которая вызывается из Главного меню программы.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Распределение оплаты (образование).

Закладка "Распределение"

Для заполнения табличной части на закладке Распределение следует нажать на кнопку Заполнить оплатами. В процессе заполнения будет проанализирована информация о суммах поступления /возврата денежных средств по договорам на оказание образовательных услуг, а также будет выполнено распределение сумм по учащимся.

В случае если у одного Контрагента имеется один договор на оказание образовательных услуг нескольким Учащимся, то распределение автоматически производится по актуальному списку данных учащихся.

Просмотр реквизитов документов

Для просмотра реквизитов первичного документа и документа по оплате следует использовать кнопку Показать данные оплаты. В результате в табличной части станут доступны колонки с необходимыми данными.

Корректировка списка учащихся и сумм в распределении

Для корректировки списка учащихся и сумм в распределении следует с помощью гиперссылки Распределено в поле Учащийся открыть Форму распределения общих договоров.

Нажатие на кнопку Заполнить открывает меню с двумя командами:

  • Заполнить учащимися. В результате применения данной команды табличная часть формы будет заполнена только актуальными учащимися;
  • Распределить суммы равномерно. Использование этой команды позволяет распределить общую сумму оплаты равными долями по учащимся.
