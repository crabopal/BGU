Документ "Табель учета посещаемости учащихся"

Документ предназначен для формирования и печати Табеля учета посещаемости учащихся.

Работа со списком документов

Список документов Табели учета посещаемости учащихся можно открыть с помощью команды Табели учета посещаемости учащихся меню функций раздела Платное обучение.

В форме списка предусмотрен отбор по реквизитам Организация, Факультет и Группа студентов.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Табели учета посещаемости учащихся.

Заполнение реквизитов шапки документа
  • Организация – учебное заведение, от имени которого оформляется табель. Выбирается из справочника Организации.
  • Дата – дата оформления документа. Как правило, это последний рабочий день учреждения в месяце предоставления услуги.
  • Факультет – факультет учебного заведения. Выбирается из справочника Подразделения.
  • Группа студентов – группа учащихся на факультете учебного заведения. Выбирается из справочника Группы учащихся.
  • Период начисления – месяц, за который формируется табель.

После указания Периода начисления значения реквизитов Количество дней в месяце и Количество рабочих дней заполняются автоматически в соответствии с производственным календарем Российской Федерации.

Значения реквизитов Количество дней в месяце и Количество рабочих дней приведены для информации и не редактируются.

Тумблер Вид табеля может находиться в положениях По дням или Сводно.

В табель, который имеет вид По дням, необходимо вводить информацию для каждого дня учебы.

В табель, который имеет вид Сводно, для каждого учащегося вводится сводная информация о посещениях за месяц.

Заполнение реквизитов табличной части

Рассмотрим в качестве примера заполнение табеля, который имеет вид По дням.

Для заполнения табличной следует использовать кнопку Заполнить.

В результате в табличной части появится список учащихся, отобранных в соответствии с выбранными реквизитами Организация, Факультет и Группа студентов.

Для учащихся, которые в месяце формирования табеля не посещали учебное заведение, необходимо в колонке, соответствующей дню пропуска, выбрать из выпадающего списка признак отсутствия:

  • Н(о) – оплачиваемое непосещение. День, в который зафиксировано данное отсутствие при расчете месячной платы, включается в оплачиваемые дни.
  • Н(н) – неоплачиваемое непосещение. День с данным видом отсутствия при расчете месячной платы исключается из числа оплачиваемых дней.

В колонке Причины непосещения можно вызвать диалог редактирования текстовой информации для краткого описания причин пропуска посещений.

Для проверки правильности и полноты заполнения документа можно сформировать печатную форму Табель учета посещаемости учащихся.

Правильно заполненный документ следует провести.

При проведении документа формируются данные о непосещениях учащимися учебного заведения, которые, могут быть использованы при автоматизации последующих расчетов.

Примечание. Если Ставка за месяц, заданная в справочнике Ставки оплаты, не зависит от фактического количества посещений, то данные о непосещениях учащимися учебного заведения не будут использоваться в расчетах.
