Заполнение документа

Документ "Регистрация строки книги покупок"

Вспомогательный документ Регистрация строки книги покупок предназначен для безусловной регистрации вручную счета-фактуры в книге покупок или дополнительном листе книги покупок, с формированием соответствующих записей по учету входящего НДС в течение текущего налогового периода.

После заполнения и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида Регистрация строки книги покупок можно открыть с помощью команды Регистрация строки книги покупок панели навигации раздела Учет и отчетность.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Регистрация строки книги покупок.

Заполнение документа

Счет-фактура – счет-фактура, записи по которому не были сформированы в книге продаж или которые нуждаются в корректировке, либо Таможенная декларация по импорту. Выбирается из списка документов соответствующего вида.

Примечание. Если документ используется для регистрации счета-фактуры в книге покупок, то его следует вводить на основании тех счетов-фактур, по которым НДС еще не начислен и которые не были зарегистрированы в книге покупок при своем проведении.

Действие – вариант регистрации счета-фактуры. Может принимать значения:

  • Регистрация – данный вариант предназначен для безусловной регистрации счета-фактуры в книге покупок в текущем налоговом периоде или в дополнительном листе в прошедшем налоговом периоде. Применяется, если автоматическая регистрация счета-фактуры по каким-либо причинам была не выполнена, например, по причине отсутствия необходимой информации для регистрации, наличии ошибки в ведении учета и т п.

Значение Регистрация используется также для начисления НДС при получении товаров по импорту.

В этом случае документ заполняется на основании документа Таможенная декларация по импорту.

  • Аннулирование – данный вариант предназначен для корректировки в текущем налоговом периоде счетов-фактур прошлых налоговых периодов.

Примечание. При выборе варианта Аннулирование документ аннулируется полностью. Табличная часть при этом заполняется автоматически и выводится справочно, так как защищена от редактирования.

Место записи – определяет место записи документа Регистрация строки книги покупок и может принимать значения:

  • Основной раздел – основной раздел книги продаж;
  • Дополнительный лист книги – дополнительный лист книги продаж.

Код вида операции – отражает код операции согласно приказу ФНС России № ММВ-7-3/136@ от 19.03.2016 г. Заполняется автоматически при вводе на основании.

Счет-фактура на отгрузку – гиперссылка доступна, если в шапке указана причина налогообложения "Аванс полученный", по другим причинам реквизит не выводится в форме документа. При переходе по гиперссылке открывается форма Счета-фактуры на отгрузку следует указать счет-фактуру или список счетов-фактур, выставленных к реализации, при которой был зачтен ранее полученный аванс, и вычет будет заявляется данным документом Регистрация строки книги покупок. Данные из этого реквизита выводятся в графу 7а книги покупок (дополнительного листа книги покупок) для указанного счета-фактуры на аванс. Реквизит заполняется автоматически при вводе на основании.

Все остальные реквизиты документа также заполняются автоматически данными из документа-основания.
