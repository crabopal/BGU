Документ "Справка об оплате услуг для налогового вычета"

Документ Справка об оплате услуг для налогового вычета предназначен для подготовки справок о фактических расходах налогоплательщика на оказанные услуги по следующим формам:

  • КНД 1151158 (Приказ ФНС России от 18.10.2023 № ЕД-7-11/755@) – в части образовательных услуг;
  • КНД 1151156 (Приказ ФНС России от 08.11.2023 № ЕД-7-11/824@) – в части медицинских услуг;
  • КНД 1151160 (Приказ ФНС России от 18.10.2023 № ЕД-7-11/756@) – в части физкультурно-оздоровительных услуг.

Для выгрузки данных по указанным формам, справки должны быть объединены в Журнал справок об оплате услуг по соответствующим наборам реквизитов.

После проведения документа можно сформировать печатную форму справки об оплате услуг для налогового вычета. При проведении документа выполняется проверка корректности заполнения реквизитов.

Работа со списком документов

Список документов вида Справки об оплате услуг для налогового вычета можно открыть с помощью соответствующей команды, размещенной в группе Справки для налоговых вычетов меню функций раздела Услуги, работы, производство.

В случае использования документов платного обучения, список документов вида Справки об оплате услуг для налогового вычета можно открыть с помощью соответствующей команды, размещенной в группе Справки для налоговых вычетов меню функций раздела Платное обучение.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Справки об оплате услуг для налогового вычета.

Работа с документом

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Отчетный год – указывается отчетный год, в котором были оказаны услуги.

Налоговый орган – указывается налоговый орган, для которого формируется журнал справок.

Номер сведений – заполняется автоматически.

Номер корректировки – заполняется автоматически, в случае если документ-справка введен на основании другого документа, подлежащего корректировке.

Аннулирующая – при установке признака аннулирующая, справке автоматически присваивается номер корректировки 999. Ввод корректирующих справок на основании аннулирующих не выполняется.

Вид справки, оказанные услуги – выбор вида услуг, по которым формируется журнал и входящие в него документы-справки.

Закладка Физическое лицо (его супруг/супруга), оплатившее услуги – заполняется данными налогоплательщика, получающего справку для оформления налогового вычета:

Налогоплательщик – выбор выполняется из справочника контрагенты, по данным выбранного элемента справочника выполняется заполнение остальных реквизитов закладки: Фамилия, Имя, Отчество, ИНН, Дата рождения, Код вида дкоумента, Серия и номер, Дата выдачи.

По умолчанию переключатель Налогоплательщик и получатель услуги одно лицо установлен. Если налогоплательщик производил оплату за другое физическое лицо, требуется выключить переключатель. В этом случае становится доступна закладка Физическое лицо, которому оказаны услуги:

Получатель услуги – выбор выполняется из справочника контрагенты, по данным выбранного элемента справочника выполняется заполнение остальных реквизитов закладки: Фамилия, Имя, Отчество, ИНН, Дата рождения, Код вида дкоумента, Серия и номер, Дата выдачи.

В группе реквизитов Сведения по оплаченным услугам выполняется заполнение сумм расходов на оказанные услуги.

Может быть задан отбор по договорам, если при заполнении суммы расходов требуется учитывать только договоры с определенными параметрами, отбор выполняется с помощью гиперссылки в поле Договоры.

С помощью кнопки Заполнить сумму по данным учета выполняется расчет суммы расходов и её отражение в соответствующем поле, в зависимости от вида справки по оказанным услугам.

Для вида справки по образовательным услугам предусмотрен дополнительный флаг Обучение проводилось по очной форме обучения, устанавливаемый вручную.
