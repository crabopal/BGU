Документ "Заявление на возврат по чеку ККМ"

Документ Заявление на возврат по чеку ККМ предназначен для оформления возврата денежных средств при реализации в розницу с использованием контрольно-кассовой техники.

Работа со списком документов

Список документов вида Заявление на возврат по чеку ККМ можно открыть с помощью команды Заявления на возврат по чекам ККМ меню функций раздела Денежные средства.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Заявления на возврат по чекам ККМ.

Примечание. Документ Заявление на возврат по чеку ККМ можно создать на основании документа Чек ККМ.

Более подробно с особенностями работы с документом Заявление на возврат по чеку ККМ можно ознакомиться в статье "Оформление розничных продаж", опубликованной на ИТС (Бухгалтерия государственного учреждения, редакция 2 – Методика ведения учета – Учет розничных продаж).
