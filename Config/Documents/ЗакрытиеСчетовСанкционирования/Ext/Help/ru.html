Проведение документа

Документ "Закрытие счетов санкционирования завершаемого финансового года"

В соответствии с инструкцией по учету по завершении текущего финансового года показатели (остатки) по соответствующим аналитическим счетам учета бюджетных ассигнований, лимитов бюджетных обязательств, исполненных денежных обязательств и утвержденных сметных (плановых, прогнозных) назначений по доходам (поступлениям), расходам (выплатам) текущего финансового года на следующий год не переносятся.

Документ Закрытие счетов санкционирования завершаемого финансового года предназначен для формирования записей по закрытию счетов учета ассигнований, ЛБО, предельных объемов финансирования текущего финансового года и плановых периодов последним днем года, а также для перерегистрации с понижением глубины планирования плановых оборотов по счетам санкционирования, сформированных на плановые периоды.

После заполнения реквизитов и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Документы вида Закрытие счетов санкционирования завершаемого финансового года находятся в журнале Документы закрытия года. Журнал Документы закрытия года можно открыть с помощью команды Документы закрытия года меню функций раздела Учет и отчетность.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели журнала Документы закрытия года и выбрать в списке тип документа Закрытие счетов санкционирования завершаемого финансового года.

Заполнение реквизитов шапки документа
  • Дата документа заполняется автоматически значением рабочей (текущей) даты. Для закрытия года можно указать 31 декабря текущего отчетного года или оставить текущую дату;
  • Организация – учреждение, для которого производится закрытие счетов. Выбирается из справочника Организации;
  • Финансовый год – финансовый год, который требуется закрыть.

Важно! Дата формирования бухгалтерских записей межотчетного периода может отличаться от даты документа. Операция межотчетного периода может вводиться текущей датой (реквизит Дата), но бухгалтерская запись межотчетного периода все равно отражается последним днем года - 31.12.20ХХ с указанием уточнения периода, который заполняется в реквизите Финансовый год.
  • Обрабатывать счета плановых периодов и Перерегистрация бюджетных данных – флажки устанавливаются если необходимо перерегистрировать бюджетные и плановые данные, сформированные на плановые периоды.
  • Изменение типа учреждения – флажок, устанавливается в случае изменения типа учреждения.

Типовая операция – имеет одно значение, Закрытие счетов санкционирования завершаемого финансового года.

Закладка "Закрытие счетов"

После нажатия на кнопку Заполнить по данным учета табличная часть будет заполнена остатками на счетах по счетам санкционирования, сформированными на конец года.

Примечание. Реквизиты табличной части, за исключением сумм остатков по дебету и кредиту, не редактируются.

Закладка "Перерегистрация бюджетных данных"

После нажатия кнопки Заполнить по данным учета табличная часть будет заполнена данными по счетам санкционирования, сформированными на конец года, которые подлежат перерегистрации с понижением глубины планирования плановых и/или бюджетных данных, принятых на плановые периоды.

Если "старый" КПС перестает действовать в новом году, то на закладке Перерегистрация бюджетных данных следует нажать кнопку Замена КПС.

Откроется таблица соответствия КПС, в которой следует указать актуальные КПС для проводок:

  • в левой части отражаются данные по КПС, присутствующие в проводках перерегистрируемых документов (Вид, Код, Период действия);
  • в правой колонке Заменить на КПС следует указать актуальные КПС, на которые будут заменены "старые" КПС в проводках перерегистрации.

Если недействующих КПС в программе нет, документы будут сформированы по "старым" КПС.

Проведение документа

При проведении документа формируются бухгалтерские записи:

  • по закрытию остатков по счетам санкционирования в корреспонденции со служебным счетом 000 "Вспомогательный";
  • по перерегистрации с понижением глубины планирования оборотов плановых (бюджетных) данных, сформированных на плановые периоды.

Для каждой сформированной проводки устанавливается тип межотчетного периода Технологические операции.

Методика закрытия счетов санкционирования и перерегистрации обязательств подробно описана в статье "Перенос или перерегистрация показателей по санкционированию на плановые периоды", размещенной на ИТС (Бухгалтерия государственного учреждения. Редакция 2 – Ведение учета – Санкционирование).
