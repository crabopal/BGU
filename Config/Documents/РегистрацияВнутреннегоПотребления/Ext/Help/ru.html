Регистрация внутреннего потребления для НДС

Документ Регистрация внутреннего потребления для НДС используется для регистрации налоговой базы НДС по строительно-монтажным работам (СМР).

Примечание. При выполнении строительно-монтажных работ для собственного потребления налоговая база определяется как стоимость выполненных работ, исчисленная исходя из всех фактических расходов налогоплательщика на их выполнение, за исключением расходов по подрядным договорам.

Если учреждение ведет строительно-монтажные работы для собственного потребления, то документ следует вводить в конце каждого налогового периода.

Документ проводок не формирует.

Для начисления НДС в бюджет на основании документа Регистрация внутреннего потребления для НДС следует ввести документ Счет-фактура выданный.

Работа со списком документов

Список документов вида Регистрация внутреннего потребления для НДС можно открыть с помощью команды Регистрация внутреннего потребления для НДС меню функций раздела Налоги.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Регистрация внутреннего потребления для НДС.

Работа с документом

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Так, для реквизита Дата, следует выбрать дату в конце налогового периода.

КФО – код вида финансового обеспечения. Выбирается из списка.

Для заполнения табличной части следует нажать на кнопку Заполнить.

При этом табличная часть будет заполнена объектами строительства, по которым ведутся работы и суммами расходов сформированными по этим объектам в текущем налоговом периоде.

Примечание. Табличная часть заполняется суммами оборотов сформированными по дебету счета 106.КС «Вложения в основные средства - недвижимое имущество учреждения. Капитальное строительство» по способу строительства «Хозяйственный способ» в текущем налоговом периоде. Способ строительства определяется значением субконто счета 106.КС, которое задается при формировании проводок по расходам.

По завершении работы с документом следует нажать на кнопку Провести и закрыть.

Дополнительные возможности

На основании документа Регистрация внутреннего потребления для НДС можно ввести документ Счет-фактура выданный.
