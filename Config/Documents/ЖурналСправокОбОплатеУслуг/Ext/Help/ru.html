Документ "Журнал справок об оплате услуг"

Документ Журнал справок об оплате услуг предназначен для подготовки и отправки в ФНС журналов сведений о фактических расходах налогоплательщика на оказанные услуги по следующим формам:

  • КНД 1115141 (Приказ ФНС России от 18.10.2023 № ЕД-7-11/755@) – в части образовательных услуг;
  • КНД 1115139 (Приказ ФНС России от 08.11.2023 № ЕД-7-11/824@) – в части медицинских услуг;
  • КНД 1115143 (Приказ ФНС России от 18.10.2023 № ЕД-7-11/756@) – в части физкультурно-оздоровительных услуг.

Документ Журнал справок об оплате услуг содержит табличную часть с отдельными документами-справками об оплате услуг, каждая из которых является страницей выгружаемого журнала. Для заполнения документа-справки используется документ Справка об оплате услуг для налогового вычета, соответсвующие следующим формам:

  • КНД 1151158 (Приказ ФНС России от 18.10.2023 № ЕД-7-11/755@) – в части образовательных услуг;
  • КНД 1151156 (Приказ ФНС России от 08.11.2023 № ЕД-7-11/824@) – в части медицинских услуг;
  • КНД 1151160 (Приказ ФНС России от 18.10.2023 № ЕД-7-11/756@) – в части физкультурно-оздоровительных услуг.

Заполнение журнала справками с соответствующими отборами выполняется с помощью команд группы команд Заполнить.

При проведении документа автоматически создается уведомление в едином рабочем месте 1С-Отчетность, с которым можно работать с помощью стандартных средств 1С-Отчетность.

После проведения документа можно сформировать печатную форму журнала, а так же выполнить проверку выгрузки и выгрузку журнала в форматах ФНС.

Работа со списком документов

Список документов вида Журнал справок об оплате услуг можно открыть с помощью соответствующей команды, размещенной в группе Справки для налоговых вычетов меню функций раздела Услуги, работы, производство.

В случае использования документов платного обучения список документов вида Журнал справок об оплате услуг можно открыть с помощью соответствующей команды, размещенной в группе Справки для налоговых вычетов меню функций раздела Платное обучение.

Так же возможен ввод документа с помощью единого рабочего места окна 1С-Отчетности на закладке Уведомления.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Журналы справок об оплате услуг.

Также возможно создание документа из единого рабочего места 1С-Отчетности, с помощью команды Создать на закладке Уведомления. При создании из единого рабочего места 1С-Отчетности, после нажатия кнопки Создать и выборе одного из видов уведомлений:
- Журнал справок об оплате образовательных услуг;
- Журнал справок об оплате медицинских услуг;
- Журнал справок об оплате физкультурно-оздоровительных услуг;
открывается вспомогательное окно Выбор редакции формы. Команда Создать открывает форму документа, с возможностью заполнения отдельными документами-справками. Команда Форма ручного заполнения открывает форму регламентированного отчета для ручного заполнения.

Работа с документом

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Отчетный год – указывается отчетный год, в котором были оказаны услуги.

Налоговый орган – указывается налоговый орган, для которого формируется журнал справок.

Вид справки, оказанные услуги – выбор вида услуг, по которым формируется журнал и входящие в него документы-справки.

Реквизиты табличной части:

Справка об оплате услуг – документ Справка об оплате услуг для налогового вычета, в котором отражена информация об оплате оказанных услуг.

Для заполнения табличной части можно воспользоваться командами группы Заполнить.

Команда Заполнить справками без журналов добавляет в табличную часть все документы-справки с учетом отбора по реквизитам журнала.
