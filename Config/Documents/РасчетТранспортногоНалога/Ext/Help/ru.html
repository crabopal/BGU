Документ "Расчет транспортного налога"

С 2021 года отменена обязанность по представлению налоговых деклараций по транспортному налогу, а для верификации платежей по транспортному налогу, поступившему за соответствующий налоговый период, учреждениям направляются сообщения об исчисленных налоговыми органами суммах по данному налогу.

Документ Расчет транспортного налога предназначен для рассчета учреждениями суммы транспортного налога поквартально, а также формирования печатной формы в разрезе налоговых органов и кодов по ОКТМО для удобного сравнения с присланными сообщениями из налоговых органов.

Работа со списком документов

Документы вида Расчет транспортного налога можно открыть с помощью команды Расчет транспортного налога меню функций раздела Налоги.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели формы Расчет транспортного налога.

Работа с документом

Отчетный период – указывается отчетный период, за который нужно рассчитать сумму транспортного налога.

Организация – заполняется автоматически, значение можно изменить.

Для автоматического заполнения таблицы транпортными средствами учреждения следует использовать кнопку Заполнить. В результате графы Транспортное средство, Инвентарный номер, Налоговый орган, Код по ОКТМО, Налоговая база, Налоговая ставка, Сумма налога заполнятся автоматически согласно регистру сведений Регистрация транспортных средств, в котором для каждого транспортного средсва учреждения были предварительно введены данные о их порядке налогообложения транспортным налогом.

При необходимости добавления новых строк в ручном режиме следует использовать кнопку Добавить. Далее для расчета транспортного налога следует воспользоваться кнопкой Рассчитать.

Дополнительные возможности

На основании документа Расчет транспортного налога можно ввести документ Начисление имущественных налогов.
