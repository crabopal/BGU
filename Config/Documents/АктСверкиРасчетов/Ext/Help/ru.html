Документ "Акт сверки расчетов (ф. 0510477)"

Документ Акт сверки расчетов (ф. 0510477) применяется для отражения результатов сверки расчетов с должником (кредитором) в целях фиксации задолженности.
Например, при предъявлении исковых требований, урегулировании задолженности по договору (соглашению), если такое требование установлено заключенным договором (соглашением) или актами Правительства Российской Федерации.

Документ Акт сверки расчетов (ф. 0510477) применяется при сверке субъектом учета расчетов:

  • с контрагентами по документам-основаниям на поставку товаров, оказание услуг, выполнение работ;
  • по администрируемым доходам (за исключением доходов, администрируемых ФНС России);
  • по кредитам, займам (ссудам);
  • с прочими дебиторами, учтенными на счете 021005000 "Расчеты с прочими дебиторами";
  • по средствам, полученным во временное распоряжение, учтенными на счете 330401000 "Расчеты по средствам, полученным во временное распоряжение".

Документ Акт сверки расчетов (ф. 0510477) не применяется:

  • для сверки расчетов по счету 030100000 "Расчеты с кредиторами по долговым обязательствам";
  • для сверки расчетов с работниками (сотрудниками) субъекта учета (например, по расчетам по заработной плате, учтенными на счетах 030211000 "Расчеты по заработной плате" и 020610000 "Расчеты по заработной плате", по расчетам с подотчетными лицами, учтенными на счете 020800000 "Расчеты с подотчетными лицами);
  • для сверки расчетов с нерезидентами, учтенными на счетах 020500000 "Расчеты по доходам", 020600000 "Расчеты по выданным авансам", 020700000 "Расчеты по кредитам, займам (ссудам)", 030200000 "Расчеты по принятым обязательствам";
  • для сверки расчетов по счетам 020400000 "Финансовые вложения", 021500000 "Вложения в финансовые активы", для сверки расчетов с физическими лицами, учтенных на счетах 020500000 "Расчеты по доходам";
  • для сверки расчетов по межбюджетным трансфертам, субсидиям, субвенциям".

Документ формируется ответственным исполнителем бухгалтерской службы субъекта учета. Если бухгалтерский учет ведется по группе дебиторов (кредиторов), документ формируется ответственным исполнителем, осуществляющим ведение персонифицированного управленческого учета.

После заполнения и записи документа можно сформировать печатную форму Акт сверки расчетов (ф. 0510477).

Важно. Форма Акт сверки расчетов (ф. 0510477) состоит из заголовочной части, Раздела 1 "По данным учреждения", который заполняется учреждением и содержит данные по номерам счетов и Раздела 2 "По данным контрагента", заполняемым контрагентом без указания данных по номерам счетов. В документе Акт сверки расчетов (ф. 0510477) заполняется только Раздел 1, табличная часть для заполнения Раздела 2 отсутствует. Контрагенту для заполнения Раздела 2 направляется бумажная форма Акта сверки расчетов (ф. 0510477), так как законодательство не содержит описания формата обмена в виде электронных документов для обмена по ЭДО.
В программе возможен обмен с контрагентом только в виде скан-копии подписанной печатной формы, сформированной из документа Акт сверки расчетов (ф. 0510477).

Работа со списком документов

Список документов вида Акт сверки расчетов (ф. 0510477) можно открыть с помощью команды Акты сверки расчетов (ф. 0510477) меню функций раздела Инвентаризация.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Акты сверки расчетов (ф. 0510477).

Заполнение реквизитов шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Контрагент – наименование поставщика или покупателя. Выбирается из справочника Контрагенты, при этом группа реквизитов ИНН, КПП, ОГРН заполняется автоматически. При необходимости предусмотрена возможность ручного изменения реквизитов ИНН, КПП, ОГРН.

Период сверки с/по – дата начала и дата окончания периода, за который выполняется сверка в формате "ДД.ММ.ГГГГ".

Примечание. Документ Акт сверки расчетов (ф. 0510477) может формироваться как на дату проведения инвентаризации с дебиторами (кредиторами), по которым имеются ненулевые остатки на дату проведения инвентаризации, на дату исполнения сторонами обязательств по договору (соглашению), если такое требование установлено заключенным договором (соглашением), в иных случаях (например, по решению субъекта учета, при наличии соответствующего запроса), так и на иную дату, установленную субъектом учета в учетной политике (в порядке проведения инвентаризации).

Закладка "Раздел 1 "По данным учреждения""

Раздел 1 "По данным учреждения" содержит информацию с подсчетом итогов по каждому правовому основанию и раскрытием итогов в разрезе счетов бухгалтерского учета по всем документам-основаниям (элементам справочника Договоры и иные основания возникновения обязательств), заключенными с контрагентом, указанном в шапке документа.

Раздел 1 заполняется автоматически по кнопке Заполнить по данным бух. учета. При автоматическом заполнении производится анализ бухгалтерских записей по регистру бухгалтерии согласно заданному в шапке документа периоду по счетам учета, которые указаны на закладке Счета при настройке отбора на закладке Отбор. Также для Раздела 1 доступно ручное заполнение, например, когда бухгалтерский учет ведется по группе дебиторов (кредиторов) и Акт сверки расчетов (ф. 0510477) формируется по данным персонифицированного управленческого учета.

Реквизитный состав Раздела 1 документа соответствует структуре показателей утвержденной формы Акта сверки расчетов (ф. 0510477) и представлен в виде соответствующих табличных частей на отдельных закладках.

Данные в разрезе договоров представлены в следующих табличных частях Раздела 1:

  • на закладке Операции – заполняется список операций за указанный период, которые включают сведения о договоре, валюте, сумме операции, ее содержании и о первичном учетном документе. При автоматическом заполнении Раздела 1 по данным бухгалтерского учета список операций заполняется по данным бухгалтерских записей регистра бухгалтерии. При необходимости реквизиты закладки можно скорректировать вручную.
  • на закладке Обороты – обобщенные сведения по операциям в разрезе валюты и договора. Реквизиты табличной части закладки рассчитываются полностью автоматически по данным закладки Операции, ручная корректировка не предусмотрена.
  • на закладке Сальдо начальное – сальдо на дату начала периода сверки в разрезе валюты и договора. При автоматическом заполнении Раздела 1 по данным бухгалтерского учета сальдо начальное заполняется по данным остатков регистра бухгалтерии на дату начала периода сверки. При необходимости реквизиты закладки можно скорректировать вручную.
  • на закладке Сальдо конечное – сальдо на дату окончания периода сверки в разрезе валюты и договора. Реквизиты табличной части закладки рассчитываются полностью автоматически по данным закладки Сальдо конечное по счетам, ручная корректировка не предусмотрена.
  • на закладке Сальдо конечное по счетам – сальдо на дату окончания периода сверки в разрезе валюты, договора и счета учета. При автоматическом заполнении Раздела 1 по данным бухгалтерского учета сальдо конечное по счетам заполняется по данным остатков регистра бухгалтерии на дату окончания периода сверки. При необходимости реквизиты закладки можно скорректировать вручную.

Примечание. Отличие табличных частей закладок Сальдо конечное и Сальдо конечное по счетам заключается в том, что колонка Счет предусмотрена только в табличной части закладки Сальдо конечное по счетам.

Данные по документу в целом (без разреза по договорам) представлены в табличных частях закладки Сальдо всего по документу Раздела 1:

  • на закладке Сальдо начальное всего по документу – заполняются обобщенные сведения по сальдо начальному в разрезе валюты. Реквизиты табличной части закладки рассчитываются полностью автоматически по данным закладки Сальдо начальное, ручная корректировка не предусмотрена.
  • на закладке Сальдо конечное всего по документу – обобщенные сведения по сальдо конечному в разрезе валюты. Реквизиты табличной части закладки рассчитываются полностью автоматически по данным закладки Сальдо конечное, ручная корректировка не предусмотрена.
  • на закладке Сальдо конечное по счетам всего по документу – обобщенные сведения по сальдо конечному по счетам в разрезе валюты. Реквизиты табличной части закладки рассчитываются полностью автоматически по данным закладки Сальдо конечное по счетам, ручная корректировка не предусмотрена.

Примечание. Предусмотрено автоматическое заполнение по данным бухгалтерского учета, а также ручная корректировка только для табличных частей закладок Операции, Сальдо начальное, Сальдо конечное по счетам. Все остальные табличные части закладок Раздела 1 рассчитываются автоматически на основании данных, указанных в табличных частях перечисленных закладок. Такое решение обусловлено экономической сутью показателей и структурой показателей Раздела 1 в утвержденной форме Акта сверки расчетов (ф. 0510477).

Важно. Колонки по дебету и кредиту на всех закладках Раздела 1 заполняются только в случае сверки состояния расчетов с резидентами по кредитам, займам (ссудам) (счет 020700000 "Расчеты по кредитам, займам (ссудам)"):
– Проценты – по начисленным и неуплаченным процентам;
– Штрафы – по штрафным санкциям за нецелевое использование средств;
– Пени – по штрафам (пеням) за несвоевременный возврат и неуплату процентов.
Для сверки расчетов с иными дебиторами (кредиторами) перечисленные колонки не заполняются, заполняется только колонка Основной долг.

Закладка "Отбор"

На закладке отбор в отдельных закладках расположены настройки отбора по счетам бюджетного учета и по договорам для заполнения документа по данным бухгалтерского учета.

В табличной части закладки Счета указывается список счетов бухгалтерского, бюджетного учета, по которым необходимо выполнить сверку. Табличная часть заполняется автоматически по кнопке Заполнить, также доступно ручное заполнение.

Примечание. Операции списания доходов будущих периодов по договорам аренды и долгосрочным договорам в акте сверки расчетов не отражаются, поскольку заполнение акта сверки по счетам 040110100"Доходы текущего финансового года", 040140100 "Доходы будущих периодов" законодательством не предусмотрено.

В табличной части закладки Договоры указывается список договоров контрагента. При отсутствии заполненных строк в табличной части закладки отбор по договорам при заполнении по данным бухгалтерского учета не применяется.

Закладка "Представители сторон"

На закладке указываются представители учреждения, которые подписывают Раздел 1:

  • Ответственный исполнитель бухгалтерской службы – ответственный исполнитель бухгалтерской службы или ответственный исполнитель, осуществляющий ведение управленческого учета;
  • Главный бухгалтер – главный бухгалтер субъекта учета (централизованной бухгалтерии);
  • Руководитель – руководитель субъекта учета.

Важно. Указание в документе Акт сверки расчетов (ф. 0510477) представителей контрагента не предусмотрено, так как они указываются в Разделе 2, который заполняют сторонние контрагенты, а не учреждения.
