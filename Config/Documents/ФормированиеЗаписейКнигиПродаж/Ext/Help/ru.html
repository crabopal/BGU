Документ "Формирование записей книги продаж"

Документ Формирование записей книги продаж используется для регистрации в книге продаж счетов-фактур, выданных покупателям, а также иных документов, служащих основанием для начисления НДС.

Примечание. При автозаполнении в документ попадают только те счета-фактуры, по которым НДС для перечисления в бюджет еще не начислен и которые еще не зарегистрированы в книге продаж.

Если все счета-фактуры выданные, введенные в текущем налоговом периоде, уже зарегистрированы в книге продаж и НДС для перечисления в бюджет по ним уже начислен, то документ Формирование записей книги продаж после автозаполнения может оказаться пустым.

Это будет означать, что счета-фактуры, для которых требуется регистрация в книге продаж, отсутствуют.

После заполнения и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида Формирование записей книги продаж можно открыть с помощью команды Формирование записей книги продаж меню функций раздела Налоги.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Формирование записей книги продаж.

Заполнение реквизитов шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Примечание. Документ рекомендуется вводить в конце каждого налогового периода или месяца для контроля за тем, чтобы все выданные счета-фактуры были отражены в книге продаж.

Заполнение реквизитов на закладках документа

Документ состоит из закладок, соответствующих причинам налогообложения:

  • Реализация;
  • Реализация по 0%;
  • Авансы выданные;
  • Авансы выданные, предъявленные комиссионером (агентом) – соответствует причине налогообложения Счет-фактура на аванс от комиссионера (перевыставленный).

При нажатии на кнопку Заполнить документ командной панели формы документа табличные части закладок заполняются построчно записями книги продаж за текущий налоговый период, которые не были автоматически сформированы счетами-фактурами в момент проведения.

Несмотря на предусмотренную возможность заполнения вручную, рекомендуется производить автоматическое заполнение документа с использованием кнопки Заполнить документ.
После автоматического заполнения документа заполненные строки его табличной части можно вручную отредактировать.

Если счет-фактура по какой либо строке табличной части документа (графа Счет – фактура) не должен быть зарегистрирован в текущем налоговом периоде, то данную строку следует удалить.

Если счет-фактура по какой либо строке табличной части документа должен быть зарегистрирован в дополнительном листе книги продаж, то следует установить флаг в поле Запись доп. листа и задать в поле Корректируемый период дату регистрации счета-фактуры в прошлом налоговом периоде.

Закладка "Бухгалтерская операция"

Типовая операция – выбирается из списка Типовые операции.

Для документа предусмотрена одна типовая операция:

  • НДС начисленный.

Для данной типовой операции следует заполнить реквизит:

  • КПС для счета 303.04 – классификационный признак счета для счета 303.04. Выбирается в справочнике КПС.

Примечание. Если существует рабочий счет, то заполнение реквизита КПС для счета 303.04 необязательно.

Регистрация документа

Регистрация документа Формирование записей книги продаж производится в списке Формирование записей книги продаж.
