Документ "Переоценка валютных остатков"

Согласно «Инструкции по применению единого плана счетов бухгалтерского учета для государственных органов власти (государственных органов), органов местного самоуправления, органов управления государственными внебюджетными фондами, государственных академий наук, государственных (муниципальных) учреждений» (утверждена Приказом Минфина России от 1 декабря 2010 г. № 157н) переоценка денежных средств, активов и обязательств, выраженных в иностранной валюте осуществляется на дату совершения операций в иностранной валюте и на отчетную дату (на дату формирования регистра бухгалтерского учета).

Документ Переоценка валютных остатков предназначен для пересчета рублевых эквивалентов валютных остатков на аналитических счетах, учет на которых ведется в иностранных валютах, с отнесением возникающих курсовых разниц на финансовый результат от переоценки активов текущего финансового года.

Документ позволяет сформировать проводки по переоценке валютных остатков по счетам 201.27, 201.34, счетам расчетов, другим счетам и объектам аналитики.

Документ выполняет переоценку рублевого покрытия остатков по валютному счету, указанному в документе, по курсам валют, установленным на дату документа.

После заполнения и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида Переоценка валютных остатков можно открыть с помощью команды Переоценка валютных остатков меню функций раздела Учет и отчетность.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Переоценка валютных остатков.

Заполнение реквизитов шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Примечание. Если для реквизитов КФО, Счет, КПС и Валюта заданы значения, то заполнение табличной части происходит с установкой отбора по заданным значениям реквизитов. Если значения реквизитов не заданы, то заполнение табличной части производится без установки отборов.
  • КФО – код финансового обеспечения, в разрезе которого требуется переоценка валютных остатков на счетах учета. Выбирается из списка.
  • Счет – синтетический счет учета, валютные остатки на котором необходимо переоценить. Выбирается из фрагмента Плана счетов ЕПСБУ, ограниченного счетами, по которым установлен признак Валютный учет.
  • КПС – классификационный признак счета, в разрезе которого требуется переоценка валютных остатков на счетах учета Выбирается из справочника КПС.
  • Валюта – валюта, остатки в которой необходимо переоценить Выбирается из справочника Валюты.
  • Курс – если в шапке документа выбрана валюта, то реквизит содержит последнее значение курса выбранной валюты к валюте регламентированного учета. Реквизит недоступен для редактирования.
  • Кратность – если в шапке документа выбрана валюта, остатки по которой будут переоценены, то реквизит содержит последнее значение кратности значения выбранной валюты к валюте регламентированного учета. Реквизит недоступен для редактирования.

Если на момент создания документа курсы валют не актуальны, то в шапке документа становится доступна гиперссылка с предупреждением о необходимости загрузить последние курсы валют.

Нажатие на гиперссылку открывает стандартную обработку загрузки курсов валют.

Обновить курсы валют можно в любой момент времени, нажав на кнопку Загрузить курсы валют в командной панели формы документа.

Закладка "Таблица переоценки"

Для заполнения табличной части на закладке Таблица переоценки по данным бухгалтерского учета следует нажать на кнопку Заполнить по данным учета.

На каждую валюту будет создана отдельная строка.

Если по субсчету ведется аналитический учет, то будут созданы отдельные строки по каждому объекту аналитики, имеющему валютный остаток.

Значения колонок Сумма после переоценки и Курсовая разница рассчитываются автоматически.

Значения в колонках табличной части недоступны для редактирования.

Закладка "Бухгалтерская операция"

Реквизит Типовая операция имеет по умолчанию значение Переоценка валютных остатков.

При переоценке валюты на счетах 201.27 и 201.34 кроме проводок по балансовым счетам формируются также проводки по соответствующим забалансовым счетам.
