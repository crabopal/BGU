Документ "Перенос остатков по КПС"

В результате вступления в действие нового приказа о бюджетной классификации существующие в базе классификационные признаки счетов (КПС) могут утратить свою актуальность.

Поскольку бюджетная классификация интегрирована в план счетов бухгалтерского учета, то могут утратить актуальность также соответствующие рабочие счета.

Это приводит к необходимости переноса остатков на новые счета – с новыми КПС.

Другими словами, требуется выполнить перенос остатков со старых, утративших актуальность КПС на новые КПС.

Для переноса остатков с устаревших КПС на новые в программе предусмотрен документ Перенос остатков по КПС.

Работа со списком документов

Документы вида Перенос остатков по КПС находятся в форме Перенос остатков, которую можно открыть с помощью команды Перенос остатков меню функций раздела Учет и отчетность.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка на закладке Перенос остатков по КПС.

Методика переноса остатков по КПС подробно описана в статье Практические рекомендации по переносу остатков с неактуальных КПС в программе «1С:Бухгалтерия государственного учреждения 8, ред. 2», размещенной на ИТС (Бухгалтерия государственного учреждения. Редакция 2, Перенос остатков по КПС).
