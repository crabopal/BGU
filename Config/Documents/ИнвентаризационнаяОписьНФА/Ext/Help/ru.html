Документ "Инвентаризационная опись по объектам НФА (ф. 0510466)"

Документ Инвентаризационная опись по объектам НФА (ф. 0510466) применяется инвентаризационной комиссией для отражения результатов проведения инвентаризации остатков нефинансовых активов и имущества, учтенного на соответствующих забалансовых счетах.

Документ Инвентаризационная опись по объектам НФА (ф. 0510466) формируется ответственным исполнителем бухгалтерской службы на основании документа Решение о проведении инвентаризации (ф. 0510439) по ответственному лицу и месту (подразделению) проведения инвентаризации и детализируется по каждому инвентаризируемому объекту нефинансовых активов не позднее дня начала инвентаризации.

Документ Инвентаризационная опись по объектам НФА (ф. 0510466) заполняется по учетным данным групп счетов: 101.00 "Основные средства"; 102.00 "Нематериальные активы"; 103.00 "Непроизведенные активы"; 105.00 "Материальные запасы"; 106.00 "Вложения в нефинансовые активы"; 108.00 "Нефинансовые активы имущества казны"; 111.00 "Права пользования активами"; 113.00 "Биологические активы", а также забалансовых счетов: 01 "Имущество, полученное в пользование", 02 "Материальные ценности на хранении", 07 "Награды, призы, кубки и ценные подарки, сувениры", 12 "Спецоборудование для выполнения научно-исследовательских работ по договорам с заказчиками", 13 "Экспериментальные устройства", 21 "Основные средства в эксплуатации", 22 "Материальные ценности, полученные по централизованному снабжению", 23 "Периодические издания для пользования", 25 "Имущество, переданное в возмездное пользование (аренду)" в части объектов финансовой аренды, 27 "Материальные ценности, выданные в личное пользование работникам (сотрудникам)" в части материальных запасов, указанных в документе Решение о проведении инвентаризации (ф. 0510439).

Примечание. Если объекты основных средств учитываются на счетах 010100000 "Основные средства", 010300000 "Непроизведенные активы" и одновременно отражаются на забалансовых счетах 24 "Нефинансовые активы, переданные в доверительное управление", 25 "Имущество, переданное в возмездное пользование (аренду)", 26 "Имущество, переданное в безвозмездное пользование", 27 "Материальные ценности, выданные в личное пользование работникам (сотрудникам)", то такие объекты инвентаризируются по соответствующим счетам 010100000 "Основные средства", 010300000 "Непроизведенные активы" с учетом информации, отраженной на забалансовых счетах.

После заполнения и записи документа можно сформировать печатную форму Инвентаризационная опись (сличительная ведомость) по объектам нефинансовых активов (ф. 0510466).

Работа со списком документов

Список документов вида Инвентаризационная опись по объектам НФА (ф. 0510466) можно открыть с помощью команды Инвентаризационные описи по объектам НФА (ф. 0510466) меню функций раздела Инвентаризация.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Инвентаризационные описи по объектам НФА (ф. 0510466).

Заполнение реквизитов шапки и подвала документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Подразделение – подразделение, в котором проводится инвентаризация. Выбирается из справочника Подразделения при активной настройке "Учет по подразделениям" (Раздел Главное - Настройки параметров учета - Общие настройки).

ИФО – источник финансового обеспечения, выбирается из одноименного справочника при активной настройке "Учет по ИФО" (Раздел Главное - Настройки параметров учета - Общие настройки).

Для начала работы с документом необходимо предварительно в шапке документа указать Решение о проведении инвентаризации (ф. 0510439), в открывшемся окне Выбор данных из Решения с учетом изменений необходимо отметить строку, по которой следует заполнить документ описи, и нажать на кнопку Выбрать строки. После этого будет автоматически заполнена закладка Комиссия составом инвентаризационной комиссии, а также реквизиты в шапке документа Инвентаризационная опись по объектам НФА (ф. 0510466), в группе реквизитов Сведения об инвентаризации из Решения:

  • По состоянию на – дата, по состоянию на которую проводится инвентаризация, в формате "ДД.ММ.ГГГГ";
  • Номер комиссии – номер инвентаризационной комиссии/рабочей комиссии в составе инвентаризационной;
  • Ответственное лицо – фамилия, имя, отчество (при наличии) ответственного лица (ответственного лица группы лиц) за сохранность и (или) использование по назначению имущества;
  • Список счетов – коды счетов, по которым проводится инвентаризация;
  • Период проведения с/по – даты начала и окончания инвентаризации в формате "ДД.ММ.ГГГГ";
  • Место проведения – место (подразделение) проведения инвентаризации.

Примечание. Редактирование вышеперечисленных реквизитов в документе описи не предусмотрено, так как они зафиксированы документом Решение о проведении инвентаризации (ф. 0510439), выбранном в шапке документа.

Документом Инвентаризационная опись по объектам НФА (ф. 0510466) можно проводить как сплошную, так и выборочную инвентаризацию. Методика проведения такой инвентаризации описана в статье "Выборочная инвентаризация в целях прекращения признания активом объекта ОС", размещенной на ИТС (Бухгалтерия государственного учреждения. Редакция 2 – Инвентаризация – Формирование документов инвентаризации согласно приказу Минфина России от 15.04.2021 № 61н).

В подвале документа Инвентаризационная опись по объектам НФА (ф. 0510466) в соответствующих реквизитах следует заполнить ответственного исполнителя бухгалтерской службы и ответственного исполнителя инвентаризационной комиссии.

До начала инвентаризации ответственное лицо (ответственное лицо группы лиц) формирует и подписывает простой ЭП расписку, являющуюся неотъемлемым приложением Инвентаризационной описи (сличительной ведомости) по объектам нефинансовых активов (ф. 0510466), о том, что к началу проведения инвентаризации все документы, относящиеся к приходу и расходу нефинансовых активов, сданы в бухгалтерию, неоприходованных или списанных нефинансовых активов не имеется.

Для формирования документа Расписка инвентаризации следует записать документ Инвентаризационная опись по объектам НФА (ф. 0510466) по кнопке Записать и нажать на гиперссылку Создать расписку в шапке документа. При этом откроется окно созданного документа Расписка инвентаризации, который необходимо сохранить и провести.

Важно. Заполнение расписки ответственным лицом (ответственным лицом группы лиц) является обязательным условием для продолжения заполнения описи, поэтому только после проведения документа Расписка инвентаризации становится возможным заполнение закладок Раздел 1, Раздел 2.1, Раздел 2.2, Раздел 3 и Раздел 4 документа Инвентаризационная опись по объектам НФА (ф. 0510466).

Заполнение закладки "Раздел 1"

Раздел 1 "Сведения об объектах нефинансовых активов по данным бухгалтерского учета" заполняется на закладке Раздел 1 по кнопке Заполнить (Заполнить по данным бух. учета). Раздел 1 инвентаризационной описи заполняется остатками нефинансовых активов и имущества, учтенного на соответствующих забалансовых счетах на конец предыдущего дня от даты, по состоянию на которую проводится инвентаризация, указанной в шапке документа в реквизите По состоянию на.

Например, если инвентаризация проводится:
- при смене ответственного лица, то реквизит По состоянию на будет заполнен датой, соответствующей дате Инвентаризация по состоянию на, указанной в документе Решение о проведении инвентаризации (ф. 0510439), а остатки по счетам будут взяты на конец предшествующего дня;
- перед составлением годовой отчетности за 2025 финансовый год, то реквизит По состоянию на будет заполнен датой 01.01.2026, а остатки по счетам будут взяты на конец дня 31.12.2025.

В результате автозаполнения в табличной части закладки Раздел 1 будут заполнены реквизиты:

  • N – код строки;
  • НФА – наименование объекта учета. Указывается реквизит Наименование элемента справочника Основные средства, НМА, НПА или Номенклатура в зависимости от вида учитываемого имущества;
  • Инвентарный номер – указывается инвентарный номер, присвоенный элементу справочника Основные средства, НМА, НПА. В отношении элементов справочника Номенклатура выводится значение "не применяется". Если инвентарный номер не присвоен, тогда в печатной форме описи указывается Код соответствующего элемента справочника;
  • Ед. изм. – указывается единица измерения, присвоенная соответствующему элементу справочника Номенклатура, для элемента справочника Основные средства, НМА, НПА единица измерения всегда указывается как "штука";
  • Место инвентаризации – указывается значение, которое было определено в соответствующем поле документа Решение о проведении инвентаризации (ф. 0510439) (значение элемента справочника Места хранения или текстовая строка);
  • Счет, КПС, КФО – соответственно, на которых имеются остатки имущества на дату инвентаризации;
  • Количество – остаток на дату инвентаризации в количественном выражении;
  • Балансовая стоимость – балансовая стоимость имущества на дату инвентаризации.

Ручная корректировка табличной части закладки Раздел 1 не предусмотрена.

Примечание. Для проведения инвентаризации с помощью ТСД необходимо после заполнения табличной части закладки Раздел 1 по данным бухгалтерского учета выгрузить эти данные в ТСД. Для этого следует подключить к компьютеру ТСД, нажать кнопку Заполнить и выбрать в меню пункт Выгрузить данные в ТСД.

Раздел 1 формируется и подписывается ответственным исполнителем бухгалтерской службы простой ЭП.

Заполнение закладки "Раздел 2.1"

Подраздел 2.1 "Фактическое наличие" Раздела 2 "Сведения об объектах нефинансовых активов по данным инвентаризационной комиссии" заполняется ответственным исполнителем инвентаризационной комиссии на закладке Раздел 2.1. По кнопке Заполнить (Заполнить по данным раздела 1 (без количества)/Заполнить по данным раздела 1 (с количеством) таблица может быть заполнена автоматически по данным Раздела 1.

В результате автозаполнения в табличной части закладки Раздел 2.1 по данным соответствующих одноименных реквизитов будут заполнены реквизиты: N, НФА, Инвентарный номер, Ед. изм., Место инвентаризации, Количество.

Примечание. При проведении инвентаризации с помощью ТСД необходимо после сканирования штрих-кодов у всех объектов НФА, подлежащих инвентаризации, подключить ТСД к компьютеру, нажать на кнопку Заполнить и выбрать в меню пункт Загрузить данные из ТСД. В результате графа документа Количество будет заполнена.

После автозаполнения табличной части Раздела 2.1 в графе Количество следует проверить и, в случае отклонений, указать вручную информацию о фактическом наличии соответствующих объектов НФА.

При обнаружении излишков которые не имели остатков на дату Инвентаризация по состоянию на либо тех, которые никогда не находили своего отражения в данных бухгалтерского (бюджетного) учета учреждения и соответственно не нашли своего отражения в Разделе 1 в табличную часть Раздела 2.1 с помощью кнопки Добавить можно добавить строки с информацией о выявленных излишках нефинансовых активов.

Далее следует вручную заполнить реквизиты Статус объекта, Целевая функция актива и Примечание. Данные реквизиты можно заполнить группой, для этого следует выделить нужные строки и нажать кнопку Заполнить – Групповое заполнение строк. Реквизиты заполняются следующим образом:

  • Статус объекта – выбирается одно из значений элемента справочника Статусы объектов для инвентаризации;
  • Целевая функция актива – выбирается одно из значений элемента справочника Целевые функции активов для инвентаризации;
  • Примечание – вручную текстом указывается информация, не нашедшая отражения в предыдущих графах.

Примечание. Для указания разных статусов и целевых функций следует выделить строку (несколько строк) с нужными НФА и нажать кнопку Разбить строку. В открывшемся окне Разбивка строки раздела 2.1 в табличной части Фрагменты строки после разбивки с помощью кнопки Добавить можно указать количество и установить разные статусы. В результате выделенная строка разделится на две, реквизит N заполнится по порядку.

Заполнение закладки "Раздел 2.2"

Подраздел 2.2 "Результат инвентаризации" Раздела 2 "Сведения об объектах нефинансовых активов по данным инвентаризационной комиссии" заполняется ответственным исполнителем инвентаризационной комиссии.

На закладке Раздел 2.2 документа по кнопке Заполнить недостачу и излишки следует заполнить данные о выявленных излишках и недостачах.

В результате автозаполнения в табличной части закладки Раздел 2.2 по данным соответствующих одноименных реквизитов табличной части закладки Раздел 2.1 будут заполнены реквизиты: НФА, Инвентарный номер, Ед. изм., Место инвентаризации.

Реквизит N в Разделе 2.2 является служебным и указывает порядковый номер строки, в печатной форме Инвентаризационной описи (сличительной ведомости) по объектам нефинансовых активов (ф. 0510466) не отражается.

Реквизит Код строки заполняется по данным реквизита N табличной части закладки Раздел 2.1.

Также автоматически рассчитываются и автозаполняются реквизиты:

  • Недостача (Количество, Сумма) – количество и сумма недостачи (Количество, указанное на закладке Раздел 1 минус Количество, указанное на закладке Раздел 2.1, сумма рассчитывается автоматически согласно учетной стоимости);
  • Излишки, количество – количество в отношении объектов инвентаризации, по которым выявлены излишки (Количество, указанное на закладке Раздел 2.1 минус Количество, указанное на закладке Раздел 1).

Ручная корректировка автозаполненных реквизитов закладки Раздел 2.2 не предусмотрена.

Регистрация признаков несоответствия условиям актива или обесценения

Для переноса строк, по которым не выявлены излишки и недостачи, но при этом обнаружены признаки несоответствия условиям актива и (или) признаки обесценения на закладке Раздел 2.1 следует нажать кнопку Скопировать в раздел 2.2. После этого в Разделе 2.2 появляются соответствующие строки, в которых в реквизитах Количество и Сумма граф Не соответствует условиям актива или Признаки обесценения следует вручную указать количество активов, несоответствующих критериям, либо с признаками обесценения.

Раздел 2 подписывается членами инвентаризационной комиссии простой ЭП, председателем комиссии (лицом, уполномоченным председателем инвентаризационной комиссии) - ЭЦП.

Заполнение закладки "Раздел 3"

Раздел 3 "Объяснение причин расхождений" заполняется в случае если в ходе инвентаризации установлены расхождения (излишки и (или) недостача) по имуществу на закладке Раздел 3 по кнопке Заполнить по данным раздела 2.2.

В результате автозаполнения в табличной части закладки Раздел 3 по данным соответствующих одноименных реквизитов табличной части закладки Раздел 2.2 будут заполнены реквизиты: Код строки, НФА, Инвентарный номер, Ед. изм., Место инвентаризации, Количество и Сумма графы Недостача, всего, Излишки количество, всего.

Реквизит N в Разделе 3 является служебным и указывает порядковый номер строки, в печатной форме Инвентаризационной описи (сличительной ведомости) по объектам нефинансовых активов (ф. 0510466) не отражается.

Первоначально все расхождения (излишки и (или) недостачи) автоматически заполняются в графе не подтверждено (Излишки количество/Недостача).

Если недостача или излишки, выявленные при инвентаризации, подтверждены первичными учетными документами, то в зависимости от выявленных расхождений следует вручную заполнить реквизиты Количество, Сумма в графе Недостача, подтверждено или реквизиты Цена, Количество, Сумма в графе Излишки, подтверждено. При этом, в графе Первичный учетный документ в реквизитах Наименование, Номер, Дата следует указать реквизиты первичного учетного документа.

После окончательного указания излишков/недостач, подтвержденных и не подтвержденных первичными учетными документами, текстом нужно вручную указать Объяснение причин расхождений.

В случае отсутствия расхождений (излишков и (или) недостачи) табличная часть закладки Раздел 3 и перечень приложений к ней не формируются и в копии электронной Инвентаризационной описи (сличительной ведомости) по объектам нефинансовых активов (ф. 0510466) на бумажном носителе не отображается.

В случае если недостача и (или) излишки объясняются наличием первичных учетных документов, подтверждающих поступление или выбытие объектов нефинансовых активов и не переданных в бухгалтерскую службу на момент инвентаризации, такие первичные учетные документы прилагаются к объяснению причин расхождений в виде скан-копии в формате pdf ответственным лицом (ответственным лицом группы лиц). Для этого на панели навигации документа описи следует перейти по гиперссылке Присоединенные Файлы и в открывшемся окне нажать кнопку Добавить - Файл с компьютера.

Чтобы в Приложении отражалось наименование документа, следует перейти в присоединенные файлы, нажать на правую кнопку мыши и выбрать команду Открыть карточку, в поле "Описание" заполнить наименование файла.

Приложенные таким способом файлы отразятся в печатной форме Инвентаризационная опись (сличительная ведомость) по объектам нефинансовых активов (ф. 0510466) в качестве приложений (в строке "Приложение N __") к Разделу 3.

Раздел 3 подписывается ответственным лицом (ответственным лицом группы лиц) с применением простой ЭП.

Заполнение закладки "Раздел 4"

Раздел 4 "Заключение инвентаризационной комиссии" заполняется ответственным исполнителем инвентаризационной комиссии на закладке Раздел 4 по кнопке Заполнить по данным разделов 2.2 и 3.

Табличная часть закладки Раздел 4 автозаполняется одноименными реквизитами: Код строки, НФА, Инвентарный номер, Ед. Изм., Место инвентаризации, Недостача, не подтверждено (Количество, Сумма), Излишки количество, не подтверждено, Не соответствует условиям актива (Количество, Сумма), Признаки обесценения (Количество, Сумма), заполненными в табличной части на закладках Раздел 2.2, Раздел 3, данные не корректируются.

Реквизит N в Разделе 4 является служебным и указывает порядковый номер строки, в печатной форме Инвентаризационной описи (сличительной ведомости) по объектам нефинансовых активов (ф. 0510466) не отражается.

Реквизит Заключение комиссии следует заполнить заключением комиссии по каждой строке. Сделать это можно произвольным текстом или одним из значений элемента справочника Заключения комиссии по инвентаризационным описям.

Примечание. При отсутствии излишков и (или) недостач, не подтвержденных первичными учетными документами, а также имущества, не соответствующего критериям активов и имеющего признаки обесценения, во всех реквизитах табличной части закладки Раздел 4 отражаются нули. Поле Заключение комиссии автозаполнится значением "Отклонения не выявлены. Объекты, не соответствующие условиям актива или имеющие признаки обесценения, не установлены. Принять результаты инвентаризации: фактическое наличие объектов инвентаризации соответствует учетным данным" из справочника Заключения комиссии по инвентаризационным описям.

Реквизит Статус объяснения следует заполнить статусом объяснения причин по каждому выявленному расхождению путем выбора из предопределенного списка:

  • 0 – объяснение ответственного лица не требуется. Автозаполняется при отсутствии излишков и (или) недостачи;
  • 1 - не принято – объяснение ответственного лица не принято;
  • 2 - принято – объяснение ответственного лица принято.

Раздел 4 подписывается членами инвентаризационной комиссии простой ЭП, председателем инвентаризационной комиссии (лицом, уполномоченным председателем комиссии) - ЭЦП.

Закладка "Комиссия"

Закладка Комиссия в результате выбора в шапке документа Решение о проведении инвентаризации (ф. 0510439) заполняется автоматически членами инвентаризационной комиссии. После этого в таблице можно отметить отсутствующих членов комиссии и указать причину их отсутствия.

Примечание. В случаях если в документе Решение о проведении инвентаризации (ф. 0510439) назначены рабочие инвентаризационные комиссии, предварительно заполненные из справочника Комиссии, в котором для членов рабочих комиссий, выступающих в качестве уполномоченных лиц, установлены соответствующие статусы Уполномоченное председателем лицо, то на закладке Комиссия документа Инвентаризационная опись по объектам НФА (ф. 0510466) в качестве подписантов заполняются только уполномоченное председателем лицо и члены этой рабочей комиссии.

Дополнительные возможности

После проведения документа с помощью кнопки Ввести документы по отклонениям формируются соответствующие документы по оприходованию излишков и списанию недостач, не подтвержденных первичными учетными документами, а также переоценке и (или) обесценению имущества.

По виду отклонения Излишки:

  • по ОС, НМА, НПА, правам пользования НМА (счета 101.00, 102.00, 103.00, 111.60, заб. счет 21) – документ Принятие к учету ОС, НМА, НПА;
  • по МЗ и БА (счета 105.00, 113.00) – документ Поступление МЗ;
  • по ИК (счет 108.00) – документы Принятие к учету ОС, НМА, НПА (Имущество казны), Поступление МЗ (Имущество казны).

По виду отклонения Не соответствует условиям актива:

  • по ОС, НМА (счета 101.00, 102.00, заб. счет 21) – документ Решение о прекращении признания активом;
  • по МЗ (счет 105.00) – документ Решение о прекращении признания активом (материальные запасы);
  • по ИК (счет 108.00) – документы Решение о прекращении признания активом (имущество казны), Решение о прекращении признания активом (материальные запасы) (Имущество казны).

По виду отклонения Недостача:

  • по ОС, НМА, НПА, правам пользования НМА (счета 101.00, 102.00, 103.00, 111.60, заб. счет 01, 02, 21 субконто «Основные средства») – документы Списание объектов ОС, НМА, НПА, Списание транспорта и Списание библиотечного фонда;
  • по МЗ и БА (счета 105.00, 113.00) – документ Акт списания материалов;
  • по ИК (счет 108.00, заб. счет 01, 02 субконто «Основные средства») – документы Списание объектов ОС, НМА, НПА (Имущество казны), Списание транспорта (Имущество казны), Акт списания материалов (Имущество казны).

По виду отклонения Изменение стоимости по ОС, НПА (счета 101.00, 103.00) создается документ Переоценка ОС, НПА.

По виду отклонения Признаки обесценения по ОС, НМА, НПА, правам пользования НМА (счета 101.00, 102.00, 103.00 (кроме 103.11), 111.60) создается документ Обесценение ОС, НМА, НПА, для земельных участков на счете 103.11 создается документ Переоценка ОС, НПА.
