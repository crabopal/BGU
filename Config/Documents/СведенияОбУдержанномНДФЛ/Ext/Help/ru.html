Документ "Сведения об удержанном НДФЛ"

Сведения из документа Сведения об удержанном НДФЛ могут быть использованы для заполнения документов Уведомление об исчисленных суммах налогов, Распределение ЕНП.

Документ Сведения об удержанном НДФЛ загружается из программы "1С:Зарплата и кадры государственного учреждения 8" (ред. 3) либо иной программы, используемой для расчета заработной платы. Документ не формирует проводок по бухгалтерским счетам, содержит информацию об удержанном НДФЛ из документа Отражение удержанного НДФЛ в бухучете программы "1С:ЗГУ 8" (ред.3).

Работа со списком документов

Список документов вида Сведения об удержанном НДФЛ можно открыть с помощью команды Сведения об удержанном НДФЛ меню функций раздела Учет и отчетность в группе Заработная плата.

Создание нового документа

Документ формируется автоматически при загрузке данных из программы "1С:Зарплата и кадры государственного учреждения 8" (ред. 3) либо иной программы, используемой для расчета заработной платы.
Для ввода нового документа вручную можно нажать на кнопку Создать командной панели списка Сведения об удержанном НДФЛ.

Работа с документом

Период сдачи отчета – месяц, за который подаются данные в налоговый орган.

Дата – дата формирования документа.

Организация – учреждение, от имени которого сформирован документ.

Реквизиты табличной части:

Вид операции по зарплате – определяется автоматически по КБК налога при загрузке из "1С:ЗГУ 8" (ред.3). Используется в алгоритмах подбора настройки статьи финансирования для заполнения значений ИФО, КФО, КПС документа.

Статья финансирования (зарплата) – элемент справочника Статьи финансирования (зарплата).

КБК – код бюджетной классификации для уплаты удержанного НДФЛ.

Регистрация в налоговом органе – регистрация, соответствующая указанному коду налогового органа, КПП, коду по ОКТМО.

Код, КПП, Код по ОКМО – код налогового органа, КПП и код по ОКТМО предоставления расчета.

Сумма – сумма налога на доходы физических лиц, подлежащая перечислению.

Дата удержания – по дате удержания определяется отчетный период при заполнении документа Уведомление об исчисленных суммах налога.

Срок уплаты – срок уплаты, заполняется при загрузке документа из программы "1С:ЗГУ 8" (ред.3).

ИФО – источник финансового обеспечения для уплаты налога. Определяется по настройкам статьи финансирования при загрузке из "1С:ЗГУ 8".

Подразделение – используется, если требуется учет по подразделениям на счете 303.01.

Примечание. Загрузка подразделения из программы "1С:ЗГУ 8" (ред.3) не предусмотрена.

КФО, КПС, КЭК – коды классификации расходов бюджета для уплаты налога. КФО и КПС определяются по настройкам статьи финансирования при загрузке из "1С:ЗГУ 8", КЭК переносится непосредственно из документа "1С:ЗГУ 8".

Счет – счет и аналитика учета расчетов по налогу на доходы физических лиц. Заполняется при загрузке документа из программы "1С:ЗГУ 8" (ред.3) согласно настройкам Способы отражения в учете (зарплата). Если не заполнено, для расчетов используется счет 303.01. Используется при заполнении документа Распределение ЕНП.

При проведении документа формируются записи в регистр накопления Сведения об удержанном НДФЛ.

Дополнительные возможности

На основании документа Сведения об удержанном НДФЛ можно ввести документ Уведомление об исчисленных суммах налога, Распределение ЕНП.
