Документ "Инвентаризация государственного долга по кредитам и гарантиям"

Документ Инвентаризация государственного долга по кредитам и гарантиям предназначен для формирования регистра бухгалтерского учета Инвентаризационная опись состояния государственного долга Российской Федерации по полученным кредитам и предоставленным гарантиям (ф. 0504085).

Работа со списком документов

Список документов Инвентаризация государственного долга по кредитам и гарантиям можно открыть с помощью команды Инвентаризация госдолга по кредитам и гарантиям меню функций раздела Планирование и санкционирование или раздела Инвентаризация.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Инвентаризация государственного долга по кредитам и гарантиям.

Заполнение реквизитов документа

Заполнение реквизитов документа выполняется аналогично заполнению реквизитов документа Инвентаризация кредитов и займов.

Печать

Чтобы распечатать Инвентаризационную опись состояния государственного долга Российской Федерации по полученным кредитам и предоставленным гарантиям (ф. 0504085) ее необходимо предварительно записать с помощью кнопки Записать командной панели формы документа.

Для формирования печатной формы ведомости нужно нажать кнопку Печать.
