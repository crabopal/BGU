Документ "Отчет комиссионера"

Документ Отчет комиссионера предназначен для отражения отчета о продажах товаров и услуг, полученного от комиссионера (агента) и услуги, оказанной комиссионером (комиссионного вознаграждения).

Документ позволяет оформить операцию "Реализация товаров/услуг через комиссионера (агента)".

После заполнения и записи документа можно сформировать печатную форму Отчет комиссионера.

Также после заполнения реквизитов бухгалтерской операции и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида Отчет комиссионера можно открыть с помощью команды Отчет комиссионера меню функций раздела Материальные запасы.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Отчет комиссионера с пиктограммой «плюса» из командной панели списка Отчеты комиссионеров и выбрать Оптовые продажи или Розничные продажи.

Закладка "Главное"

На закладке Главное заполняются реквизиты:

  • Вид операции – устанавливается автоматически от выбора операции при создании документа;
  • Контрагент – комиссионер, от которого был получен Отчет комитента по продажам товара;
  • Договор – договор с комиссионером;
  • МОЛ/Место хранения – центр материальной ответственности на счете 105.ХХ;
  • КФО - код финансового обеспечения;
  • Первичный документ – заполняется данными первичного документа;
  • Счет учета переданных МЗ – заполняется автоматически;
  • Флаг Выписывать счета-фактуры сводно, если планируется подготовка сводных счетов-фактур комитента;
  • реквизиты Реализация и Возвраты заполняются рассчитанными данными по счетам-фактурам, выставленным комиссионером и представленным в отчете;
  • реквизиты группы Комиссионное вознаграждение заполняются из одноименной группы карточки договора с комитентом (элемента справочника Договоры и иные основания возникновения обязательств);
  • % НДС – заполняется по умолчанию ставкой 20%;
  • Услуга по вознаграждению за комиссию – необходимо заполнить услугой по вознаграждению за реализацию товара;
  • реквизиты КПС и КЭК относятся к аналитике взаиморасчетов по комиссионному вознаграждению.

Закладка "Реализация"

На закладке Реализация указывается список реализованных товаров и услуг по покупателям.

Закладка разделена на 2 взаимосвязанные таблицы. По строке покупателя из верхней таблицы реализован отбор в нижней.

Верхняя таблица содержит информацию о покупателях комиссионных товаров и счетах-фактурах, выставленных комиссионером.

Покупатель – покупатель из отчета комиссионера.

Реквизиты Всего и НДС автоматически рассчитываются по записям табличной части Товары и недоступны для редактирования.

Если есть данные по счету-фактуре от комиссионера, то необходимо включить флаг Счет-фактура и заполнить реквизиты Номер и Дата.

Реквизит Выставленный комиссионеру выводится справочно и отражает информацию по сформированному в программе счету-фактуре по этому покупателю.

Нижняя таблица заполняется данными по проданной номенклатуре. Реализован также подбор номенклатуры по счету ТПР. После подбора номенклатуры заполняются данные табличной части.

В реквизитах Цена, Сумма, Цена передачи и Сумма передачи указываются данные согласно суммам номенклатуры на счете ТПР. Реквизит Партия заполняется значением Доп. аналитики из подбора. Остальные реквизиты рассчитываются согласно данным документа. В случае необходимости данные в реквизитах можно корректировать.

Примечание. В случае отражения отчета по нескольким покупателям нижняя таблица заполняется для каждого покупателя отдельно.

Закладка "Возвраты"

На закладке Возвраты указывается список возвращенных товаров и услуг по покупателям.

Закладка разделена на 2 взаимосвязанные таблицы. По строке покупателя из верхней таблицы реализован отбор во второй.

Верхняя таблица содержит информацию о покупателях комиссионных товаров и счетах-фактурах, выставленных комиссионером.

Покупатель – покупатель из отчета комиссионера.

Реквизиты Всего и НДС автоматически рассчитываются по записям табличной части Товары и недоступны для редактирования;

Если есть данные по счету-фактуре от комиссионера, то необходимо включить флаг Корректировочный счет-фактура и заполнить реквизиты Номер и Дата.

Реквизит Выставленный комиссионеру выводится справочно и отражает информацию по сформированному в программе счету-фактуре по этому покупателю.

Нижняя таблица заполняется данными по возвращенной номенклатуре. Реализован также подбор номенклатуры по документу реализации. После подбора номенклатуры заполняются данные табличной части:

  • Номенклатура – товар для отражения возврата;
  • Ед. Изм. – единица измерения товара;
  • Счет учета – счет учета товара;
  • КПС – КПС товара;
  • КЭК – КЭК товара;
  • Количество – количество возвращенного товара;
  • Цена – цена возвращенного товара;
  • Сумма – на какую сумму возвращен товар.
  • Партия – партия возвращенного товара;
  • Цена передачи – цена по которой был передан товар;
  • Цена оприходования – себестоимость единицы товара;
  • % НДС – НДС товара;
  • НДС – сумма НДС;
  • Документ реализации – документ реализации по которому был возврат;
  • Сумма вознаграждения – сумма вознаграждения рассчитанная по этому товару в документе реализации;
  • НДС вознаграждения – сумма НДС вознаграждения рассчитанная по этому товару в документе реализации.

Примечание. В случае отражения возврата по нескольким покупателям нижняя таблица заполняется для каждого покупателя отдельно.

Закладка "Денежные средства"

На закладке Денежные средства указывается информация о денежных средствах, которые получены от покупателя за товары и услуги комиссионера (агента). Информация о денежных средствах заполняется пользователем вручную. При этом возможны три варианта платежей, которые заполняются в поле Вид отчета по платежам:

  • Аванс – сумма, которую перечислил покупатель в качестве аванса за комиссионные товары комитента.
  • Зачет аванса – сумма, на которую был отгружен комиссионный товар покупателю по полученному ранее авансу.
  • Оплата – сумма оплаты, которую покупатель заплатил за ранее отгруженные ему товары комитента.

Закладка "Бухгалтерская операция"

Типовая операция – выбирается из списка Типовые операции:

Реализация товаров/услуг через комиссионера (агента).

Для данной типовой операции необходимо заполнить реквизиты:

В группе Расчеты:

  • Счет расчетов – устанавливается автоматически;

В группе Реализация товаров, работ, услуг (БУ):

  • КПС – для отражения;
  • Счет – устанавливается автоматически;
  • КЭК – код экономической классификации. Выбирается из фрагмента справочника КЭК, содержащего только актуальные для данной операции значения КЭК.

В группе Реализация товаров, работ, услуг (НУ):

  • Вид деятельности НУ;
  • Счет доходов (НУ) – по умолчанию установлено значение авто. При установке этого значения счет доходов подбреется автоматически. Реквизит доступен для редактирования.

В группе Комиссионное вознаграждение (БУ):

  • Расходы по комиссионному вознаграждению – счет для отражения расходов по комиссионному вознаграждению. При выборе счета ниже будут автоматически подставлены реквизиты для заполнения его субконто.

В группе Комиссионное вознаграждение (НУ):

  • Расходы по комиссионному вознаграждению – счет для отражения расходов в целях налогового учета.

В группе Учет НДС:

  • Счет учета НДС – устанавливается автоматически, и доступен для редактирования;
  • Счет НДС к распределению – устанавливается автоматически, и доступен для редактирования.

В группе Денежное обязательство:

  • флаг Принятие денежного обязательства – устанавливается, если необходимо отразить проводки по принятию денежных обязательств;
  • Раздел л/с – указывается раздел лицевого счета, заполняется только КУ для бюджетных средств (КФО 1).

Дополнительные возможности

На основании документа Отчет комиссионера можно ввести документы Счет-фактура выданный, Счет-фактура полученный, Регистрация строки книги продаж.
