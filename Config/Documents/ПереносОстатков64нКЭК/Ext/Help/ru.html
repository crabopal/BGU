Документ «Переход на применение приказа 64н (КЭК)»

Документ предназначен для переноса остатков на начало 2018 года и оборотов по счетам с необоротными КЭК с 01.01.2018 г. по дату перехода на применение приказа 64н от 31.03.2018 г. Данные будут переноситься со старых КЭК на новые согласно настроечной таблице, показанной на форме документа.

Счета, с которых будут обрабатываться обработкой: 109.61, 109.71, 109.81, 210.02, 210.04, 304.04, 304.05, 401.10, 401.20, 401.40, 401.50, 401.60. Счета 5-го раздела обрабатываться не будут.

Документ содержит две операции:

  • Перенос остатков. Предназначена для переноса остатков по счетам с необоротными КЭК на начало 2018 г. Дату переноса остатков при этой операции, следует устанавливать 31.12.2017 г.
  • Перенос оборотов. Предназначена для переноса оборотов по счетам с необоротными КЭК за период с 01.01.2018 по дату начала применения приказа 64н.

Под переносом оборотов понимается:

Сторнирование оборотов по счетам со старыми КЭК и формирование оборотов по счетам с новым КЭК.

Например:

Была операция

Д-т 401.10.130, К-т 109.61.290 – в этой операции устарел КЭК 130, и он будет заменен на КЭК 131, а также КЭК 290, и он будет перенесен на КЭК 296.

Документ сформирует следующие проводки:

- Д-т 401.10.130, К-т 109.61.290  СТОРНО старой операции.

- Д-т 401.10.131, К-т 109.61.291  новая операция с новым КЭК.

Все корректирующие проводки будут сформированы на дату документа «Переход на применение приказа 64н (КЭК)».

Правила переноса остатков и оборотов

Правила переноса остатков и оборотов приведены в таблице на форме документа.

Таблица содержит колонки со следующим смыслом:

Колонка с КЭК содержит КЭК-источник с которого будут переноситься остатки или корректироваться обороты на КЭК, указанный в колонке на КЭК.

Если в колонке по КФО указан конкретный КФО, то указанный в строке перенос будет выполнен только в рамках этого КФО.

Перенос документом оборотов выполняется за период, указанный в реквизитах Перенос оборотов за период с… по…. Наличие этих реквизитов дает возможность выполнять перенос по частям. Каждую часть переносить за короткий промежуток времени, например, за один день. Это может быть востребовано при большом объеме базы, когда единовременный перенос за весь период с 01.01.2018 по дату перехода на применение 64н, может оказаться очень длительным.

По кнопке Настроить открывается форма редактирования макета с настройками. Настройка применяется для всех документов "Переход на применение приказа 64н (КЭК)". Если есть проведеные документы, то после изменения настроек их необходимо перепровести. При изменении настроек так же необходимо внести соответствующие изменения в настройки документа Переход на применение приказа 64н (Расчеты).
