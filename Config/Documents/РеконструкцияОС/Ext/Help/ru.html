Документ "Реконструкция, модернизация ОС, НМА, НПА"

Документ предназначен для изменения первоначальной стоимости ОС в связи с достройкой, дооборудованием, реконструкцией или модернизацией соответствующих объектов (далее реконструкцией), изменения стоимости нематериальных активов при проведении работ по их модернизации, отражения операций отнесения произведенных вложений в улучшение объектов непроизведенных активов, неотделимых от них.

Также документ предназначен для отражения данных по ремонту объектов, не приводящих к изменению их стоимости.

После заполнения и записи документа можно сформировать печатную форму Акт приема-сдачи отремонтированных, реконструированных и модернизированных объектов основных средств (форма по ОКУД 0504103).

Также после заполнения реквизитов бухгалтерской операции и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида Реконструкция, модернизация ОС, НМА, НПА можно открыть с помощью команды Реконструкция, модернизация ОС, НМА, НПА меню функций раздела ОС, НМА, НПА.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Реконструкция, модернизация ОС, НМА, НПА.

Заполнение реквизитов шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Реквизит Вид операции может принимать значения:

  • Ремонт ОС;
  • Модернизация, реконструкция, достройка ОС;
  • Модернизация, дополнительные вложения в НМА;
  • Модернизация, улучшение объектов НПА.

Значение реквизита Вид операции определяет состав реквизитов на закладке Стоимость вложений, а также задает способ заполнения реквизита Сумма ремонта (реконструкции) группы Стоимость работ.

КФО – код финансового обеспечения. Выбирается из списка.
КПС – классификационный признак счета. Выбирается из справочника КПС.
Режим – переключатель, позволяющий выбрать режим ввода данных:

  • Один объект – документ создан для одного объекта ОС, НМА или НПА. Информация об объекте в данном режиме вводится в поля на закладке Основное средство, НМА, НПА;
  • Несколько объектов – документ создан для нескольких объектов ОС, НМА или НПА. Информация об объектах в данном режиме вводится в табличную часть на закладке Основные средства, НМА, НПА.

Примечание. Расчет числовых показателей в табличной части выполняется с помощью кнопки Рассчитать.

Режим документа только для регистрации акта приема-сдачи

Только регистрация акта приема-сдачи – флажок позволяет оформить документ без формирования проводок и движений по регистрам. При включенном флажке документ используется только регистрации входящего акта выполненных работ подрядной организации и формирования Акта приема-сдачи отремонтированных работ (ф. 0504103).

Для формирования проводок и движений по регистрам, в данном случае, на основании документа следует ввести документ Решение о признании объектов НФА, который и сформирует необходимые движения по реконструкции, модернизации.

Примечание. Такой режим работы документа реализован для исполнения требований писем Минфина России № 02-07-07/117981 от 1 декабря 2022 г. "О Методических рекомендациях по переходу на применение с 2023 года унифицированных форм электронных первичных документов" и № 02-06-09/73731 от 04.08.2023.

Если флажок Только регистрация акта приема-сдачи включен реквизиты, которые нужны только для формирования движений, меняют поведение:

  • реквизиты налогового учета и закладка Налоговый учет становятся невидимыми;
  • реквизиты карточки капвложений становятся невидимыми;
  • нельзя выбрать типовую операцию на закладке Бухгалтерская операция.

Примечание. Работа документа с выключенным флажком Только регистрация акта приема-сдачи соответствует прежнему режиму работы документа, когда на основании входящего акта о проведенном ремонте от подрядной организации вводился документ Решение о признании объектов НФА, который не формировал движений, а на его основании вводился документ Реконструкция, модернизация ОС, НМА, НПА, который формировал движения.

Заполнение документа для вида операции "Ремонт ОС"

Рассмотрим заполнение документа в режиме Один объект при выбранном виде операции Ремонт ОС.

Примечание. Заполнение в режиме Несколько объектов производится аналогично, в табличной части закладки Основные средства, НМА, НПА.

Документ с операцией Ремонт ОС при проведении движений не формирует, если не включен флажок Сформировать движения по внутреннему перемещению.

Сформировать движения по внутреннему перемещению – флажок, при включении которого:

  • документ при проведении формирует движения по внутреннему перемещению;
  • на закладке Основное средство, НМА, НПА или табличной части (в зависимости от режима одиночный или множественный) становится виден реквизит МОЛ/Место хранения-получатель, на которого следует переместить объект, полученный из ремонта.

Примечание. Флажок Сформировать движения по внутреннему перемещению виден только для вида операции Ремонт ОС.

Закладка "Стоимость вложений"

Значения реквизитов группы Стоимость работ вводятся вручную

Сумма вложений в ремонт – полная стоимость работ по ремонту (реконструкции) объекта, включающая в том числе затраты на демонтаж и транспортировку;

Расшифровку суммы вложений в ремонт по КФО можно выполнить по гиперссылке Расшифровка затрат по КФО….

Примечание. Расшифровка затрат по КФО выводится в разд. 8 «Сведения о произведенном ремонте, достройке, реконструкции, модернизации», инвентарных карточек 0509215 и 0509216.

Сумма ремонта – стоимость работ по ремонту объекта;
Затраты на демонтаж – стоимость работ по демонтажу объекта ОС;
Затраты по транспортировке – стоимость транспортировки объекта.

Закладка "Основное средство, НМА, НПА"

Объект ОС, НМА, НПА – объект основного средства, в который производятся вложения. Выбирается из справочника Основные средства;

Инвентарный номер – инвентарный номер объекта ОС.

Значения реквизитов Счет учета и МОЛ/Место хранения заполняется автоматически по данным учета и выведены для справки.

Вид работы – вид выполненных работ. Вводится текстом.

Значения реквизитов групп Стоимость объекта и Срок полезного использования (в месяцах), также заполняются автоматически по данным учета и выведены для справки.

Заполнение документа для операций по модернизации ОС, НМА, НПА

Рассмотрим заполнение документа в режиме Один объект, если вид операции имеет одно из значений:

  • Модернизация, реконструкция, достройка ОС;
  • Модернизация, дополнительные вложения в НМА;
  • Модернизация, улучшение объектов НПА.

Примечание. Заполнение в режиме Несколько объектов производится аналогично, в табличной части закладки Основные средства, НМА, НПА.

Для перечисленных видов операции стоимость вложений формируется на субсчетах счета 106.00 "Вложения в нефинансовые активы" плана счетов.

Закладка "Стоимость вложений"

Реквизиты группы Капитальные вложения:

  • Объект вложений – объект капитальных вложений, на котором накоплены вложения в ОС, НМА, НПА. Выбирается из справочника Основные средства среди объектов, у которых реквизит Вид НФА имеет значение Основные средства, Нематериальные активы, Непроизведенные активы или Капитальные вложения. После выбора объекта вложений реквизиты Счет вложений и Сумма вложений заполняются автоматически.
  • Счет вложений – субсчет счета 106.00 плана счетов, на котором накоплена стоимость вложений.
  • Сумма вложений – суммовой остаток вложений, накопленных на дату документа на Счете вложений.

Расшифровку суммы вложений в ремонт по КФО можно выполнить по гиперссылке Расшифровка затрат по КФО….

Примечание. Расшифровка затрат по КФО выводится в разд. 8 «Сведения о произведенном ремонте, достройке, реконструкции, модернизации», инвентарных карточек 0509215 и 0509216.

Значения реквизитов группы Стоимость работ:

  • Сумма модернизации – общая стоимость работ по модернизации, включая затраты на демонтаж и транспортировку. Заполняется автоматически по кнопке Рассчитать сумму вложений;
  • Затраты на демонтаж – стоимость работ по демонтажу объекта ОС. Заполняется вручную;
  • Затраты по транспортировке – стоимость транспортировки объекта. Заполняется вручную.
  • Расшифровка вложений по ЦМО и КПС – табличная часть, где приводится расшифровка вложений по ЦМО, классификационным признакам, количеству и сумме. Заполняется автоматически по данным бухгалтерского учета.

Закладка "Основное средство, НМА, НПА"

Объект ОС, НМА, НПА – объект основного средства, в который производятся вложения. Выбирается из справочника Основные средства.

Инвентарный номер – инвентарный номер объекта ОС.

Счет учета и МОЛ/Место хранения - заполняется автоматически по данным учета и выводятся для справки.

Вид работы – вид проведенных работ. Вводится текстом.

Реквизиты группы Стоимость объекта:

Восстановительная, Остаточная – восстановительная и остаточная стоимость объектов. Рассчитываются по данным учета.

По окончании работ – стоимость рассчитывается как сумма восстановительной стоимости и суммы вложений.

Реквизиты группы Срок полезного использования (в месяцах):

После модернизации – новый полный срок полезного использования (эксплуатации) объекта ОС после модернизации. Значение реквизита заполняется вручную.

Примечание. Следует задавать не оставшийся, а полный срок полезного использования.

Оставшийся, Фактический срок эксплуатации – оставшийся срок полезного использования и фактический срок эксплуатации. Рассчитываются автоматически по данным учета.

Предполагаемый объем выработки – указывается планируемый объем за весь срок полезного использования объекта. Например, 200 000 (км) - для автомобиля или 100 000 (шт. деталей) - для станка.


Налоговый учет

Для организаций, которые в соответствии с учетной политикой являются плательщиками налога на прибыль, при отражении операций модернизации ОС, НМА, НПА по приносящей доход деятельности (КФО = 2) доступны реквизиты налогового учета.

Операции по капитальному ремонту ОС в налоговом учете по налогу на прибыль не отражаются.

Реквизиты НУ в группе Капитальные вложения:

  • Сумма вложений НУ – суммовой остаток вложений, накопленных на дату документа на счете налогового учета Н08 «Вложения во внеоборотные активы».

В группу Расходы, не включенные в сумму вложений НУ включены расходы, накопленные на счете налогового учета Н08 «Вложения во внеоборотные активы», которые не могут быть включены в сумму вложений и в налоговую базу по налогу на прибыль, в частности:

  • Не учитываемые при налогообложении – не учитываемые при налогообложении в соответствии с гл. 25 НК РФ, например, не соответствующие критериям в п.1 ст. 252 НК РФ.
  • Особый порядок налогообложения (ЕНВД и пр.) – по видам деятельности, для которых применяется отличный от общего порядок налогообложения (ЕНВД и пр.). В соответствии с п. 2 ст. 274 НК РФ налогоплательщик ведет раздельный учет таких расходов.

В группе Стоимость объекта рассчитываются восстановительная, остаточная стоимость и стоимость по окончании работ для целей налогового учете (НУ) рассчитываются аналогично бухгалтерскому учету.

В группе Срок полезного использования необходимо вручную заполнить срок эксплуатации объекта ОС после модернизации в реквизите После
модернизации (НУ). Оставшийся срок полезного использования для целей НУ вычисляется автоматически.

При использовании режима Один объект на закладке Налоговый учет можно указать параметры учета амортизационной премии:

  • Включить амортизационную премию в состав расходов – флажок, устанавливается, если необходимо включить в состав расходов отчетного (налогового) периода расходы на капитальные вложения в соответствии с п.9 ст. 258 НК РФ.
  • Сумма амортизационной премии - указывается размер амортизационной премии.
  • Счет учета затрат, Субконто счета затрат – счет и аналитика налогового учета расходов на капитальные вложения.

Расходы в виде капитальных вложений, предусмотренные п. 9 статьи 258 НК РФ, признаются в качестве косвенных расходов (абзац 2 п. 3 статьи НК РФ).
Поэтому Счет учета затрат выбирается из списка счетов налогового учета косвенных расходов.

Примечание. В режиме Несколько объектов закладка Налоговый учет не отображается. При этом параметры учета амортизационной премии указываются в строке таблицы Основные средства, НМА, НПА.

Закладка "Акт"

Группа Исполнитель работ:

Контрагент – исполнитель работ по капремонту или модернизации. Выбирается в справочнике Контрагенты.
Договор – выбирается из справочника Договоры и иные основания возникновения обязательств.

В группе Сроки проведения работ указываются даты начала и окончания работ по модернизации По договору и Фактически.

При необходимости ввода дополнительной информации по строке можно использовать реквизит Примечание.

Группа Первичный документ:

Вид – вид документа. Выбирается из справочника Виды первичных документов;
Номер и от (Дата) – номер и дата первичного документа.

Закладка "Комиссия"

Если в учреждении уже создана комиссия с необходимыми обязанностями, то ее можно выбрать из справочника Постоянно действующие комиссии, который можно открыть с помощью команды Выбрать из постоянно действующих комиссий.

После выбора комиссии реквизиты номер и дата Приказа о назначении комиссии, Председатель комиссии и Члены комиссии будут заполнены автоматически.

При необходимости реквизиты на закладке можно заполнить вручную. Для этого в группе реквизитов Приказ о назначении комиссии следует указать номер и дату соответствующего приказа.

Группа Председатель комиссии включает реквизиты Должность, Фамилия, Имя и Отчество.

Для заполнения реквизитов можно выбрать необходимого сотрудника из справочника Сотрудники или заполнить поля вручную.

Информация о должности, фамилии, имени и отчестве каждого члена комиссии вводится в табличную часть закладки.

Для удобного заполнения документа предназначена кнопка Подобрать, нажатие на которую позволяет вызвать форму подбора справочника Сотрудники.

В группе Сведения о проводимой инвентаризации заполняются реквизиты, необходимые для заполнения соответствующих полей печатной формы: Приказ №, дата (от), Период проведения с и по, Причина и Место проведения.

В группе реквизитов Дата подписания описи указываются даты подписания инвентаризационной описи ответственным лицом и комиссией.

Закладка "Бухгалтерская операция"

Реквизит Типовая операция имеет по умолчанию одно значение:

  • Реконструкция, модернизация, капитальный ремонт.

Для данной типовой операции необходимо заполнить реквизит:

  • Вид затрат – выбирается из справочника Виды затрат.
