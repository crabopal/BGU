Документ "Регистрация исполнения договоров"

Документ Регистрация исполнения договоров используется для ручной регистрации исполнения плана графика закупок, реализации по договорам с поставщиками и покупателями, в случае, если исполнение договора не было отражено автоматически документами поступления, реализации имущества, работ, услуг.

Работа со списком документов

Список документов вида Регистрация исполнения договоров можно открыть с помощью команды Регистрация исполнения договоров меню функций раздела Планирование и санкционирование.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Регистрация исполнения договоров.

Заполнение шапки документа

Вид договора – выбирается из списка:

  • С поставщиком – выбирается для отражения исполнения Плана-графика закупок.
  • С покупателем (в т.ч. субсидии на гос. задание) – выбирается для отражения исполнения Плана-графика реализации.

Заполнение табличной части

При заполнении таблицы для добавления новой строки можно использовать кнопку Добавить командной панели таблицы.
Исполнить до – крайняя запланированная дата отгрузки по договору. Позднее данной даты обязательство по отгрузке товаров, работ, услуг будет считаться просроченным.
Сумма – сумма отгрузки.
Контрагент – выбирается из справочника Контрагенты.
Договор – выбирается из справочника Договоры и иные основания возникновения обязательств. Выбор договора ограничен указанными реквизитами Организация, Контрагент и Вид договора.
Счет расчетов – выбирается из Плана счетов ЕПСБУ.
КФО – код финансового обеспечения, выбирается из списка.
КПС – классификационный признак счета, выбирается из справочника КПС.
КЭК – код экономической классификации, выбирается из справочника КЭК.

Проведение документа

При проведении документа производится запись информации в зависимости от вида договора в регистры накопления:

  • Исполнение обязательств поставщиками;
  • Исполнение договоров с покупателями.

После проведения документа можно посмотреть отражение исполнение плана графика закупок, реализации по договорам с контрагентом, сформировав отчет Контроль исполнения договоров из карточки договора с контрагентом по ссылке Исполнение договора формы Контроль исполнения договоров.
