Документ "Установка цен номенклатуры"

Для задания цены номенклатуры для каждого типа цен используется документ "Установка цен номенклатуры".

Работа со списком документов

Список документов Установка цен номенклатуры можно открыть с помощью команды Установка цен номенклатуры меню функций разделов Материальные запасы и Услуги, работы, производство.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Установка цен номенклатуры.

Заполнение документа

Примечание. Если информация о номенклатуре уже присутствует в справочнике, то для выбора позиций номенклатуры удобно использовать форму подбора, которая открывается с помощью кнопки Подобрать командной панели табличной части.

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

  • Тип цены – выбирается из справочника Типы цен номенклатуры;
  • Не проводить нулевые значения – если флаг установлен, то цена элемента номенклатуры, для которого в документе не указано новое значение цены (указана цена "0"), останется без изменения. Если флаг снят, то цена такого элемента номенклатуры после проведения документа будет равна "0".

Информация о номенклатуре и ценах вводится в табличную часть документа:

  • Номенклатура – наименование МЗ, выбирается из справочника Номенклатура;
  • Цена – значение вводится для тех элементов номенклатуры, для которых это необходимо.

Для установки цен номенклатуры следует после заполнения табличной части документа нажать на кнопку Провести и закрыть командной панели формы.
