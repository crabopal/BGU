Документ "Инвентаризационная опись состояния государственного (муниципального) долга по привлеченным кредитам (ф. 0510473)"

Документ Инвентаризационная опись состояния государственного (муниципального) долга по привлеченным кредитам (ф. 0510473) применяется для отражения результатов инвентаризации остатков долговых обязательств РФ, субъектов РФ и муниципальных образований в виде привлеченных кредитов.

Документ поддерживает инвентаризацию на следующих счетах учета:

  • 301.11 "Расчеты с бюджетами бюджетной системы Российской Федерации по привлеченным бюджетным кредитам в рублях";
  • 301.13 "Расчеты с иными кредиторами по государственному (муниципальному) долгу";
  • 301.21 "Расчеты с бюджетами бюджетной системы Российской Федерации по привлеченным бюджетным кредитам в рамках целевых иностранных кредитов (заимствований)";
  • 301.23 "Расчеты с иными кредиторами по государственному (муниципальному) долгу в рамках целевых иностранных кредитов (заимствований)";
  • 301.43 "Расчеты с иными кредиторами по государственному (муниципальному) долгу в иностранной валюте".

Документ Инвентаризационная опись состояния государственного (муниципального) долга по привлеченным кредитам (ф. 0510473) формируется ответственным исполнителем бухгалтерской службы на основании документа Решение о проведении инвентаризации (ф. 0510439) по месту проведения инвентаризации, а также по виду задолженности ("внутренний долг"; "внешний долг"), указанному в шапке документа Инвентаризационная опись состояния государственного (муниципального) долга по привлеченным кредитам (ф. 0510473).

После заполнения и записи документа можно сформировать печатную форму Инвентаризационной описи состояния государственного (муниципального) долга по привлеченным кредитам (ф. 0510473).

Заполнение реквизитов шапки и подвала документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Подразделение – выбирается из справочника Подразделения. Реквизит доступен, если включена настройка Учет по подразделениям (Раздел Главное - Настройки параметров учета - Общие настройки). Если реквизит заполнен и на счете учета долговых обязательств включен учет по подразделениям, Раздел 1 будет заполнен остатками в выбранном подразделении. Если реквизит не заполнен, Раздел 1 будет заполнен без отбора по Подразделению.

ИФО – выбирается из справочника Источники финансового обеспечения. Реквизит доступен для выбора, если включена настройка Учет по ИФО (Раздел Главное - Настройки параметров учета - Общие настройки). Ели реквизит не заполнен, Раздел 1 будет заполнен без отбора по ИФО.

Для начала работы с документом необходимо предварительно в шапке документа указать Вид задолженности путем выбора одного из предопределенных значений: "внутренний долг"; "внешний долг". Для отбора остатков в рублях используется значение "внутренний долг", для отбора остатков в иностранной валюте используется значение "внешний долг".

Также в шапке следует указать Решение о проведении инвентаризации (ф. 0510439), в открывшемся окне Выбор данных из Решения с учетом изменений необходимо отметить строки, по которым следует заполнить документ описи и нажать на кнопку Выбрать строки. После этого будет автоматически заполнена закладка Комиссия составом инвентаризационной комиссии, а также реквизиты в шапке документа Инвентаризационная опись состояния государственного (муниципального) долга по привлеченным кредитам (ф. 0510473), в группе реквизитов Сведения об инвентаризации из Решения:

  • По состоянию на – дата, по состоянию на которую проводится инвентаризация, в формате "ДД.ММ.ГГГГ";
  • Номер комиссии – номер инвентаризационной комиссии/рабочей комиссии в составе инвентаризационной;
  • Список счетов – список счетов, отобранных из документа Решение о проведении инвентаризации (ф. 0510439);
  • Период проведения с/по – даты начала и окончания инвентаризации в формате "ДД.ММ.ГГГГ";
  • Место проведения – адрес или место проведения инвентаризации.

Примечание. Редактирование вышеперечисленных реквизитов в документе описи не предусмотрено, так как они зафиксированы документом Решении о проведении инвентаризации (ф. 0510439), выбранном в шапке документа.

Ответственное лицо – ответственное лицо, осуществляющее взаимодействие с бухгалтерской службой в части передачи документов, необходимых для отражения в бухгалтерском учете состояния государственного (муниципального) долга по привлеченным кредитам, которым формируется и подписывается простой ЭП расписка, являющаяся неотъемлемым приложением к Инвентаризационной описи состояния государственного (муниципального) долга по привлеченным кредитам (ф. 0510473).

В подвале документа Инвентаризационная опись состояния государственного (муниципального) долга по привлеченным кредитам (ф. 0510473) в соответствующих реквизитах следует заполнить ответственного исполнителя бухгалтерской службы и ответственного исполнителя инвентаризационной комиссии.

До начала проведения инвентаризации ответственным лицом, осуществляющим взаимодействие с бухгалтерской службой в части передачи документов, необходимых для отражения в бухгалтерском учете состояния государственного (муниципального) долга по привлеченным кредитам, формируется и подписывается простой ЭП расписка, являющаяся неотъемлемым приложением к Инвентаризационной описи состояния государственного (муниципального) долга по привлеченным кредитам (ф. 0510473), что к началу проведения инвентаризации все документы по обязательствам государственного (муниципального) долга по привлеченным кредитам переданы в бухгалтерскую службу для отражения в бухгалтерском учете.

Документ Расписка инвентаризации формируется нажатием на гиперссылку:

  • Создать расписку, если документ Инвентаризационная опись состояния государственного (муниципального) долга по привлеченным кредитам (ф. 0510473) предварительно записан;
  • Создать расписку (документ будет записан), если документ не записан, при этом перед открытием окна представления формы документа Расписка инвентаризации документ будет записан автоматически.

При нажатии на гиперссылку откроется окно созданного документа Расписка инвентаризации, который следует сохранить и провести.

Заполнение расписки ответственным лицом, осуществляющим взаимодействие с бухгалтерской службой в части передачи документов, необходимых для отражения в бухгалтерском учете состояния государственного (муниципального) долга по привлеченным кредитам является обязательным условием для продолжения заполнения описи, поэтому только после проведения документа Расписка инвентаризации становится возможным заполнение закладок Раздел 1, Раздел 2, Раздел 3.1 и Раздел 3.2 документа Инвентаризационная опись состояния государственного (муниципального) долга по привлеченным кредитам (ф. 0510473).

Заполнение закладки "Раздел 1"

Раздел 1 "Сведения о состоянии государственного долга по привлеченным кредитам по данным бухгалтерского учета" заполняется ответственным исполнителем бухгалтерской службы на закладке Раздел 1 по кнопке Заполнить по данным учета. Документ описи будет заполнен остатками по счетам 301.11, 301.13, 301.21, 301.23, 301.43 с учетом отбора, указанного на закладке Отбор из решения.

Остатки определяются на конец предыдущего дня от даты, по состоянию на которую проводится инвентаризация, указанной в шапке документа в реквизите По состоянию на.

Например, если инвентаризация проводится перед составлением годовой отчетности за 2025 финансовый год, то реквизит По состоянию на будет заполнен датой 01.01.2026, а остатки по счетам 301.00 будут взяты на конец дня 31.12.2025.

В результате автозаполнения в табличной части закладки Раздел 1 будут заполнены реквизиты:

  • N – порядковый номер строки;
  • Код подраздела – код подраздела соответствующей группы кредиторов;
  • Группа кредиторов – элемент справочника Контрагенты вида "Учетная группа". Заполняется, если аналитический учет на счете 301.ХХ ведется по группам кредиторов (в карточке Контрагента указан Вид контрагента "Учетная группа");
  • Код строки – порядковый номер строки текущего подраздела по группе кредиторов. Используется для вывода в печатной форме;
  • Договор – служебное поле, заполняемое соответствующим элементом справочника Договоры и иные основания возникновения обязательств, в разрезе которого существует остаток задолженности. Не заполняется, если заполнена Группа кредиторов;
  • Документ-основание (Наименование, Номер, Дата) – соответствующие значения реквизитов Вид обязательства, №, От элемента справочника Договоры и иные основания возникновения обязательств. Не заполняется, если заполнена Группа кредиторов;
  • Дата погашения – дата погашения задолженности. Заполняется автоматически, в зависимости от выбранной настройки "Классификации задолженности по срокам исполнения (долгосрочная, краткосрочная, просроченная)" (Настройка параметров учета – Ведение учета). Если применяется упрощенный режим, то дата погашения определяется, как дата исполнения (погашения) договора. При этом в зависимости от настройки ведения учета для классификации дебиторской и кредиторской задолженности в упрощенном режиме она может определяться по дате поля Срок исполнения (погашения), указанной в документе Регистрация обязательств и сведений по договорам либо по значению поля Окончание в карточке Договора на закладке Свойства. Если используется основной режим, ведутся графики платежей по договорам, то дата погашения заполнится предельной датой платежа по графику платежей, а в случае незаполнения графика - дата погашения определяется, как дата исполнения (погашения) договора в упрощенном режиме. Не заполняется, если заполнена Группа кредиторов.
  • Кредитор – элемент справочника Контрагенты. Заполняется значением субконто Контрагенты остатков по счету 301.ХХ. Не заполняется, если заполнена Группа кредиторов;
  • КФО, Счет, КПС – заполняется по остаткам на счете 301.ХХ;
  • Код срока кредита – заполняется соответствующим значением кода срока кредита. При автоматическом заполнении срок кредита определяется по значению указанному в реквизите Дата погашения и началу действия договора. Начало действия договора задается в реквизите Срок действия с карточки договора (при оформлении документа Регистрация обязательств и сведений по договорам). Если Срок действия с в карточке договора не заполнен, датой начала действия договора считается дата договора указанная в реквизите от:. Не заполняется, если заполнена Группа кредиторов;
  • Валюта – элемент справочника Валюты. Валюта остатка на счете 301.ХХ;
  • Сумма долга, вал. – при автоматическом заполнении определяется по остаткам на счете 301.ХХ со значением субконто "Виды расчетов по займам (кредитам)" равным значению "Основной долг";
  • Сумма долга, руб. – при автоматическом заполнении определяется по остаткам на счете 301.ХХ со значением субконто "Виды расчетов по займам (кредитам)" равным значению "Основной долг";
  • Проценты, вал. – при автоматическом заполнении определяется по остаткам на счете 301.ХХ со значением субконто "Виды расчетов по займам (кредитам)" равным значению "Проценты";
  • Проценты, руб. – при автоматическом заполнении определяется по остаткам на счете 301.ХХ со значением субконто "Виды расчетов по займам (кредитам)" равным значению "Проценты";
  • Итого, вал. – общая сумма задолженности в валюте = Сумма долга, вал. + Проценты, вал.;
  • Итого, руб. – общая сумма задолженности в рублях = Сумма долга, руб. + Проценты, руб..

Ручное редактирование табличной части Раздела 1 не предусмотрено.

Команда Расшифровать открывает отчет Анализ задолженности с отбором, соответствтующим реквизитам текущей строки Раздела 1.

Раздел 1 подписывается ответственным исполнителем бухгалтерской службы простой ЭП.

Заполнение закладки "Раздел 2"

Раздел 2 "Сведения о состоянии государственного (муниципального) долга по привлеченным кредитам по данным инвентаризационной комиссии" заполняется ответственным исполнителем инвентаризационной комиссии. На закладке Раздел 2 по кнопке Заполнить (Заполнить по данным раздела 1 (без сумм)/(включая суммы) таблица может быть заполнена автоматически по данным Раздела 1.

В результате автозаполнения командой Заполнить по данным раздела 1 (без сумм) в табличной части закладки Раздел 2 по данным соответствующих одноименных реквизитов табличной части закладки Раздел 1 будут заполнены реквизиты: Код подраздела, Группа кредиторов, Код строки, Договор, Документ-основание, Дата погашения, Кредитор, КФО, Счет, КПС, Код срока кредита, Валюта.

При выборе команды Заполнить по данным раздела 1 (включая суммы) открывается форма Настройка заполнения раздела 2.

Переключатель Заполнить сумму долга и начисленные проценты по данным раздела 1 установлен по умолчанию.

При установке переключателя Вся задолженность согласована, вся задолженность будет считаться согласованной.

При установке переключателя Заполнить просроченную задолженность по данным бух. учета будет выполнено заполнение реквизитов просроченной задолженности по данным бух. учета.

Команда Заполнить раздел 2 в окне Настройка заполнения раздела 2 выполнит заполнение Раздела 2 в соответствии с указанными настройками.

При инвентаризации обязательств в разрезе кредиторов (в текущей строке реквизит Группа кредиторов не заполнен), реквизиты Код подраздела, Группа кредиторов, Код строки, Договор, Документ-основание, Дата погашения, Кредитор, КФО, Счет, КПС, Код срока кредита, Валюта, заполненные по данным Раздела 1 корректировке не подлежат.

Предусмотрено ручное заполнение суммовых показателей табличной части Раздела 2, сгруппированных в строках Сумма долга, Согласованная задолженность, Просроченная задолженность.

При редактировании суммовых показателей в строке Согласованная задолженность выполняется автоматический пересчет показателей в строке Не согласованная задолженность.

Документ-основание согласования задолженности основного долга указывается в реквизите Документ-основание (сумма долга) вручную.

Документ-основание согласования задолженности по начисленным процентам указывается в реквизите Документ-основание (проценты) вручную.

При инвентаризации долговых обязательств в разрезе групп кредиторов (заполнен реквизит Группа кредиторов в строке табличной части), все данные Раздела 2 по соответствующей группе кредиторов заполняются вручную. Новые строки табличной части добавляются командой Добавить или Скопировать. Удалить строку можно командой Удалить или клавишей Del.

Код строки нумеруется автоматически по соответствующей группе кредиторов.

Если по данным бухгалтерского учета сформировалось несколько разделов по разным группам кредиторов, при добавлении строки в Раздел 2 будет предложено выбрать соответствующую группу кредиторов.

При инвентаризации долговых обязательств в разрезе кредиторов, добавление строк в Раздел 2 не предусмотрено.

Команда Расшифровать открывает отчет Анализ задолженности с отбором, соответствующим реквизитам текущей строки Раздела 2.

Заполнение закладки "Раздел 3.1"

Подраздел 3.1 "Заключение комиссии по отклонениям по результатам инвентаризации" заполняется ответственным исполнителем инвентаризационной комиссии на закладке Раздел 3.1 по кнопке Заполнить по данным разделов 1 и 2.

В результате автозаполнения в табличной части закладки Раздел 3.1 будут заполнены реквизиты: N, Код подраздела, Группа кредиторов, Код строки, Договор, Документ-основание (Наименование, Дата, Номер), Дата погашения, Кредитор, КФО, Счет, КПС, Код срока кредита, Валюта, Отклонения по результатам инвентаризации (Сумма долга, вал., Сумма долга, руб., Проценты, вал., Проценты, руб., Итого, вал., Итого, руб.).

В случае если по итогам инвентаризации отклонения не установлены, то заключение инвентаризационной комиссии будет заполнено значением "Отклонения не выявлены, данные инвентаризационной комиссии соответствуют учетным данным", а в остальных графах проставлены нули.

Если же по итогам инвентаризации есть отклонения, заключение комиссии можно написать произвольным текстом в реквизите Заключение комиссии, либо выбрать из справочника Заключения комиссии по инвентаризационным описям.

Заполнение закладки "Раздел 3.2"

Подраздел 3.2 "Заключение комиссии по просроченной и (или) не согласованной с кредиторами задолженности" заполняется ответственным исполнителем инвентаризационной комиссии на закладке Раздел 3.2 по кнопке Заполнить по данным раздела 2.

В результате автозаполнения в табличной части закладки Раздел 3.2 будут заполнены реквизиты: N, Код подраздела, Группа кредиторов, Код строки, Договор, Документ-основание (Наименование, Дата, Номер), Дата погашения, Кредитор, КФО, Счет, КПС, Код срока кредита, Валюта, Задолженность, не согласованная с кредиторами (Сумма долга, вал., Сумма долга, руб., Проценты, вал., Проценты, руб., Итого, вал., Итого, руб.), Просроченная задолженность (Сумма долга, вал., Сумма долга, руб., Проценты, вал., Проценты, руб., Итого, вал., Итого, руб.).

В случае если по итогам инвентаризации просроченная задолженность не выявлена, заключение инвентаризационной комиссии будет заполнено значением "Просроченная задолженность и задолженность, не согласованная с кредиторами, отсутствует", а в остальных графах проставлены нули.

Если же по итогам инвентаризации есть отклонения, заключение комиссии можно написать произвольным текстом в реквизите Заключение комиссии, либо выбрать из справочника Заключения комиссии по инвентаризационным описям.

Раздел 3 подписывается членами инвентаризационной комиссии простой ЭП, председателем инвентаризационной комиссии - ЭЦП.

Закладка "Комиссия"

Состав комиссии определен в документе Решение о проведении инвентаризации и изменению не подлежит. Заполняется автоматически при выборе Решения о проведении инвентаризации в соответствующем реквизите.

В таблице можно отметить отсутствующих лиц и замещающее лицо для председателя комиссии.

Примечание. В случаях если в документе Решение о проведении инвентаризации (ф. 0510439) назначены рабочие инвентаризационные комиссии, предварительно заполненные из справочника Комиссии, в котором для членов рабочих комиссий, выступающих в качестве уполномоченных лиц, установлены соответствующие статусы Уполномоченное председателем лицо, то на закладке Комиссия документа Инвентаризационная опись состояния государственного (муниципального) долга по привлеченным кредитам (ф. 0510473) в качестве подписантов заполняются только уполномоченное председателем лицо и члены этой рабочей комиссии.

Закладка "Отбор из Решения"

Содержит список счетов, которые были выбраны в окне Выбор данных из Решения с учетом изменений после выбора Решения о проведении инвентаризации в соответствующем реквизите.

При заполнении Раздела 1 по данным бухгалтерского учета остатки будут заполнены с дополнительным отбором по КФО и счетам, указанным в таблице Отбор счетов.
