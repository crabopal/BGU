Документ "Внутреннее перемещение ОС, НМА, НПА"

Документ Внутреннее перемещение ОС, НМА, НПА предназначен для оформления и учета операций по перемещению капитальных вложений и объектов НФА внутри учреждения, в т.ч. выдаче объектов основных средств в личное пользование сотрудникам и возврату из личного пользования.

Документ позволяет оформить следующие операции:

  • Перемещение ОС, НМА, НПА на балансе (101, 102, 103);
  • Перемещение собственных ОС в оперативном учете (21);
  • Перемещение ОС, НМА, НПА полученных в пользование (01);
  • Перемещение ОС, НМА, НПА, принятых на хранение (02);
  • Перемещение ОС, полученных по централизованному снабжению (22);
  • Перемещение ОС, НМА, НПА между счетами. Например, передача имущества в концессию;
  • Перемещение капитальных вложений.

После заполнения и записи документа можно сформировать печатные формы Накладная на внутреннее перемещение объектов нефинансовых активов (ф. 0510450), Акт приема-передачи объектов, полученных в личное пользование (ф. 0510434).

Также после заполнения реквизитов бухгалтерской операции и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов Внутреннее перемещение ОС, НМА, НПА можно открыть с помощью команды Внутреннее перемещение ОС, НМА, НПА меню функций раздела ОС, НМА, НПА.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Внутреннее перемещение ОС, НМА, НПА.

Заполнение реквизитов шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Реквизит Вид операции может принимать значения:

  • Перемещение собственных ОС, НМА, НПА на балансе (101, 102, 103);
  • Перемещение собственных ОС в оперативном учете (21);
  • Перемещение ОС, НМА, НПА полученных в пользование (01);
  • Перемещение ОС, НМА, НПА, принятых на хранение (02);
  • Перемещение ОС, полученных по централизованному снабжению (22);
  • Перемещение ОС, НМА, НПА между счетами;
  • Перемещение капитальных вложений.

В группе Основание необходимо заполнить реквизиты:

  • Основание – вид документа-основания. Выбирается из справочника Виды первичных документов;
  • Дата и Номер – дата и номер документа-основания.

В группе Отправитель необходимо заполнить реквизиты:

  • МОЛ/Место хранения – центр материальной ответственности отправителя. Выбирается из справочника Центры материальной ответственности;
  • Подразделение – подразделение отправителя. Выбирается из справочника Подразделения.

В группе Получатель необходимо заполнить реквизиты:

  • МОЛ/Место хранения – центр материальной ответственности получателя. Выбирается из справочника Центры материальной ответственности;
  • Подразделение – подразделение получателя. Выбирается из справочника Подразделения.

Примечание. Группы реквизитов Отправитель и Получатель в документе не доступны для вида операции Перемещение ОС, НМА, НПА между счетами.

Закладка "Основные средства"

Данные о перемещаемых основных средствах, нематериальных активах, непроизведенных активах вводятся в табличную часть.

Реквизиты табличной части для вида операции Перемещение ОС, НМА, НПА между счетами:

  • Основное средство – выбирается из справочника Основные средства, НМА, НПА;

Примечание. Для выбора объектов ОС, НМА, НПА удобно использовать форму подбора, которая открывается с помощью кнопки Подобрать командной панели табличной части.

Список формы подбора будет содержать объекты ОС, у которых значение реквизита Вид учета в карточке объекта позволяет применить к ним Вид операции, указанный в шапке документа.

После выбора объектов ОС, НМА, НПА с использованием формы подбора в строках табличной части будут заполнены реквизиты:

  • Счет учета (текущий) – субсчет счета, на котором на текущую дату ведется учет объекта ОС, НМА, НПА.
  • Счет учета (новый) – субсчет счета, на который необходимо переместить объект ОС, НМА, НПА. Реквизит заполняется из фрагмента Плана счетов ЕПСБУ, который открывается по кнопке Установить новый счет.

Реквизиты табличной части для всех остальных видов операций:

  • Основное средство – выбирается из справочника Основные средства, НМА, НПА;

Примечание. Для выбора объектов ОС, НМА, НПА удобно использовать форму подбора, которая открывается с помощью кнопки Подобрать командной панели табличной части.

Список формы подбора будет содержать объекты ОС, у которых значение реквизита Вид учета в карточке объекта позволяет применить к ним Вид операции, указанный в шапке документа.

После выбора объектов ОС, НМА, НПА с использованием формы подбора в строках табличной части будут заполнены реквизиты:

  • Гр. уч – признак группового учета для выбранного объекта ОС. Для объектов ОС, по которым задано ведение группового учета, автоматически устанавливается флаг;
  • Счет учета – субсчет счета 101.00 на котором ведется учет объекта ОС, НМА, НПА;
  • Инв. номер – инвентарный номер объекта основных средств;

Примечание. Реквизит Инв. номер в обязательном порядке используется при учете объектов основных средств стоимостью более 10 000 руб., за исключением объектов библиотечного фонда. Для объектов стоимостью до 10 000 руб. программа позволяет использовать инвентарные номера по желанию.
  • КФО – код финансового обеспечения.
  • КПС – классификационный признак счета.
  • Количество – количество объектов ОС. Для одиночных объектов ОС, имеющих инвентарный номер, значение реквизита автоматически устанавливается равным 1. Реквизит доступен для заполнения для объектов ОС, у которых не предусмотрены инвентарные номера;
  • Цена – балансовая стоимость объекта ОС, НМА, НПА;
  • Сумма – балансовая стоимость объектов ОС, НМА, НПА по строке.

Реквизиты Цена и Сумма недоступны для редактирования. Значения реквизитов рассчитываются автоматически с помощью кнопки Рассчитать командной панели табличной части.

Если местонахождение объекта ОС не совпадает с местонахождением, указанным в реквизите МОЛ/Место хранения, то реквизиты Цена и Сумма для такого объекта заполнены не будут.

При изменении значений реквизитов шапки заполненного документа необходимо перезаполнить табличную часть, т.к. данные в ней могут не соответствовать новым значениям реквизитов шапки документа. При невыполнении данного требования попытка проведения документа может оказаться невозможна.

  • Примечание – дополнительная информация в виде текста. Вводится при необходимости.

Закладка "Бухгалтерская операция"

Значение реквизита Типовая операция зависит от Вида операции, указанного в шапке документа.

Если реквизит Вид операции имеет значение Перемещение собственных ОС на балансе (101, 102, 103), то типовая операция имеет значение Внутреннее перемещение.

Для вида операции Перемещение ОС в оперативном учете (21) используется типовая операция Внутреннее перемещение (оперативный учет).

Для типовых операций Внутреннее перемещение и Внутреннее перемещение (оперативный учет) доступно заполнение реквизитов:

  • Выдать в личное пользование – флажок устанавливается для отражения выдачи в личное пользование;
  • Вернуть из личного пользования – флажок устанавливается для отражения возврата из личного пользования;
  • Сотрудник – в зависимости от установленного флажка указывается сотрудник, которому выдается имущество в личное пользование или сотрудник, который возвращает имущество из личного пользования. Значение реквизита выбирается из справочника Сотрудники.

Примечание. Если в шапке документа, в группе Получатель, в реквизите МОЛ/Место хранения указан нужный сотрудник, то реквизит Сотрудник на закладке Бухгалтерская операция можно не заполнять.

Если Вид операции имеет значение Перемещение ОС, полученных в пользование (01), Перемещение ОС на хранении (02) или Перемещение ОС, полученных по централизованному снабжению (22), то используется типовая операция Внутреннее перемещение (забалансовый учет).

Если Вид операции имеет значение Перемещение капитальных вложений, то используется типовая операция Внутреннее перемещение капитальных вложений.

Если Вид операции имеет значение Перемещение ОС, НМА, НПА между счетами, то используются типовые операции:

  • Внутреннее перемещение между счетами (реклассификация через счет 401.10.172);
  • Внутреннее перемещение между счетами (концессия 101.ХХ - 101.ХХ).

Для типовой операции Внутреннее перемещение между счетами (реклассификация через счет 401.10.172) необходимо заполнить реквизит Счет переноса – указать КПС для счета 401.10.172.

Для остальных типовых операций заполнение дополнительных реквизитов не требуется.

Регистрация документа

Регистрация документа Внутреннее перемещение ОС производится в журнале Документы по основным средствам.

Дополнительные возможности

На основании документа Внутреннее перемещение ОС, НМА, НПА можно ввести документ Сторно.
