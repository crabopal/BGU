Документ "Акт о результатах инвентаризации (ф. 0510463)"

Документ Акт о результатах инвентаризации (ф. 0510463) предназначен для обобщения результатов проведенной инвентаризационной комиссией инвентаризации и формирования Акта о результатах инвентаризации по форме ОКУД 0510463.

Работа со списком документов

Список документов вида Акт о результатах инвентаризации (ф. 0510463) можно открыть с помощью команды Акты о результатах инвентаризации (ф. 0510463) меню функций раздела Инвентаризация.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Акты о результатах инвентаризации (ф. 0510463).

Заполнение документа

В документе Акт о результатах инвентаризации (ф. 0510463) обобщаются результаты инвентаризации, отраженные в инвентаризационных описях, если инвентаризация по группам объектов была проведена по одному Решению о проведении инвентаризации (ф. 0510439) и по состоянию на одну дату.

Предусмотрено автоматическое заполнение документа сведениями из инвентаризационных описей. Возможна ручная корректировка данных документа.

Для автоматического заполнения закладок Раздел 1, Раздел 2, Раздел 3, Приложения к разделу 2, Приложения к разделу 3 документа необходимо предварительно в шапке документа указать Решение о проведении инвентаризации, выбрать из него дату инвентаризации и номер инвентаризационной комиссии. После этого необходимо нажать кнопку Заполнить по описям командной панели формы документа.

В автоматическое заполнение попадают документы инвентаризационных описей, которые успешно сопоставлены с указанным в шапке документом Решение о проведении инвентаризации с учетом актуальных данных (введенных на его основании документов Изменение решения о проведении инвентаризации). Сопоставление выполняется при выполнении условий:

  • документ описи проведен;
  • в документе описи указана дата инвентаризации, совпадающая с датой инвентаризации из графы 6 раздела 1 документа Решение о проведении инвентаризации (ф. 0510439);
  • документ описи составлен в отношении того же ответственного лица, которое указано в документе Решение о проведении инвентаризации;
  • документ описи составлен по тем же счетам и КФО, которые указаны в документе Решение о проведении инвентаризации.

Заполнение закладок "Раздел 1", "Раздел 2", "Раздел 3", "Приложения к разделу 2", "Приложения к разделу 3"

Для разделов 1 "Результаты инвентаризации без выявленных отклонений по суммовым (количественным) показателям и качественным характеристикам", 2 "Результаты инвентаризации с выявленными отклонениями", 3 "Результаты выявления качественных характеристик" и приложений к разделам 2, 3 предусмотрены отдельные закладки на форме документа.

В табличной части закладки Раздел 1 отражается перечень инвентаризационных описей, инвентаризация по которым установила соответствие фактического наличия (состояния) инвентаризируемых объектов учетным данным.

В табличной части закладки Раздел 2 отражается перечень инвентаризационных описей, инвентаризация по которым установила несоответствие фактического наличия инвентаризируемых объектов учетным данным, и (или) наличие неподтвержденных расчетов и (или) обязательств, а также несоответствие учетных данных денежных средств банковским выпискам.

В табличной части закладки Раздел 3 отражается перечень инвентаризационных описей, инвентаризация по которым установила несоответствие качественных характеристик объектов учетным данным, наличие просроченных (с истекшим сроком исковой давности) расчетов и (или) обязательств (например, объект нефинансового актива не соответствует условиям актива, просроченная задолженность имеет признаки безнадежной задолженности).

Для описей, заполненных в табличной части закладки Раздел 1 не предусмотрено приложений.
Для описей, заполненных в табличной части закладок Раздел 2 и Раздел 3 предусмотрены соответствующие приложения к разделам. При указании описи в табличных частях закладок Раздел 2 или Раздел 3 обязательно наличие такой описи в соответствующем приложении к разделу.

Если по какой-то описи автоматически не выявлено никаких расхождений, то опись будет отражена в табличной части закладки Раздел 1. Если выявлены какие-то расхождения, то опись отражается в табличных частях закладок Раздел 2 или Раздел 3 и в соответствующем приложении к разделу.

На закладке Раздел 1 командной панели табличной части предусмотрена кнопка Переместить опись в раздел (2, 3). Такое действие может потребоваться, если расхождения в описи автоматически не выявлены, но в действительности они существуют. При нажатии кнопки строка с описью переносится из табличной части закладки Раздел 1 на указанную закладку Раздел 2 или Раздел 3.

На закладках Раздел 1 и Раздел 3 командной панели табличной части предусмотрена кнопка Добавить опись в приложение для добавления вручную выбранной строки табличной части с описью в соответствующую табличную часть закладок Приложения к разделу 2, Приложения к разделу 3, если по каким-то причинам не произошло автоматическое заполнение при нажатии на кнопку Заполнить по описям командной панели формы документа.

Закладка "Комиссия"

На закладке Комиссия указывается инвентаризационная комиссия, выбранная ранее из документа Решение о проведении инвентаризации.

Примечание. В случаях если в документе Решение о проведении инвентаризации (ф. 0510439) назначены рабочие инвентаризационные комиссии, предварительно заполненные из справочника Комиссии, в котором для членов рабочих комиссий, выступающих в качестве уполномоченных лиц, установлены флажки Уполномоченное председателем лицо, то на закладке Комиссия документа Акт о результатах инвентаризации (ф. 0510463) в качестве подписантов заполняются только председатель и уполномоченные лица каждой рабочей комиссии.
