Перенос остатков по компенсации родительской платы

Документ "Перенос остатков по компенсации родительской платы"

Документ Перенос остатков по компенсации родительской платы предназначен для переноса данных о начисленной компенсации части родительской платы по классификационным признакам счетов.

При переносе бухгалтерских остатков по расчетам компенсации части родительской платы в случае изменения КПС перенос данных по регистру накопления Учет компенсации родительской платы не выполняется.

Для корректного отображения данных по остаткам начисленной части компенсации части родительской платы в различных отчетах необходимо выполнить перенос с помощью данного документа.

Работа со списком документов

Список документов Перенос остатков по компенсации родительской платы можно открыть с помощью команды Перенос остатков по компенсации родительской платы меню функций раздела Платное обучение.

Создание нового документа

Для ввода нового документа следует нажать на кнопку Создать командной панели списка Перенос остатков по компенсации родительской платы.

Так же предусмотрен ввод нового документа на основании созданного ранее документа Перенос остатков. В этом случае выполняется автоматическое заполнение реквизитов шапки документа.

Заполнение реквизитов шапки документа


Под Организацией в данном случае понимается учреждение, уполномоченное начислять и выплачивать компенсацию родительской платы. Это может быть как собственно детское учреждение, начисляющее компенсацию исключительно в рамках своего учреждения, так и централизованная бухгалтерия, ведущая учет и начисляющая компенсацию для нескольких детских учреждений.

Детское учреждение – организация, для которой по данным расчета компенсации родительской платы будет формироваться документ Начисление компенсации родительской платы. Выбирается из справочника Организации.

Примечание. Если реквизит Детское учреждение заполнен, то документ будет сформирован на основании расчета компенсации только одного детского учреждения. При незаполненном реквизите Детское учреждение документ будет формироваться на основании расчетов компенсации всех детских учреждений, учет по которым ведется в информационной базе.

Старый КПС – указывается классификационный признак счета, с которого должен быть выполнен перенос остатков регистра Учет компенсации родительской платы.

Новый КПС – указывается классификационный признак счета, на который должен быть выполнен перенос.

Табличная часть документа


Табличную часть Перенос по КПС удобно заполнить автоматически с помощью нажатия на кнопку Заполнить табличную часть командной панели.

При этом программа автоматически найдет остатки по регистру накопления Учет компенсации родительской платы по параметрам заполнения, указанных в шапке документа и на основании этих данных заполнит табличную часть.

В результате автозаполнения в табличной части будут заполнены реквизиты:

  • Детское учреждение – детское учреждение, за посещение которого начисляется компенсация родительской платы. Если заполнен одноименный реквизит шапки документа, то колонка табличной части скрыта;
  • Ребенок – ребенок, за которого начисляется компенсация родительской платы.
  • Начало периода – дата начала начисления компенсации;
  • Настройка компенсации – элемент соответствующего справочника, согласно которому выполнено начисление;
  • КФО – код вида финансового обеспечения;
  • Плательщик (родитель) – плательщик родительской платы (родитель или законный представитель ребенка), которому должна быть начислена и выплачена компенсация родительской платы.
  • Процент компенсации – числовое значение процента компенсации части родительской платы.
  • Сумма компенсации – сумма компенсации, которая будет начислена для дальнейшего перечисления получателю — родителю или законному представителю ребенка.
