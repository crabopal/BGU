Проведение документа

Документ "Закрытие балансовых счетов в конце года"

Документ Закрытие балансовых счетов в конце года предназначен для выполнения заключительных операций по балансовым счетам в конце текущего отчетного года, а также при изменении типа учреждения.

Важно
Документ является последним в году и вводится 31 декабря после оформления всех операций года. Учреждение может ввести только один документ Закрытие балансовых счетов в конце года в год.

После заполнения реквизитов и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Документы вида Закрытие балансовых счетов в конце года находятся в журнале Документы закрытия года.
Журнал Документы закрытия года можно открыть с помощью команды Документы закрытия года меню функций раздела Учет и отчетность.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели панели журнала Документы закрытия года и выбрать в списке тип документа Закрытие балансовых счетов в конце года.

Заполнение реквизитов шапки документа
  • Дата документа заполняется автоматически значением рабочей (текущей) даты. Для закрытия года следует указать 31 декабря текущего отчетного года;
  • Организация – учреждение, для которого производится закрытие счетов. Выбирается из справочника Организации;
  • Изменение типа учреждения – флажок, устанавливается в случае изменения типа учреждения;
  • Финансовый год – закончившийся финансовый год.

Реквизит Типовая операция имеет одно значение – Закрытие балансовых счетов в конце года.

Заполнение реквизитов табличной части

После нажатия на кнопку Заполнить по данным учета табличная часть заполняется номерами счетов, КФО и ИФО, которые должны быть закрыты в конце года и по которым в базе есть остатки.

Примечание. Пользователь может удалить строку для счета, который не надо закрывать. Для этого следует настроить список заключаемых счетов по гиперссылке Настройка заключаемых счетов, которая находится справа в шапке документа.
Например, если при расчетах между головным учреждением и обособленными подразделениями по счету 304.04 "Внутриведомственные расчеты" в конце года должны остаться незакрытыми расчеты, нужно убрать флаг со счета 304 04, перейдя по гиперссылке Настройка заключаемых счетов.

В колонках КПС, Счет фин. результата для каждого из закрываемых счетов необходимо выбрать рабочий счет, на который будет проведено закрытие счетов (КПС и счет 401 30).

Примечание. Согласно пункту 2 Инструкции № 162н в разрядах 1 - 17 номера счета 0 401 30 000 "Финансовый результат прошлых отчетных периодов" отражаются нули.

Для группового заполнения КПС счета 401.30 можно использовать кнопку Заполнить КПС счета 401.30.

Проведение документа

Для формировании проводок по закрытию балансовых счетов следует нажать кнопку Провести или Провести и закрыть.

При проведения документа формируются следующие проводки:

  • Д-т 401.10.ххх К-т 401.30.000 – по списанию начисленных доходов на финансовый результат;
  • Д-т 401.30.000, К-т 401.20.ххх – по списанию начисленных расходов на финансовый результат;
  • Д-т 1.401.30.000, К-т 1.210.02.ххх – по закрытию счетов расчетов с органами, осуществляющими кассовое обслуживание исполнения бюджетов по поступлениям в бюджет;
  • Д-т 1.304.05.ххх, К-т 1.401.30.000 – по закрытию счетов расчетов с органами, осуществляющими кассовое обслуживание исполнения бюджетов по платежам из бюджета;
  • Дт 401.30.000 Кт 304.04.ххх – по списанию главным распорядителем (распорядителем) бюджетных средств, использованных получателем, на основании отчетности получателей;
  • Дт 304.04.ххх Кт 401.30.000 / Дт 401.30.000 Кт 304.04.ххх – по закрытию внутриведомственных расчетов в части законченных расчетов между главным распорядителем (распорядителем) и получателем средств бюджета, между головным учреждением и обособленными подразделениями в сумме завершенных в финансовом году расчетов по поступлению (передаче) нефинансовых, финансовых активов (обязательств);
  • Д-т 304.06.830, К-т 401.30.000 / Дт 401.30.000 Кт 304.06.830 – закрытие расчетов по поступлению (передаче) нефинансовых, финансовых активов (обязательств), сформированных на счете 304.06;

Примечание. Операции по незавершенным расчетам по принятию средств между источниками финансового обеспечения, осуществляемых в пределах остатка средств учреждения на лицевом счете (в кассе) учреждения, отраженных на счете 030406000 "Расчеты с прочими кредиторами", при завершении финансового года не формируются.
  • Д-т 401.30.000, К-т 401.30.730 – списание расчетов с прочими кредиторами на финансовый результат.

Аналогично документом отражаются проводки по закрытию в конце года показателей счетов бухгалтерского учета по отражению ошибок прошлых лет (401.16, 401.17, 401.18, 401.19, 401.26, 401.27, 401.28, 401.29, 304.66, 304.76, 304.86, 304.96) с применением счета 0 401 30 000 "Финансовый результат прошлых отчетных периодов".

Для каждой сформированной проводки устанавливается тип межотчетного периода Заключение счетов.
