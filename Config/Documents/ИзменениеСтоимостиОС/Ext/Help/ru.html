Изменение стоимости, амортизации, обесценения ОС, НМА, НПА

 

Документ предназначен:

  • для изменения стоимости, амортизации, обесценения ОС, НМА и НПА в случаях, не предусмотренных другими учетными документами;
  • для изменения порядка погашения стоимости и параметров начисления амортизации: способа начисления амортизации, срока полезного использования, нормы начисления амортизации.

Документ формирует движения по регистрам:

  • регистр бухгалтерии «Журнал проводок (ЕПСБУ)»;
  • регистр накопления «Стоимость объектов ОС, НМА, НПА»;
  • регистр накопления «Амортизация, обесценение объектов ОС, НМА, НПА»;
  • регистр сведений «Параметры амортизации ОС (бухгалтерский учет)»;
  • регистр сведений «Расчет амортизации ОС».

В документе предусмотрены следующие операции:

  • Изменение амортизации (106, 109, 401.20 – 104) - для формирования записей:
    • Дт счет учета затрат (106.хИ.340, 109.хх.271, 401.20.271), Кт счет амортизации (104.хх.410) на сумму изменения амортизации: в положительном значении - при увеличении амортизации, в отрицательном значении - при уменьшении амортизации.
    Примечание. При этой операции норма амортизации не изменяется. Для изменения суммы амортизации и нормы используйте следующую операцию.
  • Изменение стоимости (101, 102 – 106, 401.10), амортизации (106, 109, 401.20 – 104) - для формирования записей:
    • Дт счет учета (101.хх.310, 102.хх.320), Кт счет корреспондент (106.х1.310, 106.х2.320, 106.КС.310, 401.10.100) на сумму изменения балансовой стоимости ОС, НМА: в положительном значении - при увеличении, в отрицательном значении - при уменьшении;
    • Дт счет учета затрат (106.хИ.340, 109.хх.271, 401.20.271), Кт счет амортизации (104.хх.410) на сумму изменения амортизации: в положительном значении - при увеличении, в отрицательном значении - при уменьшении.
  • Изменение стоимости (401.10 – 101, 102), амортизации (104 – 101, 102), обесценения (114 – 101, 102) - для формирования записей:
    • Дт счет амортизации (104.хх.410, 104.хх.420), Кт счет учета (101.хх.410, 102.хх.420) на сумму списания балансовой стоимости за счет амортизации, приходящейся на ликвидируемую часть: в положительном значении - при уменьшении стоимости и амортизации, в отрицательном значении - при увеличении амортизации и стоимости.
    • Дт счет обесценения (114.хх.412), Кт счет учета (101.хх.410, 102.хх.420) на сумму списания балансовой стоимости за счет обесценения, приходящегося на ликвидируемую часть: в положительном значении - при уменьшении стоимости и обесценения, в отрицательном значении - при увеличении обесценения и стоимости.
    • Дт счет корреспондент (401.10.100), Кт счет учета (101.хх.410, 102.хх.420) на сумму изменения остаточной стоимости ОС, НМА: в положительном значении - при уменьшении, в отрицательном значении - при увеличении.
  • Изменение стоимости (401.20 – 101, 102), амортизации (104 – 401.20), обесценения (114 – 401.20) - для формирования записей:
    • Дт счет корреспондент (401.20.200), Кт счет учета (101.хх.410, 102.хх.420) на сумму изменения балансовой стоимости ОС, НМА: в положительном значении - при уменьшении, в отрицательном значении - при увеличении.
    • Дт счет амортизации (104.хх.410) , Кт счет корреспондент (401.20.200) на сумму изменения амортизации: в положительном значении - при уменьшении амортизации, в отрицательном значении - при увеличении амортизации.
    • Дт счет обесценения(114.хх.412) , Кт счет корреспондент (401.20.200) на сумму изменения обесценения: в положительном значении - при уменьшении обесценения, в отрицательном значении - при увеличении обесценения.
  • Изменение нормы амортизации - для изменения нормы амортизации по ОС и НМА, для которых установлен линейный способ начисления амортизации. При проведении документа формируются записи в регистре сведений "Расчет амортизации ОС" с новыми параметрами для вычисления амортизации - остаточной стоимостью и оставшимся сроком полезного использования, который действуют с месяца проведения документа. Новая запись в регистр формируется даже в том случае, если СПИ и оставшийся СПИ не изменены.

Счет коррекспондент указывается на закладке «Бухгалтерская операция».
Счет учета ОС (НМА) определяется по остаткам регистра бухгалтерии.
Счет амортизации определяется по регистру сведений «Соответствие счетов ОС» в соответствии со счетом учета ОС, НМА, НПА.
Счет учета затрат для начисления амортизации определяется по регистру «Параметры отражения затрат по амортизации».
Счета определяются по регистрам на дату документа.

Документом можно отразить следующие хозяйственные операции:

Изменение суммы начисленной ранее амортизации из-за исправления ОКОФ

Для этого необходимо выбрать операцию «Изменение амортизации (106, 109, 401.20 – 104)», подобрать в табличную часть объект ОС (НМА), во второй подстроке «после изменения» указать новый срок полезного использования в колонке «Срок полезного использования» и новую сумму амортизации в колонке «Сумма амортизации», провести документ.

  • Дт КРБ 106.хИ.340, 109.хх.271, КРБ 401.20.271, Кт КРБ 104.хх.410 = +/- сумма изменения амортизации;
  • Регистр сведений «Расчет амортизации»: новый оставшийся СПИ, новая остаточная стоимость для вычисления амортизации;
  • Регистр накопления «Амортизация объектов основных средств»: приход, +/- сумма изменения амортизации.

Доначисление амортизации объектам по ОС и НМА за период нахождения в составе ИК

Для этого необходимо выбрать операцию «Изменение амортизации (106, 109, 401.20 – 104)», подобрать в табличную часть объект ОС (НМА), во второй подстроке «после изменения» указать новую сумму амортизации в колонке «Сумма амортизации», провести документ.

  • Дт КРБ 106.хИ.340, 109.хх.271, КРБ 401.20.271, Кт КРБ 104.хх.410 = + сумма изменения амортизации;
  • Регистр сведений «Расчет амортизации»: новый оставшийся СПИ, новая остаточная стоимость для вычисления амортизации;
  • Регистр накопления «Амортизация объектов основных средств»: приход, + сумма.

Ликвидация части ОС (НМА)

Для отражения ликвидации части объекта ОС (НМА) необходимо выбрать операцию «Изменение стоимости (401.10 – 101, 102), амортизации (104 – 101, 102)», в поле Счет указать 401.10.172, в поле Вид НФА выбрать «Основные средства» или «Нематериальные активы», заполнить реквизит Вид движения НФА из перечисления.
Далее подобрать в табличную часть документа объект ОС (НМА), во второй подстроке «после изменения» указать новую балансовую стоимость в колонке Балансовая стоимость и новую сумму амортизации в колонке Сумма амортизации, провести документ. Печатной формы для акта не предусмотрено, операция оформляется бухгалтерской справкой ф. 0504833.

  • Дт КРБ 104.хх.410, Кт КРБ 101.хх.410 = + сумма списания балансовой стоимости за счет амортизации, приходящейся на ликвидируемую часть;
  • Дт КДБ 401.10.172, Кт КРБ 101.хх.410 = + сумма списания остаточной стоимости;
  • Регистр сведений «Расчет амортизации»: новый оставшийся СПИ, новая остаточная стоимость для вычисления амортизации;
  • Регистр накопления «Стоимость объектов основных средств»: расход, + сумма;
  • Регистр накопления «Амортизация объектов основных средств»: расход, + сумма.

Отражение на счетах бухгалтерского учета доначисления амортизации по объектам ОС и НМА до 100% балансовой стоимости по объектам ОС (НМА), по которым способ начисления амортизации изменен на «100% при вводе в эксплуатацию»

Для этого необходимо выбрать операцию «Изменение стоимости (101, 102 – 106, 401.10), амортизации (106, 109, 401.20 – 104)», подобрать в табличную часть ОС (НМА), во второй подстроке «после изменения» в колонке «Способ начисления амортизации» указать «100 % при вводе в эксплуатацию». При этом в колонке «Сумма амортизации» автоматически установится сумма балансовой стоимости. Провести документ.

  • Дт КРБ 106.хИ.340, 109.хх.271, КРБ 401.20.271, Кт КРБ 104.хх.410 = + сумма;
  • Регистр накопления «Амортизация объектов основных средств»: приход, + сумма;
  • Регистр сведений «Параметры амортизации ОС (бухгалтерский учет)»: способ начисления амортизации «100 % при вводе в эксплуатацию».

Изменение СПИ для НМА с линейной амортизацией

Для этого необходимо выбрать любую операцию, например операцию «Изменение амортизации (109, 401.20 – 104)», подобрать в табличную часть ОС (НМА), во второй подстроке «после изменения» указать новый срок полезного использования в колонке «Срок полезного использования», провести документ.

  • Регистр сведений «Расчет амортизации ОС»: новый срок полезного использования и норма начисления амортизации.

В этом случае при проведении документа формируются записи:

  • Дт КРБ 106.хИ.340, 109.хх.271, КРБ 401.20.271, Кт КРБ 104.хх.410 = +/- сумма изменения амортизации;
  • Регистр сведений «Расчет амортизации»: новый оставшийся СПИ, новая остаточная стоимость для вычисления амортизации;
  • Регистр накопления «Амортизация объектов основных средств»: приход, +/- сумма изменения амортизации.

Изменение нормы амортизации по ОС, находящихся на консервации до 01.01.2018, при переходе на применение федерального стандарта "Основные средства" 

Для изменения нормы амортизации необходимо выбрать операцию «Изменение нормы амортизации», подобрать в табличную часть ОС и провести документ. При необходимости во второй подстроке «после изменения» можно исправить новые СПИ и оставшийся срок полезного использования в колонках «Срок полезного использования», «Оставшийся срок», которые будут использоваться в дальнейшем при расчете суммы амортизации.

При расчете оставшегося СПИ период нахождения объекта на консервации включается в фактический срок эксплуатации ОС, согласно пункту 7 Письма Минфина России от 15.12.2017 N 02-07-07/84237.

При проведении документа формируются записи в регистр, даже если СПИ и оставшийся СПИ не были изменены:

  • Регистр сведений «Расчет амортизации»: новый СПИ, новый оставшийся СПИ, новая остаточная стоимость для вычисления амортизации.

Замечание. Для возобновления начисления амортизации объектов ОС, находящихся на консервации, при переходе на применение федерального стандарта "Основные средства" применяется документ Консервация ОС с операцией Расконсервация.
