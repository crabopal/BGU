Дополнительные возможности

Документ "Требование - накладная (Материальные запасы)"

Документ используется для оформления следующих операций:

  • Возврат из неавтоматизированной торговой точки (105.08.340);
  • Передача материальных запасов для изготовления НФА (106.00, 109.00);
  • Перемещение в неавтоматизированную торговую точку (105.08.340);
  • Перемещение материальных запасов между материально ответственными лицами и счетами (105.00, забаланс);
  • Перемещение между НТТ (105.08.340);
  • Списание материалов (109,00, 401.20).

После заполнения и записи документа можно сформировать печатные формы Требования-накладная (ф. 0510451), Накладная на внутреннее перемещение объектов нефинансовых активов (ф. 0510450).

Кроме того, после заполнения реквизитов бухгалтерской операции и проведения документа можно сформировать Справку о содержании драг. материалов и бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида Требование - накладная (Материальные запасы) можно открыть с помощью команды Требования - накладные (Материальные запасы) меню функций раздела Материальные запасы.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Требования - накладные (Материальные запасы).

Заполнение реквизитов шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Реквизиты группы Отправитель:

  • МОЛ/Место хранения – центр материальной ответственности отправителя. Выбирается из справочника Центры материальной ответственности.

Примечание. Если при выбытии материальных запасов - товаров из розничной торговой точки указать МОЛ/Место хранения из настроек кассы ККМ, то становится доступна установка флага Оформить выбытие товаров со склада торговой точки.
  • Подразделение – подразделение отправителя. Выбирается из справочника Подразделения.

Реквизиты группы Получатель:

  • МОЛ/Место хранения – центр материальной ответственности получателя. Выбирается из справочника Центры материальной ответственности;
  • Подразделение – подразделение получателя. Выбирается из справочника Подразделения.

Закладка "Учет"

Операция – выбирается из списка. Может принимать значения:

  • Перемещение, выбытие материальных активов;
  • Перемещение между счетами учета;
  • Перемещение в розницу (в НТТ);
  • Перемещение в рознице (между НТТ);
  • Возврат из розницы (из НТТ).

От выбранного значения реквизита Операция зависит доступность для заполнения других реквизитов документа.

Счет учета – счет учета материальных запасов. Определяет тип номенклатуры – 105.00 «Материальные запасы», 02.22 «Материальные запасы – особо ценное движимое имущество на хранении» и т.д. Выбирается из списка. От значения реквизита Счет учета зависит доступность для заполнения других реквизитов документа.

Кор. счет – выбирается из Плана счетов (ЕПСБУ). Отражается в печатной форме документа, а также используется для определения субконто при списании материалов на счета себестоимости производства.

Примечание. В программе автоматизировано заполнение закладки Материалы по спецификации выпускаемой продукции. При выборе кор. счета 109.60 «Себестоимость готовой продукции, работ, услуг» становятся доступны реквизиты Номенклатура (Субконто 1 счета 109.60) и Виды затрат (Субконто 2 счета 109.60). Выбор в реквизите Номенклатура готовой продукции позволяет заполнить таблицу Материалы с помощью кнопки Заполнить по спецификации на закладке Материалы. Если выбрана Номенклатурная группа продукции, то документ заполняется по спецификациям продукции, входящей в эту группу.

Типовая операция – выбирается из списка Типовые операции:

  • Возврат из НТТ (105.08.340);
  • Передача для изготовления НФА (106.00, 109.00);
  • Перемещение в НТТ (105.08.340);
  • Перемещение между МОЛ и счетами (105.00, забаланс);
  • Перемещение между НТТ (105.08.340);
  • Списание материалов (109.00, 401.20).

Важно!
Доступность для выбора той или иной типовой операции зависит от выбранных значений для реквизитов документа.

Закладка "Материалы"
  • Номенклатура – наименование материала. Выбирается из справочника Номенклатура;

Примечание. Для выбора позиций номенклатуры удобно использовать форму подбора, которая открывается с помощью кнопки Подобрать командной панели табличной части.
  • Ед. изм – единица измерения. Заполняется автоматически и соответствует значению реквизита Ед. измерения выбранного элемента номенклатуры;
  • Счет учета – счет учета МЗ.
  • КФО – код финансового обеспечения. Выбирается в списке КФО.
  • КПС – классификационный признак счета. Выбирается в списке КПС.
  • КЭК – код экономической классификации.

Примечание. При выборе номенклатуры в табличную часть документа автоматически проставляются реквизиты Счет учета и КЭК соответствующие значению реквизита Тип номенклатуры, указанному в элементе справочника Номенклатура. При необходимости КЭК можно изменить вручную.
  • Доп. аналитика – дополнительная аналитика.
  • Затребовано – количество затребованных номенклатурных единиц.
  • Отпущено – количество отпущенных номенклатурных единиц.
  • Цена – цена единицы номенклатуры.
  • Сумма – сумма по строке.
  • Примечание – дополнительная информация в виде текста. Вводится при необходимости.

Примечание. Реквизиты Цена и Сумма доступны только для операций с участием неавтоматизированных торговых точек.

Закладка "Драгоценные материалы"

Внимание!
Заполнение реквизитов на закладке Драгоценные материалы выполняется только для типовой операции Списание материалов. Для иных типовых операций закладку Драгоценные материалы заполнять не следует!

Табличная часть, расположенная в левой части закладки, содержит список всех объектов МЗ, которые были указаны на закладке Материалы.

Для заполнения табличной части Содержание драгоценных материалов, расположенной справа, следует использовать кнопку Заполнить командной панели.

В результате в табличной части Содержание драгоценных материалов появится одна или несколько строк с информацией о драгоценных материалах, которые содержатся в объектах МЗ.

Регистрация документа

Регистрация документа Требования - накладная (Материальные запасы) производится в журнале Документы по учету материальных запасов.

Дополнительные возможности

На основании документа Требования - накладная (Материальные запасы) можно ввести документы Акт списания материалов, Ведомость на выдачу МЗ на нужды учреждения, Изменение остатков товаров в торговой точке и Сторно.
