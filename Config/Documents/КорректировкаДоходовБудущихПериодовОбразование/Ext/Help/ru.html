Документ "Корректировка, прекращение долгосрочного договора (образование)"

Документ Корректировка, прекращение долгосрочного договора (образование) предназначен для отражения в учете операций:

  • по досрочному расторжению долгосрочных договоров с учащимися;
  • по иным корректировкам сумм предстоящих доходов по договору, например, при предоставлении скидок, льгот и пр.
  • по корректировке порядка оплаты и/или порядка признания доходов текущего периода, например, при изменении способа и срока признания доходов, счета и аналитики учета доходов, отражения в налоговом учете.

После заполнения реквизитов бухгалтерской операции и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида Корректировка, прекращение долгосрочного договора (образование) можно открыть с помощью команды Корректировка, прекращение долгосрочного договора (образование), размещенной в группе Образовательные услуги – Долгосрочные договоры меню функций раздела Платное обучение.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Корректировка, прекращение долгосрочного договора (образование).

Заполнение реквизитов шапки документа

Учащийся – выбирается из справочника Учащиеся. При выборе учащегося автоматически заполняются реквизиты Контрагент и Договор.
Контрагент – выбирается из справочника Контрагенты.
Договор – выбирается из справочника Договоры и иные основания возникновения обязательств.
Вид операции – выбирается из списка:

  • Досрочное прекращение договора – в случае досрочного расторжения долгосрочных договоров.
  • Корректировка доходов будущих периодов – при иных корректировках предстоящих доходов по договору. Например, при изменении размера платы за обучение, общежития, при предоставлении скидок, льгот и пр.

При выборе вида операции Корректировка доходов будущих периодов необходимо установить флажки Суммы доходов и/или Порядок учета доходов в зависимости от того, что планируется изменить этим документом:

  • Суммы доходов – для изменения сумм предстоящих доходов по договору;
  • Порядок учета доходов – для изменения параметров признания доходов текущего периода (по месяцам / по календарным дням / по графику / в особом порядке), периода списания доходов, счета и аналитики учета доходов в бухгалтерском учете, отражения в налоговом учете.

При выборе вида операции Досрочное прекращение договора флажок Суммы доходов установлен и недоступен для изменения. Флажок Порядок оплаты следует установить, если сумму корректировки предстоящих доходов по договору необходимо рассчитать на основании порядка (графика) оплаты по долгосрочному договору за незавершенные периоды обучения, либо за произвольный указанный период. В противном случае, при автоматическом расчете остаток предстоящих доходов по договору на счете 401.40 "Доходы будущих периодов" будет помещен в колонку Изменить (+ / -) с минусом, таким образом, после проведения документа весь остаток предстоящих доходов по договору будет обнулен.

Примечание. Группа реквизитов Увеличение (уменьшение) стоимости образовательных услуг используется для автоматического пересчета порядка (графика) оплаты по договору за незавершенные периоды обучения, либо за произвольный указанный период. С помощью опции Изменить суммы на процент (индексация) можно увеличить (уменьшить) стоимость обучения за указанные периоды на относительную величину (в процентах), с помощью опции Распределить сумму по периодам - на абсолютную величину (в валюте). Если дата начала (окончания) периода пересчета не совпадает с началом (окончанием) периода обучения (семестра, месяца и пр.), расчет производится пропорционально количеству календарных дней, вошедших в период пересчета.
Примеры:
1) При предоставлении скидки на обучение на следующий календарный год можно ввести сумму скидки (с минусом) в поле Распределить сумму по периодам, а в полях За периоды с/по указать период предоставления скидки.
2) При досрочном прекращении долгосрочного договора, действовавшего с 01.09.2020 по 19.10.2021, в поле Изменить суммы на процент (индексация) можно ввести значение -100%, а в поле За периоды с указать дату 20.10.2021 (дату окончания указывать в данном случае необязательно, поскольку пересчет выполняется до конца срока действия договора).

Закладка "Доходы будущих периодов"

При нажатии на кнопку Заполнить табличная часть на закладке Доходы будущих периодов автоматически заполняется по остаткам на счете учета доходов по долгосрочным договорам с учащимися (401.40 "Доходы будущих периодов"):

  • Номенклатура – элемент справочника Номенклатура, номенклатура услуг (работ) для аналитического учета доходов будущих периодов (401.40).
  • Остаток – автоматически заполняются остатки предстоящих доходов по выбранному договору.
  • Изменить (+ / -) – следует ввести суммы корректировки предстоящих доходов за оставшийся срок договора. При досрочном прекращении договора заполняется автоматически.
  • После изменения – автоматически рассчитываются суммы предстоящих доходов за оставшийся срок договора с учетом произведенных корректировок.
  • Счет учета – автоматически заполняется счет учета доходов будущих периодов (401.40), включая КФО, КПС и КЭК.
  • Расчеты – автоматически заполняется счет расчетов (205.ХХ) в зависимости от значения КЭК доходов. При необходимости, значения можно изменить.

Закладка "Порядок учета доходов"

Закладка Порядок учета доходов доступна при выборе в шапке документа вида операции Корректировка доходов будущих периодов и установке флажка Порядок учета доходов.
Закладка Порядок учета доходов заполняется аналогично закладке Порядок учета доходов документа Начисление доходов будущих периодов (образование).

Закладка "Порядок оплаты"

Закладка Порядок оплаты применяется, чтобы скорректировать порядок оплаты по договорам с учащимися. Данная закладка доступна при выборе в шапке документа вида операции Корректировка доходов будущих периодов.
Первоначально строки табличной части заполняются автоматически актуальными данными по договору с учащимся. Строки, заполненные автоматически, не подлежат удалению или корректировке. Для того, чтобы изменить сумму оплаты по такой строке следует указать соответствующую сумму изменения с плюсом или минусом в колонке Сумма. Для добавления новых строк следует использовать кнопку Добавить командной панели, либо ввести новые строки копированием существующих.
Например, для переноса даты оплаты по договору с учащимся на месяц вперед, следует в строке с первоначальной датой оплаты (реквизит Оплатить до) в колонке Сумма указать сумму корректировки с минусом. Затем следует добавить новую строку с новой датой оплаты и в колонке Сумма указать ту же сумму корректировки с плюсом.
После произведенных корректировок, показатели в колонке После изменения будут пересчитаны автоматически.

  • Оплатить до – планируемая (крайняя) дата оплаты, после которой платеж будет считаться просроченным.
  • До изменения – первоначальная сумма.
  • Сумма – указывается сумма корректировки с плюсом или с минусом.
  • После изменения – автоматически рассчитывается сумма с учетом произведенных корректировок.
  • Валюта – валюта расчетов.
  • Период обучения – период оказания образовательных услуг (месяц, семестр и т.п.), следует указать дату начала и окончания периода.
  • Примечание – произвольное примечание, например, "1 семестр", "2 семестр" и т.п.

Итоговая сумма корректировки порядка оплаты должна соответствовать итоговой сумме корректировки доходов будущих периодов.

Закладка "Бухгалтерская операция"

Типовая операция – выбирается из списка Типовые операции.
При выборе типовой операции Корректировка доходов будущих периодов (205.00) при проведении документа формируются следующие бухгалтерские записи:

При корректировке в сторону увеличения:

  • Дт 0 205 30 56Х - Кт 0 401 40 13Х – увеличение предстоящих доходов.

При корректировке в сторону уменьшения:

  • Дт 0 401 40 13Х – Кт 0 205 30 66Х – уменьшение предстоящих доходов.

При отражении досрочного прекращения договора или корректировок в межотчетном периоде (датой 31.12.20ХХ 23:59:59 с установленным флажком Отразить в межотчетном периоде) для всех видов операций доступна типовая операция Корректировка доходов будущих периодов в межотчетном периоде (401.30). При проведении документа с данной типовой операцией формируются аналогичные проводки в корреспонденции со счетом 401.30 "Финансовый результат прошлых отчетных периодов".

Дополнительные возможности

На основании документа Корректировка, прекращение долгосрочного договора (образование) можно ввести документы Начисление доходов будущих периодов (образование), Начисление за услуги образования, Начисление учащимся за прочие услуги и Сторно.
