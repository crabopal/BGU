Документ "Решение о признании объектов нефинансовых активов (имущество казны)"

Документ Решение о признании объектов нефинансовых активов (имущество казны) предназначен:

  • для принятия к учету на счета 108.00 объектов имущества казны со счета 106.50 при их приобретении, изготовлении.
  • для отражения операций по увеличению стоимости объектов после модернизации, реконструкции объектов имущества казны.

После записи документа и голосования членов комиссии можно сформировать Лист голосования.

После проведения и подписания должностными лицами документа формируется унифицированная форма электронного первичного документа (ЭД) Решение о признании объектов нефинансовых активов (ф. 0510441).

Работа со списком документов

Список документов вида Решение о признании объектов нефинансовых активов (имущество казны) можно открыть с помощью команды Решение о признании объектов нефинансовых активов (имущество казны), размещенной в группе Основные средства, НМА, НПА меню функций раздела Имущество казны.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Решение о признании объектов нефинансовых активов (имущество казны).

Заполнение реквизитов шапки документа

Документ-основание – документ, являющийся основанием ввода. Основанием могут выступать следующие документы:

  • Поступление ОС, НМА, НПА (имущество казны);
  • Реконструкция, модернизация ОС (имущество казны).

Примечание. При вводе на основании документов Поступление ОС, НМА, НПА (имущество казны) и Реконструкция, модернизация ОС (имущество казны) документ заполняется автоматически.

Вид операции – определяет операцию, которая будет оформляться документом. Доступны три вида операций:

  • Признание объектов нефинансовых активов в связи с приобретением;
  • Признание объектов нефинансовых активов в связи с созданием хозяйственным способом;
  • Признание (удорожание) объектов нефинансовых активов при реконструкции (модернизации), дооборудовании.

Вид объекта – выбирается наименование аналитической группы нефинансовых активов, которая определяет счет учета объекта (группы объектов) имущества казны.

КФО – код финансового обеспечения, за счет которого объекты принимаются к учету.

Поступление библиотечного фонда на карточку группового учета – флажок следует включить, если оформляется поступление библиотечного фонда. При включенном флажке в табличной части скрывается реквизит Количество, а при проведении не контролируется его заполнение.

Формировать движения по модернизации – определяет, будет ли документ формировать движения по регистрам при проведении. Флажок виден, только для вида операции Признание (удорожание) объектов нефинансовых активов при реконструкции (модернизации), дооборудовании.

Примечание. Согласно Методическим рекомендациям, доведенным письмом Минфина России от 01.12.2022 № 02-07-07/117981 при оформлении операций модернизации должны оформляться два первичных документа Акт приема-сдачи отремонтированных объектов основных средств (ф. 0504103) и Решение о признании объектов нефинансовых активов (ф. 0510441).
Для формирования Акта (ф. 0504103) используется документ Реконструкция, модернизация ОС (имущество казны), а для Решения (ф. 0510441) – документ Решение о признании объектов нефинансовых активов (имущество казны).
При этом движения по регистрам формирует только один из документов.
Документ Решение о признании объектов нефинансовых активов можно создать из документа Реконструкция, модернизация ОС (имущество казны) по кнопке Создать на основании. При создании способом "на основании" движения по регистрам будут сформированы в документе Решение о признании объектов нефинансовых активов, так как будет автоматически установлен флажок Формировать движения по модернизации.
При установке флажка Формировать движения по модернизации на форме документа появляются дополнительные реквизиты, необходимые для формирования движений.

Закладка "Общие сведения"

В группе Получатель необходимо заполнить реквизиты:

  • ЦМО – ответственное лицо, на которое принимаются объекты нефинансовых активов имущества казны, и которое будет обеспечивать сохранность и целевое использование объектов.
  • Подразделение – если учет ведется по подразделениям, то указывается подразделение, в которое принимаются объекты нефинансовых активов имущества казны.

В группе Отправитель заполняются реквизиты:

  • Контрагент – организация, выполнившая поставку, изготовление или модернизацию объекта (группы объектов).
  • Договор – договор, по которому поступают объекты от контрагента.

Примечание. Группа Отправитель видна при выполнении одного из условий:
– если счет учета (реквизит Вид объекта) имеет субконто "Договоры";
– если в шапке документа выбран вид операции Признание (удорожание) объектов нефинансовых активов при реконструкции (модернизации), дооборудовании и включен флажок Формировать движения по модернизации;
– если заполнен документ-основание.

Закладка "Стоимость вложений"

В реквизите Объект вложений указывается объект капитальных вложений, на котором накоплена фактическая стоимость ОС, НМА и НПА имущества казны (на счете 106.50). Объект вложений можно выбрать из справочника Основные средства, НМА, НПА или подбирать по остаткам на счетах 106.50 по кнопке Подобрать по остаткам. После заполнения объекта вложений реквизиты Счет вложений, Сумма вложений и Количество заполняются автоматически.

Кнопка Рассчитать сумму вложений (справа от реквизита Счет вложений) выполняет пересчет сумм вложений.

В группе Карточка капвложений, если включен флажок Отразить в карточке капвложений, в реквизите Карточка капвложений следует указать созданную ранее карточку капвложений, для формирования записей в регистр сведений Операции капвложений с целью отражения информации о завершении вложений (инвестиций) в объекты основных средств, нематериальных, непроизведенных активов имущества казны в Карточке учета капитальных вложений (ф. 0509211).

Закладка "Основные средства, НМА, НПА"

Табличная часть закладки заполняется объектами, которые принимаются к учету, а также соответствующими учетными данными по каждому объекту.

Табличную часть можно заполнить путем подбора из справочника Основные средства, НМА, НПА по кнопке Подобрать.

Есть возможность группового изменения данных строк табличной части. Для этого нужно выделить строки, данные которых нужно изменить, и нажав на кнопку Изменить выделенные строки выбрать один из пунктов:

  • Заполнить реквизиты – для группового заполнения реквизитов выделенных строк;
  • Отражение в учете – для заполнения группы реквизитов Отражение в учете выделенных строк.

Примечание. Группа реквизитов Отражение в учете видна только, если в учетной политике учреждения на закладке Имущество казны включен флажок Начислять амортизацию имущества казны.

Для вида операции Признание (удорожание) объектов нефинансовых активов при реконструкции (модернизации), дооборудовании в табличную часть подбираются объекты, которые были модернизированы.

Также становится доступна кнопка Рассчитать стоимости, по которой можно рассчитать стоимость и учетный КПС объектов, подобранных в табличную часть.

Закладка "Сведения о видах работ"

Закладка доступна, если в шапке документа выбран вид операции Признание (удорожание) объектов нефинансовых активов при реконструкции (модернизации), дооборудовании.

Табличная часть закладки заполняется по кнопке Перенести из таблицы "Основные средства…".

В табличной части дополнительно можно указать Вид работы, дополнительную детализацию суммы затрат, выделив из нее суммы на транспортировку и демонтаж.

Закладка "Комиссия"

В реквизите Комиссия из справочника Комиссии следует выбрать действующую комиссию учреждения, которая принимает решение о признании объектов НФА активом.

После выбора комиссии состав комиссии заполнится автоматически, при этом в таблице необходимо отметить отсутствующих членов комиссии и указать причину их отсутствия.

После записи документа (кнопка Записать) на закладке Основные средства, НМА, НПА становится доступной возможность зарегистрировать результаты голосования членов комиссии. Для этого в группе Голосование в поле Сотрудник выбирается член комиссии, который по кнопке Установить решение и выборе За… или Против… принимает решение по каждому объекту НФА.

Если в группе Голосование в поле Сотрудник должностное лицо не выбрано, становится доступной возможность согласовать всеми единовременно по кнопке Единогласное решение и выборе Установить решение "За" во всех строках или Установить решение "Против" во всех строках.

Сохранить результаты голосования можно по кнопке Сохранить результаты в группе Голосование, расположенной на закладке Основные средства, НМА, НПА.

Примечание. В таблице Основные средства, НМА, НПА становится доступной дополнительная графа Решение – решение За или Против выбранного члена комиссии по строке документа (по каждому объекту НФА).

Итог голосования всех членов комиссии оформляется Листом голосования.

Закладка "Драгоценные материалы"

На закладке Драгоценные материалы указываются содержащиеся в основных средствах, НМА и НПА имущества казны драгоценные материалы.

Примечание. Закладка не доступна для вида операции Признание (удорожание) объектов нефинансовых активов при реконструкции (модернизации).

Табличная часть, расположенная в левой части закладки, содержит список всех объектов, которые указаны на закладке Основные средства, НМА, НПА.

Данные о содержании драгоценных металлов и камней вводятся в форму Редактирование списка драг. материалов в объектах.

Для вызова формы следует установить курсор на строку с объектом и использовать кнопку Редактировать для объекта / драг. материалы командной панели левой табличной части.

Для ввода строк в форму Редактирование списка драг. материалов в объектах можно использовать кнопку Добавить.

Реквизиты формы Редактирование списка драг. материалов в объектах:

Драгоценный материал – драгоценный металл или камень. Выбирается из справочника Драгоценные материалы.

Масса в объекте – масса драгоценного металла или камня, которая содержится в одном объекте.

Общая масса – суммарная масса драгоценного металла или камня во всех объектах, указанных в строке. Рассчитывается автоматически как произведение значений реквизитов Количество и Масса в объекте.

Единица измерения – выбирается из справочника Классификатор единиц измерения.

Количество в объекте (шт.) – количество драгоценных камней в объекте, в штуках.

Общее количество (шт.) – общее количество драгоценных камней во всех объектах, указанных в строке, в штуках.

После заполнения формы Редактирование списка драг. материалов в объектах следует нажать на кнопку Добавить в документ.

В результате в табличной части Содержание драгоценных материалов, расположенной справа, появится одна или несколько строк с информацией о драгоценных материалах, которые содержатся в объектах.

Также табличную часть Содержание драгоценных материалов можно заполнить по данным технической документации по кнопке Заполнить по тех. документации, если эти данные были заполнены для объектов.

Закладка "Бухгалтерская операция"

Типовая операция автоматически проставляется в зависимости от вида операции, установленного в шапке документа.

Для видов операций Признание объектов нефинансовых активов в связи с приобретением и Признание объектов нефинансовых активов в связи с созданием хозяйственным способом используется типовая операция "Признание объектов НФА (приобретение и изготовление)", при проведении документа отражаются бухгалтерские записи:

  • Д-т 1.108.ХХ.3ХХ, К-т 1.106.5Х.3ХХ – приняты к учету объекты основных средств, НМА, НПА, прав пользования НМА;
  • Д-т 1.401.20.271 (1.109.ХХ.271), К-т 1.108.ХХ.41Х – списаны объекты при выдаче в эксплуатацию. Формируется, если по объекту установлен Порядок погашения стоимости "Списание при вводе в эксплуатацию", и объект выдается в эксплуатацию документом принятия к учету;
  • Д-т 1.401.20.271 (1.109.ХХ.271), К-т 1.104.ХХ.4ХХ – начисление 100% амортизации при вводе в эксплуатацию. Формируется, если по имуществу казны начисляется амортизация и по объекту установлен Способ начисления амортизации "100 % при вводе в эксплуатацию", и он выдается в эксплуатацию документом принятия к учету.

Примечание. При заполнении документа Решение о признании объектов нефинансовыми активами (имущество казны) с видом операции Признание объектов нефинансовых активов в связи с созданием хозяйственным способом на закладке Стоимость вложений в реквизите Количество следует указать количество изготовленных ОС или НМА для расчета первоначальной стоимости. Реквизит Количество открыт для редактирования, его следует заполнить вручную.

Для вида операции Признание (удорожание) объектов нефинансовых активов при реконструкции (модернизации), дооборудовании используется типовая операция "Реконструкция, модернизация", при условии установки в шапке документа флажка Формировать движения по модернизации. При проведении документа отражаются бухгалтерские записи:

  • Д-т 1.108.50.3ХХ (1.108.90.3ХХ), К-т 1.106.51.3ХХ (1.106.91.3ХХ) – принятие к учету ОС имущества казны в связи с реконструкцией (модернизацией), дооборудованием по стоимости удорожания.

Внимание!
Бухгалтерские записи формируются только по строкам документа, по которым резолюция комиссии была одобрена в результате голосования.

Дополнительные возможности

На основании документа Решение о признании объектов нефинансовых активов (имущество казны) можно ввести документ Регистрация капвложений, Реконструкция, модернизация ОС (имущество казны), Сторно.
