Документ "Кассовое поступление"

Документ Кассовое поступление является универсальным документом, предназначенным для формирования проводок по входящим расчетно-платежным документам, регистрирующим поступление на лицевой счет учреждения платы за продукцию, выполненные работы, оказанные услуги; ошибочно зачисленных на лицевой счет средств; возвращенных поставщиком сумм по не отоваренным счетам и т.п.

В одном документе можно отразить поступление на счет средств, которые должны быть отнесены на несколько счетов бухгалтерского учета и на разные статьи доходов и расходов.

Документ позволяет оформить следующие хозяйственные операции:

  • возврат остатков подотчетных сумм (208 00);
  • возврат задатка (залога, обеспечения) (210.05);
  • возникновение (принятие) долговых обязательств (301.00);
  • изменение остатков денежных средств по КФО (304.06);
  • погашение дебиторской задолженности поставщиков (302.00, 206.00);
  • погашение задолженности по налогам и сборам (303.00);
  • погашение задолженности по предоставленным кредитам, займам (ссудам), по уплаченным гарантиям (207.00);
  • поступление (возврат) неиспользованных остатков денежных средств (1 201 23, 1 304 04);
  • поступление (зачисление) денежных средств в доход бюджета (1 201 23);
  • поступление (зачисление) денежных средств со счета "Денежные средства учреждения в пути" (201.23);
  • поступление бюджетного финансирования на банковский счет (1 304 04);
  • поступление доходов (205.00, 209.00);
  • поступление наличных в счет восстановления расходов (210.03);
  • поступление наличных в счет доходов (210.03);
  • поступление наличных в счет средств во временном распоряжении (3 210 03);
  • поступление родительской платы;
  • поступление средств во временном распоряжении (304.01);
  • поступление средств от головного учреждения, обособленного подразделения (304.04).

В программе реализовано отражение исполнения графика платежей по договорам с ведением графиков платежей при проведении документа Кассовое поступление с типовыми операциями:

  • Поступление доходов (205.00, 209.00).
  • Погашение дебиторской задолженности поставщиков (302.00, 206.00).
  • Погашение задолженности по предоставленным кредитам, займам (ссудам), по уплаченным гарантиям (207.00).

Документ оформляется на основании платежного документа, указанного в выписке казначейства.

Также после заполнения и записи документа можно сформировать Расчетный документ без применения ККТ (Пост. № 296 от 15.03.2017) или бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Документы вида Кассовое поступление находятся в списке расчетно-платежных документов Журнала расчетно-платежных документов.

Чтобы получить доступ к списку расчетно-платежных документов, следует с помощью команды Расчетно-платежные документы меню функций раздела Денежные средства открыть форму Журнала расчетно-платежных документов и перейти на закладку Расчетно-платежные документы.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Расчетно-платежные документы и выбрать в меню пункт Кассовое поступление.

Заполнение реквизитов шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Лицевой счет – лицевой счет организации, на который выполнено перечисление средств. Выбирается в справочнике Реквизиты лицевых счетов.

Кор. счет – корреспондирующий счет расчетов, от выбранного значения реквизита зависит состав доступных типовых операций. Выбирается из списка:

  • 205.00, 209.00 Расчеты по доходам (полученным авансам)

Примечание. Доступны типовые операции:
Поступление доходов (205.00, 209.00).
Поступление родительской платы.
  • 206.00 Расчеты по выданным авансам

Примечание. Доступна типовая операция:
Погашение дебиторской задолженности поставщиков (302.00, 206.00).
  • 207.00 Расчеты по кредитам, займам (ссудам)

Примечание. Доступна типовая операция:
Погашение задолженности по предоставленным кредитам, займам (ссудам), по уплаченным гарантиям (207 00).
  • 208.00 Расчеты с подотчетными лицами

Примечание. Доступна типовая операция:
Возврат остатков подотчетных сумм (208 00).
  • 301.00 Расчеты с кредиторами по долговым обязательствам

Примечание. Доступна типовая операция:
Возникновение (принятие) долговых обязательств (301 00).
  • 302.00 Расчеты по принятым обязательствам

Примечание. Доступна типовая операция:
Погашение дебиторской задолженности поставщиков (302.00, 206.00).
  • 303.00 Расчеты по платежам в бюджеты

Примечание. Доступна типовая операция:
Погашение задолженности по налогам и сборам (303.00).
  • Прочие счета

Поступление (возврат) неиспользованных остатков денежных средств (1 201 23, 1 304 04).
Поступление (зачисление) денежных средств в доход бюджета (1 201 23).

Налог, сбор – вид налога либо иного обязательного платежа. Выбирается из справочника Налоги и платежи организации.

Контрагент – организация (физическое лицо), являющаяся отправителем средств. Выбирается из справочника Контрагенты.

Контроль – гиперссылка для вызова формы Контроль исполнения договоров с информацией об общем объеме запланированных (неисполненных) платежей по договору, а также о сумме просроченных платежей по договору (в т.ч. более 30 и более 90 дней просрочки).

Важно!
Гиперссылка Контроль доступна в документах поступления и списания денежных средств по договорам, в которых задано ведение графиков платежей.

Поступление родительской платы – при поступлении родительской платы следует установить флажок.

Расчеты с использованием ЭСП – при осуществлении расчетов с использованием ККТ с юридическими лицами или индивидуальным предпринимателем следует установить флажок для печати кассовых чеков.

Закладка "Реквизиты документа"
  • Валюта – по умолчанию установлено значение RUB (российский рубль). Если выбрана другая валюта, то дополнительно следует указать сведения о курсе пересчета (реквизиты Курс и Кратность). Курс валюты может выть указан автоматически, если сведения о нем на дату документа содержатся в справочнике Валюты;
  • Сумма – указывается общая сумма платежа по документу в рублях.

В группе Первичный документ следует заполнить реквизиты:

  • Вид – вид первичного документа. Выбирается из справочника Виды первичных документов;
  • Номер – номер первичного документа;
  • Дата – дата первичного документа.

В группе Плательщик, счет плательщика следует заполнить реквизиты:

  • Плательщик – плательщик денежных средств. Выбирается из справочника Контрагенты;
  • Счет плательщика – счет плательщика денежных средств. Выбирается из справочника Банковские и казначейские счета;
  • Идентификатор платежа – уникальный идентификатор платежа (УИП);
  • Назначение платежа – назначение платежа в виде произвольного текста;
  • Исполняемый договор – реквизит используется для определения раздела лицевого счета. Становится виден и доступен для заполнения при осуществлении операций на лицевом счете с признаком ведения казначейского сопровождения в разрезе разделов лицевого счета.

Закладка "Расшифровка платежа"

В табличной части общая сумма кассовой выплаты (документа) детализируется по счетам бухгалтерского учета и аналитическим признакам.

Подобрать – кнопка для вызова формы Подбор платежей по графику, предназначенной для подбора в табличную часть неисполненных по графику платежей. Возвраты денежных средств от поставщиков (кредиторов) и возвраты покупателям (дебиторам) отражаются в графике платежей с минусом.

Важно!
Кнопка Подобрать доступна в документах поступления и списания денежных средств по договорам, в которых задано ведение графиков платежей.

Заполнить по задолженности – кнопка, предназначенная для автоматического заполнения табличной части по остаткам на выбранном Кор. счете (205.00, 206.00, 209.00 и 302.00), по контрагенту, указанному в шапке документа в реквизите Контрагент. Если в шапке документа указано значение для реквизита Договор и учет расчетов на счете ведется по договорам, то остатки дополнительно отбираются только по указанному договору.

Примечание. Кнопка Заполнить по задолженности доступна, только если реквизит Кор. счет принимает значение 205.00, 206.00, 209.00 или 302.00.
  • КФО – код финансового обеспечения. Выбирается из списка.
  • Источник средств – вид средств, за счет которых должно быть оформлено получение средств. Следует выбрать раздел лицевого счета, указанного в шапке документа;
  • КБК – классификационный признак счета, по которому должно быть оформлено получение средств. Выбирается из справочника КПС;
  • КОСГУ – код экономической классификации. Выбирается из справочника КЭК;

Примечание. Для средств во временном распоряжении реквизит КОСГУ не указываются.
  • Сумма – сумма в рублях по соответствующим кодам бюджетной классификации;
  • Договор – основание платежа. Выбирается из справочника Договоры и иные основания возникновения обязательств;
  • Примечание – в случае необходимости, указывается в скобках код цели, а также иная информация, необходимая для исполнения бюджета.

Вид расчетов – выбирается из списка:

  • Основной долг,
  • Проценты,
  • Штрафы,
  • Пени на основной долг,
  • Пени на проценты.

Примечание. Реквизит Вид расчетов заполняется, если в шапке документа выбран Кор. счет 207.00 "Расчеты по кредитам, займам (ссудам)".

В случае когда оплата от покупателей была произведена удаленно электронными средствами платежа (ЭСП) с удержанием комиссии и поступает на расчетный счет по реестру платежей следует заполнить реквизиты Сумма оплаты ЭСП и Сумма комиссии ЭСП.

График платежей – колонка, в которой указываются Вид расчетов и Дата оплаты (по графику платежей).

Важно!
Колонка График платежей доступна в документах поступления и списания денежных средств по договорам, в которых задано ведение графиков платежей.

Счет расчетов – колонка, в которой справочно отображается счет расчетов, соответствующий выбранным КЭК и Кор. счету.

Примечание. Колонка Счет расчетов доступна, только если реквизит Кор. счет в шапке документа имеет значение 205.00, 206.00, 209.00 или 302.00.

Погашение задолженности – может принимать значения:

  • Погасить задолженность – будет выполнено погашение имеющейся задолженности на счете расчетов. Если сумма, указанная в строке табличной части, превысит сумму задолженности на счете расчетов, то программа сформирует соответствующее сообщение.
  • Не погашать – погашение имеющейся задолженности на счете расчетов выполнено не будет. Поступление суммы, указанной в строке табличной части, в этом случае будет интерпретировано как поступление аванса.
  • Автоматически – программа автоматически выбирает способ погашения, Погасить задолженность или Не погашать, исходя из имеющихся остатков задолженности на счете расчетов. При этом вся имеющаяся на счете расчетов задолженность будет погашена, а сумма, превышающая задолженность, будет учтена как аванс.

Примечание. Колонка Погашение задолженности доступна, только если реквизит Кор. счет в шапке документа имеет значение 205.00, 206.00, 209.00 или 302.00.

Важно!
В некоторых случаях родительская плата, а также иная оплата от физических лиц, поступает на расчетный счет по реестру платежей и отражается документом Кассовое поступление с заполненной расшифровкой платежей. Для отражения плательщиков - физических лиц в строках табличной части Расшифровка платежа необходимо наличие поля Контрагент, которое по умолчанию скрыто. Для того чтобы сделать поле Контрагент доступным для заполнения следует нажать на копку Еще командной панели формы документа и выбрать команду Изменить форму. Далее, в окне Настройка формы, следует последовательно раскрыть группы Реквизиты документа, Расшифровка платежа, Расшифровка платежа группа основание и установить флажок у реквизита Контрагент. После подтверждения выбора кнопкой ОК окна Настройка формы в табличной части на закладке Расшифровка платежа появится поле Контрагент. Данные о физических лицах из полученного реестра платежей необходимо ввести в поле Контрагент в каждой строке.

Закладка "Бухгалтерская операция"

Типовая операция – выбирается из списка Типовые операции.

Возникновение (принятие) долговых обязательств (301 00)

Для данной типовой операции необходимо заполнить следующие реквизиты:

Группа Расчеты

  • Счет расчетов – выбирается из фрагмента Плана счетов ЕПСБУ, ограниченного счетами 301.00;
  • КПС расчетов – совпадает с КПС назначения платежа. Выбирается из справочника КПС.

Группа Дебет

  • Счет дебета – выбирается из фрагмента плана счетов (ЕПСБУ). Может принимать значения 201.11, 201.21, 201.27 или 210.02;
  • КПС для счета 201.00 – выбирается из справочника КПС.

Погашение дебиторской задолженности поставщиков (302.00, 206.00)

Для данной типовой операции необходимо заполнить реквизиты:

Группа Дебет

  • Счет дебета – выбирается из фрагмента плана счетов (ЕПСБУ). Может принимать значения 201.11, 201.21, 201.27 или 304.05;
  • КПС для счета 201.00 – выбирается из справочника КПС.

Примечание. Если у организации настроен рабочий план счетов, то заполнение реквизита КПС необязательно.

Группа Переоценка авансов. Реквизиты группы предназначены для переоценки авансов в валюте.

  • Переоценить авансы – флажок, следует установить при необходимости выполнить переоценку аванса;
  • Счет курсовых разниц – имеет по умолчанию значение 401.10;
  • Субконто 1, Субконто 2, Субконто 3 – выбранные субконто Счета курсовых разниц.

Погашение задолженности по налогам и сборам (303.00)

Для данной типовой операции необходимо заполнить реквизиты:

  • Счет дебета – выбирается из фрагмента плана счетов (ЕПСБУ). Может принимать значения 201.11, 201.21, 210.02 или 304.05;
