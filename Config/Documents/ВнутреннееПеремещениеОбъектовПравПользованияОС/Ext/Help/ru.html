Документ "Внутреннее перемещение объектов прав пользования ОС, НПА"

Документ Внутреннее перемещение объектов прав пользования ОС, НПА предназначен для оформления и учета операций по перемещению объектов прав пользования ОС и НПА внутри учреждения от одного материально ответственного лица другому.

Также документ применяется для перемещения объектов прав пользования между подразделениями, если учет прав пользования имуществом ведется по подразделениям.

После заполнения и записи документа можно сформировать печатную форму Накладная на внутреннее перемещение объектов нефинансовых активов (ф. 0510450).

Также после заполнения реквизитов бухгалтерской операции и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида Внутреннее перемещение объектов прав пользования ОС, НПА можно открыть с помощью команды Внутреннее перемещение объектов прав пользования ОС, НПА, размещенной в группе Права пользования меню функций раздела ОС, НМА, НПА, а также в группе Долгосрочные договоры, аренда меню функций раздела Услуги, работы, производство.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Внутреннее перемещение объектов прав пользования ОС, НПА.

Заполнение реквизитов шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Основание – вид документа-основания. Выбирается из справочника Виды первичных документов.

Дата и Номер – дата и номер документа-основания.

В группе Отправитель необходимо заполнить реквизиты:

  • МОЛ/Место хранения – центр материальной ответственности отправителя. Выбирается из справочника Центры материальной ответственности.
  • Подразделение – подразделение отправителя. Выбирается из справочника Подразделения.

В группе Получатель необходимо заполнить реквизиты:

  • МОЛ/Место хранения – центр материальной ответственности получателя. Выбирается из справочника Центры материальной ответственности.
  • Подразделение – подразделение получателя, если ведется учет по подразделениям на счетах 111.00. Выбирается из справочника Подразделения.

Примечание. Реквизит Подразделение будет присутствовать в группах Отправитель и Получатель только в том случае, если будет установлен флажок Учет по подразделениям и настроен учет по подразделениям на счетах 111.00 в разделе Общие настройки формы Настройка параметров учета раздела Администрирование.

Закладка "Права пользования ОС, НПА"

Использование кнопки Заполнить командной панели позволяет заполнить табличную часть закладки всеми объектами прав пользования ОС и НПА по указанному МОЛ и подразделению.

После заполнения табличной части следует удалить строки с объектами прав пользования ОС и НПА, которые не подлежат перемещению.

Для ввода данных в табличную часть вручную можно использовать кнопку Добавить командной панели.

После добавления новой строки в ней следует указать:

  • Право пользования – ОС или НПА, выбирается из справочника Основные средства.
  • Договор – выбирается из справочника Договоры и иные основания возникновения обязательств.

Реквизиты Счет учета, КФО, КПС и Сумма недоступны для редактирования.

Значения данных реквизитов рассчитываются автоматически с помощью кнопки Рассчитать командной панели табличной части.

Примечание. Для выбора прав пользования удобно использовать форму подбора, которая открывается с помощью кнопки Подобрать командной панели табличной части.

После выбора объектов основных средств с использованием формы подбора в строках табличной части будут заполнены реквизиты:

  • Счет учета – субсчет счета 111.00, на котором ведется учет объекта ОС, НПА - права пользования.
  • КФО – код вида финансового обеспечения.
  • КПС – классификационный признак счета.
  • Сумма – учетная стоимость объекта права пользования (справедливая стоимость арендных платежей).

Примечание. При изменении значений реквизитов шапки заполненного документа необходимо перезаполнить табличную часть, так как данные в ней могут не соответствовать новым значениям реквизитов шапки документа. При невыполнении данного требования проведение документа может оказаться невозможным.

Закладка "Бухгалтерская операция"

Для документа предусмотрена одна типовая операция – Внутреннее перемещение.

Регистрация документа

Регистрация документа Внутреннее перемещение объектов прав пользования ОС, НПА производится в журналах Журнал операций и Документы по основным средствам.

Дополнительные возможности

На основании документа Внутреннее перемещение объектов прав пользования ОС, НПА можно ввести документ Сторно.
