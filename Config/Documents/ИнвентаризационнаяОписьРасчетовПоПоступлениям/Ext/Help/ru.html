Документ "Инвентаризационная опись расчетов по поступлениям (ф. 0510468)"

Документ Инвентаризационная опись расчетов по поступлениям (ф. 0510468) применяется инвентаризационной комиссией для отражения результатов проведения инвентаризации расчетов по доходам (поступлениям) учреждений, учтенных на балансовых счетах 020500000 "Расчеты по доходам", 020900000 "Расчеты по ущербу и иным доходам", а также на забалансовых счетах 04 "Сомнительная задолженность", 20 "Задолженность, невостребованная кредиторами".

Документ Инвентаризационная опись расчетов по поступлениям (ф. 0510468) формируется ответственным исполнителем бухгалтерской службы.

После заполнения и записи документа можно сформировать печатную форму Инвентаризационная опись расчетов по поступлениям (ф. 0510468).

Работа со списком документов

Список документов вида Инвентаризационная опись расчетов по поступлениям (ф. 0510468) можно открыть с помощью команды Инвентаризационные описи расчетов по поступлениям (ф. 0510468) меню функций раздела Инвентаризация.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Инвентаризационные описи расчетов по поступлениям (ф. 0510468).

Заполнение реквизитов шапки и подвала документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Подразделение – подразделение, выбирается из справочника Подразделения. Реквизит доступен, если включена настройка Учет по подразделениям (Раздел Главное - Настройки параметров учета - Общие настройки).

ИФО – источник финансового обеспечения, выбирается из одноименного справочника, если включена настройка Учет по ИФО (Раздел Главное - Настройки параметров учета - Общие настройки).

Для начала работы с документом необходимо предварительно в шапке документа указать Решение о проведении инвентаризации (ф. 0510439), в открывшемся окне Выбор данных из Решения с учетом изменений необходимо отметить строку, по которой следует заполнить документ описи, и нажать на кнопку Выбрать строки. После этого будет автоматически заполнена закладка Комиссия составом инвентаризационной комиссии, а также реквизиты в шапке документа Инвентаризационная опись расчетов по поступлениям (ф. 0510468), в группе реквизитов Сведения об инвентаризации из Решения:

  • По состоянию на – дата, по состоянию на которую проводится инвентаризация, в формате "ДД.ММ.ГГГГ";
  • Номер комиссии – номер инвентаризационной комиссии/рабочей комиссии в составе инвентаризационной;
  • Список счетов – список счетов, отобранных из документа Решение о проведении инвентаризации (ф. 0510439);
  • Период проведения с/по – даты начала и окончания инвентаризации в формате "ДД.ММ.ГГГГ";
  • Место проведения – место проведения инвентаризации (адрес, место нахождения), соответствующее показателю поля Место инвентаризации документа Решение о проведении инвентаризации (ф. 0510439).

Примечание. Редактирование вышеперечисленных реквизитов в документе описи не предусмотрено, так как они зафиксированы документом Решении о проведении инвентаризации (ф. 0510439), выбранном в шапке документа.

В подвале документа Инвентаризационная опись расчетов по поступлениям (ф. 0510468) в соответствующих реквизитах следует заполнить ответственного исполнителя бухгалтерской службы и ответственного исполнителя инвентаризационной комиссии.

До начала проведения инвентаризации ответственным исполнителем бухгалтерской службы формируется и подписывается простой ЭП расписка, являющаяся неотъемлемым приложением к Инвентаризационной описи расчетов по поступлениям (ф. 0510468), о том, что к началу проведения инвентаризации все поступления денежных средств подтверждены банковскими выписками, и выписками из лицевых счетов.

Документ Расписка инвентаризации формируется нажатием на гиперссылку Создать расписку после записи документа.

При нажатии на гиперссылку откроется окно созданного документа Расписка инвентаризации, который следует сохранить и провести.

Важно. Заполнение расписки ответственным исполнителем бухгалтерской службы является обязательным условием для продолжения заполнения описи, поэтому только после проведения документа Расписка инвентаризации становится возможным заполнение закладок Раздел 1 (Раздел 1.1, Раздел 1.2) и Раздел 2 (Раздел 2.1, Раздел 2.2) документа Инвентаризационная опись расчетов по поступлениям (ф. 0510468).

Заполнение закладки "Раздел 1"

Раздел 1 "Сведения о расчетах по доходам (поступлениям) по данным бухгалтерского учета" заполняется на закладке Раздел 1 по кнопке Заполнить (По данным бух. учета/Просроченную/Просроченную и без оборотов за год). Документ описи будет заполнен остатками по счетам расчетов по доходам (поступлениям) на конец предыдущего дня от даты, по состоянию на которую проводится инвентаризация, указанной в шапке документа в реквизите По состоянию на.

Например, если инвентаризация проводится перед составлением годовой отчетности за 2025 финансовый год, то реквизит По состоянию на будет заполнен датой 01.01.2026, а остатки по счетам будут взяты на конец дня 31.12.2025.

В результате автозаполнения в табличных частях закладок Раздел 1.1 и Раздел 1.2 будут заполнены реквизиты:

  • N – код строки;
  • Контрагент – наименование контрагента. Заполняется по данным соответсвующего элемента справочника Контрагенты, в разрезе которого существует остаток задолженности;
  • Идентификатор контрагента – генерируется конфигурацией согласно пункту 4 Методических указаний, утв. приказом Минфина России от 15.04.2021 № 61н, хранится в реквизите УИН, в карточке договора (справочнике Договоры и иные основания возникновения обязательств) на закладке Свойства;
  • Договор – заполняется соответствующим элементом справочника Договоры и иные основания возникновения обязательств, в разрезе которого существует остаток задолженности;
  • Дата исполнения – дата исполнения задолженности по документу-основанию.

Для учета задолженности в разрезе дат исполнения, а также для классификации задолженности по срокам исполнения в программе предусмотрены два режима (Раздел Главное – Настройки параметров учета – Ведение учета):

1. Основной режим – ведение графиков исполнения по договору (график платежей, план-график реализации) в специальных аналитических регистрах.

2. Упрощенный режим – в этом случае дата исполнения указывается:

– в карточке договора в реквизите Окончание. Для отнесения задолженности к просроченной следует также установить признак "Просрочен" – в этом случае весь остаток задолженности на счетах бухгалтерского учета (205.00 и пр.) по договору будет отнесен к просроченной задолженности, если дата инвентаризации превышает дату исполнения, указанную в реквизите Окончание.

– в документах Регистрация обязательств и сведений по договорам в реквизите Срок исполнения (погашения). Начиная с указанной предельной даты исполнения, вся задолженность по договору на всех счетах расчетов будет считаться просроченной.

Примечание. Согласно пункту 17 ФСБУ "Единый план счетов бухгалтерского учета государственных финансов", утв. Приказом Минфина от 30.08.2024 № 121н, Стандарт № 121н, в случае невозможности установления конкретной даты исполнения задолженности или обязательства в аналитическом показателе "дата исполнения" отражается значение "31.12.2999", для этого реквизиты Окончание, Срок исполнения (погашения) следует вручную заполнить датой "31.12.2999".

Упрощенный режим применяется, если нет возможности применить основной режим, т.е. нет возможности произвести расчет по графикам исполнения (ведение и контроль исполнения графиков отключены, отсутствует требуемый для расчета график и т.п.). В базовой версии доступен только упрощенный режим.

Если согласно пункту 17 Стандарта № 121н учет задолженности ведется в разрезе дат исполнения (в БГУ2 основной и упрощенный режимы), то реквизит Дата исполнения автозаполняется следующим образом:

– в основном режиме – предельной датой платежа на дату инвентаризации из реквизитов Оплатить до, указанных в Графике платежей. Если же по условиям договора-основания возникновения задолженности предусмотрен аванс: сначала приходит оплата от покупателя, а потом происходит реализация товаров, работ, услуг, то берется последняя дата Плана-графика реализации из реквизита Исполнить до;

– в упрощенном режиме – по дате реквизита Срок исполнения (погашения), указанной в документе Регистрация обязательств и сведений по договорам либо по значению поля Окончание в карточке Договора на закладке Свойства, в зависимости от настройки ведения учета для классификации дебиторской и кредиторской задолженности в упрощенном режиме.

Также в табличных частях закладок Раздел 1.1 и Раздел 1.2 будут автозаполнены реквизиты:

  • КФО, Счет, КПС, КЭК – соответственно, на которых имеются остатки задолженности на дату инвентаризации. При этом для балансовых счетов, реквизит КЭК указывается в виде 00Х, где Х – институциональная единица, определяемая в соответствии с Типом контрагента;
  • Валюта – валюта расчетов;
  • Сумма в валюте – сумма в иностранной валюте;
  • Сумма в рублях – сумма в рублях (рублевом эквиваленте) по соответствующему курсу на дату переоценки валютных остатков.

По кнопке Расшифровать в командной панели соответствующих табличных частей доступна расшифровка расчета показателей долгосрочной и просроченной задолженности по датам исполнения в строке документа. При этом будет сформирован отчет Анализ задолженности в режиме По датам исполнения.

Ручная корректировка табличной части закладки Раздел 1 не предусмотрена.

Раздел 1 формируется и подписывается ответственным исполнителем бухгалтерской службы простой ЭП.

Заполнение закладки "Раздел 2"

Раздел 2 "Сведения о расчетах по доходам (поступлениям) по данным инвентаризационной комиссии" заполняется на закладке Раздел 2.

Раздел 2 содержит табличные части Раздел 2.1 "Дебиторская задолженность по данным инвентаризационной комиссии" и Раздел 2.2 "Кредиторская задолженность по данным инвентаризационной комиссии".

По кнопке Заполнить по данным раздела 1 таблицы заполняется автоматически по данным Раздела 1.

В результате автозаполнения в табличных частях закладок Раздел 2.1 и Раздел 2.2 по данным соответствующих реквизитов табличных частей закладок Раздел 1.1 и Раздел 1.2 будут заполнены реквизиты: N, КФО, Счет, КПС, КЭК, Контрагент, Идентификатор контрагента, Договор, Дата исполнения, Валюта.

Строки графы Всего заполняется по-разному в зависимости от наличия/отсутствия валютного учета. Если расчеты по задолженности ведутся с контрагентом в иностранной валюте, тогда поле разбивается на две строки (в валюте и в рублях).

Строки по графам Краткосрочная (текущая) (14.01), Просроченная (14.02), Долгосрочная (14.03) заполняются согласно настройкам учета задолженности в разрезе дат исполнения, а также классификации задолженности по срокам исполнения и могут быть скорректированы вручную либо полностью заполнены вручную.

Строки по графам Сомнительная (14.04), Истек срок давности (14.05), Безнадежная (14.06), Иная (14.07) заполняются вручную.

По умолчанию, вся задолженность отражается в Разделах 2.1 и 2.2 в реквизите Не подтверждено актом сверки. Если такие акты есть, то сумму задолженности, согласно акту сверки, можно указать вручную (или убрать из поля Не подтверждено актом сверки, после чего она отразится в реквизите Подтверждено актом сверки) и заполнить соответствующие дату и номер.

Группа реквизитов Отражение просроченной и долгосрочной задолженности заполняется вручную. При этом Дата возникновения автоматически заполняется датой начала срока действия договора (правового основания расчетов), указанного в реквизите Срок действия документа Регистрация обязательств и сведений по договорам (группа Сроки договора (обязательства) на закладке Обязательство). Если дата начала срока действия договора не указана, дата возникновения задолженности заполняется датой договора (обязательства), указанного в реквизите Вид обязательства справочника Договоры и иные основания возникновения обязательств. При необходимости, значение в колонке Дата возникновения можно скорректировать вручную.

Реквизит Заключение комиссии заполняется вручную или одним из значений элемента справочника Заключения комиссии по инвентаризационным описям.

После создания (по кнопке Списать - …) и проведения документов по списанию/восстановлению дебиторской/кредиторской задолженности в Разделах 2.1 и 2.2 отражается индикация об их записи и проведении, а в реквизите Документ выводится гиперссылка на документ. Формируется "Чек-лист" по формированию документов на списание сомнительной задолженности: один флаг - записан, два флага - записан и проведен.

По кнопке Расшифровать в командной панели соответствующих табличных частей доступна расшифровка расчета показателей долгосрочной и просроченной задолженности по датам исполнения в строке документа. При этом будет сформирован отчет Анализ задолженности в режиме По датам исполнения.

Команда Групповое заполнение строк предназначена для массового автозаполнения (при необходимости) реквизитов Заключение комиссии, Подтверждено актом сверки, Акт сверки (дата, номер), Не подтверждено актом сверки, группы реквизитов Отражение просроченной и долгосрочной задолженности в выделенных строках

Закладка "Комиссия"

Состав комиссии определен в документе Решение о проведении инвентаризации и изменению не подлежит. Заполняется автоматически при выборе Решения о проведении инвентаризации в соответствующем реквизите.

В таблице можно отметить отсутствующих лиц и замещающее лицо для председателя комиссии.

Примечание. В случаях если в документе Решение о проведении инвентаризации (ф. 0510439) назначены рабочие инвентаризационные комиссии, предварительно заполненные из справочника Комиссии, в котором для членов рабочих комиссий, выступающих в качестве уполномоченных лиц, установлены соответствующие статусы Уполномоченное председателем лицо, то на закладке Комиссия документа Инвентаризационная опись расчетов по поступлениям (ф. 0510468) в качестве подписантов заполняются только уполномоченное председателем лицо и члены этой рабочей комиссии.

Дополнительные возможности

После проведения документа Инвентаризационная опись расчетов по поступлениям (ф. 0510468) для целей списания/восстановления задолженностей становится доступна кнопка Списать и соответствующие подкоманды:

  • на закладке Раздел 2.1 – Списать сомнительную задолженность; Восстановить сомнительную задолженность; Списать безнадежную к взысканию задолженность; Списать сомнительную задолженность по графе 14.04; Списать безнадежную к взысканию задолженность по графе 14.06.
  • на закладке Раздел 2.2 – Списать без последующего наблюдения; Списать с последующим наблюдением; Прекратить наблюдение задолженности; Списать задолженность с истекшим сроком давности по графе 14.05.

Подкоманды закладки Раздел 2.1 предназначены для формирования документа Списание, восстановление задолженности по доходам, закладки Раздел 2.2 – для формирования документа Списание кредиторской задолженности.
