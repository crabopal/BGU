Документ "Изменение решения о проведении инвентаризации"

Документ Изменение решения о проведении инвентаризации применяется для оформления внесения изменений в Решение о проведении инвентаризации (ф. 0510439) или его аннулирования.

Примечание. Внесение изменений в Решение о проведении инвентаризации (ф. 0510439) допускается до начала проведения субъектом учета инвентаризации.

После заполнения и проведения документа по кнопке Печать можно распечатать Изменение решения о проведении инвентаризации (ф. 0510447).

Работа со списком документов

Список документов вида Изменение решения о проведении инвентаризации можно открыть с помощью команды Изменение решение о проведении инвентаризации меню функций раздела Инвентаризация.

Создание нового документа

Документ Изменение решения о проведении инвентаризации вводится на основании соответствующих документов Решение о проведении инвентаризации или Изменение решения о проведении инвентаризации, в которые следует внести изменения, по кнопке Создать на основании.

Заполнение реквизитов документа

После создания на основании документ Изменение решения о проведении инвентаризации автоматически заполнятся данными по документу-основанию, и в шапке документа следует указать соответствующий Тип изменения:

  • Корректирующий – при изменении условий решения о проведении инвентаризации. При этом становятся доступны для редактирования те же реквизиты на закладках, что в документе Решение о проведении инвентаризации на этапе его создания или редактирования.

На закладках Объекты инвентаризации и Инвентаризационные комиссии в графе Тип изменения следует построчно выбрать соответствующий тип изменений: "корректировка" или "отмена". В случае указания типа изменения как "корректировка" следует скорректировать нужные графы табличной части в строке Новое.

С помощью кнопки Добавить в табличную часть закладки Объекты инвентаризации можно ввести новые строки, в которых автоматически заполнится графа Тип изменения – "дополнение".

  • Аннулирующий – при полной отмене решения о проведении инвентаризации. При этом нельзя будет редактировать данные в документе.

В остальном, порядок заполнения, подписания и утверждения документа Изменение решения о проведении инвентаризации аналогичен порядку заполнения, подписания и утверждения документа Решение о проведении инвентаризации.
