Документ "Корректировка доходов будущих периодов"

Документ Корректировка доходов будущих периодов предназначен для отражения в учете операций:

  • по досрочному расторжению договора аренды (имущественного найма) или договора безвозмездного пользования;
  • по иным корректировкам, например, при изменении размера арендных платежей, предоставлении льгот и пр.
  • по корректировке доходов будущих периодов по иным долгосрочным договорам, в частности, по субсидиям, полученным на выполнение государственного задания;
  • по уменьшению объема предоставленных средств субсидий, грантов;
  • по корректировке порядка признания доходов текущего периода, например, при изменении способа и срока признания доходов, счета и аналитики учета доходов, отражения в налоговом учете.

После заполнения реквизитов бухгалтерской операции и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида Корректировка доходов будущих периодов можно открыть с помощью команды Корректировка доходов будущих периодов, размещенной в группе Долгосрочные договоры меню функций раздела Услуги, работы, производство.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Корректировка доходов будущих периодов.

Заполнение реквизитов шапки документа

Контрагент – выбирается из справочника Контрагенты.
Договор – выбирается из справочника Договоры и иные основания возникновения обязательств.
Вид операции – выбирается из списка:

  • Досрочное прекращение договора – в случае досрочного расторжения долгосрочных договоров, договоров аренды (имущественного найма) или договоров безвозмездного пользования.
  • Корректировка доходов будущих периодов – при иных корректировках предстоящих доходов по договору. Например, при изменении размера арендных платежей, предоставлении льгот, при уменьшении объема предоставленных средств межбюджетных трансфертов, субсидий и пр.

При выборе вида операции Корректировка доходов будущих периодов необходимо установить флажки Суммы доходов и/или Порядок учета доходов в зависимости от того, что планируется изменить этим документом:

  • Суммы доходов – для изменения сумм доходов, в т.ч. арендных платежей по договору, упущенной выгоды по договорам аренды на льготных условиях или безвозмездного пользования (т.е. изменения стоимости аренды по договору и / или справедливой стоимости);
  • Порядок учета доходов – для изменения параметров признания доходов текущего периода (по месяцам / по календарным дням / по графику / в особом порядке), периода списания доходов, счета и аналитики учета доходов в бухгалтерском учете, отражения в налоговом учете.

Примечание. Признание в текущем (последнем) месяце доходами текущего финансового года доходов будущих периодов (ДБП) по долгосрочным договорам и соглашениям, а также отнесение на финансовый результат текущего периода отложенных расходов по упущенной выгоде (РБП) по договорам аренды на льготных условиях и безвозмездного пользования производится документом Списание доходов будущих периодов, также как и при регламентном ежемесячном отражении этих сумм на счетах финансового результата текущего периода.
Для признания доходов и расходов в текущем (последнем) месяце, в группе реквизитов Признание доходов за текущий месяц необходимо указать период фактического действия договора (соглашения) в текущем (последнем) месяце и нажать на кнопку Сформировать. Например, при досрочном прекращении договора аренды на льготных условиях для списания сумм ДБП и РБП необходимо указать срок пользования имуществом в текущем (последнем) месяце. Документ Списание доходов будущих периодов в этом случае будет сформирован на дату окончания договора с учетом фактического количества дней пользования имуществом в текущем (последнем) месяце. При необходимости, рассчитанные автоматически суммы можно скорректировать вручную.

Закладка "Доходы будущих периодов"

При нажатии на кнопку Заполнить табличная часть на закладке Доходы будущих периодов автоматически заполняется по остаткам на счете учета доходов по долгосрочным договорам (соглашениям), по договорам предоставления прав пользования в операционную аренду (401.40 "Доходы будущих периодов") и по упущенной выгоде по договорам аренды на льготных условиях или безвозмездного пользования (счет 401.50"Расходы будущих периодов"):
Номенклатура – элемент справочника Номенклатура, номенклатура услуг (работ) для аналитического учета доходов будущих периодов (401.40).
В колонке Счет учета заполняются счета учета доходов и расходов будущих периодов:

  • счет учета доходов будущих периодов (401.40, 401.41, 401.49), включая КФО, КПС и КЭК;
  • счет учета упущенной выгоды (401.50), возникающей по договорам безвозмездного пользования и договорам аренды на льготных условиях, включая КФО, КПС и КЭК.

В колонке Остаток автоматически заполняются остатки предстоящих доходов по выбранному договору, а если в шапке документа выбран договор безвозмездного пользования или договор аренды на льготных условиях, то также заполняются остатки предстоящих расходов по упущенной выгоде от предоставления прав пользования активом.
В колонке Изменить (+ / -):

  • По договорам аренды (безвозмездного пользования) в строках Справедливая стоимость и Упущенная выгода вводятся суммы корректировки арендных платежей за оставшийся срок договора. В строке Сумма по договору автоматически рассчитывается корректировка суммы расчетов по договору.
  • По прочим долгосрочным договорам вводятся суммы корректировки предстоящих доходов за оставшийся срок договора.

После произведенных корректировок, показатели в колонке После изменения будут пересчитаны автоматически.
В колонке Расчеты автоматически заполняется счет расчетов (205.ХХ) в зависимости от значения КЭК доходов. При необходимости, значения можно изменить.
Статья РБП по упущенной выгоде – предопределенный элемент Упущенная выгода по договорам аренды на льготных условиях справочника Расходы будущих периодов. Автоматически заполняется по договорам безвозмездного пользования и договорам аренды на льготных условиях.

Закладка "Порядок учета доходов"

Закладка Порядок учета доходов доступна при выборе в шапке документа вида операции Корректировка доходов будущих периодов и установке флажка Порядок учета доходов.
Закладка Порядок учета доходов заполняется аналогично закладке Порядок учета доходов документа Начисление доходов будущих периодов.

Закладка "Бухгалтерская операция"

Типовая операция – выбирается из списка Типовые операции.
При выборе типовой операции Корректировка доходов будущих периодов (205.00, 210.05) при проведении документа формируются следующие бухгалтерские записи:

В случае корректировки объектов учета операционной аренды в бухгалтерском учете правообладателя (арендодателя) имущества:

В сторону увеличения:

  • Дт 0 205 00 56Х (0 210 05 56Х) - Кт 0 401 40 12Х – увеличение предстоящих доходов от предоставления права пользования активом;
  • Дт 0 401 50 2ХХ - Кт 0 210 05 66Х – увеличение остатка расходов по упущенной выгоде от предоставления права пользования активом (при аренде на льготных условиях).

В сторону уменьшения:

  • Дт 0 401 40 12Х – Кт 0 205 00 66Х (0 210 05 66Х) – уменьшение предстоящих доходов от предоставления права пользования активом;
  • Дт 0 210 05 56Х – Кт 0 401 50 2ХХ – уменьшение остатка расходов по упущенной выгоде от предоставления права пользования активом (при аренде на льготных условиях).

В случае корректировки доходов будущих периодов по иным долгосрочным договорам реализации:

В сторону увеличения:

  • Дт 0 205 00 56Х - Кт 0 401 40 1ХХ (0 401 41 1ХХ, 0 401 49 1ХХ) – увеличение предстоящих доходов.

В сторону уменьшения:

  • Дт 0 401 40 1ХХ (0 401 41 1ХХ, 0 401 49 1ХХ) – Кт 0 205 00 66Х – уменьшение предстоящих доходов.

При отражении досрочного прекращения договора или корректировок в межотчетном периоде (датой 31.12.20ХХ 23:59:59 с установленным флажком Отразить в межотчетном периоде) для всех видов операций доступна типовая операция Корректировка доходов будущих периодов в межотчетном периоде (401.30). При проведении документа с данной типовой операцией формируются аналогичные проводки в корреспонденции со счетом 401.30 "Финансовый результат прошлых отчетных периодов".
Для отражения уменьшения объема предоставленных средств субсидии (гранта) применяется типовая операция Уменьшение объема предоставленных средств субсидии, гранта (401.40 - 205.00). При проведении документа формируются следующие бухгалтерские записи:

  • Дт 0 401 40 1ХХ - Кт 0 205 00 66Х– уменьшение дебиторской задолженности по субсидиям (грантам) в связи с уменьшением объема предоставленных средств согласно соглашению (договору).

Регистрация документа

Регистрация документа Корректировка доходов будущих периодов производится в журналах Журнал операций и Журнал расчетов с покупателями.

Дополнительные возможности

На основании документа Корректировка доходов будущих периодов можно ввести документы Списание доходов будущих периодов и Сторно.
