Документ "Плановые поступления оплаты (образование)"

Документ Плановые поступления оплаты (образование) предназначен для ввода данных об ожидаемых в определенном периоде на заданную дату поступлениях сумм оплаты за образовательные услуги. Источником данных для документа являются документы Приказ (образование). Ввод плановых поступлений позволит в дальнейшем проанализировать соответствие сумм плановых и фактических поступлений за указанный период времени.

Примечание. Данный документ применяется только по краткосрочным договорам образования. В случае, если в программе по учащимся заполнены справочники подсистемы Образовательные услуги и в Приказе (образование) для краткосрочных договоров заданы Ставки оплаты, то документы подсистемы заполняются автоматически по заданным отборам.

Работа со списком документов

Список документов Плановые поступления оплаты (образование) можно открыть с помощью команды Плановые поступления оплаты (образование) меню функций раздела Платное обучение.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Плановые поступления оплаты (образование).

Заполнение реквизитов шапки документа

  • За период – после установки флага следует указать период, за который вводятся суммы планового поступления оплаты. При снятом флаге необходимо задать период в каждой строке табличной части;
  • На дату оплаты – после установки флага следует указать дату оплаты. При снятом флаге необходимо задать дату оплаты в каждой строке табличной части;
  • Факультет – наименование факультета, выбирается из справочника Подразделения;
  • Номенклатура – наименование образовательной услуги. Выбирается из фрагмента справочника Номенклатура, ограниченного списком услуг.

Заполнение табличной части

Для добавления строк в табличную часть закладки вручную можно использовать кнопку Добавить командной панели.

Для автоматического заполнения данными табличной части следует нажать на кнопку Заполнить и выбрать в меню команду Учащиеся по отбору. Откроется форма Настройка параметров отбора учащихся, которая настроена по умолчанию на отбор учащихся по факультету, указанному в шапке документа, и которая может быть при необходимости дополнена отбором по другим реквизитам – Группа, Курс, Льгота и т.д. По окончании настройки отбора после нажатия на кнопку Выполнить отбор и заполнить документ табличная часть на закладке будет заполнена данными.

Внимание! Табличная часть заполняется данными, которые актуальны на дату документа.

Реквизиты табличной части:

  • Учащийся – учащийся факультета;
  • Группа Плательщик включает реквизиты Контрагент и Договор контрагента, которые указаны в карточке учащегося;
  • Сумма – ожидаемая сумма оплаты. Рассчитывается автоматически с помощью кнопки Рассчитать на основании данных, введенных документами вида Приказ (образование).

Следует учитывать, что каждый последующий документ вида Плановые поступления оплаты (образование) с совпадающей датой оплаты отменяет плановое поступление суммы в предыдущем документе и устанавливает новую плановую сумму.

Для того чтобы сторнировать суммы плановых поступлений, необходимо ввести новый документ Плановые поступления оплаты (образование) с установленным в строках табличной части флагом Аннуляция.

Примечание. При включенном флаге Аннуляция в табличной части остается доступным для заполнения только поле Дата оплаты, которое необходимо заполнить. При проведении документа суммы во всех отмеченных строках сторнируются полностью.

Дополнительные возможности

На основании документа Плановые поступления оплаты (образование) можно создать документ Квитанция на оплату.
