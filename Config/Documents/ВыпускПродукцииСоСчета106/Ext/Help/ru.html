Документ "Выпуск продукции со счета 106.хИ"

Документ Выпуск продукции со счета 106.хИ предназначен для оприходования готовой продукции, изготовленной для собственного потребления, со счетов 106.хИ (106.2И и 106.3И).

После заполнения и записи документа можно сформировать печатную форму Требования-накладная (ф. 0510451).

Также после заполнения реквизитов бухгалтерской операции и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида Выпуск продукции со счета 106.хИ можно открыть с помощью команды Выпуск продукции со счета 106.хИ меню функций раздела Услуги, работы, производство.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Выпуск продукции со счета 106.хИ.

Заполнение реквизитов шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Счет производства – полный счет производства, на котором были собраны затраты на изготовление продукции. Выбирается из фрагмента Плана счетов, ограниченного счетами 106.2И и 106.3И.

КПС, КФО и КЭК заполняются автоматически после выбора значения реквизита Счет производства.

Группа реквизитов Отправитель (данные для печати):

  • МОЛ/Место хранения – центр материальной ответственности в производстве. Выбирается из справочника Центры материальной ответственности.
  • Подразделение – подразделение производства. Выбирается из справочника Подразделения.

Группа реквизитов Получатель:

  • МОЛ/Место хранения – центр материальной ответственности на складе. Выбирается из справочника Центры материальной ответственности.
  • Подразделение – подразделение склада. Выбирается из справочника Подразделения.

Табличная часть "Продукция"

Табличная часть Продукция содержит перечень выпущенной продукции — элементы справочника Номенклатура.

В каждой строки табличной части следует указать количество выпущенной продукции и полный рабочий счет, на который она будет оприходована.

Табличная часть "Затраты на выпуск продукции"

Табличная часть Затраты на выпуск продукции содержит список видов затрат, которые пошли на изготовление продукции, КПС, по которым затраты были собраны и суммы.

Примечание. Табличная часть Затраты на выпуск продукции отображает затраты по строке, являющейся текущей в таблице Продукция.

Заполнение табличных частей

Если необходимо списать со счета 106.хИ затраты по всем выпущенным позициям номенклатуры, то следует использовать кнопку Заполнить командной панели документа.

Табличные части Продукция и Затраты на выпуск продукции при этом будут заполнены автоматически.

Если какую-то продукцию оприходовать не нужно, то ее следует удалить из верхней таблицы. Данные нижней таблицы, относящиеся к удаляемой продукции, очистятся автоматически.

Примечание. КПС счета производства, который указан в шапке документа, не влияет на заполнение документа. То есть, при автоматическом заполнении документа остатки на счете 106.хИ собираются по счету в целом в разрезе КПС и видов затрат, по которым реально были сформированы затраты на счете 106.хИ.

Если необходимо списать со счета затраты по нескольким выпущенным позициям номенклатуры, то для заполнения таблицы Продукция можно использовать форму Подбор номенклатуры, которая вызывается с помощью кнопки Подобрать командной панели таблицы.

Заполнение табличной части Затраты на выпуск продукции для выбранных номенклатурных позиций по видам затрат произойдет после нажатия на кнопку Заполнить затраты командной панели табличной части.

Если на счете 106.хИ по указанным в документе позициям должны остаться остатки незавершенного производства, то в нижней таблице с видами затрат в поле Сумма следует указать сумму, которую следует списать со счета 106.хИ на готовую продукцию.

Значение Сумма в строке соответствующей номенклатурной позиции таблицы Продукция изменится автоматически.

При проведении документа со счета 106.хИ будет списана сумма затрат, указанных в таблице Затраты на выпуск продукции, при этом на счете будут присутствовать остатки незавершенного производства, то есть затраты, которые в дальнейшем войдут в себестоимость изготовления той же номенклатуры продукции.

Закладка "Бухгалтерская операция"

Типовая операция – имеет единственное значение Выпуск продукции.

При проведении документа формируются проводки Дт 105.хх, Кт 106.хИ по каждой номенклатуре и виду затрат, указанных в табличных частях документа.

Если документ оформлен по КФО = 2, то при проведении будут сформированы проводки по счетам налогового учета:
Дт Н10 (Н41, Н43), Кт Н 20.01

В налоговом учете продукция принимается к учету по той же стоимости, что и в бухгалтерском. Счет НУ, на который приходуются материалы, определяется по счету бухгалтерского учета (БУ).

Соответствие счетов БУ и НУ:

  • 105.х7 - Н43 – продукция
  • 105.х8 - Н41 – товары
  • для всех остальных - Н10 – прочие МЗ
