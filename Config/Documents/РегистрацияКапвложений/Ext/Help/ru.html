Документ "Регистрация капвложений"

Документ предназначен для привязки карточек капвложений к проводкам документов, формирующих движения по счетам 106.ХХ.

Документ является сервисным, и должен использоваться в случаях:

- Документ, который сформировал движения по счетам 106.ХХ не имеет собственных реквизитов для привязки карточек капвложений к проводкам документа (напрмер, документ Операция (бухгалтерская));

- Документ, который сформировал движения по счетам 106.ХХ имеет собственные реквизиты для привязки карточек капвложений к проводкам документа, но их не заполнили при проведении документа. Соотвественно, не произошло привязки карточки капвложений к проводкам;

Работа с документом

Документ вводится на основании документа, к которому нужно привязать карточки капвложений. Реквизит "Документ-основание" является обязательным для заполнения.

Реквизиты "Номер" и "Дата" недоступны для редактирования, и заполняются автоматически. Дата документа, строго соответствует дате документа-основания.

При вводе на основании табличная часть документа заполняется объектами вложений, по которым формировались движения по счетам 106.ХХ в проводках документа-основания, и движения по которым еще не привязаны к карточкам капвложений.
Т.е. если в документе-основания для части объектов вложений карточки указаны, а для части нет, то в документ "Регистрация капвложений" попадут только те объекты, по которым движения еще не привязаны к карточкам. 

Примечание
Если при вводе на основании табличная часть документ оказалась пустой, то вероятно, движения всех объектов в документе-основания уже привязаны к карточкам.

После ввода на основании в табличной части документа, для каждого объекта следует указать соответствующую карточку капвложений.

Документ провести. Документ делает движения по регистру сведений "Операции капвложений".
