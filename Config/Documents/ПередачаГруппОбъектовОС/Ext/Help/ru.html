Документ "Передача групп объектов основных средств"

Для оформления и учета операций по передаче нескольких однотипных объектов ОС, НМА и НПА, а также библиотечного фонда используется документ "Передача групп объектов (Акт приема - передачи ОС-1б)".

Документ позволяет оформить следующие операции:

  • Безвозмездная передача кап. вложений;
  • Безвозмездная передача ОС, НМА, НПА;
  • Возврат контрагенту (аренда, хранение);
  • Передача НФА по договору аренды/безвозмездного пользования;
  • Передача объектов ОС, НМА, НПА учредителю;
  • Передача ОС (оперативный учет);
  • Реализация объектов ОС, НМА, НПА;
  • Реализация ОС (оперативный учет).

После заполнения и записи документа можно сформировать печатные формы "Акт о приеме – передаче групп объектов основных средств (кроме зданий, сооружений) ОС-1б" (форма по ОКУД 0306031) и "Товарно-транспортная накладная" (ф. № 1-Т).

Также после заполнения реквизитов бухгалтерской операции и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида "Передача групп объектов ОС" можно открыть с помощью команды "Передача групп объектов ОС" панели навигации раздела "Основные средства, НМА, НПА".

Создание нового документа

Для ввода нового документа можно нажать на кнопку "Создать" командной панели списка "Передача групп объектов ОС".

Заполнение реквизитов шапки документа

В первую очередь необходимо заполнить реквизиты "Организация" и "Дата".

Лицевой счет – выбирается из справочника Реквизиты лицевых счетов.
КФО – код финансового обеспечения. Выбирается в списке КФО.
КПС – классификационный признак счета. Выбирается в списке КПС.
Дата списания с бухгалтерского учета – дата списания объекта ОС в бухгалтерском учете.

Вид передачи – может принимать значения:

  • Передача собственных ОС, НМА, НПА на балансе (101.00, 102.00, 103.00);
  • Передача собственных ОС, НМА, НПА в оперативном учете (21);
  • Передача кап. вложений (106.00);
  • Возврат ОС, НМА, НПА, полученных по договорам пользования (01);
  • Возврат ОС, НМА, НПА, принятых на хранение (02);
  • Передача ОС, НМА, НПА в аренду (25);
  • Передача ОС, НМА, НПА в безвозмездное пользование (26);
  • Передача ОС в оперативном учете в аренду (25);
  • Передача ОС в оперативном учете в безвозмездное пользование (26).

В группе "Получатель" заполняются реквизиты:

  • "Контрагент" – выбирается из справочника "Контрагенты";
  • "Договор" – выбирается из справочника "Договоры или иные основания возникновения обязательств";
  • "Р/счет – расчетный счет" - выбирается из справочника "Банковские и казначейские счета".

В группе "Место хранения (отправитель)" заполняются реквизиты:

  • "МОЛ/Место хранения" – центр материальной ответственности. Выбирается из справочника "Центры материальной ответственности";
  • "Подразделение" – подразделение организации. Выбирается из справочника "Подразделения".

Заполнение реквизитов на закладке "Основные средства"

"Сумма включает НДС" – наличие или отсутствие флага у реквизита определяет порядок отражения НДС в первичном документе.

Примечание. Управление порядком отражения НДС с помощью установки или снятия флага "Сумма включает НДС" имеет значение и выполняются только для операции "Реализация объектов ОС, НМА, НПА
".

Информация об основных средствах вводится в табличную часть:

  • "Основное средство" – выбирается из справочника "Основные средства";

Примечание. Для выбора объектов основных средств удобно использовать форму подбора, которая открывается с помощью кнопки "Подбор" командной панели табличной части.

После выбора объектов основных средств с использованием формы подбора в строках табличной части будут заполнены реквизиты:

  • "Гр. уч" – установлен флаг признака группового учета для выбранного объекта ОС;
  • "Счет учета" – субсчет счета 101.00 на котором ведется учет объекта основных средств;
  • "Инв. номер" – инвентарный номер объекта основных средств;

Примечание. Реквизит "Инв. номер" используется при учете объектов основных средств стоимостью более 3000 руб., за исключением объектов библиотечного фонда.
  • "Количество" – количество объектов ОС. Для одиночных объектов ОС, имеющих инвентарный номер, значение реквизита автоматически устанавливается равным "1". Реквизит доступен для заполнения для объектов ОС, у которых не предусмотрены инвентарные номера;
  • "Цена" – балансовая стоимость одного объекта ОС.

Значения реквизитов "Балансовая стоимость" и "Амортизация" рассчитываются автоматически с помощью кнопки "Рассчитать" командной панели табличной части.

Внимание!
При изменении значений реквизитов шапки заполненного документа необходимо перезаполнить табличную часть, т.к. данные в ней могут не соответствовать новым значениям реквизитов шапки документа. При невыполнении данного требования попытка проведения документа может оказаться невозможна.

Заполнение реквизитов "Сумма продажи", "Ставка НДС", "Сумма НДС" и "Всего" выполняется только для операции "Реализация объектов ОС, НМА, НПА".

Заполнение реквизитов на закладке "Сведения об акте"

Группа реквизитов "Основание для составления акта":

  • "Приказ, распоряжение, договор" – наименование документа-основания с указанием его вида и основных обязательств;
  • "№" – номер документа-основания;
  • "от" – дата документа-основания.

Заполнение реквизитов на закладке "Комиссия"

Группа "Председатель комиссии" включает реквизиты "Должность", "Фамилия", "Имя" и "Отчество".

Информация о должности, фамилии, имени и отчестве каждого члена комиссии вводится в табличную часть закладки.

Примечание. Если в организации уже создана комиссия с необходимыми обязанностями, то ее можно выбрать из справочника "Постоянно действующие комиссии<", который можно открыть с помощью команды "Выбрать из постоянно действующих комиссий". После выбора комиссии все реквизиты на закладке будут заполнены автоматически.

Заполнение реквизитов на закладке "Бухгалтерская операция"

"Типовая операция" – выбирается из списка "Типовые операции".

Безвозмездная передача кап. вложений

Для данной типовой операции необходимо заполнить реквизиты:

  • "Вид затрат" – выбирается из справочника "Виды затрат".

Группа реквизитов "Счет передачи":

  • "Счет передачи" – выбирается из фрагмента "Плана счетов (ЕПСБУ)".
  • "КЭК (для счета 401.20)" – код экономической классификации. Выбирается из фрагмента справочника "КЭК", содержащего только актуальные для данной операции значения "КЭК".

Безвозмездная передача ОС, НМА, НПА

Для данной типовой операции необходимо заполнить реквизиты:

  • "Счет передачи" – выбирается из фрагмента "Плана счетов (ЕПСБУ)".
  • "КЭК (для счета 401.20)" – код экономической классификации. Выбирается из фрагмента справочника "КЭК", содержащего только актуальные для данной операции значения "КЭК".

Передача ОС (оперативный учет)

Дополнительные реквизиты у данной типовой операции отсутствуют.

Реализация объектов ОС, НМА, НПА

Для данной типовой операции необходимо заполнить реквизиты:

  • "КПС" – классификация доходов бюджета. Выбирается в справочнике "КПС";
  • "Начислять НДС" – установка флага задает начисление НДС.

Группа реквизитов "Начисление дохода":

  • "Не администратор дохода (флаг установлен – 303.05.730, не установлен – 401.10.172)" – установка флага производится, если организация не является администратором дохода;
  • "Вид налогов и платежей (для счета 303.05)" – выбирается из справочника "Виды налогов и платежей".

Реализация ОС (оперативный учет)

Для данной типовой операции необходимо заполнить реквизиты:

  • "КПС" – классификация доходов бюджета. Выбирается в справочнике "КПС";
  • "Начислять НДС" – установка флага задает начисление НДС.

Группа реквизитов "Начисление дохода":

  • "Не администратор дохода (флаг установлен – 303.05.730, не установлен – 401.10.172)" – установка флага производится, если организация не является администратором дохода;
  • "Вид налогов и платежей (для счета 303.05)" – выбирается из справочника "Виды налогов и платежей".

Регистрация документа

Регистрация документа "Передача групп объектов ОС" производится в журнале "Документы по основным средствам".

Дополнительные возможности

На основании документа "Передача групп объектов ОС" можно ввести документы "Счет – фактура выданный" и "Сторно".
