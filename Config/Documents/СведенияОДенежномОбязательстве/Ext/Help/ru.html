Документ "Сведения о денежном обязательстве"

Документ Сведения о денежном обязательстве предназначен для формирования в печатном и электронном виде формы Сведения о денежном обязательстве (письмо от 12.01.2021 № 09-01-09/563).

Работа со списком документов

Список документов вида Сведения о денежном обязательстве можно открыть с помощью команды Сведения о денежном обязательстве меню функций раздела Планирование и санкционирование.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Сведения о денежном обязательстве.

Заполнение реквизитов документа

Подтверждающий документ – документ, который используется для постановки на учет денежных обязательств или для внесения изменений в поставленные на учет денежные обязательства в органах Федерального казначейства. Выбирается из списка:

  • Авансовый отчет;
  • Заявление на выдачу аванса;
  • Исходящее извещение;
  • Обслуживание кредитов и займов;
  • Отражение зарплаты в учете;
  • Поступление МЗ;
  • Поступление МЗ (в пути);
  • Поступление ОС, НМА, НПА;
  • Поступление ОС (в пути);
  • Поступление услуг, работ;
  • Приходный кассовый ордер (фондовый);
  • Регистрация обязательств и сведений по договорам.

Лицевой счет – выбирается из справочника Реквизиты лицевых счетов.

Вид средств – выбирается из списка.

Объект ФАИП (КМИ) – кнопка выбора открывает форму Выбор типа данных, в которой следует выбрать Мероприятия по информатизации или Основные средства, НМА. НПА. После выбора типа данных открывается справочник Мероприятия по информатизации, или, соответственно, справочник Основные средства, НМА. НПА.

Срок исполнения – указывается срок исполнения денежного обязательства.

Учетный номер – указывается учетный номер денежного обязательства, присвоенный органом Федерального казначейства.

Заполненный документ следует записать с помощью кнопки командной панели Записать.

После этого можно сформировать печатную форму документа с помощью кнопки Сведения о денежном обязательстве.

Дополнительные возможности

На основании документа Сведения о денежном обязательстве можно ввести документы Заявка на кассовый расход и Платежное поручение.
