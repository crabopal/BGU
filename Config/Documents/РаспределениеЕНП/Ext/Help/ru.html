Документ "Распределение ЕНП"

Документ Распределение ЕНП предназначен для формирования операций по распределению (зачету) сумм единого налогового платежа в счет уменьшения задолженности по соответствующим налогам, сборам, взносам. При проведении документа формируются бухгалтерские записи по дебету соответствующих счетов аналитического учета счета 030300000 "Расчеты по платежам в бюджеты" и кредиту счета 030314000 "Расчеты по единому налоговому платежу".

После проведения документа можно сформировать Бухгалтерскую справку (ф. 0504833).

Работа со списком документов

Список документов вида Распределение ЕНП можно открыть с помощью команды Распределение ЕНП меню функций раздела Налоги в группе Единый налоговый счет.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Распределение ЕНП.

Также документ Распределение ЕНП можно ввести на основании документа Сведения об удержанном НДФЛ.

При вводе на основании документ Распределение ЕНП заполняется автоматически.

Заполнение реквизитов шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

В группе реквизитов Первичный документ можно указать вид, номер и дату первичного документа для отражения в журнале операций. Если реквизиты не заполнены, в журнале операций в качестве первичного документа отражается Бухгалтерская справка (ф. 0504833).

Закладка "Принадлежность сумм ЕНП"

Табличная часть на закладке Принадлежность сумм ЕНП является основанием для формирования проводок при проведении документа.

Реквизиты табличной части:

Вид налога, платежа – выбирается из справочника Виды налогов и платежей. При выборе значения автоматически заполняется значение Счет и Субконто1 выбранного счета.

Налоги и платежи организации – выбирается из справочника Налоги и платежи организаций. Если на счете учета налога используется Субконто2 типа Налоги и платежи организаций, Субконто2 в поле Счет будет заполнено выбранным значением.

ИФО – выбирается из справочника Источники финансового обеспечения. Реквизит доступен для выбора, если включена опция Учет по ИФО.

Подразделение – выбирается из справочника Подразделения. Реквизит доступен, если включена опция Учет по подразделениям и на счете учета налога ведется учет по подразделениям. Устанавливается в проводке по дебету бухгалтерской записи. Также устанавливается по кредиту бухгалтерской записи, если для счета ЕНП требуется указание подразделения, и на закладке Счет ЕНП подразделение не заполнено.

КФО – код финансового обеспечения, выбирается из списка.

Счет – счет учета расчетов по соответствующему налогу, сбору, взносу. Счет дебета бухгалтерской записи по распределению суммы единого налогового платежа.

КПС – классификационный признак счета. Выбирается из справочника КПС. Используется для формирования записи по дебету и кредиту проводки.

Уменьшение задолженности – сумма, которая будет зачтена в счет уменьшения соответствующей обязанности по платежам в бюджет. На эту сумму будет сформирована бухгалтерская запись.

Для заполнения табличной части можно воспользоваться командой Подобрать.

Команда Подобрать открывает форму подбора платежей Подбор налогов.

Работа в окне "Подбор налогов"

Окно Подбор налогов содержит информацию об остатках на счетах расчетов на дату, указанную в шапке формы (по гиперссылке Остатки расчетов). При открытии формы подбора дата остатков устанавливается равной дате документа. Остатки отображаются на конец дня указанной даты. При нажатии на гиперссылку Остатки расчетов можно изменить дату, на которую отображаются остатки.

Так же в шапке отображается остаток на счете 303.14 "Расчеты по единому налоговому платежу" в целом по организации. Для изменения даты остатка можно нажать на гиперссылку Остаток ЕНП. Если в базе ведется учет обособленных подразделений, выделенных на отдельный баланс, остаток ЕНП отображается в сумме по головной организации и по всем обособленным подразделениям, выделенным на отдельный баланс. Если в базе включена опция Ограничивать доступ на уровне записей остаток формируется с учетом установленного ограничения.

Основная таблица формы содержит остатки, сгруппированные по видам налога, счету учета, КБК налога. В колонке Остаток расчетов отображается сумма остатка на заданную дату, в целом по виду налога. В колонке Подобрано отображается подобранная сумма. Для переноса суммы в Подобрано достаточно нажать на пиктограмму "Стрелка вправо" или команду Выбрать командной панели списка.

Редактирование суммы Подобрано выполняется в отдельном окне Редактирование строки распределения.

При нажатии в колонке Подобрано на пиктограмму в виде карандаша открывается форма Редактирование строки распределения. Так же открыть окно редактирования можно по двойному клику левой клавишей мыши в строке или клавишей Enter.

Таблица Редактирование строки распределения отображает остатки по выбранному виду налога в развернутом виде по всей аналитике учета.

В окне Редактирование строки распределения можно переключится в режим отображения оборотов тумблером Показать обороты.

Для выбора периода отображения оборотов служит гиперссылка Показать обороты.

При включении тумблера Показать обороты в колонке Расчеты в верхней строке отображается остаток, в нижней строке оборот.

Перенести сумму в Подобрано можно по двойному клику мыши (нажатием клавиши Enter или на пиктограмму "Стрелка вправо") по соответствующей сумме. Сумму в колонке Подобрано также можно ввести вручную.

Для вида налога НДФЛ отображается отдельный переключатель, по каким данным формировать обороты: по данным бухгалтерского счета 303.01 или по данным, загруженным из ЗГУ в документ Сведения об удержанном НДФЛ.

Команда ОК подтверждает выбор результата и его перенос в окно Подбор налогов.

Гиперссылка Настроить список в окне Подбор налогов открывает окно Настройка списка Платежи в составе ЕНП. В этом списке можно отключить отображение налогов, которые не уплачиваются в составе ЕНП и соответственно по которым не требуется формировать бухгалтерские записи в уменьшение обязанности за счет распределения сумм единого налогового платежа.

При включении тумблера Показать все в окне Подбор налогов будут отображены все остатки, без учета настройки Настройка списка Платежи в составе ЕНП.

Посмотреть результат подбора в окне Подбор налогов можно, если развернуть группу Подобранные налоги, платежи.

Команда Перенести в документ переносит результат подбора в табличную часть документа на закладке Принадлежность сумм ЕНП.

Закладка "Счет ЕНП"

На закладке Счет ЕНП заполняется аналитика счета 030314000 "Расчеты по единому налоговому платежу".

Счет – счет учета расчетов по единому налоговому платежу. Счет кредита бухгалтерской записи по распределению суммы единого налогового платежа. При вводе нового документа по умолчанию заполняется значением счета 303.14.

Подразделение – выбирается из справочника Подразделения. Реквизит отображается, если включена опция Учет по подразделениям и на счете учета ЕНП ведется учет по подразделениям. Устанавливается в проводке по кредиту бухгалтерской записи.

Субконто1, Субконто2, Субконто3 – субконто счета 303.14. При вводе нового документа Субконто1 заполняется предопределенным значением справочника Виды налогов и платежей "Единый налоговый платеж".

Закладка "Бухгалтерская операция"

Реквизит Типовая операция имеет по умолчанию значение Распределение ЕНП.

При проведении документа формируются бухгалтерские записи по дебету соответствующих счетов аналитического учета счета 030300000 "Расчеты по платежам в бюджеты" и кредиту счета 030314000 "Расчеты по единому налоговому платежу".
