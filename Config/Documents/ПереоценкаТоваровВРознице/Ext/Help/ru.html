Документ "Переоценка товаров в рознице"

Предназначен для оформления операции по переоценке товаров в розничной торговой точке, в которой учет товаров ведется в розничных ценах.

В процессе работы с документом Переоценка товаров в рознице в качестве источника данных о ценах до и после переоценки можно использовать:

  • документы вида Установка цен номенклатуры;
  • введенные вручную в табличную часть цены на товары до и после переоценки.

Также программа позволяет одновременно использовать в одном документе оба указанных способа заполнения.

После заполнения и записи документа можно сформировать печатную форму ведомости по переоценке товаров.

Также после заполнения реквизитов бухгалтерской операции и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

При проведении заполненного документа формируются проводки по переоценке товаров в рознице.

Работа со списком документов

Список документов вида Переоценка товаров в рознице можно открыть с помощью команды Переоценка товаров в рознице меню функций раздела Материальные запасы.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Переоценка товаров в рознице.

Заполнение реквизитов шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

  • МОЛ/Место хранения - неавтоматизированная торговая точка, в которой выполняется переоценка. Выбирается из справочника Центры материальной ответственности;
  • Подразделение – выбирается из справочника Подразделения.

При установленном флаге Указывать сумму переоценки вручную документ заполняется со свернутой номенклатурой. При этом:

  • становится доступен реквизит Сумма переоценки, в котором указывается общая сумма переоценки по торговой точке без распределения по номенклатуре;
  • реквизиты группы Документы установки цен становятся недоступны;
  • табличная часть документа не заполняется.

При снятом флаге Указывать сумму переоценки вручную документ заполняется с развернутой номенклатурой. При этом:

  • реквизит Сумма переоценки становится недоступен для заполнения;
  • реквизиты До переоценки и После переоценки группы Документы установки цен становятся доступны, и в них можно указать соответствующие документы вида Установка цен номенклатуры. Данные реквизиты не являются обязательными для заполнения;
  • данные о ценах до и после переоценки по каждой номенклатурной позиции, для которой принято решение о переоценке, вводятся в табличную часть.

Заполнение реквизитов табличной части
  • Номенклатура – позиция номенклатуры, которую необходимо переоценить, выбирается из справочника Номенклатура. Кроме того в программе реализован более удобный способ заполнения табличной части с использованием формы Подбора, вызываемой с помощью кнопки Подобрать;

Примечание. Если позиция номенклатуры одновременно присутствует в обоих документах вида Установка цен номенклатуры, указанных в реквизитах До переоценки и После переоценки, то поля Цена до переоценки и Цена после переоценки для этой позиции номенклатуры будут заполнены автоматически после ее выбора в поле Номенклатура.
  • Количество – количество номенклатуры;
  • Цена до переоценки и Цена после переоценки. Эти поля могут быть заполнены как автоматически, на основании документов Установка цен номенклатуры, так и вручную.

Значение реквизита Сумма переоценки рассчитывается по формуле:

Сумма переоценки = количество * (цена после переоценки) - количество * (цена до переоценки)

Важно
Если после заполнения табличной части будут внесены изменения в документ, указанный в поле шапки документа До переоценки или После переоценки, то для актуализации цены в полях табличной части можно использовать кнопку Заполнить цены. При этом следует иметь в виду, что поля с ценами, заполненные вручную, после нажатии на кнопку Заполнить цены будут очищены.

Заполнение реквизитов "Бухгалтерской операции"

Типовая операция имеет одно значение – Переоценка товаров в рознице.

  • КФО – код финансового обеспечения, выбирается из списка;
  • КПС – классификационный признак счета. Выбирается в справочнике КПС.
  • КЭК – код экономической классификации.

Проведение документа

При проведении документа формируются проводки по переоценке товаров в рознице:
Д-т 105.Г8, К-т 105.39 - на сумму наценки или, в случае сторнирования, – на сумму уценки.

Дополнительные возможности
