Документ "Обслуживание кредитов и займов"

Документ Обслуживание кредитов и займов предназначен для формирования бухгалтерских записей по некассовым операциям с кредитами, займами, долговыми обязательствами.

После проведения документа можно распечатать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов Обслуживание кредитов и займов можно открыть с помощью команды Обслуживание кредитов и займов меню функций раздела Планирование и санкционирование.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Обслуживание кредитов и займов.

Заполнение реквизитов документа

Вид операции – определяет характер хозяйственной операции, выбирается из списка. Может принимать следующие значения:

  • Начисление процентов, штрафов, пеней по предоставленным кредитам, займам (ссудам).
  • Начисление процентов, штрафов, пеней по долговым обязательствам.
  • Списание дебиторской задолженности по предоставленным кредитам, займам (ссудам).
  • Прекращение долгового обязательства в случае его исполнения гарантом и отсутствии регрессивного требования.
  • Начисление задолженности по гарантии перед кредитором с регрессивным требованием к заемщику.
  • Начисление задолженности по гарантии перед кредитором без регрессивного требования к заемщику.
  • Перевод долга по гарантии с кредитора на гаранта.
  • Предоставление государственной (муниципальной) гарантии.
  • Прекращение государственной (муниципальной) гарантии.

Примечание. Если для договоров вида Предоставленный кредит (заем), Полученный кредит ведется график платежей то для автоматического заполнения табличной части можно использовать кнопку Заполнить.

Бухгалтерская операция

Типовая операция – единственная операция Обслуживание кредитов и займов.

Для данной типовой операции можно заполнить реквизиты:

  • Принять денежное обязательство – флажок, следует установить при необходимости принять денежное обязательство;
  • Раздел лицевого счета – раздел лицевого счета, на который будет принято денежное обязательство. Выбирается из справочника Разделы лицевых счетов.

Дополнительные возможности

На основании документа Обслуживание кредитов и займов можно ввести документ Сведения о денежном обязательстве.
