Документ "Путевой лист трактора (форма № 412-АПК)"

Документ Путевой лист трактора (форма № 412-АПК) предназначен для заполнения и печати формы Путевой лист трактора (форма № 412-АПК), утвержденной приказом Минсельхоза России от 16.05.2003 № 750.

Работа со списком документов

Документы вида Путевой лист трактора (форма № 412-АПК) содержатся в Журнале путевых листов, который можно открыть с помощью команды Журнал путевых листов меню функций раздела ГСМ.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели Журнала путевых листов и выбрать в списке Путевой лист трактора (форма № 412-АПК).

Заполнение реквизитов шапки
  • Номер – номер путевого листа. Присваивается автоматически, но его можно изменить;
  • Серия – серия путевого листа. Заполняется при необходимости;
  • Срок действия – дата окончания действия путевого листа. По умолчанию заполняется датой путевого листа, но может быть изменен;
  • Трактор – трактор, выбирается из справочника Основные средства.

Реквизиты Гаражный номер и Государственный номерной знак заполняются автоматически после выбора трактора, согласно данным, указанным в регистре сведений Паспорта транспортных средств для данного транспортного средства.

При этом реквизит Гаражный номер не выводится в печатной форме путевого листа ф. 412-АПК, однако необходим для заполнения отчета Журнал учета движения путевых листов (ф. № 8) и идентификации путевого листа по гаражному номеру.

  • Тракторист – выбирается из справочника Сотрудники.

Закладка "Общие сведения"
  • Подразделение – обособленное подразделение организации, выполняющее механизированные работы. Данный реквизит предназначен для организации в обособленном подразделении отдельной нумерации документов. Выбирается из справочника Подразделения.

Примечание. Установка флажка Обособленная нумерация документов в карточке обособленного подразделения позволяет реализовать в данном подразделении обособленную нумерацию документов с префиксом, указанном в поле Префикс.

Группа Данные трактора:

  • Марка трактора – заполняется автоматически значением, указанным для реквизита Марка машины в регистре сведений Паспорта транспортных средств для данного транспортного средства. В печатной форме путевого листа отображается в реквизите Марка машины.
  • Инвентарный номер – заполняется автоматически значением, указанным для реквизита Инвентарный номер на закладке Основные сведения соответствующего элемента справочника Основные средства.

Группа Ответственные лица:

Прицепщик и Бригадир – выбираются из справочника Сотрудники.

Группа Коды:

Отделение (участок) – заполняется вручную;
Бригада – заполняется при выборе транспортного средства из индивидуальной характеристики Колонна выбранного трактора и допускает корректировку в документе.

Табличная часть Прицепы

Если транспортная работа предполагает использование прицепа, то следует добавить строку в табличную часть Прицепы.

Примечание. При заполнении табличной части Прицепы следует учитывать, что в печатную форму путевого листа можно ввести данные только об одном прицепе.

Прицеп – выбирается из справочника Основные средства.

Реквизиты Гаражный номер, Государственный номерной знак и Марка заполняются автоматически после выбора прицепа, согласно данным, указанным в регистре сведений Паспорта транспортных средств для данного транспортного средства. . Поле Инвентарный номер будет заполнено по данным инвентарного учета прицепа.


Закладка "Горючее"

На закладке Горючее вводятся данные о выдаче горючего.

В табличной части Движение горючего можно отразить движение горючего:

  • Вид ГСМ – выбирается из справочника Виды ГСМ. Реквизиты Марка, Код марки и Единица измерения ГСМ заполняются автоматически на основании данных в карточке выбранного Вида ГСМ;
  • Выдано, л – количество выданного горючего в литрах;
  • Остатки – в поля данной колонки вводятся остатки горючего При выезде и При возвращении.

Закладка "Задание трактористу"

В табличной части на закладке Задание трактористу следует добавить строки и заполнить следующие поля.

Колонка В чье распоряжение:
заказчик – заполняется выбором из справочника Контрагенты, или из справочника Подразделения, или из справочника Сотрудники:
в распоряжение – наименование заказчика заполняется автоматически, если выбрано значение в поле заказчик. Допустимо заполнение поля вручную.

Колонка Адрес пункта:
погрузка – указывается адрес погрузки, допускается заполнение выбором из списка часто посещаемых адресов для трактора;
разгрузка – указывается адрес разгрузки, допускается заполнение выбором из списка часто посещаемых адресов для трактора.

Колонка Груз:
наименование – указывается наименование груза;
вес груза, т – указывается вес груза в тоннах.

Колонка Данные о грузе:
класс груза – указывается класс груза;
кол-во мест, шт. – указывается количество мест.

Колонка Параметры задания:
ездок с грузом – указывается количество ездок с грузом;
расстояние, км – указывается расстояние в километрах.

Закладка "Выезд"

В группе Выезд трактора следует заполнить реквизиты:
Время начала работы;
Механик/бригадир подтвердил начало работы - указывается, если работник определен на этапе оформления путевого листа.

В группе Ответственные за выезд следует заполнить реквизиты:
Выезд разрешил механик/бригадир;
Принял тракторист.

Печать документа

Чтобы распечатать путевой лист трактора (форма № 412-АПК), документ необходимо предварительно записать с помощью кнопки Записать командной панели формы документа.

Для формирования печатной формы следует нажать кнопку Путевой лист трактора (ф. 412-АПК).

Правильно заполненный документ следует провести и закрыть с помощью кнопки Провести и закрыть.

Ввод данных путевого листа после возвращения из рейса

В общем случае после возвращения из рейса путевой лист сдается для расчета расхода ГСМ.

Если требуется сохранить данные из путевого листа, которые были внесены вручную, то можно открыть документ, соответствующий путевому листу, и ввести в него эти данные.

Для ввода указанных данных используются закладки Возвращение и Результаты.

Дополнительные возможности

После получения от тракториста заполненного путевого листа на основании документа Путевой лист трактора (форма 412-АПК) для расчета нормативного и фактического расхода, а также списания ГСМ следует ввести документ Таксировка путевого листа.

Для ввода Таксировки путевого листа можно использовать гиперссылку Ввести таксировку в левом нижнем углу формы документа.
