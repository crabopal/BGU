Документ "Регистрация плательщиков по договору (образование)"

Документ Регистрация плательщиков по договору (образование) предназначен для установки соответствия договора на обучение и нескольких плательщиков, вносящих оплату по этому договору. В качестве плательщика может выступать как одно или несколько физических лиц, так и одно или несколько юридических лиц. К примеру, часть платы по договору может вносить учащийся или его родственник, а другую часть - организация, для дальнейшего трудоустройства учащегося.

При проведении документ формирует движения по регистру сведений Плательщики по договору (образование).

Работа со списком документов

Список документов Регистрация плательщиков по договору (образование) можно открыть с помощью команды Регистрация плательщиков по договору (образование) меню функций раздела Платное обучение.

В форме списка предусмотрен отбор по реквизитам Организация, Учащийся и Договор.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Регистрация плательщиков по договору (образование).

Также создание документов по списку учащихся может быть выполнено с помощью Помощника регистрации плательщиков (образование).

Заполнение реквизитов шапки документа

Для каждого договора учащегося, по которому требуется установить соответствие плательщиков, следует ввести отдельный документ Регистрация плательщиков по договору (образование).

  • Учащийся – указывается учащийся для которого выполняется регистрация плательщиков по договору;
  • Договор – указывается договор, по которому выполняется регистрация плательщиков.

Заполнение реквизитов табличной части

Добавление строк в табличную часть выполняется с помощью кнопки Добавить.

В каждой строке табличной части документа следует заполнить поля:

  • Контрагент (плательщик) – указывается контрагент, выполняющий оплату по договору;
  • Сумма оплаты – необязательное для заполнения поле, сумма может быть указана для расчета процента оплаты;
  • Процент оплаты – процент оплаты договора плательщиком текущей строки, общая сумма процентов в табличной части должна быть равна 100%;
  • Порядок выписки СФ - должно быть выбрано одно из значений: На плательщика или Сводно, в зависимости от необходимости выписки счетов фактур для выбранного контрагента.
