Принятие к учету зданий (сооружений)

Документ Принятие к учету зданий (сооружений) используется для включения зданий (сооружений) в состав основных средств организации и отражения в учете ввода зданий (сооружений) в эксплуатацию.

Документ позволяет оформить следующие операции:

  • безвозмездное получение зданий (401.10);
  • оприходование излишков основных средств, выявленных при инвентаризации (101 - 401.10.180);
  • получение ОС от учредителя в оперативное управление;
  • прекращение договора аренды/безвозмездного пользования;
  • принятие к учету ОС на забалансовые счета (аренда, хранение);
  • принятие к учету ОС, поступивших в натуральной форме при возмещении ущерба, причиненного виновным лицом (101 - 401.172);
  • централизованное получение зданий (304.04.310);

При оформлении любой из перечисленных бухгалтерских операций с помощью документа "Принятие к учету здания (сооружения)" регистрируются две хозяйственные операции – поступление ОС и принятие поступившего ОС к учету.
  • принятие к учету ОС по сформированной стоимости вложений (101 - 106).

При оформлении данной операции с помощью документа "Принятие к учету здания (сооружения)" регистрируется только одна хозяйственная операция – принятие указанного ОС к учету. Для регистрации поступления данного ОС необходимо предварительно, до принятия к учету, оформить документ "Поступление ОС, НМА, НПА".

После заполнения и записи документа можно сформировать печатную форму "Акт о приеме-передаче здания (сооружения) ОС-1а" (форма по ОКУД 0306030).

Также после заполнения реквизитов бухгалтерской операции и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида "Принятие к учету здания (сооружения)" можно открыть с помощью команды "Принятие к учету зданий (сооружений)" панели навигации раздела "Основные средства, НМА, НПА".

Создание нового документа

Для ввода нового документа можно нажать на кнопку "Создать" командной панели списка "Принятие к учету зданий (сооружений)".

Заполнение реквизитов шапки документа

В первую очередь необходимо заполнить реквизиты "Дата" и "Организация".

Реквизит "Вид поступления" может принимать значения:

  • принятие к учету со счета 106 (приобретение);

Данное значение используется только при оформлении операции "Принятие к учету ОС по сформированной стоимости вложений" для приобретенных объектов НФА. При этом реквизиты "Первоначальная стоимость" и "Количество объектов" на закладке "Основное средство" недоступны для заполнения вручную.
Значение реквизитов "Первоначальная стоимость" и "Количество объектов" формируются после нажатия на кнопку "Рассчитать".
  • принятие к учету со счета 106 (изготовление);

Данное значение используется только при оформлении операции "Принятие к учету ОС, НМА, НПА по сформированной стоимости вложений" для изготовленных объектов НФА. При этом реквизит "Первоначальная стоимость" на закладке "Основное средство" недоступен для заполнения вручную.
Значение реквизита "Первоначальная стоимость" формируется после нажатия кнопки "Рассчитать".
  • поступление на счет 101 (102, 103), 01, 02

Значение "Поступление на счет 101 (102, 103), 01, 02" реквизита "Вид поступления" используется при оформлении всех операций документа, за исключением операции "Принятие к учету ОС по сформированной стоимости вложений".
При этом реквизит "Первоначальная стоимость" следует заполнить вручную.
  • прекращение договора аренды (25).

Данное значение используется при оформлении операции "Прекращение договора аренды/безвозмездного пользования".

  • прекращение договора безвозмездного использования (26).

Группа реквизитов Организация-сдатчик:

  • Контрагент – выбирается из справочника Контрагенты;
  • Р/счет – расчетный счет контрагента. Выбирается в справочнике Банковские и казначейские счета.

Группа реквизитов Организация-получатель:

  • Л/счет – лицевой счет организации. Выбирается в справочнике Реквизиты лицевых счетов.

Заполнение реквизитов на закладке Основное средство

Группа Реквизиты счета:

  • КФО – код финансового обеспечения. Выбирается в списке КФО;
  • КПС – классификационный признак счета. Выбирается в списке КПС.

Группа Место хранения:

  • МОЛ/Место хранения – центр материальной ответственности. Выбирается в справочнике Центры материальной ответственности.
  • Подразделение – подразделение организации. Выбирается из справочника Подразделения.

При оформлении типовой операции Принятие к учету ОС по сформированной стоимости вложений стоимость вложений формируется на субсчетах счета 106.00 «Вложения в нефинансовые активы» плана счетов (ЕПСБУ).

Для расчета суммы вложений для данной типовой операции необходимо заполнить реквизиты группы Объект вложений:

  • Объект вложений – объект капитальных вложений выбирается из справочника Основные средства.
  • Cчет – субсчет счета 106.00. Выбирается из плана счетов (ЕПСБУ).

Первоначальная стоимость и количество объектов капитальных вложений на субсчете счета 106.00 будут автоматически рассчитаны после нажатия кнопки Рассчитать.

Группа Основное средство:

  • Объект – объект ОС. Выбирается из справочника Основные средства. Если ранее было выбрано значение реквизита Объект вложений, то значение реквизита Объект подставляется автоматически;
  • Инв. номер – инвентарный номер объекта ОС. Выбирается из справочника Инвентарные номера ОС.

Реквизиты группы Основание для составления акта заполняются для всех типовых операций.

Заполнение реквизитов на закладке "Амортизация"

В группе "Параметры амортизации" заполняются реквизиты "Срок полезного использования" и "Порядок погашения стоимости", выбирается "Способ начисления амортизации".

Примечание. Если амортизация временно не должна начисляться, то необходимо снять флаг "Начислять амортизацию".

Установка флага "Начислять амортизацию"в дальнейшем выполняется с помощью документа "Изменение параметров амортизации ОС".

Реквизиты группы "Затраты по амортизации":

  • "Счет" – счет учета затрат по амортизации. Выбирается из Плана счетов (ЕПСБУ);
  • "КЭК" – код экономической классификации. Подставляется автоматически после заполнения реквизита "Счет";
  • "КПС" – классификационный признак счета. При необходимости заполнения выбирается из справочника "КПС";

При незаданном "КПС" поле выбора "КПС" содержит текст "", при этом амортизация ОС выполняется по "КПС", указанному для счета "101.ХХ".
Программа позволяет начислять амортизацию на "КПС", отличный от "КПС" счета учета ОС "101.ХХ". При заданном значении "КПС" амортизация будет производиться на указанный "КПС".

Доступность для заполнения реквизитов "Субконто 1", "Субконто 2" и "Субконто 3" зависит от настройки аналитического учета на счете учета затрат, указанном в реквизите "Счет".

Реквизиты группы "Сведения о переданной амортизации и дате ввода в эксплуатацию" заполняются при приеме основного средства, которое было ранее введено в эксплуатацию у поставщика.

При этом реквизиты "Дата ввода в эксплуатацию", "Оставшийся срок полезного использования" и "Переданная амортизация" заполняются на основании данных, содержащихся в акте поставщика.

Заполнение реквизитов на закладке "Комиссия"

Группа "Председатель комиссии" включает реквизиты "Должность", "Фамилия", "Имя" и "Отчество".

Информация о должности, фамилии, имени и отчестве каждого члена комиссии вводится в табличную часть закладки.

Примечание. Если в организации уже создана комиссия с необходимыми обязанностями, то ее можно выбрать из справочника "Постоянно действующие комиссии", который можно открыть с помощью команды "Выбрать из постоянно действующих комиссий". После выбора комиссии все реквизиты на закладке будут заполнены автоматически.

Заполнение реквизитов на закладке "Бухгалтерская операция"

"Типовая операция" – выбирается из списка "Типовые операции".

Для документа предусмотрены следующие типовые операции:

Безвозмездное получение зданий (401.10)

Для данной типовой операции необходимо заполнить реквизиты:

  • "КДБ" – классификация доходов бюджета. Выбирается в справочнике "КПС";
  • "КЭК" – код экономической классификации. Выбирается в справочнике "КЭК".

Оприходование излишков основных средств, выявленных при инвентаризации (101 - 401.10.180)

Для данной типовой операции необходимо заполнить реквизит:

  • "КПС для счета 401.10" – классификационный признак счета для счета 401.10. Выбирается из справочника "КПС".

Прекращение договора аренды / безвозмездного пользования

Реквизиты у данной типовой операции отсутствуют.

Принятие к учету ОС на забалансовые счета (аренда, хранение)

Реквизиты у данной типовой операции отсутствуют.

Принятие к учету ОС, поступивших в натуральной форме при возмещении ущерба, причиненного виновным лицом (101 - 401.172)

Для данной типовой операции необходимо заполнить реквизит:

  • "КПС для счета 401.10" – классификационный признак счета для счета 401.10. Выбирается из справочника "КПС".

Централизованное получение зданий (304.04.310)

Примечание. Для формирования проводки 101 - 304.04 обязательно должен быть заполнен реквизит "Контрагент" в шапке документа.

Принятие к учету ОС по сформированной стоимости вложений (101 - 106)

Для данной типовой операции необходимо заполнить реквизит:

  • "Вид затрат" – выбирается из справочника "Виды затрат".

Примечание. При выборе операции "Принятие к учету ОС по сформированной стоимости вложений" следует обязательно заполнить реквизит "Объект вложений" на закладке "Основное средство".

Регистрация документа

Регистрация документа "Принятие к учету здания (сооружения)" производится в журнале "Документы по основным средствам".

Дополнительные возможности

На основании документа "Принятие к учету здания (сооружения)" можно ввести документ "Сторно".

Реквизиты у данной типовой операции отсутствуют.
