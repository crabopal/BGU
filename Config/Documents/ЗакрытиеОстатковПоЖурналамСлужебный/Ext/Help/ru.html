Документ "Формирование остатков по журналам операций"

Документ Формирование остатков по журналам операций предназначен для закрытия остатков по журналам операций.

Документ Формирование остатков по журналам операций вводится в последний день года.

После заполнения реквизитов и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Документы вида Формирование остатков по журналам операций находятся в журнале Документы закрытия года. Журнал Документы закрытия года можно открыть с помощью команды Документы закрытия года меню функций раздела Учет и отчетность.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели журнала Документы закрытия года и выбрать в списке тип документа Формирование остатков по журналам операций.

Заполнение реквизитов документа

Дата документа заполняется автоматически значением рабочей (текущей) даты. Для закрытия года следует указать – последний день финансового года (31 декабря);
Организация – учреждение, для которого производится закрытие счетов. Выбирается из справочника Организации.
Финансовый год – окончившийся финансовый год.

Типовая операция – имеет значение Формирование остатков по журналам.

Проведение документа

При проведении документа бухгалтерские записи по завершению счетов формируются в корреспонденции со служебным счетом "Вспомогательный" 000.

В результате документа закрываются остатки по журналам операций.

Для каждой сформированной проводки устанавливается тип Служебные операции.
