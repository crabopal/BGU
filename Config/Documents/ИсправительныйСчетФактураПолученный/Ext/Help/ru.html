Документ "Исправительный счет-фактура полученный"

Документ Исправительный счет-фактура полученный предназначен для внесения исправлений в счета-фактуры или корректировочные счета-фактуры, полученные от поставщиков.

По сути, Исправительный счет-фактура является новым экземпляром счета-фактуры или корректировочного счета-фактуры.

Исправительный счет-фактуру можно ввести на основании документов Счет-фактура полученный, Корректировочный счет-фактура полученный и Исправительный счет-фактура полученный.

Примечание. Возможность ввода документа на основании другого документа Исправительный счет-фактура полученный позволяет многократно и последовательно вносить исправления.

После заполнения и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида Исправительный счет-фактура полученный можно открыть с помощью команды Исправительные счета-фактуры полученные меню функций раздела Налоги.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Исправительные счета-фактуры полученные.

Заполнение реквизитов шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Все реквизиты шапки документа, за исключением группы Исправление, заполняются так же, как реквизиты шапки документа Корректировочный счет-фактура полученный.

Реквизиты группы Исправление:

  • Номер исправления – порядковый номер исправления счета-фактуры или корректировочного счета-фактуры;
  • Дата – дата исправления счета-фактуры или корректировочного счета-фактуры.

Закладка "Товары, работы, услуги"

Закладка содержит табличную часть, в которой приводятся данные о полученных товарах, работах и услугах, а также о корреспонденции счетов, по которой производится исправление НДС.

Примечание. При вводе на основании табличная часть заполняется автоматически.

После вода документа на основании его табличная часть содержит поля реквизитов суммовых показателей, отражающих данные ...до изменения и ...после изменения.

Реквизиты ...до изменения отражают данные документа-основания, которые будут сторнированы при проведении.

Реквизиты ...после изменения отражают новые данные, по которым будут сформированы новые движения.

Также табличная часть может содержать поля ...до корректировки, отражающие данные исходного счета-фактуры, исправление которых производится текущим документом, и которые выводятся только для информации.

Примечание. Видимость реквизитов …до корректировки в форме документа по умолчанию отключена, но при необходимости ее можно включить, используя Настройку формы.
Для открытия окна Настройка формы следует нажать на кнопку Еще командной панели формы документа и выбрать в списке команду Изменить форму.
Далее следует в дереве элементов окна последовательно открыть группы Основная часть, Товары, работы, услуги и Состав НФА.
Соответствующие реквизиты …до корректировки находятся в группах Количество, Сумма Ставка НДС и т.д.
Включения видимости данных реквизитов выполняется с помощью установки флагов рядом с их наименованиями.

Для исправления суммовых показателей счета-фактуры следует вносить изменения в значения реквизитов ...после изменения.

Закладка "Реквизиты счета-фактуры"

Закладка содержит текстовые поля для ввода реквизитов счета-фактуры: Наименование продавца, Адрес продавца, ИНН продавца и т.д.

Примечание. При вводе на основании реквизиты на закладке заполняются автоматически.

Закладка "Платежные документы"

На данной закладке указываются даты и номера платежных документов, в соответствии с которыми производится начисление НДС.

Закладка "Бухгалтерская операция"

Типовая операция – выбирается из списка Типовые операции.

Для документа предусмотрена одна типовая операция:

  • Исправление входящего НДС.

Для данной типовой операции следует заполнить реквизит:

  • КПС для счета 303.04 – классификационный признак счета для счета 303.04. Выбирается в справочнике КПС.

Примечание. Если существует рабочий счет, то заполнение реквизита КПС для счета 303.04 необязательно.

Регистрация документа

Регистрация документа Исправительный счет-фактура полученный производится в списке Исправительные счета-фактуры полученные.

Дополнительные возможности

На основании документа Исправительный счет-фактура полученный можно ввести документы:

  • Исправительный счет-фактура полученный;
  • Корректировочный счет-фактура полученный;
  • Регистрация строки книги продаж.
