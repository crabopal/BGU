Документ "Инвентаризация кредитов и займов"

Документ Инвентаризация кредитов и займов предназначен для формирования регистра бухгалтерского учета Инвентаризационная опись задолженности по кредитам, займам (ссудам) (ф. 0504083).

Работа со списком документов

Список документов Инвентаризация кредитов и займов можно открыть с помощью команды Инвентаризация кредитов и займов меню функций раздела Планирование и санкционирование или раздела Инвентаризация.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Инвентаризация кредитов и займов.

Заполнение реквизитов шапки документа

Инвентаризация по состоянию на – дата, на которую проводится инвентаризация и определяются остатки по счетам бухгалтерского учета при автозаполнении документа.

КФО – код вида финансового обеспечения. Выбирается из списка.

Закладка "Задолженность"

Для заполнения табличной части на закладке Задолженность удобно использовать кнопку Заполнить.

После нажатия на кнопку Заполнить следует выбрать из списка вариант заполнения:

  • по данным бухгалтерского учета – заполняется по данным бухгалтерского учета, отраженным в программе;
  • подтвержденные суммы по данным бух. учета – используется, если дебитор (заемщик) подтвердил задолженность по акту сверки расчетов;
  • просроченные суммы по данным договоров – используется при наличии просроченной задолженности.

Закладка "Комиссия"

Если в учреждении уже создана комиссия с необходимыми обязанностями, то ее можно выбрать из справочника Постоянно действующие комиссии, который можно открыть с помощью команды Выбрать из постоянно действующих комиссий.

После выбора комиссии реквизиты номер и дата Приказа о назначении комиссии, Председатель комиссии и Члены комиссии будут заполнены автоматически.

При необходимости реквизиты на закладке можно заполнить вручную. Для этого в группе реквизитов Приказ о назначении комиссии следует указать номер и дату соответствующего приказа.

Группа Председатель комиссии включает реквизиты Должность, Фамилия, Имя и Отчество.

Для заполнения реквизитов можно выбрать необходимого сотрудника из справочника Сотрудники или заполнить поля вручную.

Информация о должности, фамилии, имени и отчестве каждого члена комиссии вводится в табличную часть закладки.

Для удобного заполнения документа предназначена кнопка Подобрать, нажатие на которую позволяет вызвать форму подбора справочника Сотрудники.

В группе Сведения о проводимой инвентаризиции заполняются реквизиты, необходимые для заполнения соответствующих полей печатной формы: Приказ №, дата (от), Период проведения с и по, Причина и Место проведения.

В группе реквизитов Дата подписания описи указываются даты подписания инвентаризационной описи ответсвенным лицом и комиссией.

Печать

Чтобы распечатать Инвентаризационную опись задолженности по кредитам, займам (ссудам) (ф. 0504083) ее необходимо предварительно записать с помощью кнопки Записать командной панели формы документа.

Для формирования печатной формы ведомости нужно нажать кнопку Печать.
