Дополнительные возможности

Документ "Списание автотранспорта имущества казны (ОС-4а)"

Для оформления и учета операции по списанию автотранспортного средства в составе имущества казны используется документ Списание автотранспорта ИК (Акт списания ОС-4а).

После заполнения и записи документа можно сформировать печатную форму Акт о списании автотранспортных средств ОС-4а (форма по ОКУД 0306004).

Также после заполнения реквизитов бухгалтерской операции и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида Списание автотранспорта ИК можно открыть с помощью команды Списание автотранспорта ИК панели навигации раздела Имущество казны.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Списание автотранспорта ИК.

Заполнение реквизитов шапки документа

В первую очередь необходимо заполнить реквизиты Организация и Дата.

Подразделение – выбирается из справочника Подразделения.

Дата списания с бухгалтерского учета – дата списания автотранспортного средства в составе имущества казны в бухгалтерском учете.

Заполнение реквизитов на закладке "Сведения об основном средстве"
  • КФО – код финансового обеспечения, равен "1" (бюджетная деятельность);
  • КПС – классификационный признак счета учета объекта ОС в составе имущества казны. Выбирается в справочнике КПС;
  • Основное средство – транспортное средство. Выбирается из справочника Основные средства;
  • Инв. номер – инвентарный номер.

В группе реквизитов Основание для составления акта следует указать наименование, номер и дату первичного документа, послужившего основанием для составления Акт о списании автотранспортных средств по форме ОС 4а.
Реквизиты Балансовая стоимость и Амортизация группы реквизитов Расчет стоимости ОС заполняются автоматически после нажатия на кнопку Рассчитать стоимость ОС.
Причина списания – причина списания автотранспортного средства. Выбирается из справочника Причины списания НФА.

Заполнение реквизитов на закладке "Комиссия"

Группа Председатель комиссии включает реквизиты Должность, Фамилия, Имя и Отчество.

Информация о должности, фамилии, имени и отчестве каждого члена комиссии вводится в табличную часть закладки.

Примечание. Если в организации уже создана комиссия с необходимыми обязанностями, то ее можно выбрать из справочника Постоянно действующие комиссии, который можно открыть с помощью команды Выбрать из постоянно действующих комиссий. После выбора комиссии все реквизиты на закладке будут заполнены автоматически.

Заполнение реквизитов на закладке "Бухгалтерская операция"

Типовая операция – выбирается из списка Типовые операции.

Выбытие вследствие стихийных бедствий

Для данной типовой операции необходимо заполнить реквизит КПС (401.20) – классификационный признак счета для счета 401.20. Выбирается из справочника КПС.

Выбытие имущества казны

Типовая операция Выбытие имущества казны выбирается при списании недостач, выбытии реализованных или пришедших в негодность объектов автотранспорта в составе имущества казны.

Для данной типовой операции необходимо заполнить реквизит КПС (401.10) – классификационный признак счета для счета 401.10. Выбирается из справочника КПС.

Проведение документа

После заполнения реквизитов документ необходимо провести. Состав бухгалтерских проводок, сформированных при проведении документа, зависит от выбранной Типовой операции.

Проводки, формируемые для типовой операции Выбытие вследствие стихийных бедствий:

  • Дт 401.20.273 "Расходы текущего финансового года" – Кт 104.58.410 "Амортизация движимого имущества в составе имущества казны", начисление амортизации текущего месяца;
  • Дт 104.58.410 "Амортизация движимого имущества в составе имущества казны" – Кт 108.52.410 "Движимое имущество, составляющее казну", списание амортизации, начисленной на автотранспортное средство имущества казны;
  • Дт 401.20.273 "Расходы текущего финансового года" – Кт 108.52.410 "Движимое имущество, составляющее казну", списание остаточной стоимости автотранспортного средства имущества казны.

Проводки, формируемые для типовой операции Выбытие имущества казны:

  • Дт 401.10.172 "Доходы текущего финансового года" – Кт 104.58.410 "Амортизация движимого имущества в составе имущества казны", начисление амортизации текущего месяца;
  • Дт 104.58.410 "Амортизация движимого имущества в составе имущества казны" – Кт 108.52.410 "Движимое имущество, составляющее казну", списание амортизации, начисленной на автотранспортное средство имущества казны;
  • Дт 401.10.172 "Доходы текущего финансового года" – Кт 108.52.410 "Движимое имущество, составляющее казну", списание остаточной стоимости автотранспортного средства имущества казны.

Регистрация документа

Регистрация документа Списание автотранспорта ИК производится в журнале Документы по учету имущества казны.

Дополнительные возможности
