Документ "Оприходование МЗ по фактической стоимости"

Документ Оприходование МЗ по фактической стоимости предназначен для принятия к учету материальных запасов по фактической стоимости, если приобретение или безвозмездное получение материальных запасов сопровождается дополнительными расходами на услуги по их доставке, хранению и т.д.
На основании заполненного и проведенного документа можно распечатать «Приходный ордер» (ф. 0504207) и бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида Оприходование МЗ по фактической стоимости можно открыть с помощью команды Оприходование МЗ по фактической стоимости меню функций раздела Материальные запасы.

Создание нового документа

Новый документ можно создать из документа Поступление МЗ с помощью кнопки Создать на основании – Оприходование МЗ по фактической стоимости.
Также новый документ можно ввести с помощью кнопки Создать командной панели списка Оприходование МЗ по фактической стоимости.

Заполнение реквизитов шапки документа

Партии МЗ – документ, которым были сформированы проводки по оприходованию материалов на счет 106.ХП. Выбираются из списка Авансовый отчет, Ввод начальных остатков, Поступления МЗ.

КПС счета 105 – классификационный признак счета. Выбирается из справочника.

Группа Отправитель:

  • МОЛ/Место хранения – центр материальной ответственности (материально ответственное лицо, место хранения), в который приходуются материалы. Выбирается из справочника Центры материальной ответственности.
  • Подразделение – выбирается из справочника Подразделения.

Аналогичные реквизиты следует заполнить в группе Получатель.

Закладка "Материалы"

Информация о материальных запасах, в которые производятся вложения дополнительных расходов по их доставке, хранению и т. д., вводится в табличную часть на закладке Материалы.
Реквизиты табличной части заполняются автоматически при нажатии на кнопку Заполнить по основанию:

  • Номенклатура – наименование материала из справочника Номенклатура.
  • Количество – количество материальных запасов в партии.
  • Сумма – стоимость указанного количества материальных запасов, сформированная с учетом остатков на счете 106.ХП.
  • Счет учета материалов – полный счет учета материалов и дополнительная аналитика (при наличии). После выбора КПС счета 105 и нажатии кнопки Заполнить КПС учета во всех графах автоматически заполнится КПС, входящий в полный счет учета.
  • Счет вложений – полный счет учета вложений 106.2П или 106.3П и вид затрат.

Закладка "Бухгалтерская операция"

Предусмотрена единственная типовая операция - Принятие к учету по фактической стоимости.

Проведение документа

Для проведения документа необходимо нажать кнопку Провести или Провести и закрыть.
При проведении документа формируются следующие бухгалтерские записи:

  • Дт 0.105.XX.340 – Кт 0.106.3П.340 (0.106.2П.340) (оприходование материальных запасов в сумме их фактической стоимости, сформированной при их приобретении, при безвозмездном получении).
