Документ "Начисление за услуги образования"

Документ Начисление за услуги образования предназначен для отражения в учете:

  • начисления плательщикам сумм по краткосрочным договорам образовательных услуг;
  • признания доходов будущих периодов по долгосрочным договорам об оказании образовательных услуг доходами текущего периода (равномерно или неравномерно согласно графику).

Документ позволяет производить начисления как в рублях, так и в произвольной валюте. Для включения возможности выполнять начисления в валюте следует установить флаг Учет расчетов и обязательств ведется в иностранных валютах в разделе Общие настройки формы Настройка параметров учета.

Внимание! Документ Начисление за услуги образования формируется по одному виду валюты. Если необходимо выполнить начисление по разным видам валюты, то следует создать несколько документов Начисление за услуги образования с указанием конкретной валюты начисления в каждом.

Работа со списком документов

Список документов Начисления за услуги образования можно открыть с помощью команды Начисления за услуги образования меню функций раздела Платное обучение.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Начисления за услуги образования.

Заполнение реквизитов шапки документа

Период начисления – выбирается месяц начисления;

Факультет – наименование факультета. Выбирается из справочника Подразделения;

Номенклатура – наименование образовательной услуги. Выбирается из фрагмента справочника Номенклатура, ограниченного перечнем услуг.

Вид начисления может принимать значения:

  • По долгосрочным договорам – по договорам, учет доходов по которым ведется согласно Стандарту "Долгосрочные договоры" (с 01.01.2020 г.).
  • По краткосрочным договорам – по договорам, которые не относятся к долгосрочным.

НДС не учитывается – гиперссылка для вызова формы Цены в документе, которая содержит группы Валюта документа и НДС в документе.

Группа Валюта документа позволяют задать для документа значения реквизитов Валюта, Курс и Кратность на определенную дату.

Группа НДС в документе содержит флажки:

  • Учитывать НДС – после установки флажка в табличной части документа будут доступны колонки Ставка НДС и Сумма НДС.
  • Включен в сумму – установка или снятие флажка способ отображения НДС в документе.

Закладка "Начисления"

Для добавления строк в табличную часть закладки вручную можно использовать кнопку Добавить командной панели.

Для автоматического заполнения данными табличной части следует нажать на кнопку Заполнить и выбрать в меню команду Учащиеся по отбору. Откроется форма Настройка параметров отбора учащихся, которая настроена по умолчанию на отбор учащихся по факультету, указанному в шапке документа, и которая может быть при необходимости дополнена отбором по другим реквизитам – Группа, Курс, Льгота и т.д. По окончании настройки отбора после нажатия на кнопку Выполнить отбор и заполнить документ табличная часть на закладке будет заполнена данными.

Внимание! Табличная часть заполняется данными, которые актуальны на дату документа.

Общие реквизиты табличной части для любого Вида начисления:

  • Учащийся – учащийся факультета.
  • Группа Плательщик включает реквизиты Контрагент и Договор контрагента, которые указаны в карточке учащегося.
  • Порядок выписки счета-фактуры – автоматически указывается порядок, заданный в карточке учащегося.
  • План-график реализации – порядок отражения начисления в плане-графике реализации по договору, если указанный график ведется: Отразить сейчас, Отразить позднее или Не отражать.

Реквизиты табличной части для вида начисления По краткосрочным договорам:

  • Период начисления – дата начала и дата окончания начисления. Период высчитывается автоматически с учетом данных в документах вида Приказ (образование).
  • Ставка оплаты – выводится ставка учащегося, указанная в документе Приказ (образование).
  • Льгота – выводится льгота учащегося, если она назначена документом Приказ (образование).
  • Дней посещения – количество дней посещения. Реквизит доступен для заполнения в случае, если в карточке Ставки оплаты заполнен реквизит Ставка за день. В этом случае сумма начисления будет рассчитана автоматически с помощью умножения ставки за день на количество дней посещения. В остальных случаях данное поле заполнения не требует.
  • Сумма – сумма начисления, рассчитывается автоматически. Формулу расчета можно просмотреть с помощью кнопки Показать формулу расчета командной панели табличной части. В случае если значение реквизита Сумма будет задано вручную, то поля Ставка оплаты и Льгота будут очищены.
  • Ставка НДС– ставка НДС, выбирается из списка.
  • Сумма НДС – сумма НДС, рассчитывается автоматически.

Реквизиты табличной части для вида начисления По долгосрочным договорам::

  • Счет учета и Остаток – счет учета и остаток доходов будущих периодов. Заполняются автоматически по остаткам на счетах группы 401.40.
  • Сумма – сумма начисления, сумма доходов от реализации текущего периода. При заполнении документа рассчитывается автоматически на основании остатков доходов будущих периодов по счету 401.40 и установленного для договора способа признания доходов – По месяцам, По календарным дням, По графику или В особом порядке.
  • Ставка НДС – ставка НДС, заполняется автоматически, устанавливается в карточке номенклатуры образовательных услуг (реквизит шапки Номенклатура).
  • Сумма НДС – сумма НДС, рассчитывается автоматически.
  • Всего – итоговая сумма по строке, рассчитывается автоматически.
  • Счет доходов, Субконто доходов – счет и аналитика бухгалтерского учета доходов текущего периода. Заполняется автоматически на основании параметров, установленных документом Начисление доходов будущих периодов (образование).
  • Налоговый учет – порядок отражения доходов в налоговом учете по налогу на прибыль. Заполняется автоматически на основании параметров, установленных документом Начисление доходов будущих периодов (образование).
  • Параметры расчета – справочно приводится способ и параметры признания доходов текущего периода по договору, установленные документом Начисление доходов будущих периодов (образование).
  • Коэффициент списания – справочно приводится формула расчета и значение коэффициента списания. Коэффициент списания определяет долю доходов будущих периодов, перенесенных в данном месяце на доходы текущего периода следующим образом: Остаток доходов будущих периодов * Коэффициент списания = Сумма доходов от реализации текущего периода. Коэффициент списания рассчитывается как отношение значения в колонке Всего к значению в колонке Остаток.

Закладка "Бухгалтерская операция"

Типовая операция – выбирается из списка Типовые операции.

Для вида начисления По краткосрочным договорам типовая операция имеет значение Начисление за платное обучение (205 – 401.10).

Для данной типовой операции необходимо заполнить реквизиты:

  • КФО – код финансового обеспечения. Выбирается из списка;
  • КПС – классификационный признак счета. Выбирается из справочника.

Группа Счет и аналитика доходов:

  • Счет доходов – автоматически принимает значение 401.10.
  • КЭК – код экономической классификации. Выбирается из справочника.

В группе Расчеты при наличии на счете расчета дополнительной аналитики заполняется реквизит Доп. аналитика.

Для вида начисления По долгосрочным договорам типовая операция имеет значение Начисление по долгосрочным договорам на платное обучение (401.40 - 401.10).

Дополнительные возможности

На основании документа Начисление за услуги образования можно создать документы:

  • Квитанция на оплату;
  • Сторно.

Формирование счетов-фактур и актов об оказании услуг

Для формирования счетов-фактур и актов об оказании услуг необходимо открыть форму Управление счетами-фактурами и печать с помощью гиперссылки, расположенной в нижней части формы документа Начисление за услуги образования. Счета-фактуры автоматически создаются после нажатия на кнопку Сформировать счета-фактуры командной панели формы.

Создание счетов-фактур выполняется по правилам, заданным в карточке каждого учащегося в реквизите Порядок выписки СФ группы Сведения о плательщике за услуги образования.

Реквизит Порядок выписки СФ может принимать значения:

  • На плательщика. В этом случае счет-фактура будет оформлен на Плательщика, который указан в карточке учащегося;
  • Сводно. В данном случае счет-фактура будет оформлен на служебного контрагента, указанного в реквизите Контрагент для сводного счета-фактуры в разделе Услуги, работы, производство формы Настройка параметров учета.

Сформированные счета-фактуры можно открыть, просмотреть и при необходимости отредактировать с помощью гиперссылок в колонке Счет-фактура формы Управление счетами-фактурами и печать.

Анализ и исправление ошибок

Если в процессе формирования счетов-фактур возникли ошибки, то сообщения о них появятся в колонке Ошибка. Необходимо проанализировать текст ошибок и исправить их. Далее, если переоформление счетов-фактур не требуется, то следует нажать на кнопку Обновить список. Для того чтобы снова сформировать счета-фактуры следует использовать кнопку Сформировать счета-фактуры.

Печать одиночного счета-фактуры

Для того чтобы сформировать печатную форму одного счета-фактуры, следует выделить его в списке, нажать на кнопку Печать командной панели формы Управление счетами-фактурами и печать и выбрать в меню пункт Счет-фактура.

Групповая печать счетов-фактур

Для группового создания печатных форм счетов фактур следует выделить их в списке, нажать на кнопку Печать и выбрать в меню пункт Счет-фактура.

Печать "Акта об оказании услуг"

Для создания печатной формы Акта об оказании услуг следует выделить строку табличной части, нажать на кнопку Печать командной панели формы Управление счетами-фактурами и печать и выбрать в меню пункт Акт об оказании услуг. Групповое создание печатных форм актов выполняется аналогично групповому созданию форм счетов-фактур.

Автоматическая нумерация "Актов об оказании услуг"

Нумерация печатных форм Актов об оказании услуг в рамках одного документа Начисление за услуги образования выполняется по следующему правилу. Номер каждого Акта состоит из номера документа Начисление за услуги образования и номера соответствующего Счета-фактуры, разделенных знаком "/" без кавычек.

Пример. Документ Начисление за услуги образования от 30.09.2012 имеет номер БУ00-000003. В форме Управление счетами-фактурами и печать по команде Сформировать счета-фактуры был сформирован документ Счет-фактура выданный от 30.09.2012 с БУ00-000001. При формировании печатной формы Акта об оказании услуг системой автоматически будет сформирован Акт от 30.09.2012 с номером БУ00-00003/БУ00-000001.
