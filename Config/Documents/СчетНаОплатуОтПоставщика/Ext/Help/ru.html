Документ "Счет на оплату от поставщика"

Документ используется, в основном, как владелец входного электронного документа «Счет», полученного от поставщика.

Документ формируется автоматически при получении электронного документа «Счет», и содержит реквизиты шапки своего электронного документа.

Из формы документа можно открыть электронный документ «Счет», который содержит всю информацию по документу. Электронный документ можно открыть либо по гиперссылке Состояние ЭД, либо из панели инструментов ЭД / Открыть актуальный электронный документ.

Если есть необходимость, документ возможно использовать самостоятельно, т.е. без использования электронного документооборота.
