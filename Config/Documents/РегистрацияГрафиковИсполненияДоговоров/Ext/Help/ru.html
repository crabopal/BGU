Документ "Регистрация графиков исполнения договора"

Документ Регистрация графиков исполнения договора используется для регистрации и корректировки плановых данных (графиков) по договорам с контрагентами.

Работа со списком документов

Список документов вида Регистрация графиков исполнения договоров можно открыть с помощью команды Регистрация графиков исполнения договоров меню функций раздела Планирование и санкционирование.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Регистрация графиков исполнения договоров. Также новый документ можно создать на основании Договора или иного основания возникновения обязательств.

Заполнение шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Контрагент – выбирается из справочника Контрагенты.
Договор – выбирается из справочника Договоры и иные основания возникновения обязательств. Выбор договора ограничен указанными реквизитами Организация и Контрагент.
Доступные виды графиков определяются значением реквизита Вид договора у выбранного Договора:

  • С поставщиком. Доступны График платежей и План-график закупок.
  • С покупателем (в т.ч. субсидии на гос. задание). Доступны График платежей и План-график реализации.
  • Предоставленный кредит (заем) и Полученный кредит. Доступен График платежей.

Закладка "График платежей"

Используется для ввода и уточнения актуального графика платежей.

Если полный график платежей на текущий момент не известен, то можно ввести несколько очередных платежей, либо сводные данные об ожидаемых платежах (по месяцам, кварталам и т.д.).

График платежей можно уточнять в течение срока действия договора.

Примечание. Закладка График платежей доступна для заполнения, если в договоре, указанном в реквизите Договор, установлен флажок График платежей в группе Вести графики исполнения.

При заполнении таблицы для добавления новой строки можно использовать кнопку Добавить командной панели таблицы.

Оплатить до – крайняя запланированная дата оплаты по договору. Позднее данной даты обязательство по оплате товаров, работ, услуг будет считаться просроченным.

Вид расчетов – выбирается из списка:

  • Основной долг.
  • Проценты.
  • Штрафы.
  • Пени на основной долг.
  • Пени на проценты.

Сумма – сумма оплаты.

КФО – код финансового обеспечения, выбирается из списка.

КПС – классификационный признак счета, выбирается из справочника КПС.

КЭК – код экономической классификации, выбирается из справочника КЭК.

Счет расчетов – выбирается из фрагмента Плана счетов ЕПСБУ.

Закладка "План-график реализации"

Используется для ввода и уточнения актуального плана-графика реализации.

Если полный план-график реализации на текущий момент не известен, то можно ввести данные об известных очередных отгрузках, либо ввести сводные данные об ожидаемых отгрузках (по месяцам, кварталам и т.д.).

План-график реализации можно уточнять в течение срока действия договора.

Внимание!
План-график закупок (реализации) содержит только суммы основного долга. Планы по поступлению (выплате) процентов, штрафов, пеней по договору отражаются только в графике платежей. План-график закупок (реализации) содержит только суммы основного долга.

Примечание. Закладка План-график реализации доступна для заполнения, если в договоре, указанном в реквизите Договор, установлен флажок План-график реализации в группе Вести графики исполнения.

При заполнении таблицы для добавления новой строки можно использовать кнопку Добавить командной панели таблицы.

Исполнить до – крайняя запланированная дата отгрузки по договору.
Позднее данной даты обязательство по отгрузке товаров, работ, услуг будет считаться просроченным.

Сумма – сумма отгрузки.

КФО – код финансового обеспечения, выбирается из списка.

КПС – классификационный признак счета, выбирается из справочника КПС.

КЭК – код экономической классификации, выбирается из справочника КЭК.

Счет расчетов – выбирается из фрагмента Плана счетов ЕПСБУ.

Внесение изменений в графики исполнения договора

Для внесения изменений в графики исполнения договора можно с помощью кнопки Изменить, расположенной в нижней командной панели формы документа, создать новый документ Регистрация графиков исполнения договора.

В новом документе вместо колонки Сумма появятся колонки До изменений, Изменение и После изменений.

Для ввода данных доступны колонки Изменение и После изменений.

После внесения необходимых изменений документ следует провести. Статус документа в результате проведения изменится со статуса Недействующая редакция документа на статус Действующая редакция документа.

Также, с целью внесения изменений, можно создать новый документ Регистрация графиков исполнения договора с помощью кнопки Создать на основании.
