Документ "Начисление резервов по отпускам"

Документ Начисление резервов по отпускам предназначен для отражения в учете суммы резервов на оплату отпусков (компенсации отпусков) в соответствии с положениями инструкции №157н.

После заполнения и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов Начисление резервов по отпускам можно открыть с помощью команды Начисление резервов по отпускам меню функций раздела Учет и отчетность.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Начисление резервов по отпускам.

Документ может быть заполнен как вручную, так и автоматически при обмене данными с программой «1С:Зарплата и кадры государственного учреждения», редакция 3.0.
