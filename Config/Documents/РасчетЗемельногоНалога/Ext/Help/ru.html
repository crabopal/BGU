Документ "Расчет земельного налога"

С 2021 года отменена обязанность по представлению налоговых деклараций по земельному налогу, а для верификации платежей по земельному налогу, поступившему за соответствующий налоговый период, учреждениям направляются сообщения об исчисленных налоговыми органами суммах по данному налогу.

Документ Расчет земельного налога предназначен для рассчета учреждениями суммы земельного налога поквартально, а также формирования печатной формы в разрезе налоговых органов и кодов по ОКТМО для удобного сравнения с присланными сообщениями из налоговых органов.

Работа со списком документов

Документы вида Расчет земельного налога можно открыть с помощью команды Расчет земельного налога меню функций раздела Налоги.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели формы Расчет земельного налога.

Работа с документом

Отчетный период – указывается отчетный период, за который нужно рассчитать сумму земельного налога.

Организация – заполняется автоматически, значение можно изменить.

Для автоматического заполнения таблицы земельными участками учреждения следует использовать кнопку Заполнить. В результате графы Земельный участок, Инвентарный номер, Налоговый орган, Код по ОКТМО, Налоговая база, Необлагаемая налогом сумма, Налоговая ставка, Месяцев владения, Доля в праве общей собсвенности, Доля необлагаемой налогом площади, Процент уменьшения, Сумма уменьшения, Сумма налога заполнятся автоматически согласно регистру сведений Регистрация земельного участка, в котором для каждого земельного участка учреждения были предварительно введены данные о их порядке налогообложения земельным налогом.

При необходимости добавления новых строк в ручном режиме следует использовать кнопку Добавить. Далее для расчета земельного налога следует воспользоваться кнопкой Рассчитать.

Дополнительные возможности

На основании документа Расчет земельного налога можно ввести документ Начисление имущественных налогов.
