Проведение документа

Документ "Принятие к учету зданий (сооружений) имущества казны (ОС-1а)"

Документ Принятие к учету зданий (сооружений) имущества казны (ОС-1а) используется для принятия к учету зданий (сооружений) и включения их в состав имущества казны.

После заполнения и записи документа можно сформировать печатную форму Акт о приеме-передаче здания (сооружений) ОС-1а (форма по ОКУД 0306030).

Также после заполнения реквизитов бухгалтерской операции и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида Принятие к учету зданий (сооружений) ИК можно открыть с помощью команды Принятие к учету зданий (сооружений) ИК панели навигации раздела Имущество казны.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Принятие к учету зданий (сооружений) ИК.

Заполнение реквизитов шапки документа

В первую очередь необходимо заполнить реквизиты Организация и Дата.

  • Лицевой счет – лицевой счет организации, с которого должно производиться при необходимости перечисление средств. Выбирается в справочнике Реквизиты лицевых счетов;
  • Поставщик – поставщик объекта имущества казны. Выбирается из справочника Контрагенты.

Реквизит Вид поступления может принимать значения:

  • Поступление;
  • Возврат из аренды;
  • Возврат из безвозмездного пользования.

В группе реквизитов Основание для составления акта следует указать наименование, номер и дату первичного документа, послужившего основанием для составления Акта о приеме передаче основных средств по форме ОС 1а.

Вид первичного документа, по которому поступил объект ИК, его номер и дату следует указать в группе реквизитов Первичный документ.

Заполнение реквизитов на закладке "Общие сведения"
  • Основное средство – выбирается из справочника Основные средства. Для выбора при этом доступны только объекты ОС, у которых реквизит Вид НФА имеет значение Имущество казны;
  • Инвентарный номер – выбирается из справочника Инвентарные номера ОС;
  • Первоначальная стоимость – первоначальная стоимость объекта ОС.

В случае ошибок, допущенных в процессе оформления документа при возврате имущества казны из аренды или безвозмездного пользования, автоматическое заполнение реквизита Первоначальная стоимость может не состояться. В этом случае необходимо найти и исправить ошибки, допущенные при заполнении документа, а затем нажать на кнопку Пересчет, расположенную справа от поля ввода реквизита Первоначальная стоимость. Кнопка Пересчет доступна, только если реквизит Вид поступления имеет значения Возврат из аренды или Возврат из безвозмездного пользования.

Переданная амортизация – полученная сумма амортизации.

Внимание! Реквизит Переданная амортизация, а также реквизиты групп Параметры начисления амортизации, Затраты по амортизации и Ввод в эксплуатацию доступны для заполнения только для значения Поступление реквизита Вид поступления в шапке документа.

В группе Параметры начисления амортизации заполняются реквизиты Срок полезного использования и Порядок погашения стоимости, выбирается Способ начисления амортизации.

Примечание. Если амортизация временно не должна начисляться, то необходимо снять флаг Начислять амортизацию.

Реквизиты группы Затраты по амортизации:

  • Счет – счет учета затрат по амортизации. Выбирается из Плана счетов (ЕПСБУ);
  • КЭК – код экономической классификации. Подставляется автоматически после заполнения реквизита Счет;
  • КПС – классификационный признак счета затрат. При необходимости заполнения выбирается из справочника КПС.

Важно! При незаданном КПС поле выбора КПС содержит текст , при этом амортизация или списание балансовой стоимости ОС выполняется по КПС, указанному для счета 101.ХХ.

Программа позволяет начислять амортизацию на КПС, отличный от КПС счета учета ОС 101.ХХ. При заданном значении КПС амортизация или списание балансовой стоимости будут выполняться на указанный КПС.

Примечание. Доступность для заполнения реквизитов Субконто 1, Субконто 2 и Субконто 3 зависит от настройки аналитического учета на счете учета затрат, указанном в реквизите Счет.

Реквизит Переданная амортизация, а также реквизиты группы Ввод в эксплуатацию заполняются при приеме основного средства, которое было ранее введено в эксплуатацию у поставщика. Заполнение указанных реквизитов при этом производится на основании данных, которые содержатся в акте поставщика.

Заполнение реквизитов на закладке "Комиссия"

Группа Председатель комиссии включает реквизиты Должность, Фамилия, Имя и Отчество.

Информация о должности, фамилии, имени и отчестве каждого члена комиссии вводится в табличную часть закладки.

Примечание. Если в организации уже создана комиссия с необходимыми обязанностями, то ее можно выбрать из справочника Постоянно действующие комиссии, который можно открыть с помощью команды Выбрать из постоянно действующих комиссий. После выбора комиссии все реквизиты на закладке будут заполнены автоматически.

Заполнение реквизитов на закладке "Бухгалтерская операция"

Типовая операция – выбирается из списка Типовые операции.

Если реквизит Вид поступления в шапке документа имеет значение Поступление, то Типовая операция может принимать значения:

  • Внутриведомственное поступление;
  • Поступление от других организаций.

Если реквизит Вид поступления имеет значение Возврат из аренды или Возврат из безвозмездного пользования, то реквизит Типовая операция может принимать только одно значение – Возврат из пользования.

Внутриведомственное поступление

Для данной типовой операции необходимо заполнить реквизиты:

  • КПС счета 304.04 – классификационный признак счета для счета 304.04. Выбирается из справочника КПС;
  • КПС счета 108 – классификационный признак счета для счета 108.ХХ, выбирается в справочнике КПС. Если заполнен рабочий план счетов, то этот реквизит необязателен для заполнения.

Поступление от других организаций

Для данной типовой операции необходимо заполнить реквизиты:

  • КПС счета 108 – классификационный признак счета для счета 108.ХХ, выбирается в справочнике КПС. Если заполнен рабочий план счетов, то этот реквизит необязателен для заполнения;
  • КПС кредита – классификационный признак счета кредита. Выбирается из справочника КПС;
  • КЭК кредита – код экономической классификации счета кредита. Выбирается из справочника КЭК.

Возврат из пользования

Реквизиты у данной типовой операции отсутствуют.

Проведение документа

После заполнения реквизитов документ необходимо провести. Состав бухгалтерских проводок, сформированных при проведении документа, зависит от выбранной Типовой операции.

Проводки, формируемые для типовой операции Внутриведомственное поступление:

  • Дт 108.51 "Недвижимое имущество, составляющее казну" – Кт 304.04 "Внутриведомственные расчеты" на сумму, равную первоначальной стоимости объекта имущества казны;
  • Дт 304.04 "Внутриведомственные расчеты" – Кт 104.51 "Амортизация недвижимого имущества в составе имущества казны" на сумму переданной амортизации.

Проводки, формируемые для типовой операции Поступление от других организаций:

  • Дт 108.51 "Недвижимое имущество, составляющие казну" – Кт 401.10 "Доходы текущего финансового года" на сумму, равную первоначальной стоимости объекта имущества казны;
  • Дт 401.10 "Доходы текущего финансового года" – Кт 104.51 "Амортизация движимого имущества в составе имущества казны" на сумму переданной амортизации.

Проводка, формируемая для типовой операции Возврат из пользования:

  • Кт 25.11 "ОС - недвижимое имущество, переданное в аренду" или Кт 26.11 "ОС - недвижимое имущество, переданное в безвозмездное пользование" на сумму, равную первоначальной стоимости объекта имущества казны.

Регистрация документа

Регистрация документа Принятие к учету зданий (сооружений) ИК производится в журнале Документы по учету имущества казны.

Дополнительные возможности

На основании документа Принятие к учету зданий (сооружений) ИК можно ввести документ Сторно.
