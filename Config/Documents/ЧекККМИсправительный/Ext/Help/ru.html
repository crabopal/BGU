Документ "Исправительный чек ККМ"

Документ Исправительный чек ККМ предназначен для формирования чеков для операций двух видов:

  • Исправление чека ККМ;
  • Неприменение ККТ.

Документ Исправительный чек ККМ с видом операции Исправление чека ККМ применяется для формирования чека с обратным типом расчета (чека сторно), идентичного некорректному чеку, с целью исправления ошибок.

Документ с операцией Исправление чека ККМ можно вводить на основании любого документа программы с возможностью печати кассового чека.:

  • Приходный кассовый ордер;
  • Расходный кассовый ордер;
  • Эквайринговая операция;
  • Кассовое поступление;
  • Кассовое выбытие;
  • Заявка на возврат;
  • Заявка на кассовый расход;
  • Заявка на кассовый расход (сокращенная);
  • Платежное поручение;
  • Чек ККМ;
  • Чек ККМ на возврат;
  • Чек ККМ на передачу;
  • Чеки ККМ для реестра платежей.

Примечание. При вводе на основании документа Чеки ККМ для реестра платежей требуется указать некорректный кассовый чек из списка.

Примечание. Документ Исправительный чек ККМ с видом операции Исправление чека ККМ позволяет сторнировать некорректный чек ККМ документа-основания и напечатать чек-сторно. Далее необходимо вернуться к документу-основанию, внести в него необходимые исправления, а затем провести и напечатать корректный чек.

Документ Исправительный чек ККМ с видом операции Неприменение ККТ применяется для формирования чека коррекции в целях освобождения от административной ответственности в случае, если ранее имела место продажа товара (услуг, работ) без выдачи чека.

Работа со списком документов

Список документов вида Исправительный чек ККМ можно открыть с помощью команды Исправительный чек ККМ группы Управление ККТ в меню функций раздела Денежные средства.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Исправительный чек ККМ.
