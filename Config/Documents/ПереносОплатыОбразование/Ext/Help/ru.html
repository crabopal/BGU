Документ "Перенос оплаты (образование)"

Документ Перенос оплаты (образование) предназначен для отражения в учете операций по зачету платежей контрагентов (прочих кредиторов) в оплату услуг по договорам платного обучения учащихся. В частности, документ может применяться при зачете поступивших средств материнского капитала в оплату по договорам платного обучения.

После заполнения реквизитов бухгалтерской операции и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида Перенос оплаты (образование) можно открыть с помощью команды Перенос оплаты (образование), размещенной в группе Образовательные услуги – Расчеты меню функций раздела Платное обучение.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Перенос оплаты (образование).

Заполнение реквизитов шапки документа

Группа реквизитов Отбор поступлений денежных средств:

  • Контрагент (кредитор) – плательщик (прочий кредитор), от которого поступил платеж, выбирается из справочника Контрагенты.
  • Договор – отбор по договору с контрагентом (кредитором), необязательно к заполнению, выбирается из справочника Договоры и иные основания возникновения обязательств.
  • За период с ... по ... – выбираются даты начала и окончания периода отбора документов поступления денежных средств.

Закладка "Расчеты"

При нажатии на кнопку Заполнить табличная часть на закладке Расчеты автоматически заполняется по документам поступления денежных средств от выбранного контрагента (кредитора) за указанный период:

  • Кредитор, договор – контрагент (кредитор) и договор, по которым учитывается кредиторская задолженность.
  • Счет учета – счет учета расчетов с кредитором (счет учета кредиторской задолженности), включая КФО, КПС.
  • Документ оплаты – документ поступления денежных средств, например, Кассовое поступление, Приходный кассовый ордер, Эквайринговая операция.
  • Валюта – валюта поступления денежных средств.
  • Оплачено – сумма поступления денежных средств.
  • Зачесть в оплату – сумма, которую нужно зачесть в оплату услуг по договору платного обучения учащегося.
  • Учащийся, факультет – учащийся выбирается из справочника Учащиеся, факультет выбирается из справочника Подразделения.
  • Плательщик, договор – плательщик за образовательные услуги выбирается из справочника Контрагенты, договор обучения выбирается из справочника Договоры и иные основания возникновения обязательств.
  • График платежей – вид расчетов и дата оплаты по графику платежей (доступно если по договору обучения ведется график платежей). Если в качестве даты оплаты указано значение "", автоматически погашаются очередные неисполненные платежи по графику платежей.
  • Расчеты – счет учета расчетов по договору платного обучения (счет учета дебиторской задолженности), автоматически заполняется счет расчетов 205.31.

Закладка "Бухгалтерская операция"

Типовая операция – выбирается из списка Типовые операции.

При выборе типовой операции Реклассификация платежей, зачет платежей в оплату услуг при проведении документа формируются следующие бухгалтерские записи:

  • Дт 0 205 00 56Х - Кт 0 205 30 56Х – реклассификация платежей, зачет платежей контрагентов (прочих кредиторов) в оплату услуг по договорам платного обучения учащихся.

При установленном флажке Переносить через счет бухгалтерские записи по реклассификации платежей формируются через промежуточный счет (304.06).
