Документ "Инвентаризационная опись расчетов по кредитам, займам (ф. 0510471)"

Документ Инвентаризационная опись расчетов по кредитам, займам (ф. 0510471) применяется инвентаризационной комиссией для отражения результатов проведения инвентаризации задолженности по выданным кредитам, займам (ссудам), находящимся на учете у учреждения, на счетах группы 207.00 "Расчеты по кредитам, займам (ссудам)".

Документ Инвентаризационная опись расчетов по кредитам, займам (ф. 0510471) формируется ответственным исполнителем бухгалтерской службы по месту проведения инвентаризации на основании документа Решение о проведении инвентаризации (ф. 0510439) и наименованию задолженности, указанному в шапке документа Инвентаризационная опись расчетов по кредитам, займам (ф. 0510471).

После заполнения и записи документа можно сформировать печатную форму Инвентаризационной описи расчетов по кредитам, займам (ссудам) (ф. 0510471).

Работа со списком документов

Список документов вида Инвентаризационная опись расчетов по кредитам, займам (ф. 0510471) можно открыть с помощью команды Инвентаризационные описи расчетов по кредитам, займам (ф. 0510471) меню функций раздела Инвентаризация.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Инвентаризационные описи расчетов по кредитам, займам (ф. 0510471).

Заполнение реквизитов шапки и подвала документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Подразделение – подразделение, выбирается из справочника Подразделения. Реквизит доступен, если включена настройка Учет по подразделениям (Раздел Главное - Настройки параметров учета - Общие настройки).

ИФО – источник финансового обеспечения, выбирается из одноименного справочника, если включена настройка Учет по ИФО (Раздел Главное - Настройки параметров учета - Общие настройки).

Для начала работы с документом необходимо предварительно в шапке документа указать Наименование задолженности путем выбора предопределенных значений: кредит; заем; ссуда.

Также в шапке следует указать Решение о проведении инвентаризации (ф. 0510439), в открывшемся окне Выбор данных из Решения с учетом изменений необходимо отметить строку, по которой следует заполнить документ описи и нажать на кнопку Выбрать строки. После этого будет автоматически заполнена закладка Комиссия составом инвентаризационной комиссии, а также реквизиты в шапке документа Инвентаризационная опись расчетов по кредитам, займам (ф. 0510471), в группе реквизитов Сведения об инвентаризации из Решения:

  • По состоянию на – дата, по состоянию на которую проводится инвентаризация, в формате "ДД.ММ.ГГГГ";
  • Номер комиссии – номер инвентаризационной комиссии/рабочей комиссии в составе инвентаризационной;
  • Список счетов – список счетов, отобранных из документа Решение о проведении инвентаризации (ф. 0510439);
  • Период проведения с/по – даты начала и окончания инвентаризации в формате "ДД.ММ.ГГГГ";
  • Место проведения – место проведения (адрес, место нахождения) инвентаризации.

Примечание. Редактирование вышеперечисленных реквизитов в документе описи не предусмотрено, так как они зафиксированы документом Решении о проведении инвентаризации (ф. 0510439), выбранном в шапке документа.

В подвале документа Инвентаризационная опись расчетов по кредитам, займам (ф. 0510471) в соответствующих реквизитах следует заполнить ответственного исполнителя бухгалтерской службы и ответственного исполнителя инвентаризационной комиссии.

До начала проведения инвентаризации ответственным лицом бухгалтерской службы формируется и подписывается простой ЭП расписка, являющаяся неотъемлемым приложением к Инвентаризационной описи расчетов по кредитам, займам (ссудам) (ф. 0510471), что к началу проведения инвентаризации все денежные средства бюджета подтверждены банковскими выписками (выписками из лицевых счетов) и документами-основаниями согласования задолженности.

Документ Расписка инвентаризации формируется нажатием на гиперссылку Создать расписку после записи документа.

При нажатии на гиперссылку откроется окно созданного документа Расписка инвентаризации, который следует сохранить и провести.

Заполнение расписки ответственным лицом бухгалтерской службы является обязательным условием для продолжения заполнения описи, поэтому только после проведения документа Расписка инвентаризации становится возможным заполнение закладок Раздел 1 и Раздел 2 документа Инвентаризационная опись расчетов по кредитам, займам (ф. 0510471).

Заполнение закладки "Раздел 1"

Раздел 1 "Сведения о кредитах, займах (ссудах) по данным бухгалтерского учета" заполняется ответственным исполнителем бухгалтерской службы на закладке Раздел 1 по кнопке Заполнить по данным бух.учета. Документ описи будет заполнен остатками по соответствующим аналитическим счетам счета 207.00 на конец предыдущего дня от даты, по состоянию на которую проводится инвентаризация, указанной в шапке документа в реквизите По состоянию на.

Например, если инвентаризация проводится перед составлением годовой отчетности за 2025 финансовый год, то реквизит По состоянию на будет заполнен датой 01.01.2026, а остатки по счетам 207.00 будут взяты на конец дня 31.12.2025.

В результате автозаполнения в табличной части закладки Раздел 1 будут заполнены реквизиты:

  • N – код строки;
  • Контрагент, идентификатор, договор – заполняются соответствующими данными по остаткам задолженности: для контрагента берется значение реквизита Наименование элемента справочника Контрагенты, для договора – Наименование элемента справочника Договоры и иные основания возникновения обязательств. Идентификатор генерируется в соответствии с пунктом 4 Методических указаний, утв. приказом Минфина России 15.04.2021 № 61н;
  • Дата исполнения – заполняется дата, в зависимости от выбранной настройки "Классификации задолженности по срокам исполнения (долгосрочная, краткосрочная, просроченная)" (Настройка параметров учета – Ведение учета). Если применяется упрощенный режим, то дата исполнения определяется, как дата исполнения договора. При этом в зависимости от настройки ведения учета для классификации дебиторской и кредиторской задолженности в упрощенном режиме она может определяться по дате поля Срок исполнения (погашения), указанной в документе Регистрация обязательств и сведений по договорам либо по значению поля Окончание в карточке Договора на закладке Свойства. Если используется основной режим, ведутся графики платежей по договорам, то дата исполнения заполнится предельной датой платежа по графику платежей, а в случае незаполнения графика - дата погашения определяется, как дата исполнения (погашения) договора в упрощенном режиме;
  • Счет, Валюта – соответствующие значения по данным учета, по остаткам на счете 207.ХХ;
  • Основной долг (в валюте, в рублях) – остатки сумм основного долга в валюте и в рублях (рублевом эквиваленте);
  • Проценты (в валюте, в рублях) – остатки сумм процентов по основному долгу в валюте и в рублях (рублевом эквиваленте);
  • Штрафы (в валюте, в рублях) – остатки сумм штрафов валюте и в рублях (рублевом эквиваленте);
  • Пени (в валюте, в рублях) – остатки сумм пеней на основной долг и на проценты в валюте и в рублях (рублевом эквиваленте);
  • Итого в рублях – общий остаток задолженности в рублях (рублевом эквиваленте).

По кнопке Расшифровать вызывается отчет Анализ задолженности.

Заполнение закладки "Раздел 2"

Раздел 2 "Сведения о кредитах, займах (ссудах) по данным инвентаризационной комиссии" заполняется ответственным исполнителем инвентаризационной комиссии. На закладке Раздел 2 по кнопке Заполнить (По данным раздела 1) таблица может быть заполнена автоматически по данным Раздела 1.

В результате автозаполнения командой Заполнить (По данным раздела 1) в табличной части закладки Раздел 2 по данным соответствующих одноименных реквизитов табличной части закладки Раздел 1 будут заполнены реквизиты: N, Контрагент, идентификатор, договор, Дата исполнения, Счет, Валюта.

Код строки – определяется автоматически и служит реквизитом для отражения в графе 1 Раздела 2 печатной формы Инвентаризационной описи расчетов по кредитам, займам (ссудам) (ф. 0510471).

Итого в рублях – указывается итоговая сумма в рублях (рублевом эквиваленте).

Реквизиты Основной долг (в валюте, в рублях, Статус, требует реклассификации, Акт сверки), Проценты (в валюте, в рублях, Статус, требует реклассификации, Акт сверки), Штрафы (в валюте, в рублях, Статус, требует реклассификации, Акт сверки), Пени (в валюте, в рублях, Статус, требует реклассификации, Акт сверки) предзаполняются соответствующими значениями граф Основной долг (в валюте, в рублях), Проценты (в валюте, в рублях), Штрафы (в валюте, в рублях), Пени (в валюте, в рублях) табличной части закладки Раздел 1 в части сумм долга в валюте и в рублях (рублевом эквиваленте).

Статус автозаполняется в зависимости от срока исполнения задолженности на дату инвентаризации (Текущая, Просроченная, Долгосрочная). Например, если на дату инвентаризации срок ее исполнения прошел, тогда автозаполнится статус "Просроченная".

Изначально вся задолженность определяется как Неподтвержденная (реквизит Показатели), т.е. сверка не проводилась, акт сверки не составлялся. Если сверка проводилась и задолженность (или ее часть) подтверждена актом сверки, ее можно указать в соответствующем реквизите Подтвержденная и заполнить реквизит Акт сверки.

Также вручную можно изменить значения реквизитов Статус, требует реклассификации. Флажок Требует реклассификации доступен для ручного редактирования при наличии возможности указания суммы просроченной задолженности. Если сумма просроченной задолженности не может быть указана или равна 0, то установить флажок нельзя. Если задолженность требуется разделить на два разных Статуса с разными суммами, можно воспользоваться командой Разбить строку.

Заключение комиссии можно написать произвольным текстом в реквизите Заключение комиссии, либо либо выбрать из справочника Заключения комиссии по инвентаризационным описям.

Для группового заполнения реквизитов можно использовать команду Заполнить (Групповое заполнение строк…).

Закладка "Комиссия"

Состав комиссии определен в документе Решение о проведении инвентаризации и изменению не подлежит. Заполняется автоматически при выборе Решения о проведении инвентаризации в соответствующем реквизите.

В таблице можно отметить отсутствующих лиц и замещающее лицо для председателя комиссии.

Примечание. В случаях если в документе Решение о проведении инвентаризации (ф. 0510439) назначены рабочие инвентаризационные комиссии, предварительно заполненные из справочника Комиссии, в котором для членов рабочих комиссий, выступающих в качестве уполномоченных лиц, установлены соответствующие статусы Уполномоченное председателем лицо, то на закладке Комиссия документа Инвентаризационная опись расчетов по кредитам, займам (ф. 0510471) в качестве подписантов заполняются только уполномоченное председателем лицо и члены этой рабочей комиссии.

Закладка "Отбор из Решения"

Содержит список счетов, которые были выбраны в окне Выбор данных из Решения с учетом изменений после выбора Решения о проведении инвентаризации в соответствующем реквизите.

При заполнении Раздела 1 по данным бухгалтерского учета остатки будут заполнены с дополнительным отбором по КФО и счетам, указанным в таблице Отбор счетов.
