Акт об оказании услуг

Документ Акт об оказании услуг предназначен для отражения в бухгалтерском учете операций по оказанию организацией услуг, выполнению работ по приносящей доход деятельности, а также услуг по функциям, возложенным государственным органом, контрагентам – юридическим или физическим лицам.

Документ позволяет оформить следующие операции:

  • реализация услуг (205, 209 – 401.10);
  • реализация бюджетных услуг, в т.ч. аренда федерального имущества не для администратора дохода (205 – 303.05).

После заполнения и записи документа можно сформировать печатную форму Акт об оказании услуг.

Также после заполнения реквизитов бухгалтерской операции и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

При проведении документа Акт об оказании услуг в программе будет отражено исполнение графика реализации по договору, для которого график реализации существует.

Работа со списком документов

Список документов вида Акт об оказании услуг можно открыть с помощью команды Акты об оказании услуг меню функций раздела Услуги, работы производство.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Акты об оказании услуг.

Заполнение реквизитов шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

  • Документ-основание – документ вида Счет на оплату. Выбирается из списка Счета на оплату.

Примечание. Если Акт об оказании услуг заполняется на основании документа вида Счет на оплату, то большинство реквизитов будут заполнены автоматически.
  • Контрагент – выбирается из справочника Контрагенты;
  • Договор – выбирается из справочника Договоры или иные основания возникновения обязательств.

Контроль – гиперссылка для вызова формы Контроль исполнения договоров с информацией об общем объеме запланированных (неисполненных) обязательств по договору, а также о сумме просроченных обязательств по договору (в т.ч. более 30 и более 90 дней просрочки).

Важно!
Гиперссылка Контроль доступна в документах поступления и реализации товаров, работ, услуг по договорам, в которых задано ведение графиков закупок (реализации).

Тип цен: ; НДС не включен в сумму – гиперссылка для вызова формы Цены в документе, позволяющей выбрать Тип цен и установить порядок отражения НДС.

Тип цены выбирается из справочника Типы цен номенклатуры. При выбранном типе цены и заданных ценах на товары (работы, услуги) в процессе заполнения табличной части цены на товары (работы, услуги) подставляются автоматически.

Примечание. Если Акт об оказании услуг заполняется на основании документа вида Счет на оплату, то Тип цены и порядок отражения НДС будут установлены в соответствии со Счетом на оплату.

Закладка "Услуги"

Реализация по ставке 0% – флаг устанавливается при отражении операций реализации услуг, облагаемых НДС по ставке 0%.

Информация об услугах вводится в табличную часть:

  • Номенклатура – наименование услуги, работы. Выбирается из справочника Номенклатура;

Примечание. Для выбора услуг удобно использовать форму подбора, которая открывается с помощью кнопки Подобрать командной панели табличной части.

Важно
Список формы подбора ограничен позициями номенклатуры, допускающими использование при заполнении данного документа.
  • Агентская услуга – признак агентской услуги. Активируется вручную. При активировании становится доступна группа реквизитов Комитент.

Примечание. Реквизит доступен только при включенном функционале Продажа товаров или услуг комитентов (принципалов) в настройках параметров учета.
  • Комитент – комитент по агентским услугам;
  • Договор комитента – договор комитента по агентским услугам.
  • Количество – количество оказанных услуг, выполненных работ;
  • Цена – стоимость за единицу оказанной услуги, выполненной работы;

Примечание. Под единицей услуги, работы понимается значение реквизита Ед. измерения, указанное в карточке услуги, работы в справочнике Номенклатура.
  • Сумма – суммарная стоимость услуги, работы по строке. Рассчитывается автоматически, может быть скорректирована вручную;

Примечание. При корректировке вручную значения в поле Сумма автоматически выполняется пересчет значения в поле Цена.
  • Ставка НДС – ставка НДС. Выбирается из списка;
  • Сумма НДС – сумма НДС. Рассчитывается автоматически;
  • Всего – итоговая сумма по строке. Рассчитывается автоматически.

Если на закладке Услуги документа установлен флажок Использовать скидки (наценки), то следует заполнить строки Цена (без скидок/наценок), Скидка (наценка). Порядок их заполнения описан для закладки Услуги, работы документа Счет на оплату.

Закладка "Бухгалтерская операция"

Типовая операция – выбирается из списка Типовые операции.

Реализация услуг (205, 209 – 401.10)

Для данной типовой операции необходимо заполнить реквизиты:

  • КФО – код финансового обеспечения. Выбирается в справочнике КФО;
  • КПС – классификационный признак счета. Выбирается в справочнике КПС;
  • КЭК – код экономической классификации. Выбирается из фрагмента справочника КЭК, содержащего только актуальные для данной операции значения КЭК.

В группе Расчеты:

  • Счет расчетов – выбирается из списка. Может принимать значения 205.00 или 209.00.
  • Зачет аванса – управляет зачетом аванса и может принимать значения: Автоматически, Не зачитывать.
  • Доп. аналитика – дополнительная аналитика, если используется.

В группе Бухгалтерский учет в реквизите Счет доходов автоматом устанавливается счет 401.10.

В группе Налоговый учет следует заполнить реквизиты Вид деятельности (НУ), Счет доходов (НУ) и Статья прочих доходов (НУ).

Реализация бюджетных услуг, в т.ч. аренда федерального имущества не для администратора дохода (205 – 303.05)

Для данной типовой операции необходимо заполнить реквизиты:

  • КФО – код финансового обеспечения. Выбирается в справочнике КФО;
  • КПС – классификационный признак счета. Выбирается в справочнике КПС;
  • Счет (Дт) – счет дебета. Выбирается из фрагмента Плана счетов ЕПСБУ;
  • Вид налога – выбирается из справочника Виды налогов и платежей;
  • Зачет аванса – управляет зачетом аванса и может принимать значения: Автоматически, Не зачитывать.

Дополнительные возможности

На основании документа Акт об оказании услуг можно ввести документы:

  • Квитанция на оплату;
  • Списание затрат по услугам;
  • Приходный кассовых ордер;
  • Счет-фактура выданный;
  • Чек ККМ;
  • Чек ККМ на передачу;
  • Сторно.
