Документ "Начисление платы за услуги дошкольного учреждения"

Документ Начисление платы за услуги дошкольного учреждения предназначен для начисления сумм родительской платы за основные и дополнительные платные услуги, которые детское учреждение оказало детям, а также для отражения начисленных сумм в бухгалтерском учете.

После заполнения и записи документа можно сформировать печатные формы Ведомость по расчетам с родителями за содержание детей в детских учреждениях и Акт об оказании услуг.

Также после заполнения реквизитов бухгалтерской операции и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Примечание. До начала работы с документом Начисление платы за услуги дошкольного учреждения следует ввести документ Табель учета посещаемости детей для периода начисления.

Работа со списком документов

Список документов вида Начисление платы за услуги дошкольного учреждения можно открыть с помощью команды Начисление платы за услуги дошкольного учреждения меню функций раздела Платное обучение.

В форме списка предусмотрен отбор по реквизитам Организация и Группа детского учреждения.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Начисление платы за услуги дошкольного учреждения.

Заполнение реквизитов шапки документа

Документ оформляется в последний день месяца и отражает фактически оказанные услуги.

По каждой услуге, оказанной детям, следует ввести отдельный документ Начисление родительской платы.

Положение переключателя Родительская плата выбирается для документа, с помощью которого будет выполнено начисление платы за основные услуги, то есть за присмотр и уход для заданной группы детского учреждения.

Положение переключателя Доп. образовательные услуги выбирается для документа, с помощью которого будет выполнено начисление платы за дополнительные образовательные услуги для заданной группы.

  • Период начисления – месяц года, за который выполняется начисление. По умолчанию автоматически подставляется текущий месяц текущего года, и это значение можно отредактировать;
  • Дата – последний день месяца, указанного в реквизите Период начисления;
  • Организация – наименование детского учреждения;
  • Настройка расчета – настройка расчета родительской платы. Выбирается из справочника Настройки расчетов по родительской плате.
  • Группа ДДУ – выбирается из справочника Группы детского учреждения.
  • Направление деятельности – выбирается из справочника Направления деятельности.

Заполнение реквизитов табличной части

Для заполнения табличной части вручную можно использовать кнопку Добавить командной панели табличной части.

При нажатии на кнопку Заполнить командной панели табличной части выпадает меню с командами Заполнить и рассчитать и Заполнить и рассчитать, указав дополнительный отбор.

В результате использования команды Заполнить и рассчитать в табличной части появится список детей, отобранных в соответствии с заданными значениями реквизитов в шапке документа.

Использование команды Заполнить и рассчитать, указав дополнительный отбор позволяет при отборе детей в список учесть дополнительный отбор по реквизитам и свойствам справочников Дети и Договоры и иные основания возникновения обязательств.

В заполненной тем или иным способом таблице для каждого ребенка будут указаны договор, запланированные и фактические дни посещения, ставка оплаты и льгота, сумма по договору и размер задолженности, а также рассчитана сумма к оплате.

Если в программе был введен документ Табель учета посещаемости детей, то графа Дни посещения (к оплате) будет заполнена автоматически на основании данных документа Табель учета посещаемости детей.

Если в программе не был введен документ Табель учета посещаемости детей, то значения в графе Дни посещения (к оплате) при автозаполнении будут заданы следующим образом:

  • согласно графику работы группы детского учреждения, если в справочнике Группы по услугам детского учреждения реквизит График работы заполнен;
  • согласно производственному календарю Российской Федерации, если в справочнике Группы по услугам детского учреждения реквизит График работы не заполнен.

Сумма рассчитывается автоматически по формуле:

Сумма = (Фиксированная ставка за месяц * Количество месяцев + Переменная ставка за месяц * Количество месяцев * Дней посещения / Количество дней по графику + Ставка за день * Дней посещения) * (100 – Процент льготы) / 100)

Для просмотра формулы расчета любой суммы можно поместить курсор в интересующую строку и нажать на кнопку Показать формулу расчета командной панели табличной части.

Рассчитанную сумму можно скорректировать вручную.

Закладка "Бухгалтерская операция"

Типовая операция – выбирается из списка Типовые операции и может принимать одно значение:

Начисление родительской платы (205 – 401.10).

Для данной типовой операции необходимо заполнить реквизиты:

  • КФО – код финансового обеспечения. Выбирается из списка;
  • КПС – классификационный признак счета, по которому учитываются доходы от поступления родительской платы. Выбирается из справочника КПС;
  • КЭК – код экономической классификации доходов для счета 401.10, выбирается из фрагмента справочника КЭК.
