Документ "Принятие к учету групп объектов ОС"

Документ применяется для принятия к учету основных средств, поступивших одновременно, являющихся однотипными и имеющими одинаковую стоимость – библиотечных фондов, производственного и хозяйственного инвентаря.

Документ позволяет оформить следующие операции:

  • безвозмездное получение объектов ОС, НМА (401.10);
  • оприходование излишков основных средств, выявленных при инвентаризации;
  • прекращение договора аренды/безвозмездного пользования;
  • принятие к учету ОС в оперативном учете (Счет 21);
  • принятие к учету ОС на забалансовые счета (аренда, хранение);
  • принятие к учету ОС, поступивших в натуральной форме при возмещении ущерба, причиненного виновным лицом;
  • централизованное получение объектов ОС, НМА (304.04.310);

При оформлении любой из перечисленных бухгалтерских операций с помощью документа "Принятие к учету групп объектов ОС" регистрируются две хозяйственные операции – поступление ОС и принятие поступившего ОС к учету.
  • принятие к учету ОС, НМА по сформированной стоимости вложений.

Важно!
При оформлении данной операции с помощью документа "Принятие к учету групп объектов ОС" регистрируется только одна хозяйственная операция – принятие указанного ОС к учету. Для регистрации поступления данного ОС необходимо предварительно, до принятия к учету, оформить документ "Поступление ОС, НМА НПА".

После заполнения и записи документа можно сформировать печатную форму "Акт о приеме-передаче групп объектов основных средств (кроме зданий, сооружений) ОС-1б" (форма по ОКУД 0306031).

Также после заполнения реквизитов бухгалтерской операции и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида "Принятие к учету групп объектов ОС" можно открыть с помощью команды "Принятие к учету групп объектов ОС" панели навигации раздела "Основные средства, НМА, НПА".

Создание нового документа

Для ввода нового документа можно нажать на кнопку "Создать" командной панели списка "Принятие к учету групп объектов ОС".

Заполнение реквизитов шапки документа

В первую очередь необходимо заполнить реквизиты Организация и Дата.

Реквизит Вид поступления может принимать значения:

  • принятие к учету со счета 106 (приобретение);

Важно!
Значение Принятие к учету со счета 106 (приобретение) реквизита Вид поступления используется при оформлении только операции Принятие к учету ОС, НМА по сформированной стоимости вложений для приобретенных объектов НФА.
При этом реквизиты Первоначальная стоимость и Количество группы Первоначальная стоимость на закладке Параметры акта недоступны для заполнения вручную.
Значение реквизитов Первоначальная стоимость и Количество формируются после нажатия кнопки Рассчитать командной панели формы документа.
  • принятие к учету со счета 106 (изготовление);

Важно!
Значение Принятие к учету со счета 106 (изготовление) реквизита Вид поступления используется при оформлении только операции Принятие к учету ОС, НМА по сформированной стоимости вложений для изготовленных объектов НФА.
При этом реквизит Первоначальная стоимость на закладке Параметры акта недоступен для заполнения вручную.
Значение реквизита Первоначальная стоимость формируется после нажатия кнопки Рассчитать командной панели формы документа.
  • поступление на счет 101(102, 103), 01, 02.

Значение Поступление на счет 101 (102, 103), 01, 02 реквизита Вид поступления используется при оформлении всех операций документа, за исключением операции Принятие к учету ОС, НМА по сформированной стоимости вложений.
При этом реквизиты Первоначальная стоимость и Количество на закладке Параметры акта следует заполнить вручную.

Значения Прекращение договора аренды (25), Прекращение договора безвозмездного использования (26), Прекращение договора аренды (25) ОС в оперативном учете и Прекращение договора безвозмездного использования (26) в оперативном учете используются при оформлении операции Прекращение договора аренды/безвозмездного пользования.

Группа реквизитов Организация-сдатчик:

  • Контрагент – выбирается из справочника Контрагенты.
  • Р/счет – расчетный счет контрагента. Выбирается в справочнике Банковские и казначейские счета.

Группа реквизитов Организация-получатель:

  • Л/счет – лицевой счет организации. Выбирается в справочнике Реквизиты лицевых счетов.

Заполнение реквизитов на закладке "Параметры акта"

Группа Реквизиты счета:

  • КФО – код финансового обеспечения. Выбирается в списке КФО.
  • Счет – выбирается из фрагмента рабочего плана счетов.
  • КПС – классификационный признак счета. Выбирается в списке КПС.

Группа Место хранения:

  • МОЛ/Место хранения – центр материальной ответственности. Выбирается в справочнике Центры материальной ответственности.
  • Подразделение – подразделение организации. Выбирается из справочника Подразделения.

При оформлении типовой операции Принятие к учету ОС, НМА по сформированной стоимости вложений стоимость вложений формируется на субсчетах счета 106 "Вложения в нефинансовые активы" плана счетов (ЕПСБУ).

Для расчета суммы вложений для данной типовой операции необходимо заполнить реквизиты группы Объект вложений:

  • Объект – выбирается из справочника Основные средства.
  • Счет – субсчет счета 106. Выбирается из фрагмента рабочего плана счетов, содержащего только субсчета счета 106.

Реквизиты группы Основание для составления акта и Приложение заполняются для всех типовых операций.

Заполнение реквизитов на закладке "Основное средство"

Информация об объектах ОС вводится в табличную часть:

  • "Основное средство" – выбирается из справочника "Основные средства";

Примечание. Для выбора объектов основных средств удобно использовать форму подбора, которая открывается с помощью кнопки "Подбор" командной панели табличной части.

После выбора объектов основных средств с использованием формы подбора в строках табличной части будут заполнены реквизиты:

  • "Гр. уч" – установлен флаг для признака группового учета;
  • "Инв. номер" – инвентарный номер объекта основных средств;

Примечание. Реквизит "Инв. номер" используется при учете объектов основных средств стоимостью более 3000 руб., за исключением объектов библиотечного фонда.
  • "Количество" – количество объектов ОС;
  • "Сумма" – стоимость объекта основных средств.

Для быстрого ввода информации об основном средстве в справочник "Основные средства" необходимо нажать гиперссылку "Заполнить данные об основном средстве". При этом открывается форма для ввода данных, в которой отображается только тот минимум реквизитов, которые необходимо заполнить в карточке ОС перед проведением документа. Остальные реквизиты основного средства можно заполнить позднее в справочнике "Основные средства".

Реквизиты в колонке "Переданная амортизация" заполняются при приеме основного средства, которое было ранее введено в эксплуатацию у поставщика.

При этом реквизиты "Дата ввода в эксплуатацию", "Оставшийся срок полезного использования" и "Сумма" заполняются на основании данных, содержащихся в акте поставщика.

Заполнение реквизитов на закладке "Амортизация"

В группе "Параметры амортизации" заполняются реквизиты "Срок полезного использования" и "Порядок погашения стоимости", выбирается "Способ начисления амортизации".

При вводе объекта ОС в эксплуатацию одновременно с принятием к учету следует установить флаг "Ввод в эксплуатацию одновременно с принятием к учету".

Реквизиты группы "Счет затрат":

  • "Счет" – счет учета затрат по амортизации или списанию. Выбирается из Плана счетов (ЕПСБУ);
  • "КЭК" – код экономической классификации. Подставляется автоматически после заполнения реквизита "Счет";
  • "КПС" – классификационный признак счета затрат. При необходимости заполнения выбирается из справочника "КПС";

Важно!
При незаданном "КПС" поле выбора "КПС" содержит текст "", при этом амортизация или списание балансовой стоимости ОС выполняется по "КПС", указанному для счета "101.ХХ".
Программа позволяет начислять амортизацию на "КПС", отличный от "КПС" счета учета ОС "101.ХХ". При заданном значении "КПС" амортизация или списание балансовой стоимости будут выполняться на указанный "КПС".

Доступность для заполнения реквизитов "Субконто 1", "Субконто 2" и "Субконто 3" зависит от настройки аналитического учета на счете учета затрат, указанном в реквизите "Счет".

Заполнение реквизитов на закладке "Комиссия"

Группа "Председатель комиссии" включает реквизиты "Должность", "Фамилия", "Имя" и "Отчество".

Информация о должности, фамилии, имени и отчестве каждого члена комиссии вводится в табличную часть закладки.

Примечание. Если в организации уже создана комиссия с необходимыми обязанностями, то ее можно выбрать из справочника "Постоянно действующие комиссии", который можно открыть с помощью команды "Выбрать из постоянно действующих комиссий". После выбора комиссии все реквизиты на закладке будут заполнены автоматически.

Заполнение реквизитов на закладке "Бухгалтерская операция"

"Типовая операция" – выбирается из списка "Типовые операции".
