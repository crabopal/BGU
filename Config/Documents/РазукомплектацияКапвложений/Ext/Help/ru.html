Документ «Разукомплектация капвложений»

 Документ предназначен для разукомплектации капитальных вложений, собранных на счете 106.хх по какому-то обобщенному объекту вложений, на вложения в другие объекты. Т.е. для формирования проводок:
  • Д-т 106.х1 <ОбъектЦелевой1>, К-т 106.х0 <ОбъектИсходный>
  • Д-т 106.х2 <ОбъектЦелевой2>, К-т 106.х0 <ОбъектИсходный>
  • и т. д.
 После разукомплектации капитальных вложений по целевым объектам, целевые объекты могут быть приняты к учету на счета 101.хх, 102.хх, 103.хх документами «Принятие к учету ОС, НМА, НПА» или «Решение о признании объектов ОС, НМА, НПА».

Примерный сценарий использования документа

 На счете 106.11 собираются затраты по строительству нескольких объектов. По окончании строительства, к учету должны быть приняты несколько объектов. Прежде чем принять целевые объекты к учету, капвложения, собранные на счете 106.11, следует распределить на целевые объекты по счетам 106.хх. А после распределения принять целевые объекты к учету.

Внимание!
Проводки по разукомплектации капвложений выполняются общей суммой без детализации по видам затрат, которые были собраны на исходном объекте капвложений.

Порядок работы с документом

Заполнить реквизит Объект вложений, это объект, капвложения в который подлежат разукомплектации.
Счет учета – указать счет, на котором собраны капвложения, подлежащие разукомплектации.
Вид затрат – указать служебный вид затрат, который будет подставлен в проводки Д-т 106, К-т 106 вторым субконто.
Отразить в карточке капвложений – флажок следует включить, если операцию разукоплектации капвложений в исходный объект, указанный в реквизите Объект капвложений, следует отразить в его карточке капвложений. И в реквизите Карточка капвложений, в этом случае, следует указать карточку, в которой будет отражена эта разукомплектация.
В реквизите Вариант распределения выбрать подходящий вариант, согласно которому суммы капвложений, собранные на исходном объекте, будут распределены на другие (целевые) объекты.
  • если выбран вариант «Пропорционально суммам», то в реквизите «Сумма» таблицы «Распределение капвложений по объектам» нужно будет указать общую сумму вложений, для каждого целевого объекта. При этом общая сумма вложений во все целевые объекты должна быть равна общей сумме капвложений таблицы «Капвложения»
  • если выбран вариант «Пропорционально процентам», то в реквизите «Процент %» таблицы «Распределение капвложений по объектам» нужно будет указать долю в процентах от общей суммы капвложений. Сумма всех долей, указанных в таблице «Распределение капвложений по объектам» должна быть равна 100 %.
Далее по кнопке Заполнить остатки заполнить таблицу Капвложения. Таблица будет заполнена остатками капвложений в разрезе аналитики счета (КФО, КПС, ЦМО, Подразделения).
Таблицу Распределение капвложений по объектам заполнить объектами, на которые будет выполнено распределение капвложений. В соответствующей графе Сумма или Процент %, в зависимости от выбранного варианта распределения, указать базу распределения.
По кнопке Заполнить реквизиты можно выполнить групповое заполнение прочих реквизитов таблицы для выделенных строк.
В колонке Карточка капвложений следует включить флажок и указать карточку капвложений, на которой будет отражена операция перевода капвложений в объект, указанный в текущей строке.
