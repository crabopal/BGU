Документ "Акт списания библиотечного фонда"

Для оформления и учета операции по списанию литературы, исключенной из библиотеки, предназначен документ Акт списания библиотечного фонда.

Документ позволяет оформить следующие операции:

  • Списание библиотечного фонда вследствие стихийных бедствий;
  • Списание библиотечного фонда по причине порчи;
  • Списание недостач библиотечного фонда;
  • Списание пришедшего в негодность библиотечного фонда.

После заполнения и записи документа можно сформировать печатную форму Акт о списании исключенных объектов библиотечного фонда (форма по ОКУД 0504144).

Также после заполнения реквизитов бухгалтерской операции и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов


Список документов вида Акт списания библиотечного фонда можно открыть с помощью команды Списание библиотечного фонда меню функций раздела ОС, НМА, НПА.

Создание нового документа


Для ввода нового документа можно нажать на кнопку Создать командной панели списка Списание библиотечного фонда.

Заполнение реквизитов шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

  • МОЛ/Место хранения – центр материальной ответственности, с которого списывается библиотечный фонд.. Выбирается из справочника Центры материальной ответственности;
  • Подразделение – подразделение организации. Выбирается из справочника Подразделения;
  • КФО – код финансового обеспечения. Выбирается в списке КФО.

Закладка "Общие сведения"


По умолчанию дата списания ОС, НМА, НПА в бухгалтерском учете совпадает с датой документа Акт списания библиотечного фонда. Если необходимо задать иную дату списания, отличную от даты документа, то следует использовать команду Изменить.

Причина списания – причина списания транспорта. Выбирается из справочника Причины списания НФА.

МОЛ/Место хранения – центр материальной ответственности. Выбирается из справочника Центры материальной ответственности.

Группа реквизитов Основание для составления акта:

  • Правовое основание – правовое основание хозяйственной операции. Наименование документа: приказ, распоряжение, договор и т. д.
  • № и от – номер и дата документа-основания.

Реквизиты группы Получатель:

  • Принять на хранение – флажок, который следует установить при признании библиотечного фонда не активами. При проведении документа сформируется проводка по принятию библиотечного фонда на забалансовый счет 02.3 "ОС, не признанные активом".
  • МОЛ/Место хранения – материально ответственное лицо, отвечающее за хранение транспорта. Выбирается из справочника Центры материальной ответственности.

Закладка "Основные средства"


Информация о библиотечном фонде вводится в табличную часть.

  • Основное средство – выбирается из справочника Основные средства, НМА, НПА;

Примечание. Для выбора объектов основных средств удобно использовать форму подбора, которая открывается с помощью кнопки Подобрать командной панели табличной части.

После выбора объектов основных средств с использованием формы подбора в строках табличной части будут заполнены реквизиты:

  • Гр. уч – установлен признак группового учета для выбранного объекта ОС;
  • Инв. номер – инвентарный номер объекта основных средств;
  • КПС – классификационный признак счета. Выбирается в справочнике КПС;
  • Количество – количество объектов ОС. Для одиночных объектов ОС, имеющих инвентарный номер, значение реквизита автоматически устанавливается равным 1. Реквизит доступен для заполнения для объектов ОС, у которых не предусмотрены инвентарные номера.

Значения реквизитов Балансовая стоимость и Амортизация рассчитываются автоматически с помощью кнопки Рассчитать командной панели табличной части.

Закладка "Приложение"


На закладке Приложение можно ввести в табличную часть список книг, исключенных из библиотечного фонда. При этом для каждой книги заполняются реквизиты Автор книги и название, Количество, Цена, Сумма, Единица и Коэффициент.

Примечание. Итоги по количеству и сумме на закладке Приложение должны совпадать с итогами на закладке Основные средства.

Закладка "Комиссия"

Если в учреждении уже создана комиссия с необходимыми обязанностями, то ее можно выбрать из справочника Постоянно действующие комиссии, который можно открыть с помощью команды Выбрать из постоянно действующих комиссий.

После выбора комиссии реквизиты номер и дата Приказа о назначении комиссии, Председатель комиссии и Члены комиссии будут заполнены автоматически.

При необходимости реквизиты на закладке можно заполнить вручную. Для этого в группе реквизитов Приказ о назначении комиссии следует указать номер и дату соответствующего приказа.

Группа Председатель комиссии включает реквизиты Должность, Фамилия, Имя и Отчество.

Для заполнения реквизитов можно выбрать необходимого сотрудника из справочника Сотрудники или заполнить поля вручную.

Информация о должности, фамилии, имени и отчестве каждого члена комиссии вводится в табличную часть закладки.

Для удобного заполнения документа предназначена кнопка Подобрать, нажатие на которую позволяет вызвать форму подбора справочника Сотрудники.

В группе Сведения о проводимой инвентаризации заполняются реквизиты, необходимые для заполнения соответствующих полей печатной формы: Приказ №, дата (от), Период проведения с и по, Причина и Место проведения.

В группе реквизитов Дата подписания описи указываются даты подписания инвентаризационной описи ответственным лицом и комиссией.

Закладка "Бухгалтерская операция"


Типовая операция – выбирается из списка Типовые операции:

  • Списание библиотечного фонда вследствие стихийных бедствий;
  • Списание библиотечного фонда по причине порчи;
  • Списание недостач библиотечного фонда;
  • Списание пришедшего в негодность библиотечного фонда.

Регистрация документа


Регистрация документа Акт списания библиотечного фонда производится в журнале Документы по основным средствам.

Дополнительные возможности


На основании документа Акт списания библиотечного фонда можно ввести документ Сторно.
