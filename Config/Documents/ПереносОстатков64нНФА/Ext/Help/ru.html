Документ «Переход на применение приказа 64н (НФА)»

Документ предназначен для переноса остатков на начало 2018 года и оборотов с 01.01.2018 г. по дату перехода на применение приказа 64н от 31.03.2018 г. по счетам 101 00, 102 00, 103 00, 104 00, 105 00, 106 00, 107 00, 108 00, 21.

В документе предусмотрены следующие операции:

  • Перенос на забаланс объектов, не соответствующих критериям активов (02) – если необходимо, применяется для списания материальных ценностей, которые не соответствуют критериям активов, не признаются объектами основных средств и до принятия решения об их списании подлежат отражению на забалансовом счете 02 "Материальные ценности, принятые на хранение".
  • По остаткам ОС автоматически формируется списание балансовой стоимости и амортизации в корреспонденции со счетом переноса (401.30) и отражается поступление на счет 02.1. Обороты за 2018 г. сторнируются. По оборотам 2018 года (ОС нет в остатках по состоянию на 01.01.2018) автоматически сторнируются записи по балансовым счетам с 01.01.2018 до даты перехода, при этом поступление на счет 02.1 следует отразить дополнительно специализированным документом Принятие к учету ОС, НМА, НПА;

Важно! При проведении документа с операцией Перенос на забаланс объектов, не соответствующих критериям активов (02) необходимо учитывать следующие возможные проблемы:
- поскольку при этой операции обороты 2018 года, например, начисление амортизации, не переносятся на новые счета, а только сторнируются, могут возникнуть отрицательные остатки на счетах затрат 109.хх для начисления амортизации (по кредиту счетов затрат останется отражено закрытие 109 счета, а дебетовые обороты будут сторнированы);
- остаточная стоимость объектов ОС, не соответствующих критериям активов, но не списанных на забалансовый счет 02.1, могла быть учтена при расчете среднегодовой стоимости для расчета налога на имущество за отчетные периоды 2018 года, что потребует представить уточненные налоговые расчеты за эти же отчетные периоды (Письмо Минфина России от 02.04.2018 № 03-05-05-01/21113).

  • Перенос на счета учета имущества в концессии (101.9Х, 103.91, 106.9Х) – применяется для переноса остатков по счетам 101.10, 101.20, 101.30, 101.40, 103 11, 106.11, 106.21, 106.31, 106.13, 106.41 на счета группы 90 «Имущество в концессии»;
  • Перенос на счета учета имущества казны в концессии (108.9Х, 106.9Х) - применяется для переноса остатков по счетам 108.51, 108.52, 108.55 на счета группы 90 «Имущество в концессии»;
    Перенос со счетов учета предметов лизинга (101.4Х, 102.40, 106.4Х, 107.41) - применяется для переноса остатков по счетам 101 40, 102 40, 106.41, 106.42, 107 41 на соответствующие счета 101 00, 102 00, 106 00, 107 41.
    • Перенос выполняется по следующему правилу:

  • Перенос на счета учета сооружений (101.Х2, 21.Х2) -  применяется для переноса остатков со счетов 101 13, 101 23,101 33, 21.23, 21.33 на счета 101 12, 101 22, 101 32, 21.22, 21.32.
  • Перенос на счета учета библиотечного фонда (101.Х8) - применяется для переноса остатков со счетов 101 07 «Библиотечный фонд» на счета 101 08 «Прочие основные средства».

  • Перенос с исключенных счетов (101.18, 101.21, 101.31, 104.58, 104.59) - применяется для переноса остатков со счетов, которые упразднены в ЕПСБУ.

В подсказе операции приводится схема переноса данных – соответствие старых счетов новым.

В документе следует выбрать соответствующую операцию.

Операции следует выполнять строго в порядке их следования в списке операций документа:

  1. сначала, при необходимости, списываются ОС, которые не соответствуют критериям активов, не признаются объектами основных средств, на забалансовый счет 02;
  2. далее, при необходимости, часть объектов с разных счетов переносится на счета учета имущества в концессии;
  3. далее переносятся все объекты с устаревших счетов предметов лизинга 101 40;
  4. часть объектов с разных счетов переносится на счет 101 03 «Инвестиционная недвижимость»;
  5. затем оставшиеся на устаревших счетах сооружения, библиотечный фонд переходят на другие счета;
  6. биоресурсы переходят на новые счета;
  7. в завершение, если есть остатки на упраздненных счетах, они переносятся на действующие счета.

Следует выполнять только те операции, в которых есть необходимость. Такой порядок позволит сделать операции не пересекающимися по составу переносимых объектов.

В зависимости от вида операции в спецификацию документа отбираются конкретные объекты – кнопкой Подбор (например, по имуществу в концессии) или все объекты, по которым на соответствующих счетах есть остатки на 01.01.2018 г., а также обороты с 01.01.2018 по дату перехода, – кнопкой Заполнить.
Для операций Перенос на забаланс объектов, не соответствующих критериям активов (02),  Перенос на счета учета имущества в концессии (101.9Х, 103.91, 106.9Х) и Перенос на счета учета имущества казны в концессии (108.9Х, 106.9Х) объекты в концессии необходимо подобрать по кнопке Подбор.

Замечание. Для операции Перенос на счета учета имущества казны в концессии (108.9Х, 106.9Х) в форме списка основных средств, НМА, НПА по кнопке Подбор отражаются только объекты, в карточках которых установлен флажок Имущество казны.

Для остальных операций табличную часть документа рекомендуется заполнить по кнопке Заполнить.
Например:
- при выборе операции Перенос на счета учета библиотечного фонда (101.Х8) в спецификацию будут включены объекты по старому счету 101 37 (с датой окончания действия 31.12.2017);
- при выборе операции Перенос на счета учета биологических ресурсов (101.Х7, 21.Х7) в спецификацию будут включены объекты с типом НФА «Биологические ресурсы» - включаются остатки и обороты по счетам 101.Х8, 21.Х8.

Количество объектов, включаемых в спецификацию документа, можно ограничить отбором по ИФО, КФО, счету.

Закладка "Объекты переноса"

На закладке Объекты переноса для каждого отобранного пользователем (кнопкой Подбор) или автоматически (кнопкой Заполнить) элемента справочника Основные средства (Номенклатура – для операции Перенос со счетов учета предметов лизинга (105.4Х, 106.4Х, 107.43)) отражаются старый и новый счет учета (если для старого счета есть однозначное соответствие новому).

Если объект с групповым учетом учитывается на нескольких счетах, например: 101.33 (не введенные в эксплуатацию) и 21.33 (введенные в эксплуатацию) или по объекту в обрабатываемом периоде были операции по нескольким счетам (103.11 и 106.13), то, отобранный объект попадет в таблицу со всеми счетами, по которым были остатки, движение.

Объект может быть только в одном документе (программно контролируется).
 
Для счетов, для которых не установлено однозначное соответствие, в каждой строке следует выбрать новый счет.
Если необходимо установить один счет в нескольких строках, эти строки следует выделить, удерживая клавишу Ctrl, а затем нажать кнопку Установить новый счет и указать новый счет.
Чтобы установить новый счет во всех строках, нужно выделить все строки клавишами Ctrl + A, а затем нажать кнопку Установить новый счет и указать новый счет.

Закладка "Бухгалтерская операция"

В соответствии с Методическими указаниями по применению СГС "Основные средства" (письма Минфина России от 15.12.2017 № 02-07-07/84237, от 30.11.2017 № 02-07-07/79257) в межотчетный период перенос входящих остатков должен выполняться в корреспонденции со счетом 401 30.

Следует выбрать рабочий счет 401.30 с нулевым КПС (17 нулей) вида ГКБК (для казенных учреждений) АУ и БУ с уточнением гКБК (для бюджетных и автономных учреждений).
Для казенных учреждений необходимо использовать КПС вида ГКБК с актуальной структурой, т.е. без кода главы (дата начала действия актуального КПС должна быть 01.01.2016 и позже).

При списании остатков по 106 счету в качестве оборотного субконто "Виды затрат" подставляется значение из поля "Вид затрат (об)". Рекомендуется указать "Все затраты".

Для операции Перенос на забаланс объектов, не соответствующих критериям активов (02) объект, по которому есть остатки на 01.01.2018, на дату переноса остаков принимается к учету на забалансовом счете 02.1 в условной оценке: один объект, один рубль (п. 335 Инструкции № 157н). В этом случае в шапке документа необходимо указать Контрагента - свое учреждение выбором из справочника Контрагенты.
 

Проведение и печать документа

Если дата перехода 01.01.2018, то переносятся только остатки.
Бухгалтерские записи по переносу остатков формируются в межотчетный период (31.12.2017) в корреспонденции со счетом 401 30.
Если отражается перенос по забалансовым счетам 21, счет 401.30 не применяется.

Если дата перехода более поздняя, то переносятся и остатки (датой 31.12.2017), и обороты (датой, предшествующей дате перехода).
Бухгалтерские записи 2018 г. по старым счетам сторнируются, вместо них создаются новые записи по новым счетам, за исключением операции Перенос на забаланс объектов, не соответствующих критериям активов (02).
При операции Перенос на забаланс объектов, не соответствующих критериям активов (02) по остаткам ОС (то есть если ОС есть в остатках по состоянию на 01.01.2018), не соответствующих критериям активов, автоматически формируется списание балансовой стоимости и амортизации в корреспонденции со счетом переноса (401.30) и отражается поступление на счет 02.1 - датой переноса остатков; обороты за 2018 г. сторнируются датой перехода. По оборотам 2018 года (то есть если ОС нет в остатках по состоянию на 01.01.2018) датой перехода автоматически сторнируются записи по балансовым счетам с 01.01.2018 до даты перехода, при этом поступление на счет 02.1, если это необходимо, следует отразить дополнительно специализированным документом Принятие к учету ОС, НМА, НПА.
 
При формировании проводок по счетам 101.ХХ, 102.ХХ и 108.ХХ, одновременно формируются проводки по счетам амортизации 104.ХХ.

Если в течение 2018 г. года по одному объекту было несколько движений, например, внутреннее перемещение, начисление амортизации, модернизация, и т.п., то будут отобраны и сторнированы все старые записи, и введены аналогичные новые записи по новым счетам.

При проведении документа, кроме бухгалтерских записей, формируются записи в регистр сведений Учетные данные объекта ОС, НПА, НПА, в котором хранится счет учета.
При списании объектов на счет 02.1 движения так же формируются по регистру сведений События ОС и регистрам накопления Стоимость объектов основных средств, Стоимость объектов основных средств (по контрагентам), Амортизация объектов основных средств.

После проведения из документа можно распечатать бухгалтерские справки по переносу остатков и по переносу оборотов.
