Документ "Чек ККМ"

Документ Чек ККМ предназначен для регистрации факта реализации в розницу с использованием контрольно-кассовой техники.

Работа со списком документов

Список документов вида Чек ККМ можно открыть с помощью команды Чеки ККМ группы Розничные продажи в меню функций раздела Денежные средства.

Примечание. Для печати кассового чека необходимо, чтобы кассовая смена была открыта. Открыть кассовую смену можно с помощью кнопки Открыть кассовую смену в форме Управление фискальным устройством, вызвать которую можно с помощью кнопки Управление фискальным устройством командной панели формы списка Чеки ККМ.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Чеки ККМ, а затем выбрать в открывшемся меню команду Чек ККМ.

Дополнительные возможности

На основании документа Чек ККМ можно ввести документы:

  • Заявление на возврат по чеку ККМ;
  • Исправительный чек ККМ;
  • Чек ККМ на возврат.

Примечание. Документ Исправительный чек ККМ с видом операции Исправление чека ККМ позволяет сторнировать некорректный Чек ККМ и напечатать чек-сторно. Далее необходимо вернуться к документу-основанию, внести в него необходимые исправления, а затем провести и напечатать корректный чек.

Более подробно с особенностями работы с документом Чек ККМ можно ознакомиться в статье "Оформление розничных продаж", опубликованной на ИТС (Бухгалтерия государственного учреждения, редакция 2 – Методика ведения учета – Учет розничных продаж).
