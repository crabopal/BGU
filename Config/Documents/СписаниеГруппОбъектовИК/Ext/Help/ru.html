Документ "Списание групп объектов имущества казны"

Для оформления и отражения в учете операций по списанию однотипных объектов ОС, НМА и НПА стоимостью до 3000 руб. в составе имущества казны за исключением библиотечного фонда используется документ Списание групп объектов ИК (Акт списания групп объектов ОС-4б).

После заполнения и записи документа можно сформировать печатную форму Акт о списании групп объектов основных средств ОС-4б (форма по ОКУД 0306033).

Также после заполнения реквизитов бухгалтерской операции и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов
Список документов вида Списание групп объектов ИК можно открыть с помощью команды Списание групп объектов ИК панели навигации раздела Имущество казны.

Создание нового документа
Для ввода нового документа можно нажать на кнопку Создать командной панели списка Списание групп объектов ИК.

Заполнение реквизитов шапки документа

В первую очередь необходимо заполнить реквизиты Организация и Дата.

  • КФО – код финансового обеспечения, равен "1" (бюджетная деятельность);
  • КПС – классификационный признак счета учета объектов ОС в составе имущества казны. Выбирается в справочнике КПС;
  • Дата списания с бухгалтерского учета – дата списания групп объектов имущества казны в бухгалтерском учете.

В группе реквизитов Основание для составления акта следует указать наименование, номер и дату первичного документа, послужившего основанием для составления Акта о списании групп объектов основных средств по форме ОС-4б.

Заполнение реквизитов на закладке "Основные средства"

Информация об объектах ОС вводится в табличную часть.

Основное средство – выбирается из справочника Основные средства. Для выбора объектов основных средств удобно использовать форму подбора, которая открывается с помощью кнопки Подбор командной панели табличной части.

После выбора объекта основных средств с использованием формы подбора в строках табличной части будут заполнены реквизиты:

  • Гр. уч. – установлен флаг для признака группового учета;
  • Счет учета – счет 108.ХХ, на котором ведется учет объектов основных средств;
  • Количество – количество объектов основных средств;
  • Баланс. стоим. 1 ед. – балансовая стоимость одного объекта ОС;
  • Бал. стоимость – балансовая стоимость всех объектов основных средств. Рассчитывается автоматически как произведение значений реквизитов Первоначальная стоимость и Количество.

В случае ошибок, допущенных в процессе оформления документа, автоматическое заполнение реквизитов Количество, Баланс. стоим. 1 ед. и Бал. стоимость может не состояться. В этом случае необходимо найти и исправить ошибки, допущенные при заполнении документа, а затем нажать на кнопку Рассчитать стоимость командной панели табличной части.

  • Амортизация – начисленная сумма амортизации, если указанное начисление имело место;
  • Причина списания – причина списания группы объектов ОС. Выбирается из справочника Причины списания НФА.

Заполнение реквизитов на закладке "Комиссия"

Группа Председатель комиссии включает реквизиты Должность, Фамилия, Имя и Отчество.

Информация о должности, фамилии, имени и отчестве каждого члена комиссии вводится в табличную часть закладки.

Примечание. Если в организации уже создана комиссия с необходимыми обязанностями, то ее можно выбрать из справочника Постоянно действующие комиссии, который можно открыть с помощью команды Выбрать из постоянно действующих комиссий. После выбора комиссии все реквизиты на закладке будут заполнены автоматически.

Заполнение реквизитов на закладке "Бухгалтерская операция"

Типовая операция – выбирается из списка Типовые операции.

Выбытие вследствие стихийных бедствий

Для данной типовой операции необходимо заполнить реквизит КПС (401.20) – классификационный признак счета для счета 401.20. Выбирается из справочника КПС.

Выбытие имущества казны

Типовая операция Выбытие имущества казны выбирается при списании недостач, выбытии реализованных или пришедших в негодность групп объектов в составе имущества казны.

Для данной типовой операции необходимо заполнить реквизит КПС (401.10) – классификационный признак счета для счета 401.10. Выбирается из справочника КПС.

Проведение документа

После заполнения реквизитов документ необходимо провести. Состав бухгалтерских проводок, сформированных при проведении документа, зависит от выбранной Типовой операции.

Проводки, формируемые для типовой операции Выбытие вследствие стихийных бедствий:

  • Дт 401.20.273 "Расходы текущего финансового года" – Кт 108.5Х.410 "НФА, составляющие казну", списание остаточной стоимости группы объектов имущества казны.

Проводки, формируемые для типовой операции Выбытие имущества казны:

  • Дт 401.10.172 "Доходы текущего финансового года" – Кт 108.5Х.410 "НФА, составляющие казну", списание остаточной стоимости группы объектов имущества казны.

Регистрация документа
