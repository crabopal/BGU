Документ "Регистрация способа распределения налога по источникам финансирования"

Документ Регистрация способа распределения налога по источникам финансирования предназначен для настройки отражения в учете расходов по транспортному налогу, земельному налогу, налогу на имущество. Предусмотрена возможность задать коэффициент распределения суммы налога по разным источникам, если оплата налога производится из разных источников.

Новая настройка применяется с даты документа Регистрация способа распределения налога по источникам финансирования. Что бы настройка вступила в действие, документ необходимо провести.

Способ распределения, указанный в документе, используется при заполнении документа Начисление имущественных налогов на основании документов Расчет транспортного налога, Расчет земельного налога, Расчет налога на имущество.

Работа со списком документов

Список документов вида Регистрация способов распределения налога по источникам финансирования можно открыть с помощью команды Регистрация способов распределения налога меню функций раздела Налоги.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Регистрация способов распределения налога по источникам финансирования.

Заполнение реквизитов шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Вид налога - вид налога, для которого выполняется регистрация способа распределения и отражения налога в учете.

Переключатель Применяется:

  • Для всех основных средств - если выбран вариант Для всех основных средств, в группе реквизитов Учетные данные объектов налогообложения доступно указание ИФО, КФО, КПС счета учета основных средств, для которых будет применяться настройка.
  • Для списка основных средств - если выбран вариант Для списка основных средств, появляется закладка Основные средства, на которой можно указать список основных средств, для которых будет применяться настройка.

Группа реквизитов Учетные данные объектов налогообложения. Доступна, если выбран вариант Для всех основных средств.

ИФО - выбирается из справочника Источники финансового обеспечения. Реквизит доступен для выбора, если включена опция Учет по ИФО. Обязателен для заполнения. Способ распределения будет применяться к суммам налога, рассчитанным по объектам налогообложения, которые учитываются на заданном ИФО.

КФО - код финансового обеспечения, выбирается из списка. Обязателен для заполнения. Способ распределения будет применяться к суммам налога, рассчитанным по объектам налогообложения, которые учитываются на заданном КФО.

КПС - классификационный признак счета. Выбирается из справочника КПС. Не обязателен к заполнению. Способ распределения будет применяться к суммам налога, рассчитанным по объектам налогообложения, которые учитываются на заданном КПС. Если не указан, применяется ко всем КПС, за исключением тех КПС, для которых другим документом Регистрация способа распределения налога по источникам финансирования задан собственный способ отражения налога в учете.

Закладка "Настройка распределения по источникам"

На закладке Настройка распределения по источникам в строках табличной части необходимо указать источники финансирования и аналитику дебета для формирования проводки по начислению имущественного налога. На основании этих данных будет заполнена табличная часть документа Начисление имущественных налогов. Если в табличной части заполнено несколько строк, сумма налога будет распределена по источникам финансирования согласно значению, указанному в поле Коэффициент.

Раздел лицевого счета - выбирается из справочника Разделы лицевых счетов. В зависимости от переключателя В шапке, В таблице может указываться в шапке документа или по каждой строке табличной части. Аналитика для принятия бюджетных, денежных обязательств.

ИФО - выбирается из справочника Источники финансового обеспечения. Реквизит доступен для выбора, если включена опция Учет по ИФО. Обязателен для заполнения. Сумма налога будет отражена по указанному ИФО.

Подразделение - выбирается из справочника Подразделения. Реквизит доступен, если включена опция Учет по подразделениям.

КФО - код финансового обеспечения, выбирается из списка. Реквизит обязателен для заполнения. Сумма налога будет отражена по указанному КФО.

КПС - классификационный признак счета. Выбирается из справочника КПС.

КЭК - код экономической классификации. Выбирается из справочника КЭК.

Отражение в учете - счет дебета и аналитика счета дебета для формирования проводок по начислению налога.

Коэффициент - коэффициент пропорции. Определяет, какая часть суммы рассчитанного налога будет отнесена по источнику финансирования, указанному в строке.

Закладка "Основные средства"

Закладка Основные средства доступна, если переключатель Применяется установлен в значение Для списка основных средств.
В строках табличной части на закладке Основные средства можно указать, к каким объектам ОС относится текущий способ распределения. При заполнении документа Начисление имущественных налогов сумма налога по таким объектам ОС будет распределена согласно заданной настройке.

Основное средство - выбирается объект из справочника Основные средства. Обязателен к заполнению, если установлен переключатель в значение Для списка основных средств.

Инвентарный номер - выбирается из справочника Инвентарные номера. Не обязателен к заполнению. Можно заполнить, если для отдельного инвентарного объекта групповой карточки основных средств необходимо задать индивидуальный способ распределения налога по источникам финансирования и отражения в учете.
