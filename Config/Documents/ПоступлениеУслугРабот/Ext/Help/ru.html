Документ "Поступление услуг, работ"

Для отражения в учете услуг и работ, выполненных сторонними организациями, предназначен документ Поступление услуг, работ.

Документ позволяет учесть затраты на полученные услуги и выполненные сторонними организациями работы различными способами:

  • в составе накладных общехозяйственных расходов и издержек обращения;
  • в составе себестоимости готовой продукции (109.60);
  • в составе фактической стоимости изготовления МЗ (106.04);
  • как вложения в ОС, НМА, НПА, права пользования НМА увеличивающие стоимость соответствующих объектов учета;
  • в составе фактической стоимости МЗ при покупке (106.04);
  • отнести на расходы будущих периодов (401.50);
  • начислить обязательства за счет резерва (401.60);
  • отнести расходы на финансовый результат (401.20).

После заполнения реквизитов, включая реквизиты бухгалтерской операции, и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Примечание. При проведении документа Поступление услуг, работ в программе будет отражено исполнение графика закупок по договору, для которого график закупок существует.

Работа со списком документов

Список документов вида Поступление услуг, работ можно открыть с помощью команды Поступление услуг, работ меню функций разделов Материальные запасы, ОС, НМА, НПА или Услуги, работы, производство.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Поступление услуг, работ.

Заполнение реквизитов шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Контрагент – поставщик НФА. Выбирается из справочника Контрагенты;

Договор – выбирается из справочника Договоры и иные основания возникновения обязательств, подчиненного справочнику Контрагенты.

Контроль – гиперссылка для вызова формы Контроль исполнения договоров с информацией об общем объеме запланированных (неисполненных) обязательств по договору, а также о сумме просроченных обязательств по договору (в т.ч. более 30 и более 90 дней просрочки).

Примечание. Гиперссылка Контроль доступна в документах поступления и реализации товаров, работ, услуг по договорам, в которых задано ведение графиков закупок (реализации).

Зачет аванса – управляет зачетом аванса и может принимать значения:

  • Автоматически:
  • По документу;
  • Не зачитывать.

НДС не включен в сумму, не принимается к вычету – гиперссылка, предназначенная для вызова диалога Цены в документе, который позволяет установить порядок отражения НДС документе.

Закладка "Услуги, работы"

Данные о количестве и стоимости услуг, работ вводятся в табличную часть:

  • Номенклатура – наименование услуги, работы. Выбирается из справочника Номенклатура. Для выбора нескольких позиций номенклатуры удобно использовать форму подбора номенклатуры, которая открывается с помощью кнопки Подобрать командной панели табличной части;
  • Единица измерения – учетная единица измерения. Если карточка номенклатуры содержит значение реквизита Единица измерения, то это значение будет автоматически подставлено в поле Единица измерения табличной части документа;
  • Количество – количество оказанных услуг, выполненных работ;
  • Сумма – стоимость указанного количества услуг, работ. Если гиперссылка в шапке документа имеет значение НДС включен в сумму, то сумму следует указывать с НДС, в противном случае – без НДС.
  • Ставка НДС – ставка налога на добавленную стоимость;
  • Сумма НДС – сумма налога на добавленную стоимость по строке;
  • Распределяется – флажок. Следует установить, если полученная услуга, выполненная работа будет использоваться в рамках как деятельности облагаемой НДС, так и деятельности, не облагаемой НДС;
  • Всего – сумма по строке с учетом налога на добавленную стоимость. Рассчитывается автоматически;
  • КФО – код вида финансового обеспечения;
  • КПС – классификационный признак счета;
  • КЭК – код экономической классификации;
  • Вид затрат – вид затрат, выбирается из справочника Виды затрат с отбором по выбранному значению КЭК.

Примечание. Для группового заполнения аналитики затрат следует выделить в табличной части несколько строк, а затем нажать на кнопку Установить аналитику затрат. Откроется форма Аналитика затрат, в которую следует ввести значения КПС, КЭК и Вид затрат, а затем подтвердить сделанный выбор кнопкой Установить в выделенных строках.

Закладка "Дополнительно"

Реквизиты группы Документ поставщика:

  • Вид документа – вид документа. Выбирается из справочника Виды первичных документов или вводится вручную произвольным текстом;
  • Номер – номер первичного документа;
  • Дата – дата первичного документа.

Группа Сведения о приемке услуг, работ используется при ЭДО с контрагентами для заполнения сведений ответной части электронного документа в случае использования формата УПД в полученном электронном документе. При установке флажка Услуги, работы приняты, появляется возможность заполнить сведения о дате приемки услуг, работ по акту и о принявшем их лице, чтобы эти сведения были внесены в подписанный электронный документ.

Закладка "Зачет аванса"

Табличная часть доступна для заполнения в случае, если реквизит Зачет аванса в шапке документа имеет значение По документу.

Для использования возможности зачета аванса по документам расчетов необходимо, чтобы в проводках по документам расчетов для счетов 206.00 были заполнены Субконто 3 Документы расчетов.

В случаях, если настройках программы задано ведение валютного учета или в настройках учетной политики учреждения задано использование упрощенной системы налогообложения, то при проведении документов расчетов Субконто 3 для счетов 206.00 будут заполняться автоматически.

Для заполнения Субконто 3 счетов 206.00 в иных случаях потребуется предварительно выполнить настройку Плана счетов (ЕПСБУ).

Для этого следует с помощью команды План счетов (ЕПСБУ) раздела Учет и отчетность открыть План счетов (ЕПСБУ), далее следует открыть карточку необходимого счета 206.00, перейти к табличной части Виды субконто счета и установить флажок в колонке Обязательный для вида субконто Документы расчетов.

Аналогичным образом, признак Обязательный следует установить для всех счетов 206.00, для которых необходимо выполнять зачет аванса по документу.

Закладка "Бухгалтерская операция"

Типовая операция – выбирается из списка Типовые операции.

Вложения в ОС, НМА, НПА

Заполнение реквизитов группы Бухгалтерский учет:

  • Счет дебета – субсчет счета 106. Выбирается из фрагмента плана счетов (ЕПСБУ), содержащего только актуальные для данной операции субсчета счета 106;
  • Объект вложений – объект НФА. Выбирается из справочника Основные средства, НМА, НПА.
  • МОЛ/Место хранения – центр материальной ответственности. Выбирается из справочника Центры материальной ответственности.
  • Счет расчетов – заполняется автоматически по аналитике затрат. При необходимости можно заполнить из открывающегося фрагмента плана счетов ЕПСБУ.

Вложения в права пользования НМА (106.60)

Реквизиты типовой операции заполняются аналогично реквизитам типовой операции Вложения в ОС, НМА, НПА.

Накладные, общехозяйственные расходы и издержки обращения

Заполнение реквизитов группы Бухгалтерский учет:

  • Счет дебета – субсчет счета 109.00. Выбирается из фрагмента плана счетов (ЕПСБУ), содержащего только актуальные для данной операции счета 109.70 или 109.80.
  • Направление деятельности – выбирается из справочника Направления деятельности.

Примечание. Значение реквизита Направление деятельности следует выбирать только в том случае, если на субсчетах 109.70 и 109 80 в Плане счетов задано ведение учета в разрезе направлений деятельности.

Отнесение расходов на финансовый результат (401.20)

Заполнение реквизитов группы Бухгалтерский учет:

  • Счет дебета – 401.20, единственное значение.

Начисление обязательств за счет резерва (401.60)

Заполнение реквизитов группы Бухгалтерский учет:

  • Счет дебета – 401.60, единственное значение.
  • Резервы и оценочные обязательства – выбирается из справочника Резервы и оценочные обязательства.

Расходы будущих периодов (401.50)
  • Счет дебета – 401.50, единственное значение.
  • Расходы будущих периодов – выбирается из справочника Расходы будущих периодов.
  • Договоры – выбирается из справочника Договоры и иные основания возникновения обязательств.

Заполнение реквизитов группы Бухгалтерский учет:

Формирование себестоимости готовой продукции (109.60)

Заполнение реквизитов группы Бухгалтерский учет:

  • Продукция, работа, услуга – выбирается из фрагмента справочника Номенклатура;
  • Направление деятельности – выбирается из справочника Направления деятельности.

Формирование фактической стоимости изготовления МЗ (106.04)

Заполнение реквизитов группы Бухгалтерский учет:

  • Счет дебета – субсчет счета 106.04. Выбирается из фрагмента плана счетов (ЕПСБУ), содержащего только актуальные для данной операции субсчета счета 106.04;
  • МЗ (продукции) – выбирается из фрагмента справочника Номенклатура;
  • МОЛ/Место хранения – центр материальной ответственности. Выбирается из справочника Центры материальной ответственности.

Формирование фактической стоимости МЗ при покупке (106.04)

Заполнение реквизитов группы Бухгалтерский учет:

  • Счет вложений в МЗ – субсчет счета 106.04. Выбирается из фрагмента плана счетов (ЕПСБУ), содержащего только актуальные для данной операции субсчета счета 106.04;
  • Партия – выбор типа данных, а затем документа поступления.
  • База распределения – выбирается из списка.
  • ЦМО – центр материальной ответственности. Выбирается из справочника Центры материальной ответственности. Если в реквизите Партия выбран документ Поступление МЗ, то можно не заполнять.

Группы реквизитов, общие для всех типовых операций

Заполнение реквизитов группы Налоговый учет:

Счет дебета – выбирается из фрагмента плана счетов (ЕПСБУ).
Расходы будущих периодов – значение выбирается из справочника Расходы будущих периодов.
Реализуемые активы – значение выбирается из справочника Номенклатура или Основные средства, НМА, НПА.

Заполнение реквизитов группы Учет НДС:

Принять НДС к вычету – флажок устанавливается при необходимости в учете НДС.
Счет учета НДС – счет учета НДС. Выбирается из фрагмента плана счетов (ЕПСБУ).
Счет НДС к распределению – выбирается из фрагмента плана счетов (ЕПСБУ).

Важно!
Реквизиты группы Учет НДС необходимо заполнять, если значение реквизита КФО отлично от 1 и операция поступления услуг, работ облагается НДС.

Заполнение реквизитов группы Денежное обязательство:

Принять денежное обязательство – установка флажка позволяет принять денежное обязательство;
Раздел л/с – раздел лицевого счета. Выбирается из справочника Разделы лицевых счетов.

Регистрация документа

Регистрация документа Поступление услуг, работ производится в списке Поступление услуг, работ.

Дополнительные возможности

На основании документа Поступление услуг, работ можно ввести документы Заявка на кассовый расход, Платежное поручение, Регистрация исполнения договоров, Сведения о денежном обязательстве, Счет-фактура выданный, Счет-фактура полученный, Сторно.
