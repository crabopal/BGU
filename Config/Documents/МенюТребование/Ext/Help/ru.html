Документ "Меню-требование"

Документ Меню-требование предназначен для расчета потребности в продуктах, контроля количества и списания продуктов питания, а также для оформления возврата неиспользованных продуктов.

Документ Меню-требование можно также использовать в качестве механизма планирования.

Так, например, документ Меню-требование позволяет ввести в программу данные, на основании которых можно рассчитать потребность в продуктах для организации питания в учреждении на длительный срок, более 1 дня.

Также документ позволяет рассчитать потребность в продуктах для организации питания в учреждении на конкретный день и составить калькуляцию стоимости питания.

Документ позволяет оформить одну бухгалтерскую операцию – Меню-требование.

Важно!
Возврат неиспользованных продуктов рассматривается в программе как частный случай списания продуктов, у которых реквизит Количество имеет отрицательное значение.

После заполнения и записи документа можно сформировать печатную форму Меню - требование на выдачу продуктов питания (форма по ОКУД 0504202).

Также после заполнения реквизитов бухгалтерской операции и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида Меню - требование на выдачу продуктов питания можно открыть с помощью команды Меню - требования меню функций разделов Услуги, работы, производство или Материальные запасы .

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Меню - требования.

Заполнение реквизитов шапки документа

Совет. До заполнения документа рекомендуется получить данные о количестве довольствующихся на плановый день по всем категориям питающихся.
Полученные данные следует сравнить с данными о количестве питающихся на закладке Плановая стоимость/количество питающихся для каждой категории довольствующихся в справочнике Категории довольствующихся.
Если изменение численности питающихся носит долговременный характер, то новые данные о количестве довольствующихся рекомендуется ввести в табличную часть Количество довольствующихся для соответствующей категории с указанием даты, начиная с которой изменение вступило в силу.
Если изменение численности питающихся носит разовый характер, то изменения в справочник Категории довольствующихся вносить не следует. В этом случае данные о новом значении количества довольствующихся будут введены непосредственно в документ Меню - требование при его заполнении.

Дата – дата, на которую выполняется планирование и списание продуктов по меню-требованию.

МОЛ/Место хранения – центр материальной ответственности, с которого будет производиться списание продуктов. Выбирается из справочника Центры материальной ответственности.

Вид операции – тумблер, который может находится в положении Списание продуктов или Возврат продуктов.

Тумблер, установленный в положение Списание продуктов, означает, что документом будет выполнено списание продуктов по меню.

Тумблер, установленный в положение Возврат продуктов, означает, что документом будет зарегистрирован возврат материально-ответственному лицу излишне выданных продуктов.

Заполнить документ можно как вручную, так и автоматически.

Если организация ведет учет рецептов и составляет меню, то большинство реквизитов на закладках Раскладка продуктов и Списание продуктов можно заполнить в автоматическом режиме.

Если организация не ведет учет рецептов и не составляет меню, а просто оформляет списание продуктов в бухгалтерском учете на основании каких-нибудь внешних данных, то реквизиты на закладках Раскладка продуктов и Списание продуктов необходимо вводить вручную.

Табличные части "Категории довольствующихся и их количество", "Меню - раскладка" и "Состав блюд" при необходимости можно редактировать.

Списание продуктов. Заполнение в автоматическом режиме

При нажатии на кнопку Заполнить документ командной панели формы Меню-требования открывается меню, которое содержит команды:

  • Заполнить меню-требование (все таблицы);
  • Заполнить категории довольствующихся;
  • Заполнить меню-раскладку по всем категориям;
  • Заполнить состав блюд по меню-раскладке;
  • Заполнить продукты к списанию по составу блюд.

Использование команды Заполнить меню-требование (все таблицы) позволяет автоматически заполнить реквизиты документа на всех закладках.

Все остальные команды меню предполагают
последовательное, поэтапное заполнение документа.

Так, например, в результате использования команды Заполнить категории довольствующихся табличная часть Категории довольствующихся и их количество будет заполнена данными о категориях и количестве питающихся, вариантах меню и очередном порядке меню для каждой категории.

Важно!
Значение реквизита Порядок меню изменяется циклически. При заполнении документа в первый раз значение реквизита Порядок меню для категории питающихся будет равно 1, что соответствует меню для первого дня. В то же время значение реквизита можно изменить на любое другое допустимое значение, то есть на такое, которое находится в диапазоне от 1 до максимального значения. Максимальное значение может быть равно, например, 7, для семидневного меню, или 10, для десятидневного и т.д. При заполнении документа в последующие дни значение реквизита будет увеличиваться на единицу каждый день, и это будет происходить до тех пор, пока не будет достигнуто максимальное значение для данной категории. После этого цикл начнется сначала, со значения реквизита равного 1.

Использовании далее команды Заполнить меню-раскладку по всем категориям довольствующихся позволяет полностью заполнить табличные части Меню-раскладка и Состав блюд на закладке Раскладка продуктов.

При установке курсора на категорию в табличной части Категории довольствующихся в табличной части Меню - раскладка в колонках Прием пищи, Блюдо, Спецификация и Выход появятся данные о дневном меню для данной категории и текущего значения реквизита Порядок меню, соответствующие варианту меню для данной категории, а также о количестве питающихся.

При нажатии на кнопку Показывать состав блюд на закладке Раскладка продуктов появится табличная часть Состав блюд, в которой содержатся данные о спецификации готового блюда, выделенного курсором в табличной части Меню - раскладка.

Табличные части Категории довольствующихся, Меню-раскладка и Состав блюд при необходимости можно редактировать. В табличную часть Категории довольствующихся можно добавить новую категорию питающихся, например, Прикомандированные сотрудники.
После этого программа предложит выбрать вариант меню для этой категории. Затем для данной категории питающихся в табличную часть Меню - раскладка можно ввести данные по приемам пищи и готовым блюдам. После использования команды Заполнить состав блюд по меню-раскладке табличная часть Состав блюда будет заполнена данными о составе блюд.

Для существующей категории, например, Дети, группа продленного дня в табличной части Меню - раскладка можно добавить новый прием пищи и новые блюда. Также в Меню - раскладка можно заменить блюда, предусмотренные вариантом меню для данной категории, на другие. Реквизиты Номенклатура и Количество табличной части Состав блюда можно также редактировать.

При добавлении готового блюда в справочнике Номенклатура доступны для выбора только элементы номенклатуры, у которых реквизит Тип номенклатуры имеет значение Готовое блюдо.

Закладка "Списание продуктов"

Для автоматического заполнения табличной части закладки Списание продуктов следует использовать команду Заполнить продукты к списанию по составу блюд.

При этом в колонке Номенклатура появятся наименования продуктов, подлежащих списанию, и программа попытается автоматически распределить эти продукты по счетам бухгалтерского учета с учетом наличия остатков на счетах.

При распределении по счетам принимаются во внимание источники средств, то есть сочетание КФО и ИФО, в рамках которых можно списать продукты для каждой категории довольствующихся.

Примечание. Источники средств, которые можно использовать при списании продуктов для категории питающихся, задаются в карточке категории довольствующихся в справочнике Категории довольствующихся.

После автоматического заполнения документа у тех продуктов, которые удалось распределить по счетам, будут заполнены все колонки табличной части, в том числе ИФО, КФО и КПС.

Для тех продуктов, распределить которые не удалось из-за отсутствия необходимых остатков на счетах, поля ИФО, КФО и КПС останутся пустыми, кроме того, в них будет присутствовать прерывистая красная линия.

Для получения информации о недостающих продуктах по текущему документу Меню-требование можно сформировать отчет Справка-расчет о недостающих продуктах с помощью кнопки Вывести остатки командной панели формы документа.

Закладка "Категории довольствующихся"

Если в справочнике Категории довольствующихся уже введены необходимые категории, то для добавления их в табличную часть следует использовать команду Заполнить категории довольствующихся.

Если в справочнике Категории довольствующихся отсутствуют необходимые категории питающихся, то для добавления их в табличную часть следует использовать кнопку Добавить командной панели табличной части.

Закладка "Списание продуктов"

Ввод данных на закладке Списание продуктов выполняется для текущей категории довольствующихся.

Текущей категорией является категория довольствующихся, на которой в настоящее время установлен курсор.

Для заполнения табличной части для текущей категории следует использовать кнопку Добавить командной панели.

При этом для каждой строки (каждого продукта питания) необходимо заполнить реквизиты:

  • Номенклатура – наименование списываемого продукта питания. Выбирается из справочника Номенклатура.
  • Счет учета – выбирается из плана счетов ЕПСБУ.
  • КФО – код финансового обеспечения. Выбирается в списке КФО.
  • КПС – классификационный признак счета. Выбирается в списке КПС.
  • Количество – количество списываемого продукта питания.

Варианты использования нескольких меню-требований в день

Как правило, ежедневно оформляется только один документ Меню-требование, который содержит все продукты питания, необходимые для приготовления блюд дневного рациона и предназначенные к списанию.

В то же время иногда возникает необходимость оформления двух и более документов вида Меню-требование. Это происходит в случае, если:

  • Продукты для списания находятся на разных складах (кладовых);
  • В течение дня появляются новые довольствующиеся, которых нужно накормить.

Для корректного отражения в учете данных ситуаций предназначены тумблер Вид меню требования, который может находится в положениях Первичное и Дополнительное, а также флажок Добавить к основному контингенту.

Заметим, что флажок Добавить к основному контингенту будет доступен только при положении тумблера Дополнительное.

Если за текущий день уже есть оформленное меню-требование, а новый оформляемый документ является вторичным меню-требованием, то тумблер следует установить в положение Дополнительное как для первого, так и для второго случая.

Если это случай списания продуктов с другого склада, то флажок Добавить к основному контингенту должен быть отключен.

В этом случае таблицы Категории довольствующихся в обоих документах должны быть одинаковы, так как продукты. выдаются одним и тем же довольствующимся, только с разных складов.

В отчеты по питанию из всех меню-требований за день будет взято максимальное количество довольствующихся по каждой категории.

Если имеет место второй случай, при котором в течение дня появляются новые довольствующиеся, то для вторичного меню-требования следует установить тумблер в положение Дополнительное и включить флажок Добавить к основному контингенту.

В этом случае в отчетах по питанию количество довольствующихся, указанное в дополнительном документе, будет суммироваться к количеством довольствующихся из первичного документа .

Возврат продуктов. Заполнение реквизитов

При оформлении возврата продуктов в шапке документа следует установить флаг Возврат продуктов.

После этого на закладке Списание продуктов в табличной части Продукты по текущей категории появятся две новые колонки – Цена и Сумма.

Заполнение реквизитов на закладках документа выполняется аналогично заполнению реквизитов вручную, рассмотренному выше.Отличие заключается в том, что в поле Количество следует вводить не положительные значения, а отрицательные.

Закладка "Подписи"

На закладке можно указать ответственных лиц, подписывающих меню-требование.

Значения реквизитов Бухгалтер, Врач, Повар и Кладовщик выбираются из справочника Сотрудники.

Печать "Меню-требования"

Чтобы распечатать меню – требование, его необходимо предварительно записать с помощью кнопки Записать командной панели формы документа.

Для формирования печатной формы документа можно нажать на кнопку Печать и выбрать в меню пункт Меню - требование.

Закладка "Бухгалтерская операция"

Реквизит Типовая операция имеет по умолчанию значение Меню-требование .

Документом формируются проводки:

В части бухгалтерского учета (БУ):

– выбытие продуктов питания на изготовление готовых блюд:

  • Дебет 0 401 20 272 (0 109 ХХ 272) Кредит 0 105 32 442

– возврат неиспользованных продуктов на склад:

  • методом "красное сторно" - Дебет 0 401 20 272 (0 109 ХХ 272) Кредит 0 105 32 442

Примечание. Предварительно корреспонденции счетов следует настроить в справочнике Категории довольствующихся.

В части налогового учета (НУ):

При проведении документа, оформленного по КФО 2, формируются проводки по налоговому учету (НУ).

Счет дебета налогового учета, на который будет списан продукт, определяется счетом дебета бухгалтерского учета.

– при списании в БУ на счета затрат по изготовлению готовой продукции, выполнения работ, услуг, на счета общехозяйственных расходов и издержек обращения (109.ХХ):

  • Дебет Н20 (Н25, Н26, Н44) Кредит Н10 (Н41, Н43)

– при списании в БУ в увеличение расходов текущего периода (401.20):

  • Дебет Н91.02 Кредит Н10 (Н41, Н43) Для этой проводки в табличной части следует заполнить реквизит Статья прочих расходов.

Дополнительные возможности

На основании документа Меню - требование можно ввести документы Меню-требование (возврат) и Сторно.
