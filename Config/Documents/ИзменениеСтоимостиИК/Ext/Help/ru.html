Документ "Изменение стоимости, амортизации ОС, НМА, НПА (Имущество казны)"

Документ Изменение стоимости, амортизации ОС, НМА, НПА (Имущество казны) предназначен:

  • для изменения стоимости, амортизации ОС, НМА и НПА, включенных в состав имущества казны в случаях, не предусмотренных другими учетными документами;
  • для изменения порядка погашения стоимости и параметров начисления амортизации: способа начисления амортизации, срока полезного использования и нормы начисления амортизации.

Документ формирует движения по регистрам:

  • регистр бухгалтерии "Журнал проводок (ЕПСБУ)";
  • регистр накопления "Стоимость объектов ОС, НМА, НПА";
  • регистр накопления "Амортизация, обесценение объектов ОС, НМА, НПА";
  • регистр сведений "Параметры амортизации ОС (бухгалтерский учет)";
  • регистр сведений "Расчет амортизации ОС".

После заполнения реквизитов бухгалтерской операции и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида Изменение стоимости, амортизации ОС, НМА, НПА (Имущество казны) можно открыть с помощью команды Изменение стоимости, амортизации ОС, НМА, НПА (Имущество казны) группы Прочие операции в меню функций раздела Имущество казны.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Изменение стоимости, амортизации ОС, НМА, НПА (Имущество казны).

Заполнение реквизитов шапки документа

Вид операции – выбирается из списка:

  • Изменение амортизации (106, 109, 401.20 – 104);
  • Изменение стоимости (108 – 106, 401.10), амортизации (106, 109, 401.20 – 104);
  • Изменение стоимости (401.10 – 108), амортизации (104 – 108);
  • Изменение стоимости (401.20 – 108), амортизации (104 – 401.20);
  • Изменение нормы амортизации.

Основание – первичный документ, являющийся основанием для изменения стоимости, амортизации, обесценения ОС, НМА, НПА. Выбирается из справочника Виды первичных документов.

Номер и Дата – номер и дата первичного документа, являющегося основанием для ввода настоящего документа.

Отбор – гиперссылка для вызова формы Настройка отбора, предназначенной для настройки отбора по реквизитам КПС, Цена, Состояние, МОЛ и т. д.

КФО – код вида финансового обеспечения, выбирается из списка.

Закладка "Основные средства"

Информация об объектах ОС вводится в табличную часть. Основное средство – выбирается из справочника Основные средства. Для выбора объектов основных средств удобно использовать форму Подбор ОС, НМА, НПА по остаткам, которая открывается с помощью кнопки Подобрать командной панели табличной части. Кнопка Заполнить позволяет заполнить табличную часть объектами ОС с отбором по организации, КФО и условиям отбора, указанным в гиперссылке Отбор.

Закладка "Бухгалтерская операция"

Для вида операции Изменение амортизации (106, 109, 401.20 – 104) применяется типовая операция Изменение амортизации.

Например, данный вид операции используется для доначисления амортизации объектам по ОС и НМА за период нахождения в составе имущества казны, если не меняется срок полезного использования.

После заполнения и проведения документа формируются записи:

  • Дт Счет учета затрат (106.хИ.340, 109.хх.271, 401.20.271), Кт Счет амортизации (104.хх.410) на сумму изменения амортизации: с положительным значением – при увеличении амортизации, с отрицательным значением – при уменьшении амортизации.

Примечание. При использовании этой операции норма амортизации не изменяется. Для изменения суммы и нормы амортизации следует использовать операцию Изменение стоимости (108 – 106, 401.10), амортизации (106, 109, 401.20 – 104).

Для вида операции Изменение стоимости (108–106, 401.10), амортизации (106, 109, 401.20 – 104) применяется типовая операция Изменение стоимости, амортизации (увеличение).

Например, данный вид операции используется:

  • для изменения кадастровой стоимости земельного участка в сторону увеличения;
  • для изменения срока полезного использования по нематериальным активам с линейной амортизацией;
  • для отражения в учете доначисления амортизации по объектам ОС и НМА до 100 % балансовой стоимости по объектам ОС (НМА), по которым способ начисления амортизации изменен на «100 % при вводе в эксплуатацию»;
  • для доначисления амортизации объектам по ОС и НМА за период нахождения в составе имущества казны, если меняется срок полезного использования.

После заполнения и проведения документа формируются записи:

  • Дт Счет учета (108.хх.310, 108.хх.320, 108.хх.330), Кт Счет-корреспондент (106.50.310 (320, 330), 401.10.100) на сумму изменения балансовой стоимости ОС, НМА, НПА имущества казны: с положительным значением – при увеличении, с отрицательным значением – при уменьшении.
  • Дт Счет учета затрат (106.50.300, 109.хх.271, 401.20.271), Кт Счет амортизации (104.хх.411(421)) на сумму изменения амортизации: с положительным значением – при увеличении, с отрицательным значением – при уменьшении.

Для вида операции Изменение стоимости (401.10 – 108), амортизации (104 – 108) применяется типовая операция Изменение стоимости, амортизации (списание). Например, данный вид операции используется для изменения кадастровой стоимости земельного участка в сторону уменьшения.

После заполнения и проведения документа формируются записи:

  • Дт Счет амортизации (104.хх.411(421)), Кт Счет учета (108.хх.410, 108.хх.420) на сумму списания балансовой стоимости за счет амортизации, приходящейся на ликвидируемую часть: с положительным значением – при уменьшении стоимости и амортизации, с отрицательным значением – при увеличении стоимости и амортизации.
  • Дт Счет-корреспондент (401.10.100), Кт Счет учета (108.хх.410, 108.хх.420, 108.хх.430) на сумму изменения остаточной (кадастровой) стоимости ОС, НМА, НПА имущества казны: с положительным значением – при уменьшении стоимости, с отрицательным значением – при увеличении стоимости.

Для вида операции Изменение стоимости (401.20 – 108), амортизации (104 – 401.20) применяется типовая операция Изменение стоимости, амортизации (передача).

После заполнения и проведения документа формируются записи:

  • Дт Счет-корреспондент (401.20.200), Кт Счет учета (108.хх.410, 108.хх.420, 108.хх.430) на сумму изменения балансовой стоимости ОС, НМА имущества казны: с положительным значением – при уменьшении, с отрицательным значением – при увеличении.
  • Дт Счет амортизации (104.хх.410, 104.хх.420), Кт Счет-корреспондент (401.20.200) на сумму изменения амортизации: с положительным значением – при уменьшении амортизации, с отрицательным значением – при увеличении амортизации.

Вид операции Изменение нормы амортизации предназначен для изменения нормы амортизации по ОС и НМА имущества казны, для которых установлен линейный способ начисления амортизации. Типовая операция у этого вида операции отсутствует.

После заполнения и проведения документа формируются записи в регистре сведений Расчет амортизации ОС с новыми параметрами для вычисления амортизации – остаточной стоимостью и оставшимся сроком полезного использования, которые действуют с месяца проведения документа. Новая запись в регистре формируется даже в том случае, если срок полезного использования и оставшийся срок полезного использования не были изменены.

Примечание. Счет учета ОС (НМА) определяется по остаткам регистра бухгалтерии.
Счет амортизации определяется по регистру сведений Соответствие счетов ОС в соответствии со счетом учета ОС, НМА, НПА.
Счет учета затрат для начисления амортизации определяется по регистру Параметры отражения затрат по амортизации.
Счета определяются по регистрам на дату документа.
