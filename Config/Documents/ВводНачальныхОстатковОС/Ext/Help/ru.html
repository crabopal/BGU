Документ "Ввод начальных остатков ОС, НМА, НПА"

Документ Ввод начальных остатков ОС, НМА, НПА предназначен для ввода начальных остатков по объектам ОС, НМА, прав пользования НМА, НПА, в том числе в составе имущества казны.

Также документ позволяет вводить и корректировать историю сведений до даты начала ведения учета в программе, то есть до даты ввода остатков или даты свертки информационной базы, для отражения в инвентарной карточке (ф. 0504031 и ф. 0504032):

  • истории изменения стоимости (модернизации, реконструкции и т.п ) и амортизации, параметров погашения стоимости;
  • истории изменения местонахождения инвентарных объектов;
  • истории капитального ремонта;
  • истории изменения наличия драгоценных материалов.

Документом Ввод начальных остатков ОС, НМА, НПА с установленным режимом ввода Налоговый учет также вводятся начальные остатки по расходам на приобретение ОС и НМА по счетам У01.хх "Расходы на приобретение основных средств (УСН)" и У04.хх "Расходы на приобретение нематериальных активов (УСН)").

Создание нового документа

Для ввода начальных остатков ОС, НМА и НПА необходимо с помощью команды Помощник ввода начальных остатков меню функций раздела Администрирование открыть форму Помощник ввода начальных остатков.

Далее следует установить курсор на строку с номером соответствующего счета на закладке Основные или Забалансовые счета, и нажать на кнопку командной панели Ввести остатки по счету.

Также документ Ввод начальных остатков ОС, НМА, НПА можно создать с помощью кнопки Создать командной панели на закладке Ввод остатков ОС. НМА, НПА.

Документ Ввод остатков ОС, НМА, НПА вводится по одному объекту ОС, НМА, НПА, который указывается в шапке документа.

При групповом учете, по инвентарным номерам или без них, на закладке Инвентарные объекты вводится информация обо всех инвентарных объектах группы. В документе объединяется информация о начальных остатках по балансовым счетам 101.00, 102.00, 103.00, 104.00, 108.00, 111.60 и забалансовым счетам 21, 25, 26 по выбранному объекту (группе объектов).

Режимы ввода данных

Документ имеет три режима ввода данных:

  • бух. учет – ввод остатков по бухгалтерскому учету;
  • налог.учет – ввод остатков по налоговому учету;
  • история – ввод (корректировка) истории сведений до даты начала ведения учета по объекту ОС, НМА, НПА в информационной базе.

Режимы ввода данных можно комбинировать:

Ввод остатков по бухгалтерскому учету производится при начале ведения учета по организации в информационной базе. Остатки вводятся на дату ввода начальных остатков, которая устанавливается индивидуально для каждой организации.

Ввод остатков по налоговому учету производится:

  • при начале ведения учета по организации в информационной базе – одновременно с остатками по бухгалтерскому учету;
  • при начале ведения налогового учета по организации, если для нее уже ведется бухгалтерский учет. Остатки вводятся только по налоговому учету на конец года, предшествующего тому, с которого в информационной базе начинается ведение учета по общей или упрощенной системе налогообложения;
  • при изменении системы налогообложения – с общей на упрощенную, или наоборот. Остатки вводятся только по налоговому учету на конец года, предшествующего тому, с которого изменилась система налогообложения.

Ввод (корректировка) истории сведений может производиться:

  • при начале ведения учета по организации в информационной базе – одновременно с остатками по бухгалтерскому учету;
  • в любой произвольный момент времени после ввода остатков по бухгалтерскому учету.

Ввод (корректировка) истории сведений

Ввод, а также корректировка истории сведений по объекту ОС, НМА, НПА до даты начала ведения учета в программе, производится в любой произвольный момент времени после ввода остатков или одновременно с вводом остатков по бухгалтерскому учету.

Документ с режимом история вводится обязательно на основании последнего документа по тому же ОС, НМА, НПА.

Документов с режимом история может быть неограниченное количество. Таким образом, документы составляют «цепочку», первым звеном которой является документ с режимом бух. учет.

Для ввода или корректировки истории сведений до даты начала ведения учета по объекту, остатки по которому были ранее введены документом Ввод начальных остатков или документами Корректировка регистров при свертке информационной базы, необходимо сначала перенести начальные остатки в документ-агрегатор Ввод остатков ОС, НМА, НПА.

Такой документ отмечается информационным сообщением Этот документ заменил все документы по выбранному основному средству, введенные на дату ввода остатков (свертки базы) на форме документа. Данный документ не подлежит редактированию и хранит записи по всем регистрам, отраженным в информационной базе ранее даты ввода остатков или свертки базы.

Для переноса движений в документ-агрегатор в новом документе Ввод остатков ОС, НМА, НПА с режимом история по гиперссылке Создать документ-агрегатор открывается помощник Объединение данных по основному средству в один документ.

Табличная часть помощника Документы автоматически заполняется документами по объекту, введенными ранее даты ввода остатков или даты свертки, указанной в реквизите Период.

Для создания документа-агрегатора следует нажать на кнопку Создать документ. При этом будет создан документ Ввод остатков ОС, НМА, НПА, который будет автоматически выбран как документ основание для корректировки истории и указан в поле Скорректировать сведения, установленные документом.

Внимание!
Операция переноса является необратимой. Информация о начальных остатках по объекту ОС, НМА, НПА удаляется из документов ввода остатков и переносится в документ Ввод остатков ОС, НМА, НПА.

Далее по кнопке ОК документ Ввод остатков ОС, НМА, НПА с режимом История заполнится данными документа-основания. В этом документе можно редактировать историю объекта.

Закладка "Общие"

На закладке Общие следует заполнить реквизиты:

  • Счет учета – счет учета ОС, НМА, НПА. Если все объекты группы стоимостью менее 10 000 руб. введены в эксплуатацию и находятся на 21 счете, все равно указывается балансовый счет, на который они были приняты к учету.
  • Номер инв. карточки – номер инвентарной карточки. Если номер не задан, то считается, что инвентарная карточка не открыта, и формироваться она не будет.
  • Состояние – состояние объекта на дату ввода остатков: Принят к учету (счета 101,102,103,108), Введен в эксплуатацию (счета 101,102,103,108), Списан при вводе в эксплуатацию (счет 21), Выбыл с учета.
  • МОЛ/Место хранения – местонахождение объекта на дату ввода остатков.
  • В пользовании – указывается, находится ли объект в пользовании: Не передавался, Передан в аренду (счет 25), Передан в безвозмездное пользование (счет 26).
  • Контрагент – контрагент, у которого объект находится в пользовании.

Группа Даты событий и Документ – даты событий принятия к учету, ввода в эксплуатацию (инд. учет), списания (инд. учет) и реквизиты первичных документов (дата, номер, наименование).

Группа Стоимость и амортизация на дату ввода начальных остатков:

  • Первоначальная – первоначальные количество, стоимость, амортизация, обесценение объекта (группы объектов) в бухгалтерском и налоговом учете.
  • Балансовая – количество, стоимость, амортизация, обесценение объекта (группы объектов) в бухгалтерском и налоговом учете на момент ввода остатков. Для объектов с индивидуальным учетом поля заполняются вручную, для группы объектов поля рассчитываются автоматически по данным таблицы Инвентарные объекты.

Примечание. Реквизит Балансовая стоимость доступен для заполнения, если в реквизите Состояние указано состояние объекта на дату ввода остатков: Принят к учету (счета 101,102,103,108) или Введен в эксплуатацию (счета 101,102,103,108).
  • При выбытии – количество, стоимость, амортизация, обесценение объекта (группы объектов) в бухгалтерском и налоговом учете на дату выбытия объектов ОС, НМА, НПА.

Примечание. Реквизит При выбытии доступен для заполнения, если в реквизите Состояние указано состояние объекта на дату ввода остатков: Списан при вводе в эксплуатацию (счет 21) или Выбыл с учета.

Группа Забалансовый учет – заполняется автоматически. Если в режиме ввода установлен признак Подробно и объект с индивидуальным учетом, то поля заполняются вручную.

Закладка "Инвентарные объекты"

Закладка Инвентарные объекты доступна, если объект ОС. НМА, НПА с групповым учетом.

Для автоматического заполнения табличной части следует использовать кнопку Заполнить командной панели.

Состав реквизитов табличной части зависит от установленного в шапке документа переключателя Инвентарный учет (с инв. номерами или без инв. номеров):

  • Объект ОС, НМА, НПА (Состояние) – инвентарный номер объекта и состояние объекта на момент ввода остатков;
  • Местонахождение – местонахождение объекта на дату ввода остатков;
  • Количество – количество объектов. Если инвентарный номер задан, то количество должно быть 1;
  • Стоимость – стоимость объектов;
  • В пользовании – указывается, находится ли объект в пользовании: Не передавался, Передан в аренду (счет 25), Передан в безвозмездное пользование (счет 26).

Если выбраны значения Передан в аренду (счет 25) или Передан в безвозмездное пользование (счет 26) дополнительно заполняются реквизиты Контрагент, Количество, Сумма и субсчет забалансового счета 25 или 26;

  • Ввод в эксплуатацию – реквизиты документа ввода в эксплуатацию: дата, номер и наименование;
  • Списание – реквизиты документа списания: дата, номер, наименование и причина выбытия.

Закладка "Амортизация"

На закладке указываются способ погашения стоимости и параметры амортизации. Закладка доступна в режимах бух. учет и история.

Если режим история не задан, то на закладке указываются: параметры амортизации, расчет месячной нормы амортизации (для метода начисления амортизации, отличного от "100% при вводе в эксплуатацию").

Если режим история задан, то эти данные вводятся в таблице Стоимость.

На закладке заполняется счет учета затрат амортизации с аналитикой.

Закладка "Налоговый учет"

Закладка доступна, если режим ввода налог. учет установлен, КФО = 2, и в учетной политике организации установлена общая система налогообложения.

На закладке указываются параметры отражения в налоговом учете.

Закладка "УСН"

Закладка доступна, если режим ввода налог. учет установлен, КФО = 2, и в учетной политике организации установлена упрощенная система налогообложения.

На закладке указываются параметры отражения в налоговом учете.

Закладка "Стоимость"

Закладка доступна в режиме история для объектов с индивидуальным учетом или с групповым учетом с инвентарными номерами. На закладке заполняется история изменения стоимости и амортизации инвентарных объектов до даты ввода начальных остатков.

По кнопке Заполнить таблица заполняется данными из таблицы Инвентарные объекты.

Реквизиты табличной части:

  • Инвентарный номер (групповой учет) – номер инвентарного объекта;
  • Событие – указывается событие, по причине которого произошло изменение стоимости (модернизация, переоценка, консервация, расконсервация, прочее). Если указано событие Принятие к учету, то колонки Дата и Документ заполняются автоматически и недоступны для редактирования;

В зависимости от указанного события в колонке Событие появляется дополнительный реквизит, где можно вводить параметры сведений о переоценке, срок консервации.

  • Дата – дата события;
  • Балансовая стоимость – балансовая стоимость на дату события;
  • Срок полезн. исп. – срок полезного использования на дату события;
  • Погашение стоимости – порядок погашения стоимости и способ начисления амортизации на дату события;
  • Амортизация – сумма начисленной амортизации и период начисления амортизации. Период должен находиться в интервале между датой текущего события и датой следующего события. В поле сумма указывается сумма амортизации, начисленная на конец периода. Даты начала и конца периода можно не указывать, в этом случае документ самостоятельно рассчитает даты периода. В поле норма можно ввести параметры вычисления нормы амортизации;
  • Обесценение – сумма начисленного обесценения;
  • Документ – указываются реквизиты документа: дата, номер, название.

Закладка "Местонахождение"

Закладка доступна в режиме история. На закладке заполняется история изменения местонахождения инвентарных объектов до даты ввода начальных остатков.

По кнопке Заполнить таблица заполняется данными из таблицы Инвентарные объекты.

Реквизиты табличной части:

  • Инвентарный номер (групповой учет) – номер инвентарного объекта;
  • Событие – событие изменения местонахождения;
  • Дата – дата события;
  • Мол/Место хранения – место хранения;
  • Документ – указываются реквизиты документа: дата, номер, название;
  • Количество (групповой учет без инв. номеров) – количество объектов в группе;
  • Сумма (групповой учет без инв. номеров) – сумма группы объектов.

Закладка "Кап. ремонт"

Закладка доступна в режиме история. На закладке заполняется история капительного ремонта инвентарных объектов до даты ввода начальных остатков:

Инвентарный номер (групповой учет) – номер инвентарного объекта;
Дата – дата капитального ремонта;
Сумма – сумма капитального ремонта;
Документ – указываются реквизиты документа: номер, название;
Гарантийный талон – указываются реквизиты гарантийного талона: дата, номер, срок действия.

Закладка "Драг. материалы"

Закладка доступна в режиме история. На закладке заполняется история изменения содержания драгоценных материалов в инвентарных объектах до даты ввода начальных остатков:

  • Инвентарный номер (групповой учет) – номер инвентарного объекта;
  • Дата – дата изменения содержания драг. материалов;
  • Драг. материал – драгоценный металл или камень. Выбирается из справочника Драгоценные материалы;
  • Ед. изм. – выбирается из справочника Классификатор единиц измерения;
  • Масса – масса драгоценного металла или камня, которая содержится в объекте;
  • Количество – количество драгоценных камней в объекте, в штуках;
  • Документ – указываются реквизиты документа основания: дата, номер, название.

Бухгалтерская операция

Реквизит Типовая операция имеет по умолчанию значение Ввод начальных остатков ОС, НМА, НПА.
