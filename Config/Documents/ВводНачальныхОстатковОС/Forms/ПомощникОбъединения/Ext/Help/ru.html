Помощник объединения

Предназначен для объединения документов ввода начальных остатков и истории по ОС, НМА, НПА в один документ Ввод остатков ОС, НМА, НПА на каждую группу объектов.

Применяется, когда необходимо исправить сведения об объектах ОС, НМА, НПА (далее ОС), которые «разбросаны» по многим документам. Например, если информационная база была свернута, сведения находятся в документах Корректировка записей регистров, их редактирование в таком виде затруднительно.

Помощник объединяет документы типов:

  • (устарел) Ввод истории амортизации ОС;
  • (устарел) Ввод истории капремонта и модернизации;
  • Ввод начальных остатков;
  • Ввод начальных остатков ОС, НМА, НПА;
  • Изменение данных ОС, НМА и НПА;
  • Изменение наличия драгоценных материалов;
  • Изменение параметров амортизации ОС и НМА;
  • Изменение состояния ОС;
  • Корректировка амортизации ОС и НМА;
  • Корректировка регистров;
  • Операция (бухгалтерская).

Помощник доступен в двух режимах:

  • Индивидуальный - для одного ОС. Открывается в этом режиме по гиперссылке Создать документ-агрегатор из формы Режим ввода остатков документа Ввод остатков ОС, НМА, НПА.
  • Групповой - для списка ОС. Открывается в этом режиме из списка документов Ввод остатков ОС, НМА, НПА по команде меню Еще / Помощник объединения (в том числе в помощнике ввода начальных остатков).

На форме доступны элементы:

Учреждение (в режиме Групповой);

Основные средства, НМА, НПА (в режиме Групповой)  -  список ОС, для которых необходимо объединить документы. По кнопке Заполнить список заполняется ОС, по которым есть остатки по счетам 101.00, 102.00, 103.00, 104.00, 108.00 (кроме 108.56), 21, 25, 26 на дату Период, а также объекты ОС, по которым в регистре сведений События ОС есть запись с событием "Принятие к учету" (позволяет учесть списанные объекты ОС);

Основное средство (в режиме Индивидуальный) – ОС, для которого необходимо объединить документы;

Период – дата ввода остатков или последней свертки базы. На эту дату выполняется поиск документов;

Документы – список документов по объекту ОС или списку объектов;

Получить документы – кнопка, по которой заполняется список документов. В список подбираются проведеные документы, у которых есть движения на дату Период;

Объединить – кнопка, по которой выполняется объединение документов по каждому объекту ОС в отдельный один новый документ Ввод остатков ОС, НМА, НПА.

 

В режиме Групповой список в списке документов могут отображаться обработанные и не обработанные документы по одному ОС (переключатель Отображать документы установлен в положение Текущего ОС) или только не обработанные документы списком по всем ОС (переключатель Отображать документы установлен в положение Всех ОС).

Состояние ОС и документов:

 

После заполнения списка документов и в процессе объединения документов, ОС и документы по ним отмечаются пиктограммами, соответствующими результатам объединения. Отсутствие пиктограммы означает, что обработка ОС и документа еще не выполнялась. Применяются следующие пиктограммы:

 - документы по ОС уже объединены. Отмечаются ОС на этапе получения документов, у которых найден один документ и этот документ типа Ввод остатков ОС, НМА, НПА;

 - документы по ОС отсутствуют. Отмечаются ОС на этапе получения документов. Так же отмечаются ОС, если в процессе объединения в документах по ОС отсутствуют проводки и движения по регистру сведений События ОС;

 - документы по ОС объединены успешно. Отмечаются ОС в процессе объединения,  для которых удалось объединить документы. Документы по таким ОС отмечаются так же;

 - документы по ОС не удалось объединить. Отмечаются ОС, документы по которым не удалось объединить. Такое может произойти, если тип документа не входит в список объединяемых типов документов (скорее всего неверно указана дата в поле Период, и в список документов попали учетные документы), или если при записи документа произошла ошибка (в этом случае можно повторить попытку объединения).

 

Если действие Заполнить, Получить документы или Объединить выполняется более 2 секунд, выполнение переходит в фоновое задание. В верхней части формы появляется панель с названием выполняемого действия и кнопкой Прервать. По этой кнопке можно прервать выполнение действия. Во время выполнения фонового задания форма помощника доступна только для просмотра.

 

Панель контроля

 

Предназначена для контроля состояния учетных данных в результате объединения движений документов.

По кнопке Движения формируется отчет по движениям подобранных основных средств. Отчет формируется в разрезе ОС и регистров. В таблицах движений регистров не выводятся колонки "Регистратор" и "Номер строки".
По кнопке Инв. карточки формируется отчет по инвентарным карточкам подобранных основных средств.

Сценарий использования:

Подберите основные средства, для которых необходимо объединить движения. Сформируйте отчеты по движениям и инвентарным карточкам и сохраните их на компьютере. Откройте помощник объединения по гиперссылке. Выполните объединение движений документов. Повторно сформируйте отчеты по движениям и инвентарным карточкам и сохраните их на компьтере. Сравните отчеты попарно до и после объединения движений. Убедитесь, что данные не изменились (если изменились, проанализируйте что изменилось).
