Документ "Формирование остатков по счетам расчетов по институциональным единицам"

С 1 января 2021 обороты по счетам расчетов по дебиторской (кредиторской) задолженности 205.00, 206.00, 208.00, 209.00, 210.03, 210.05, 210.10, 302.00, 303.00, 304.02, 304.03, 304.06, которые содержат в 24 - 26 разрядах номера счета подстатьи КОСГУ 560 "Увеличение прочей дебиторской задолженности", 730 "Увеличение прочей кредиторской задолженности", не закрываются, а формируют остатки с отражением в 26 разряде номера счета третьего разряда соответствующих подстатей КОСГУ, отражающего Классификацию институциональных единиц.

Документ Формирование остатков по счетам расчетов по институциональным единицам предназначен для формирования остатков по счетам расчетов по дебиторской (кредиторской) задолженности с отражением в 26 разряде номера счета кода по Классификации институциональных единиц.

Документ Формирование остатков по счетам расчетов по институциональным единицам вводится в последний день года.

После заполнения реквизитов и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Документы вида Формирование остатков по счетам расчетов находятся в журнале Документы закрытия года. Журнал Документы закрытия года можно открыть с помощью команды Документы закрытия года меню функций раздела Учет и отчетность.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели журнала Документы закрытия года и выбрать в списке тип документа Формирование остатков по счетам расчетов.

Заполнение реквизитов документа

Дата документа заполняется автоматически значением рабочей (текущей) даты. Для закрытия года следует указать последний день финансового года (31 декабря).

Организация – учреждение, для которого производится закрытие счетов. Выбирается из справочника Организации.

Финансовый год – окончившийся финансовый год.

Типовая операция – имеет значение Формирование остатков по счетам расчетов.

Проведение документа

При проведении документа формируются бухгалтерские записи по переносу остатков по счетам расчетов по КЭК на счета, в 26 разряде номера счета которых отражаются коды по Классификации институциональных единиц, то есть на счета с КОСГУ 001 – 009.

Внимание!
В соответствии с п. 13.6, п. 14.6 "Порядка применения классификации операций сектора государственного управления" (утвержденного Приказом Минфина России от 29.11.2017 № 209н) по счетам 205.10, 205.40, 205.81 проводки формируются по КОСГУ 560, 660 без детализации (без учета типа контрагента). Поэтому при проведении документа Формирование остатков по счетам расчетов остатки на начало года по счетам 205.10, 205.40, 205.81 формируются по КОСГУ 000.

Для каждой сформированной проводки устанавливается тип межотчетного периода Изменение валюты баланса.

Методика формирования остатков по счетам расчетов по институциональным единицам подробно описана в статье "Формирование остатков по счетам расчетов по институциональным единицам на 01.01.2021", размещенной на ИТС (Бухгалтерия государственного учреждения – Учет с 2021 г. – Переход на применение приказа Минфина России от 14.09.2020 № 198н).
