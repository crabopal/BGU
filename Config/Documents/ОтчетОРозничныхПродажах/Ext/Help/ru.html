Документ "Отчет о розничных продажах"

Предназначен для оформления результата розничной реализации за смену в неавтоматизированной торговой точке. Документ заполняется по результирующим данным кассового аппарата о сумме выручки.

После заполнения и записи документа можно сформировать печатную форму Справка отчет кассира-операциониста (форма по ОКУД 0330106) – унифицированную форму № КМ-6.
Также после заполнения реквизитов бухгалтерской операции и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида Отчет о розничных продажах можно открыть с помощью команды Отчеты о розничных продажах меню функций раздела Материальные запасы.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Отчеты о розничных продажах.

Заполнение реквизитов шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

  • МОЛ/Место хранения – неавтоматизированная торговая точка, по реализации в которой оформляется отчет. Выбирается из справочника Центры материальной ответственности;
  • Подразделение – выбирается из справочника Подразделения;
  • Контрагент – наименование контрагента, которое будет отображаться в графе Наименование покупателя книги продаж. Значение этого реквизита также будет подставляться в документ Регистрация строки книги продаж при его вводе на основании документа Отчет о розничных продажах. Рекомендуем выбирать для этого реквизита какое-либо служебное значение, например, Розница;
  • Сумма выручки – сумма выручки кассовой смены.

В группе реквизитов Первичный документ можно указать вид, номер и дату кассового документа, например, Z-отчета кассового аппарата, по данным которого оформляется документ Отчет о розничных продажах.

Закладка "Выручка"

В табличной части закладки сумму выручки следует расшифровать по ставкам и суммам НДС.

Закладка "Бухгалтерская операция"

Типовая операция – имеет значение Отчет о розничных продажах.

КФО – код финансового обеспечения, выбирается из списка;

Группа реквизитов Счет розницы:

КПС – классификационный признак счета. Выбирается в справочнике КПС.
Счет – выбирается из списка. Может принимать значения:

  • 105.Б8 "(В рознице) Товары – особо ценное движимое имущество учреждения";
  • 105.Г8 "(В рознице) Товары – иное движимое имущество учреждения".

КЭК – код экономической классификации.

В группе реквизитов группы Счет и аналитика доходов следует указать счет дохода 401.10, КПС и КЭК.

Проведение документа

При проведении документа формируются проводки по списанию розничной стоимости товаров со счета учета розницы 105.Г8:
Д-т 401.10.130, К-т 105.Г8

Примечание. Проводки по реализации наценки по проданным товарам формируются регламентным документом Расчет торговой наценки по проданным товарам в конце месяца (Д-т 401.10.130, К-т 105.39 СТОРНО наценки по реализованным товарам).

Дополнительные возможности

На основании документа Отчет о розничных продажах можно ввести документы:

  • Регистрация строки книги продаж – для начисления НДС с реализации;
  • Приходный кассовый ордер – для оприходования выручки в кассу и формированию проводки Д-т 201.34, К-т 401.10.130;
  • Сторно.
