Документ "Изменения остатков товаров в торговой точке"

Для ввода и корректировки остатков товаров в розничной торговой точке на дату начала ведения контроля остатков товаров используется документ Изменения остатков товаров в торговой точке.

Работа со списком документов

Список документов вида Изменения остатков товаров в торговой точке можно открыть с помощью команды Изменения остатков товаров в торговой точке меню функций раздела Материальные запасы.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Изменения остатков товаров в торговой точке.

Заполнение реквизитов шапки документа

Документ-основание – документы вида Акт о приемке материалов, Поступление МЗ или Требование-накладная (Материальные запасы). Выбираются из соответствующего списка.

Примечание. При использовании документа-основания реквизиты "Изменения остатков товаров в торговой точке" будут заполнены автоматически.

Вид движения – выбирается один из вариантов Поступление или Выбытие в зависимости от того, что следует отразить – ввод остатков в розничной торговой точке или их выбытие.
МОЛ/Место хранения – выбирается элемент из справочника Центры материальной ответственности, который указан на закладке в настройках кассы ККМ.

Предварительно следует настроить кассу ККМ для контроля остатков товаров. Для этого в справочнике Кассы ККМ (фискальные регистраторы) на закладке Настройки заполнения документов в группе реквизитов Контроль остатков товаров при розничных продажах следует установить флажок Вести контроль остатков товаров на складе торговой точки и указать МОЛ/Место хранения товаров.

Далее в табличной части заполняется список товаров из справочника Номенклатура и указывается их количество в розничной торговой точке.
Список товаров и их количество в розничной торговой точке на дату документа Изменения остатков товаров в торговой точке можно заполнить с помощью команды Заполнить по данным бухгалтерского учета по остаткам на счетах 105.00 по субконто ЦМО, которое указано в реквизите МОЛ/Место хранения.
После заполнения документ можно записать по кнопке Записать или провести по кнопке Провести или по кнопке Провести и Закрыть.

Дополнительные возможности

После проведения документа с помощью кнопки Движения документа можно просмотреть сформированные движения в регистре накопления Товары в торговых точках.
Также на основании документа Изменения остатков товаров в торговой точке можно ввести документ Сторно.
