Расчет базы по налогу на прибыль

Документ Расчет базы по налогу на прибыль является регламентным документом налогового учета и предназначен для формирования налоговой базы по налогу на прибыль на счете Н99 "Прибыли и убытки".

Документ следует вводить в конце каждого месяца.

Важно!
Для отражения формирования налоговой базы по налогу на прибыль казенного учреждения (КФО 1) документ Расчет базы по налогу на прибыль не применяется. Для этого применяется документ Операция (бухгалтерская) (раздел Учет и отчетность, команда меню функций Операции (бухгалтерские)), в котором следует вручную ввести бухгалтерские записи Д-т НПВ, К-т счетов Н90.01, Н90.02, Н91.01. Более подробно с особенностями налогового учета по налогу на прибыль в казенном учреждении можно ознакомиться в статье "Налоговый учет по налогу на прибыль в казенном учреждении", опубликованной на ИТС (Бухгалтерия государственного учреждения, редакция 2 – Методика ведения учета – Налоговый учет по налогу на прибыль).

Работа со списком документов

Документы вида Расчет базы по налогу на прибыль находятся в журнале Регламентные документы налогового учета, для вызова которого можно использовать команду Регламентные документы меню функций раздела Налоги.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели журнала Регламентные документы налогового учета и выбрать в списке вид документа Расчет базы по налогу на прибыль.

Работа с документом

Период – налоговый период, месяц года.

Организация – заполняется автоматически, но данное значение можно изменить.

По кнопке Заполнить документ автоматически заполняется по данным налогового учета (по налогу на прибыль):

1. Закладка Закрытие счета Н90 заполняется по оборотам счета Н90 "Доходы и расходы по обычным видам деятельности" (разница кредитового и дебетового оборота) за выбранный период (месяц).

2. Закладка Закрытие счета Н91 заполняется по оборотам счета Н91 "Прочие доходы и расходы" (разница кредитового и дебетового оборота) за выбранный период (месяц).

3. Закладка Списание убытков прошлых лет заполняется накопительным итогом с начала года с учетом положений ст. 283 НК РФ "Перенос убытков на будущее":

  • По данным о прибыли с начала года (счет Н99 "Прибыли и убытки", разница кредитового и дебетового оборота).
  • По данным об остатках несписанных убытков прошлых лет (остатки по счету Н97 "Расходы будущих периодов" по статьям расходов будущих периодов вида "Убытки прошлых лет (ст. 283 НК РФ)").


При необходимости добавления новых строк в ручном режиме следует использовать кнопку Добавить на соответствующей закладке.

Закладка "Бухгалтерская операция"

Типовая операция – имеет значение Расчет налоговой базы по налогу на прибыль.

При проведении документа Расчет базы по налогу на прибыль формируется налоговая база на счете Н99 "Прибыли и убытки" в корреспонденции со счетами:

  • Н90.09 "Прибыль / убыток от продаж" по данным закладки Закрытие счета Н90 – прибыль увеличивает налоговую базу (Дт Н90.09 Кт Н99), убыток уменьшает налоговую базу (Дт Н99 Кт Н90.09);
  • Н91.09 "Сальдо прочих доходов и расходов" по данным закладки Закрытие счета Н91 – положительное сальдо увеличивает налоговую базу (Дт Н91.09 Кт Н99), отрицательное сальдо уменьшает налоговую базу (Дт Н99 Кт Н91.09);
  • Н97 "Расходы будущих периодов" по данным закладки Списание убытков прошлых лет – суммы списанных убытков прошлых лет уменьшают налоговую базу (Дт Н99 Кт Н97), суммы восстановленных убытков прошлых лет (в случае, если суммы списанных убытков прошлых лет превышают прибыль с начала года) увеличивают налоговую базу (Дт Н99 Кт Н97, сторно).
