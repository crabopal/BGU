Дополнительные возможности

Входящее извещение

Документ Входящее извещение в зависимости от выбранного вида извещения используется для решения разных задач:

  • регистрации факта поступления извещения (ф. 0504833) после фактического получения нефинансовых активов;
  • отражения факта получения администратором кассовых поступлений сведений об ожидаемых поступлениях в бюджет;
  • отражения факта получения администратором кассовых поступлений дохода, начисленного ранее и переданного администратору кассовых поступлений исходящим извещением;
  • отражения факта получения от получателя НФА подтверждения о получении НФА;
  • отражения факта принятия к учету расчетов между головным учреждением, обособленными подразделениями (филиалами) по получению финансовых активов и/или требований;
  • отражения факта принятия к учету расчетов между головным учреждением, обособленными подразделениями (филиалами) по получению обязательств, бланков строгой отчетности, финансовых вложений и вложений в финансовые активы;
  • отражения по методу начисления показателей финансового результата расходов текущего финансового года по операциям от предоставления субсидий с условиями, если на дату формирования учреждением отчетности отсутствуют отчеты по субсидиям, а также расчеты по возврату остатков средств субсидий (по состоянию на начало финансового года, следующего за отчетным) (письмо Минфина России от 04.02.2020 № 02-06-07/6939).

После заполнения и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Документы вида Входящее извещение находятся в списке Внутриведомственные, межведомственные, межбюджетные расчеты.

Список документов Внутриведомственные, межведомственные, межбюджетные расчеты можно открыть с помощью команды Внутриведомственные, межведомственные, межбюджетные расчеты меню функций раздела Учет и отчетность.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Внутриведомственные, межведомственные, межбюджетные расчеты и выбрать Входящее извещение в форме выбора типа документа.

Заполнение реквизитов шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Реквизит Вид извещения может принимать значения:

  • Получение НФА. Применяется для регистрации факта поступления документов поставки НФА, имеющего место после фактического получения НФА. Используется при трехсторонней поставке НФА, в которой заказчик заказывает и оплачивает НФА, получатель получает НФА, а поставщик является исполнителем.
  • Начисление дохода. Применяется для регистрации факта получения администратором кассовых поступлений сведений об ожидаемых поступлениях в бюджет.
  • Получение дохода. Вид извещения Получение дохода применяется для регистрации факта получения администратором кассовых поступлений дохода, начисленного и переданного ранее администратору исходящим извещением.
  • Подтверждение получения НФА. Применяется при трехсторонней поставке НФА покупателем. Отражает факт получения от подведомственной организации подтверждения получения НФА от поставщика.
  • Получение ФА и требований. Применяется для отражения факта принятия к учету расчетов между головным учреждением, обособленными подразделениями (филиалами) по получению финансовых активов и требований.
  • Получение обязательств. Применяется для отражения факта принятия к учету расчетов между головным учреждением, обособленными подразделениями (филиалами) по получению обязательств.
  • Расчеты по МБТ, субсидиям. Применяется стороной, предоставившей целевые субсидии текущего (капитального) характера, субсидию на госзадание, межбюджетные трансферты (МБТ) с условиями, для отражения признания расходов по представлению субсидий, МБТ с условиями, а также расчетов по возврату неиспользованных средств целевой субсидии текущего (капитального) характера, субсидий на госзадание и МБТ.

Документ Входящее извещение с видами Получение БСО, Получение финансовых вложений и Получение вложений в финансовые активы применяется для подтверждения получения БСО, финансовых вложений и вложений в финансовые активы при электронном документообороте (ЭДО).

Документ Входящее извещение с видом Подтверждение расчетов по МБТ, субсидиям получает получатель бюджетных средств, получивший целевую субсидию текущего (капитального) характера, субсидию на госзадание, межбюджетные трансферты (МБТ) с условиями при электронном документообороте (ЭДО) со стороной, предоставившей целевую субсидию текущего (капитального) характера, субсидию на госзадание или МБТ.

Методика обмена извещениями (ф. 0504805) по ЭДО подробно описана в статье "Обмен извещениями (ф. 0504805), подписанными электронной подписью, через ЭДО с контрагентами в программе "1С:Бухгалтерия государственного учреждения 8" редакции 2", размещенной на ИТС (Бухгалтерия государственного учреждения, редакция 2 – Обмен электронными документами с контрагентами).

Получение НФА

Основание – документ-основание вида Поступление НФА (централизованное снабжение). Выбирается в списке, открывающемся после указания типа документа Поступление НФА (централизованное снабжение) в форме Выбор типа данных;

Примечание. После выбора документа-основания все реквизиты документа Входящее извещение, за исключением реквизитов на закладке Бухгалтерская операция, будут заполнены.

Отправитель – организация отправитель исходящего извещения. Выбирается из справочника Контрагенты.

В группе Поставщик следует заполнить реквизиты:

  • Поставщик – организация-поставщик товарно-материальных ценностей, исполнитель работ или услуг. Выбирается из справочника Контрагенты;
  • Договор – государственный (муниципальный) контракт, договор по которому осуществляется централизованная поставка. Выбирается из справочника Договоры и иные основания возникновения обязательств, подчиненного справочнику Контрагенты.

Закладка "Основные средства"

На закладке Основные средства построчно вводится информация по основным средствам, фактически полученным организацией:

  • Основное средство – полученный объект ОС. Выбирается из справочника Основные средства, НМА, НПА;
  • Количество – количество полученных объектов ОС;
  • Сумма – сумма по строке;
  • КФО – код вида финансового обеспечения. Выбирается из справочника КФО;
  • Счет учета – субсчет забалансового счета 22.1 "ОС, полученные по централизованному снабжению", выбирается автоматически.

Закладка "Материалы"

На закладке Материалы построчно вводится информация по материальным запасам, фактически полученным организацией:

  • Номенклатура – полученные материалы. Выбираются из справочника Номенклатура;
  • Количество – количество полученных материалов;
  • Сумма – сумма по строке;
  • КФО – код вида финансового обеспечения. Выбирается из справочника КФО;
  • Счет учета – субсчет забалансового счета 22.2 "МЗ, полученные по централизованному снабжению", выбирается автоматически.

Закладка "Возвратная тара"

На закладке Возвратная тара построчно вводится информация по возвратной таре, фактически полученной организацией:

  • Номенклатура – полученная возвратная тара. Выбирается из справочника Номенклатура;

  • Сумма – сумма по строке;

Закладка "Бухгалтерская операция"

Типовая операция – операция Поступление документов по ранее поступившим НФА. Выбирается из списка Типовые операции.

МОЛ/Место хранения – центр материальной ответственности организации. Выбирается из справочника Центры материальной ответственности.

При проведении входящего извещения вида Получение НФА формируются проводки по списанию НФА в кредит субсчетов забалансового счета 22 "Материальные ценности, полученные по централизованному снабжению".

На данной закладке оформляются все полученные от отправителя проводки, отражающие обязательства по будущим поступлениям в бюджет, ожидаемым администратором кассовых поступлений.

Полученный доход учитывается по дебету счета 303.05 "Расчеты по прочим платежам в бюджет".

Закладка "Бухгалтерская операция"

Закладка "Передаваемые проводки"

На данной закладке оформляются проводки по отражению признания расходов по предоставлению целевой субсидии текущего (капитального) характера, субсидии на госзадание, МБТ с условиями и расчетов по возврату неиспользованных средств субсидий и трансфертов по полученным ранее от отправителя данным.
