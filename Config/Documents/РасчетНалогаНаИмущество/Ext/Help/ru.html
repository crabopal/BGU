Документ "Расчет налога на имущество"

С 2021 года отменена обязанность по представлению налоговых расчетов по авансовым платежам по налогу на имущество за 2020 год и последующие периоды в соответствии с Федеральным законом от 15.04.2019 № 63-ФЗ. Налоговый расчет по авансовому платежу по налогу на имущество организаций утратил силу.

Документ Расчет налога на имущество предназначен для рассчета суммы налога и сумм авансовых платежей по налогу на имущество. Из документа можно сформировать печатную форму Расчет налога на имущество в разрезе налоговых органов и кодов по ОКТМО. Для расчета исходя из среднегодовой стоимости печатная форма группируется в порядке заполнения раздела 2 декларации по налогу на имущество.

При проведении документа за Отчетный период 4 квартал (налоговый период - календарный год) формируются записи в регистр сведений Расчет налога на имущество по среднегодовой стоимости.

Данные из регистра Расчет налога на имущество по среднегодовой стоимости используются при автоматическом заполнении Декларации по налогу на имущество.

Работа со списком документов

Документы вида Расчет налога на имущество можно открыть с помощью команды Расчет налога на имущество меню функций раздела Налоги.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели формы Расчет налога на имущество.

Работа с документом

Отчетный период – указывается отчетный период, за который нужно рассчитать сумму налога на имущество.

Организация – заполняется автоматически, значение можно изменить.

В документе две закладки:

  • По среднегодовой стоимости – заполняется по объектам, налоговая база для которых определяется как среднегодовая стоимость имущества, признаваемого объектом налогообложения;
  • По кадастровой стоимости – заполняется по объектам, налоговая база для которых определяется как кадастровая стоимость имущества (ст. 378.2 НК РФ).

Закладка "По среднегодовой стоимости"

Кнопка Заполнить – для заполнения данных и расчета сумм налога.

Табличная часть заполняется согласно сведений о порядке налогообложения имущества учреждения налогом на имущество, установленных в Учетной политике на закладке Налог на имущество и/или в предварительно введенных документах Регистрация порядка налогообложения имущества. Заполняется имуществом, для которого при принятии объектов к учету установлен Вид имущества - Недвижимое имущество.

  • Основное средство;
  • Инвентарный номер;
  • Налоговый орган;
  • Код по ОКТМО;
  • Код вида имущества;
  • Остаточная стоимость – по состоянию на каждый месяц отчетного (налогового) периода;
  • Средняя стоимость – рассчитывается автоматически;
  • Доля стоимости на территории субъекта РФ – только для имущества с кодом вида имущества 02;
  • Налоговая ставка;
  • Налоговая льгота;
  • Код льготы – выбирается из списка для имущества с налоговой льготой "Освобождается от налогообложения". Для имущества с установленной льготой "Облагается по сниженной ставке" используется льгота с кодом 2012400;
  • Сумма налога исчислено – колонка видна только для годового расчета (отчетный период 4 квартал). Сумма налога исчисленная по итогам налогового периода. Рассчитывается автоматически;
  • Сумма авансовых платежей – колонки первый квартал, второй квартал, третий квартал. Заполняются по данным проведенных документов Расчета налога на имущество за 1, 2, 3 квартал текущего периода. Отображаются только для годового расчета (отчетный период 4 квартал). Раздел 1 Декларации по налогу на имущество заполняется по данным колонок Сумма авансовых платежей;
  • Сумма налога к уплате – сумма налога к уплате за отчетный период. Рассчитывается автоматически.

При ручном редактировании данных в табличной части По среднегодовой стоимости пересчет суммы налога в строке автоматически не выполняется. Для расчета налога следует использовать кнопку Рассчитать.

Закладка "По кадастровой стоимости"

Кнопка Заполнить – для заполнения данных и расчета сумм налога.

Табличная часть заполняется имуществом, для которого при регистрации порядка налогообложения документом Регистрация порядка налогообложения имущества в качестве налоговой базы выбрана Кадастровая стоимость.

Примечание. Списание объекта с балансового учета не прекращает использование объекта при заполнении документа Расчет налога на имущество по кадастровой стоимости. Для прекращения использования объекта при заполнении документа необходимо оформить документ Регистрация порядка налогообложения имущества с вариантом регистрации Отмена регистрации.
  • Основное средство;
  • Инвентарный номер;
  • Налоговый орган;
  • Код по ОКТМО;
  • Код вида имущества;
  • Кадастровая стоимость;
  • Необлагаемая кадастровая стоимость;
  • Доля в праве общей собственности;
  • Доля стоимости на территории субъекта РФ;
  • Налоговая ставка;
  • Налоговая льгота;
  • Месяцев владения;
  • Сумма налога исчислено – колонка видна только для годового расчета (отчетный период 4 квартал). Сумма налога исчисленная по итогам налогового периода. Рассчитывается автоматически;
  • Сумма аванса – заполняется по данным проведенных документов Расчета налога на имущество за 1, 2, 3 квартал текущего периода. Отображаются только для годового расчета (отчетный период 4 квартал);
  • Сумма налога к уплате – сумма налога к уплате за отчетный период. Рассчитывается автоматически.

При необходимости добавления новых строк в ручном режиме следует использовать кнопку Добавить. Сумма налога рассчитывается автоматически, при редактировании данных строки.

Дополнительные возможности

На основании документа Расчет налога на имущество можно ввести документ Начисление имущественных налогов.
