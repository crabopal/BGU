Документ "Изменение параметров начисления амортизации ОС и НМА"

Изначально параметры начисления амортизации для объектов основных средств и нематериальных активов устанавливаются при принятии их к учету с использованием документов:

  • Принятие к учету ОС, НМА, НПА;
  • Перевод готовой продукции в состав ОС.

В некоторых случаях, например, при изменении учетной политики, обнаружении ошибки в установленных значениях параметров амортизации появляется потребность в их корректировке.

Для изменения параметров амортизации используется документ Изменение параметров амортизации ОС и НМА.

Работа со списком документов


Список документов вида Изменение параметров амортизации ОС можно открыть с помощью команды Изменение параметров амортизации ОС меню функций раздела ОС, НМА, НПА.

Создание нового документа


Для ввода нового документа можно нажать на кнопку Создать командной панели списка Изменение параметров амортизации ОС.

Заполнение реквизитов шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Режим – переключатель, позволяющий выбрать режим ввода данных:

  • Один объект – документ Изменение параметров амортизации ОС и НМА создан для одного объекта ОС или НМА. Информация об объекте в данном режиме вводится в поля на закладках Затраты по амортизации, Начисление амортизации и Расчет амортизации;
  • Несколько объектов – документ Изменение параметров амортизации ОС и НМА создан для нескольких объектов ОС или НМА. Информация об объектах в данном режиме вводится в табличную часть.

Отражать в бух. учете и Отражать в налог. учете – установка или снятие флажков делает возможным или, соответственно, невозможным изменение параметров амортизации в соответствующем учете.

Изменение параметров амортизации для одного объекта ОС или НМА

В шапке документа установлен режим Один объект.

Основное средство – выбирается из справочника Основные средства, НМА, НПА.

Примечание. Документ имеет три закладки: Затраты по амортизации, Начисление амортизации и Расчет амортизации. Каждая закладка содержит две группы идентичных реквизитов – Старые значения и Новые значения.

Примечание. После выбора основного средства значения реквизитов группы Старые значения на всех закладках будут соответствовать значениям, заданным ранее при принятии объекта ОС или НМА к учету или установленным в последнем для данного объекта ОС или НМА документе Изменение параметров амортизации ОС и НМА.

Закладка "Затраты по амортизации"


Реквизиты группы Новые значения на закладке Затраты по амортизации позволяют изменить для выбранного объекта ОС или НМА счет и аналитику учета затрат по амортизации.

Изменять параметры амортизации – установка флага позволяет задать новые значения для реквизитов:

  • Счет учета затрат – выбирается из фрагмента Плана счетов (ЕПСБУ);
  • КЭК – код экономической классификации. Выбирается из справочника КЭК;
  • Подразделение – выбирается из справочника Подразделения;
  • Субконто1, Субконто2 и Субконто3 – разрезы аналитического учета у выбранного Счета учета затрат.

Закладка "Начисление амортизации"


Реквизиты группы Новые значения на закладке Начисление амортизации позволяют изменить для выбранного объекта ОС или НМА порядок погашения
стоимости, способ начисления амортизации и признак начисления амортизации.

Изменять начисление амортизации и Изменять порядок погашения стоимости – установка флажков позволяет задать новые значения для реквизитов.

Порядок погашения стоимости – выбирается из списка.

Примечание. При выбранном значении Начисление амортизации для реквизита Порядок погашения стоимости становятся доступны для изменения реквизит Способ начисления амортизации.

Примечание. Снятие флага у реквизита Начислять амортизацию или Начислять амортизацию (НУ) позволяет временно отменить начисление амортизации в бухгалтерском учете и/или в налоговом учете для объекта основного средства или НМА.

Закладка "Расчет амортизации"


Реквизиты группы Новые значения на закладке Расчет амортизации позволяют изменить для выбранного объекта ОС Срок полезного использования, Срок использования для вычисления амортизации, Стоимость для вычисления амортизации, Коэффициент ускорения, Параметр выработки, Предполагаемый объем выработки, Срок полезного использования (НУ) и Специальный коэффициент (НУ).

Изменять расчет амортизации – установка флага позволяет задать для реквизитов новые значения.

Изменение параметров амортизации для нескольких объектов ОС или НМА

После установки в шапке документа режима Несколько объектов появляется и становится доступна для ввода данных табличная часть.

Закладки Затраты по амортизации, Начисление амортизации и Расчет амортизации становятся при этом недоступны.

Установка или снятие флажков Параметры амортизации, Начисление амортизации, Изменять порядок погашения стоимости и Расчет амортизации делает доступными или, соответственно, недоступными для заполнения соответствующие колонки табличной части.

Группа Отбор, в которую входят реквизиты Вид НФА, КПС, КФО и Счет учета, позволяет ограничить отбор объектов ОС и НМА в табличную часть заданными значениями реквизитов.

Для автоматического заполнения табличной части следует использовать кнопку Заполнить командной панели табличной части.

Проведение документа

При проведении документа в общем случае производится запись информации в регистры сведений:

  • Параметры отражения затрат по амортизации;
  • Параметры амортизации ОС (бухгалтерский учет);
  • Начисление амортизации ОС (налоговый учет);
  • Параметры амортизации ОС (налоговый учет);
  • Расчет амортизации ОС;
  • Специальный коэффициент для амортизации ОС (налоговый учет).

Регистрация документа


Регистрация документа Изменение параметров амортизации ОС производится в журнале Документы по основным средствам.
