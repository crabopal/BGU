Документ "Оприходование МЗ по фактической стоимости (Имущество казны)"

Документ Оприходование МЗ по фактической стоимости (Имущество казны) предназначен для принятия к учету в имущество казны материальных запасов по фактической стоимости, если приобретение или безвозмездное получение материальных запасов сопровождается дополнительными расходами на услуги по их доставке, хранению и т.д.
На основании заполненного и проведенного документа можно распечатать «Приходный ордер» (ф. 0504207) и бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида Оприходование МЗ по фактической стоимости (Имущество казны) можно открыть с помощью команды Оприходование МЗ по фактической стоимости (Имущество казны) меню функций раздела МИмущество казны.

Создание нового документа

Новый документ можно создать из документа Поступление МЗ с помощью кнопки Создать на основании – Оприходование МЗ по фактической стоимости.
Также новый документ можно ввести с помощью кнопки Создать командной панели списка Оприходование МЗ по фактической стоимости (Имущество казны).

Заполнение реквизитов шапки документа

Партии МЗ – документ, которым были сформированы проводки по оприходованию материалов на счет 106.ХП. Выбираются из списка Авансовый отчет, Ввод начальных остатков, Поступления МЗ.
МОЛ/Место хранения – центр материальной ответственности (материально ответственное лицо, место хранения), в который приходуются материалы. Выбирается из справочника Центры материальной ответственности.

Реквизит МОЛ/Место хранения доступен для заполнения только при включенном субконто Центры материальной ответственности на счете 108.56.

КПС счета 108.56 – классификационный признак счета. Выбирается из справочника.
Подразделение – выбирается из справочника Подразделения.

Закладка "Материалы"

Информация о материальных запасах имущества казны, в которые производятся вложения дополнительных расходов по их доставке, хранению и т. д., вводится в табличную часть на закладке Материалы.
Реквизиты табличной части заполняются автоматически при нажатии на кнопку Заполнить по основанию:

  • Номенклатура – наименование материала из справочника Номенклатура.
  • Количество – количество материальных запасов в партии.
  • Сумма – стоимость указанного количества материальных запасов, сформированная с учетом остатков на счете 106.ХП.
  • Счет учета материалов – полный счет учета материалов и дополнительная аналитика (при наличии). После выбора КПС счета 108.56 и нажатии кнопки Заполнить КПС учета во всех графах автоматически заполнится КПС, входящий в полный счет учета.
  • Счет вложений – полный счет учета вложений 106.2П или 106.3П.
  • Вид затрат – вид затрат.

Закладка "Бухгалтерская операция"

Предусмотрена единственная типовая операция - Принятие к учету по фактической стоимости.

Проведение документа

Для проведения документа необходимо нажать кнопку Провести или Провести и закрыть.
При проведении документа формируются следующие бухгалтерские записи:

  • Дт 0.108.56.340 – Кт 0.106.3П.340 (0.106.2П.340) (оприходование материальных запасов в состав имущества казны в сумме их фактической стоимости, сформированной при их приобретении, при безвозмездном получении).
