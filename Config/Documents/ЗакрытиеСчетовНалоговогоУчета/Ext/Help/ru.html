Документ "Закрытие счетов налогового учета"

Документ Закрытие счетов налогового учета является регламентным и применяется для закрытия счетов налогового учета в конце года.

Работа со списком документов

Документы вида Закрытие счетов налогового учета находятся в журнале Регламентные документы налогового учета, для вызова которого можно использовать команду Регламентные документы меню функций раздела Налоги.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели журнала Регламентные документы налогового учета и выбрать в списке вид документа Закрытие счетов налогового учета.

Работа с документом

При работе с документом следует заполнить реквизиты:

Дата – последний день года.

Организация – заполняется автоматически, но данное значение можно изменить.

Документ Закрытие счетов налогового учета имеет три режима работы, которые определяются значением реквизита Вид операции:

  • Закрытие года;
  • Переход на другую систему налогообложения;
  • Прочее.

Закрытие года

Режим Закрытие года применяется для закрытия счетов налогового учета в конце года.

В данном режиме выполняются следующие операции:

  • Закрываются остатки по субсчетам Н90 «Доходы и расходы по обычным видам деятельности», Н91 «Прочие доходы и расходы» (остатки в целом по счету Н90, Н91 закрываются ежемесячно регламентным документом Расчет базы по налогу на прибыль).
  • Остатки расходов на счетах Н25 «Накладные расходы производства готовой продукции, работ, услуг», Н26 «Общехозяйственные расходы», Н44 «Издержки обращения» на конец года списываются на счет Н99 «Прибыли и убытки» (при правильном ведении налогового учета остатков по счетам Н25, Н26, Н44 на конец года быть не должно, эти счета закрываются ежемесячно регламентным документом Закрытие счетов производственных затрат).
  • Списываются (без корреспонденции) остатки по вспомогательным счетам Н69 «Расчеты по социальному страхованию и обеспечению», Н70 «Расходы на оплату труда», НПВ «Поступление и выбытие имущества, работ, услуг, прав».

Операции отражаются в межотчетном периоде, в группе Технологические операции.

Переход на другую систему налогообложения

Режим Переход на другую систему налогообложения применяется при переходе на другую систему налогообложения, например, на УСН.

В этом режиме списываются остатки по всем счетам налогового учета (без корреспонденции, методом красное сторно).

Для объектов ОС и НМА на счетах Н01 «Основные средства», Н04 «Нематериальные активы» формируются движения по регистру «Первоначальные сведения ОС, НМА (налоговый учет)». В дальнейшем, для этих объектов будет доступен ввод начальных остатков по налоговому учету (если впоследствии учреждение снова вернется на общий режим налогообложения).

Прочее

Режим Прочее применяется в других случаях.

В этом режиме в форме документа следует указать список счетов налогового учета с префиксом "Н", которые необходимо закрыть.
Остатки по выбранным счетам списываются без корреспонденции, методом красное сторно.

Для заполнения табличной части следует использовать кнопку Заполнить по данным учета.

Бухгалтерская операция

Типовая операция имеет одно значение – Закрытие счетов налогового учета.
