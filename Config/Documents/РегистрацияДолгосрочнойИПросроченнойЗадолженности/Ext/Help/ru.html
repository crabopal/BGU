Документ "Регистрация долгосрочной и просроченной задолженности"

Документ предназначен для отражения данных о долгосрочной и просроченной задолженности в регистре сведений Сведения о долгосрочной и просроченной задолженности, для последующего заполнения в формах регламентированной отчетности.

Движения документа в части долгосрочной и просроченной задолженности аналогичны движениям документа Инвентаризация расчетов с контрагентами (ф. 0504089), но не требуют составления актов инвентаризации и подписей инвентаризационной комиссии.

Отражение сведений по дебиторской задолженности выполнятся по счетам, включая все субсчета указанных счетов:

  • 205.00 "Расчеты по доходам";
  • 206.00 "Расчеты по выданным авансам";
  • 207.00 "Расчеты по кредитам, займам (ссудам)";
  • 208.00 "Расчеты с подотчетными лицами";
  • 209.00 "Расчеты по ущербу и иным доходам";
  • 210.05 "Расчеты с прочими дебиторами";
  • 303.00 "Расчеты по платежам в бюджеты";
  • 04 "Сомнительная задолженность";
  • 20 "Задолженность, невостребованная кредиторами".

Отражение сведений по кредиторской задолженности выполнятся по счетам, включая все субсчета указанных счетов:

  • 205.00 "Расчеты по доходам";
  • 208.00 "Расчеты с подотчетными лицами";
  • 209.00 "Расчеты по ущербу и иным доходам";
  • 301.00 "Расчеты с кредиторами по долговым обязательствам";
  • 302.00 "Расчеты по принятым обязательствам";
  • 303.00 "Расчеты по платежам в бюджеты".

При анализе счета 304.00 "Прочие расчеты с кредиторами" во внимание принимаются остатки только на субсчетах:

  • 304.01 "Расчеты по средствам, полученным во временное распоряжение";
  • 304.02 "Расчеты с депонентами";
  • 304.03 "Расчеты по удержаниям из выплат по оплате труда";
  • 304.04 "Внутриведомственные расчеты".

Работа со списком документов

Список документов вида Регистрация долгосрочной и просроченной задолженности можно открыть с помощью команды Регистрация долгосрочной и просроченной задолженности меню функций раздела Учет и отчетность.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Регистрация долгосрочной и просроченной задолженности.

Заполнение реквизитов шапки документа

В шапке документа необходимо заполнить реквизиты Организация и Дата, указать дату в поле Сведения по состоянию на.

Переключетель Детализация расчетов с контрагентами можно устанавливать в одно из положений:

  • По контрагентам – для детализации расчетов сводно по контрагентам;
  • По договорам – для детализации расчетов по каждому договору, заключенному с контрагентами. Данный режим является предпочтительным для инвентаризации расчетов с контрагентами с заполнением показателей долгосрочной и просроченной задолженности.

Закладки "Дебиторская задолженность" и "Кредиторская задолженность"

Для заполнения табличных частей на закладках Дебиторская задолженность и Кредиторская задолженность рекомендуется использовать возможность автозаполнения по данным учета. При этом для одновременного заполнения табличных частей на обеих закладках следует использовать кнопку Заполнить по данным учета командной панели формы документа. Чтобы заполнить табличную часть на одной закладке, то есть данными или о дебиторской или о кредиторской задолженности, необходимо воспользоваться кнопкой Заполнить командной панели табличной части закладки Дебиторская задолженность (Кредиторская задолженность).

При заполнении по данным учета таблица на закладке Дебиторская задолженность (Кредиторская задолженность) будет заполнена остатками на соответствующих счетах учета. Если по какому-либо счету расчетов ведется аналитический учет в разрезе субконто Контрагенты, то поле Контрагент будет заполнено соответствующим наименованием контрагента. В то же время, если по счету не ведется учет в разрезе субконто Контрагенты, то поле Контрагент будет заполнено наименованием счета.

Для учета задолженности в разрезе дат исполнения, а также для классификации задолженности по срокам исполнения в программе предусмотрены два режима:

  • Основной режим – ведение графиков исполнения по договору (график платежей, план-график закупок, реализации) в специальных аналитических регистрах.
  • Упрощенный режим – в этом случае дата исполнения указывается:

– в карточке договора в реквизите Окончание. Для отнесения задолженности к просроченной следует также установить признак "Просрочен" – в этом случае весь остаток задолженности на счетах бухгалтерского учета (205.00, 206.00, 301.00, 302.00 и пр.) по договору будет отнесен к просроченной задолженности, если дата инвентаризации превышает дату исполнения, указанную в реквизите Окончание.
– в документах Регистрация обязательств и сведений по договорам в реквизите Срок исполнения (погашения). Начиная с указанной предельной даты исполнения, вся задолженность по договору на всех счетах расчетов будет считаться просроченной.

Примечание. Согласно пункту 3 Инструкции № 157н в случае невозможности установления конкретной даты исполнения задолженности или обязательства в аналитическом показателе "дата исполнения" отражается значение "31.12.2999", для этого реквизиты Окончание, Срок исполнения (погашения) следует вручную заполнить датой "31.12.2999".

Упрощенный режим применяется, если нет возможности применить основной режим, т.е. нет возможности произвести расчет по графикам исполнения (ведение и контроль исполнения графиков отключены, отсутствует требуемый для расчета график и т.п.). В базовой версии доступен только упрощенный режим.

Колонка Всего (справочно) заполняется общей суммой задолженности по данным регистра бухгалтерии. При проведении данные этой колонки движений не формируют, но позволяют пользователю оценить соотношение суммы общей задолженности и входящих в нее сумм долгосрочной и просроченной задолженности.

Если согласно пункту 3 Инструкции № 157н учет задолженности ведется в разрезе дат исполнения (в БГУ2 основной и упрощенный режимы), то колонки Долгосрочная и Просроченная задолженности (графы Сумма, Дата исполнения) заполняются автоматически. Если по договорам не введены графики исполнения и в карточке договора не указана дата окончания и признак "Просрочен", то колонки Долгосрочная и Просроченная задолженности (графы Сумма, Дата исполнения) не заполнятся.

В колонке Просроченная – Сумма заполняется общая сумма просроченной задолженности по договору (правовому основанию). В колонке Просроченная – Дата исполнения указывается наиболее ранняя дата возникновения просроченной задолженности – дата первого просроченного платежа (реализации, поступления) из реквизитов Оплатить до (Исполнить до), указанных в Графике платежей, План-графике реализации (закупок).

Дата возникновения задолженности в колонке Дата возникновения автоматически заполняется датой начала срока действия договора (правового основания расчетов), указанного в реквизите Срок действия документа Регистрация обязательств и сведений по договорам (группа Сроки договора (обязательства) на закладке Обязательство). Если дата начала срока действия договора не указана, дата возникновения задолженности заполняется датой договора (обязательства), указанного в реквизите Вид обязательства справочника Договоры и иные основания возникновения обязательств. При необходимости, значение в колонке Дата возникновения можно скорректировать вручную.

После автоматического заполнения колонок Долгосрочная и Просроченная значения показателей долгосрочной и просроченной задолженности, при необходимости можно скорректировать вручную.

Расшифровка расчета показателей долгосрочной и просроченной задолженности по датам исполнения в строке документа доступна по кнопке Расшифровать в командной панели табличной части. При этом будет сформирован отчет Анализ задолженности в режиме По датам исполнения либо отчет Анализ задолженности по платежам в бюджеты (для счетов 303.00).

Закладка "Настройки заполнения"

Внимание!
Если после заполнения документа в настройки отбора были внесены изменения, то документ следует перезаполнить. В противном случае данные расчетов не будут соответствовать значениям установленных отборов.

Закладка Настройки заполнения позволяет настроить отбор данных, которые попадут в документ при автозаполнении. Использование отбора позволяет уменьшить количество информации в документе и выделить отдельную область расчетов.

Помимо отбора по КФО, в документе предусмотрена также возможность отбора по счетам учета расчетов и по контрагентам.

При создании нового документа табличная часть Счета учета расчетов (включая субсчета) автоматически заполняется значениями по умолчанию. Счета для автозаполнения дебиторской и кредиторской задолженности располагаются в общем списке счетов учета расчетов в соответствующих группах. Полученный список счетов в дальнейшем можно отредактировать, удаляя существующие и добавляя новые счета. Для восстановления полного, по умолчанию, списка счетов учета расчетов предназначена кнопка Заполнить командной панели табличной части Счета учета расчетов (включая субсчета).

При создании нового документа табличная часть Контрагенты не заполнена. Это означает, что фильтр по контрагентам отключен, и, следовательно, при автозаполнении в документ будут выведены данные о кредиторской и дебиторской задолженности по всем контрагентам. Автозаполнение документа после добавления в список контрагентов позволит отобрать в документ данные по расчетам только с указанными контрагентами.

В списки счетов и контрагентов можно добавлять как отдельные элементы, то есть счета и, соответственно, контрагентов, так и группы элементов. Если в отбор добавлена группа элементов, например группа справочника Контрагенты, то при автозаполнении в документ будут добавлены расчеты по всем контрагентам, входящим в группу. То же самое относится к счетам.
