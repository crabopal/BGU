Документ "Ведомость на выдачу МЗ на нужды учреждения"

Выдача материальных ценностей в пользование для хозяйственных, научных и учебных целей, а также перемещение материальных запасов между материально ответственными лицами оформляется с помощью документа Ведомость на выдачу МЗ на нужды учреждения.

После заполнения и записи документа можно сформировать печатную форму Ведомость выдачи материальных ценностей на нужды учреждения (форма по ОКУД 0504210).

Также после заполнения реквизитов бухгалтерской операции и проведения документа можно сформировать Справку о содержании драг. материалов и бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов Ведомости на выдачу МЗ на нужды учреждения можно открыть с помощью команды Ведомости на выдачу МЗ на нужды учреждения меню функций раздела Материальные запасы.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Ведомости на выдачу МЗ на нужды учреждения.

Заполнение реквизитов шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

  • Подразделение – наименование подразделения - отправителя материальных запасов. Выбирается из справочника Подразделения;
  • МОЛ/Место хранения – центр материальной ответственности отправителя. Выбирается из справочника Центры материальной ответственности;
  • КФО – код финансового обеспечения. Выбирается в списке КФО;
  • Отразить на счете 27 – флажок, устанавливается при выдаче МЗ в личное пользование. Для отражения списания на счет 27 после установки флажка МОЛ в табличной части будут выбираться из справочника Сотрудники.
  • Документ-основание – выбирается из списка документов вида Поступление МЗ.

Закладка "Материальные запасы"
  • МОЛ получатель – центр материальной ответственности получателя. Выбирается из справочника Центры материальной ответственности. Для группового ввода значения реквизита в поля выбранных строк следует использовать кнопку Заполнить, а затем команду меню Установить получателя;
  • Номенклатура – наименование материального запаса. Выбирается из справочника Номенклатура;

Примечание. Для выбора позиций номенклатуры удобно использовать форму подбора, которая открывается с помощью кнопки Подобрать командной панели табличной части.
  • Ед. изм – единица измерения. Заполняется автоматически и соответствует значению реквизита Ед. измерения выбранного элемента номенклатуры;
  • Счет учета – счет учета МЗ;
  • КПС – классификационный признак счета. Для группового ввода значения реквизита в поля выбранных строк следует использовать кнопку Заполнить, а затем команду меню Заполнить КПС;
  • КЭК – код экономической классификации.

Примечание. При подборе номенклатуры в табличную часть документа автоматически проставляются реквизиты Счет учета, КПС и КЭК соответствующие значению реквизита Тип номенклатуры, указанному в элементе справочника Номенклатура. При необходимости КЭК можно изменить вручную.
  • Количество – количество перемещаемых номенклатурных единиц.

Закладка "Драгоценные материалы"

Примечание. Заполнение реквизитов на закладке Драгоценные материалы выполняется только для типовой операции Списание материалов. Если будет выбрана типовая операция Перемещение материальных запасов между материально ответственными лицами, то закладку Драгоценные материалы заполнять не следует!

Табличная часть, расположенная в левой части закладки, содержит список всех объектов МЗ, которые были указаны на закладке Материалы.

Для заполнения табличной части Содержание драгоценных материалов, расположенной справа, следует использовать кнопку командной панели Заполнить .

В результате в табличной части Содержание драгоценных материалов появится одна или несколько строк с информацией о драгоценных материалах, которые содержатся в объектах МЗ.

Аналитика операции – заполняется, если выбытие материальных ценностей связано с одной из следующих причин:

  • Реализовано другим организациям;
  • Израсходовано на производственные нужды, включая отходы и потери;
  • Израсходовано на научно-исследовательские цели, включая отходы и потери;
  • Сданы лом и отходы для переработки и аффинажа;
  • Сданы лом и отходы организации-заготовителю для переработки и аффинажа.

Заполнение реквизита Аналитика операции требуется для автоматического заполнения статистического отчета по форме 2 -ДМ.

Номенклатура лома – единица номенклатуры, предназначенная для оперативного учета содержания драгоценных материалов в регистре накопления Наличие драгоценных материалов в ломе и отходах.

Выбирается из справочника Номенклатура.

Если Номенклатура лома указана, то в таблице Содержание драг. материалов следует заполнить колонки Лигатурная масса лома и Источник образования отходов и лома.

Реквизит Номенклатура лома можно заполнить, только если списанные МЗ не уничтожены в результате стихийных бедствий, либо других причин.

Заполнение реквизита Источник образования отходов и лома требуется для автоматического заполнения статистического отчета по форме 2 –ДМ (приложение).

Использование на данном этапе Номенклатуры лома позволяет списать в бухгалтерском учете все драгоценные материалы во всех МЗ, указанных в документе, и учесть их в составе одного объекта, например, Лом драг. материалов, в регистре накопления Наличие драгоценных материалов в ломе и отходах.

Далее данный объект необходимо принять к учету с помощью документа Поступление МЗ.

Если не использовать Номенклатуру лома на данном этапе, то в дальнейшем потребуется вручную редактировать список драгоценных материалов в составе Лома драг. материалов при принятии его к учету с помощью документа Поступление МЗ.

Печать ведомости на выдачу МЗ на нужды учреждения

Чтобы распечатать ведомость ее необходимо предварительно записать с помощью кнопки Записать объект командной панели формы документа.

Для формирования печатной формы документа нажмите кнопку Печать и выберите в меню пункт Ведомость выдачи МЦ на нужды учреждения.

Примечание. Суммы по документу рассчитываются после заполнения реквизитов Бухгалтерской операции и проведения документа. После этого для просмотра сумм можно открыть печатную форму ведомости или бухгалтерскую справку.

Закладка "Бухгалтерская операция"

Типовая операция – выбирается из списка Типовые операции.

Для документа Ведомость на выдачу МЗ на нужды учреждения предусмотрены следующие типовые операции:

  • перемещение материальных запасов между материально ответственными лицами;
  • списание материалов.

Дополнительные возможности

На основании документа Ведомость на выдачу МЗ на нужды учреждения можно ввести документ Сторно.
