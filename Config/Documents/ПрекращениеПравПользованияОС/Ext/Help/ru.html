Документ "Корректировка, прекращение прав пользования ОС, НПА"

Документ Корректировка, прекращение прав пользования ОС, НПА предназначен для отражения в учете операций:

  • по прекращению прав пользования активами при завершении срока полезного использования объектов учета операционной аренды в связи с окончанием срока действия договора;
  • по прекращению прав пользования активами в случае досрочного расторжения договора имущественного найма или договора безвозмездного пользования;
  • по корректировке стоимости прав пользования, например, при изменении цены аренды;
  • по корректировке порядка начисления амортизации прав пользования, например, при изменении счета или аналитики расходов текущего периода для начисления амортизации прав пользования.

После заполнения реквизитов бухгалтерской операции и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида Корректировка, прекращение прав пользования ОС, НПА можно открыть с помощью команды Корректировка, прекращение прав пользования ОС, НПА, размещенной в группе Права пользования меню функций раздела ОС, НМА, НПА, а также в группе Долгосрочные договоры, аренда меню функций раздела Услуги, работы, производство.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Корректировка, прекращение прав пользования ОС, НПА.

Заполнение реквизитов шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Вид операции – выбирается из списка:

  • Завершение срока аренды (пользования) – для прекращения прав пользования активами по договорам, срок которых истек на дату оформления документа.
  • Досрочное прекращение аренды (пользования) – для досрочного прекращения прав пользования активами по действующим на дату оформления документа договорам.
  • Корректировка прав пользования – для корректировки стоимости прав пользования по договорам операционной аренды, а также для корректировки способа и срока признания расходов, счета и аналитики учета расходов по амортизации, отражения в бухгалтерском и налоговом учете.

При выборе вида операции Корректировка прав пользования необходимо установить флажки Стоимость прав пользования и/или Порядок начисления амортизации в зависимости от того, что планируется изменить этим документом:

  • Стоимость прав пользования – для изменения сумм балансовой стоимости объектов прав пользования, накопленной амортизации, отложенных доходов (т.е. изменения стоимости объекта прав пользования по договору и / или справедливой стоимости);
  • Порядок начисления амортизации – для изменения параметров признания доходов (по месяцам / по календарным дням / по графику / в особом порядке), периода признания доходов и начисления амортизации, принятия НДС к вычету, счета затрат для начисления амортизации (счета, КПС, КЭК).

В шапке документа предусмотрен отбор по реквизитам КФО, Контрагент и Договор(ы).

Примечание. Если значения реквизитов КФО, Контрагент и Договор(ы) указаны, то табличная часть на закладке Права пользования будет заполнена с учетом установленного отбора.

Начисление амортизации за текущий (последний) месяц пользования имуществом производится документом Начисление амортизации прав пользования ОС, НПА, также как и при регламентном ежемесячном начислении амортизации прав пользования.

Для начисления амортизации за текущий (последний) месяц, в группе реквизитов Начисление амортизации за текущий месяц необходимо указать период фактического действия договора аренды (пользования) в текущем (последнем) месяце и нажать на кнопку Сформировать.

Например, при досрочном прекращении договора аренды для начисления амортизации необходимо указать срок пользования объектами аренды в текущем (последнем) месяце пользования имуществом.

Документ Начисление амортизации прав пользования ОС, НПА в этом случае будет сформирован на дату окончания срока пользования имуществом, а сумма амортизации будет скорректирована с учетом фактического количества дней пользования имуществом в текущем (последнем) месяце.

При необходимости, рассчитанную автоматически сумму амортизации можно скорректировать вручную.

Закладка "Права пользования"

При нажатии на кнопку Заполнить табличная часть на закладке Права пользования автоматически заполняется по остаткам на счетах учета прав пользования активами (111.40 "Права пользования нефинансовыми активами", 104.40 "Амортизация прав пользования активами") и отложенных доходов от предоставления права пользования (401.40 "Доходы будущих периодов").

В результате табличная часть построчно заполнена спецификациями объектов прав пользования имуществом в разрезе контрагентов и договоров:

  • для вида операции Завершение срока аренды (пользования) – по договорам, срок которых истек на дату оформления документа.
  • для вида операции Досрочное прекращение аренды (пользования) – по действующим на дату оформления документа договорам.
  • для вида операции Корректировка прав пользования – по договорам, независимо от срока их действия, по которым есть остатки на счетах.

Для видов операций Завершение срока аренды (пользования) и Досрочное прекращение аренды (пользования) при необходимости можно удалить лишние строки или скорректировать суммы в колонке Списать (сторнировать).

Для поиска и отбора строк можно использовать кнопки Найти и Отменить поиск командной панели табличной части.

Примечание. Добавление строк в табличную часть вручную не предусмотрено.

Для вида операции Корректировка прав пользования изменение стоимости прав пользования предполагает изменение сумм вручную в графе Изменить (+/-).

В колонке Контрагент, договор по данным счета 111.40 заполняются поля:

  • контрагент-арендодатель – элемент справочника Контрагенты;
  • договор аренды (имущественного найма) или безвозмездного пользования – элемент справочника Договоры и иные основания возникновения обязательств.

В колонке Объект ОС, НПА по данным счета 111.40 заполняется объект права пользования имуществом – элемент справочника Основные средства, НМА, НПА с видом НФА Права пользования имуществом.

В колонке Вид операции заполняется вид операции, который был указан в документе Принятие к учету прав пользования ОС, НПА: Поступление в аренду, Поступление в аренду на льготных условиях или Поступление в безвозмездное пользование.

В колонке Аналитический учет заполняются аналитические признаки учета объектов операционной аренды:

  • МОЛ/Место хранения – место нахождения имущества, полученного в пользование, а также лицо, ответственное за его сохранность и (или) использование по назначению.
  • Подразделение – элемент справочника Подразделения, если учет прав пользования активами ведется в разрезе подразделений.
  • Номенклатура – элемент справочника Номенклатура, номенклатура услуги по аренде, пользованию имуществом для аналитического учета отложенных доходов от предоставления права пользования активом (401.40).

В колонке Аналитический учет по данным счета 111.40 заполняются аналитические признаки учета объектов операционной аренды: МОЛ/Место хранения, Подразделение.

В колонке Счет учета заполняются счета учета объектов операционной аренды:

  • счет учета прав пользования НФА (111.40), включая КФО и КПС;
  • счет учета амортизации прав пользования активами (104.40), включая КФО, КПС;
  • счет учета отложенных доходов от предоставления права пользования активом (401.40), возникающих по договорам безвозмездного пользования и договорам аренды на льготных условиях, включая КФО, КПС и КЭК.

В колонке Остаток автоматически заполняются остатки по счетам учета объектов операционной аренды.

В колонке Списать (сторнировать) заполняются суммы, на которые необходимо отразить прекращение прав пользования активами.

По умолчанию данные суммы равны остаткам на счетах учета 111.40, 104.40 и 401.40, что соответствует полному прекращению прав пользования:

  • Балансовая стоимость – балансовая стоимость объекта учета аренды.
  • Накопленная амортизация – накопленная амортизация за период пользования объектом учета аренды.
  • Отложенные доходы – отложенные доходы от предоставления права пользования активом. Заполняется только по договорам безвозмездного пользования и договорам аренды на льготных условиях.

В колонке После изменения в строках Балансовая стоимость, Накопленная амортизация и Отложенные доходы рассчитывается стоимость соответствующих объектов учета операционной аренды за оставшийся срок договора после отражения прекращения прав пользования активами или произведенных корректировок в учете.

По договорам аренды в колонке Расчеты (резервы) автоматически заполняются параметры корректировки резервов предстоящих расходов по арендной плате:

  • В колонке Остаток резервов заполняется остаток резервов предстоящих расходов по договору аренды по данным счета 401.60. При расчетах в иностранной валюте остаток резервов отражается в иностранной валюте и в рублевом эквиваленте на дату признания резерва.
  • В колонке Расчеты (резервы) отражаются корректировки (увеличения или уменьшения) резервов, т.е. суммы увеличения или уменьшения общей суммы арендных платежей за весь срок пользования имуществом. При расчетах в иностранной валюте суммы корректировки резервов отражаются в иностранной валюте и в рублевом эквиваленте на дату документа (дату признания резерва). Сумма корректировки резервов в рублях рассчитывается по значениям, указанным в графе Изменение (+ / -) / Списать (сторнировать), по формуле: балансовая стоимость объекта учета аренды (111.40) - накопленная амортизация за период пользования объектом учета аренды (104.40) - отложенные доходы от предоставления права пользования активом (401.40). Сумма корректировки резервов пересчитывается в иностранную валюту по курсу на дату признания резерва
  • В колонке Счет расчетов заполняются счет и КПС расчетов по арендной плате (302.24 или 302.29) по данным регистра сведений Параметры амортизации прав пользования ОС, НПА.
  • В колонке Резерв заполняются счет, КПС и статья резервов предстоящих расходов по арендной плате (401.60) по данным регистра сведений Параметры амортизации прав пользования ОС, НПА.

При выборе вида операции Корректировка прав пользования можно отразить изменение сумм балансовой стоимости, амортизации, отложенных доходов в графе Изменить (+/-). Показатели в графе После изменения будут пересчитаны автоматически. При этом Сумма расчетов рассчитывается по формуле: изменение балансовой стоимости (111.40) - изменение накопленной амортизации (104.40) - изменение отложенных доходов (401.40).

Закладка "Параметры амортизации"

Закладка Параметры амортизации доступна при выборе в шапке документа вида операции Корректировка прав пользования и установке флажка Порядок начисления амортизации.

По кнопке Заполнить табличная часть документа заполняется автоматически по данным регистра сведений Параметры амортизации прав пользования ОС, НМА, НПА.

Колонка Отложенные доходы заполняется по данным регистра сведений Параметры списания доходов будущих периодов.

Реквизиты в колонках Право пользования, Вид операции, Остаточная стоимость недоступны для изменения.

На закладке предусмотрено изменение следующих параметров:

  • Расчеты – счет расчетов (302.24, 302.29), КПС счета расчетов, принятие НДС к вычету (флажок Принимать НДС к вычету);
  • Признание расходов – порядок признания расходов (по месяцам, по календарным дням, в особом порядке, по графику) и даты начала и окончания начисления амортизации;
  • Счет расходов – счет расходов для начисления амортизации (счет, КПС, КЭК счета затрат);
  • Субконто расходов – субконто расходов для начисления амортизации;
  • Отложенные доходы – отражение отложенных доходов от предоставления права пользования активом в бухгалтерском и налоговом учете.

Новые параметры действуют, начиная с даты документа.

Закладка "Бухгалтерская операция"

Для видов операций Завершение срока аренды (пользования) и Досрочное прекращение аренды (пользования) типовая операция имеет значение Прекращение прав пользования ОС, НПА.

При проведении документа по каждому объекту аренды (каждой строке документа) формируются бухгалтерские записи:

  • Дт 0 104 4Х 451 - Кт 0 111 4Х 451 – уменьшение балансовой стоимости права пользования активом на сумму накопленной амортизации;
  • Дт 0 401 60 224 (229) – Кт 0 111 4Х 451 – уменьшение остаточной стоимости права пользования активом в уменьшение резервов предстоящих расходов по договору аренды;
  • Дт 0 401 40 180 – Кт 0 111 4Х 451– уменьшение остаточной стоимости права пользования активом в уменьшение остатка отложенных доходов от предоставления права пользования активом (по договорам безвозмездного пользования и договорам аренды на льготных условиях).

Если Вид операции имеет значение Корректировка прав пользования, то используется типовая операция Корректировка прав пользования ОС, НПА.

При проведении документа по каждому объекту аренды (каждой строке документа) формируются бухгалтерские записи:

При корректировке в сторону увеличения:

  • Дт 0 111 4Х 351 - Кт 0 401 60 224 (229) – увеличение остаточной стоимости права пользования активом и резервов предстоящих расходов по договору аренды;
  • Дт 0 111 4Х 351 - Кт 0 401 40 18Х – увеличение остаточной стоимости права пользования активом и остатка отложенных доходов от предоставления права пользования активом (по договорам безвозмездного пользования и договорам аренды на льготных условиях).

При корректировке в сторону уменьшения:

  • Дт 0 401 60 224 (229) – Кт 0 111 4Х 451– уменьшение остаточной стоимости права пользования активом и резервов предстоящих расходов по договору аренды;
  • Дт 0 401 40 18Х – Кт 0 111 4Х 451 – уменьшение остаточной стоимости права пользования активом и остатка отложенных доходов от предоставления права пользования активом (по договорам безвозмездного пользования и договорам аренды на льготных условиях);
  • Дт 0 104 4Х 451 – Кт 0 111 4Х 451 – уменьшение балансовой стоимости права пользования активом и суммы накопленной амортизации.

В случае, если установлен флажок Отразить отложенные обязательства, также формируются бухгалтерские записи по корректировке отложенных обязательств Дт 0 501 93 224 (229) (0 506 90 224 (229)) – Кт 0 502 99 224 (229)).

При отражении прекращения права пользования, в т.ч. досрочного или корректировок в межотчетном периоде (датой 31.12.20ХХ 23:59:59 с установленным флажком Отразить в межотчетном периоде) для всех видов операций доступна типовая операция Корректировка прав пользования ОС, НПА в межотчетном периоде (401.30). При проведении документа с данной типовой операцией формируются аналогичные проводки в корреспонденции со счетом 401.30 "Финансовый результат прошлых отчетных периодов".

Регистрация документа

Регистрация документа Корректировка, прекращение прав пользования ОС, НПА производится в журналах Журнал операций, Документы по основным средствам и Журнал расчетов с поставщиками.

Дополнительные возможности

На основании документа Корректировка, прекращение прав пользования ОС, НПА можно ввести документ Сторно.
