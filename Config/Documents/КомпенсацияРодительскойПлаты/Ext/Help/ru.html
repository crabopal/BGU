Документ "Расчет компенсации родительской платы"

Документ применяется для расчета компенсации родительской платы.

Для автоматизации расчета компенсации предварительно следует выполнить настройку расчета компенсации, которая вызывается с помощью команды Настройка компенсации родительской платы в группе Учет расчетов за содержание детей в ДДУ раздела Специализированные подсистемы формы Настройка параметров учета раздела Администрирование.

После заполнения и записи документа можно сформировать печатную форму Ведомость по расчетам компенсации родительской платы за присмотр и уход за детьми.

Работа со списком документов

Список документов вида Расчет компенсации родительской платы можно открыть с помощью команды Расчет компенсации родительской платы меню функций раздела Платное обучение.

В форме списка предусмотрен отбор по реквизитам Организация и Группа детского учреждения.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Расчет компенсации родительской платы.

Заполнение реквизитов шапки документа
  • Период расчета – месяц года, за который выполняется расчет. По умолчанию автоматически подставляется месяц, предшествующий текущему месяцу, и это значение можно отредактировать;
  • Дата – дата документа;
  • Организация – наименование детского учреждения;
  • Группа детского учреждения – выбирается из справочника Группы детского учреждения;
  • Настройка расчета – настройка расчета родительской платы. Выбирается из справочника Настройки расчетов по родительской плате;
  • Направление деятельности – выбирается из справочника Направления деятельности.

Закладка "Расчет компенсаций"

Для заполнения табличной части вручную можно использовать кнопку Добавить командной панели табличной части.

При нажатии на кнопку Заполнить командной панели табличной части выпадает меню с командами Заполнить и рассчитать и Заполнить и рассчитать, указав дополнительный отбор.

В результате использования команды Заполнить и рассчитать в табличной части появится список детей, отобранных в соответствии с заданными значениями реквизитов в шапке документа.

Использование команды Заполнить и рассчитать, указав дополнительный отбор позволяет при отборе детей в список учесть дополнительный отбор по реквизитам и свойствам справочников Дети и Договоры и иные основания возникновения обязательств.

В заполненной тем или иным способом таблице для каждого ребенка будут указаны Плательщик, Счет плательщика, База расчета, а также Компенсация – Процент и Сумма.

Дополнительные возможности

На основании документа Расчет компенсации родительской платы можно создать документ Начисление компенсации родительской платы.
