Проведение документа

Документ "Начисление имущественных налогов"

Документ Начисление имущественных налогов предназначен для отражения в бухгалтерском учете операций по начислению транспортного налога, земельного налога, налога на имущество.
После проведения документа можно сформировать Бухгалтерскую справку (ф. 0504833).

Работа со списком документов

Список документов вида Начисление имущественных налогов можно открыть с помощью команды Начисление имущественных налогов меню функций раздела Налоги.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Начисление имущественных налогов. При нажатии кнопки Создать из выпадающего списка необходимо выбрать вид налога: Транспортный налог, Земельный налог или Налог на имущество.

Так же новый документ можно ввести на основании документа расчета налога: Расчет транспортного налога, Расчет земельного налога, Расчет налога на имущество.

Заполнение реквизитов шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Вид налога - вид налога, для которого выполняется начисление.

Расчет налога - Документ-основание, может принимать вид Расчет транспортного налога, Расчет земельного налога или Расчет налога на имущество.
При выборе документа-основания большинство реквизитов документа заполняются автоматически.

В группе реквизитов Первичный документ можно указать вид, номер и дату первичного документа для отражения в журнале операций. Если реквизиты не заполнены, в журнале операций в качестве первичного документа отражается Бухгалтерская справка (ф. 0504833).

Закладка "Бухгалтерский учет"

Основание принятия обязательства - выбирается из справочника Договоры и иные основания возникновения обязательств. Аналитика для принятия бюджетных, денежных обязательств.

Раздел лицевого счета - выбирается из справочника Разделы лицевых счетов. В зависимости от переключателя В шапке, В таблице может указываться в шапке документа или по каждой строке табличной части. Аналитика для принятия бюджетных, денежных обязательств.

Табличная часть на закладке Бухгалтерский учет является основанием для формирования проводок при проведении документа.
Если документ был введен на основании документов Расчет транспортного налога, Расчет земельного налога, Расчет налога на имущество, табличная часть будет заполнена автоматически.
Для добавления строки в табличную часть можно использовать команду Добавить.

Команда Заполнить - позволяет выбрать документ-основание Расчет налога и заполнить табличную часть на основании расчета.

При заполнении документа на основании документа Расчета налога суммы рассчитанного налога группируются по КФО, на котором учитывается объект налогообложения, объект ОС.
Если задана настройка Настройка аналитического учета налогов, заполнение реквизитов табличной части Вид налога и Налог выполняется в соответствии с настройкой, действующей на дату документа.
Если для учетных данных объектов налогообложения задана настройка отражения в учете Регистрация способов распределения налога, группировка строк табличной части выполняется с учетом заданных способов распределения.

Команда Распределение по источникам - открывает отдельное окно Распределение налога по источникам финансирования. Если документ был заполнен на основании расчета налога, открытая форма будет содержать данные расчета налога и примененные способы распределения налога. При необходимости можно внести изменения, например, коэффициент распределения между источниками, если сумма налога распределяется по разным источникам, и перенести результат распределения в документ.

По команде Распределение по источникам группы команд Печать командной панели формы документа можно сформировать печатную форму с результатом распределения сумм налога по источникам финансирования.

Реквизиты табличной части:

Вид налога, платежа - выбирается из справочника Виды налогов и платежей. Служит аналитикой для соответствующего счета аналитического учета счета 303.00. Счет учета, указанный в карточке Вид налога, платежа, используется при формировании проводки.

Налоги и платежи организации - выбирается из справочника Налоги и платежи организаций. Служит аналитикой для соответствующего счета аналитического учета счета 303.00.

ИФО - выбирается из справочника Источники финансового обеспечения. Реквизит доступен для выбора, если включена опция Учет по ИФО.

Подразделение - выбирается из справочника Подразделения. Реквизит доступен, если включена опция Учет по подразделениям. Если на счете учета налога или на счете учета затрат установлен учет по подразделениям, значение поля будет установлено в проводке. Для счета затрат в поле Отражение в учете можно указать подразделение, отличное от текущего значения.

КФО - код финансового обеспечения, выбирается из списка.

КПС - классификационный признак счета. Выбирается из справочника КПС. Используется для формирования записи по кредиту проводки, а так же по дебету проводки, если для счета дебета в колонке Отражение в учете не определен собственный КПС дебета.

КЭК - код экономической классификации. Выбирается из справочника КЭК. Используется при формировании проводки по затратным счетам 109.00, 110.00, 401.20.

Раздел лицевого счета - реквизит доступен, если переключатель установлен в положение В таблице. Выбирается из справочника Разделы лицевых счетов. Аналитика для принятия бюджетных, денежных обязательств.

Код цели - видимость устанавливается по команде Еще - Изменить форму.... Выбирается из справочника Виды целевых средств. Заполняется при необходимости вести счета санкционирования в разрезе видов целевых средств.

Код мероприятия - видимость устанавливается по команде Еще - Изменить форму.... Выбирается из справочника Мероприятия. Заполняется при необходимости вести счета санкционирования в разрезе мероприятий.

Доп. классификация - видимость устанавливается по команде Еще - Изменить форму.... Выбирается из справочника Дополнительная бюджетная классификация. Заполняется при необходимости вести счета санкционирования в разрезе дополнительной бюджетной классификации.

Сумма - сумма начисления.

Отражение в учете - счет дебета и аналитика счета дебета для формирования проводки.

Закладка "Данные расчета"

Закладка отображается, если заполнено поле Расчет налога - документ-основание для начисления налога.
На закладке Данные расчета отображается список, заполненный по данным документа-основания Расчет налога. Список сформирован с учетом группировки по способам распределения налога по источникам финансирования и отражения в учете. Список доступен только на просмотр. Для редактирования данных можно использовать команду Распределение по источникам на закладке Бухгалтерский учет.

Закладка "Бухгалтерская операция"

Реквизит Типовая операция имеет по умолчанию значение Начисление имущественных налогов.

Группа реквизитов Обязательства:

Принять обязательства - при установке флага формируются проводки по принятию обязательств на счет 502.11. По умолчанию флаг установлен.

Принять денежные обязательства - при установке флага формируются проводки по принятию денежных обязательств на счет 502.12. По умолчанию флаг установлен.

Проведение документа

При проведении документа по каждой строке табличной части закладки Бухгалтерский учет формируется проводка с кредита счета аналитического учета счета 303.00 (в зависимости от Счета учета, указанного в карточке Вид налога, платежа) в дебет счета, указанного в поле Отражение в учете.
Если установлены флаги Принять обязательства, Принять денежные обязательства формируются проводки по принятию обязательств, денежных обязательств.
