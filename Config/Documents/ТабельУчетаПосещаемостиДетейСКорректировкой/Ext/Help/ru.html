Документ "Табель учета посещаемости детей (с корректировкой)"

Документ предназначен для формирования и печати Табеля учета посещаемости детей (форма по ОКУД 0504608).

Использование документов Табель учета посещаемости детей (с корректировкой) возможно при включенной настройке параметров учета Редактируемые табели посещаемости ДДУ. При этом ввод новых документов Табель учета посещаемости детей становится недоступным.

Работа со списком документов


Список документов Табели учета посещаемости детей (с корректировкой) можно открыть с помощью команды Табели учета посещаемости детей (с корректировкой) меню функций раздела Платное обучение.

В форме списка предусмотрен отбор по реквизитам Организация и Группа детского учреждения.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Табели учета посещаемости детей (с корректировкой).

Заполнение реквизитов шапки документа

Организация – организация, от имени которой оформляется табель. Выбирается из справочника Организации.

Дата документа – дата оформления документа. Как правило, это последний рабочий день учреждения в месяце предоставления услуги.

Группа – группа детского дошкольного учреждения. Выбирается из справочника Группы детского учреждения.

Период начисления – месяц, за который формируется табель.

После указания Периода начисления значения реквизитов Количество дней в месяце и Количество рабочих дней заполняются автоматически в соответствии с графиком работы выбранной группы по услугам или, если для группы не задан график работы, то в соответствии с производственным календарем Российской Федерации.

Значения реквизитов Количество дней в месяце и Количество рабочих дней приведены для информации и не редактируются.

Тумблер Вид табеля может находиться в положениях По дням или Сводно:

  • Табель вида По дням предназначен для ввода информации по каждому рабочему дню;
  • Табель вида Сводно предназначен для ввода количества дней посещения за месяц.

Тумблер Вид услуг может находиться в положениях Родительская плата или Доп. образовательные услуги:

  • Табель с видом услуги Родительская плата используется для расчета начислений платы за основные услуги, то есть за присмотр и уход;
  • Табель с видом услуги Доп. образовательные услуги используется для расчета начислений по дополнительной образовательным услугам.

Заполнение реквизитов табличной части

Рассмотрим в качестве примера заполнение табеля, который имеет вид По дням.

Для заполнения табличной следует использовать кнопку Заполнить табель командной панели табличной части.

В результате в табличной части появится список детей, отобранных в соответствии с выбранными реквизитами Организация и Группа.

Для детей, которые в месяце формирования табеля не посещали детское учреждение, необходимо в колонке, соответствующей дню пропуска, выбрать из выпадающего списка признак отсутствия:

  • Н(о) – оплачиваемое непосещение. День, в который зафиксировано данное отсутствие при расчете месячной платы включается в оплачиваемые дни;
  • Н(н) – неоплачиваемое непосещение. День с данным видом отсутствия при расчете месячной платы исключается из числа оплачиваемых дней.

В колонке Причины непосещения указывается краткое описание причин пропуска посещений.

Для проверки правильности и полноты заполнения документа можно сформировать печатную форму Табель учета посещаемости детей (ф. 0504608).

Правильно заполненный документ следует провести.

При проведении документа формируются данные о непосещениях ребенком дошкольного учреждения, которые необходимы для автоматизации последующих расчетов.
