Документ "Ввод истории прав пользования ОС, НПА"

Документ Ввод истории прав пользования ОС, НПА предназначен для ручной регистрации записей в Карточке учета права пользования нефинансовым активом (ф. 0509214).


Работа со списком документов

Список документов вида Ввод истории прав пользования ОС, НПА можно открыть с помощью команды Ввод истории прав пользования ОС, НПА, размещенной в группе Права пользования меню функций раздела ОС, НМА, НПА.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Ввод истории прав пользования ОС, НПА.

Заполнение реквизитов шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Контрагент – арендодатель (правообладатель, собственник имущества), выбирается из справочника Контрагенты.

Договор – договор с арендодателем, выбирается из справочника Договоры и иные основания возникновения обязательств.

Закладка "Основные сведения"

На закладке “Основные сведения” указываются первоначальные сведения о каждом объекте права пользования (условие пользования, дата приемки, срок пользования и др.) вместе с реквизитами первичного документа (договора), которые выводятся в разделе 1.1 “Сведения о договоре права пользования нефинансовым активом – Основные сведения” Карточки учета права пользования нефинансовым активом (ф. 0509214).

Закладка "Сведения об изменениях"

На закладке “Сведения об изменениях” вводятся записи о произведенных изменениях (в хронологическом порядке) вместе с реквизитами первичного документа (дополнительного соглашения и т.п.), которые выводятся в разделе 1.2 “Сведения о договоре права пользования нефинансовым активом – Сведения об изменениях” Карточки учета права пользования нефинансовым активом (ф. 0509214).

Закладка "Сведения об имуществе (объекте прав пользования)"

На закладке “Сведения об имуществе (объекте прав пользования)” указываются наименование основного объекта права пользования активом и (или) объектов, включенных в основной объект, наименование и значение характеристик, признаков, определяющих основной объект и (или) объекты, включенные в основной объект), которые выводятся в разделе 4.1 “Сведения об объекте права пользования – Основные характеристики” Карточки учета права пользования нефинансовым активом (ф. 0509214).
