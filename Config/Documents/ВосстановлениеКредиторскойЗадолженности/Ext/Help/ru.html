Документ "Восстановление кредиторской задолженности"

Документ Восстановление кредиторской задолженности предназначен для отражения в бухгалтерском учете операций восстановления кредиторской задолженности, списанной на забалансовый счет 20 "Задолженность, невостребованная кредиторами", на балансовые счета учета 205.00, 208.00, 209.00, 301.00, 302.00, 303.00, 304.01, 304.02, 304.03, 304.06.

После заполнения и проведения документа по кнопке Печать можно сформировать Решение о восстановлении кредиторской задолженности (форма по ОКУД 0510446).

Также можно распечатать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида Восстановление кредиторской задолженности можно открыть с помощью команды Восстановление кредиторской задолженности меню функций раздела Учет и отчетность.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Восстановление кредиторской задолженности.

Заполнение шапки документа

Контрагент (заявитель) – контрагент (кредитор). Выбирается из справочника Контрагенты.

При выборе в шапке документа реквизита Контрагент (заявитель) появлятся сообщение "Заполнить по данным бухгалтерского учета", в котором следует нажать кнопку Да для заполнения документа информацией о списанной кредиторской задолженности.

Вид документа – индентификаторы контрагентов - физических лиц, которые формируются по выбранному виду документа либо в автоматическом режиме.

Индентификатор плательщика – идентификатор контрагентов - юридических лиц по форматам ГИС ГМП 2.Х.

Заявитель является правопреемником первоначального кредитора – флажок устанавливается в случае если Контрагент (заявитель) является правопреемником первоначального кредитора. При этом в соответствующем поле выбирается контрагент - первоначальный кредитор, по которому будут отбираться данные о списанной кредиторской задолженности при заполнении документа.

Подразделение – подразделение для отбора остатков задолженности. Отбор применяется в случае, если учет на счете учета задолженности ведется в разрезе подразделений. Выбирается из справочника Подразделения.

Закладка "Кредиторская задолженность"

При выборе в шапке документа реквизита Контрагент (заявитель) и нажатии на кнопку Да всплывающего сообщения "Заполнить документ по данным бухгалтерского учета" в документе заполняется информация о списанной кредиторской задолженности выбранного контрагента (кредитора) в разрезе документов списания задолженности. Сумму задолженности к восстановлению, при необходимости, можно скорректировать (в колонке Восстановить).

Закладка "Платежные реквизиты контрагента"

Способ оплаты – выбирается из списка значений: Наличными или Безналично.

При безналичном способе оплаты платежные реквизиты контрагента (заявителя) могут быть заполнены автоматически на основании зарегистрированного в программе счета (выбирается из справочника Банковские и казначейские счета) или банковской карты контрагента (выбирается из справочника Банковские карты контрагентов).

Информация, указанная на закладке, используется для формирования раздела 3 "Платежные реквизиты контрагента (заявителя)" формы 0510446 "Решение о восстановлении кредиторской задолженности".

Закладка "Бухгалтерская операция"

Типовая операция – единственная, Восстановление кредиторской задолженности.

При проведении документа в учете отражаются бухгалтерские записи:

  • Дт 401.10.173 Кт 205.00, 208.00, 209.00, 301.00, 302.00, 303.00, 304.01, 304.02, 304.03, 304.06 – восстановление кредиторской задолженности с балансовых счетов учета;
  • Одновременно задолженность учреждения, списывается с забалансового счета 20 "Задолженность, невостребованная кредиторами".
