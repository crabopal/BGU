Документ "Начисление процентов, пеней, штрафов к уплате"

Документ Начисление процентов, пеней, штрафов к уплате применяется для отражения в учете начисления процентов, пеней и штрафов к уплате по договорам с контрагентами, в том числе, в связи с возмещением ущерба, нарушением условий контрактов, законодательства и другим причинам.
После проведения документа можно распечатать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида Начисление процентов, пеней, штрафов к уплате можно открыть с помощью команды Начисление процентов, пеней, штрафов к уплате меню функций раздела Планирование и санкционирование.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Начисление процентов, пеней, штрафов к уплате.

Заполнение шапки документа

Период начисления – период, за который производится начисление процентов, пеней, штрафов.
В шапке документа предусмотрен отбор по реквизитам Контрагент, Договор, КФО и Вид расчетов.

Примечание. Если значения реквизитов Контрагент, Договор, КФО и Вид расчетов указаны, то табличная часть на закладке Начисление будет заполнена с учетом установленного отбора.

Закладка «Начисление»

Табличную часть документа можно заполнить вручную или автоматически.
При заполнении табличной части вручную для добавления новой строки можно использовать кнопку Добавить командной панели таблицы.

Примечание. Если по договору с контрагентом ведется график платежей, то по кнопке Заполнить табличная часть документа может быть заполнена автоматически по данным о запланированных к уплате процентах, пени, штрафах за выбранный период с учетом установленных отборов (недоступно в базовой версии).

Контрагент – выбирается из справочника Контрагенты.
Договор – выбирается из справочника Договоры и иные основания возникновения обязательств. Выбор договора ограничен указанными реквизитами Организация и Контрагент.
Вид расчетов – выбирается из списка:

  • Проценты.
  • Штрафы.
  • Пени на основной долг.
  • Пени на проценты.

Оплатить до – крайняя запланированная дата оплаты процентов, пеней, штрафов.
Сумма – сумма оплаты.
КФО – код финансового обеспечения, выбирается из списка.
Счет расчетов – выбирается из фрагмента Плана счетов ЕПСБУ, ограниченного субсчетами счета 302.00.
КПС – классификационный признак счета, выбирается из справочника КПС.
КЭК доходов – код экономической классификации доходов, выбирается из фрагмента справочника КЭК.

Закладка "Бухгалтерская операция"

Типовая операция – единственная операция Начисление процентов, пеней, штрафов к уплате.
Для данной типовой операции можно заполнить реквизиты:

  • Принять денежное обязательство – флажок, следует установить при необходимости принять денежное обязательство;
  • Раздел лицевого счета – раздел лицевого счета, на который будет принято денежное обязательство. Выбирается из справочника Разделы лицевых счетов.

Проведение документа

При проведении документа отражаются следующие бухгалтерские записи:

  • Дт 0.401.20.2ХХ – Кт 0.302.ХХ.7ХХ (начисление процентов, пеней, штрафов к уплате);
  • Дт Н91.02 – Кт НПВ (отражение в налоговом учете внереализационных расходов или расходов, не учитываемых при определении налоговой базы по налогу на прибыль);
  • Дт 0.502.11.2ХХ – Кт 0.502.12.2ХХ (принятие денежных обязательств).
