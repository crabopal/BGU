Документ "Списание расходов будущих периодов"

Документ Списание расходов будущих периодов используется для отнесения расходов учреждения, произведенных ранее и учитываемых в составе расходов будущих периодов (РБП), на себестоимость готовой продукции или на финансовый результат текущего финансового года.

Документ Списание расходов будущих периодов является регламентным и его следует вводить ежемесячно.

После заполнения и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов Списание расходов будущих периодов можно открыть с помощью команды Списание расходов будущих периодов меню функций раздела Учет и отчетность.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Списание расходов будущих периодов.

Работа с документом

Реквизиты шапки документа:

  • Период – месяц списания расходов будущих периодов;
  • Организация – заполняется автоматически, но данное значение можно изменить.

Для автоматического заполнения таблиц на закладках Бухгалтерский учет и Налоговый учет следует использовать кнопку Заполнить.

При этом выполняется расчет остатков и сумм РБП к списанию в текущем месяце на основе параметров списания, указанных в справочнике Расходы будущих периодов.

Примечание. Если для РБП установлено признание расходов В особом порядке, то сумму списания для него следует указать вручную.
