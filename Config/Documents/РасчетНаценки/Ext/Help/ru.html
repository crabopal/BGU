Документ "Расчет торговой наценки"

Предназначен для расчета и списания торговой наценки для проданных товаров, учитываемых по ценам реализации.

Документ является регламентным и должен вводиться в конце каждого месяца для каждой организации, по которой ведется учет розничной торговли в ценах реализации.

Документ определяет сумму реализации за месяц и рассчитывает сумму наценки, которую необходимо списать со счетов учета наценки 105.29 и 105.39.

После заполнения и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида Расчет торговой наценки по проданным товарам можно открыть с помощью команды Расчет торговой наценки меню функций раздела Материальные запасы.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Расчет торговой наценки по проданным товарам.

Заполнение реквизитов шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Типовая операция имеет значение Расчет торговой наценки по проданным товарам.

Проведение документа

В результате проведения будет сформирована проводка по списанию торговой наценки:

Д-т 401.10.130, К-т 105.39 (29) - СТОРНО на сумму рассчитанной наценки.

Дополнительные возможности

На основании документа Расчет торговой наценки можно ввести документ Сторно.
