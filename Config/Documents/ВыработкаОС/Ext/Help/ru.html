Документ "Выработка ОС"

Для начисления амортизации по объекту ОС, для которого задан метод начисления амортизации Пропорционально объему продукции, необходимы данные об объеме продукции (выполненных работ), выработанной с использованием данного ОС.

Для регистрации объема выработанной продукции (выполненных работ) с целью последующего начисления амортизации предназначен документ Выработка ОС.

Работа со списком документов

Список документов вида Выработка ОС можно открыть с помощью команды Выработка ОС группы Прочие операции в меню функций раздела ОС, НМА и НПА.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Выработка ОС.

Заполнение шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Заполнение реквизитов табличной части

В табличной части для каждого основного средства следует указать объем выработанной продукции (выполненных работ).

Для ввода нескольких объектов ОС в табличную часть удобно использовать форму подбора, которая вызывается кнопкой Подбор.

Для добавления новой строки в табличную часть можно использовать кнопку Добавить командной панели.

  • Основное средство – основное средство, по которому указывается объем продукции (выполненных работ). Выбирается из справочника Основные средства.

Примечание. Для быстрого заполнения документа группой однотипных основных средств нужно ввести в табличное поле хотя бы один такой объект и автоматически заполнить табличное поле с помощью кнопки Заполнить – По наименованию.
  • Инвентарный номер – инвентарный номер объекта ОС. Заполняется автоматически после выбора объекта ОС.
  • Параметр выработки – наименование характеристики, объем которой используется для начисления амортизации. Выбирается из справочника Параметры выработки ОС.
  • Количество – объем выработки по указанной характеристике.

При проведении документа данные о выработке объекта ОС записываются в регистр накопления Выработка ОС.

Дополнительные возможности

На основании документа Выработка ОС можно ввести документ Сторно.
