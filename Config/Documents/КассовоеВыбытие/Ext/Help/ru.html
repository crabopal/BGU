Документ "Кассовое выбытие"

Документ Кассовое выбытие является универсальным документом, позволяющим вводить любые операции по списанию средств с лицевого счета учреждения, в том числе по оплате поставщикам за товары, работы и услуги, по уплате страховых взносов, налогов, пени, штрафов и т.п., по возврату авансов покупателей.

Документ оформляется на основании платежного документа, указанного в выписке банка (казначейства).

Внимание!
Документ Кассовое выбытие создается только в том случае, если в выписке, полученной из органа, осуществляющего кассовое обслуживание, присутствуют операции, не отраженные в заявках на расходование денежных средств.

В одном документе можно отразить списание со счета средств, которые должны быть отнесены на несколько счетов бухгалтерского учета, КФО и на разные статьи доходов и расходов.

Документ позволяет оформить следующие операции:

  • возврат в бюджет субсидий, трансфертов, грантов прошлых лет (303.00);
  • возврат полученных авансов, излишне полученных доходов (205.00, 209.00);
  • оплата поставщикам и другие платежи (206.00, 302.00);
  • перечисление задатка (залога, обеспечения) (210.05);
  • перечисление компенсации родительской платы по получателям (302.00);
  • перечисление на счет 40116 (получение наличных, банковская карта) (210.03);
  • перечисление подотчетным лицам (208.00);
  • перечисление подотчетным лицам по ведомости (208.00);
  • перечисление физическим лицам по ведомости (302.00);
  • перечисление средств во временном распоряжении (304.01);
  • перечисление средств головному учреждению, обособленному подразделению (304 04);
  • перечисление средств на банковские счета распорядителей, получателей бюджетных средств (1 304 04);
  • перечисление средств на покупку иностранной валюты (201.23);
  • перечисление удержаний из зарплаты, выплат по оплате труда, стипендий (304.03);
  • перечисление удержаний из зарплаты, выплат по оплате труда, стипендий (по ведомости) (304.03);
  • погашение задолженности по долговым обязательствам (301.00);
  • предоставление кредитов, займов (ссуд) (207.00);
  • уплата налогов, и сборов и иных платежей в бюджет (303.00).

В программе реализовано отражение исполнения графика платежей по договорам с ведением графиков платежей при проведении документа Кассовое выбытие с типовыми операциями:

  • Оплата поставщикам и другие платежи (206.00, 302.00).
  • Возврат полученных авансов, излишне полученных доходов (205.00, 209.00).
  • Погашение задолженности по долговым обязательствам (301.00).

После проведения документа можно распечатать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Документы вида Кассовое выбытие находятся в списке расчетно-платежных документов Журнала расчетно-платежных документов.

Чтобы получить доступ к списку расчетно-платежных документов, следует с помощью команды Расчетно-платежные документы меню функций раздела Денежные средства открыть форму Журнала расчетно-платежных документов и перейти на закладку Расчетно-платежные документы.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Расчетно-платежные документы и выбрать в меню пункт Кассовое выбытие.

Заполнение реквизитов шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Лицевой счет – лицевой счет организации, с которого выполнено перечисление средств. Выбирается в справочнике Реквизиты лицевых счетов.

Кор. счет – корреспондирующий счет расчетов, от выбранного значения реквизита зависит состав доступных типовых операций. Выбирается из списка:

  • 205.00, 209.00 Расчеты по доходам (полученным авансам)

Примечание. Доступна типовая операция:
Возврат полученных авансов, излишне полученных доходов (205.00, 209.00).
  • 206.00 Расчеты по выданным авансам

Примечание. Доступна типовая операция
Оплата поставщикам и другие платежи (206.00, 302.00).
  • 207.00 Расчеты по кредитам, займам (ссудам)

Примечание. Доступна типовая операция:
Предоставление кредитов, займов (ссуд) (207.00).
  • 208.00 Расчеты с подотчетными лицами

Примечание. Доступны типовые операции:
Перечисление подотчетным лицам (208.00),
Перечисление подотчетным лицам по ведомости (208.00).
  • 301.00 Расчеты с кредиторами по долговым обязательствам

Примечание. Доступна типовая операция:
Погашение задолженности по долговым обязательствам (301.00).
  • 302.00 Расчеты по принятым обязательствам

Примечание. Доступны типовые операции:
Оплата поставщикам и другие платежи (206.00, 302.00),
Перечисление компенсации родительской платы по получателям (302.00),
Перечисление физическим лицам по ведомости (302.00).
  • 303.00 Расчеты по платежам в бюджеты

Примечание. Доступны типовые операции:
Возврат в бюджет субсидий, трансфертов, грантов прошлых лет (303.00),
Уплата налогов, сборов и иных платежей в бюджет (303.00).
  • Прочие счета

Примечание. Доступны типовые операции:
Перечисление на счет 40116 (получение наличных, банковская карта) (210.03),
Перечисление задатка (залога, обеспечения) (210.05),
Перечисление средств во временном распоряжении (304.01),
Перечисление средств головному учреждению, обособленному подразделению (304.04),
Перечисление средств на банковские счета распорядителей, получателей бюджетных средств (1 304 04),
Перечисление средств на покупку иностранной валюты (201.23),
Перечисление удержаний из зарплаты, выплат по оплате труда, стипендий (304.03),
Перечисление удержаний из зарплаты, выплат по оплате труда, стипендий (по ведомости) (304.03).

Налог, сбор – вид налога либо иного обязательного платежа. Выбирается из справочника Налоги и платежи организации.

Контрагент – организация (физлицо), являющаяся получателем средств. Выбирается из справочника Контрагенты.

Договор – основание платежа. Выбирается из справочника Договоры и иные основания возникновения обязательств.

Контроль – гиперссылка для вызова формы Контроль исполнения договоров с информацией об общем объеме запланированных (неисполненных) платежей по договору, а также о сумме просроченных платежей по договору (в т.ч. более 30 и более 90 дней просрочки).

Важно!
Гиперссылка Контроль доступна в документах поступления и списания денежных средств по договорам, в которых задано ведение графиков платежей.

Закладка "Реквизиты документа"
  • Валюта – по умолчанию установлено значение RUB (российский рубль). Если выбрана другая валюта, то дополнительно следует указать сведения о курсе пересчета (реквизиты Курс и Кратность). Курс валюты может быть указан автоматически, если сведения о нем на дату документа содержатся в справочнике Валюты;
  • Сумма – указывается общая сумма платежа по документу в рублях.

Реквизиты группы Первичный документ:

  • Вид – вид первичного документа. Выбирается из справочника Виды первичных документов;
  • Номер – номер первичного документа;
  • Дата – дата первичного документа.

Реквизмты группы Получатель, счет получателя:

  • Получатель – получатель денежных средств. Выбирается из справочника Контрагенты;
  • Счет получателя – счет получателя денежных средств. Выбирается из справочника Банковские и казначейские счета;
  • Назначение платежа – назначение платежа в виде произвольного текста.
  • Исполняемый договор – реквизит используется для определения раздела лицевого счета. Становится виден и доступен для заполнения при осуществлении операций на лицевом счете с признаком ведения казначейского сопровождения в разрезе разделов лицевого счета.

Закладка "Расшифровка платежа"

В табличной части общая сумма кассовой выплаты (документа) детализируется по счетам бухгалтерского учета и аналитическим признакам.

Подобрать – кнопка для вызова формы Подбор платежей по графику, предназначенной для подбора в табличную часть неисполненных по графику платежей. Возвраты денежных средств от поставщиков (кредиторов) и возвраты покупателям (дебиторам) отражаются в графике платежей с минусом.

Важно!
Кнопка Подобрать доступна в документах поступления и списания денежных средств по договорам, в которых задано ведение графиков платежей.

Заполнить по задолженности – кнопка, предназначенная для автоматического заполнения табличной части по остаткам на выбранном Кор. счете (205.00, 206.00, 209.00 и 302.00), по контрагенту, указанному в шапке документа в реквизите Контрагент.

Если в шапке документа указано значение для реквизита Договор и учет расчетов на счете ведется по договорам, то остатки дополнительно отбираются только по указанному договору.

Примечание. Кнопка Заполнить по задолженности доступна, только если реквизит Кор. счет принимает значение 205.00, 206.00, 209.00 или 302.00.

КФО – код финансового обеспечения. Выбирается из списка.

Источник средств – вид средств, за счет которых должна быть произведена кассовая выплата. Следует выбрать раздел лицевого счета, указанного в шапке документа.

КБК – классификационный признак счета, по которому должна быть произведена выплата. Выбирается из справочника КПС.

КОСГУ – код экономической классификации, соответствующий выплате. Выбирается из справочника КЭК.

Примечание. Для средств во временном распоряжении реквизит КОСГУ не указываются.

Сумма – сумма в рублях по соответствующим кодам бюджетной классификации.

Примечание – в случае необходимости, указывается в скобках код цели, а также иная информация, необходимая для исполнения бюджета.

Вид расчетов – выбирается из списка:

  • Основной долг,
  • Проценты.
  • Штрафы,
  • Пени на основной долг,
  • Пени на проценты.

Примечание. Реквизит Вид расчетов заполняется, если в шапке документа выбран Кор. счет 301.00 "Расчеты с кредиторами по долговым обязательствам".

График платежей – колонка, в которой указываются Вид расчетов и Дата оплаты (по графику платежей).

Важно!
Колонка График платежей доступна в документах поступления и списания денежных средств по договорам, в которых задано ведение графиков платежей.

Счет расчетов – колонка, в которой справочно отображается счет расчетов, соответствующий выбранным КЭК и Кор. счету.

Примечание. Колонка Счет расчетов доступна, только если реквизит Кор. счет в шапке документа имеет значение 205.00, 206.00, 209.00 или 302.00.

Погашение задолженности – может принимать значения:

  • Погасить задолженность – будет выполнено погашение имеющейся задолженности на счете расчетов. Если сумма, указанная в строке табличной части, превысит сумму задолженности на счете расчетов, то программа сформирует соответствующее сообщение.
  • Не погашать – погашение имеющейся задолженности на счете расчетов выполнено не будет.
  • Автоматически – программа автоматически выбирает способ погашения, Погасить задолженность или Не погашать, исходя из имеющихся остатков задолженности на счете расчетов. При этом вся имеющаяся на счете расчетов задолженность будет погашена, а сумма, превышающая задолженность, будет учтена как аванс.

Примечание. Колонка Погашение задолженности доступна, только если реквизит Кор. счет в шапке документа имеет значение 205.00, 206.00, 209.00 или 302.00.

Типовая операция – выбирается из списка Типовые операции.

Возврат полученных авансов, излишне полученных доходов (205.00, 209.00).

Для данной типовой операции необходимо заполнить следующие реквизиты.

Примечание. Если у организации настроен рабочий план счетов, то заполнение реквизита КПС необязательно.

Формировать проводки по исполнению плана доходов (Дт 508.00 Кт 507.00) – флажок, который следует установить при необходимости автоматически скорректировать план доходов на сумму возврата.

Возврат прошлых лет – флажок, который следует установить когда необходимо отразить возврат прошлых лет. В результате проведения документа формируется дополнительная проводка по вспомогательному забалансовому счету ВПЛ "Возвраты прошлых лет".

Оплата поставщикам и другие платежи (206.00, 302.00)

Для данной типовой операции необходимо заполнить реквизиты:

  • Счет кредита – выбирается из фрагмента плана счетов (ЕПСБУ). Может принимать значения 201.11, 201.21, 201.27 или 304.05;
  • КПС для счета 201.00 – выбирается из справочника КПС.

Примечание. Если у организации настроен рабочий план счетов, то заполнение реквизита КПС необязательно.

Группа Курсовая разница (конвертация валюты)

  • Счет отнесения курсовых разниц – выбирается из Плана счетов ЕПСБУ;
  • Субконто 1, Субконто 2 и Субконто 3 – субконто выбранного счета отнесения курсовых разниц.

Перечисление компенсации родительской платы по получателям (302.00)

Для данной типовой операции необходимо заполнить реквизиты:

Группа Кредит:

  • Счет кредита – выбирается из фрагмента плана счетов (ЕПСБУ). Может принимать значения 201.11, 201.21, 201.27 или 304.05;
  • КПС для счета 201.00 – выбирается из справочника КПС.

Группа Расчеты:

  • Счет расчетов – значение по умолчанию 302.62.

Перечисление на счет 40116 (получение наличных, банковская карта) (210.03)

Для данной типовой операции необходимо заполнить реквизиты:

  • Счет кредита – выбирается из фрагмента плана счетов (ЕПСБУ). Может принимать значения 201.11, 210.02 или 304.05;
  • КПС для счета 201.00 – выбирается из справочника КПС.

Группа Указывается для казенных учреждений ( по КФО 1)

  • Забалансовый счет для счета кредита – выбирается из фрагмента плана счетов (ЕПСБУ). Может принимать значения 17.01 или 18.01.

Перечисление подотчетным лицам (208.00)

Для данной типовой операции необходимо заполнить реквизиты:

  • Счет кредита – выбирается из фрагмента плана счетов (ЕПСБУ). Может принимать значения 201.11, 201.21, 201.27 или 304.05.
  • КПС для счета 201.00 – выбирается из справочника КПС.

Перечисление задатка (залога, обеспечения) (210.05)

Для данной типовой операции необходимо заполнить реквизиты:

Примечание. Документ Исправительный чек ККМ с видом операции Исправление чека ККМ позволяет сторнировать некорректный чек ККМ документа-основания и напечатать чек-сторно. Далее необходимо вернуться к документу-основанию, внести в него необходимые исправления, а затем провести и напечатать корректный чек.
