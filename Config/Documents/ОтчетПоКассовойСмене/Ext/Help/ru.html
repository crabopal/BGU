Документ "Отчет по кассовой смене"

Документ Отчет по кассовой смене предназначен для объединения данных всех чеков продажи и возврата кассовой смены для последующего отражения в бухгалтерском и налоговом учете.

Примечание. Документ Отчет по кассовой смене формируется после закрытия кассовой смены.

Работа со списком документов

Список документов вида Отчет по кассовой смене можно открыть с помощью команды Отчеты по кассовой смене группы Розничные продажи в меню функций раздела Денежные средства.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Отчеты по кассовой смене.

Заполнение документа

Для автоматического заполнения табличной части документа следует использовать кнопку Заполнить данными за смену.

Далее следует сверить данные, полученные в результате автозаполнения, с данными Отчета о состоянии ККТ, сформированного при закрытии кассовой смены.

Кассир - операционист – выбирается из справочника Сотрудники.

Для отражения в учете выручки и НДС в рознице на основании документа Отчет по кассовой смене следует ввести документы:

  • Приходный кассовый ордер – на сумму выручки наличными (с учетом возвратов) для сдачи в кассу учреждения;
  • Эквайринговая операция – для учета оплаты платежными картами (с учетом возвратов);
  • Акт об оказании услуг – для отражения в учете оказанных услуг или работ (с учетом возвратов);
  • Накладная на реализацию продукции и товаров (торг-12) – для отражения реализации продукции и товаров розничному покупателю;
  • Регистрация строки книги продаж – для учета НДС с розничных продаж.

Более подробно с особенностями работы с документом Отчет по кассовой смене можно ознакомиться в статье "Оформление розничных продаж", опубликованной на ИТС (Бухгалтерия государственного учреждения, редакция 2 – Методика ведения учета – Учет розничных продаж).
