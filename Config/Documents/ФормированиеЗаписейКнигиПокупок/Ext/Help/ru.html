Регистрация документа

Документ "Формирование записей книги покупок"

Документ Формирование записей книги покупок используется для регистрации в книге покупок счетов-фактур, выставленных поставщиками, а также иных документов, служащих основанием для принятия НДС к вычету.

Этот документ применяется также для регистрации в книге покупок счетов-фактур, оформленных на аванс полученный после реализации товаров (работ, услуг) в счет полученного аванса.

Примечание. При автозаполнении в документ попадают только те счета-фактуры, по которым НДС еще не принят к вычету и которые еще не зарегистрированы в книге покупок.

Если все счета-фактуры полученные, введенные в текущем налоговом периоде, уже зарегистрированы в книге покупок и НДС по ним принят к вычету, то документ Формирование записей книги покупок после автозаполнения может оказаться пустым.

Это будет означать, что счета-фактуры, для которых требуется регистрация в книге покупок, отсутствуют.

После заполнения и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида Формирование записей книги покупок можно открыть с помощью команды Формирование записей книги покупок меню функций раздела Налоги.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Формирование записей книги покупок.

Заполнение реквизитов шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Примечание. Документ рекомендуется вводить в конце каждого налогового периода (или месяца) для контроля за тем, чтобы все полученные счета-фактуры были отражены в книге покупок.

Заполнение реквизитов на закладках документа

Документ состоит из закладок, соответствующих причинам налогообложения:

  • Покупка;
  • Авансы полученные;
  • Авансы полученные, предъявленные комиссионером (агентом);
  • НДС налогового агента;
  • СМР хоз. способом;
  • НДС на таможне.

При нажатии на кнопку Заполнить документ командной панели формы документа табличные части закладок заполняются построчно записями книги покупок за текущий налоговый период, которые не были автоматически сформированы счетами-фактурами в момент проведения.

Несмотря на предусмотренную возможность заполнения вручную, рекомендуется производить автоматическое заполнение документа с использованием кнопки Заполнить документ.
После автоматического заполнения документа заполненные строки его табличной части можно вручную отредактировать.

Если счет-фактура по какой либо строке табличной части документа (графа Счет – фактура) не должен быть зарегистрирован в текущем налоговом периоде, то данную строку следует удалить.

Если счет-фактура по какой либо строке табличной части документа должен быть зарегистрирован в дополнительном листе книги покупок, то следует установить флаг в поле Запись доп. листа и задать в поле Корректируемый период дату регистрации счета-фактуры в прошлом налоговом периоде.

Особенности заполнения реквизитов на закладке Авансы полученные

Реквизит Счет-фактура на отгрузку – предназначен для указания счет-фактуры или списка счетов-фактур выставленных к реализации, при которой был зачтен ранее полученный аванс, и вычет будет заявляется данным документом Формирование записей книги покупок. При переходе по гиперссылке открывается форма "Счета-фактуры на отгрузку". Данные из этого реквизита выводятся в графу 7а книги покупок (дополнительного листа книги покупок) для указанного счета-фактуры на аванс и на указанную дату зачета аванса. Реквизит заполняется автоматически при заполнении табличной части закладки Авансы полученные по данным учета.

Закладка "Бухгалтерская операция"

Типовая операция – выбирается из списка Типовые операции.

Для документа предусмотрена одна типовая операция:

  • Принятие НДС к вычету.

Для данной типовой операции следует заполнить реквизит:

  • КПС для счета 303.04 – классификационный признак счета для счета 303.04. Выбирается в справочнике КПС.

Примечание. Если существует рабочий счет, то заполнение реквизита КПС для счета 303.04 необязательно.

Регистрация документа

Регистрация документа Формирование записей книги покупок производится в списке Формирование записей книги покупок.
