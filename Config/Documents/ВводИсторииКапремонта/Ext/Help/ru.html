Проведение документа

Документ "Ввод истории капитального ремонта"

Документ Ввод истории капитального ремонта и модернизации предназначен для ввода данных о капитальных ремонтах и модернизациях ОС.

Далее введенная история капитального ремонта и модернизации используется только при формировании Инвентарной карточки ОС (форма по ОКУД
0504031).

Работа со списком документов

Список документов вида Ввод истории капитального ремонта и модернизации можно открыть с помощью команды Ввод истории кап. ремонта панели навигации раздела Основные средства, НМА, НПА.

Создание нового документа

Для ввода нового документа можно нажать кнопку Создать командной панели списка Ввод истории капитального ремонта и модернизации.

Заполнение реквизитов шапки документа

Основное средство – объект ОС, для которого необходимо ввести данные о выполненных ремонтах и модернизациях. Выбирается из справочника Основные средства.

Инвентарный номер – инвентарный номер выбранного объекта ОС.

Заполнение реквизитов на закладке "Капремонт"


Сведения о проведенных капитальных ремонтах объекта ОС вводятся в табличную часть на закладке Капремонт.

Для добавления новой строки можно использовать кнопку Добавить командной панели табличной части.

Информацию о каждом капитальном ремонте, выполненном на определенную дату (колонка Дата), следует указывать в отдельной строке.

Информация о гарантийном талоне (сертификате) вводится в колонки Дата, Номер и Срок действия группы Гарантийный талон, и выводится в дальнейшем в инвентарную карточку объекта.

Заполнение реквизитов на закладке "Модернизация"


Сведения о проведенных модернизациях объекта ОС вводятся в табличную часть на закладке Модернизация.

Для добавления новой строки можно использовать кнопку Добавить командной панели табличной части.

Информацию о каждой модернизации, выполненной на определенную дату (колонка Дата), следует указывать в отдельной строке.

Проведение документа


При проведении документа производится запись информации:

о выполненных капитальных ремонтах – в регистр сведений Капитальный ремонт ОС;

о выполненных модернизациях – в регистр сведений Модернизация ОС.
