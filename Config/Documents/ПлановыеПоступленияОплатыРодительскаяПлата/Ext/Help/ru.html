Документ "Расчет платы за услуги дошкольного учреждения"

В соответствии с действующим порядком в начале очередного месяца родителям выписывается квитанция на оплату за услуги дошкольного учреждения, в которой указывается общая сумма родительской платы за месяц.

В случае оказания дополнительных платных услуг по соответствующему договору выписывается дополнительная квитанция.

Документ Расчет платы за услуги дошкольного учреждения предназначен для ввода данных об ожидаемых на заданную дату поступлениях сумм родительской платы.

Ввод плановых поступлений позволяет в дальнейшем проанализировать соответствие сумм плановых и фактических поступлений за указанный период времени.

Работа со списком документов

Список документов Расчет платы за услуги дошкольного учреждения можно открыть с помощью команды Расчет платы за услуги дошкольного учреждения меню функций раздела Платное обучение.

В форме списка предусмотрен отбор по реквизитам Организация и Группа детского учреждения.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Расчет платы за услуги дошкольного учреждения.

Заполнение реквизитов шапки документа

По каждой услуге, которая будет оказана детям или группе детей следует ввести отдельный документ Расчет платы за услуги дошкольного учреждения.

  • Дата – в качестве даты документа следует указывать первый рабочий день месяца (периода), за который должна производиться оплата;
  • Организация – детское учреждение, по которому оформляется документ Расчет платы за услуги дошкольного учреждения;
  • Группа детского учреждения – выбирается из справочника Группы детского учреждения. Задание значения реквизита Группа детского учреждения позволяет в дальнейшем использовать механизм автозаполнения табличной части документа;
  • Направление деятельности – выбирается из справочника Направления деятельности.

Положение переключателя Родительская плата выбирается для документа, с помощью которого будет выполнен расчет платы за основные услуги, то есть за присмотр и уход для заданной группы детского учреждения.

Положение переключателя Доп. образовательные услуги выбирается для документа, с помощью которого будет выполнен расчет платы за дополнительные образовательные услуги для заданной группы.

  • Расчетный период – период, за который вводятся суммы планового поступления оплаты;
  • Настройка расчета – настройка расчета родительской платы. Выбирается из справочника Настройки расчетов по родительской плате;
  • Срок оплаты– крайняя желаемая дата оплаты.

Заполнение реквизитов табличной части

Чтобы рассчитать суммы запланированной оплаты по каждому ребенку, в табличную часть следует ввести список детей, информацию о договорах по услуге, ставках оплаты, а также о льготах.

Для заполнения табличной части вручную можно использовать кнопку Добавить командной панели табличной части.

При нажатии на кнопку Заполнить командной панели табличной части выпадает меню с командами Заполнить и рассчитать и Заполнить и рассчитать, указав дополнительный отбор.

В результате использования команды Заполнить и рассчитать в табличной части появится список детей, отобранных в соответствии с заданными значениями реквизитов в шапке документа.

Использование команды Заполнить и рассчитать, указав дополнительный отбор позволяет при отборе детей в список учесть дополнительный отбор по реквизитам и свойствам справочников Дети и Договоры и иные основания возникновения обязательств.

В заполненной тем или иным способом таблице для каждого ребенка будут указаны договор, дни посещения, ставка оплаты и льгота, сумма по договору и размер задолженности, а также рассчитана сумма к оплате.

При этом для каждого ребенка будут указаны договор, дни посещения, ставка оплаты и льгота, сумма по договору и размер задолженности, а также рассчитана Сумма к оплате.

Значение реквизита Долг на начало месяца формируется как сальдо на начало месяца по счету 205.00 "Расчеты по доходам" по конкретному ребенку.

Сумма оплаты рассчитывается автоматически по формуле:

Сумма оплаты = (Фиксированная ставка за месяц * Количество месяцев + Переменная ставка за месяц * Количество месяцев * Дней посещения / Количество дней по графику + Ставка за день * Дней посещения) * (100 – Процент льготы) / 100) + Долг на начало периода

Для просмотра формулы расчета любой суммы можно поместить курсор в интересующую строку и нажать на кнопку Показать формулу расчета командной панели табличной части.

Рассчитанные значения Суммы к оплате можно скорректировать вручную.

Для того чтобы сторнировать суммы плановых поступлений, необходимо ввести новый документ Расчет платы за услуги дошкольного учреждения с установленным в необходимых строках флагом Аннулировано.

Примечание. При проведении документа суммы во всех отмеченных строках будут полностью сторнированы.
