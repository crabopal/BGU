Документ «Приказ (образование)»

Документ Приказ (образование) используется для изменения состояния учащихся, например, Зачисление, Отчисление, а также используется для краткосрочных договоров, когда изменяется ставка оплаты, назначенные льготы и т.д. Действие, выполняемое приказом, определяется реквизитом Вид приказа.

Работа со списком документов

Список документов Приказы (образование) можно открыть с помощью команды Приказы (образование) меню функций раздела Платное обучение.

Создание нового документа

Для создания нового документа можно нажать на кнопку Создать командной панели формы списка Приказы (образование).

Заполнение реквизитов шапки документа
  • Дата – дата создания приказа;
  • Организация – наименование организации. Выбирается из справочника Организации;
  • Вид приказа – выбирается из справочника Виды приказов. Реквизит Вид приказа определяет состав полей табличной части и состояние учащихся, которое будет для них установлено в результате проведения документа;
  • Начало действия – дата начала действия приказа;
  • Факультет – факультет образовательного учреждения. Выбирается из справочника Подразделения.

Заполнение табличной части

Табличную часть документа можно заполнить вручную, добавляя учащихся с помощью кнопки Добавить командной панели табличной части или автоматически, с помощью кнопки Заполнить.

Автоматический вариант заполнения выбирается из меню, которое появляется после нажатия на кнопку Заполнить:

  • Учащимися по отбору. Данный вариант позволяет выполнить отбор среди актуальных учащихся факультета, указанного в шапке документа.
  • Учащимися по отбору (без факультета). Данный вариант позволяет выполнить отбор среди всех актуальных учащихся, без учета факультета.

После использования того или иного автоматического варианта заполнения в табличной части будет заполнена только колонка Учащийся.

Использование режима Заполнить – Поля значениями позволяет автоматически заполнить остальные поля приказа заданными значениями по всем строкам.

Пример. Для зачисления учащихся в учебное значение используется Приказ (образование) с реквизитом Вид приказа, имеющим значение Зачисление на обучение. Для данного Вида приказа в справочнике Виды приказов в организации были установлены поля Курс, Специальность, Группа и Ставка оплаты. При этом все поля определены как обязательные к заполнению. После заполнения тем или иным способом колонки Учащийся следует нажать на кнопку Заполнить и выбрать пункт Поля значениями. Появится диалог Настройка заполняемых полей, в котором следует задать значения для реквизитов Курс, Специальность, Группа и Ставка оплаты. После нажатия на кнопку Заполнить документ все поля во всех строках документа, кроме поля Льгота, будут заполнены.
