Документ "Заявка-обоснование закупки малого объема"

Документ Заявка-обоснование закупки малого объема применяется для формирования в электронном виде расчета потребности в финансовом обеспечении расходов закупки товаров, работ, услуг для собственных хозяйственных нужд учреждения или в целях обеспечения хозяйственных нужд другого учреждения в соответствии с переданными полномочиями по закупке товаров, работ, услуг, осуществляемых в соответствии с п. 4, 5 и 28 ч. 1 ст. 93 Федерального закона от 5 апреля 2013 г. № 44-ФЗ "О контрактной системе в сфере закупок товаров, работ, услуг для обеспечения государственных и муниципальных нужд".

Заявка заполняется работником учреждения (подотчетным лицом), который осуществляет закупки товаров, работ, услуг малого объема для собственных хозяйственных нужд учреждения, на каждый идентификационный код закупки из плана закупок.

После заполнения и записи документа по кнопке Печать – Заявка-обоснование закупки малого объема может быть распечатана ф. 0504518 "Заявка-обоснование закупки товаров, работ, услуг малого объема".

Работа со списком документов

Для ввода нового документа можно нажать кнопку Создать командной панели списка Заявки обоснования закупки товаров, работ, услуг малого объема.

Заполнение реквизитов шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Подразделение – структурное подразделение учреждения. Выбирается из справочника Подразделения.

Идентификационный код закупки – идентификационный код закупки из плана закупок.

Срок выдачи, дней – указывается, на сколько дней сотруднику выдается подотчетная сумма на осуществление закупки.

Вид оплаты – выбирается из списка и может принимать значения:

  • Перечисление на расчетный счет;
  • Оплата наличными через подотчетное лицо;
  • Оплата по карте через подотчетное лицо.

Документ-основание, номер, дата – указывается наименование, номер и дата плана-графика, в соответствии с которым осуществляется закупка товаров, работ, услуг малого объема. Документ-основание выбирается из справочника Виды первичных документов, а также может быть указан вручную.

Закладка "Товары, работы, услуги"

Номенклатура – товары, работы или услуги, закупаемые организацией или подотчетным лицом в соответствии с государственным или муниципальным контрактом, а также в рамках предпринимательской деятельности. Выбирается из справочника Номенклатура.

ОКПД – код номенклатуры по Общероссийскому классификатору видов экономической деятельности, продукции и услуг.

Ед. изм. – учетная единица измерения (шт, кг, м и т.д.).

Примечание. Если карточка номенклатуры содержит значения реквизитов ОКПД и Единица измерения, то эти значения будут автоматически подставлены в соответствующие поля табличной части документа.

Количество – количество закупаемых товаров, работ, услуг в соответствии с единицей измерения для выбранной номенклатуры.

Цена – цена планируемых расходов, вводится вручную.

Сумма – рассчитывается автоматически как произведение Количества и Цены. Если ввести Сумму вручную без заполнения Количества и Цены, то Цена будет установлена равной Сумме, а Количеству будет присвоено значение "1".

Обеспечение – реквизит виден, при выборе в шапке документа Видов оплаты: оплата наличными через подотчетное лицо или оплата по карте через подотчетное лицо. Значение способа обеспечения финансирования планируемых расходов, устанавливается путем выбора из предложенного списка значений: Выдача денежных средств под отчет, Выдача денежных документов под отчет.

КФО – код финансового обеспечения, выбирается из списка КФО.

КПС – классификационный признак счета, выбирается из справочника Классификационные признаки счетов (КПС).

КЭК – код экономической классификации, выбирается из справочника Коды экономической классификации (КЭК).

Финансовый год – финансовый год, на который осуществляется закупка товаров, работ, услуг.

Наличие ЛБО – отметка о наличии (отсутствии) лимитов бюджетных обязательств. Проверка наличия ЛБО осуществляется по кнопке Проверить наличие ЛБО.

Дополнительная информация – при наличии, указывается дополнительная информация по закупке.

Раздел лицевого счета – раздел лицевого счета. Выбирается из справочника Разделы лицевых счетов.

Закладка "Сведения о закупке"

На закладке указывается справочная информация, формируемая из данных единого агрегатора торговли.

В группе реквизитов Объявление о закупке – указывается наименование, номер и дата размещения извещения - документа, являющегося основанием объявления закупки товаров, работ, услуг малого объема.

Статус закупки – переключатель устанавливается в одно из положений в зависимости от соответствующего статуса закупки: Не проводилась, Не состоялась, Состоялась.

Договор – выбирается из справочника Договоры и иные основания возникновения обязательств.

Закладка "Подотчетное лицо"

Закладка Подотчетное лицо становится доступна для заполнения при выборе в шапке документа Видов оплаты: оплата наличными через подотчетное лицо или оплата по карте через подотчетное лицо.

Подотчетное лицо – подотчетное лицо, которое осуществляет закупки товаров, работ, услуг малого объема. Выбирается из справочника Сотрудники.

Руководитель подразделения – руководитель подразделения подотчетного лица. Выбирается из справочника Сотрудники.

Группа реквизитов Задолженность по ранее выданным авансам заполняется автоматически по данным расчетно-платежных документов по выданным авансам. По кнопке Обновить можно обновить данные по задолженности подотчетного лица.

  • Валюта – заполняется значением, соответствующим валюте задолженности.
  • Задолженность – сумма задолженности подотчетного лица по ранее выданным авансам.
  • По отчетам на проверке – сумма задолженности подотчетного лица по отчетам на проверке, заполняется вручную.
  • Просроченная – сумма просроченной задолженности подотчетного лица по ранее выданным авансам, заполняется вручную.

Закладка "Бухгалтерская операция"

Реквизит Типовая операция имеет по умолчанию значение Принятие обязательств по выплате подотчетному лицу и при проведении формирует проводки по принятию обязательств, в т.ч. денежных обязательств по предполагаемым расходам подотчетного лица со способом обеспечения Выдача денежных средств под отчет.

Реквизиты типовой операции:

  • Принять (бюджетные обязательства) – если флажок установлен, то будут при проведении также приняты (бюджетные) обязательства.
  • Бюджетные данные без детализации по КОСГУ – если флажок установлен, то в проводке принятия обязательств по стороне дебета будет установлено КОСГУ 000.

Также в нижней части документа указываются данные ответственных лиц, которые утверждают документ: Руководитель учреждения, Руководитель финансово-экономического подразделения, Ответственное лицо контрактной службы, Ответственный исполнитель бухгалтерской службы.

Дополнительные возможности
