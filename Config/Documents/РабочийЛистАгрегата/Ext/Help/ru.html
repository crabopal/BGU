Документ "Рабочий лист агрегата"

Документ Рабочий лист агрегата предназначен для формирования и печати неунифицированной первичного документа для учета работы двигателя стационарного (передвижного) агрегата (станции), теплового агрегата, силовой установки, специального оборудования с приводом от двигателя базового шасси и иных аналогичных объектов основных средств.

В одном документе можно указать данные одного агрегата, материально ответственного лица, а также произвольное количество строк, в каждой из которых содержится информация о машинисте-операторе и результатах работы агрегата.

Работа со списком документов

Документы вида Рабочий лист агрегата содержатся в Журнале учетных листов агрегатов, который можно открыть с помощью команды Журнал учетных листов агрегатов меню функций раздела ГСМ.

Создание нового документа

Для ввода нового документа можно нажать на кнопку Создать командной панели списка Журнала учетных листов агрегатов и выбрать в списке Рабочий лист агрегата.

Заполнение реквизитов шапки документа

Реквизиты Организация и Дата заполняются автоматически. При необходимости их можно изменить.

Важно!
Списание ГСМ в бухгалтерском учете происходит на указанную дату документа после заполнения и проведения документа.
  • Агрегат – выбирается из справочника Основные средства.
  • Срок действия – дата окончания действия Рабочего листа агрегата.

Марка двигателя и Номер двигателя агрегата – заполняются автоматически при выборе агрегата, согласно данным, указанным в регистре Паспорта транспортных средств, расположенном на закладке Инвентарный объект соответствующего элемента справочника Основные средства, НМА, НПА (свойства Модель двигателя и Номер двигателя).

  • МОЛ – материально ответственное лицо. Выбирается из справочника Сотрудники.

Закладка "Общие сведения"
  • Подразделение – структурное подразделение, ответственное за эксплуатацию агрегата. Данный реквизит предназначен для организации в обособленном подразделении отдельной нумерации документов.Выбирается из справочника Подразделения;

Примечание. Установка флажка Обособленная нумерация документов в карточке обособленного подразделения позволяет реализовать в данном подразделении обособленную нумерацию документов с префиксом, указанном в поле Префикс.
  • Руководитель подразделения – выбирается из справочника Сотрудники;
  • Запланировано моторесурсов – количество запланированной работы агрегата по данному рабочему листу;
  • Единица измерения – единица измерения запланированных моторесурсов.

Флажки Выдан МОЛ и Получен от МОЛ устанавливаются соответственно при выдаче рабочего листа агрегата материально-ответственному лицу и при его получении для таксировки.

Печать документа

Чтобы распечатать рабочий лист агрегата, документ необходимо предварительно записать с помощью кнопки Записать командной панели формы документа. Для формирования печатной формы документа следует нажать кнопку Рабочий лист агрегата.

Правильно заполненный документ следует провести и закрыть с помощью кнопки Провести и закрыть.

Ввод данных рабочего листа агрегата по окончании работ

В общем случае по окончании работ рабочий лист агрегата сдается для расчета расхода ГСМ. Если требуется сохранить данные из рабочего листа, которые были внесены вручную, то можно открыть документ, соответствующий рабочему листу, и ввести в него эти данные.

Для ввода указанных данных используется закладка Результаты.

Дополнительные возможности

После получения заполненного рабочего листа агрегата на основании документа Рабочий лист агрегата для расчета нормативного и фактического расхода, а также списания ГСМ следует ввести документ Таксировка учетного листа агрегата.

Для ввода Таксировки учетного листа агрегата можно использовать гиперссылку Ввести таксировку в левом нижнем углу формы документа.
