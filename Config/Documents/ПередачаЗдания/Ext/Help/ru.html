Документ "Передача здания (сооружения)"

Для оформления и учета операции по передаче здания или сооружения используется документ "Передача здания (сооружения) (Акт приема - передачи ОС-1а)".

Документ позволяет оформить следующие операции:

  • безвозмездная передача;
  • безвозмездная передача кап. вложений;
  • возврат контрагенту (аренда, хранение)
  • передача НФА по договору аренды/безвозмездного пользования;
  • передача объектов ОС учредителю;
  • реализация объектов ОС.

После заполнения и записи документа можно сформировать печатную форму "Акт о приеме – передаче здания (сооружения) ОС-1а" (форма по ОКУД 0306030).

Также после заполнения реквизитов бухгалтерской операции и проведения документа можно сформировать бухгалтерскую справку по ф. 0504833.

Работа со списком документов

Список документов вида "Передача здания (сооружения)" можно открыть с помощью команды "Передача зданий (сооружений)" панели навигации раздела "Основные средства, НМА, НПА".

Создание нового документа

Для ввода нового документа можно нажать на кнопку "Создать" командной панели списка "Передача зданий (сооружений)".

Заполнение реквизитов шапки документа

В первую очередь необходимо заполнить реквизиты "Организация" и "Дата".

"Лицевой счет" – выбирается из справочника "Реквизиты лицевых счетов".
"Дата списания с бухгалтерского учета" – дата списания объекта ОС в бухгалтерском учете.

Вид передачи – может принимать значения:

  • Передача собственных ОС, НМА, НПА на балансе (101.00, 102.00, 103.00);
  • Передача собственных ОС, НМА, НПА в оперативном учете (21);
  • Передача кап. вложений (106.00);
  • Возврат ОС, НМА, НПА, полученных по договорам пользования (01);
  • Возврат ОС, НМА, НПА, принятых на хранение (02);
  • Передача ОС, НМА, НПА в аренду (25);
  • Передача ОС, НМА, НПА в безвозмездное пользование (26).

В группе "Получатель" заполняются реквизиты:

  • "Контрагент" – выбирается из справочника "Контрагенты";
  • "Договор" – выбирается из справочника "Договоры или иные основания возникновения обязательств";
  • "р/счет" – расчетный счет контрагента. Выбирается в справочнике "Банковские и казначейские счета".

В группе "Место хранения (отправитель)" заполняются реквизиты:

  • "МОЛ/Место хранения" – центр материальной ответственности. Выбирается из справочника "Центры материальной ответственности";
  • "Подразделение" – подразделение организации. Выбирается из справочника "Подразделения".

Заполнение реквизитов на закладке "Сведения об основном средстве"

В группе "Сведения о передаваемом объекте (ОС, НПА)" заполняются реквизиты:

  • "КФО" – код финансового обеспечения. Выбирается в справочнике "КФО";
  • "КПС" – классификационный признак счета. Выбирается в справочнике "КПС";
  • "Объект" – объект основного средства. Выбирается из справочника "Основные средства";
  • "Инв. номер" – инвентарный номер.

Если по выбранному объекту основных средств ведется групповой учет, то инвентарный номер выбирается из справочника "Инвентарные номера ОС". Если групповой учет по объекту ОС не ведется, то инвентарный номер подставляется автоматически.

Группа реквизитов "Основание для составления акта":

  • "Приказ, распоряжение, договор" – наименование документа-основания с указанием его вида и основных обязательств"
  • "№" – номер документа-основания;
  • "от" – дата документа-основания.

Группа реквизитов "Стоимость":

  • "Балансовая стоимость" – балансовая стоимость объекта ОС;
  • "Амортизация" – начисленная амортизация объекта ОС.

Реквизиты "Балансовая стоимость" и "Амортизация" заполняются автоматически после нажатия на кнопку "Рассчитать стоимость ОС".

Внимание!
Заполнение реквизитов "Цена продажи", "Ставка НДС", а также управление порядком отражения НДС с помощью установки или снятия флага "Сумма включает НДС" выполняются только для операции "Реализация объекта основных средств".

Заполнение реквизитов на закладке "Комиссия"

Группа "Председатель комиссии" включает реквизиты "Должность", "Фамилия", "Имя" и "Отчество".

Информация о должности, фамилии, имени и отчестве каждого члена комиссии вводится в табличную часть закладки.

Примечание. Если в организации уже создана комиссия с необходимыми обязанностями, то ее можно выбрать из справочника "Постоянно действующие комиссии", который можно открыть с помощью команды "Выбрать из постоянно действующих комиссий". После выбора комиссии все реквизиты на закладке будут заполнены автоматически.

Заполнение реквизитов на закладке "Бухгалтерская операция"

"Типовая операция" – выбирается из списка "Типовые операции".

Примечание. Если на передаваемый объект ОС начисляется амортизация, то при проведении документа на данный объект будет начислена амортизация за месяц передачи.

Безвозмездная передача

Для данной типовой операции необходимо заполнить реквизиты:

  • "Счет передачи" – выбирается из фрагмента "Плана счетов (ЕПСБУ)". Может принимать значение "304.04" или "401.20";
  • "КЭК (для счета 401.20)" – код экономической классификации. Выбирается из фрагмента справочника "КЭК", содержащего только актуальные для данной операции значения "КЭК".

Безвозмездная передача кап. вложений

Для данной типовой операции необходимо заполнить реквизиты:

  • "Вид затрат" – выбирается из справочника "Виды затрат".

Группа реквизитов "Счет передачи":

  • "Счет передачи" – выбирается из фрагмента "Плана счетов (ЕПСБУ)". Может принимать значение "304.04" или "401.20";
  • "КЭК (для счета 401.20)" – код экономической классификации. Выбирается из фрагмента справочника "КЭК", содержащего только актуальные для данной операции значения "КЭК".

Возврат контрагенту (аренда, хранение)

Дополнительные реквизиты у данной типовой операции отсутствуют.

Передача НФА по договору аренды / безвозмездного пользования

Дополнительные реквизиты у данной типовой операции отсутствуют.

Передача объектов основных средств учредителю

Для данной типовой операции необходимо заполнить реквизиты:

  • "КПС" – классификационный признак счета. Выбирается из справочника "КПС".

Реализация объектов основных средств

Для данной типовой операции необходимо заполнить реквизиты:

  • "КПС" – классификация доходов бюджета. Выбирается в справочнике "КПС";
  • "Начислять НДС" – установка флага задает начисление НДС.

Группа реквизитов "Начисление дохода":

  • "Не администратор дохода (флаг установлен – 303.05.730, не установлен – 401.10.172)" – установка флага производится, если организация не является администратором дохода;
  • "Вид налогов и платежей (для счета 303.05)" – выбирается из справочника "Виды налогов и платежей".

Регистрация документа

Регистрация документа "Передача зданий (сооружений)" производится в журнале "Документы по основным средствам".

Дополнительные возможности

На основании документа "Передача зданий (сооружений)" можно ввести документы "Счет – фактура выданный" и "Сторно".
