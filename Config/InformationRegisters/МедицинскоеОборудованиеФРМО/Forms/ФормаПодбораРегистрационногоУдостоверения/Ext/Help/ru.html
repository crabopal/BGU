Регистрационные удостоверения


Форма подбора регистрационного удостоверения.
Поиск осуществляется через сервис 1С:ФНСИ по классификатору "Справочник регистрационных удостоверений и моделей по классификации Росздравнадзора".
Для работы с сервисом требуется подключенная интернет-поддержка (с 01.09.2026 будет требоваться договор ИТС уровня ПРОФ).

Если отборы не заданы, то поиск осуществляется по типу медицинского изделия. Результат поиска можно уточнить, задав отборы:
 - Номер: номер регистрационного удостоверения, поиск по полному совпадению;
 - Модель: наименование модели, поиск по вхождению в любом месте без учета регистра.

Вывод результата поиска выполняется постранично. Количество записей на странице задается в поле "на странице". Если результат содержит больше одной страницы, то в подвале формы отображаются кнопки навигации по страницам.

Классификатор на сайте ФНСИ Минздрава.
