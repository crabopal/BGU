Настройки обмена с ФРМО


Организация - медицинская организация, для которой выполняется настройка обмена;
Подключение - Способ подключения к ИПС ЕГИСЗ для обмена с ФРМО;
Идентификатор (OID) - идентификатор организации в реестре идентификаторов объектов Минздрава России. Должен начинаться с "1.2.643.5.1.13.13.12" (найти в Реестре ФНСИ Минздрава);
Кнопка со стрелкой - загрузка идентификатора организации (OID) по ИНН и КПП организации из сервиса 1С:ФНСИ из классификатора "Реестр медицинских и фармацевтических организаций Российской Федерации".


Способы подключения

Напрямую к ИПС ЕГИСЗ

прямое подключение к интеграционной подсистеме интеграции прикладных подсистем ЕГИСЗ для обмена с подсистемой ФРМО;

Адрес сервиса - адрес веб-службы ФРМО вместе с идентификатором веб-службы, через "/". Идентификатор указывается в заявке на подключение в таблице 2. Например "ips.rosminzdrav.ru/13e078133bbb4";
Кнопка с замком - использовать защищенное соединение (https) или не использовать (http);
Идентификатор ИС - идентификатор информационной системы в ИПС, указывается так же в заявке на подключение (найти в Реестре информационных систем);
Сертификат - сертификат ключа электронной подписи, которым будут подписываться запросы. Алгоритмом подписи должен быть ГОСТ Р 34.10-2012 с длиной ключа 256;
Пароль - пароль сертификата.

Через сервис "1С:ЕГИСЗ"

подключение через сервис 1С:ЕГИСЗ в защищенном сегменте облачной платформы "1C:Fresh". Для подключения необходимо подать заявку на Подключение к ФРМО/ФРМР ЕГИСЗ.

Ключ доступа - уникальный ключ доступа организации, для доступа к сервису. Сообщается в ответном сообщении на подключение;

Через ГИС субъекта "1С:Медицина.Регион"

подключение через конфигурацию 1С:Медицина. Регион, выступающей в роли прокси-сервера, выполняющей роль "Иной информационной системы в здравоохранении" для подключения к подсистеме ФРМО в ЕГИСЗ.

Адрес сервиса - адрес публикации сервиса ФРМО/ФРМР в Регионе;
Кнопка с замком - использовать защищенное соединение (https) или не использовать (http);
Ключ доступа - внутренний идентификатор МИС, указанный в плане обмена "Медицинские информационные системы региона";
Логин и Пароль  - учетная запись для подключения к Региону. В случае анонимного доступа поля остаются пустыми.


Выполнять обмен на клиенте - Если флаг установлен, то обмен с ФРМО будет выполняться на клиенте. Если флаг снят, обмен с ФРМО будет выполняться на сервере. При работе через web-клиент настройка игнорируется, обмен выполняется на сервере.
