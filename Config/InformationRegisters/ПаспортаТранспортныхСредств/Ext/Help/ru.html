Регистр сведений "Паспорта транспортных средств"

Регистр сведений Паспорта транспортных средств предназначен для хранения сведений из паспортов транспортных средств, а также иных дополнительных данных.

Вызов регистра сведений

Для вызова регистра сведений Паспорта транспортных средств можно использовать гиперссылку Паспорта транспортных средств на закладке Инвентарный объект карточки основного средства.

Заполнение карточки "Паспорта транспортных средств"

При вводе данных в карточку Паспорта транспортных средств необходимо заполнить следующие реквизиты:

  • Период – дата, с которой действуют сведения.
  • Организация – учреждение, на балансе которого учитывается транспортное средство.
  • Основное средство – транспортное средство.
  • Инвентарный номер – инвентарный номер транспортно средства.

Группа Основная информация

  • Паспорт (серия, номер) – номер технического паспорта транспортного средства.
  • Идентификационный номер (VIN).
  • Марка – марка транспортного средства.
  • Модель – модель транспортного средства.
  • Тип – тип транспортного средства.
  • Модель двигателя – марка двигателя транспортного средства/агрегата.
  • Номер двигателя – номер двигателя транспортного средства/агрегата.
  • Номер шасси (рамы) – номер шасси (рамы) транспортного средства/агрегата.
  • Номер кузова (кабины, прицепа) – номер кузова (кабины, прицепа)
  • Экологический класс – переключатель, может принимать значения 0, 1, 2, 3, 4, 5 или 6.
  • Масса без нагрузки (кг) – масса транспортного средства по паспорту.

Группа Дополнительная информация

  • Гаражный номер.
  • Грузоподъемность.
  • Колонна.

Группа Свидетельство о регистрации

  • Регистрационный знак – знак государственной регистрации транспортного средства.
  • Дата регистрации – дата постановки транспортного средства на учет в ГИБДД (ГАИ).
  • Дата снятия с учета – дата снятия с учета в ГИБДД (ГАИ).
