Регистр сведений "Настройки округления результата расчета нормативного расхода ГСМ"

Регистр сведений Настройки округления результата расчета нормативного расхода ГСМ предназначен для установки режима округления результатов расчета нормативного расхода ГСМ.

Для заполнения регистра Настройки округления результата расчета нормативного расхода ГСМ можно использовать команду Настройки округления результата расчета нормативного расхода ГСМ меню функций раздела ГСМ.

Заполнение реквизитов

Наименование – наименование поправочного коэффициента.

Настройки действуют с – указать дату, с которой начинают действовать настройки.

Организация – учреждение, для которого задается настройка.

Вид ГСМ – заполняется только, если для данного вида ГСМ настройки режима округления будут отличаться от настроек режима округления для всей организации.

Количество знаков дробной части – направление округления знаков дробной части. Для округления в большую сторону следует указать в поле "Округлять 1,5 до" значение "2", в меньшую – "1".

Примечание. Для смазочных материалов и специальных жидкостей количество знаков дробной части желательно устанавливать равным 3, т.к. в противном случае небольшой расход смазочных материалов по путевому листу может постоянно округляться до 0, что исказит корректность данных расхода за период.

Для сохранения настроек следует нажать кнопку Записать и закрыть.
