Для вызова формы Параметры компенсации родительской платы можно использовать гиперссылку Настроить расчет компенсации родительской платы в группе Учет расчетов за содержание детей в ДДУ на странице Специализированные подсистемы формы Настройка параметров учета раздела Администрирование.

Группа Способ расчета компенсации

Способ расчета компенсации – база для расчета компенсации родительской платы. Может принимать значения:

  • По фактической оплате.
  • По среднемесячной по региону.

В случае выбора значения По среднемесячной по региону в форме появляется группа реквизитов Настройка расчета по средней:

  • Вид ставки – может принимать значения Дневная или Месячная.
  • Ставка – значение ставки в рублях, задается числом.
  • Действует с – дата начала действия ставки.

Группа Организация, осуществляющая учет компенсации родительской платы

Организация – организация, ведущая учет начисленной и выплаченной компенсации родительской платы. Заполняется, если организация ведет бухгалтерский учет по нескольким дошкольным образовательным учреждениям, например является централизованной бухгалтерией. Выбирается из справочника Организации.

Группа Сводное начисление компенсации

Начислять компенсацию родительской платы сводно – флажок, после установки которого компенсация родительской платы будет начисляться сводно. При снятом флажке компенсация начисляется по получателям.

Группа Контрагент по умолчанию

Контрагент – контрагент для учета начислений компенсаций родительской платы сводно, в случае, флажок Начислять компенсацию родительской платы сводно установлен. Выбранное значение используется в дальнейшем как значение субконто по умолчанию для счета 302.62 при проведении документа Начисление компенсации родительской платы.
