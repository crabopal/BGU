Регистр сведений «Пользовательские выражения полей форматов обмена с казначейством/банком»

В регистре сведений хранится информация о пользовательских выражениях полей форматов обмена, которые используются при экспорте/импорте документами "Задание на экспорт"/"Задание на импорт", вместо выражений, указанных в формате обмена.

В регистре содержатся следующие данные:

- Формат обмена - формат обмена для которого будет использоваться данное пользовательское выражение;

- Обрабатываемое поле - имя поля, для которой будет использоваться данное пользовательское выражение ("Значение", "Порядок заполнения", "Дополнительные действия", "Служебные пометки/доп. условия включения секций");

- Поле файла - значение поля "Поле файла" из табличной части "Правила обмена" справочника "Форматы", по этому полю происходит связь пользовательских выражений со строками табличной части "Правила обмена" справочника "Форматы";

- Номер строки - содержит номер строки табличной части "Правила обмена" - если в табличной части "Правила обмена" справочника "Форматы" имеются несколько строк с одинаковым значением в колонке "Поле файла", то в поле "Номер строки" необходимо указать тот номер строки, для которой необходимо применять данное пользовательское выражение (если указано значение "0", то данное правило применяется для всех строк с указанными значением в поле "Поле файла", приоритет у правил с указанием номера строки);

- Выражение в формате обмена - значение поля, укзанное в табличной части в справочнике "Форматы"(на форме не редактируется);

- Пользовательское выражение - значение поля, которое указывает пользователь, будет применяться вместо значения, отображенного в поле "Выражение в формате обмена";

- Использовать - признак использования данного пользовательского выражения.
