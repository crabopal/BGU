Регистр сведений "Корректные корреспонденции счетов"

Регистр сведений Корректные корреспонденции счетов предназначен для хранения корректных корреспонденций счетов бухгалтерского учета.
В список корректных корреспонденций типовой конфигурации программы включены только корреспонденции счетов, приведенные в действующих Инструкциях по применению плана счетов бюджетного и бухгалтерского учета, утв. приказами Минфина России от 06.12.2010 № 162н, от 16.12.2010 № 174н и от 23.12.2010 № 183н.
Регистр сведений Корректные корреспонденции счетов используется при проведении Технологического анализа для выявления корреспонденций счетов, не согласующихся с корректными корреспонденциями счетов, установленными Инструкциями по применению плана счетов, утв. приказами Минфина России от 06.12.2010 № 162н, от 16.12.2010 № 174н и от 23.12.2010 № 183н.

Работа с регистром

Регистр сведений Корректные корреспонденции счетов можно открыть с помощью команды Корректные корреспонденции счетов меню функций раздела Учет и отчетность.

Создание нового элемента

Чтобы Технологический анализ при каждой проверке не выводил отсутствующие корреспонденции счетов как некорректные – их следует самостоятельно ввести в регистр сведений Корректные корреспонденции счетов. Например, данные корреспонденции счетов вводятся, если используются в учете, являются правомерными и утверждены учетной политикой учреждения.

Примечание. Перед тем как добавить в регистр сведений Корректные корреспонденции счетов корреспонденции, отмеченные Технологическим анализом, как ошибочные, следует проверить их на правомерность применения в учете. Если операции будут признаны неправомерными, то необходимо внести исправления в учет и не использовать в дальнейшем данные корреспонденции.

Недостающие корреспонденции счетов можно ввести в регистр сведений Корректные корреспонденции счетов двумя способами:

  • добавлением каждой корреспонденции счетов в регистр;
  • загрузкой корреспонденций счетов из заранее подготовленного файла.

Внимание!
Редактировать регистр сведений Корректные корреспонденции счетов может только пользователь с ролями Добавление Изменение Настроек Плана Счетов и Полные Права.

Добавление каждой корреспонденции счетов в регистр

Для добавления корреспонденции счетов в регистр сведений следует нажать на кнопку Создать командной панели формы Корректные корреспонденции счетов.
Далее в полях Дебет и Кредит указать счета создаваемой корреспонденции, путем выбора из Плана счетов (ЕПСБУ).
В поле Комментарий следует указать текст - содержание корреспонденции счетов, который может быть выведен в отчетах Журнал операций (ф.0504071), в графе Содержание операции, с включенным флажком Сворачивать однотипные проводки.
Для сохранения созданной корреспонденции счетов в регистре сведений следует нажать кнопку Записать и закрыть.

Загрузка корреспонденций счетов в регистр из файла

В случае если необходимо добавить много корреспонденций счетов и в несколько информационных баз, то следует воспользоваться загрузкой корреспонденций счетов из предварительно заполненного файла с расширением .mxl.

Файл должен иметь следующую структуру:

  • - в графе указывается счет учета, применяющийся в дебете корреспонденции. Например, 104.34;
  • - в графе указывается дата начала действия выбранного в дебете счета, которая указана в Плане счетов (ЕПСБУ);
  • - в графе указывается счет учета, применяющийся по кредиту корреспонденции. Например, 104.36;
  • - в графе указывается дата начала действия выбранного по кредиту счета, которая указана в Плане счетов (ЕПСБУ);
  • - текст - содержание корреспонденции счетов, который может быть выведен в отчетах Журнал операций (ф.0504071), в графе Содержание операции, с включенным флажком Сворачивать однотипные проводки.

Далее для загрузки корреспонденций счетов в регистр из файла следует нажать кнопку Загрузить корректные корреспонденции. В открывшейся форме следует установить переключатель в режим Заполнить данными из файла, в поле Имя файла следует указать путь до файла с заполненными корреспонденциями счетов. Далее для начала загрузки следует нажать кнопку Загрузить.

Чтобы найти внесенные в регистр корреспонденции счетов, можно воспользоваться панелью поиска в форме регистра сведений Корректные корреспонденции счетов.
