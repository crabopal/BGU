Регистр сведений "Настройки ККТ и эквайринга для рабочих мест"

Регистр сведений Настройки ККТ и эквайринга для рабочих мест предназначен для хранения настроек, определяющих использование на указанном рабочем месте определенного терминала, фискального регистратора и параметров договора эквайринга. Данные настройки позволяют автоматически заполнять значительную часть реквизитов документа Эквайринговая операция при его создании.

Работа со списком

Список Настройки ККТ и эквайринга для рабочих мест можно открыть с помощью команды Настройки ККТ и эквайринга для рабочих мест раздела Денежные средства формы Настройка параметров учета раздела Администрирование.

Создание нового элемента

Для ввода новой настройки эквайринга можно нажать кнопку Создать командной панели формы списка Настройки ККТ и эквайринга для рабочих мест.

Заполнение реквизитов элемента справочника
  • Рабочее место – является измерением регистра, которое определяет настройки эквайринга. Создается автоматически. Выбирается из справочника Рабочие места;
  • Параметры договора эквайринга – значение выбирается из справочника Параметры договора эквайринга.
  • Параметры договора платежного агента – значение выбирается из справочника Параметры договора платежного агента.

Примечание. Реквизит Параметры договора платежного агента доступен для заполнения только при установленном флажке Использовать настройки платежного агента в разделе Администрирование – Настройка параметров учета – Денежные средства.

Группа Оборудование:

  • Касса ККМ – значение выбирается из справочника Кассы ККМ (фискальные регистраторы);
  • Эквайринговый терминал – значение выбирается из справочника Эквайринговые терминалы.
