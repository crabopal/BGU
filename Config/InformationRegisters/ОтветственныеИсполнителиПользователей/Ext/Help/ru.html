Ответственные исполнители пользователей

Список ответственных можно открыть с помощью команды Ответственные исполнители пользователей меню функций раздела Справочники.

Для каждого пользователя можно установить сотрудника организации, который будет автоматически установлен в реквизит Бухгалтер на закладке Бухгалтерская операция в форме документа.

Необходимо создавать настройки только по сотрудникам, у которых по одному пользователю автоматически может быть найдено несколько сотрудников.

Если в программе указана организация, выполняющая функции централизованной бухгалтерии, то в настройке можно указать сотрудника централизованной бухгалтерии, который отвечает за проведение документов по организации, выбранной в документе.
