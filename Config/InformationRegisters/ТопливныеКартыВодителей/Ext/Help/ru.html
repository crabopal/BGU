Регистр сведений "Топливные карты водителей"

Регистр сведений Топливные карты водителей предназначен для хранения информации по топливным картам, закрепленным за конкретными водителями.

Для вызова справочника можно использовать команду Топливные карты водителей меню функций раздела ГСМ.

Заполнение реквизитов элемента справочника
  • Водитель – выбирается из справочника Сотрудники;
  • БСО – топливная карта водителя. Выбирается из справочника Бланки строгой отчетности;
  • Серия – серия топливной карты. Выбирается из справочника Серии бланков строгой отчетности;
  • Номер – номер топливной карты;
  • Количество – количество топливных карт.
