Регистр сведений "Значения показателей отчетов"

Регистр сведений "Значение показателей отчетов" предназначен для хранения значений показателей сформированных отчетов - документов "Экземпляр отчета".

Измерения регистра сведений

Экземпляр отчета

Ссылка на экземпляр отчета которыому принадлежит значение.

Показатель

Измерение "Показатель" ссылается на элемент справочника "Показали отчетов".

Индекс

Чиловой индекс строки группы раскрытия.

Ресурсы регистра сведений

Значение

Значение проказателя.

Числовое значение

Числовое значение показателя.

Длинное строковое значение

Строковое значение показателя неограниченной длинны.
