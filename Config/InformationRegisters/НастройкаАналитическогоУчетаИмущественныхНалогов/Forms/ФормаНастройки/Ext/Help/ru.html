Настройка аналитического учета имущественных налогов


Вспомогательная форма для настройки соответствия параметров расчета имущественного налога справочникам Виды налогов и платежей, Налоги и платежи организации.

Форма Настройка аналитического учета имущественных налогов открывается по виду налога: транспортный налог, земельный налог, налог на имущество с отбором по организации.

Настройка используется при заполнении документа Начисление имущественных налогов на основании документов Расчет транспортного налога, Расчет земельного налога, Расчет налога на имущество.

На основании выполненной настройки в зависимости от кода ОКТМО, по которому рассчитан налог, выполняется подстановка аналитики Вид налога и Налог для отражения в проводке по счетам 303.05, 303.12, 303.13. Для земельного налога настройка выполняется так же для КБК налога.

В поле по состоянию на указывается период (год), на который выполняется настройка. Настройка применяется с начала года и действует, пока не будет внесена новая настройка. Кнопки со стрелками служат для изменения периода. 

В зависимости от вида настраиваемого налога список ограничен территориями, где зарегистрированы транспортные средства, по месту нахождения земельных участков, где учтено недвижимое имущество.

Код по ОКТМО - код по ОКТМО, где зарегистрированы транспортные средства, территории по месту нахождения земельных участков, территории, где учтено недвижимое имущество. Заполняется автоматически.

КБК - только для земельного налога. КБК земельного налога, указанный при регистрации земельного участка. Заполняется автоматически.

Вид налога, платежа - Выбирается из справочника Виды налогов и платежей. Используется для дальнейшей автоподстановки в документ Начисление имущественных налогов.

Налоги и платежи организации - Выбирается из справочника Налоги и платежи организации. Используется для дальнейшей автоподстановки в документ Начисление имущественных налогов.
