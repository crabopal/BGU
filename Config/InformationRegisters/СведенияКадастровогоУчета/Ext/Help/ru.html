Регистр сведений "Сведения кадастрового учета"

Регистр сведений Сведения кадастрового учета предназначен для хранения сведений кадастрового учета:

  • объектов недвижимого имущества, налоговая база по которым определяется как кадастровая стоимость (ст. 378.2 НК РФ), в целях исчисления налога на имущество, авансов по налогу на имущество;
  • земельных участков в целях исчисления земельного налога.

Вызов регистра сведений

Для вызова регистра сведений Сведения кадастрового учета можно использовать гиперссылку Сведения кадастрового учета (ЕГРН) на закладке Инвентарный объект карточки основного средства.

Заполнение карточки "Сведения кадастрового учета"

При вводе данных в карточку Сведения кадастрового учета необходимо заполнить следующие реквизиты:

  • Период – дата, с которой действуют сведения.
  • Организация – учреждение, на балансе которого учитывается объект недвижимости, в т.ч. земельные участки.
  • Основное средство – объект недвижимости, налоговая база по которому определяется как кадастровая стоимость (в т.ч. земельные участки).
  • Инвентарный номер – инвентарный номер объекта недвижимости.
  • Вид объекта недвижимости – вид объекта недвижимости. Используется при печати карточки капвложений (ф.0509211).
  • Кадастровая стоимость – кадастровая стоимость объекта недвижимости, применяется в целях исчисления налога на имущество и земельного налога (авансов). В целях исчисления налога на имущество кадастровая стоимость объектов недвижимости применяется в размере, определенном на 1 января года, за который рассчитывается налог на имущество, авансовый платеж (п. 2 ст. 375 НК РФ). В целях исчисления земельного налога для земельных участков кадастровая стоимость определяется по состоянию на 1 января календарного года по результатам проведения государственной кадастровой оценки земель.
  • Кадастровый номер – кадастровый номер объекта недвижимости в соответствии с ЕГРН.
  • Кадастровый номер земли, на которой расположен объект.
  • Это помещение – флажок, после установки которого становится доступно поле для указания кадастрового номера здания.
  • Кадастровый номер здания, в котором расположен объект.
  • Условный номер – условный номер объекта в соответствии с ЕГРН. Используется при заполнении раздела 2.1 декларации по налогу на имущество.
  • Количество этажей.
  • Общая площадь здания (м2).
  • Общий строительный объем (м3).
  • Объект подземной части (м3).
