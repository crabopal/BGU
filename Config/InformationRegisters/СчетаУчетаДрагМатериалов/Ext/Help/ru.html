Регистр сведений "Настройки счетов учета МЦ с драгоценными материалами"

Предназначен только для учреждений, которые используют свои счета для учета материальных ценностей, содержащих драгоценные материалы.

В регистре сведений хранится список настроек для данных счетов.

Для вызова регистра сведений можно использовать команду Настройки счетов учета МЦ с драгоценными материалами меню функций разделов Материальные запасы и учет ОС, НМА и НПА.
