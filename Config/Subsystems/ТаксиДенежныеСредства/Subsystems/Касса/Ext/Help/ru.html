Подистема предназначна для ведения и учта расчетов через кассу.

"1С:Бухгалтерия государственного учреждения" обеспечивает ведение кассовых операций в соответствии с "Порядком ведения кассовых операций" и "Инструкцией по применению ЕПСБУ".

Учет наличных денежных средств в программе ведется на активном балансовом счете 201.34 "Касса".

Денежные документы учитываются на активном балансовом счете 201.35 "Денежные документы".

Для оформления кассовых операций с денежными средствами в программе предназначены документы вида Приходный кассовый ордер и Расходный кассовый ордер, которые позволяют распечатать заполненные ордера и сформировать проводки, отражающие операцию на счетах бухгалтерского учета.

Операции с денежными документами отражаются с помощью документов Приходный кассовый ордер (фондовый) и Расходный кассовый ордер (фондовый).

Для формирования объявления на взнос наличными предназначен документ Объявление на взнос наличными.

Формирование листов кассовой книги выполняется с помощью документа Отчет кассира, который следует вводить ежедневно – в дни работы учреждения, независимо от наличия оборотов по кассе.

Документ Инвентаризация денежных средств используется для оформления Инвентаризационной описи наличных денежных средств по ф. 0504088.

Для оформления Акта инвентаризации наличных денежных средств по ф. ИНВ-15 в программе следует использовать одноименный документ.

Работу с документами по кассе облегчает рабочее место Касса организации.

По кассовым операциям предусмотрено формирование отчетов:

  • Кассовая книга, по ф. 0504514;
  • Журнал регистрации приходных и расходных ордеров.
